상용로그

우리가 쓰는 수는 십진법이므로 밑이 10인 로그가 가장 편합니다. 이것을 상용로그라 합니다. 상용로그의 정수 부분은 수의 자릿수를, 소수 부분은 맨 앞의 숫자들을 알려 줍니다. 이 절에서는 250 같은 큰 수를 직접 계산하지 않고 몇 자리인지 알아내고, 몇 배씩 차이 나는 양을 다루기 쉬운 수로 바꾼 산성도, 지진 규모, 소리의 세기를 상용로그로 읽습니다.

  1. 질문250을 끝까지 곱하지 않고 몇 자리 수인지 알 수 있을까요? 맨 앞자리 숫자까지 알 수 있을까요?
  2. 복원loga Mk = k loga M, loga MN = loga M + loga N입니다. 102 = 100은 세 자리, 103 = 1000은 네 자리입니다.
  3. 설명밑이 10인 로그를 상용로그라 하고, 밑을 생략해 log N으로 씁니다. 양수 N을 N = a × 10n(1 ≤ a < 10, n은 정수)으로 쓰면 log N = n + log a이고 0 ≤ log a < 1입니다. 그래서 log N의 정수 부분 n은 자리의 크기를, 소수 부분 log a는 숫자의 배열을 정합니다. n ≥ 0이면 N의 정수 부분은 n + 1자리이고, n < 0이면 N은 소수점 아래 −n째 자리에서 처음으로 0이 아닌 숫자가 나옵니다. 맨 앞 숫자는 10소수 부분의 정수 부분입니다. 예: log 250 = 50 log 2 ≈ 15.05이므로 250은 16자리이고, 100.05 ≈ 1.13이라 맨 앞 숫자는 1입니다.
  4. 연결계산기가 없던 시절에는 1.00부터 9.99까지의 상용로그 값을 적은 상용로그표로 소수 부분을 찾았습니다. 정수 부분은 자릿수만 보면 되므로 표 하나로 모든 양수의 로그를 구할 수 있었습니다. 이 생각이 다음 카드의 pH, 지진 규모, 데시벨로 이어집니다.
  5. 적용320을 눌러 자릿수와 맨 앞 숫자를 확인하세요. 지수를 1씩 늘리면 아래 눈금의 점은 얼마씩 움직이고, 한 바퀴 돌 때 정수 부분은 어떻게 바뀌나요? 7−10, 2−30에서는 처음으로 0이 아닌 숫자가 소수점 아래 몇째 자리에 나오나요?
  6. 판단log N ≈ −8.45일 때 정수 부분을 −8, 소수 부분을 −0.45로 읽는 실수가 흔합니다. 소수 부분은 언제나 0 이상 1 미만이 되도록 정하므로 −8.45 = −9 + 0.55입니다. 또 정수 부분이 15이면 16자리입니다. 15자리로 답하지 않도록 100 = 1이 한 자리라는 것을 떠올리세요.

1.5.2

규모 7 지진은 규모 5 지진보다 몇 배 셀까?

  1. 질문뉴스에서 "규모 7.0"과 "규모 5.0"은 2만큼 차이 납니다. 그러면 지진이 내놓은 에너지도 두 배쯤 차이 날까요?
  2. 복원log N = k ⇔ N = 10k이고, log M − log N = log(M/N)입니다. 로그 값이 1 늘면 진수는 10배가 됩니다.
  3. 설명자연과 사회에는 아주 작은 값부터 아주 큰 값까지 몇십 자리에 걸쳐 변하는 양이 많습니다. 이런 양은 상용로그를 취해 다루기 쉬운 수로 바꾸어 씁니다. 지진의 규모 M과 에너지 E(J) 사이에는 log E = 4.8 + 1.5M이라는 관계가 알려져 있습니다. 그래서 규모가 1 크면 에너지는 101.5 ≈ 32배, 2 크면 103 = 1000배입니다. 산성도는 pH = −log[H+]([H+]는 수소 이온 농도, mol/L)이므로 pH가 1 작으면 수소 이온이 10배 많습니다. 소리의 세기 수준은 10 log(I/I0) dB(I0 = 10−12 W/m2)라서 10 dB 크면 세기가 10배입니다. 세 경우 모두 로그 값의 차가 실제 양의 비를 정합니다.
  4. 연결2016년 경주 지진(규모 5.8)과 2011년 동일본 대지진(규모 9.0)의 규모 차는 3.2이지만, 에너지는 104.8, 곧 약 6만 3천 배 차이 납니다. 별의 밝기(등급), 음계의 진동수도 같은 생각으로 정합니다.
  5. 적용지진 규모에서 두 값을 1, 2, 3만큼 차이 나게 놓고 에너지의 비를 기록하세요. pH 3인 용액과 pH 6인 용액의 수소 이온 농도는 몇 배 차이 나나요? 60 dB과 90 dB의 소리는 세기가 몇 배 차이 나나요?
  6. 판단로그 눈금에서 같은 간격은 같은 "차"가 아니라 같은 "배율"입니다. "pH 4는 pH 8보다 두 배 산성"이라고 말하면 틀립니다. 수소 이온 농도는 104배 차이 납니다. 그림의 예시 값은 대표적인 대략값이고, 실제 레몬즙이나 대화 소리의 값은 상황에 따라 다릅니다. 또 데시벨은 세기의 비를 나타낼 뿐, 귀가 느끼는 크기와 정확히 비례하지는 않습니다.
