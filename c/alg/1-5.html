상용로그

우리가 쓰는 수는 십진법이므로 밑이 10인 로그가 가장 편합니다. 이것을 상용로그라 합니다. 상용로그의 정수 부분은 수의 자릿수를, 소수 부분은 맨 앞의 숫자들을 알려 줍니다. 이 절에서는 \(2^{50}\) 같은 큰 수를 직접 계산하지 않고 몇 자리인지 알아내고, 몇 배씩 차이 나는 양을 다루기 쉬운 수로 바꾼 산성도, 지진 규모, 소리의 세기를 상용로그로 읽습니다.

먼저 알면 좋은 것 로그의 뜻로그의 성질과학적 표기 \(a \times 10^n\)

상용로그

본문

종이를 50번 접을 수 있다면 두께는 처음의 \(2^{50}\)배가 된다. 이 수는 계산기로도 다 나타내기 어렵다. 그런데 정확한 값을 몰라도 몇 자리 수인지, 맨 앞자리 숫자가 무엇인지는 알 수 있다. 어떤 도구를 쓰면 될까?

먼저 알아야 할 것로그의 뜻과 성질(로그), 과학적 표기 \(a \times 10^n\ (1 \le a < 10)\).

1.5.1밑이 10인 로그

우리는 수를 10진법으로 쓴다. 그래서 밑이 10인 로그가 특히 쓸모 있다. 밑이 10인 로그 \(\log_{10} N\)을 상용로그라 하고, 밑을 생략해 \(\log N\)으로 쓴다. \(\log 10 = 1\), \(\log 100 = 2\), \(\log 1000 = 3\)이므로, 상용로그는 수가 10의 몇 제곱 정도인지를 알려 준다.

어떤 양수 \(N\)이든 과학적 표기로 \(N = a \times 10^n\ (1 \le a < 10)\)처럼 쓸 수 있다. 양변에 상용로그를 취하면 \(\log N = n + \log a\)이고, \(0 \le \log a < 1\)이다. 즉 상용로그 값의 정수 부분은 10의 지수 \(n\)이고, 소수 부분은 앞의 수 \(a\)에서 나온다.

정리 1.5.1 상용로그와 자릿수

\(N \ge 1\)이고 \(\log N\)의 정수 부분이 \(n\)이면, \(N\)은 \((n + 1)\)자리 수이다. 소수 부분 \(\alpha\)는 \(N\)의 맨 앞 숫자들을 정하며, \(N = 10^{\alpha} \times 10^n\)이다.

그림 1에서 \(n\)을 바꾸어 보자. \(\log 2^n = n\log 2\)는 \(n\)에 비례해 늘어나므로, \(n\)이 약 3.3 늘 때마다 자릿수가 하나씩 늘어난다. \(2^{10} = 1024\)가 네 자리인 것도 \(10 \times 0.3010 = 3.010\)의 정수 부분 3에서 바로 읽힌다.1

1.5.2로그 눈금

지진의 규모, 소리의 데시벨, 산성도의 pH, 별의 등급처럼 아주 넓은 범위의 양은 로그를 써서 나타낸다. 이런 눈금에서는 한 칸이 일정한 차이가 아니라 일정한 배수를 뜻한다. 가령 지진의 규모가 1 커지면 방출 에너지가 약 \(10^{1.5} \approx 32\)배가 된다.

예제 1.5.2

\(\log 2 = 0.3010\), \(\log 3 = 0.4771\)일 때, \(2^{50}\)은 몇 자리 수이고 맨 앞 숫자는 무엇인가? 또 \(\left(\tfrac{1}{3}\right)^{20}\)은 소수점 아래 몇째 자리에서 처음으로 0이 아닌 숫자가 나타나는가?

\(\log 2^{50} = 50 \times 0.3010 = 15.05\)이다. 정수 부분이 15이므로 \(2^{50}\)은 16자리 수이다. 소수 부분 0.05는 \(\log 1 = 0\)과 \(\log 2 = 0.3010\) 사이에 있으므로 \(10^{0.05}\)은 1과 2 사이이고, 맨 앞 숫자는 1이다. 실제로 \(2^{50} = 1\,125\,899\,906\,842\,624\)이다.

\(\log\left(\tfrac{1}{3}\right)^{20} = -20 \times 0.4771 = -9.542\)이다. 이것을 \(-10 + 0.458\)로 고쳐 쓰면 \(\left(\tfrac{1}{3}\right)^{20} = 10^{0.458} \times 10^{-10}\)이다. 따라서 이 수는 \(a \times 10^{-10}\ (1 \le a < 10)\) 꼴이고, 소수점 아래 10째 자리에서 처음으로 0이 아닌 숫자가 나타난다.

\(10^{0.458}\)은 \(\log 2 = 0.301\)과 \(\log 3 = 0.477\) 사이이므로 2와 3 사이이고, 그 숫자는 2이다. 아래 탐구 카드에서 거듭제곱의 자릿수와 지진 규모의 눈금을 직접 확인해 보자.

  1. 상용로그 값은 교과서 끝의 상용로그표에서 찾을 수 있다. 표에는 1.00부터 9.99까지의 수의 상용로그가 소수 넷째 자리까지 적혀 있고, 다른 수는 \(a \times 10^n\) 꼴로 고쳐 찾는다.
마무리

상용로그는 수를 \(a \times 10^n\)으로 쓸 때의 지수 \(n\)과 앞의 수 \(a\)를 한 수에 담아, 정수 부분으로 자릿수를, 소수 부분으로 맨 앞 숫자를 알려 준다. 그래서 처음 질문의 \(2^{50}\)은 \(\log 2^{50} = 15.05\)에서 16자리 수이고 맨 앞 숫자는 1이다.

  1. 질문\(2^{50}\)을 끝까지 곱하지 않고 몇 자리 수인지 알 수 있을까? 맨 앞자리 숫자까지 알 수 있을까?
  2. 복원\(\log_a M^k = k \log_a M\), \(\log_a MN = \log_a M + \log_a N\)이다. 그리고 \(10^2 = 100\)은 세 자리, \(10^3 = 1000\)은 네 자리이다.
  3. 설명밑이 10인 로그를 상용로그라 하고, 밑을 생략해 \(\log N\)으로 쓴다. 양수 \(N\)을 \(N = a \times 10^n\)(\(1 \le a < 10, n\)은 정수)으로 쓰면 \(\log N = n + \log a\)이고 \(0 \le \log a < 1\)이다. 그래서 \(\log N\)의 정수 부분 \(n\)은 자리의 크기를, 소수 부분 \(\log a\)는 숫자의 배열을 정한다. \(n \ge 0\)이면 \(N\)의 정수 부분은 \(n + 1\)자리이고, \(n < 0\)이면 \(N\)은 소수점 아래 \(-n\)째 자리에서 처음으로 0이 아닌 숫자가 나온다. 또 맨 앞 숫자는 \(10^{\text{소수 부분}}\)의 정수 부분이다. 예를 들어 \(\log 2^{50} = 50 \log 2 \approx 15.05\)이므로 \(2^{50}\)은 16자리이고, \(10^{0.05} \approx 1.13\)이라 맨 앞 숫자는 1이다.
  4. 연결계산기가 없던 시절에는 1.00부터 9.99까지의 상용로그 값을 적은 상용로그표로 소수 부분을 찾았다. 정수 부분은 자릿수만 보면 되므로 표 하나로 모든 양수의 로그를 구할 수 있었다. 이 생각이 다음 카드의 pH, 지진 규모, 데시벨로 이어진다.
  5. 적용\(3^{20}\)을 눌러 자릿수와 맨 앞 숫자를 확인해 보자. 지수를 1씩 늘리며 아래 눈금의 점이 얼마씩 움직이는지, 한 바퀴 돌 때 정수 부분이 어떻게 바뀌는지 보고, \(7^{-10}, 2^{-30}\)에서 처음으로 0이 아닌 숫자가 소수점 아래 몇째 자리에 나오는지도 찾아보자.
  6. 판단\(\log N \approx -8.45\)일 때 정수 부분을 \(-8\), 소수 부분을 \(-0.45\)로 읽는 실수가 흔하다. 소수 부분은 언제나 0 이상 1 미만이 되도록 정하므로 \(-8.45 = -9 + 0.55\)이다. 또 정수 부분이 15이면 16자리이다. \(10^0 = 1\)이 한 자리라는 것을 떠올리면 15자리로 잘못 답하지 않는다.

규모 7 지진은 규모 5 지진보다 몇 배 셀까?

—

  1. 질문뉴스에서 "규모 7.0"과 "규모 5.0"은 2만큼 차이 난다. 그러면 지진이 내놓은 에너지도 두 배쯤 차이 날까?
  2. 복원\(\log N = k \Leftrightarrow N = 10^k\)이고, \(\log M - \log N = \log(\frac{M}{N})\)이다. 즉 로그 값이 1 늘면 진수는 10배가 된다.
  3. 설명자연과 사회에는 아주 작은 값부터 아주 큰 값까지 몇십 자리에 걸쳐 변하는 양이 많다. 이런 양은 상용로그를 취해 다루기 쉬운 수로 바꾸어 쓴다. 지진의 규모 \(M\)과 에너지 \(E(\text{J})\) 사이에는 \(\log E = 4.8 + 1.5M\)이라는 관계가 알려져 있다. 그래서 규모가 1 크면 에너지는 \(10^{1.5} \approx 32\)배, 2 크면 \(10^3 = 1000\)배이다. 산성도는 \(\text{pH} = -\log[\text{H}^+]\)(\([\text{H}^+]\)는 수소 이온 농도, mol/L)이므로 pH가 1 작으면 수소 이온이 10배 많다. 소리의 세기 수준은 \(10 \log(\frac{I}{I_0})\,\text{dB}(I_0 = 10^{-12}\,\text{W}/\text{m}^2)\)라서 10 dB 크면 세기가 10배이다. 세 경우 모두 로그 값의 차가 실제 양의 비를 정한다.
  4. 연결2016년 경주 지진(규모 5.8)과 2011년 동일본 대지진(규모 9.0)의 규모 차는 3.2이지만, 에너지는 \(10^{4.8}\), 곧 약 6만 3천 배 차이 난다. 별의 밝기(등급)와 음계의 진동수도 같은 생각으로 정한다.
  5. 적용지진 규모에서 두 값을 1, 2, 3만큼 차이 나게 놓고 에너지의 비를 기록해 보자. 그다음 pH 3인 용액과 pH 6인 용액의 수소 이온 농도가 몇 배 차이 나는지, 60 dB과 90 dB의 소리는 세기가 몇 배 차이 나는지도 구해 보자.
  6. 판단로그 눈금에서 같은 간격은 같은 "차"가 아니라 같은 "배율"이다. 그래서 "pH 4는 pH 8보다 두 배 산성"이라고 말하면 틀리고, 수소 이온 농도는 \(10^4\)배 차이 난다. 그림의 예시 값은 대표적인 대략값이고, 실제 레몬즙이나 대화 소리의 값은 상황에 따라 다르다. 또 데시벨은 세기의 비를 나타낼 뿐, 귀가 느끼는 크기와 정확히 비례하지는 않는다.
