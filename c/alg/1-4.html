로그

\(2^x = 8\)은 쉽게 풀리지만 \(2^x = 5\)의 해는 지금까지의 기호로 쓸 수 없습니다. "몇 제곱하면 이 수가 되는가"에 이름을 붙인 것이 로그입니다. 이 절에서는 로그를 지수의 거꾸로 읽기로 정의하고, 지수법칙에서 로그의 성질과 밑 변환 공식을 끌어냅니다.

1.4.1

2를 몇 제곱하면 5가 될까?

로그의 뜻 · 밑과 진수의 조건

—

교점의 개수
—
\(\log_a N\)
—
검산 \(a^{\log_aN}\)
—

그림을 위아래로 끌면 수평선 \(y = N\)이 움직입니다.

  1. 질문\(2^x = 8\)의 해는 3입니다. 그러면 \(2^x = 5\)의 해는 있을까요? 있다면 어떻게 나타낼까요?
  2. 복원밑 \(a\)가 양수이면 \(a^x\)는 모든 실수 \(x\)에서 정해지고 언제나 양수입니다. \(a > 1\)이면 \(x\)가 커질 때 \(a^x\)도 커지고, \(0 < a < 1\)이면 작아집니다.
  3. 설명\(a > 0\), \(a \ne 1\)이면 \(y = a^x\)는 계속 증가하거나 계속 감소하면서 모든 양수 값을 한 번씩 지납니다. 그래서 \(N > 0\)이면 \(a^x = N\)을 만족하는 실수 \(x\)가 오직 하나 있고, 이 수를 \(\log_a N\)으로 씁니다. \(a\)를 밑, \(N\)을 진수라 합니다. 곧 \(a^x = N \Leftrightarrow x = \log_a N\)입니다. 조건은 세 가지입니다. 밑은 \(a > 0\), \(a \ne 1\)이고 진수는 \(N > 0\)입니다. 정의에서 바로 \(\log_a 1 = 0(a^0 = 1)\), \(\log_a a = 1\), \(a^{\log_aN} = N\)이 나옵니다.
  4. 연결\(2^x = 5\)의 해는 \(\log_2 5 \approx 2.322\)입니다. \(2^2 = 4\)와 \(2^3 = 8\) 사이이므로 2와 3 사이의 값이 나오는 것이 자연스럽습니다. 지진 규모, 소리의 세기(dB), 산성도(pH)는 모두 로그로 정한 양이고, 밑이 10인 상용로그로 다룹니다.
  5. 적용다섯 보기를 차례로 눌러 교점이 몇 개인지 확인하세요. 밑이 1일 때와 진수가 음수일 때 무엇이 문제인가요? 밑 0.5에서 진수를 1보다 크게 하면 로그 값의 부호는 어떻게 되나요?
  6. 판단\(\log_2(-4)\)를 \(-2\)라고 하는 실수가 있습니다. \(2^{-2} = \frac{1}{4}\)이지 \(-4\)가 아닙니다. 양수 밑의 거듭제곱은 음수가 될 수 없으므로 진수가 0 이하이면 로그는 정의되지 않습니다. 밑이 1이면 \(1^x = 1\)이라 \(N \ne 1\)이면 해가 없고, \(N = 1\)이면 해가 무수히 많아 값이 하나로 정해지지 않습니다.

1.4.2

로그를 쓰면 왜 곱셈이 덧셈이 될까?

로그의 성질 · 로그 눈금자

—

화살표 길이의 합
—
도착점의 로그 값
—
도착점의 수
—

밑이 10인 로그(\(\log\))로 그렸습니다. 아래 눈금에서 수 사이의 간격은 그 수의 로그 값의 차입니다.

  1. 질문\(2 \times 4 = 8\)을 덧셈만으로 계산할 수 있을까요? 계산기가 없던 시절 천문학자와 항해사는 큰 수의 곱셈을 덧셈으로 바꾸어 계산했습니다. 어떻게 했을까요?
  2. 복원\(a^x = M \Leftrightarrow x = \log_a M\)입니다. 지수법칙은 \(a^xa^y = a^{x+y}\), \(a^x \div a^y = a^{x-y}\), \((a^x)^k = a^{kx}\)입니다.
  3. 설명\(\log_a M = x\), \(\log_a N = y\)로 두면 \(M = a^x\), \(N = a^y\)입니다. 그러면 \(MN = a^{x+y}\)이므로 \(\log_a MN = x + y\)입니다. 같은 방법으로 \(a > 0\), \(a \ne 1\), \(M > 0\), \(N > 0\)이고 \(k\)가 실수일 때 다음이 성립합니다. \(\log_a MN = \log_a M + \log_a N\), \(\log_a (\frac{M}{N}) = \log_a M - \log_a N\), \(\log_a M^k = k \log_a M\). 지수의 덧셈·뺄셈·곱셈이 그대로 로그의 성질이 됩니다. 아래 눈금자는 수를 그 로그 값의 자리에 찍은 것이라, 길이를 이어 붙이면 수가 곱해집니다.
  4. 연결이 눈금 두 개를 맞대어 미끄러뜨리는 도구가 계산자입니다. 17세기 네이피어가 로그를 만든 뒤, 계산자는 전자계산기가 나오기 전까지 공학 계산에 쓰였습니다. 지진 규모나 소리의 세기처럼 몇 배씩 변하는 양을 로그 눈금으로 그리는 까닭도 같습니다.
  5. 적용곱에서 \(M = 2\), \(N = 5\)로 두면 도착점은 어디인가요? 몫에서 \(M\)보다 큰 \(N\)을 고르면 도착점은 1의 어느 쪽에 생기고, 로그 값의 부호는 어떻게 되나요? 거듭제곱에서 \(k = -1\)과 \(k = 0.5\)는 각각 무엇을 계산하나요?
  6. 판단\(\log_a(M + N) = \log_a M + \log_a N\)은 틀린 식입니다. 로그가 덧셈으로 바꾸는 것은 곱셈입니다. \((\log_a M)^k\)와 \(\log_a M^k\)도 다릅니다. 또 성질은 진수가 양수일 때만 씁니다. \(\log_2((-2)(-4)) = 3\)이지만 \(\log_2(-2)\)와 \(\log_2(-4)\)는 정의되지 않습니다.

1.4.3

밑이 다른 로그는 서로 어떤 관계일까?

밑 변환 공식 · 두 로그 곡선의 비
\(\log_a x\)
—
\(\log_b x\)
—
비 \(\log_bx / \log_ax\)
—
\(1 / \log_a b\)
—

그림을 좌우로 끌면 진수 \(x\)가 움직입니다. \(x = 1\)에서는 두 높이가 모두 0이라 비를 정할 수 없습니다.

  1. 질문계산기에는 보통 밑이 10인 \(\log\)만 있습니다. 그러면 \(\log_2 5\)는 어떻게 계산할까요? 밑이 다른 로그 사이에는 어떤 관계가 있을까요?
  2. 복원\(\log_a M^k = k \log_a M\)이고, \(a^{\log_ax} = x\)입니다.
  3. 설명\(\log_b x = t\)로 두면 \(x = b^t\)입니다. 양변에 밑이 \(a\)인 로그를 취하면 \(\log_a x = t \log_a b\)이므로 \(\log_b x = \log_a x / \log_a b\)입니다(\(a, b\)는 1이 아닌 양수, \(x > 0\)). 이것이 밑 변환 공식입니다. 그래프로 보면 \(y = \log_b x\)는 \(y = \log_a x\)를 세로로 \(1/\log_a b\)배 한 곡선입니다. 그래서 어느 \(x\)에서나 두 높이의 비가 같습니다. 특히 \(x = a\)로 두면 \(\log_b a = 1/\log_a b\), 곧 \(\log_a b \times \log_b a = 1\)입니다.
  4. 연결\(\log_2 5 = \log 5 / \log 2 \approx 0.6990 / 0.3010 \approx 2.322\)입니다. 컴퓨터 과학에서 자료를 반씩 나누는 횟수는 \(\log_2\), 소리와 지진은 \(\log_{10}\)를 쓰지만, 밑 변환 공식이 있으므로 한 가지 밑의 로그만 알면 나머지는 상수배로 얻습니다.
  5. 적용\(a = 2\), \(b = 4\)로 두고 \(x\)를 움직이며 비가 변하는지 보세요. 그 비는 무엇과 같나요? \(b\)를 \(a\)와 같게 하면 두 곡선은 어떻게 되나요? \(a = 2\), \(b = 8\)에서는 비가 얼마인가요?
  6. 판단\(\log_a x / \log_a b\)를 \(\log_a(\frac{x}{b})\)나 \(\log_a x - \log_a b\)로 바꾸는 실수가 흔합니다. 로그끼리 나눈 것은 진수의 나눗셈이 아닙니다. 분모와 분자의 밑이 같아야 공식이 성립한다는 점도 확인하세요.
