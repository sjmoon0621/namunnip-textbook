로그

본문

\(2^x = 8\)이면 \(x = 3\)이다. 그런데 \(2^x = 5\)를 만족하는 \(x\)는 2와 3 사이 어딘가에 있지만, 정수도 깔끔한 분수도 아니다. 이 수를 어떻게 이름 붙이고, 어떻게 계산할까?

먼저 알아야 할 것실수 지수의 뜻(지수의 확장), 지수법칙(지수법칙), \(y = a^x\) 꼴의 그래프.

1.4.1지수를 묻는 기호

\(2^x\)는 \(x\)가 커지면 계속 커지고, 모든 양수 값을 한 번씩 지난다. 그림 1처럼 높이 5를 지나는 곳이 한 군데뿐이므로, \(2^x = 5\)인 실수 \(x\)는 하나로 정해진다. 이 수를 '2를 밑으로 하는 5의 로그'라 하고 \(\log_2 5\)로 쓴다. 즉 \(\log_2 5\)는 '2를 몇 제곱하면 5가 되는가'의 답이다.

정의 1.4.1 로그

\(a > 0\), \(a \ne 1\), \(N > 0\)일 때, \(a^x = N\)을 만족하는 실수 \(x\)를 \(a\)를 밑으로 하는 \(N\)의 로그라 하고 \(x = \log_a N\)으로 나타낸다. 이때 \(N\)을 진수라 한다. \[a^x = N \iff x = \log_a N\]

정의의 조건에는 까닭이 있다. 밑이 1이면 \(1^x\)은 언제나 1이라 5가 될 수 없고, 밑이 음수이면 실수 지수가 정해지지 않는다. 진수가 양수인 것은 \(a^x\)가 언제나 양수이기 때문이다. 정의에서 바로 \(\log_a 1 = 0\), \(\log_a a = 1\)이 나온다.

1.4.2로그의 성질

로그는 지수를 돌려 읽은 것이므로, 지수법칙이 그대로 로그의 성질이 된다. \(\log_a M = x\), \(\log_a N = y\)로 두면 \(M = a^x\), \(N = a^y\)이다. 그러면 \(MN = a^{x+y}\)이므로 \(\log_a MN = x + y\)이다. 다시 말해 진수의 곱셈이 로그의 덧셈으로 바뀐다. 그림 1에서 높이를 2배 할 때마다 \(x\)좌표가 1씩 늘어나는 것도 이 성질이다.

정리 1.4.2 로그의 성질

\(a > 0\), \(a \ne 1\), \(M > 0\), \(N > 0\)일 때 \[\log_a MN = \log_a M + \log_a N,\quad \log_a \frac{M}{N} = \log_a M - \log_a N,\quad \log_a M^k = k\log_a M\ (k\text{는 실수})\]

밑이 다른 로그는 밑을 바꾸어 비교한다. \(\log_a b = x\)이면 \(a^x = b\)이고, 양변에 밑이 \(c\)인 로그를 취하면 \(x\log_c a = \log_c b\)이다. 따라서 \(\log_a b = \dfrac{\log_c b}{\log_c a}\)이고, 이것을 밑변환 공식이라 한다.1

1.4.3예제 하나를 끝까지

예제 1.4.3

\(\log_2 3 = a\), \(\log_2 5 = b\)일 때 \(\log_2 60\)과 \(\log_3 10\)을 \(a\), \(b\)로 나타내어라.

\(60 = 2^2 \times 3 \times 5\)이므로 \(\log_2 60 = \log_2 2^2 + \log_2 3 + \log_2 5 = 2 + a + b\)이다. 곱셈이 덧셈으로 바뀌어 각 소인수의 로그만 알면 된다.

\(\log_3 10\)은 밑이 3이므로 밑을 2로 바꾼다. \(\log_3 10 = \dfrac{\log_2 10}{\log_2 3} = \dfrac{\log_2 2 + \log_2 5}{a} = \dfrac{1 + b}{a}\)이다.

확인해 보자. \(a \approx 1.585\), \(b \approx 2.322\)이므로 \(\log_2 60 \approx 5.907\)이고, 실제로 \(2^{5.907} \approx 60\)이다. 또 \(\dfrac{1 + b}{a} \approx 2.096\)이고 \(3^{2.096} \approx 10\)이다. 아래 탐구 카드에서 그래프의 높이와 가로 좌표를 오가며 로그를 직접 읽어 보자.

  1. 밑변환 공식에서 \(c = b\)로 두면 \(\log_a b = \dfrac{1}{\log_b a}\)이다. 가령 \(\log_2 8 = 3\)이고 \(\log_8 2 = \tfrac{1}{3}\)이다.
마무리

로그 \(\log_a N\)은 '\(a\)를 몇 제곱하면 \(N\)이 되는가'의 답으로, 지수 관계를 거꾸로 읽은 것이다. 그래서 지수법칙이 로그의 성질이 되어 진수의 곱은 로그의 합으로, 거듭제곱은 곱으로 바뀐다. 처음 질문의 수는 \(\log_2 5\)이고, 약 2.32이다.

2를 몇 제곱하면 5가 될까?

로그의 뜻 · 밑과 진수의 조건

—

교점의 개수
—
\(\log_a N\)
—
검산 \(a^{\log_aN}\)
—

그림을 위아래로 끌면 수평선 \(y = N\)이 움직인다.

  1. 질문\(2^x = 8\)의 해는 3이다. 그러면 \(2^x = 5\)의 해는 있을까? 있다면 어떻게 나타낼까?
  2. 복원밑 \(a\)가 양수이면 \(a^x\)는 모든 실수 \(x\)에서 정해지고 언제나 양수이다. 그리고 \(a > 1\)이면 \(x\)가 커질 때 \(a^x\)도 커지고, \(0 < a < 1\)이면 작아진다.
  3. 설명\(a > 0\), \(a \ne 1\)이면 \(y = a^x\)는 계속 증가하거나 계속 감소하면서 모든 양수 값을 한 번씩 지난다. 그래서 \(N > 0\)이면 \(a^x = N\)을 만족하는 실수 \(x\)가 오직 하나 있고, 이 수를 \(\log_a N\)으로 쓴다. 이때 \(a\)를 밑, \(N\)을 진수라 하며, 곧 \(a^x = N \Leftrightarrow x = \log_a N\)이다. 따라서 밑은 \(a > 0\), \(a \ne 1\)이고 진수는 \(N > 0\)이어야 한다. 정의에서 바로 \(\log_a 1 = 0(a^0 = 1)\), \(\log_a a = 1\), \(a^{\log_aN} = N\)이 나온다.
  4. 연결그러면 \(2^x = 5\)의 해는 \(\log_2 5 \approx 2.322\)이다. \(2^2 = 4\)와 \(2^3 = 8\) 사이이므로 2와 3 사이의 값이 나오는 것이 자연스럽다. 지진 규모, 소리의 세기(dB), 산성도(pH)는 모두 로그로 정한 양이고, 밑이 10인 상용로그로 다룬다.
  5. 적용다섯 보기를 차례로 눌러 교점이 몇 개인지 확인하고, 밑이 1일 때와 진수가 음수일 때 무엇이 문제인지 보자. 밑 0.5에서 진수를 1보다 크게 하면 로그 값이 음수가 된다.
  6. 판단\(\log_2(-4)\)를 \(-2\)라고 하는 실수가 있는데, \(2^{-2} = \frac{1}{4}\)이지 \(-4\)가 아니다. 양수 밑의 거듭제곱은 음수가 될 수 없으므로 진수가 0 이하이면 로그는 정의되지 않는다. 또 밑이 1이면 \(1^x = 1\)이라 \(N \ne 1\)이면 해가 없고, \(N = 1\)이면 해가 무수히 많아 값이 하나로 정해지지 않는다.

밑이 10인 로그(\(\log\))로 그렸다. 아래 눈금에서 수 사이의 간격은 그 수의 로그 값의 차이다.

  1. 질문\(2 \times 4 = 8\)을 덧셈만으로 계산할 수 있을까? 계산기가 없던 시절 천문학자와 항해사는 큰 수의 곱셈을 덧셈으로 바꾸어 계산했다. 어떻게 했을까?
  2. 복원\(a^x = M \Leftrightarrow x = \log_a M\)이다. 그리고 지수법칙은 \(a^xa^y = a^{x+y}\), \(a^x \div a^y = a^{x-y}\), \((a^x)^k = a^{kx}\)이다.
  3. 설명\(\log_a M = x\), \(\log_a N = y\)로 두면 \(M = a^x\), \(N = a^y\)이다. 그러면 \(MN = a^{x+y}\)이므로 \(\log_a MN = x + y\)이다. 같은 방법으로 \(a > 0\), \(a \ne 1\), \(M > 0\), \(N > 0\)이고 \(k\)가 실수일 때 \(\log_a MN = \log_a M + \log_a N\), \(\log_a (\frac{M}{N}) = \log_a M - \log_a N\), \(\log_a M^k = k \log_a M\)이 성립한다. 즉 지수의 덧셈, 뺄셈, 곱셈이 그대로 로그의 성질이 된다. 아래 눈금자는 수를 그 로그 값의 자리에 찍은 것이라, 길이를 이어 붙이면 수가 곱해진다.
  4. 연결이 눈금 두 개를 맞대어 미끄러뜨리는 도구가 계산자이다. 17세기 네이피어가 로그를 만든 뒤, 계산자는 전자계산기가 나오기 전까지 공학 계산에 쓰였다. 지진 규모나 소리의 세기처럼 몇 배씩 변하는 양을 로그 눈금으로 그리는 까닭도 같다.
  5. 적용곱에서 \(M = 2\), \(N = 5\)로 두고 도착점이 어디인지 보자. 몫에서 \(M\)보다 큰 \(N\)을 고르면 도착점이 1의 왼쪽에 생기고 로그 값이 음수가 된다. 거듭제곱에서는 \(k = -1\)과 \(k = 0.5\)가 각각 무엇을 계산하는지 확인해 보자.
  6. 판단\(\log_a(M + N) = \log_a M + \log_a N\)은 틀린 식이다. 로그가 덧셈으로 바꾸는 것은 곱셈이기 때문이다. 또 \((\log_a M)^k\)와 \(\log_a M^k\)는 다르다. 그리고 이 성질은 진수가 양수일 때만 쓴다. \(\log_2((-2)(-4)) = 3\)이지만 \(\log_2(-2)\)와 \(\log_2(-4)\)는 정의되지 않는다.

밑이 다른 로그는 서로 어떤 관계일까?

밑 변환 공식 · 두 로그 곡선의 비
\(\log_a x\)
—
\(\log_b x\)
—
비 \(\log_bx / \log_ax\)
—
\(1 / \log_a b\)
—

그림을 좌우로 끌면 진수 \(x\)가 움직인다. \(x = 1\)에서는 두 높이가 모두 0이라 비를 정할 수 없다.

  1. 질문계산기에는 보통 밑이 10인 \(\log\)만 있다. 그러면 \(\log_2 5\)는 어떻게 계산할까? 밑이 다른 로그 사이에는 어떤 관계가 있을까?
  2. 복원\(\log_a M^k = k \log_a M\)이고, \(a^{\log_ax} = x\)이다.
  3. 설명\(\log_b x = t\)로 두면 \(x = b^t\)이다. 양변에 밑이 \(a\)인 로그를 취하면 \(\log_a x = t \log_a b\)이므로 \(\log_b x = \log_a x / \log_a b\)이다(\(a, b\)는 1이 아닌 양수, \(x > 0\)). 이것이 밑 변환 공식이다. 그래프로 보면 \(y = \log_b x\)는 \(y = \log_a x\)를 세로로 \(1/\log_a b\)배 한 곡선이고, 그래서 어느 \(x\)에서나 두 높이의 비가 같다. 특히 \(x = a\)로 두면 \(\log_b a = 1/\log_a b\), 곧 \(\log_a b \times \log_b a = 1\)이다.
  4. 연결가령 \(\log_2 5 = \log 5 / \log 2 \approx 0.6990 / 0.3010 \approx 2.322\)이다. 컴퓨터 과학에서 자료를 반씩 나누는 횟수는 \(\log_2\), 소리와 지진은 \(\log_{10}\)를 쓰지만, 밑 변환 공식이 있으므로 한 가지 밑의 로그만 알면 나머지는 상수배로 얻는다.
  5. 적용\(a = 2\), \(b = 4\)로 두고 \(x\)를 움직이며 비가 변하는지, 그 비가 무엇과 같은지 보자. 다음에는 \(b\)를 \(a\)와 같게 해 두 곡선이 어떻게 되는지 보고, \(a = 2\), \(b = 8\)에서 비가 얼마인지도 구해 보자.
  6. 판단\(\log_a x / \log_a b\)를 \(\log_a(\frac{x}{b})\)나 \(\log_a x - \log_a b\)로 바꾸는 실수가 흔하다. 로그끼리 나눈 것은 진수의 나눗셈이 아니기 때문이다. 또 분모와 분자의 밑이 같아야 공식이 성립한다.
