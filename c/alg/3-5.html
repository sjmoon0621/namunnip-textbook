3.5.2

세제곱을 모으면 왜 정사각형이 될까?

k번째 띠의 넓이

13 + … + n3

—

작은 칸 하나의 넓이가 1입니다. 띠는 한 변이 1 + … + (k − 1)인 정사각형을 1 + … + k인 정사각형으로 키울 때 덧붙는 부분입니다.

  1. 질문13 = 1, 13 + 23 = 9, 13 + 23 + 33 = 36, 13 + 23 + 33 + 43 = 100. 합이 모두 제곱수입니다. 우연일까요?
  2. 복원1 + 2 + … + n = n(n + 1)/2입니다. 한 변이 a인 정사각형을 한 변이 b인 정사각형으로 키우면 덧붙는 ㄱ자 모양의 넓이는 b2 − a2입니다.
  3. 설명Tk = 1 + 2 + … + k = k(k + 1)/2라 하면 한 변이 Tk−1인 정사각형에서 Tk인 정사각형으로 키울 때 덧붙는 띠의 넓이는 Tk2 − Tk−12 = (Tk − Tk−1)(Tk + Tk−1) = k · k2 = k3입니다. (Tk − Tk−1 = k, Tk + Tk−1 = k2) 이 띠를 1번부터 n번까지 모으면 한 변이 Tn인 정사각형이 되므로 ∑k=1n k3 = {n(n + 1)/2}2입니다.
  4. 연결이 공식은 제곱의 합처럼 (k + 1)4 − k4 = 4k3 + 6k2 + 4k + 1을 k = 1부터 n까지 더해서도 얻을 수 있습니다. 그림은 그 결과가 왜 (∑k)2이라는 깔끔한 모양이 되는지 보여 줍니다. 세 공식 ∑k, ∑k2, ∑k3과 ∑의 성질을 함께 쓰면 일반항이 n의 다항식인 수열의 합을 구할 수 있습니다.
  5. 적용k를 움직이며 띠의 넓이가 k3인지 칸을 세어 보세요. n을 늘리면 정사각형의 한 변은 얼마씩 커지나요? 두 수치 13 + … + n3과 (1 + … + n)2이 늘 같은지 확인하세요.
  6. 판단∑k3 = (∑k)2은 세제곱에서만 성립하는 특별한 관계입니다. ∑k2 = (∑k)2이나 ∑k4 = (∑k2)2처럼 일반화하면 틀립니다. 또 그림은 공식이 왜 맞는지 보여 주지만, 모든 n에 대한 증명은 위의 넓이 계산(또는 수학적 귀납법)이 맡습니다.

3.5.3

분수를 차로 쪼개면 무엇이 남을까?

여러 가지 수열의 합 · 분수 꼴 수열의 합
하나씩 더한 합
—
남는 항
—
남는 항의 값
—
  1. 질문1/(1 · 2) + 1/(2 · 3) + 1/(3 · 4) + …처럼 분모가 이웃한 수의 곱인 분수를 더하면, 통분할수록 분모가 커집니다. 더 쉬운 길이 있을까요?
  2. 복원1/k − 1/(k + 1) = {(k + 1) − k}/{k(k + 1)} = 1/{k(k + 1)}입니다. 분모를 유리화할 때 (√a + √b)(√a − √b) = a − b를 씁니다.
  3. 설명항을 1/{k(k + 1)} = 1/k − 1/(k + 1)처럼 두 수의 차로 쪼개면 앞 줄의 뒤쪽 수와 다음 줄의 앞쪽 수가 같아 지워집니다. 그래서 ∑k=1n 1/{k(k + 1)} = 1 − 1/(n + 1) = n/(n + 1)입니다. 분모의 두 수가 2만큼 차이 나면 1/{k(k + 2)} = (1/2)(1/k − 1/(k + 2))처럼 앞에 1/(차)를 곱하고, 두 줄 건너 지워지므로 처음 두 개와 끝 두 개가 남습니다. 1/(√(k + 1) + √k)는 유리화하면 √(k + 1) − √k이므로 합은 √(n + 1) − 1입니다.
  4. 연결합을 '지워지는 차'의 모양으로 바꾸는 생각은 제곱의 합 공식을 구할 때 (k + 1)3 − k3을 더한 것과 같습니다. 이런 합은 여러 줄을 더해도 처음과 끝만 남기 때문에 항의 개수와 상관없이 짧은 식이 됩니다.
  5. 적용세 가지 수열을 차례로 고르고 n을 늘려 보세요. 각 경우 몇 개의 수가 남나요? 첫 번째 수열의 아래 띠는 n이 커지면 어디에 가까워지나요?
  6. 판단1/{k(k + 2)}을 1/k − 1/(k + 2)로만 쪼개는 실수가 흔합니다. 이 차는 2/{k(k + 2)}이므로 1/2을 곱해야 합니다. 또 남는 항을 셀 때 앞에서 남는 것과 뒤에서 남는 것을 모두 적어야 합니다. 쪼갠 뒤 몇 개를 적어 보고 지워지는 짝을 직접 확인하는 습관이 안전합니다.
