3.2.1

같은 수씩 커지는 수열의 100번째 항은?

등차수열 · 공차와 등차중항

—

제8항 a8
—
제100항 a100
—
양옆 항의 평균
—

첫째항(주황)과 둘째항(파랑) 점을 위아래로 끌 수 있습니다. 계단 하나는 가로 1, 세로 d입니다.

  1. 질문3, 5, 7, 9, …처럼 같은 수씩 커지는 수열에서 100번째 항을 알려면 앞의 99개 항을 모두 적어야 할까요?
  2. 복원일차함수 y = mx + b의 그래프는 기울기가 m인 직선입니다. x가 1 늘 때마다 y는 늘 m씩 늘어납니다.
  3. 설명첫째항부터 차례로 같은 수 d를 더해 얻는 수열을 등차수열, d를 공차라고 합니다. 곧 모든 n에서 an+1 − an = d입니다. 첫째항이 a이면 a2 = a + d, a3 = a + 2d, …이고 n번째 항까지는 d를 n − 1번 더하므로 일반항은 an = a + (n − 1)d입니다. 또 세 수 a, b, c가 이 순서로 등차수열을 이루면 b − a = c − b이므로 b = (a + c)/2입니다. 이때 b를 a와 c의 등차중항이라고 합니다.
  4. 연결an = a + (n − 1)d = dn + (a − d)는 n의 일차식입니다. 그래서 등차수열의 점은 기울기가 공차 d인 직선 위에 놓입니다. 거꾸로 일반항이 n의 일차식이면 그 수열은 등차수열이고, 일차항의 계수가 공차입니다.
  5. 적용첫째항 점과 둘째항 점을 끌어 보세요. 나머지 점은 어떻게 따라 움직이나요? 공차가 음수이면 점들은 어느 쪽으로 기울어지나요? k를 바꾸며 ak가 늘 양옆 항의 평균인지 확인하고, d = 0이면 어떤 수열이 되는지 보세요.
  6. 판단일반항에서 d를 n번 더한다고 생각하면 an = a + nd라는 실수를 합니다. 첫째항에서 n번째 항까지 건너는 계단은 n − 1개입니다. 또 등차중항은 '가운데 위치의 항'이 아니라 양옆 두 수의 평균이라는 관계입니다. 1, 2, 4에서 2는 가운데에 있지만 (1 + 4)/2 = 2.5가 아니므로 등차중항이 아닙니다.

3.2.2

1부터 100까지 더하는 빠른 방법은?

등차수열 · 첫째항부터 제n항까지의 합
하나씩 더한 Sn
—
a1 + an
—
n(a1 + an)/2
—

공차가 음수일 때는 모든 항이 양수가 되도록 n의 최댓값이 첫째항으로 제한됩니다(막대 길이로 보이기 위한 제한입니다).

  1. 질문가우스는 어린 시절 1 + 2 + … + 100을 순식간에 구했다고 전해집니다. 100개를 하나씩 더하지 않고 어떻게 구할 수 있었을까요?
  2. 복원등차수열의 일반항은 an = a + (n − 1)d입니다. 항을 앞에서 하나씩 갈 때마다 d씩 늘고, 뒤에서 하나씩 올 때마다 d씩 줄어듭니다.
  3. 설명첫째항부터 제n항까지의 합을 Sn이라 합니다. Sn을 앞에서부터 한 번, 뒤에서부터 한 번 적어 위아래로 더하면, 짝마다 앞쪽 항은 d 늘고 뒤쪽 항은 d 줄어 합이 늘 a1 + an입니다. 이런 짝이 n개이므로 2Sn = n(a1 + an), 곧 Sn = n(a + l)/2입니다(l은 끝항). l = a + (n − 1)d를 넣으면 Sn = n{2a + (n − 1)d}/2입니다. 1 + 2 + … + 100 = 100 × 101/2 = 5050입니다.
  4. 연결그림에서 막대 n개를 거꾸로 한 벌 더 붙이면 가로 n, 세로 a1 + an인 직사각형이 됩니다. 넓이의 절반이 Sn입니다. 사다리꼴 넓이 공식 (윗변 + 아랫변) × 높이 ÷ 2와 같은 생각입니다. Sn은 n의 이차식이 되고, 상수항이 없습니다.
  5. 적용'거꾸로 한 벌 더 붙이기'를 눌러 보세요. 모든 기둥의 높이가 같아지나요? a, d, n을 바꾸어도 기둥 높이가 늘 a1 + an인지, 하나씩 더한 값과 공식 값이 같은지 확인하세요. 공차를 −1로 하면 막대가 어떻게 바뀌나요?
  6. 판단Sn = n(a1 + an)/2에서 2로 나누는 것을 잊는 실수가 흔합니다. 직사각형은 막대 두 벌이므로 반만 취해야 합니다. 또 이 공식은 등차수열에서만 성립합니다. 짝의 합이 늘 같다는 성질이 공차가 일정한 데서 나오기 때문입니다. 항의 개수 n도 정확히 세야 합니다. 5부터 20까지의 자연수는 15개가 아니라 16개입니다.

3.2.3

합을 알면 각 항도 알 수 있을까?

등차수열 · 합과 일반항의 관계

—

—

a1 = S1
—
n ≥ 2의 an
—
등차수열인가
—

빈 원은 둘째항부터의 규칙을 n = 1에 넣은 값입니다. 채운 주황 점(a1 = S1)과 비교해 보세요.

  1. 질문어떤 수열의 첫째항부터 제n항까지의 합이 Sn = n2 + 2n이라고 합니다. 이것만으로 각 항 an을 알 수 있을까요?
  2. 복원Sn = a1 + a2 + … + an이고 Sn−1 = a1 + … + an−1입니다. 등차수열의 합은 상수항이 없는 n의 이차식(d = 0이면 일차식)입니다.
  3. 설명Sn에서 Sn−1을 빼면 마지막 항만 남으므로 an = Sn − Sn−1 (n ≥ 2)입니다. S0은 정의하지 않으므로 첫째항은 따로 a1 = S1로 구합니다. Sn = pn2 + qn + r이면 n ≥ 2에서 an = 2pn − p + q로 공차가 2p인 등차수열의 꼴입니다. 그런데 a1 = S1 = p + q + r이고, 위 식에 n = 1을 넣은 값은 p + q입니다. 두 값은 r = 0일 때만 같습니다.
  4. 연결그래서 합이 상수항 없는 이차식(또는 일차식)이면 첫째항부터 등차수열이고, 상수항이 있으면 둘째항부터만 등차수열입니다. 이 관계 an = Sn − Sn−1은 등차수열이 아닌 수열에도 늘 성립하므로, 등비수열과 여러 가지 수열의 합에서도 씁니다.
  5. 적용r = 0에서 p, q를 바꾸며 점들이 한 직선 위에 있는지 보세요. 이제 r을 바꾸면 어느 점이 움직이나요? n을 움직이며 an = Sn − Sn−1의 계산을 따라가 보세요.
  6. 판단an = Sn − Sn−1을 n = 1에도 그대로 쓰는 것이 대표 실수입니다. 상수항이 있으면 첫째항이 틀립니다. 또 'Sn이 이차식이면 등차수열'도 상수항이 0일 때만 맞습니다.
