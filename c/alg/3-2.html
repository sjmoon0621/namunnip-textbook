3.2.1

같은 수씩 커지는 수열의 100번째 항은?

등차수열 · 공차와 등차중항

—

제8항 \(a_8\)
—
제100항 \(a_{100}\)
—
양옆 항의 평균
—

첫째항(주황)과 둘째항(파랑) 점을 위아래로 끌 수 있습니다. 계단 하나는 가로 1, 세로 \(d\)입니다.

  1. 질문\(3, 5, 7, 9, \cdots\)처럼 같은 수씩 커지는 수열에서 100번째 항을 알려면 앞의 99개 항을 모두 적어야 할까요?
  2. 복원일차함수 \(y = mx + b\)의 그래프는 기울기가 \(m\)인 직선입니다. \(x\)가 1 늘 때마다 \(y\)는 늘 \(m\)씩 늘어납니다.
  3. 설명첫째항부터 차례로 같은 수 \(d\)를 더해 얻는 수열을 등차수열, \(d\)를 공차라고 합니다. 곧 모든 \(n\)에서 \(a_{n+1} - a_n = d\)입니다. 첫째항이 \(a\)이면 \(a_2 = a + d, a_3 = a + 2d, \cdots\)이고 \(n\)번째 항까지는 \(d\)를 \(n - 1\)번 더하므로 일반항은 \(a_n = a + (n - 1)d\)입니다. 또 세 수 \(a, b, c\)가 이 순서로 등차수열을 이루면 \(b - a = c - b\)이므로 \(b = \frac{a + c}{2}\)입니다. 이때 \(b\)를 \(a\)와 \(c\)의 등차중항이라고 합니다.
  4. 연결\(a_n = a + (n - 1)d = dn + (a - d)\)는 \(n\)의 일차식입니다. 그래서 등차수열의 점은 기울기가 공차 \(d\)인 직선 위에 놓입니다. 거꾸로 일반항이 \(n\)의 일차식이면 그 수열은 등차수열이고, 일차항의 계수가 공차입니다.
  5. 적용첫째항 점과 둘째항 점을 끌어 보세요. 나머지 점은 어떻게 따라 움직이나요? 공차가 음수이면 점들은 어느 쪽으로 기울어지나요? \(k\)를 바꾸며 \(a_k\)가 늘 양옆 항의 평균인지 확인하고, \(d = 0\)이면 어떤 수열이 되는지 보세요.
  6. 판단일반항에서 \(d\)를 \(n\)번 더한다고 생각하면 \(a_n = a + nd\)라는 실수를 합니다. 첫째항에서 \(n\)번째 항까지 건너는 계단은 \(n - 1\)개입니다. 또 등차중항은 '가운데 위치의 항'이 아니라 양옆 두 수의 평균이라는 관계입니다. 1, 2, 4에서 2는 가운데에 있지만 \(\frac{1 + 4}{2} = 2.5\)가 아니므로 등차중항이 아닙니다.

3.2.2

1부터 100까지 더하는 빠른 방법은?

등차수열 · 첫째항부터 제n항까지의 합
하나씩 더한 \(S_n\)
—
\(a_1 + a_n\)
—
\(\frac{n(a_1 + a_n)}{2}\)
—

공차가 음수일 때는 모든 항이 양수가 되도록 \(n\)의 최댓값이 첫째항으로 제한됩니다(막대 길이로 보이기 위한 제한입니다).

  1. 질문가우스는 어린 시절 \(1 + 2 + \cdots + 100\)을 순식간에 구했다고 전해집니다. 100개를 하나씩 더하지 않고 어떻게 구할 수 있었을까요?
  2. 복원등차수열의 일반항은 \(a_n = a + (n - 1)d\)입니다. 항을 앞에서 하나씩 갈 때마다 \(d\)씩 늘고, 뒤에서 하나씩 올 때마다 \(d\)씩 줄어듭니다.
  3. 설명첫째항부터 제\(n\)항까지의 합을 \(S_n\)이라 합니다. \(S_n\)을 앞에서부터 한 번, 뒤에서부터 한 번 적어 위아래로 더하면, 짝마다 앞쪽 항은 \(d\) 늘고 뒤쪽 항은 \(d\) 줄어 합이 늘 \(a_1 + a_n\)입니다. 이런 짝이 \(n\)개이므로 \(2S_n = n(a_1 + a_n)\), 곧 \(S_n = \frac{n(a + l)}{2}\)입니다(\(l\)은 끝항). \(l = a + (n - 1)d\)를 넣으면 \(S_n = \frac{n\{2a + (n - 1)d\}}{2}\)입니다. \(1 + 2 + \cdots + 100 = 100 \times \frac{101}{2} = 5050\)입니다.
  4. 연결그림에서 막대 \(n\)개를 거꾸로 한 벌 더 붙이면 가로 \(n\), 세로 \(a_1 + a_n\)인 직사각형이 됩니다. 넓이의 절반이 \(S_n\)입니다. 사다리꼴 넓이 공식 \((\text{윗변} + \text{아랫변}) \times \text{높이} \div 2\)와 같은 생각입니다. \(S_n\)은 \(n\)의 이차식이 되고, 상수항이 없습니다.
  5. 적용'거꾸로 한 벌 더 붙이기'를 눌러 보세요. 모든 기둥의 높이가 같아지나요? \(a, d, n\)을 바꾸어도 기둥 높이가 늘 \(a_1 + a_n\)인지, 하나씩 더한 값과 공식 값이 같은지 확인하세요. 공차를 \(-1\)로 하면 막대가 어떻게 바뀌나요?
  6. 판단\(S_n = \frac{n(a_1 + a_n)}{2}\)에서 2로 나누는 것을 잊는 실수가 흔합니다. 직사각형은 막대 두 벌이므로 반만 취해야 합니다. 또 이 공식은 등차수열에서만 성립합니다. 짝의 합이 늘 같다는 성질이 공차가 일정한 데서 나오기 때문입니다. 항의 개수 \(n\)도 정확히 세야 합니다. 5부터 20까지의 자연수는 15개가 아니라 16개입니다.

3.2.3

합을 알면 각 항도 알 수 있을까?

등차수열 · 합과 일반항의 관계

—

—

\(a_1 = S_1\)
—
\(n \ge 2\)의 \(a_n\)
—
등차수열인가
—

빈 원은 둘째항부터의 규칙을 \(n = 1\)에 넣은 값입니다. 채운 주황 점(\(a_1 = S_1\))과 비교해 보세요.

  1. 질문어떤 수열의 첫째항부터 제\(n\)항까지의 합이 \(S_n = n^2 + 2n\)이라고 합니다. 이것만으로 각 항 \(a_n\)을 알 수 있을까요?
  2. 복원\(S_n = a_1 + a_2 + \cdots + a_n\)이고 \(S_{n-1} = a_1 + \cdots + a_{n-1}\)입니다. 등차수열의 합은 상수항이 없는 \(n\)의 이차식(\(d = 0\)이면 일차식)입니다.
  3. 설명\(S_n\)에서 \(S_{n-1}\)을 빼면 마지막 항만 남으므로 \(a_n = S_n - S_{n-1} (n \ge 2)\)입니다. \(S_0\)은 정의하지 않으므로 첫째항은 따로 \(a_1 = S_1\)로 구합니다. \(S_n = pn^2 + qn + r\)이면 \(n \ge 2\)에서 \(a_n = 2pn - p + q\)로 공차가 \(2p\)인 등차수열의 꼴입니다. 그런데 \(a_1 = S_1 = p + q + r\)이고, 위 식에 \(n = 1\)을 넣은 값은 \(p + q\)입니다. 두 값은 \(r = 0\)일 때만 같습니다.
  4. 연결그래서 합이 상수항 없는 이차식(또는 일차식)이면 첫째항부터 등차수열이고, 상수항이 있으면 둘째항부터만 등차수열입니다. 이 관계 \(a_n = S_n - S_{n-1}\)은 등차수열이 아닌 수열에도 늘 성립하므로, 등비수열과 여러 가지 수열의 합에서도 씁니다.
  5. 적용\(r = 0\)에서 \(p, q\)를 바꾸며 점들이 한 직선 위에 있는지 보세요. 이제 \(r\)을 바꾸면 어느 점이 움직이나요? \(n\)을 움직이며 \(a_n = S_n - S_{n-1}\)의 계산을 따라가 보세요.
  6. 판단\(a_n = S_n - S_{n-1}\)을 \(n = 1\)에도 그대로 쓰는 것이 대표 실수입니다. 상수항이 있으면 첫째항이 틀립니다. 또 '\(S_n\)이 이차식이면 등차수열'도 상수항이 0일 때만 맞습니다.
