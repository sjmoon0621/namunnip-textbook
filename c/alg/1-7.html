지수함수와 로그함수의 그래프

지수함수와 로그함수의 성질은 그래프 한 장에 거의 다 담겨 있습니다. 밑이 1보다 크면 오르막, 작으면 내리막이고, 지수함수는 \(x\)축에, 로그함수는 \(y\)축에 한없이 가까워집니다. 이 절에서는 밑과 평행이동을 바꾸며 그래프의 모양을 정리하고, 두 그래프가 직선 \(y = x\)에 대칭인 것으로 역함수 관계를 확인합니다.

본문

\(y = 2^x\)와 \(y = \left(\tfrac{1}{2}\right)^x\)는 하나는 올라가고 하나는 내려간다. \(y = 2^{x-1} + 3\)은 \(y = 2^x\)를 어떻게 옮긴 것일까? 그래프를 그리지 않고도 점근선, 지나는 점, 증가와 감소를 식에서 바로 읽을 수 있을까?

먼저 알아야 할 것지수함수와 로그함수의 뜻(지수함수와 로그함수), 그래프의 평행이동과 대칭이동, 역함수의 그래프(공통수학2).

1.7.1\(y = a^x\)의 그래프

\(y = a^x\)의 그래프는 밑이 무엇이든 \(a^0 = 1\)이므로 점 \((0, 1)\)을 지난다. 또 \(a^x\)는 언제나 양수이므로 그래프는 \(x\)축 위에만 있고, \(x\)축에 한없이 가까워진다. 즉 \(x\)축이 점근선이다.

\(a > 1\)이면 \(x\)가 커질수록 \(y\)가 커지는 증가함수이고, \(0 < a < 1\)이면 감소함수이다. \(\left(\tfrac{1}{2}\right)^x = 2^{-x}\)이므로, \(y = \left(\tfrac{1}{2}\right)^x\)의 그래프는 \(y = 2^x\)를 \(y\)축에 대칭이동한 것이다.

정리 1.7.1 지수함수와 로그함수의 그래프

\(y = a^x\)는 점 \((0, 1)\)을 지나고 \(x\)축이 점근선이다. \(y = \log_a x\)는 점 \((1, 0)\)을 지나고 \(y\)축이 점근선이다. 둘 다 \(a > 1\)이면 증가함수, \(0 < a < 1\)이면 감소함수이며, 두 그래프는 직선 \(y = x\)에 대칭이다.

1.7.2평행이동과 대칭이동

\(y = a^{x-p} + q\)는 \(y = a^x\)를 \(x\)축 방향으로 \(p\), \(y\)축 방향으로 \(q\)만큼 평행이동한 것이다. 점 \((0, 1)\)은 \((p, 1 + q)\)로, 점근선 \(y = 0\)은 \(y = q\)로 옮겨 간다. 그림 1의 슬라이더로 \(p\)와 \(q\)를 바꾸면 그래프 전체와 점근선이 함께 움직인다.

로그함수도 마찬가지이다. \(y = \log_a (x - p) + q\)는 \(y = \log_a x\)를 평행이동한 것이고, 점근선은 \(x = p\)로 옮겨 간다. 정의역은 진수가 양수인 \(x > p\)이다.1

예제 1.7.2

\(y = 2^{x-1} + 3\)의 점근선과 \(y\)절편을 구하고, \(-1 \le x \le 3\)에서의 최댓값과 최솟값을 구하여라. 또 이 함수의 역함수를 구하여라.

\(y = 2^x\)를 오른쪽으로 1, 위로 3 옮긴 것이므로 점근선은 \(y = 3\)이다. \(x = 0\)을 넣으면 \(y = 2^{-1} + 3 = 3.5\)이므로 \(y\)절편은 3.5이다.

밑이 2로 1보다 크므로 증가함수이고, 범위의 양 끝에서 최솟값과 최댓값이 나온다. \(x = -1\)에서 \(2^{-2} + 3 = 3.25\)가 최솟값, \(x = 3\)에서 \(2^2 + 3 = 7\)이 최댓값이다.

역함수는 \(y - 3 = 2^{x-1}\)을 \(x\)에 대해 풀어 \(x - 1 = \log_2 (y - 3)\), 곧 \(x = \log_2 (y - 3) + 1\)이다. \(x\)와 \(y\)를 바꾸면 \(y = \log_2 (x - 3) + 1\)이고, 점근선은 \(x = 3\)이다. 원래 함수의 점근선 \(y = 3\)이 \(y = x\)에 대칭이동되어 \(x = 3\)이 된 것이다. 아래 탐구 카드에서 밑과 이동을 바꾸며 그래프를 직접 맞추어 보자.

  1. 밑이 1보다 큰 두 지수함수 \(y = 2^x\)와 \(y = 3^x\)를 비교하면, \(x > 0\)에서는 밑이 큰 \(3^x\)가 위에, \(x < 0\)에서는 아래에 있다. 두 그래프는 점 \((0, 1)\)에서만 만난다.
마무리

지수함수의 그래프는 점 \((0, 1)\)을 지나고 \(x\)축을 점근선으로 가지며, 밑이 1보다 크면 증가, 작으면 감소한다. 로그함수의 그래프는 이것을 \(y = x\)에 대칭이동한 모양이고, 평행이동하면 지나는 점과 점근선이 함께 옮겨 간다. 그래서 처음 질문의 \(y = 2^{x-1} + 3\)은 \(y = 2^x\)를 오른쪽으로 1, 위로 3 옮긴 그래프로, 점근선은 \(y = 3\)이다.

—
  1. 질문\(y = 2^x\)과 \(y = (\frac{1}{2})^x\)의 그래프는 어떻게 다를까? 두 그래프가 함께 지나는 점이 있을까?
  2. 복원\(y = f(x)\)의 그래프를 \(x\)축 방향으로 \(p, y\)축 방향으로 \(q\)만큼 평행이동하면 \(y = f(x - p) + q\)이다. 그리고 \(y\)축에 대칭이동하면 \(y = f(-x)\)이다.
  3. 설명\(y = a^x(a > 0, a \ne 1)\)의 그래프는 언제나 점 (0, 1)과 \((1, a)\)를 지난다. 이 그래프는 \(a > 1\)이면 증가하고 \(0 < a < 1\)이면 감소한다. 또 치역이 \(y > 0\)이라 그래프는 \(x\)축 위에만 있고, 한쪽 끝에서 \(x\)축에 한없이 가까워진다. 그래프가 한없이 가까워지는 이런 직선을 점근선이라 하는데, 여기서는 \(x\)축(\(y = 0\))이다. 그런데 \((\frac{1}{a})^x = a^{-x}\)이므로 \(y = a^x\)와 \(y = (\frac{1}{a})^x\)의 그래프는 \(y\)축에 대칭이다. 평행이동한 \(y = a^{x-p} + q\)는 점 \((p, 1 + q)\)를 지나고, 점근선은 \(y = q\), 치역은 \(y > q\)이다.
  4. 연결밑이 1에서 멀수록 그래프가 가파르다. 그리고 증가함수이므로 \(a > 1\)이면 \(a^{x_1} < a^{x_2} \Leftrightarrow x_1 < x_2\)이고, 이것이 지수부등식을 푸는 근거가 된다. 반면 \(0 < a < 1\)이면 부등호 방향이 바뀐다.
  5. 적용\(a\)를 4에서 0.2까지 천천히 줄이며 그래프가 언제 수평선이 되고 언제 내리막으로 바뀌는지 보자. 다음에는 대칭 그래프를 겹쳐 놓고 두 곡선이 만나는 점을 찾고, \(p, q\)를 움직여 점근선과 (0, 1)이 옮겨 간 점을 확인해 보자.
  6. 판단그래프가 \(x\)축에 아주 가까워 보여도 \(a^x > 0\)이므로 만나지는 않는다. 또 \(y = 2^{x-1}\)을 \(x\)축 방향으로 \(-1\)만큼 이동한 것으로 읽는 실수가 흔한데, \(x - 1\)이면 오른쪽으로 1만큼 이동한 것이다. 밑이 1이면 직선 \(y = 1\)이 되어 지수함수가 아니다.

로그함수의 그래프는 지수함수의 그래프와 어떤 관계일까?

로그함수의 그래프 · 직선 \(y = x\)에 대칭

—

P (지수함수 위)
—
Q (로그함수 위)
—
PQ의 중점
—

그림을 끌면 점 P가 지수함수의 그래프를 따라 움직인다. 가로와 세로 눈금 간격을 같게 그렸다.

  1. 질문\(y = \log_2 x\)의 그래프를 점을 하나씩 찍지 않고 그릴 수 있을까? 이미 아는 \(y = 2^x\)의 그래프를 이용할 수는 없을까?
  2. 복원로그함수 \(y = \log_a x\)는 지수함수 \(y = a^x\)의 역함수이다. 그리고 함수와 그 역함수의 그래프는 직선 \(y = x\)에 대칭이며, 점 \((s, t)\)와 \((t, s)\)도 \(y = x\)에 대칭이다.
  3. 설명지수함수 위의 점 \(P(s, a^s)\)의 좌표를 바꾼 \(Q(a^s, s)\)는 \(\log_a a^s = s\)이므로 로그함수 위에 있다. 그래서 로그함수의 그래프는 지수함수의 그래프를 직선 \(y = x\)에 대칭이동한 것이고, 성질도 그대로 옮겨 간다. 즉 \(y = \log_a x\)는 점 (1, 0)과 \((a, 1)\)을 지나고, \(a > 1\)이면 증가, \(0 < a < 1\)이면 감소한다. 정의역은 \(x > 0\)이고, \(y\)축(\(x = 0\))이 점근선이다. 또 \(y = \log_a(x - p) + q\)의 역함수는 \(y = a^{x-q} + p\)이고, 점근선은 각각 \(x = p\)와 \(y = p\)이다.
  4. 연결\(y = \log_{1/a} x = -\log_a x\)이므로 밑이 역수인 두 로그함수의 그래프는 \(x\)축에 대칭이다. 지수함수는 아주 빠르게, 로그함수는 아주 느리게 커진다는 것도 이 대칭으로 이해할 수 있다. 가령 \(\log_2 1000000\)은 20도 되지 않는다.
  5. 적용P를 움직이며 PQ의 중점이 늘 직선 \(y = x\) 위에 있는지 확인해 보자. 밑을 0.5로 바꾸어 두 그래프가 어디에서 만나는지 보고, 밑이 2일 때와 1.25일 때를 비교한 뒤, 로그함수를 \(p, q\)만큼 옮기면 지수함수가 어떻게 따라 움직이는지도 보자.
  6. 판단"\(a > 1\)이면 \(y = a^x\)와 \(y = \log_a x\)의 그래프는 늘 만나지 않는다"는 틀린 말이다. 밑이 1보다 크더라도 약 1.44 이하로 1에 가까우면 두 그래프가 직선 \(y = x\) 위에서 만난다. 예를 들어 밑이 \(\sqrt{2}\)이면 (2, 2)와 (4, 4)에서 만난다. \(a = 2\)에서 만나지 않는 것은 \(2^x > x\)가 늘 성립하기 때문이다. 또 대칭이동과 평행이동을 함께 할 때는 이동 방향이 서로 바뀌어, 로그함수의 \(x\)축 방향 이동은 지수함수의 \(y\)축 방향 이동이 된다.
