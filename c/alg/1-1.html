거듭제곱과 거듭제곱근

같은 수를 여러 번 곱한 것이 거듭제곱입니다. 거꾸로 "n번 곱해서 a가 되는 수는 무엇인가"를 물으면 거듭제곱근이 나옵니다. 이 절에서는 \(x^n = a\)의 실근이 몇 개인지 그래프로 세어 보고, 거듭제곱근끼리 곱하고 나누고 거듭제곱하는 성질을 양변을 비교해 확인합니다.

먼저 알면 좋은 것 제곱근과 그 성질자연수 지수의 거듭제곱함수의 그래프와 교점복소수

그림 위를 위아래로 끌어도 수평선 \(y = a\)가 움직입니다.

  1. 질문2를 세 번 곱하면 8입니다. 그러면 세제곱해서 8이 되는 실수는 2 하나뿐일까요? 네제곱해서 5가 되는 실수, 네제곱해서 \(-6\)이 되는 실수는 몇 개일까요?
  2. 복원제곱해서 \(a\)가 되는 수를 \(a\)의 제곱근이라 했습니다. 양수 \(a\)의 제곱근은 \(\sqrt{a}\)와 \(-\sqrt{a}\) 두 개이고, 음수의 제곱근은 실수가 아니라 허수입니다. 방정식 \(f(x) = a\)의 실근은 \(y = f(x)\)와 \(y = a\)의 교점의 \(x\)좌표입니다.
  3. 설명\(n\)이 2 이상의 자연수일 때, \(x^n = a\)를 만족하는 수 \(x\)를 \(a\)의 \(n\)제곱근이라 하고, 제곱근·세제곱근·네제곱근 … 을 통틀어 거듭제곱근이라 합니다. 복소수까지 넓히면 0이 아닌 \(a\)의 \(n\)제곱근은 \(n\)개 있습니다. 그중 실수는 그래프의 교점 수만큼입니다. \(n\)이 홀수이면 \(y = x^n\)이 계속 증가하므로 실수인 \(n\)제곱근은 \(a\)의 부호와 상관없이 하나이고, 이것을 \(\sqrt[n]{a}\)로 씁니다. \(n\)이 짝수이면 그래프가 \(y\)축에 대칭이고 \(y \ge 0\)에만 있으므로, \(a > 0\)이면 \(\sqrt[n]{a}\)(양수)와 \(-\sqrt[n]{a}\) 두 개, \(a = 0\)이면 0 하나, \(a < 0\)이면 하나도 없습니다.
  4. 연결\(\sqrt[2]{a}\)는 줄여서 \(\sqrt{a}\)로 씁니다. 세제곱근은 부피가 주어진 정육면체의 모서리를 구할 때, \(n\)제곱근은 \(n\)년 동안의 평균 증가율을 구할 때 나옵니다. 다음 절에서는 \(\sqrt[n]{a}\)를 지수 \(\frac{1}{n}\)을 써서 \(a^{1/n}\)로 나타냅니다.
  5. 적용\(n = 3\)과 \(n = 4\)에서 \(a\)를 \(-9\)부터 9까지 움직이며 교점 수가 언제 바뀌는지 적어 보세요. 짝수 하나, 홀수 하나를 더 골라 같은 규칙이 성립하는지 확인하세요. \(n\)을 키우면 \(a = 5\)일 때의 양의 교점은 1에 가까워지나요, 멀어지나요?
  6. 판단"\(-8\)의 세제곱근 가운데 실수는 없다", "\(\sqrt[4]{16} = \pm 2\)"는 흔한 실수입니다. 음수의 홀수 제곱근은 실수로 있고(\(\sqrt[3]{-8} = -2\)), 기호 \(\sqrt[n]{a}\)는 \(n\)이 짝수이면 양의 실근 하나만 가리킵니다. "16의 네제곱근"(\(\pm 2\), 허수 \(\pm 2i\)까지 네 개)과 "\(\sqrt[4]{16}\)"(2 하나)은 서로 다른 말입니다.

1.1.2

거듭제곱근끼리 곱하면 왜 근호 하나로 합쳐질까?

아래 두 막대는 양변을 똑같이 거듭제곱한 값입니다. 쓰지 않는 문자의 슬라이더는 흐리게 보입니다.

  1. 질문\(\sqrt{2} \times \sqrt{8} = \sqrt{16} = 4\)였습니다. 세제곱근에서도 \(\sqrt[3]{2} \times \sqrt[3]{4} = \sqrt[3]{8} = 2\)처럼 근호 안끼리 곱해도 될까요? 된다면 언제나 그럴까요?
  2. 복원\(\sqrt[n]{a}\)는 \(n\)제곱해서 \(a\)가 되는 실수입니다. 그래서 \((\sqrt[n]{a})^n = a\)입니다. 또 \((xy)^n = x^ny^n\)은 자연수 지수에서 이미 아는 법칙입니다.
  3. 설명양변을 \(n\)제곱해 비교합니다. \((\sqrt[n]{a} \cdot \sqrt[n]{b})^n = (\sqrt[n]{a})^n(\sqrt[n]{b})^n = ab\)이므로, \(\sqrt[n]{a} \cdot \sqrt[n]{b}\)는 \(n\)제곱해서 \(ab\)가 되는 양수, 곧 \(\sqrt[n]{ab}\)입니다. 같은 방법으로 \(a > 0\), \(b > 0\)이고 \(m, n\)이 2 이상의 자연수일 때 다음이 성립합니다. ① \(\sqrt[n]{a} \sqrt[n]{b} = \sqrt[n]{ab}\) ② \(\sqrt[n]{a} / \sqrt[n]{b} = \sqrt[n]{\frac{a}{b}}\) ③ \((\sqrt[n]{a})^m = \sqrt[n]{a^m}\) ④ \(\sqrt[m]{\sqrt[n]{a}} = \sqrt[mn]{a}\) ⑤ \(\sqrt[np]{a^{mp}} = \sqrt[n]{a^m}\) (그림에서는 \(p = 2\)). 핵심은 "양변이 모두 양수이고, 같은 수만큼 거듭제곱한 값이 같으면 원래 값도 같다"는 것입니다.
  4. 연결이 성질로 \(\sqrt[3]{54} = \sqrt[3]{27} \cdot \sqrt[3]{2} = 3\sqrt[3]{2}\)처럼 근호 안을 간단히 하고, \(\sqrt[3]{3}\)과 \(\sqrt{2}\)처럼 근호가 다른 수는 ⑤로 \(\sqrt[6]{9}, \sqrt[6]{8}\)로 맞춰 크기를 비교합니다. 다음 절에서 \(\sqrt[n]{a} = a^{1/n}\)로 쓰면 다섯 성질은 모두 지수법칙 하나로 정리됩니다.
  5. 적용①에서 \(a = -4\), \(b = -9\), \(n = 2\)로 두면 양변은 어떻게 되나요? 같은 \(a, b\)에서 \(n = 3\)이면요? ⑤에서 \(a = -2\), \(n = 3\), \(m = 3\)으로 두고 윗줄과 아랫줄을 비교해 보세요. 아랫줄이 같은데 윗줄이 다른 까닭은 무엇인가요?
  6. 판단아랫줄(거듭제곱한 값)이 같아도 윗줄이 같다고 할 수 없는 경우가 있습니다. 짝수 번 거듭제곱하면 3과 \(-3\)이 둘 다 9가 되듯 부호 정보가 사라지기 때문입니다. 그래서 성질들은 \(a > 0\), \(b > 0\)일 때로 약속하고 씁니다. 이 조건을 잊고 \(\sqrt{-4} \sqrt{-9} = \sqrt{36} = 6\)이라고 쓰면 틀립니다. 실제 값은 \(2i \cdot 3i = -6\)입니다.
