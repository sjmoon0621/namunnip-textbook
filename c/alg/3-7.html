3.7.1

몇 개를 확인하면 모든 자연수에서 참일까?

수학적 귀납법 · 원리

—

쓰러진 도미노
—
처음 멈춘 곳
—
P(k) ⇒ P(k+1)
—

도미노 사이의 초록 점은 'P(k)가 참이면 P(k + 1)도 참'이 그 자리에서 성립함을, 주황 ×는 깨짐을 뜻합니다. 화면에는 12개씩 보입니다.

  1. 질문n2 + n + 41은 n = 1, 2, 3, …, 39에서 모두 소수입니다. 39개나 확인했으니 모든 자연수 n에서 소수라고 해도 될까요?
  2. 복원명제 P(n)은 자연수 n마다 참 또는 거짓이 정해지는 문장입니다. 수열의 귀납적 정의에서는 첫째항과 '앞 항에서 다음 항'의 규칙으로 모든 항이 정해졌습니다.
  3. 설명자연수 n에 대한 명제 P(n)이 모든 자연수에서 참임을 보이려면 다음 두 가지를 보이면 됩니다. ① n = 1일 때 P(1)이 참이다. ② n = k일 때 P(k)가 참이라고 가정하면 n = k + 1일 때 P(k + 1)도 참이다. 이것을 수학적 귀납법이라고 합니다. ①로 1번 도미노가 쓰러지고, ②로 1번이 2번을, 2번이 3번을 쓰러뜨리므로 모든 도미노가 쓰러집니다. ②는 특정한 k가 아니라 모든 자연수 k에 대해 보여야 합니다.
  4. 연결수열의 귀납적 정의가 '첫째항 + 관계식'으로 모든 항을 정하듯, 수학적 귀납법은 '첫 경우 + 이어지는 규칙'으로 모든 경우의 참을 보장합니다. ①을 n = m으로 바꾸면 n ≥ m인 모든 자연수에서 참임을 보일 수 있습니다.
  5. 적용세 명제를 차례로 고르고 보는 구간을 옮겨 보세요. 소수 명제는 어디서 멈추나요? 그 앞의 39개는 무엇을 증명하지 못했나요? 2n > n2에서 처음 미는 도미노를 1과 5로 바꾸면 무엇이 달라지나요?
  6. 판단몇 개의 예를 확인하는 것은 증명이 아닙니다. 소수 명제는 n = 40에서 402 + 40 + 41 = 412이 되어 거짓입니다. 반대로 ②만 보이고 ①을 빠뜨려도 안 됩니다. 'P(k)이면 P(k + 1)'은 'n = n + 1'처럼 거짓인 명제에서도 성립할 수 있지만, 첫 도미노가 쓰러지지 않으면 아무것도 쓰러지지 않습니다.

3.7.2

P(k)에서 P(k + 1)로 어떻게 건너갈까?

수학적 귀납법 · 등식의 증명

—

1 + 3 + … + (2k − 1)
—
더하는 홀수 2k + 1
—
(k + 1)2
—
  1. 질문모든 자연수 n에 대해 1 + 3 + 5 + … + (2n − 1) = n2임을 수학적 귀납법으로 증명해 봅시다. 가장 어려운 곳은 'P(k)이면 P(k + 1)'입니다. 무엇을 가정하고 무엇을 보여야 할까요?
  2. 복원수학적 귀납법은 ① P(1)이 참이고 ② P(k)가 참이라고 가정하면 P(k + 1)도 참임을 보이는 증명 방법입니다. 1부터 k번째 홀수까지의 합에 (k + 1)번째 홀수 2k + 1을 더하면 (k + 1)번째 홀수까지의 합입니다.
  3. 설명① n = 1일 때 왼쪽은 1, 오른쪽은 12 = 1이므로 성립합니다. ② n = k일 때 1 + 3 + … + (2k − 1) = k2이 성립한다고 가정합니다. 양변에 다음 홀수 2k + 1을 더하면 1 + 3 + … + (2k − 1) + (2k + 1) = k2 + 2k + 1 = (k + 1)2입니다. 이것은 P(k + 1)입니다. ①, ②에서 모든 자연수 n에 대해 등식이 성립합니다.
  4. 연결그림에서 한 변이 k인 정사각형(가정)에 2k + 1개의 칸을 ㄱ자로 붙이면 한 변이 k + 1인 정사각형이 됩니다. 식의 k2 + 2k + 1 = (k + 1)2이 바로 이 그림입니다. 같은 틀로 ∑k = n(n + 1)/2, ∑k2 = n(n + 1)(2n + 1)/6도 증명할 수 있습니다. 앞 절에서 구한 공식들이 모든 n에서 맞다는 보증이 여기서 나옵니다.
  5. 적용'다음 단계'를 눌러 증명의 네 단계를 따라가세요. k를 바꾸어도 ㄱ자 조각의 칸 수가 늘 2k + 1이고, 결과가 늘 정사각형인지 확인하세요.
  6. 판단②에서 P(k)는 증명할 대상이 아니라 가정입니다. '증명하려는 것을 가정했으니 순환 논리'라는 오해가 흔하지만, 가정한 것은 P(k)이고 보인 것은 P(k + 1)입니다. 또 P(k + 1)의 식에서 양변을 따로 계산해 맞추지 말고, P(k)의 식에서 출발해 P(k + 1)의 식에 이르러야 합니다.
