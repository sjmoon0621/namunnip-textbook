1.3.1

거듭제곱끼리 곱하면 지수는 왜 더해질까?

지수법칙 · 인수 세기

—

남은 인수의 개수
—
법칙으로 계산 (a = 2, b = 3)
—
직접 계산
—
  1. 질문23 × 24을 계산할 때 8 × 16 = 128을 구한 뒤 2의 몇 제곱인지 다시 찾아야 할까요? 지수만 보고 바로 답할 수는 없을까요?
  2. 복원an은 a를 n번 곱한 수입니다. 곱셈은 순서를 바꾸어도, 괄호를 다시 묶어도 결과가 같습니다(교환법칙, 결합법칙).
  3. 설명그림의 동그라미 하나가 곱해지는 인수 하나입니다. am × an은 a가 m개 뒤에 n개 더 붙으므로 am+n, (am)n은 m개짜리 묶음이 n줄이므로 amn, (ab)n은 짝 ab를 n번 곱한 것을 a끼리, b끼리 다시 모으면 anbn입니다. 나눗셈은 분자와 분모에서 같은 인수를 지우므로 am−n이고, 분모 쪽이 많이 남으면 음의 지수가 됩니다. 앞 절에서 지수를 넓힐 때 이 법칙이 깨지지 않도록 뜻을 정했으므로, a > 0, b > 0이고 x, y가 실수일 때도 다음이 성립합니다. axay = ax+y, ax ÷ ay = ax−y, (ax)y = axy, (ab)x = axbx.
  4. 연결컴퓨터의 저장 용량 210 × 210 = 220, 과학 표기 (3 × 108)2 = 9 × 1016처럼 큰 수의 곱셈은 지수의 덧셈과 곱셈으로 바뀝니다. 이 생각을 거꾸로 쓰는 것이 로그입니다.
  5. 적용네 법칙을 하나씩 골라 m, n을 바꾸며 동그라미 수와 지수가 늘 일치하는지 확인하세요. 나눗셈에서 n을 m보다 크게 하면 남은 인수는 어디에 있고, 지수는 어떻게 되나요?
  6. 판단am + an = am+n, (a + b)n = an + bn은 틀린 식입니다. 지수법칙은 곱셈과 나눗셈에서만 성립합니다. 23 + 24 = 24이지만 27 = 128입니다. 또 (am)n과 amn은 다릅니다. (23)2 = 64, 29 = 512입니다.

1.3.2

지수가 소수여도 높이를 곱하면 지수가 더해질까?

실수 지수의 지수법칙 · 그래프의 높이
ax × ay
—
ax+y
—
ax + ay
—

초록 막대는 ax, 파란 막대는 ay, 주황 막대는 ax+y의 높이입니다. 그림을 좌우로 끌면 x가 움직입니다.

  1. 질문23 × 24 = 27은 인수를 세어 확인할 수 있습니다. 그런데 20.7 × 21.6은 인수를 셀 수 없습니다. 이때도 22.3이 될까요?
  2. 복원앞 절에서 지수를 0, 음의 정수, 유리수, 실수로 넓힐 때마다 aman = am+n이 깨지지 않도록 뜻을 정했습니다. 밑이 양수이면 ax는 모든 실수 x에서 하나로 정해집니다.
  3. 설명그래프 y = ax 위에서 x와 y의 높이를 곱한 값은 x + y에서의 높이와 언제나 같습니다. 지수가 정수일 때는 인수를 세어 보였고, 유리수일 때는 거듭제곱근의 성질로, 실수일 때는 유리수로 감싸는 방법으로 같은 결론을 얻습니다. 그래서 a > 0, b > 0이고 x, y가 실수일 때 axay = ax+y, ax ÷ ay = ax−y, (ax)y = axy, (ab)x = axbx가 모두 성립합니다. 높이를 곱하는 일이 가로 위치를 더하는 일로 바뀐다는 점이 지수법칙의 그림입니다.
  4. 연결세균이 하루에 2배로 늘면 0.7일 뒤에는 20.7배, 다시 1.6일 뒤에는 그 21.6배가 되어 합계 22.3배입니다. 시간을 더하면 배율은 곱해집니다. 이 관계가 지수함수를 성장과 감소의 모형으로 쓰는 까닭입니다.
  5. 적용x, y를 바꾸며 처음 두 값이 늘 같은지 확인하세요. x = −y로 두면 주황 막대의 높이는 얼마인가요? ax + ay가 ax+y와 같아지는 경우가 있는지도 찾아보세요.
  6. 판단지수법칙은 밑이 양수일 때로 약속한 것입니다. 밑이 음수이면 ((−8)2)1/6 = 2인데 (−8)2 × 1/6 = (−8)1/3으로 계산하면 −2가 되어 법칙이 깨집니다. 또 덧셈 ax + ay에는 지수법칙이 없습니다. 우연히 같아지는 값이 있더라도 법칙이 아닙니다.

1.3.3

복잡한 거듭제곱 식을 밑 하나로 정리하려면?

지수법칙 · 지수 장부

—

2의 지수
—
3의 지수
—
지금까지 정리한 값
—

식의 수를 모두 소인수 2와 3의 거듭제곱으로 바꾼 뒤, 각 밑의 지수를 따로 적어 갑니다.

  1. 질문43/2 × 8−1/3 ÷ √2는 밑도 지수도 제각각입니다. 계산기 없이 정리할 수 있을까요?
  2. 복원밑이 양수이고 지수가 실수일 때 axay = ax+y, ax ÷ ay = ax−y, (ax)y = axy, (ab)x = axbx입니다. 거듭제곱근은 n√a = a1/n입니다.
  3. 설명정리하는 순서는 늘 같습니다. 첫째, 근호를 유리수 지수로 바꿉니다. 둘째, 밑을 소인수의 거듭제곱으로 바꿉니다(4 = 22, 8 = 23, 27 = 33). 셋째, (ax)y = axy로 지수를 곱하고, (ab)x = axbx로 밑을 나눕니다. 넷째, 같은 밑끼리 곱셈은 지수를 더하고 나눗셈은 지수를 뺍니다. 그림의 수직선은 밑마다 지수를 적어 두는 장부입니다. 곱하면 오른쪽, 나누면 왼쪽으로 화살표가 이어지고, 마지막 위치가 답의 지수입니다.
  4. 연결이 방법은 단위 환산(1 km2 = (103 m)2 = 106 m2)이나 과학 표기 계산에서 그대로 쓰입니다. 밑을 하나로 맞추는 생각은 지수방정식을 풀 때도 첫 단계가 됩니다.
  5. 적용세 식을 하나씩 골라 "다음 단계"를 누르며 화살표가 어느 쪽으로 얼마나 움직이는지 보세요. 마지막 값이 처음 식을 직접 계산한 값과 같은지 아래 수치에서 확인하세요. 세 번째 식은 왜 장부가 두 줄 필요한가요?
  6. 판단43/2을 (43)/2 = 32나 4 × 3/2 = 6으로 계산하는 실수가 흔합니다. 43/2 = (22)3/2 = 23 = 8입니다. 또 밑이 다른 거듭제곱(23 × 32)은 지수를 더해 합칠 수 없습니다. 밑이 같아질 때까지 소인수로 나눈 뒤에만 지수를 더합니다.
