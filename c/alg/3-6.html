가로 2, 세로 \(n\)인 판을 \(1 \times 2\) 크기의 타일로 빈틈없이 덮는 방법의 수를 \(a_n\)이라 하자. \(n = 10\)일 때의 방법은 그림을 다 그려 세기에는 너무 많다. 그런데 \(a_9\)와 \(a_8\)을 알면 \(a_{10}\)을 바로 구할 수 있다고 한다. 어떻게 그럴까?

먼저 알아야 할 것수열과 일반항(수열의 뜻), 등차수열과 등비수열(등차수열, 등비수열), 합의 법칙(공통수학1).

3.6.1첫째항과 규칙으로 정하기

수열은 일반항으로 정할 수도 있지만, 첫째항과 이웃한 항 사이의 관계로 정할 수도 있다. 가령 '\(a_1 = 3\)이고, \(a_{n+1} = a_n + 2\)'라고 하면 \(a_2 = 5\), \(a_3 = 7\), …로 모든 항이 차례로 정해진다. 이렇게 처음 몇 항과 이웃한 항 사이의 관계식으로 수열을 정하는 것을 수열의 귀납적 정의라 하고, 관계식을 점화식이라 한다.

정리 3.6.1 대표적인 점화식

\(a_{n+1} = a_n + d\)이면 공차가 \(d\)인 등차수열이고, \(a_{n+1} = ra_n\)이면 공비가 \(r\)인 등비수열이다. \(2a_{n+1} = a_n + a_{n+2}\)이면 등차수열, \(a_{n+1}^2 = a_na_{n+2}\)이면 등비수열이다.

3.6.2경우를 나누어 점화식 세우기

점화식은 일반항을 찾기 어려운 문제에서 특히 쓸모 있다. 처음 질문의 판에서 맨 오른쪽 끝을 어떻게 덮었는지로 경우를 나누어 보자. 세로 타일 하나로 덮었다면 나머지 \(2 \times (n - 1)\) 판을 덮는 방법은 \(a_{n-1}\)가지이다. 가로 타일 두 개를 위아래로 겹쳐 덮었다면 나머지는 \(2 \times (n - 2)\) 판이고 \(a_{n-2}\)가지이다.

두 경우는 겹치지 않고 모든 경우를 빠짐없이 나누므로, 합의 법칙에 따라 \(a_n = a_{n-1} + a_{n-2}\)이다. 그런데 이 식만으로는 출발할 수 없다. \(a_1 = 1\), \(a_2 = 2\)를 직접 세어 주어야 \(a_3 = 3\), \(a_4 = 5\), \(a_5 = 8\), …이 차례로 정해진다. 그림 1의 슬라이더로 \(n\)을 바꾸어 보면 두 경우의 수가 앞의 두 값이다.1

3.6.3예제 하나를 끝까지

예제 3.6.2

처음 질문의 \(a_{10}\)을 구하여라. 또 \(a_1 = 1\), \(a_{n+1} = 2a_n + 1\)로 정해진 수열의 제5항을 구하고, \(b_n = a_n + 1\)로 두어 일반항을 구하여라.

\(a_1 = 1\), \(a_2 = 2\)에서 점화식으로 차례로 더하면 3, 5, 8, 13, 21, 34, 55, 89이므로 \(a_{10} = 89\)이다. 10칸짜리 판을 덮는 방법이 89가지라는 것을 그림을 하나도 그리지 않고 얻었다.

두 번째 수열은 1, 3, 7, 15, 31이므로 제5항은 31이다. 그런데 각 항에 1을 더하면 2, 4, 8, 16, 32로 등비수열처럼 보인다. 실제로 \(b_{n+1} = a_{n+1} + 1 = 2a_n + 2 = 2b_n\)이므로 \(\{b_n\}\)은 첫째항 2, 공비 2인 등비수열이다.

따라서 \(b_n = 2^n\)이고 \(a_n = 2^n - 1\)이다. 점화식을 아는 꼴로 바꾸는 치환 하나로 일반항까지 얻은 셈이다. 아래 탐구 카드에서 점화식의 첫째항과 규칙을 바꾸며 수열이 어떻게 이어지는지 직접 확인해 보자.

  1. \(a_n = a_{n-1} + a_{n-2}\)를 만족하는 수열 1, 1, 2, 3, 5, 8, …을 피보나치수열이라 한다. 이웃한 두 항의 비 \(\tfrac{a_{n+1}}{a_n}\)은 \(n\)이 커질수록 황금비 \(\tfrac{1 + \sqrt{5}}{2} \approx 1.618\)에 가까워진다.
마무리

귀납적 정의는 처음 몇 항과 이웃한 항 사이의 점화식으로 수열을 정하며, 일반항을 바로 찾기 어려운 경우의 수 문제에서 경우를 나누어 점화식을 세우면 쉽게 풀린다. 그래서 처음 질문의 판은 맨 끝을 덮는 두 가지 방법으로 나누어 \(a_n = a_{n-1} + a_{n-2}\)를 얻고, \(a_{10} = 89\)이다.

이 수열은
—
  1. 질문일반항 식이 없어도 '첫째항은 1이고, 각 항에 2를 더하면 다음 항이 된다'고 하면 수열이 하나로 정해질까?
  2. 복원등차수열은 이웃한 항의 차가 공차 \(d\)로 일정하고, 등비수열은 이웃한 항의 비가 공비 \(r\)로 일정하다.
  3. 설명수열을 첫째항 \(a_1\)의 값과 이웃한 항 사이의 관계식(예를 들어 \(a_{n+1} = 2a_n + 1, n = 1, 2, 3, \cdots\))으로 정하는 것을 수열의 귀납적 정의라고 한다. \(a_1\)에서 관계식으로 \(a_2\)를, \(a_2\)에서 \(a_3\)을 차례로 얻으므로 모든 항이 하나로 정해진다. 그래서 등차수열은 \(a_{n+1} = a_n + d\), 등비수열은 \(a_{n+1} = ra_n\)으로 나타낸다. 또 \(2a_{n+1} = a_n + a_{n+2}\)는 등차수열, \(a_{n+1}^2 = a_na_{n+2}\)는 등비수열의 귀납적 표현이다(등차중항과 등비중항).
  4. 연결일반항은 \(n\)을 넣으면 바로 그 항을 주는 '직접 계산'이고, 귀납적 정의는 앞 항에서 다음 항을 만드는 '한 단계씩 계산'이다. 컴퓨터 프로그램의 반복문과 같은 생각이고, 다음 카드처럼 세는 문제를 나타내는 데 특히 편하다.
  5. 적용'다음 항 만들기'를 여러 번 눌러 세 가지 규칙에서 점들이 어떻게 놓이는지 보자. 같은 관계식에서 첫째항만 바꾸어 보고, '곱하고 더하기'에서 첫째항을 4로 바꾸면 무엇이 보이는지도 확인해 보자.
  6. 판단관계식만 있고 첫째항이 없으면 수열이 정해지지 않는다. 같은 \(a_{n+1} = a_n + 2\)라도 첫째항이 1이면 홀수, 2이면 짝수의 수열이다. 또 관계식의 \(n\)이 어디서부터 성립하는지(\(n = 1, 2, 3, \cdots\))도 함께 밝혀야 한다.

작은 그림 하나가 덮는 방법 하나이다. 맨 왼쪽 조각을 지우고 남은 부분을 보자.

  1. 질문가로 \(n\), 세로 2인 판을 \(1 \times 2\) 도미노로 빈틈없이 덮는 방법의 수를 \(a_n\)이라 하자. \(n = 10\)일 때 모든 방법을 그려 보지 않고 셀 수 있을까?
  2. 복원수열은 첫째항과 이웃한 항 사이의 관계식으로 정할 수 있다. 그리고 경우의 수를 셀 때는 겹치지 않고 빠짐없이 나누어 더한다(합의 법칙).
  3. 설명맨 왼쪽 칸을 덮는 방법은 두 가지뿐이다. 세로 도미노 하나를 두면 남은 부분은 가로 \(n - 1\)인 판이고, 덮는 방법은 \(a_{n-1}\)가지이다. 가로 도미노 두 개를 위아래로 두면 남은 부분은 가로 \(n - 2\)인 판이고, \(a_{n-2}\)가지이다. 두 경우는 겹치지 않으므로 \(a_n = a_{n-1} + a_{n-2} (n \ge 3)\)이고, \(a_1 = 1\), \(a_2 = 2\)이다. 이 귀납적 정의로 \(1, 2, 3, 5, 8, 13, \cdots\)을 차례로 얻으면 \(a_{10} = 89\)이다.
  4. 연결이 관계식은 이웃한 두 항으로 다음 항을 정하므로 첫째항과 둘째항이 모두 필요하다. 계단을 한 번에 한 칸 또는 두 칸씩 오르는 방법의 수도 같은 관계를 따른다. 이렇게 문제의 구조에서 관계식을 세우는 데 귀납적 정의가 쓰인다. 일반항을 구하는 것은 이 과목의 범위를 넘지만, 관계식만으로도 원하는 항을 계산할 수 있다.
  5. 적용\(n\)을 바꾸며 초록 묶음과 주황 묶음의 개수가 각각 \(a_{n-1}\), \(a_{n-2}\)인지 세어 보자. 초록 묶음에서 맨 왼쪽 세로 조각을 지우면 남는 그림들이 가로 \(n - 1\)인 판을 덮는 방법과 같다는 것도 확인할 수 있다.
  6. 판단\(a_n = a_{n-1} + 1\)처럼 '조각 하나를 더 놓는 방법은 하나'라고 세는 실수가 흔하다. 새 조각을 어디에 놓느냐가 아니라 맨 왼쪽을 어떻게 덮느냐로 나누어야 겹치거나 빠지는 경우가 없다. 또 관계식이 \(n \ge 3\)에서만 쓰인다는 것과 처음 두 항을 함께 밝혀야 한다.
