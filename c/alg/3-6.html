수열의 귀납적 정의

도미노의 첫 조각과 '앞 조각이 넘어지면 다음 조각이 넘어진다'는 규칙만 알면 모든 조각의 운명이 정해집니다. 수열도 그렇습니다. 이 절에서는 일반항 대신 첫째항과 이웃한 항 사이의 관계로 수열을 정하는 방법을 익히고, 세는 문제를 이런 관계식으로 나타내 봅니다.

이 수열은
—
  1. 질문일반항 식이 없어도 '첫째항은 1이고, 각 항에 2를 더하면 다음 항이 된다'고 하면 수열이 하나로 정해질까요?
  2. 복원등차수열은 이웃한 항의 차가 공차 \(d\)로 일정하고, 등비수열은 이웃한 항의 비가 공비 \(r\)로 일정합니다.
  3. 설명수열을 ① 첫째항 \(a_1\)의 값과 ② 이웃한 항 사이의 관계식(예: \(a_{n+1} = 2a_n + 1, n = 1, 2, 3, \cdots\))으로 정하는 것을 수열의 귀납적 정의라고 합니다. \(a_1\)에서 관계식으로 \(a_2\)를, \(a_2\)에서 \(a_3\)을 차례로 얻으므로 모든 항이 하나로 정해집니다. 등차수열은 \(a_{n+1} = a_n + d\), 등비수열은 \(a_{n+1} = ra_n\)으로 나타냅니다. 또 \(2a_{n+1} = a_n + a_{n+2}\)는 등차수열, \(a_{n+1}^2 = a_na_{n+2}\)는 등비수열의 귀납적 표현입니다(등차중항·등비중항).
  4. 연결일반항은 \(n\)을 넣으면 바로 그 항을 주는 '직접 계산', 귀납적 정의는 앞 항에서 다음 항을 만드는 '한 단계씩 계산'입니다. 컴퓨터 프로그램의 반복문과 같은 생각이고, 다음 카드처럼 세는 문제를 나타내는 데 특히 편합니다.
  5. 적용'다음 항 만들기'를 여러 번 눌러 보세요. 세 가지 규칙에서 점들이 어떻게 놓이나요? 같은 관계식에서 첫째항만 바꾸면 어떻게 되나요? '곱하고 더하기'에서 첫째항을 4로 바꾸면 무엇이 보이나요?
  6. 판단관계식만 있고 첫째항이 없으면 수열이 정해지지 않습니다. 같은 \(a_{n+1} = a_n + 2\)라도 첫째항이 1이면 홀수, 2이면 짝수의 수열입니다. 또 관계식의 \(n\)이 어디서부터 성립하는지(\(n = 1, 2, 3, \cdots\))도 함께 밝혀야 합니다.

3.6.2

\(2\times n\) 판을 덮는 방법은 몇 가지일까?

작은 그림 하나가 덮는 방법 하나입니다. 맨 왼쪽 조각을 지우고 남은 부분을 보세요.

  1. 질문가로 \(n\), 세로 2인 판을 \(1 \times 2\) 도미노로 빈틈없이 덮는 방법의 수를 \(a_n\)이라 합시다. \(n = 10\)일 때 모든 방법을 그려 보지 않고 셀 수 있을까요?
  2. 복원수열은 첫째항과 이웃한 항 사이의 관계식으로 정할 수 있습니다. 경우의 수를 셀 때는 겹치지 않고 빠짐없이 나누어 더합니다(합의 법칙).
  3. 설명맨 왼쪽 칸을 덮는 방법은 두 가지뿐입니다. ① 세로 도미노 하나를 두면 남은 부분은 가로 \(n - 1\)인 판이고, 덮는 방법은 \(a_{n-1}\)가지입니다. ② 가로 도미노 두 개를 위아래로 두면 남은 부분은 가로 \(n - 2\)인 판이고, \(a_{n-2}\)가지입니다. 두 경우는 겹치지 않으므로 \(a_n = a_{n-1} + a_{n-2} (n \ge 3)\), 그리고 \(a_1 = 1\), \(a_2 = 2\)입니다. 이 귀납적 정의로 \(1, 2, 3, 5, 8, 13, \cdots\)을 차례로 얻고, \(a_{10} = 89\)입니다.
  4. 연결이 관계식은 이웃한 두 항으로 다음 항을 정하므로 첫째항과 둘째항이 모두 필요합니다. 계단을 한 번에 한 칸 또는 두 칸씩 오르는 방법의 수도 같은 관계를 따릅니다. 이렇게 문제의 구조에서 관계식을 세우는 것이 귀납적 정의의 쓰임입니다. 일반항을 구하는 것은 이 과목의 범위를 넘지만, 관계식만으로도 원하는 항을 계산할 수 있습니다.
  5. 적용\(n\)을 바꾸며 초록 묶음과 주황 묶음의 개수가 각각 \(a_{n-1}\), \(a_{n-2}\)인지 세어 보세요. 초록 묶음에서 맨 왼쪽 세로 조각을 지우면 남는 그림들은 무엇과 같나요?
  6. 판단\(a_n = a_{n-1} + 1\)처럼 '조각 하나를 더 놓는 방법은 하나'라고 세는 실수가 흔합니다. 새 조각을 어디에 놓느냐가 아니라 맨 왼쪽을 어떻게 덮느냐로 나누어야 겹치거나 빠지는 경우가 없습니다. 또 관계식이 \(n \ge 3\)에서만 쓰인다는 것과 처음 두 항을 함께 밝혀야 합니다.
