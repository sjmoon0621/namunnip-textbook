지수함수와 로그함수

지수를 실수까지 넓혔으므로 이제 지수 자리에 변수를 넣을 수 있습니다. 실수 x마다 ax를 하나씩 정하는 대응이 지수함수이고, 거꾸로 양수 x마다 그 지수 loga x를 정하는 대응이 로그함수입니다. 이 절에서는 두 함수의 뜻과 밑의 조건, 정의역과 치역을 대응을 직접 움직이며 확인합니다.

1.6.1

y = ax가 함수가 되려면 밑은 어때야 할까?

지수함수의 뜻 · 밑의 조건

—

출력 ax
—
찍힌 점 / 전체 입력
—
판정
—

점은 −4부터 4까지 0.25 간격의 입력에서 계산한 출력입니다. 출력이 실수가 아니면 점을 찍지 않습니다. 그림을 좌우로 끌어도 입력이 바뀝니다.

  1. 질문세균이 1시간마다 2배로 늘면 x시간 뒤에는 2x배가 됩니다. x가 0.5나 −1이어도 이 식이 뜻을 가질까요? 밑이 −2라면 어떨까요?
  2. 복원함수는 정의역의 원소마다 공역의 원소를 하나씩 정하는 대응입니다. a > 0이면 ax는 모든 실수 x에서 하나로 정해지고 언제나 양수입니다.
  3. 설명a > 0, a ≠ 1일 때 실수 x마다 ax를 대응시키는 함수 y = ax를 a를 밑으로 하는 지수함수라 합니다. 정의역은 실수 전체, 치역은 양의 실수 전체입니다. 밑이 음수이면 (−2)1/2처럼 실수가 아닌 값이 생겨 실수 전체에서 함수가 되지 않습니다. 밑이 1이면 1x = 1인 상수함수가 되어, 값이 늘거나 줄어드는 지수함수의 성질이 없고 거꾸로 지수를 찾을 수도 없으므로 제외합니다.
  4. 연결방사성 원소의 붕괴, 원금이 복리로 불어나는 예금, 세균의 증식처럼 같은 시간마다 같은 비율로 변하는 양은 지수함수로 나타납니다. x가 1 늘 때마다 출력이 a배가 되는 것이 지수함수의 핵심 성질입니다.
  5. 적용밑 2에서 x를 1씩 늘리면 출력은 몇 배가 되나요? x를 −4까지 줄이면 출력은 0이 되나요? 밑을 −2로 바꾸면 33개의 입력 가운데 몇 개에서만 점이 찍히나요?
  6. 판단y = x2(거듭제곱 함수)와 y = 2x(지수함수)를 헷갈리지 마세요. 변수가 밑에 있느냐, 지수에 있느냐가 다릅니다. 또 지수함수의 출력은 아무리 작아져도 0이나 음수가 되지 않습니다. 그래프가 x축에 가까워질 뿐 만나지 않습니다.

1.6.2

지수함수의 화살표를 거꾸로 하면 함수가 될까?

로그함수의 뜻 · 대응의 방향

—

x
—
y = loga x
—
검산 ay
—

회색 화살표는 ak와 k(k = −3, …, 3)의 대응이고, 주황 화살표가 지금 고른 x입니다. 왼쪽 열은 수가 몇 배씩 커지는 간격으로 놓았습니다.

  1. 질문세균 수가 1시간마다 2배가 되면 처음의 5배가 되는 데 몇 시간이 걸릴까요? "시간 → 배율"을 거꾸로 "배율 → 시간"으로 읽는 대응도 함수일까요?
  2. 복원함수 f가 일대일대응이면 화살표를 거꾸로 한 역함수 f−1가 있고, f의 정의역과 치역이 서로 바뀝니다. ax = N ⇔ x = loga N입니다.
  3. 설명a > 0, a ≠ 1일 때 지수함수 y = ax는 실수 전체에서 양의 실수 전체로 가는 일대일대응입니다. 서로 다른 x는 서로 다른 값으로 가고, 모든 양수가 한 번씩 값으로 나오기 때문입니다. 그래서 화살표를 거꾸로 해도 양수 x마다 y가 하나씩 정해지는데, 그 y가 바로 loga x입니다. 이 함수 y = loga x를 a를 밑으로 하는 로그함수라 합니다. 로그함수는 지수함수의 역함수이고, 정의역은 양의 실수 전체, 치역은 실수 전체입니다. 지수함수와 정의역·치역이 서로 바뀐 것입니다.
  4. 연결세균 문제의 답은 log2 5 ≈ 2.32시간입니다. 지수함수가 "시간이 지나면 얼마가 되나"를 답한다면, 로그함수는 "얼마가 되려면 시간이 얼마나 걸리나"를 답합니다. 다음 절에서는 역함수 관계를 그래프의 대칭으로 확인합니다.
  5. 적용두 방향 보기를 번갈아 눌러 화살표가 어떻게 바뀌는지 보세요. 왼쪽 열에서 0이나 음수가 없는 까닭은 무엇인가요? x를 0.05까지 줄이면 y는 어떻게 되나요? 밑을 1/2로 바꾸면 왼쪽 열의 순서는 어떻게 되나요?
  6. 판단"로그함수의 치역은 양수"라고 하는 실수가 있습니다. 양수여야 하는 것은 진수, 곧 입력 x이고, 출력 loga x는 0 < x < 1에서 (밑이 1보다 크면) 음수가 됩니다. 지수함수와 로그함수의 정의역·치역을 바꿔 적지 않도록, 늘 "어느 쪽이 지수인가"를 먼저 따지세요.
