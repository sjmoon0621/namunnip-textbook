등비수열

종이를 반으로 접을 때마다 두께가 두 배가 되듯, 이웃한 두 항의 비가 늘 같은 수열이 있습니다. 이 절에서는 이런 수열의 n번째 항이 지수함수와 어떻게 닮았는지 보고, 합을 구할 때 등차수열과는 다른 방법, 곧 합에 공비를 곱해 빼는 방법을 익힙니다.

3.3.1

같은 수를 계속 곱하면 항은 어떻게 변할까?

등비수열 · 공비와 등비중항

—

제7항 a7
—
an+1 ÷ an
—
양옆 항의 곱
—

점선 곡선은 y = a · rx−1입니다. 공비가 음수이면 이런 곡선이 없어 그리지 않습니다.

  1. 질문1, 2, 4, 8, …처럼 같은 수를 곱해 가는 수열은 등차수열과 달리 점점 빨리 커집니다. 이런 수열의 제n항은 어떻게 나타낼까요?
  2. 복원지수법칙에서 rm · rn = rm+n입니다. 지수함수 y = ax는 x가 1 늘 때마다 y가 같은 배수로 바뀝니다.
  3. 설명첫째항부터 차례로 같은 수 r을 곱해 얻는 수열을 등비수열, r을 공비라고 합니다. 모든 n에서 an+1 = ran이고, 첫째항과 공비가 0이 아니어야 비 an+1/an이 늘 r로 정해집니다. 제n항까지 r을 n − 1번 곱하므로 일반항은 an = arn−1입니다. 0이 아닌 세 수 a, b, c가 이 순서로 등비수열을 이루면 b/a = c/b이므로 b2 = ac입니다. 이때 b를 a와 c의 등비중항이라고 합니다.
  4. 연결an = arn−1은 지수함수 y = a · rx−1에 자연수 x만 넣은 것입니다. 등차수열이 일차함수와 닮았듯 등비수열은 지수함수와 닮았습니다. 그래서 |r| > 1이면 항의 크기가 빠르게 커지고, |r| < 1이면 0에 가까워집니다.
  5. 적용r을 2, 0.5, −2, −0.5, 1로 바꾸어 보세요. 점들의 모양이 어떻게 다른가요? 공비가 음수이면 부호가 어떻게 바뀌나요? k를 바꾸며 양옆 항의 곱이 늘 가운데 항의 제곱과 같은지 확인하세요. a나 r을 0으로 하면 무엇이 깨지나요?
  6. 판단등비중항 b2 = ac에서 b = √(ac)라고만 쓰면 안 됩니다. 4와 9의 등비중항은 6일 수도 −6일 수도 있습니다(4, −6, 9는 공비 −3/2). 또 '두 배씩 커진다'는 공비 2이지 '2씩 커진다'가 아닙니다. 2씩 커지는 것은 공차 2인 등차수열입니다.

3.3.2

곱해 가는 수열의 합은 어떻게 구할까?

등비수열 · S − rS

—

하나씩 더한 Sn
—
rn
—
공식 값
—
  1. 질문1 + 2 + 4 + … + 263처럼 곱해 가는 수열의 합은 등차수열처럼 거꾸로 더해 짝을 지어도 짝의 합이 같지 않습니다. 어떻게 구할까요?
  2. 복원등비수열의 일반항은 an = arn−1입니다. 각 항에 r을 곱하면 바로 다음 항이 됩니다.
  3. 설명Sn = a + ar + … + arn−1의 양변에 r을 곱하면 rSn = ar + ar2 + … + arn입니다. 두 줄은 ar부터 arn−1까지 같은 항을 공유하므로, 빼면 거의 다 지워지고 Sn − rSn = a − arn만 남습니다. 따라서 r ≠ 1이면 Sn = a(1 − rn)/(1 − r) = a(rn − 1)/(r − 1)입니다. r = 1이면 모든 항이 a이므로 Sn = na입니다.
  4. 연결합에서 일반항을 구할 때처럼, 여기서도 두 식을 빼서 같은 부분을 지우는 생각을 씁니다. 이 '어긋나게 빼기'는 여러 가지 수열의 합에서 소거되는 합으로 다시 나옵니다. r > 1이면 a(rn − 1)/(r − 1), |r| < 1이면 a(1 − rn)/(1 − r) 꼴을 쓰면 분모·분자가 양수라 계산이 편합니다.
  5. 적용'다음 단계'를 눌러 rS 줄이 한 칸 밀려 적히고 같은 항끼리 지워지는 것을 보세요. r = 1/2이나 −2에서도 같은 일이 일어나나요? r = 1을 고르면 빼기가 왜 쓸모없어지나요?
  6. 판단공식의 지수를 rn−1로 쓰는 실수가 흔합니다. 빼고 남는 마지막 항은 rS 줄의 끝인 arn입니다. 또 r = 1일 때 공식에 넣으면 0/0이 되므로 따로 Sn = na로 구해야 합니다. 이 공식은 연금이나 대출 상환 계산에도 쓰이지만, 여기서는 원리를 이해하는 데 집중합니다.
