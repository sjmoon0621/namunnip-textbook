등비수열

종이를 반으로 접을 때마다 두께가 두 배가 되듯, 이웃한 두 항의 비가 늘 같은 수열이 있습니다. 이 절에서는 이런 수열의 \(n\)번째 항이 지수함수와 어떻게 닮았는지 보고, 합을 구할 때 등차수열과는 다른 방법, 곧 합에 공비를 곱해 빼는 방법을 익힙니다.

3.3.1

같은 수를 계속 곱하면 항은 어떻게 변할까?

등비수열 · 공비와 등비중항

—

제7항 \(a_7\)
—
\(a_{n+1} \div a_n\)
—
양옆 항의 곱
—

점선 곡선은 \(y = a \cdot r^{x-1}\)입니다. 공비가 음수이면 이런 곡선이 없어 그리지 않습니다.

  1. 질문\(1, 2, 4, 8, \cdots\)처럼 같은 수를 곱해 가는 수열은 등차수열과 달리 점점 빨리 커집니다. 이런 수열의 제\(n\)항은 어떻게 나타낼까요?
  2. 복원지수법칙에서 \(r^m \cdot r^n = r^{m+n}\)입니다. 지수함수 \(y = a^x\)는 \(x\)가 1 늘 때마다 \(y\)가 같은 배수로 바뀝니다.
  3. 설명첫째항부터 차례로 같은 수 \(r\)을 곱해 얻는 수열을 등비수열, \(r\)을 공비라고 합니다. 모든 \(n\)에서 \(a_{n+1} = ra_n\)이고, 첫째항과 공비가 0이 아니어야 비 \(\frac{a_{n+1}}{a_n}\)이 늘 \(r\)로 정해집니다. 제\(n\)항까지 \(r\)을 \(n - 1\)번 곱하므로 일반항은 \(a_n = ar^{n-1}\)입니다. 0이 아닌 세 수 \(a, b, c\)가 이 순서로 등비수열을 이루면 \(\frac{b}{a} = \frac{c}{b}\)이므로 \(b^2 = ac\)입니다. 이때 \(b\)를 \(a\)와 \(c\)의 등비중항이라고 합니다.
  4. 연결\(a_n = ar^{n-1}\)은 지수함수 \(y = a \cdot r^{x-1}\)에 자연수 \(x\)만 넣은 것입니다. 등차수열이 일차함수와 닮았듯 등비수열은 지수함수와 닮았습니다. 그래서 \(|r| > 1\)이면 항의 크기가 빠르게 커지고, \(|r| < 1\)이면 0에 가까워집니다.
  5. 적용\(r\)을 \(2, 0.5, -2, -0.5, 1\)로 바꾸어 보세요. 점들의 모양이 어떻게 다른가요? 공비가 음수이면 부호가 어떻게 바뀌나요? \(k\)를 바꾸며 양옆 항의 곱이 늘 가운데 항의 제곱과 같은지 확인하세요. \(a\)나 \(r\)을 0으로 하면 무엇이 깨지나요?
  6. 판단등비중항 \(b^2 = ac\)에서 \(b = \sqrt{ac}\)라고만 쓰면 안 됩니다. 4와 9의 등비중항은 6일 수도 \(-6\)일 수도 있습니다(\(4, -6, 9\)는 공비 \(-\frac{3}{2}\)). 또 '두 배씩 커진다'는 공비 2이지 '2씩 커진다'가 아닙니다. 2씩 커지는 것은 공차 2인 등차수열입니다.

3.3.2

곱해 가는 수열의 합은 어떻게 구할까?

등비수열 · \(S - rS\)

—

하나씩 더한 \(S_n\)
—
\(r^n\)
—
공식 값
—
  1. 질문\(1 + 2 + 4 + \cdots + 2^{63}\)처럼 곱해 가는 수열의 합은 등차수열처럼 거꾸로 더해 짝을 지어도 짝의 합이 같지 않습니다. 어떻게 구할까요?
  2. 복원등비수열의 일반항은 \(a_n = ar^{n-1}\)입니다. 각 항에 \(r\)을 곱하면 바로 다음 항이 됩니다.
  3. 설명\(S_n = a + ar + \cdots + ar^{n-1}\)의 양변에 \(r\)을 곱하면 \(rS_n = ar + ar^2 + \cdots + ar^n\)입니다. 두 줄은 \(ar\)부터 \(ar^{n-1}\)까지 같은 항을 공유하므로, 빼면 거의 다 지워지고 \(S_n - rS_n = a - ar^n\)만 남습니다. 따라서 \(r \ne 1\)이면 \(S_n = \frac{a(1 - r^n)}{1 - r} = \frac{a(r^n - 1)}{r - 1}\)입니다. \(r = 1\)이면 모든 항이 \(a\)이므로 \(S_n = na\)입니다.
  4. 연결합에서 일반항을 구할 때처럼, 여기서도 두 식을 빼서 같은 부분을 지우는 생각을 씁니다. 이 '어긋나게 빼기'는 여러 가지 수열의 합에서 소거되는 합으로 다시 나옵니다. \(r > 1\)이면 \(\frac{a(r^n - 1)}{r - 1}\), \(|r| < 1\)이면 \(\frac{a(1 - r^n)}{1 - r}\) 꼴을 쓰면 분모·분자가 양수라 계산이 편합니다.
  5. 적용'다음 단계'를 눌러 \(rS\) 줄이 한 칸 밀려 적히고 같은 항끼리 지워지는 것을 보세요. \(r = \frac{1}{2}\)이나 \(-2\)에서도 같은 일이 일어나나요? \(r = 1\)을 고르면 빼기가 왜 쓸모없어지나요?
  6. 판단공식의 지수를 \(r^{n-1}\)로 쓰는 실수가 흔합니다. 빼고 남는 마지막 항은 \(rS\) 줄의 끝인 \(ar^n\)입니다. 또 \(r = 1\)일 때 공식에 넣으면 \(\frac{0}{0}\)이 되므로 따로 \(S_n = na\)로 구해야 합니다. 이 공식은 연금이나 대출 상환 계산에도 쓰이지만, 여기서는 원리를 이해하는 데 집중합니다.
