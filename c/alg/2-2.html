삼각함수와 그래프

중학교의 삼각비는 직각삼각형 안의 예각에서만 쓸 수 있었습니다. 이 절에서는 좌표평면의 동경 위 점으로 사인, 코사인, 탄젠트를 다시 정의해 모든 각으로 넓힙니다. 그러면 각이 실수인 함수가 되고, 단위원을 도는 점을 펼쳐 같은 모양이 끝없이 되풀이되는 그래프를 얻습니다.

2.2.1

\(150^\circ\)나 \(-60^\circ\)의 사인은 무엇일까?

삼각함수의 뜻 · 좌표로 정의
짝 각 Q
\(\theta\)
—
\(\sin \theta = \frac{y}{r}\)
—
\(\cos \theta = \frac{x}{r}\)
—
\(\tan \theta = \frac{y}{x}\)
—

—

점 P를 끌면 각(\(5^\circ\) 단위)과 반지름이 함께 바뀝니다. 초록 선분이 \(y\), 노란 선분이 \(x\)입니다.

  1. 질문삼각비는 직각삼각형의 예각에서만 정했습니다. \(150^\circ\)나 \(-60^\circ, \frac{4\pi}{3}\)처럼 직각삼각형에 들어갈 수 없는 각의 사인은 어떻게 정해야 할까요?
  2. 복원직각삼각형에서 \(\sin\) = 높이/빗변, \(\cos\) = 밑변/빗변, \(\tan\) = 높이/밑변입니다. 일반각 \(\theta\)는 원점에서 \(x\)축의 양의 부분을 시초선으로 하는 동경으로 나타낼 수 있습니다.
  3. 설명원점 O를 중심으로 하는 반지름 \(r\)인 원과 \(\theta\)를 나타내는 동경의 교점을 \(P(x, y)\)라 할 때, \(\sin \theta = \frac{y}{r}\), \(\cos \theta = \frac{x}{r}\), \(\tan \theta = \frac{y}{x}\) \((x \ne 0)\)로 정합니다. \(\theta\)가 예각이면 삼각비와 같습니다. 같은 동경 위의 점은 닮은 삼각형을 만들므로 이 비들은 \(r\)과 관계없이 \(\theta\)만으로 정해집니다. 그래서 \(\theta\)에 하나의 값이 대응하는 함수이고, 이것을 각각 사인함수, 코사인함수, 탄젠트함수라 하며 모두 삼각함수라 합니다. \(x, y\)는 사분면에 따라 부호가 바뀌므로 함숫값의 부호도 바뀝니다. 또 \(x^2 + y^2 = r^2\)에서 \(\sin^2\theta + \cos^2\theta = 1\)이고, \(\tan \theta = \sin \theta / \cos \theta\)입니다. \(r = 1\)인 단위원에서는 \(P = (\cos \theta, \sin \theta)\)입니다.
  4. 연결\(\theta + 2n\pi\)는 같은 동경이라 함숫값도 같습니다. \(-\theta\)의 동경은 \(\theta\)의 동경과 \(x\)축 대칭이므로 \(\sin(-\theta) = -\sin \theta\), \(\cos(-\theta) = \cos \theta\)입니다. \(\pi - \theta\)는 \(y\)축 대칭이라 \(\sin(\pi - \theta) = \sin \theta\), \(\cos(\pi - \theta) = -\cos \theta\)이고, \(\pi + \theta\)는 원점 대칭이라 사인과 코사인의 부호가 모두 바뀌고 \(\tan(\pi + \theta) = \tan \theta\)입니다. 이 성질이 다음 카드에서 그래프의 주기와 대칭으로 보입니다.
  5. 적용\(\theta\)를 고정하고 P를 원 밖으로 끌어 \(r\)만 바꿔 보세요. 세 값이 변하나요? \(\theta\)를 \(0^\circ\)에서 \(355^\circ\)까지 돌리며 사인이 음수인 사분면, 탄젠트가 양수인 사분면을 찾으세요. \(\theta = 90^\circ\)에서 탄젠트는 왜 정의되지 않나요? 짝 각을 \(\pi - \theta\)로 놓고 Q의 사인과 코사인을 P와 비교하세요.
  6. 판단\(\sin \theta\)는 '\(\sin\) 곱하기 \(\theta\)'가 아니라 \(\theta\)에 대응하는 함숫값입니다. \(\sin^2\theta\)는 \((\sin \theta)^2\)이고 \(\sin(\theta^2)\)과 다릅니다. 사인과 코사인의 값은 언제나 \(-1\) 이상 1 이하이지만, 탄젠트는 모든 실수 값을 가질 수 있고 \(x = 0\)인 \(\theta = \frac{\pi}{2} + n\pi\)에서는 정의되지 않습니다.

2.2.2

원을 도는 점의 높이를 옆으로 펼치면 어떤 모양일까?

사인·코사인·탄젠트함수의 그래프 · 주기
x (라디안)
—
\(\sin x\)
—
주기
—

—

x를 0에서 \(2\pi\), 다시 \(-2\pi\)까지 움직이면 굵은 선이 지나온 자취를 그립니다. 탄젠트에서는 원의 오른쪽 접선 위 점 T의 높이가 \(\tan x\)입니다.

  1. 질문관람차가 일정한 빠르기로 돌 때, 한 칸의 높이를 시간에 따라 그리면 어떤 모양일까요? 단위원 위를 도는 점 P의 높이를 각 \(x\)의 함수로 그려 보면 알 수 있습니다.
  2. 복원단위원에서 동경과 원의 교점은 \(P(\cos x, \sin x)\)입니다. 호도법을 쓰면 각 \(x\)는 실수이므로 가로축에 그대로 놓을 수 있습니다. \(x\)와 \(x + 2\pi\)는 같은 동경입니다.
  3. 설명\(y = \sin x\)의 그래프는 P의 높이를 옮긴 것입니다. 정의역은 실수 전체, 치역은 \(-1 \le y \le 1\)이고, 원점에 대하여 대칭입니다. 모든 실수 \(x\)에 대하여 \(f(x + p) = f(x)\)를 만족시키는 0이 아닌 상수 \(p\)가 있으면 \(f\)를 주기함수라 하고, 그런 \(p\) 중 가장 작은 양수를 주기라 합니다. \(\sin(x + 2\pi) = \sin x\)이므로 사인함수의 주기는 \(2\pi\)입니다. \(y = \cos x\)는 P의 가로 위치를 옮긴 것으로, 치역과 주기는 사인과 같고 \(y\)축에 대하여 대칭이며, \(y = \sin x\)를 \(x\)축 방향으로 \(-\frac{\pi}{2}\)만큼 평행이동한 모양입니다. \(y = \tan x\)는 직선 \(x = 1\)과 동경의 연장선이 만나는 점 T의 높이입니다. \(x = \frac{\pi}{2} + n\pi\)에서는 정의되지 않고 그래프가 이 직선들(점근선)에 한없이 가까워집니다. 치역은 실수 전체, 주기는 \(\pi\)이고 원점에 대하여 대칭입니다.
  4. 연결대칭은 앞에서 본 \(\sin(-x) = -\sin x\), \(\cos(-x) = \cos x\)가 그림으로 나타난 것입니다. 주기 \(\pi\)는 \(\tan(\pi + x) = \tan x\)에서 옵니다. 소리, 교류 전기, 밀물과 썰물처럼 되풀이되는 현상을 이 곡선으로 나타냅니다.
  5. 적용사인을 고르고 \(x\)를 0에서 \(2\pi\)까지 움직여 최댓값과 최솟값이 나오는 \(x\)를 찾으세요. 이어서 \(2\pi\)에서 \(-2\pi\)까지 움직이면 같은 모양이 몇 번 되풀이되나요? 코사인으로 바꿔 사인보다 몇만큼 앞서 같은 값을 갖는지 보세요. 탄젠트에서 \(x\)를 \(\frac{\pi}{2}\) 가까이 가져가면 T는 어디로 가나요? 전체 보기를 켜서 \(0 \le x < 2\pi\)에서 \(\sin x = \frac{1}{2}\)인 \(x\)를 두 개 찾아보세요.
  6. 판단모든 주기함수의 주기가 \(2\pi\)인 것은 아닙니다. 탄젠트의 주기는 \(\pi\)입니다. 또 \(2\pi\)도 사인함수를 되풀이시키지만 \(4\pi, 6\pi\)처럼 \(2\pi\)의 배수는 모두 그렇습니다. 주기는 그중 가장 작은 양수입니다. 탄젠트 그래프의 점근선은 그래프의 일부가 아니라 함숫값이 없는 자리입니다.

—

최댓값
—
최솟값
—
주기
—

점선은 기준 곡선 \(y = \sin x\)(또는 \(\cos x\)), 노란 점선은 최댓값과 최솟값입니다.

  1. 질문\(y = 2 \sin 3x + 1\)의 그래프를 점을 찍지 않고 그릴 수 있을까요? 식의 세 수 2, 3, 1이 그래프의 어느 부분을 바꾸는지 알면 됩니다.
  2. 복원\(y = \sin x\)의 치역은 \(-1 \le y \le 1\), 주기는 \(2\pi\)입니다. 그래프를 \(y\)축 방향으로 \(d\)만큼 평행이동하면 식은 \(y = f(x) + d\)가 됩니다.
  3. 설명\(-1 \le \sin bx \le 1\)의 각 변에 \(|a|\)를 곱하고 \(d\)를 더하면, \(y = a \sin bx + d\)의 최댓값은 \(|a| + d\), 최솟값은 \(-|a| + d\)입니다. \(a\)가 음수이면 그래프가 위아래로 뒤집힐 뿐이고, 최댓값과 최솟값은 \(|a|\)로 정해집니다. 또 \(bx\)가 \(2\pi\)만큼 늘어야 같은 값으로 돌아오므로 \(x\)는 \(\frac{2\pi}{b}\)만큼만 늘면 됩니다. 그래서 주기는 \(2\pi/|b|\)입니다. 코사인도 같습니다. \(y = a \tan bx\)의 주기는 \(\pi/|b|\)이고, 최댓값과 최솟값은 없습니다.
  4. 연결\(|a|\)는 소리의 크기, 주기는 소리의 높낮이와 관련이 있습니다. 하루 동안 기온이나 바다의 수위처럼 되풀이되는 자료도 이 꼴의 식으로 근사합니다.
  5. 적용\(b\)만 1, 2, 4로 바꾸며 한 주기의 폭이 어떻게 줄어드는지 보세요. \(a\)를 2와 \(-2\)로 바꿨을 때 최댓값은 같은가요? \(d\)를 움직이면 주기가 바뀌나요? 마지막으로 \(y = 2 \sin 3x + 1\)을 만들어 최댓값, 최솟값, 주기를 읽으세요.
  6. 판단"\(b\)가 커지면 주기도 커진다"는 실수가 흔합니다. \(b\)는 같은 시간에 몇 번 진동하는지를 정하므로 \(b\)가 2배가 되면 주기는 절반이 됩니다. 또 최댓값을 \(a + d\)로 외우면 \(a\)가 음수일 때 틀립니다. 절댓값을 붙여야 합니다.
