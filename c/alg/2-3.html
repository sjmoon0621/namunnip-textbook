사인법칙과 코사인법칙

강 건너 나무까지의 거리나 산을 뚫는 터널의 길이처럼 직접 잴 수 없는 거리가 있습니다. 이런 거리는 잴 수 있는 변과 각으로 삼각형을 만들어 계산합니다. 이 절에서는 삼각형의 변과 각 사이의 관계인 사인법칙과 코사인법칙을 세우고, 이를 이용해 높이를 재지 않고 넓이를 구합니다.

2.3.1

큰 각과 마주 보는 변은 얼마나 길까?

사인법칙 · 외접원

—

a / sin A
—
b / sin B
—
c / sin C
—
외접원의 지름 2R
—

꼭짓점을 끌어 삼각형을 바꿔 보세요. 길이는 눈금 한 칸을 1로 잰 값입니다.

  1. 질문삼각형에서 큰 각과 마주 보는 변이 더 깁니다. 그런데 각이 2배가 되면 변도 2배가 될까요? 변의 길이와 마주 보는 각 사이에 정확한 관계식이 있을까요?
  2. 복원삼각형 ABC에서 ∠A, ∠B, ∠C의 크기를 A, B, C로, 그 대변의 길이를 a, b, c로 씁니다. 한 원에서 같은 호에 대한 원주각은 크기가 같고, 지름에 대한 원주각은 90°입니다.
  3. 설명삼각형 ABC의 외접원의 반지름을 R이라 하면 a/sin A = b/sin B = c/sin C = 2R입니다. 이것을 사인법칙이라 합니다. 이유는 이렇습니다. B를 지나는 지름 BA′을 그으면 ∠BCA′ = 90°이고, A가 예각이면 ∠A′ = A입니다. 직각삼각형 A′BC에서 sin A = a/2R이므로 a = 2R sin A입니다. A가 직각이면 a가 곧 지름이고 sin 90° = 1이며, A가 둔각이면 ∠A′ = 180° − A이고 sin(180° − A) = sin A라서 같은 식이 나옵니다. 그래서 변의 길이는 각 자체가 아니라 그 각의 사인에 비례합니다: a : b : c = sin A : sin B : sin C.
  4. 연결한 변과 두 각을 알면(두 각을 알면 세 번째 각도 압니다) 나머지 변을 구할 수 있습니다. 직접 잴 수 없는 강 건너의 거리나 산의 높이를 측량할 때 쓰는 방법입니다. 두 변과 끼인각이 주어지면 다음 카드의 코사인법칙을 씁니다.
  5. 적용꼭짓점을 끌어 모양을 바꾸며 네 값이 언제나 같은지 보세요. "A = 90°"를 누르면 a와 2R은 어떤 관계인가요? 증명 보기를 켜고 A를 원 위에서 움직이면 ∠A′이 ∠A와 늘 같은지 확인하세요. A가 둔각일 때 A′은 어느 쪽 호에 있나요?
  6. 판단"a : b : c = A : B : C"라고 생각하기 쉽지만 틀립니다. 30°, 60°, 90° 삼각형의 세 변의 비는 1 : √3 : 2이지 1 : 2 : 3이 아닙니다. 또 두 변과 한 대각이 주어질 때 sin B 값만으로 B를 구하면, B와 180° − B 두 경우가 생길 수 있으니 삼각형이 되는지 따로 확인해야 합니다.

2.3.2

직각이 아닌 삼각형에서 피타고라스 정리는 어떻게 고쳐질까?

코사인법칙 · 두 변과 끼인각
b² + c²
—
보정 −2bc cos A
—
a²
—

—

노란 선분은 AH = b cos A입니다. A가 둔각이면 H가 A의 바깥쪽으로 넘어가고 이 값은 음수가 됩니다.

  1. 질문터널 양쪽 끝 B, C는 산에 가려 서로 보이지 않습니다. 산 밖의 한 점 A에서 AB, AC의 길이와 ∠A는 잴 수 있습니다. 이 세 값으로 터널 길이 BC를 구할 수 있을까요?
  2. 복원A = 90°이면 피타고라스 정리로 a2 = b2 + c2입니다. 일반각으로 정한 코사인은 둔각에서 음수입니다.
  3. 설명A를 원점, AB를 x축에 놓으면 C = (b cos A, b sin A), B = (c, 0)입니다. 두 점 사이의 거리를 구하면 a2 = (b cos A − c)2 + (b sin A)2 = b2(sin2A + cos2A) + c2 − 2bc cos A이므로 a2 = b2 + c2 − 2bc cos A입니다. 이것이 코사인법칙이고, b2 = c2 + a2 − 2ca cos B, c2 = a2 + b2 − 2ab cos C도 같습니다. A가 예각이든 둔각이든 이 한 식으로 성립합니다. 식을 고쳐 쓰면 cos A = (b2 + c2 − a2)/2bc이므로, 세 변을 알면 각을 구할 수 있습니다.
  4. 연결피타고라스 정리는 cos 90° = 0인 특별한 경우입니다. 두 변과 끼인각, 또는 세 변이 주어지면 코사인법칙을, 한 변과 두 각이 주어지면 사인법칙을 씁니다. 두 법칙을 함께 쓰면 삼각형의 모든 변과 각을 구할 수 있습니다.
  5. 적용A를 90°에 두면 보정항은 얼마인가요? A를 예각과 둔각으로 바꾸며 a2와 b2 + c2 중 어느 쪽이 큰지 보세요. b = 3, c = 5, A = 120°로 놓으면 a는 얼마인가요? 이것이 아래 문제의 터널입니다.
  6. 판단보정항의 부호를 반대로 쓰는 실수가 흔합니다. 둔각이면 cos A가 음수라서 −2bc cos A는 양수가 되고, 마주 보는 변이 피타고라스보다 길어집니다. 이 식은 A가 b와 c의 끼인각일 때만 씁니다. 끼인각이 아닌 각이 주어지면 다른 변에 대한 식을 골라야 합니다.

2.3.3

높이를 재지 않고 삼각형의 넓이를 구할 수 있을까?

삼각형의 넓이 · 여러 가지 방법

—

½bc sin A
—
헤론 √(s(s−a)(s−b)(s−c))
—
abc / 4R
—

꼭짓점 C를 끌어 보세요. 눈금 한 칸이 길이 1입니다. 세 값은 서로 다른 재료(두 변과 끼인각, 세 변, 세 변과 외접원의 반지름)로 계산한 넓이입니다.

  1. 질문삼각형 모양의 땅에서 높이를 재려면 한 꼭짓점에서 맞은편 변에 정확히 수직인 선을 그어야 합니다. 높이 대신 재기 쉬운 변의 길이와 각으로 넓이를 구할 수 있을까요?
  2. 복원삼각형의 넓이는 ½ × 밑변 × 높이입니다. 사인법칙에서 a = 2R sin A이고, 코사인법칙으로 세 변에서 cos A를 구할 수 있습니다.
  3. 설명C에서 직선 AB에 내린 높이는 h = b sin A입니다. A가 둔각이어도 sin A = sin(180° − A)이므로 같은 식이 됩니다. 따라서 S = ½bc sin A = ½ca sin B = ½ab sin C입니다. 세 변만 알 때는 코사인법칙으로 cos A를 구하고 sin A = √(1 − cos2A)를 넣으면, s = (a + b + c)/2일 때 S = √(s(s − a)(s − b)(s − c))가 됩니다(헤론의 공식). 또 sin A = a/2R을 넣으면 S = abc/4R입니다.
  4. 연결평행사변형은 대각선으로 합동인 삼각형 두 개로 나뉘므로 넓이가 ab sin θ입니다. 측량에서는 땅을 삼각형 여러 개로 나누고 변과 각을 재어 이 식으로 넓이를 더합니다.
  5. 적용C를 밑변과 평행한 점선을 따라 좌우로 끌어 보세요. 넓이가 변하나요? 그때 각 A와 변 b는 어떻게 바뀌나요? C를 A의 왼쪽 바깥으로 끌어 A를 둔각으로 만들어도 세 값이 일치하는지 확인하세요. A가 90°일 때 ½bc sin A는 어떤 익숙한 식이 되나요?
  6. 판단½bc sin A에서 A는 반드시 두 변 b, c 사이의 끼인각이어야 합니다. 끼인각이 아닌 각을 쓰면 틀립니다. 또 같은 두 변이라도 끼인각이 θ일 때와 180° − θ일 때 넓이가 같습니다. 넓이만으로는 예각 삼각형인지 둔각 삼각형인지 알 수 없습니다.
