사인법칙과 코사인법칙

본문

강 건너 나무까지의 거리를 재고 싶은데 강을 건널 수 없다. 이쪽 강가에서 두 지점 사이의 거리와, 각 지점에서 나무를 바라본 각을 잴 수는 있다. 직각이 없는 삼각형에서 이것만으로 거리를 계산할 수 있을까? 피타고라스 정리는 직각이 아닐 때 어떻게 고쳐질까?

먼저 알아야 할 것삼각함수의 뜻(삼각함수와 그래프), 중학교의 원주각의 성질, 두 점 사이의 거리, \(\sin^2\theta + \cos^2\theta = 1\).

2.3.1사인법칙

삼각형 \(ABC\)에서 각 \(A\), \(B\), \(C\)의 대변의 길이를 \(a\), \(b\), \(c\)라 하자. 큰 각과 마주 보는 변이 길다는 것은 중학교에서 배웠다. 그 관계를 정확한 비로 나타낸 것이 사인법칙이다.

꼭짓점 \(C\)에서 변 \(AB\)에 내린 수선의 길이를 \(h\)라 하면, 두 직각삼각형에서 \(h = b\sin A = a\sin B\)이다. 따라서 \(\dfrac{a}{\sin A} = \dfrac{b}{\sin B}\)이다. 같은 방법으로 \(C\)도 포함하면 세 비가 모두 같다. 그 공통의 값은 외접원의 지름 \(2R\)이다.1

정리 2.3.1 사인법칙

삼각형 \(ABC\)의 외접원의 반지름을 \(R\)이라 하면 \[\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R\]

2.3.2코사인법칙

이번에는 두 변과 그 끼인각을 알 때 나머지 변을 구해 보자. 좌표평면에 \(A\)를 원점, \(B\)를 \((c, 0)\)에 두면 \(C\)는 \((b\cos A, b\sin A)\)이다. 두 점 사이의 거리 공식으로 \(a^2 = (b\cos A - c)^2 + (b\sin A)^2\)이고, 전개하면 \(b^2(\cos^2 A + \sin^2 A) - 2bc\cos A + c^2\)이다.

여기서 \(\cos^2 A + \sin^2 A = 1\)이므로 다음 공식을 얻는다.

정리 2.3.2 코사인법칙

\[a^2 = b^2 + c^2 - 2bc\cos A\] 같은 꼴로 \(b^2 = c^2 + a^2 - 2ca\cos B\), \(c^2 = a^2 + b^2 - 2ab\cos C\)이다.

\(A = 90^\circ\)이면 \(\cos A = 0\)이므로 피타고라스 정리 \(a^2 = b^2 + c^2\)가 된다. 즉 코사인법칙은 피타고라스 정리에 '직각에서 벗어난 만큼'의 보정 \(-2bc\cos A\)를 붙인 것이다. 그림 1의 슬라이더로 각 \(A\)를 바꾸어 보면, 예각에서는 \(\cos A > 0\)이라 \(a\)가 짧아지고 둔각에서는 길어진다.

예제 2.3.3

그림 2에서 \(AB = 100\) m, \(\angle A = 70^\circ\), \(\angle B = 50^\circ\)일 때 \(AC\)의 길이를 구하여라. (\(\sin 50^\circ \approx 0.766\), \(\sin 60^\circ \approx 0.866\)) 또 두 변이 5, 4이고 끼인각이 \(60^\circ\)인 삼각형의 나머지 변의 길이를 구하여라.

삼각형의 세 각의 합은 \(180^\circ\)이므로 \(\angle C = 60^\circ\)이다. \(AC\)는 \(\angle B\)의 대변이고 \(AB\)는 \(\angle C\)의 대변이므로, 사인법칙에서 \(\dfrac{AC}{\sin 50^\circ} = \dfrac{100}{\sin 60^\circ}\)이다. 따라서 \(AC = 100 \times \dfrac{0.766}{0.866} \approx 88.5\) m이다.

두 번째 삼각형은 코사인법칙으로 \(a^2 = 5^2 + 4^2 - 2 \times 5 \times 4 \times \cos 60^\circ = 25 + 16 - 20 = 21\)이다. 따라서 나머지 변은 \(\sqrt{21} \approx 4.58\)이다. 그림 1의 처음 모습이 바로 이 삼각형이다.

두 법칙의 쓰임을 정리하면, 한 변과 두 각을 알 때는 사인법칙, 두 변과 끼인각이나 세 변을 알 때는 코사인법칙을 쓴다. 측량, 항해, 위성 위치 계산이 모두 이 두 법칙 위에 서 있다. 아래 탐구 카드에서 변과 각을 직접 바꾸며 두 법칙을 확인해 보자.

  1. 외접원에서 지름 \(BD\)를 그으면 원주각의 성질로 \(\angle A = \angle D\)이고 \(\angle BCD = 90^\circ\)이므로 \(a = 2R\sin A\)이다. 각 \(A\)가 둔각이면 \(\angle D = 180^\circ - A\)가 되지만 \(\sin(180^\circ - A) = \sin A\)이므로 결과는 같다.
마무리

사인법칙은 각 변과 그 대각의 사인의 비가 모두 외접원의 지름과 같다는 것이고, 코사인법칙은 피타고라스 정리에 끼인각에 따른 보정 \(-2bc\cos A\)를 붙인 것이다. 두 법칙으로 직각이 없는 삼각형에서도 변과 각을 계산할 수 있다. 그래서 처음 질문의 나무까지의 거리는 강가의 한 변과 두 각만으로 사인법칙을 써서 구한다.

큰 각과 마주 보는 변은 얼마나 길까?

사인법칙 · 외접원

—

\(a / \sin A\)
—
\(b / \sin B\)
—
\(c / \sin C\)
—
외접원의 지름 2R
—

꼭짓점을 끌어 삼각형을 바꿔 보자. 길이는 눈금 한 칸을 1로 잰 값이다.

  1. 질문삼각형에서 큰 각과 마주 보는 변이 더 길다. 그런데 각이 2배가 되면 변도 2배가 될까? 변의 길이와 마주 보는 각 사이에 정확한 관계식이 있을까?
  2. 복원삼각형 ABC에서 \(\angle A, \angle B, \angle C\)의 크기를 A, B, C로, 그 대변의 길이를 \(a, b, c\)로 쓴다. 그리고 한 원에서 같은 호에 대한 원주각은 크기가 같고, 지름에 대한 원주각은 \(90^\circ\)이다.
  3. 설명삼각형 ABC의 외접원의 반지름을 R이라 하면 \(a/\sin A = b/\sin B = c/\sin C = 2R\)이고, 이것을 사인법칙이라 한다. B를 지나는 지름 \(BA'\)을 그으면 \(\angle BCA' = 90^\circ\)이고, A가 예각이면 \(\angle A' = A\)이다. 그래서 직각삼각형 \(A'BC\)에서 \(\sin A = \frac{a}{2R}\)이므로 \(a = 2R \sin A\)이다. A가 직각이면 \(a\)가 곧 지름이고 \(\sin 90^\circ = 1\)이며, A가 둔각이면 \(\angle A' = 180^\circ - A\)이고 \(\sin(180^\circ - A) = \sin A\)라서 같은 식이 나온다. 즉 변의 길이는 각 자체가 아니라 그 각의 사인에 비례하여, \(a : b : c = \sin A : \sin B : \sin C\)이다.
  4. 연결따라서 한 변과 두 각을 알면(두 각을 알면 세 번째 각도 안다) 나머지 변을 구할 수 있다. 직접 잴 수 없는 강 건너의 거리나 산의 높이를 측량할 때 쓰는 방법이다. 두 변과 끼인각이 주어지면 다음 카드의 코사인법칙을 쓴다.
  5. 적용꼭짓점을 끌어 모양을 바꾸며 네 값이 언제나 같은지 보자. "\(A = 90^\circ\)"를 누르면 \(a\)가 2R과 같아진다. 증명 보기를 켜고 A를 원 위에서 움직이며 \(\angle A'\)이 \(\angle A\)와 늘 같은지 확인하고, A가 둔각일 때 \(A'\)이 어느 쪽 호에 있는지도 보자.
  6. 판단"\(a : b : c = A : B : C\)"라고 생각하기 쉽지만 틀리다. \(30^\circ, 60^\circ, 90^\circ\) 삼각형의 세 변의 비는 \(1 : \sqrt{3} : 2\)이지 1 : 2 : 3이 아니다. 또 두 변과 한 대각이 주어질 때 \(\sin B\) 값만으로 B를 구하면 B와 \(180^\circ - B\) 두 경우가 생길 수 있으므로, 삼각형이 되는지 따로 확인해야 한다.

—
보정 \(-2bc \cos A\)
—

—

—

노란 선분은 \(AH = b \cos A\)이다. A가 둔각이면 H가 A의 바깥쪽으로 넘어가고 이 값은 음수가 된다.

  1. 질문터널 양쪽 끝 B, C는 산에 가려 서로 보이지 않는다. 그런데 산 밖의 한 점 A에서는 AB, AC의 길이와 \(\angle A\)를 잴 수 있다. 이 세 값으로 터널 길이 BC를 구할 수 있을까?
  2. 복원\(A = 90^\circ\)이면 피타고라스 정리로 \(a^2 = b^2 + c^2\)이다. 그리고 일반각으로 정한 코사인은 둔각에서 음수이다.
  3. 설명A를 원점, AB를 \(x\)축에 놓으면 \(C = (b \cos A, b \sin A)\), \(B = (c, 0)\)이다. 두 점 사이의 거리를 구하면 \(a^2 = (b \cos A - c)^2 + (b \sin A)^2 = b^2(\sin^2A + \cos^2A) + c^2 - 2bc \cos A\)이므로 \(a^2 = b^2 + c^2 - 2bc \cos A\)이다. 이것이 코사인법칙이고, \(b^2 = c^2 + a^2 - 2ca \cos B\), \(c^2 = a^2 + b^2 - 2ab \cos C\)도 같은 방법으로 얻는다. 이 식은 A가 예각이든 둔각이든 한 식으로 성립한다. 또 식을 고쳐 쓰면 \(\cos A = \frac{b^2 + c^2 - a^2}{2bc}\)이므로, 세 변을 알면 각을 구할 수 있다.
  4. 연결따라서 피타고라스 정리는 \(\cos 90^\circ = 0\)인 특별한 경우이다. 두 변과 끼인각, 또는 세 변이 주어지면 코사인법칙을 쓰고, 한 변과 두 각이 주어지면 사인법칙을 쓴다. 두 법칙을 함께 쓰면 삼각형의 모든 변과 각을 구할 수 있다.
  5. 적용A를 \(90^\circ\)에 두고 보정항이 얼마인지 보자. 다음에는 A를 예각과 둔각으로 바꾸며 \(a^2\)와 \(b^2 + c^2\) 가운데 어느 쪽이 큰지 비교하고, \(b = 3\), \(c = 5\), \(A = 120^\circ\)로 놓아 \(a\)를 구해 보자. 이것이 아래 문제의 터널이다.
  6. 판단보정항의 부호를 반대로 쓰는 실수가 흔하다. 둔각이면 \(\cos A\)가 음수라서 \(-2bc \cos A\)는 양수가 되고, 마주 보는 변이 피타고라스 정리로 구한 값보다 길어진다. 또 이 식은 A가 \(b\)와 \(c\)의 끼인각일 때만 쓴다. 끼인각이 아닌 각이 주어지면 다른 변에 대한 식을 골라야 한다.

높이를 재지 않고 삼각형의 넓이를 구할 수 있을까?

삼각형의 넓이 · 여러 가지 방법

—

\(\frac{1}{2}bc \sin A\)
—
헤론 \(\sqrt{s(s-a)(s-b)(s-c)}\)
—
abc / 4R
—

꼭짓점 C를 끌어 보자. 눈금 한 칸이 길이 1이고, 세 값은 서로 다른 재료(두 변과 끼인각, 세 변, 세 변과 외접원의 반지름)로 계산한 넓이이다.

  1. 질문삼각형 모양의 땅에서 높이를 재려면 한 꼭짓점에서 맞은편 변에 정확히 수직인 선을 그어야 한다. 높이 대신 재기 쉬운 변의 길이와 각으로 넓이를 구할 수 있을까?
  2. 복원삼각형의 넓이는 \(\frac{1}{2}\) × 밑변 × 높이이다. 그리고 사인법칙에서 \(a = 2R \sin A\)이고, 코사인법칙으로 세 변에서 \(\cos A\)를 구할 수 있다.
  3. 설명C에서 직선 AB에 내린 높이는 \(h = b \sin A\)이고, A가 둔각이어도 \(\sin A = \sin(180^\circ - A)\)이므로 같은 식이 된다. 따라서 \(S = \frac{1}{2}bc \sin A = \frac{1}{2}ca \sin B = \frac{1}{2}ab \sin C\)이다. 세 변만 알 때는 코사인법칙으로 \(\cos A\)를 구하고 \(\sin A = \sqrt{1 - \cos^2A}\)를 넣으면, \(s = \frac{a + b + c}{2}\)일 때 \(S = \sqrt{s(s - a)(s - b)(s - c)}\)가 된다(헤론의 공식). 또 \(\sin A = \frac{a}{2R}\)을 넣으면 \(S = \frac{abc}{4R}\)이다.
  4. 연결평행사변형은 대각선으로 합동인 삼각형 두 개로 나뉘므로 넓이가 \(ab \sin \theta\)이다. 측량에서는 땅을 삼각형 여러 개로 나누고 변과 각을 재어 이 식으로 넓이를 더한다.
  5. 적용C를 밑변과 평행한 점선을 따라 좌우로 끌어 넓이가 변하는지, 그때 각 A와 변 \(b\)가 어떻게 바뀌는지 보자. 다음에는 C를 A의 왼쪽 바깥으로 끌어 A를 둔각으로 만들어도 세 값이 일치하는지 확인하고, A가 \(90^\circ\)일 때 \(\frac{1}{2}bc \sin A\)가 어떤 익숙한 식이 되는지도 보자.
  6. 판단\(\frac{1}{2}bc \sin A\)에서 A는 반드시 두 변 \(b, c\) 사이의 끼인각이어야 하고, 끼인각이 아닌 각을 쓰면 틀린다. 또 같은 두 변이라도 끼인각이 \(\theta\)일 때와 \(180^\circ - \theta\)일 때 넓이가 같다. 그래서 넓이만으로는 예각 삼각형인지 둔각 삼각형인지 알 수 없다.
