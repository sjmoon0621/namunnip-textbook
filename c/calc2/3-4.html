정적분과 급수의 합

미적분Ⅰ에서는 곡선 아래 넓이를 가는 직사각형으로 나누어 정적분을 생각했습니다. 이 절에서는 이 관계를 거꾸로 씁니다. \(\frac{1}{n + 1} + \frac{1}{n + 2} + \cdots + \frac{1}{2n}\)처럼 항이 \(n\)개인 합의 극한을, 직사각형 넓이의 합으로 보고 정적분으로 바꾸어 계산합니다. 공학 도구 대신 그림 속 \(n\)을 늘려 가며 합이 정적분 값에 다가가는 것을 직접 확인합니다. 이런 방법을 구분구적법이라고도 부릅니다.

정적분과 급수의 합

본문

\(\lim_{n \to \infty} \dfrac{1}{n}\left\{\left(\dfrac{1}{n}\right)^2 + \left(\dfrac{2}{n}\right)^2 + \cdots + \left(\dfrac{n}{n}\right)^2\right\}\)을 구하라는 문제가 있다. 제곱수의 합 공식으로 계산할 수도 있지만, 이 식을 가만히 보면 폭이 \(\dfrac{1}{n}\)인 막대 \(n\)개의 넓이를 더한 것처럼 생겼다. 합의 극한을 넓이로, 곧 정적분으로 읽을 수 있다면 계산이 훨씬 간단해지지 않을까?

먼저 알아야 할 것합의 기호 \(\sum\)와 자연수의 거듭제곱의 합(대수), 수열의 극한(수열의 극한의 성질), 정적분과 넓이(미적분Ⅰ).

3.4.1구분구적법

구간 \([a, b]\)를 \(n\)등분하면 소구간의 폭은 \(\Delta x = \dfrac{b - a}{n}\)이고, \(k\)번째 오른쪽 끝은 \(x_k = a + k\Delta x\)이다. 높이 \(f(x_k)\)인 직사각형의 넓이를 모두 더한 \(\sum_{k=1}^{n} f(x_k)\Delta x\)는 곡선 아래 넓이의 근삿값이다. \(n\)을 한없이 키우면 막대가 가늘어지며 근삿값이 넓이에 한없이 가까워진다. 이렇게 넓이를 구하는 방법을 구분구적법이라 한다.

정리 3.4.1 정적분과 급수의 합

함수 \(f(x)\)가 구간 \([a, b]\)에서 연속이면 \[\lim_{n \to \infty} \sum_{k=1}^{n} f\!\left(a + \frac{b - a}{n}k\right)\frac{b - a}{n} = \int_a^b f(x)\,dx\]

그림 1에서 \(n\)을 늘려 보자. \(n = 6\)이면 합은 약 0.42로 \(\dfrac{1}{3}\)보다 크지만, \(n = 60\)이면 약 0.342로 줄어든다. 직사각형이 곡선 위로 삐져나온 조각이 점점 작아지기 때문이다.1

3.4.2합을 정적분으로 읽는 요령

주어진 합에서 \(\dfrac{1}{n}\)을 \(dx\), \(\dfrac{k}{n}\)을 \(x\)로 바꾸어 읽는다. \(\dfrac{k}{n}\)이 \(k = 1\)일 때 \(\dfrac{1}{n} \to 0\), \(k = n\)일 때 1이므로 적분 구간은 \([0, 1]\)이다. \(\dfrac{2k}{n}\)처럼 쓰여 있으면 \(x = \dfrac{2k}{n}\), \(dx = \dfrac{2}{n}\)으로 보아 구간을 \([0, 2]\)로 읽을 수도 있다. 같은 합을 여러 정적분으로 읽을 수 있지만 값은 같다.

3.4.3예제 하나를 끝까지

예제 3.4.2

\(\lim_{n \to \infty} \sum_{k=1}^{n} \dfrac{1}{n + k}\)의 값을 구하여라.

\(\dfrac{1}{n + k} = \dfrac{1}{n} \cdot \dfrac{1}{1 + \frac{k}{n}}\)이다. \(\dfrac{k}{n}\)을 \(x\), \(\dfrac{1}{n}\)을 \(dx\)로 읽으면 구간은 \([0, 1]\)이고 함수는 \(\dfrac{1}{1 + x}\)이다.

따라서 \[\lim_{n \to \infty} \sum_{k=1}^{n} \frac{1}{n + k} = \int_0^1 \frac{1}{1 + x}\,dx = \Big[\ln(1 + x)\Big]_0^1 = \ln 2 \approx 0.693\] 이다. \(n = 100\)으로 직접 더하면 약 0.6907로, \(\ln 2\)에 가깝다. 이 합은 \(\dfrac{1}{n+1} + \cdots + \dfrac{1}{2n}\)으로, 조화급수의 한 토막이다. 이렇게 공식으로 계산하기 어려운 합도 정적분으로 읽으면 쉽게 구할 수 있다.

아래 탐구 카드에서 합의 극한을 넓이로 읽고, 같은 합을 서로 다른 정적분으로 읽어 보자.

  1. 제곱수의 합 공식으로 직접 계산하면 \(\dfrac{1}{n^3} \cdot \dfrac{n(n+1)(2n+1)}{6} = \dfrac{(n+1)(2n+1)}{6n^2}\)이고, \(n \to \infty\)이면 \(\dfrac{2}{6} = \dfrac{1}{3}\)이다. 정적분과 같은 값이다.
마무리

구간을 \(n\)등분한 직사각형 넓이의 합 \(\sum f(x_k)\Delta x\)는 \(n \to \infty\)일 때 정적분 \(\int_a^b f(x)dx\)가 된다. 거꾸로 합의 극한에서 \(\frac{k}{n}\)을 \(x\), \(\frac{1}{n}\)을 \(dx\)로 읽으면 정적분으로 바꾸어 계산할 수 있다. 그래서 처음 질문의 합의 극한은 \(\int_0^1 x^2dx = \frac{1}{3}\)이다.

차이
—

합 \(S_n\)는 주어진 식에 \(k\)를 차례로 넣어 더한 값이고, 직사각형 하나의 넓이가 항 하나이다.

  1. 질문\(\lim_{n\to \infty} \{\frac{1}{n + 1} + \frac{1}{n + 2} + \cdots + \frac{1}{2n}\}\)은 얼마일까? 항은 점점 작아지지만 개수는 늘어난다.
  2. 복원\(f\)가 \([a, b]\)에서 연속이면 구간을 \(n\)등분해 \(\Delta x = \frac{b - a}{n}\), \(x_k = a + k\Delta x\)로 둘 때 \(\lim_{n\to \infty} \sum_{k=1}^n f(x_k)\Delta x = \int_a^b f(x)\,dx\)이다.
  3. 설명합의 각 항을 높이 × 너비로 쪼개 본다. \(\frac{1}{n + k} = (\frac{1}{n}) \cdot \frac{1}{1 + \frac{k}{n}}\)이므로 너비는 \(\frac{1}{n}\), 높이는 \(f(\frac{k}{n}) = \frac{1}{1 + \frac{k}{n}}\)이다. \(\frac{k}{n}\)이 0에서 1까지 움직이므로 \(\lim \sum_{k=1}^n (\frac{1}{n}) f(\frac{k}{n}) = \int_0^1 f(x)\,dx\)를 써서 \(\int_0^1 \frac{1}{1 + x}\,dx = \ln 2\)를 얻는다. 일반적으로 \(\frac{1}{n}\) 또는 \(\frac{b - a}{n}\)은 \(dx\)로, \(\frac{k}{n}\)을 포함한 식은 \(x\)로, \(k = 1\)과 \(k = n\)일 때의 값은 적분 구간의 끝으로 읽는다.
  4. 연결\(k\)를 0부터 \(n - 1\)까지 더하면 직사각형의 왼쪽 끝 높이를 쓰는 셈이다. 두 합의 차는 맨 끝 직사각형 두 개의 차 \(\{f(b) - f(a)\}\Delta x\)뿐이므로 \(n \to \infty\)이면 0이 되어 극한은 같다. 이 생각은 부피, 움직인 거리처럼 잘게 나누어 더하는 모든 계산의 바탕이 된다.
  5. 적용둘째 보기에서 \(n\)을 1, 10, 80으로 바꾸며 \(S_n\)가 \(\ln 2 \approx 0.6931\)로 다가가는지 보고, 오른쪽 끝과 왼쪽 끝 중 어느 합이 더 큰지, 그것이 함수가 감소하는 것과 어떤 관계인지 생각해 보자. 셋째 보기는 너비가 \(\frac{\pi}{n}\)인데, 적분 구간이 어떻게 되는지도 확인해 보자.
  6. 판단각 항이 0으로 간다고 합도 0으로 간다고 생각하면 안 되는데, 항의 개수가 함께 늘어나기 때문이다. 또 너비를 잘못 읽기 쉬워서, \((\frac{\pi}{n}) \sin(\frac{k\pi}{n})\)을 \(\int_0^1 \sin(\pi x)\,dx\)로 읽으면 너비 \(\frac{\pi}{n}\)과 \(\frac{1}{n}\)의 차이인 \(\pi\)배만큼 틀린다.

같은 합을 서로 다른 정적분으로 읽어도 될까?

\(S_n = \sum_{k=1}^n (\frac{2}{n})(1 + \frac{2k}{n})^2\)

주어진 합 \(S_n\)
—
이 해석의 직사각형 넓이 합
—
이 해석의 정적분 값
—
판정
—

직사각형은 고른 정적분의 구간을 \(n\)등분하고 오른쪽 끝의 높이를 쓴 것이다. 첫째 값과 둘째 값이 \(n\)마다 똑같은지 보자.

  1. 질문\(\lim \sum_{k=1}^n (\frac{2}{n})(1 + \frac{2k}{n})^2\)를 정적분으로 바꾸는 방법은 하나뿐일까?
  2. 복원구간 \([a, b]\)를 \(n\)등분하면 \(\Delta x = \frac{b - a}{n}\), \(x_k = a + k\Delta x\)이고 \(\lim \sum f(x_k)\Delta x = \int_a^b f(x)\,dx\)이다.
  3. 설명\(\frac{2}{n}\)을 \(\Delta x\)로 보면 구간 길이는 2이다. 이때 \(x_k = 1 + \frac{2k}{n}\)으로 읽으면 \(x\)는 1에서 3까지 움직이고 높이는 \(x^2\)이므로 \(\int_1^3 x^2\,dx\)이고, \(x_k = \frac{2k}{n}\)으로 읽으면 높이는 \((1 + x)^2\)이고 구간은 [0, 2]이다. 한편 \(\frac{1}{n}\)을 \(\Delta x\)로 보면 남은 2는 높이에 들어가 \(\int_0^1 2(1 + 2x)^2\,dx\)가 된다. 세 해석은 직사각형의 넓이가 하나하나 같으므로 모두 같은 값 \(\frac{26}{3}\)을 주며, 그래서 \(\Delta x\), \(x_k\), \(f\)를 하나의 짝으로 맞추어 읽어야 한다.
  4. 연결세 정적분이 같은 것은 치환적분으로도 확인된다. \(\int_1^3 x^2\,dx\)에서 \(x = 1 + t\)로 놓으면 \(\int_0^2 (1 + t)^2\,dt\), \(x = 1 + 2s\)로 놓으면 \(\int_0^1 2(1 + 2s)^2\,ds\)이다. 즉 급수의 합을 정적분으로 바꾸는 일과 변수를 바꾸는 일은 같은 생각이다.
  5. 적용네 해석을 차례로 골라 첫째 값과 둘째 값을 비교하며 어느 해석에서 두 값이 어긋나는지 보자. 그리고 \(n\)을 60까지 늘리면 \(S_n\)가 어떤 수에 다가가는지 \(\frac{26}{3} \approx 8.667\)과 비교해 보자.
  6. 판단\(\frac{2}{n}\)을 너비로 정했다면 구간 길이는 2이고 \(x_k\)도 \(\frac{2}{n}\) 간격으로 움직여야 한다. 넷째 해석처럼 구간만 [0, 2]로 정하고 높이에서 1을 빠뜨리면 다른 값 \(\frac{8}{3}\)이 되므로, 너비와 구간 길이, \(x_k\)의 간격이 서로 맞는지 꼭 확인해야 한다.
