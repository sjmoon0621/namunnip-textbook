정적분과 급수의 합

미적분Ⅰ에서는 곡선 아래 넓이를 가는 직사각형으로 나누어 정적분을 생각했습니다. 이 절에서는 이 관계를 거꾸로 씁니다. 1/(n + 1) + 1/(n + 2) + ⋯ + 1/(2n)처럼 항이 n개인 합의 극한을, 직사각형 넓이의 합으로 보고 정적분으로 바꾸어 계산합니다. 공학 도구 대신 그림 속 n을 늘려 가며 합이 정적분 값에 다가가는 것을 직접 확인합니다. 이런 방법을 구분구적법이라고도 부릅니다.

3.4.1

항이 n개인 합의 극한을 넓이로 읽을 수 있을까?

차이
—

합 Sn는 주어진 식에 k를 차례로 넣어 더한 값입니다. 직사각형 하나의 넓이가 항 하나입니다.

  1. 질문limn→∞ {1/(n + 1) + 1/(n + 2) + ⋯ + 1/(2n)}은 얼마일까요? 항은 점점 작아지지만 개수는 늘어납니다.
  2. 복원f가 [a, b]에서 연속이면 구간을 n등분해 Δx = (b − a)/n, xk = a + kΔx로 둘 때 limn→∞ ∑k=1n f(xk)Δx = ∫ab f(x) dx입니다.
  3. 설명합의 각 항을 '높이 × 너비'로 쪼개 봅니다. 1/(n + k) = (1/n) · 1/(1 + k/n)이므로 너비는 1/n, 높이는 f(k/n) = 1/(1 + k/n)입니다. k/n이 0에서 1까지 움직이므로 lim ∑k=1n (1/n) f(k/n) = ∫01 f(x) dx를 써서 ∫01 1/(1 + x) dx = ln 2를 얻습니다. 일반적으로 1/n 또는 (b − a)/n은 dx, k/n을 포함한 식은 x, k = 1과 k = n일 때의 값은 적분 구간의 끝으로 읽습니다.
  4. 연결k를 0부터 n − 1까지 더하면 직사각형의 왼쪽 끝 높이를 쓰는 셈입니다. 두 합의 차는 맨 끝 직사각형 두 개의 차 {f(b) − f(a)}Δx뿐이므로 n → ∞이면 0이 되어 극한은 같습니다. 이 생각은 부피, 움직인 거리처럼 '잘게 나누어 더하는' 모든 계산의 바탕이 됩니다.
  5. 적용둘째 보기에서 n을 1, 10, 80으로 바꾸며 Sn가 ln 2 ≈ 0.6931로 다가가는지 보세요. 오른쪽 끝과 왼쪽 끝 중 어느 합이 더 큰가요? 함수가 감소하는 것과 어떤 관계인가요? 셋째 보기는 너비가 π/n입니다. 적분 구간은 어떻게 되나요?
  6. 판단각 항이 0으로 간다고 합도 0으로 간다고 생각하면 안 됩니다. 항의 개수가 함께 늘어나기 때문입니다. 또 너비를 잘못 읽기 쉽습니다. (π/n) sin(kπ/n)을 ∫01 sin(πx) dx로 읽으면 너비 π/n과 1/n의 차이인 π배만큼 틀립니다.

3.4.2

같은 합을 서로 다른 정적분으로 읽어도 될까?

정적분과 급수의 합 · 비교

Sn = ∑k=1n (2/n)(1 + 2k/n)2

주어진 합 Sn
—
이 해석의 직사각형 넓이 합
—
이 해석의 정적분 값
—
판정
—

직사각형은 고른 정적분의 구간을 n등분하고 오른쪽 끝의 높이를 쓴 것입니다. 첫째 값과 둘째 값이 n마다 똑같은지 보세요.

  1. 질문lim ∑k=1n (2/n)(1 + 2k/n)2를 정적분으로 바꾸는 방법은 하나뿐일까요?
  2. 복원구간 [a, b]를 n등분하면 Δx = (b − a)/n, xk = a + kΔx이고 lim ∑ f(xk)Δx = ∫ab f(x) dx입니다.
  3. 설명2/n을 Δx로 보면 구간 길이는 2입니다. xk = 1 + 2k/n으로 읽으면 x는 1에서 3까지 움직이고 높이는 x2이므로 ∫13 x2 dx입니다. xk = 2k/n으로 읽으면 높이는 (1 + x)2이고 구간은 [0, 2]입니다. 1/n을 Δx로 보면 남은 2는 높이에 들어가 ∫01 2(1 + 2x)2 dx가 됩니다. 세 해석은 직사각형의 넓이가 하나하나 같으므로 모두 같은 값 26/3을 줍니다. 핵심은 Δx, xk, f를 하나의 짝으로 맞추어 읽는 것입니다.
  4. 연결세 정적분이 같은 것은 치환적분으로도 확인됩니다. ∫13 x2 dx에서 x = 1 + t로 놓으면 ∫02 (1 + t)2 dt, x = 1 + 2s로 놓으면 ∫01 2(1 + 2s)2 ds입니다. 급수의 합을 정적분으로 바꾸는 일과 변수를 바꾸는 일은 같은 생각입니다.
  5. 적용네 해석을 차례로 골라 첫째 값과 둘째 값을 비교하세요. 어느 해석에서 두 값이 어긋나나요? n을 60까지 늘리면 Sn는 어떤 수에 다가가나요? 26/3 ≈ 8.667과 비교해 보세요.
  6. 판단2/n을 너비로 정했다면 구간 길이는 2이고 xk도 2/n 간격으로 움직여야 합니다. 넷째 해석처럼 구간만 [0, 2]로 정하고 높이에서 1을 빠뜨리면 다른 값 8/3이 됩니다. 너비와 구간 길이, xk의 간격이 서로 맞는지 꼭 확인하세요.
