몫의 미분법

곱의 도함수가 두 도함수의 곱이 아니었듯이, 몫의 도함수도 두 도함수의 몫이 아닙니다. 이 절에서는 먼저 역수 1/g(x)를 도함수의 정의로 미분하고, 곱의 미분법과 합쳐 몫의 미분법을 얻습니다. 이것으로 유리함수와 x−n, 그리고 tan x를 비롯해 새로 정의하는 sec x, csc x, cot x를 미분합니다.

접선의 기울기는 아주 작은 h(0.00001)로 잰 할선의 기울기입니다. 점 P는 그림을 가로로 끌어도 움직입니다.

  1. 질문곱의 미분법은 (fg)′ = f′g + fg′이었습니다. 그러면 몫 f/g의 도함수는 간단히 f′/g′일까요?
  2. 복원도함수의 정의 f′(x) = limh→0 {f(x + h) − f(x)}/h, 곱의 미분법, 그리고 미분가능한 함수는 연속이라는 사실을 씁니다.
  3. 설명먼저 역수입니다. {1/g(x + h) − 1/g(x)}/h = −{g(x + h) − g(x)}/h · 1/{g(x + h)g(x)}이고, h → 0이면 (1/g)′ = −g′/g2입니다. f/g = f · (1/g)에 곱의 미분법을 쓰면 f′/g − fg′/g2, 곧 (f/g)′ = (f′g − fg′)/g2입니다(g(x) ≠ 0). 특히 n이 자연수일 때 (x−n)′ = (1/xn)′ = −nxn−1/x2n = −nx−n−1이므로, 거듭제곱 공식 (xk)′ = kxk−1이 정수 지수 전체로 넓어집니다.
  4. 연결tan x = sin x/cos x처럼 몫으로 정의된 함수는 모두 이 공식으로 미분합니다. 분자가 0이 되는 곳에서 접선이 수평이므로, 유리함수의 극대·극소를 찾을 때도 씁니다.
  5. 적용세 함수에서 점 P를 옮기며 접선의 기울기와 아래 두 값을 비교하세요. 어느 쪽이 늘 같나요? 첫 번째 함수에서 접선이 수평인 x를 찾고, 그때 분자 f′g − fg′의 값을 확인하세요. 세 번째 함수에서는 접선이 수평인 곳이 어디인가요?
  6. 판단분자의 순서가 중요합니다. 곱의 미분법은 두 항을 더하므로 순서가 상관없지만, 몫은 빼므로 fg′ − f′g로 쓰면 부호가 반대가 됩니다. 분모는 g가 아니라 g2입니다. 또 g(x) = 0인 곳에서는 함수 자체가 정의되지 않으므로 공식도 쓸 수 없습니다.

점선은 점근선입니다. 함수가 정의되지 않는 x에서는 점을 그리지 않습니다.

  1. 질문y = tan x는 한 주기 안에서 늘 증가합니다. 가장 완만한 곳에서도 기울기가 1보다 작아지지 않는 것처럼 보이는데, 정말 그럴까요? 기울기를 식으로 나타낼 수 있을까요?
  2. 복원몫의 미분법 (f/g)′ = (f′g − fg′)/g2, (sin x)′ = cos x, (cos x)′ = −sin x를 씁니다. 새 함수도 정의합니다. 시컨트 sec x = 1/cos x, 코시컨트 csc x = 1/sin x, 코탄젠트 cot x = cos x/sin x입니다.
  3. 설명(tan x)′ = {cos x · cos x − sin x · (−sin x)}/cos2 x = 1/cos2 x이므로 (tan x)′ = sec2 x = 1 + tan2 x입니다. 이 값은 언제나 1 이상이고, tan x = 0인 곳에서 가장 작은 1입니다. 같은 방법으로 (cot x)′ = −csc2 x, (sec x)′ = sec x tan x, (csc x)′ = −csc x cot x입니다. 예를 들어 (sec x)′ = (1/cos x)′ = sin x/cos2 x = (1/cos x)(sin x/cos x)입니다.
  4. 연결sec2 x = 1 + tan2 x는 sin2 x + cos2 x = 1을 cos2 x로 나눈 식입니다. 적분에서는 거꾸로 ∫sec2 x dx = tan x + C로 씁니다.
  5. 적용tan x에서 P를 옮기며 접선의 기울기가 가장 작아지는 x를 찾으세요. 그때 기울기는 얼마인가요? cot x의 기울기는 어떤 범위에 있나요? sec x에서 접선이 수평인 곳은 어디이고, 그 이유를 공식 sec x tan x로 설명해 보세요.
  6. 판단sec x를 cos x의 역함수 cos−1 x와 혼동하면 안 됩니다. sec x는 역수 1/cos x입니다. 또 csc는 sin의 역수, sec는 cos의 역수로 이름과 짝이 엇갈리니 주의합니다. 네 공식 모두 분모가 0이 아닌 곳, 곧 함수가 정의되는 곳에서만 성립합니다.
