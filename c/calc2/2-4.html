몫의 미분법

곱의 도함수가 두 도함수의 곱이 아니었듯이, 몫의 도함수도 두 도함수의 몫이 아닙니다. 이 절에서는 먼저 역수 \(\frac{1}{g(x)}\)를 도함수의 정의로 미분하고, 곱의 미분법과 합쳐 몫의 미분법을 얻습니다. 이것으로 유리함수와 \(x^{-n}\), 그리고 \(\tan x\)를 비롯해 새로 정의하는 \(\sec x\), \(\csc x\), \(\cot x\)를 미분합니다.

몫 \(\frac{f}{g}\)의 도함수는 \(\frac{f'}{g'}\)일까?

몫의 미분법 · 비교
\(f(x)\)
—
\(f'(x)\)
—
\(g(x)\)
—
\(g'(x)\)
—
접선의 기울기
—
\(\frac{f'}{g'}\)
—
\(\frac{f'g - fg'}{g^2}\)
—

접선의 기울기는 아주 작은 \(h(0.00001)\)로 잰 할선의 기울기입니다. 점 \(P\)는 그림을 가로로 끌어도 움직입니다.

  1. 질문곱의 미분법은 \((fg)' = f'g + fg'\)이었습니다. 그러면 몫 \(\frac{f}{g}\)의 도함수는 간단히 \(\frac{f'}{g'}\)일까요?
  2. 복원도함수의 정의 \(f'(x) = \lim_{h\to 0} \frac{f(x + h) - f(x)}{h}\), 곱의 미분법, 그리고 미분가능한 함수는 연속이라는 사실을 씁니다.
  3. 설명먼저 역수입니다. \(\frac{\frac{1}{g(x + h)} - \frac{1}{g(x)}}{h} = -\frac{g(x + h) - g(x)}{h} \cdot \frac{1}{g(x + h)g(x)}\)이고, \(h \to 0\)이면 \((\frac{1}{g})' = -\frac{g'}{g^2}\)입니다. \(\frac{f}{g} = f \cdot (\frac{1}{g})\)에 곱의 미분법을 쓰면 \(\frac{f'}{g} - \frac{fg'}{g^2}\), 곧 \((\frac{f}{g})' = \frac{f'g - fg'}{g^2}\)입니다\((g(x) \ne 0)\). 특히 \(n\)이 자연수일 때 \((x^{-n})' = (\frac{1}{x^n})' = -\frac{nx^{n-1}}{x^{2n}} = -nx^{-n-1}\)이므로, 거듭제곱 공식 \((x^k)' = kx^{k-1}\)이 정수 지수 전체로 넓어집니다.
  4. 연결\(\tan x = \frac{\sin x}{\cos x}\)처럼 몫으로 정의된 함수는 모두 이 공식으로 미분합니다. 분자가 0이 되는 곳에서 접선이 수평이므로, 유리함수의 극대·극소를 찾을 때도 씁니다.
  5. 적용세 함수에서 점 \(P\)를 옮기며 접선의 기울기와 아래 두 값을 비교하세요. 어느 쪽이 늘 같나요? 첫 번째 함수에서 접선이 수평인 \(x\)를 찾고, 그때 분자 \(f'g - fg'\)의 값을 확인하세요. 세 번째 함수에서는 접선이 수평인 곳이 어디인가요?
  6. 판단분자의 순서가 중요합니다. 곱의 미분법은 두 항을 더하므로 순서가 상관없지만, 몫은 빼므로 \(fg' - f'g\)로 쓰면 부호가 반대가 됩니다. 분모는 \(g\)가 아니라 \(g^2\)입니다. 또 \(g(x) = 0\)인 곳에서는 함수 자체가 정의되지 않으므로 공식도 쓸 수 없습니다.

2.4.2

\(\tan x\)의 접선의 기울기는 왜 1보다 작아지지 않을까?

삼각함수의 도함수 · 몫의 미분법
높이 \(f(x)\)
—
접선의 기울기
—
\(\sec^2x\)
—

—

점선은 점근선입니다. 함수가 정의되지 않는 \(x\)에서는 점을 그리지 않습니다.

  1. 질문\(y = \tan x\)는 한 주기 안에서 늘 증가합니다. 가장 완만한 곳에서도 기울기가 1보다 작아지지 않는 것처럼 보이는데, 정말 그럴까요? 기울기를 식으로 나타낼 수 있을까요?
  2. 복원몫의 미분법 \((\frac{f}{g})' = \frac{f'g - fg'}{g^2}\), \((\sin x)' = \cos x\), \((\cos x)' = -\sin x\)를 씁니다. 새 함수도 정의합니다. 시컨트 \(\sec x = \frac{1}{\cos x}\), 코시컨트 \(\csc x = \frac{1}{\sin x}\), 코탄젠트 \(\cot x = \frac{\cos x}{\sin x}\)입니다.
  3. 설명\((\tan x)' = \frac{\cos x \cdot \cos x - \sin x \cdot (-\sin x)}{\cos^2 x} = \frac{1}{\cos^2 x}\)이므로 \((\tan x)' = \sec^2 x = 1 + \tan^2 x\)입니다. 이 값은 언제나 1 이상이고, \(\tan x = 0\)인 곳에서 가장 작은 1입니다. 같은 방법으로 \((\cot x)' = -\csc^2 x\), \((\sec x)' = \sec x \tan x\), \((\csc x)' = -\csc x \cot x\)입니다. 예를 들어 \((\sec x)' = (\frac{1}{\cos x})' = \frac{\sin x}{\cos^2 x} = (\frac{1}{\cos x})(\frac{\sin x}{\cos x})\)입니다.
  4. 연결\(\sec^2 x = 1 + \tan^2 x\)는 \(\sin^2 x + \cos^2 x = 1\)을 \(\cos^2 x\)로 나눈 식입니다. 적분에서는 거꾸로 \(\int \sec^2 x\,dx = \tan x + C\)로 씁니다.
  5. 적용\(\tan x\)에서 \(P\)를 옮기며 접선의 기울기가 가장 작아지는 \(x\)를 찾으세요. 그때 기울기는 얼마인가요? \(\cot x\)의 기울기는 어떤 범위에 있나요? \(\sec x\)에서 접선이 수평인 곳은 어디이고, 그 이유를 공식 \(\sec x \tan x\)로 설명해 보세요.
  6. 판단\(\sec x\)를 \(\cos x\)의 역함수 \(\cos^{-1} x\)와 혼동하면 안 됩니다. \(\sec x\)는 역수 \(\frac{1}{\cos x}\)입니다. 또 \(\csc\)는 \(\sin\)의 역수, \(\sec\)는 \(\cos\)의 역수로 이름과 짝이 엇갈리니 주의합니다. 네 공식 모두 분모가 0이 아닌 곳, 곧 함수가 정의되는 곳에서만 성립합니다.
