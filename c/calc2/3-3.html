부분적분법

\(x e^x\), \(x \sin x\), \(\ln x\)처럼 서로 다른 종류의 함수가 곱해진 꼴은 치환으로도 잘 풀리지 않습니다. 이 절에서는 곱의 미분법을 거꾸로 읽은 부분적분법을 배웁니다. 공식이 넓이로는 무엇을 뜻하는지 그림으로 확인하고, 곱한 두 함수 중 어느 쪽을 미분하고 어느 쪽을 적분해야 새 적분이 쉬워지는지 직접 바꾸어 보며 판단합니다.

3.3.1

넓이 두 조각을 합치면 왜 직사각형이 될까?

부분적분법 · 조작

—

초록 \(\int u\,dv\)
—
파랑 \(\int v\,du\)
—
두 넓이의 합
—
\([uv] = u(b)v(b) - u(a)v(a)\)
—

세 보기 모두 아래끝에서 \(u = 0\)이라 빼는 직사각형 \(u(a)v(a)\)는 넓이가 0입니다. 점선 직사각형이 \(u(b)v(b)\)입니다.

  1. 질문\(\int_1^b \ln x\,dx\)는 앞 절의 방법으로는 구하기 어렵습니다. 넓이를 다른 방향에서 보면 쉬운 넓이로 바꿀 수 있을까요?
  2. 복원곱의 미분법은 \(\{u(x)v(x)\}' = u'(x)v(x) + u(x)v'(x)\)입니다. 또 \(\int_a^b F'(x)\,dx = F(b) - F(a)\)입니다.
  3. 설명곱의 미분법의 양변을 \(a\)부터 \(b\)까지 적분하면 \([uv]_a^b = \int_a^b u'v\,dx + \int_a^b uv'\,dx\)입니다. 정리하면 \(\int_a^b u(x)v'(x)\,dx = [u(x)v(x)]_a^b - \int_a^b u'(x)v(x)\,dx\)이고, 이것이 부분적분법입니다. 줄여서 \(\int u\,dv = uv - \int v\,du\)로 씁니다. 그림에서 초록은 곡선 아래, 파랑은 곡선 왼쪽 넓이이고 둘을 합치면 직사각형 \(u(b)v(b)\)가 됩니다(곡선이 오른쪽 위로 올라가는 경우). 예를 들어 \(\ln x\)는 \(u = \ln x\), \(v = x\)로 보면 \(\int v\,du = \int x \cdot (\frac{1}{x})\,dx = b - 1\)이 쉬워져서 \(\int_1^b \ln x\,dx = b \ln b - b + 1\)입니다.
  4. 연결부정적분으로 쓰면 \(\int \ln x\,dx = x \ln x - x + C\)입니다. 치환적분법이 합성함수의 미분법을 뒤집은 것이라면, 부분적분법은 곱의 미분법을 뒤집은 것입니다. 첫째 보기의 곡선 \(u = \ln v\)는 \(v = e^u\)와 같으므로, 파랑 넓이는 지수함수의 넓이로도 읽을 수 있습니다.
  5. 적용\(b\)를 움직이며 두 넓이의 합이 늘 \([uv]\)와 같은지 확인하세요. 첫째 보기에서 \(b = e\)(약 2.72)이면 초록 넓이는 얼마인가요? 둘째 보기에서 \(b = 1\)이면 \(\int_0^1 x e^x\,dx\)는 얼마인가요?
  6. 판단\(\int u\,dv\)를 \(\int u\,dx \times \int v'\,dx\)처럼 따로 적분해 곱하는 실수가 있습니다. 곱의 적분은 적분의 곱이 아닙니다. 또 \([uv]\)를 계산할 때 아래끝의 값 \(u(a)v(a)\)를 빼는 것을 잊기 쉽습니다. 여기 보기들은 그 값이 0이지만 일반적으로는 0이 아닙니다.

3.3.2

어느 쪽을 미분하고 어느 쪽을 적분해야 할까?

부분적분법 · 비교

—

원래 적분 \(\int u v'\,dx\)
—
\([uv]\)
—
새 적분 \(\int u'v\,dx\)
—
\([uv]\) − 새 적분
—

\(A\)와 \(B\) 모두 공식은 성립합니다. 새 적분의 피적분함수(파랑)가 원래보다 쉬운 함수인지 보세요.

  1. 질문\(\int x e^x\,dx\)에서 \(u = x\), \(v' = e^x\)로 고를 수도 있고 \(u = e^x\), \(v' = x\)로 고를 수도 있습니다. 두 방법은 무엇이 다를까요?
  2. 복원부분적분법은 \(\int u(x)v'(x)\,dx = u(x)v(x) - \int u'(x)v(x)\,dx\)입니다. \(u\)는 미분하고 \(v'\)은 적분해서 쓰입니다.
  3. 설명공식은 어떻게 골라도 성립합니다. 다만 목적은 남는 적분 \(\int u'v\,dx\)를 원래보다 쉽게 만드는 것입니다. 그래서 \(u\)로는 미분하면 간단해지는 함수(다항식, 로그함수)를, \(v'\)로는 적분해도 복잡해지지 않는 함수(지수함수, 삼각함수)를 고릅니다. \(x e^x\)에서 \(u = x\)로 고르면 새 적분이 \(\int e^x\,dx\)가 되어 \(\int x e^x\,dx = (x - 1)e^x + C\)입니다. 반대로 고르면 새 적분에 \(x^2\)이 생겨 더 어려워집니다. 로그함수는 적분하기 어렵고 미분하면 \(\frac{1}{x}\)로 간단해지므로 거의 늘 \(u\)로 둡니다.
  4. 연결\(x^2e^x\)처럼 다항식의 차수가 높으면 부분적분을 차수만큼 되풀이합니다. \(\int e^x \sin x\,dx\)는 두 번 부분적분하면 원래 적분이 다시 나타나므로, 그것을 \(I\)로 놓고 방정식 \(2I = e^x(\sin x - \cos x)\)를 풀어 \(I\)를 구합니다.
  5. 적용보기마다 \(A\)와 \(B\)를 바꾸어 보세요. 넷째 값이 늘 첫째 값과 같은지 확인하고, 파랑 곡선이 어느 쪽에서 더 단순한지 비교하세요. \(x \sin x\)에서 \(b\)를 \(\pi\)(약 3.14)로 놓으면 원래 적분은 얼마인가요?
  6. 판단"\(u\)는 늘 앞에 쓴 인수"처럼 순서로 고르면 안 됩니다. \(x \ln x\)에서 \(u = x\)로 고르면 \(v\)를 구하려고 \(\int \ln x\,dx\)부터 풀어야 하고, 새 적분에 \(\ln x\)가 그대로 남습니다. 미분과 적분 중 어느 쪽이 함수를 더 간단하게 만드는지로 고릅니다.
