부분적분법

\(x e^x\), \(x \sin x\), \(\ln x\)처럼 서로 다른 종류의 함수가 곱해진 꼴은 치환으로도 잘 풀리지 않습니다. 이 절에서는 곱의 미분법을 거꾸로 읽은 부분적분법을 배웁니다. 공식이 넓이로는 무엇을 뜻하는지 그림으로 확인하고, 곱한 두 함수 중 어느 쪽을 미분하고 어느 쪽을 적분해야 새 적분이 쉬워지는지 직접 바꾸어 보며 판단합니다.

본문

\(\int \ln x\,dx\)나 \(\int xe^x\,dx\)는 치환으로도 풀리지 않는다. 곱으로 된 함수를 적분하는 방법은 없을까? 곱의 미분법을 거꾸로 쓰면 될 것 같다. 그 결과를 그래프로 보면, 곡선 아래 넓이와 곡선 왼쪽 넓이를 합친 것이 직사각형이 된다. 왜 그럴까?

먼저 알아야 할 것곱의 미분법(미적분Ⅰ), 여러 가지 함수의 적분(여러 가지 함수의 적분), 치환적분법(치환적분법).

3.3.1부분적분법

곱의 미분법 \((fg)' = f'g + fg'\)의 양변을 적분하면 \(fg = \int f'g\,dx + \int fg'\,dx\)이다. 이를 정리하면 곱의 적분 하나를 다른 곱의 적분으로 바꾸는 공식을 얻는다.

정리 3.3.1 부분적분법

\[\int f(x)g'(x)\,dx = f(x)g(x) - \int f'(x)g(x)\,dx\] \[\int_a^b f(x)g'(x)\,dx = \Big[f(x)g(x)\Big]_a^b - \int_a^b f'(x)g(x)\,dx\]

그림 1은 이 공식의 넓이 그림이다. \(u = x\), \(v = \ln x\)로 보면 \(\int_1^b v\,du\)가 곡선 아래 넓이, \(\int_0^{\ln b} u\,dv\)가 곡선 왼쪽 넓이이고, 둘의 합이 직사각형 넓이 \(uv\)에서 원점 쪽 작은 직사각형 넓이를 뺀 것과 같다. 여기서는 작은 직사각형의 넓이가 \(1 \times 0 = 0\)이므로 합이 바로 \(b\ln b\)이다. 슬라이더로 \(b\)를 바꾸어도 두 넓이의 합은 늘 직사각형이다.1

3.3.2어느 쪽을 미분할까

부분적분이 쓸모 있으려면 오른쪽의 \(\int f'g\,dx\)가 처음보다 쉬워야 한다. 미분하면 간단해지는 함수를 \(f\)로, 적분하기 쉬운 함수를 \(g'\)으로 고른다. 대개 로그함수, 다항함수, 삼각함수, 지수함수의 순서로 앞의 것을 \(f\)로 잡으면 잘 풀린다.

3.3.3예제 하나를 끝까지

예제 3.3.2

(1) \(\int_0^1 xe^x\,dx\)와 (2) \(\int_1^e \ln x\,dx\)의 값을 구하여라.

(1) \(f = x\), \(g' = e^x\)로 놓으면 \(f' = 1\), \(g = e^x\)이다. \(\int_0^1 xe^x\,dx = \Big[xe^x\Big]_0^1 - \int_0^1 e^x\,dx = e - (e - 1) = 1\)이다. 거꾸로 \(f = e^x\), \(g' = x\)로 잡으면 \(\int \dfrac{x^2}{2}e^x\,dx\)가 남아 오히려 복잡해진다.

(2) \(\ln x = \ln x \cdot 1\)로 보고 \(f = \ln x\), \(g' = 1\)로 놓으면 \(f' = \dfrac{1}{x}\), \(g = x\)이다. \(\int_1^e \ln x\,dx = \Big[x\ln x\Big]_1^e - \int_1^e 1\,dx = e - (e - 1) = 1\)이다. 그림 1에서 \(b = e\)로 맞추면 초록 넓이가 1이고, 주황 넓이 \(e - 1\)과 합쳐 \(e \times 1 = e\)가 된다.

아래 탐구 카드에서 부분적분의 넓이 그림과, 어느 쪽을 미분할지 고르는 요령을 직접 확인해 보자.

  1. 일반적으로 증가함수 \(y = f(x)\)와 그 역함수에 대하여 \(\int_a^b f(x)\,dx + \int_{f(a)}^{f(b)} f^{-1}(y)\,dy = bf(b) - af(a)\)가 성립한다. 부분적분을 넓이로 본 것이다.
마무리

곱의 미분법을 적분하면 \(\int fg'dx = fg - \int f'g\,dx\)인 부분적분법을 얻으며, 미분하면 간단해지는 쪽을 \(f\)로 고른다. 그래프로 보면 곡선 아래 넓이와 곡선 왼쪽 넓이의 합이 직사각형 넓이가 되는 관계이다. 그래서 처음 질문의 두 넓이 조각은 \(\int v\,du + \int u\,dv = uv\)이기 때문에 합쳐서 직사각형이 된다.

탐구 1

넓이 두 조각을 합치면 왜 직사각형이 될까?

부분적분법 · 조작

—

초록 \(\int u\,dv\)
—
파랑 \(\int v\,du\)
—
두 넓이의 합
—
\([uv] = u(b)v(b) - u(a)v(a)\)
—

세 보기 모두 아래끝에서 \(u = 0\)이라 빼는 직사각형 \(u(a)v(a)\)는 넓이가 0이다. 점선 직사각형이 \(u(b)v(b)\)이다.

  1. 질문\(\int_1^b \ln x\,dx\)는 앞 절의 방법으로는 구하기 어렵다. 넓이를 다른 방향에서 보면 쉬운 넓이로 바꿀 수 있을까?
  2. 복원곱의 미분법은 \(\{u(x)v(x)\}' = u'(x)v(x) + u(x)v'(x)\)이다. 또 \(\int_a^b F'(x)\,dx = F(b) - F(a)\)이다.
  3. 설명곱의 미분법의 양변을 \(a\)부터 \(b\)까지 적분하면 \([uv]_a^b = \int_a^b u'v\,dx + \int_a^b uv'\,dx\)이고, 정리하면 \(\int_a^b u(x)v'(x)\,dx = [u(x)v(x)]_a^b - \int_a^b u'(x)v(x)\,dx\)인데, 이것이 부분적분법이며 줄여서 \(\int u\,dv = uv - \int v\,du\)로 쓴다. 그림에서 초록은 곡선 아래, 파랑은 곡선 왼쪽 넓이이고, 곡선이 오른쪽 위로 올라가는 경우 둘을 합치면 직사각형 \(u(b)v(b)\)가 된다. 예를 들어 \(\ln x\)는 \(u = \ln x\), \(v = x\)로 보면 \(\int v\,du = \int x \cdot (\frac{1}{x})\,dx = b - 1\)이 쉬워져서 \(\int_1^b \ln x\,dx = b \ln b - b + 1\)이다.
  4. 연결부정적분으로 쓰면 \(\int \ln x\,dx = x \ln x - x + C\)이다. 치환적분법이 합성함수의 미분법을 뒤집은 것이라면, 부분적분법은 곱의 미분법을 뒤집은 것이다. 또 첫째 보기의 곡선 \(u = \ln v\)는 \(v = e^u\)와 같으므로, 파랑 넓이는 지수함수의 넓이로도 읽을 수 있다.
  5. 적용\(b\)를 움직이며 두 넓이의 합이 늘 \([uv]\)와 같은지 확인해 보자. 그리고 첫째 보기에서 \(b = e\)(약 2.72)이면 초록 넓이가 얼마인지, 둘째 보기에서 \(b = 1\)이면 \(\int_0^1 x e^x\,dx\)가 얼마인지 구해 보자.
  6. 판단\(\int u\,dv\)를 \(\int u\,dx \times \int v'\,dx\)처럼 따로 적분해 곱하는 실수가 있는데, 곱의 적분은 적분의 곱이 아니다. 또 \([uv]\)를 계산할 때 아래끝의 값 \(u(a)v(a)\)를 빼는 것을 잊기 쉽다. 여기 보기들은 그 값이 0이지만 일반적으로는 0이 아니다.

탐구 2

어느 쪽을 미분하고 어느 쪽을 적분해야 할까?

부분적분법 · 비교

—

원래 적분 \(\int u v'\,dx\)
—
\([uv]\)
—
새 적분 \(\int u'v\,dx\)
—
\([uv]\) − 새 적분
—

\(A\)와 \(B\) 모두 공식은 성립한다. 새 적분의 피적분함수(파랑)가 원래보다 쉬운 함수인지 보자.

  1. 질문\(\int x e^x\,dx\)에서 \(u = x\), \(v' = e^x\)로 고를 수도 있고 \(u = e^x\), \(v' = x\)로 고를 수도 있다. 두 방법은 무엇이 다를까?
  2. 복원부분적분법은 \(\int u(x)v'(x)\,dx = u(x)v(x) - \int u'(x)v(x)\,dx\)이며, \(u\)는 미분하고 \(v'\)은 적분해서 쓰인다.
  3. 설명공식은 어떻게 골라도 성립하지만, 목적은 남는 적분 \(\int u'v\,dx\)를 원래보다 쉽게 만드는 것이다. 그래서 \(u\)로는 다항식이나 로그함수처럼 미분하면 간단해지는 함수를, \(v'\)로는 지수함수나 삼각함수처럼 적분해도 복잡해지지 않는 함수를 고른다. \(x e^x\)에서 \(u = x\)로 고르면 새 적분이 \(\int e^x\,dx\)가 되어 \(\int x e^x\,dx = (x - 1)e^x + C\)이지만, 반대로 고르면 새 적분에 \(x^2\)이 생겨 더 어려워진다. 로그함수는 적분하기 어렵고 미분하면 \(\frac{1}{x}\)로 간단해지므로 거의 늘 \(u\)로 둔다.
  4. 연결\(x^2e^x\)처럼 다항식의 차수가 높으면 부분적분을 차수만큼 되풀이한다. 또 \(\int e^x \sin x\,dx\)는 두 번 부분적분하면 원래 적분이 다시 나타나므로, 그것을 \(I\)로 놓고 방정식 \(2I = e^x(\sin x - \cos x)\)를 풀어 \(I\)를 구한다.
  5. 적용보기마다 \(A\)와 \(B\)를 바꾸어 보며 넷째 값이 늘 첫째 값과 같은지 확인하고, 파랑 곡선이 어느 쪽에서 더 단순한지 비교해 보자. 그리고 \(x \sin x\)에서 \(b\)를 \(\pi\)(약 3.14)로 놓으면 원래 적분이 얼마인지 구해 보자.
  6. 판단‘\(u\)는 늘 앞에 쓴 인수’처럼 순서로 고르면 안 된다. \(x \ln x\)에서 \(u = x\)로 고르면 \(v\)를 구하려고 \(\int \ln x\,dx\)부터 풀어야 하고, 새 적분에 \(\ln x\)가 그대로 남기 때문이다. 그래서 미분과 적분 중 어느 쪽이 함수를 더 간단하게 만드는지로 고른다.
