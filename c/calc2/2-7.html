음함수와 역함수의 미분

원 \(x^2 + y^2 = 25\)나 \(x^3 + x\)의 역함수처럼, \(x\)와 \(y\)의 관계는 알지만 \(y\)를 \(x\)의 식으로 깔끔하게 풀기 어려운 경우가 많습니다. 이 절에서는 식을 풀지 않고 관계식 그대로 미분해 접선의 기울기를 얻습니다. 열쇠는 \(y\)를 \(x\)의 함수로 보고 합성함수의 미분법을 쓰는 것입니다. 다루는 음함수는 간단한 것으로 한정합니다.

2.7.1음함수의 미분법

\(x\)와 \(y\)의 관계가 \(f(x, y) = 0\) 꼴로 주어진 것을 음함수 표현이라 한다. 이 식에서 \(y\)를 \(x\)의 함수로 보고, 양변을 \(x\)에 대해 미분한다. 이때 \(y\)가 들어 있는 항은 합성함수의 미분법에 따라 \(\dfrac{dy}{dx}\)가 곱해진다. 예를 들어 \(\dfrac{d}{dx}(y^2) = 2y\dfrac{dy}{dx}\)이다.

방법 2.7.1 음함수의 미분

\(f(x, y) = 0\)의 양변을 \(x\)에 대하여 미분하고(\(y\)의 식에는 \(y'\)을 곱한다), 그 식을 \(y'\)에 대하여 정리한다.

\(x^2 + y^2 = 25\)를 미분하면 \(2x + 2y\,y' = 0\)이므로 \(y' = -\dfrac{x}{y}\) (\(y \ne 0\))이다. 위쪽 반원과 아래쪽 반원이 한 식에 함께 들어 있다. 반지름의 기울기는 \(\dfrac{y}{x}\)이므로 접선의 기울기와의 곱이 \(-1\), 곧 접선과 반지름은 수직이다. 그림 1에서 점을 돌려 보면 언제나 그렇다.

2.7.2역함수의 미분법

\(y = f^{-1}(x)\)이면 \(x = f(y)\)이다. 이 식을 음함수로 보고 양변을 \(x\)에 대해 미분하면 \(1 = f'(y)\dfrac{dy}{dx}\)이므로 다음을 얻는다.

정리 2.7.2 역함수의 미분법

\[\frac{dy}{dx} = \frac{1}{dx/dy},\qquad (f^{-1})'(a) = \frac{1}{f'(b)}\quad (\text{단, } f(b) = a,\ f'(b) \ne 0)\]

역함수의 그래프는 원래 그래프를 직선 \(y = x\)에 대해 뒤집은 것이므로, 대응하는 점의 접선도 뒤집혀 기울기가 역수가 된다. \(y = \ln x\)를 \(x = e^y\)로 보고 미분하면 \(\dfrac{dy}{dx} = \dfrac{1}{e^y} = \dfrac{1}{x}\)로, 앞에서 구한 결과와 같다.1

2.7.3예제 하나를 끝까지

예제 2.7.3

\(f(x) = x^3 + x + 1\)의 역함수를 \(g(x)\)라 할 때 \(g'(3)\)을 구하여라.

\(g(x)\)의 식을 직접 구하기는 어렵다. 그러나 \(g(3) = b\)이면 \(f(b) = 3\)이므로 \(b^3 + b + 1 = 3\)에서 \(b = 1\)이다(\(f\)는 증가함수이므로 근은 하나뿐이다).

\(f'(x) = 3x^2 + 1\)이므로 \(f'(1) = 4\)이고, 역함수의 미분법에 의해 \(g'(3) = \dfrac{1}{f'(1)} = \dfrac{1}{4}\)이다. 역함수의 식을 모르고도 한 점에서의 기울기는 정확히 구할 수 있다.

아래 탐구 카드에서 음함수의 접선 기울기와, 식을 모르는 역함수의 기울기를 직접 구해 보자.

  1. \(x^3 + y^3 = 6xy\)를 미분하면 \(3x^2 + 3y^2y' = 6y + 6xy'\)이므로 \(y' = \dfrac{2y - x^2}{y^2 - 2x}\)이다. \(y\)에 대해 풀지 않고도 기울기를 구할 수 있다.
마무리

음함수 \(f(x, y) = 0\)은 \(y\)를 \(x\)의 함수로 보고 양변을 미분하여 \(y'\)을 구하며, \(y\)의 항에는 합성함수의 미분법으로 \(y'\)이 곱해진다. 역함수의 도함수는 원래 함수의 도함수의 역수이다. 그래서 처음 질문의 원 위의 점 \((3, 4)\)에서 접선의 기울기는 식을 풀지 않고도 \(-\tfrac{3}{4}\)으로 바로 구할 수 있다.

초록 부분은 점 \(P\) 근처에서 \(y\)를 \(x\)의 함수로 볼 수 있는 가지이고, 회색 부분은 같은 관계식에서 나온 다른 가지이다. 점선은 \(P\)에서의 접선이다.

  1. 질문원 \(x^2 + y^2 = 25\) 위의 점 \((3, 4)\)에서 접선의 기울기를, \(y = \sqrt{25 - x^2}\)처럼 식을 풀지 않고 구할 수 있을까?
  2. 복원\(y\)가 \(x\)의 함수이면 \(y^2\)은 합성함수이다. 그래서 바깥 함수 \(u^2\)을 미분한 뒤 속 함수 \(y\)의 도함수를 곱해 \(\frac{d}{dx}(y^2) = 2y \cdot \frac{dy}{dx}\)이다.
  3. 설명\(x\)와 \(y\)의 관계가 \(F(x, y) = 0\) 꼴로 주어지고 이 관계가 \(y\)를 \(x\)의 함수로 정할 때, 그 함수를 음함수라고 한다. 이때는 식을 풀지 않고 양변을 \(x\)로 미분하면 된다. 원에서는 \(2x + 2y \cdot y' = 0\)이므로 \(y' = -\frac{x}{y} (y \ne 0)\)이고, 점 \((3, 4)\)에서 기울기는 \(-\frac{3}{4}\)이다. 위쪽 반원 \(y = \sqrt{25 - x^2}\)을 직접 미분해도 \(-\frac{x}{\sqrt{25 - x^2}} = -\frac{3}{4}\)로 같다. 또 \(xy\) 같은 항은 곱의 미분법으로 \((xy)' = y + xy'\)이다.
  4. 연결같은 방법으로 \(y = x^{\frac{p}{q}}\)를 \(y^q = x^p\)로 바꾸어 미분하면, 유리수 지수에서도 \((x^r)' = rx^{r - 1}\)임을 얻는다. 그리고 기울기를 얻으면 곧바로 접선의 방정식을 쓸 수 있다.
  5. 적용원에서 방향각을 움직여 넷째 칸의 접선이 수평, 수직이 되는 점을 찾고, 둘째 칸과 셋째 칸이 늘 같은지, 방향각 \(0^\circ\)를 지날 때 초록 가지가 어떻게 바뀌는지 보자. 셋째 식 \(x^2 + xy + y^2 = 3\)에서는 접선이 수직인 점이 직선 \(x + 2y = 0\) 위에 있는지 확인해 보자.
  6. 판단\(y'\)의 식에 \(x\)와 \(y\)가 함께 들어 있어서, 같은 \(x\)라도 위쪽 점과 아래쪽 점의 기울기가 다르다. 분모가 0인 점에서는 접선이 세로선이어서 기울기가 없다. 또 이 방법은 그 점 근처에서 \(y\)가 \(x\)의 미분가능한 함수라는 가정 위에서 쓰며, \(y^2\)을 미분해 \(2y\)만 쓰고 \(y'\)를 빠뜨리는 실수가 가장 흔하다.

\(A(a, b)\)는 \(y = f(x)\) 위에, \(B(b, a)\)는 역함수의 그래프 위에 있다. 두 기울기 삼각형은 가로와 세로가 서로 바뀐 모양이고, 넷째 칸은 역함수를 수치로 풀어 가까운 두 점으로 잰 기울기이다.

  1. 질문\(f(x) = x^3 + x\)의 역함수 \(g\)는 식으로 쓰기 어렵다. 그래도 \(g'(2)\)를 구할 수 있을까?
  2. 복원\(f\)가 일대일대응이면 역함수 \(g = f^{-1}\)가 있고, 두 그래프는 직선 \(y = x\)에 대하여 대칭이다. 또 모든 \(x\)에 대하여 \(f(g(x)) = x\)이다.
  3. 설명직선 \(y = x\)에 대해 대칭이동하면 가로와 세로가 바뀌므로 기울기는 역수가 된다. 식으로는 \(f(g(x)) = x\)의 양변을 미분해 \(f'(g(x)) \cdot g'(x) = 1\)을 얻으므로, \(b = f(a)\)이고 \(f'(a) \ne 0\)이면 \(g'(b) = \frac{1}{f'(a)}\)이다. \(\frac{dx}{dy} = \frac{1}{\frac{dy}{dx}}\)로 써도 같으며, 질문에서는 \(f(1) = 2\), \(f'(1) = 4\)이므로 \(g'(2) = \frac{1}{4}\)이다.
  4. 연결\(y = \ln x\)는 \(x = e^y\)의 역함수이고, \(\frac{dx}{dy} = e^y = x\)이므로 \((\ln x)' = \frac{1}{x}\)를 다시 얻는다. \(x = e^y\)의 양변을 \(x\)로 미분해도 같은 결과가 나오므로, 역함수의 미분은 음함수의 미분과 같은 생각이다.
  5. 적용첫 함수에서 \(a = 1\)에 맞추어 셋째 칸과 넷째 칸이 \(\frac{1}{4}\)로 같은지 보자. \(e^x\)에서는 \(a\)를 바꾸며 셋째 칸이 늘 \(\frac{1}{b}\)인지 확인하고, \(x^3\)에서 \(a\)를 0에 가깝게 보내면 \(B\)에서의 접선과 넷째 칸이 어떻게 되는지 보자.
  6. 판단\(g'(b) = \frac{1}{f'(b)}\)로 쓰는 실수가 흔한데, 넣는 값은 \(b\)가 아니라 \(f(a) = b\)를 만족하는 \(a\)이다. \(f'(a) = 0\)이면 역함수의 접선은 세로선이 되어 \(g\)는 \(b\)에서 미분가능하지 않으며, \(x^3\)의 역함수 \(\sqrt[3]{x}\)가 \(x = 0\)에서 그렇다. 또 \(f^{-1}(x)\)는 \(\frac{1}{f(x)}\)가 아니다.
