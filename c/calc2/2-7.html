음함수와 역함수의 미분

원 x2 + y2 = 25나 x3 + x의 역함수처럼, x와 y의 관계는 알지만 y를 x의 식으로 깔끔하게 풀기 어려운 경우가 많습니다. 이 절에서는 식을 풀지 않고 관계식 그대로 미분해 접선의 기울기를 얻습니다. 열쇠는 y를 x의 함수로 보고 합성함수의 미분법을 쓰는 것입니다. 다루는 음함수는 간단한 것으로 한정합니다.

초록 부분은 점 P 근처에서 y를 x의 함수로 볼 수 있는 가지입니다. 회색 부분은 같은 관계식에서 나온 다른 가지입니다. 점선은 P에서의 접선입니다.

  1. 질문원 x2 + y2 = 25 위의 점 (3, 4)에서 접선의 기울기를, y = √(25 − x2)처럼 식을 풀지 않고 구할 수 있을까요?
  2. 복원y가 x의 함수이면 y2은 합성함수입니다. 그래서 d/dx(y2) = 2y · dy/dx입니다. 바깥 함수 u2을 미분한 뒤 속 함수 y의 도함수를 곱합니다.
  3. 설명x와 y의 관계가 F(x, y) = 0 꼴로 주어지고, 이 관계가 y를 x의 함수로 정할 때 그 함수를 음함수라고 합니다. 식을 풀지 않고 양변을 x로 미분하면 됩니다. 원에서는 2x + 2y · y′ = 0이므로 y′ = −x/y (y ≠ 0)입니다. 점 (3, 4)에서 기울기는 −3/4입니다. 위쪽 반원 y = √(25 − x2)을 직접 미분해도 −x/√(25 − x2) = −3/4로 같습니다. xy 같은 항은 곱의 미분법으로 (xy)′ = y + xy′입니다.
  4. 연결같은 방법으로 y = xp/q를 yq = xp로 바꾸어 미분하면, 유리수 지수에서도 (xr)′ = rxr − 1임을 얻습니다. 기울기를 얻으면 곧바로 접선의 방정식을 쓸 수 있습니다.
  5. 적용원에서 방향각을 움직여 넷째 칸의 접선이 수평, 수직이 되는 점을 찾으세요. 둘째 칸과 셋째 칸은 늘 같은가요? 방향각 0°를 지날 때 초록 가지는 어떻게 바뀌나요? 셋째 식 x2 + xy + y2 = 3에서는 접선이 수직인 점이 직선 x + 2y = 0 위에 있는지 확인하세요.
  6. 판단y′의 식에 x와 y가 함께 들어 있습니다. 그래서 같은 x라도 위쪽 점과 아래쪽 점의 기울기가 다릅니다. 분모가 0인 점에서는 접선이 세로선이어서 기울기가 없습니다. 또 이 방법은 그 점 근처에서 y가 x의 미분가능한 함수라는 가정 위에서 씁니다. y2을 미분해 2y만 쓰고 y′를 빠뜨리는 실수가 가장 흔합니다.

A(a, b)는 y = f(x) 위에, B(b, a)는 역함수의 그래프 위에 있습니다. 두 기울기 삼각형은 가로와 세로가 서로 바뀐 모양입니다. 넷째 칸은 역함수를 수치로 풀어 가까운 두 점으로 잰 기울기입니다.

  1. 질문f(x) = x3 + x의 역함수 g는 식으로 쓰기 어렵습니다. 그래도 g′(2)를 구할 수 있을까요?
  2. 복원f가 일대일대응이면 역함수 g = f−1가 있고, 두 그래프는 직선 y = x에 대하여 대칭입니다. 또 모든 x에 대하여 f(g(x)) = x입니다.
  3. 설명직선 y = x에 대해 대칭이동하면 가로와 세로가 바뀌므로 기울기는 역수가 됩니다. 식으로는 f(g(x)) = x의 양변을 미분해 f′(g(x)) · g′(x) = 1을 얻습니다. 따라서 b = f(a)이고 f′(a) ≠ 0이면 g′(b) = 1/f′(a)입니다. dx/dy = 1/(dy/dx)로 써도 같습니다. 질문에서는 f(1) = 2, f′(1) = 4이므로 g′(2) = 1/4입니다.
  4. 연결y = ln x는 x = ey의 역함수입니다. dx/dy = ey = x이므로 (ln x)′ = 1/x를 다시 얻습니다. x = ey의 양변을 x로 미분해도 같은 결과가 나오므로, 역함수의 미분은 음함수의 미분과 같은 생각입니다.
  5. 적용첫 함수에서 a = 1에 맞추어 셋째 칸과 넷째 칸이 1/4로 같은지 보세요. ex에서는 a를 바꾸며 셋째 칸이 늘 1/b인지 확인하세요. x3에서 a를 0에 가깝게 보내면 B에서의 접선과 넷째 칸은 어떻게 되나요?
  6. 판단g′(b) = 1/f′(b)로 쓰는 실수가 흔합니다. 넣는 값은 b가 아니라 f(a) = b를 만족하는 a입니다. f′(a) = 0이면 역함수의 접선은 세로선이 되어 g는 b에서 미분가능하지 않습니다. x3의 역함수 ∛x가 x = 0에서 그렇습니다. 또 f−1(x)는 1/f(x)가 아닙니다.
