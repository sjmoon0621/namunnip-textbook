여러 가지 함수의 적분

미적분Ⅰ에서는 다항함수만 적분했습니다. 적분은 미분을 거꾸로 하는 일이므로, 앞 단원에서 구한 도함수 공식을 뒤집으면 새 함수들의 부정적분이 나옵니다. 이 절에서는 지수가 실수인 거듭제곱함수, 지수함수, 삼각함수를 적분합니다. 특히 \(x^n\)의 공식이 통하지 않는 \(n = -1\)에서 자연로그가 나타나는 까닭을 넓이로 확인합니다.

여러 가지 함수의 적분

본문

미적분Ⅰ에서 \(\int x^n\,dx = \dfrac{x^{n+1}}{n+1} + C\)를 배웠다. 그런데 \(n = -1\)을 넣으면 분모가 0이 되어 공식이 무너진다. 그렇다고 \(y = \dfrac{1}{x}\)의 그래프 아래 넓이가 없는 것은 아니다. \(x = 1\)에서 \(x = 2\)까지 \(y = \dfrac{1}{x}\) 아래의 넓이는 얼마이고, 그 넓이는 어떤 함수로 나타날까?

먼저 알아야 할 것부정적분과 정적분(미적분Ⅰ), 지수함수·로그함수의 도함수(지수·로그함수의 극한과 미분), 삼각함수의 도함수(삼각함수의 극한과 미분).

3.1.1미분을 거꾸로 읽기

부정적분은 미분의 역이다. 그러므로 앞에서 구한 도함수 공식을 거꾸로 읽으면 적분 공식을 얻는다. \((\ln|x|)' = \dfrac{1}{x}\)이므로 \(\dfrac{1}{x}\)의 부정적분은 \(\ln|x|\)이다. \(x < 0\)에서도 \(\ln(-x)\)를 미분하면 \(\dfrac{-1}{-x} = \dfrac{1}{x}\)이 되므로 절댓값을 붙인다.

정리 3.1.1 여러 가지 함수의 부정적분 (\(C\)는 적분상수)

\[\int x^n\,dx = \frac{x^{n+1}}{n+1} + C\ (n \ne -1),\qquad \int \frac{1}{x}\,dx = \ln|x| + C\] \[\int e^x\,dx = e^x + C,\quad \int a^x\,dx = \frac{a^x}{\ln a} + C,\quad \int \sin x\,dx = -\cos x + C,\quad \int \cos x\,dx = \sin x + C\] \[\int \sec^2 x\,dx = \tan x + C\]

그림 1에서 \(n\)을 \(-1\)에 가깝게 움직여 보자. \(n = -0.99\)이면 \(\dfrac{2^{0.01} - 1}{0.01} \approx 0.6956\), \(n = -1.01\)이면 \(\approx 0.6908\)로, 둘 다 \(\ln 2 \approx 0.6931\)을 사이에 두고 다가간다. \(\dfrac{1}{x}\)의 적분이 거듭제곱이 아니라 로그로 나오는 것은 공식의 빈자리를 로그가 채우는 것이다.1

3.1.2원시함수 확인하기

부정적분이 맞는지는 미분해 보면 바로 확인할 수 있다. \(\int \sin x\,dx\)의 후보로 \(\cos x\)를 떠올리기 쉽지만, \((\cos x)' = -\sin x\)이므로 부호가 틀렸다. 올바른 답 \(-\cos x\)를 미분하면 \(\sin x\)가 된다. 적분 결과를 미분하여 처음 함수가 나오는지 확인하는 습관이 실수를 막는다.

3.1.3예제 하나를 끝까지

예제 3.1.2

다음 정적분의 값을 구하여라. (1) \(\int_1^{e} \dfrac{x + 1}{x}\,dx\) (2) \(\int_0^{\pi} \sin x\,dx\) (3) \(\int_0^{1} (e^x + 2^x)\,dx\)

(1) \(\dfrac{x + 1}{x} = 1 + \dfrac{1}{x}\)이므로 \(\left[x + \ln x\right]_1^e = (e + 1) - (1 + 0) = e\)이다. (2) \(\left[-\cos x\right]_0^{\pi} = -\cos\pi + \cos 0 = 1 + 1 = 2\)이다. 사인 곡선의 한 봉우리 아래 넓이가 정확히 2라는 뜻이다.

(3) \(\left[e^x + \dfrac{2^x}{\ln 2}\right]_0^1 = (e - 1) + \dfrac{2 - 1}{\ln 2} = e - 1 + \dfrac{1}{\ln 2} \approx 1.718 + 1.443 = 3.161\)이다. 밑이 \(e\)가 아닌 지수함수는 \(\ln a\)로 나누어야 한다는 점에 주의한다.

아래 탐구 카드에서 \(x^n\)의 적분 공식이 \(n = -1\)에서 바뀌는 모습과, 여러 원시함수 후보를 미분으로 확인하는 과정을 직접 해 보자.

  1. 그래서 \(\ln x\)를 \(\ln x = \int_1^x \dfrac{1}{t}\,dt\)로 정의하기도 한다. 이렇게 정의하면 \(\ln(ab) = \ln a + \ln b\) 같은 로그의 성질도 넓이의 성질로 증명할 수 있다.
마무리

여러 가지 함수의 적분 공식은 도함수 공식을 거꾸로 읽어 얻으며, 결과를 미분하여 확인할 수 있다. \(x^n\)의 공식은 \(n = -1\)에서 쓸 수 없고, 그 자리를 \(\int \frac{1}{x}dx = \ln|x| + C\)가 채운다. 그래서 처음 질문의 \(y = \frac{1}{x}\) 아래 1에서 2까지의 넓이는 \(\ln 2 \approx 0.693\)이다.

탐구 1

\(x^n\)의 적분 공식은 \(n = -1\)에서 왜 멈출까?

거듭제곱함수의 적분 · 조작
넓이로 잰 \(\int_1^b x^n\,dx\)
—
\(\frac{b^{n+1} - 1}{n + 1}\)
—
\(\ln b\)
—

그림을 끌면 위끝 \(b\)가 움직인다. 첫 값은 칠한 넓이를 잘게 나누어 더한 값이다(\(b < 1\)이면 부호가 음수).

  1. 질문\(\int x^n\,dx = \frac{x^{n+1}}{n + 1} + C\)는 \(n\)이 정수가 아닌 실수일 때도 맞을까? 그리고 분모가 0이 되는 \(n = -1\)이면 \(\frac{1}{x}\)의 넓이는 어떻게 구할까?
  2. 복원\(x > 0\)이고 \(n\)이 실수이면 \((x^{n+1})' = (n + 1)x^n\)이고, \((\ln x)' = \frac{1}{x}\)이다. 그리고 부정적분은 미분하면 피적분함수가 되는 함수이다.
  3. 설명\(n \ne -1\)이면 \(\frac{x^{n+1}}{n + 1}\)을 미분해 \(x^n\)이 되므로 \(\int x^n\,dx = \frac{x^{n+1}}{n + 1} + C\)이고, 예를 들어 \(\int \sqrt{x}\,dx = (\frac{2}{3})x^{\frac{3}{2}} + C\), \(\int \frac{1}{x^2}\,dx = -\frac{1}{x} + C\)이다. 그런데 \(n = -1\)이면 이 식은 0으로 나누게 되어 쓸 수 없다. 대신 \((\ln x)' = \frac{1}{x}\)이므로 \(\int \frac{1}{x}\,dx = \ln |x| + C\)이며, \(x < 0\)에서도 \((\ln(-x))' = \frac{1}{x}\)이므로 절댓값을 씌운다.
  4. 연결\(n\)이 \(-1\)에 가까워지면 \(\frac{b^{n+1} - 1}{n + 1}\)은 앞 단원의 극한 \(\frac{e^h - 1}{h} \to 1\)과 같은 꼴이 되어 \(\ln b\)로 다가간다. 그래서 \(\frac{1}{x}\)의 적분은 따로 떨어진 예외가 아니라 거듭제곱 적분이 이어지는 자리에 있으며, \(\frac{1}{x}\)의 넓이로 자연로그를 정의하는 교재도 있다.
  5. 적용\(n = -0.5\), \(b = 4\)에서 넓이가 2인지 확인하고, \(n\)을 \(-1.1\), \(-1.05\)로 옮기며 둘째 값과 \(\ln b\)를 비교해 보자. 그리고 \(n = -1\)을 누르면 둘째 값이 어떻게 되고 넓이는 무엇과 같아지는지, \(b\)를 1보다 작게 하면 부호가 어떻게 되는지 보자.
  6. 판단\(\int \frac{1}{x}\,dx = \frac{x^0}{0}\) 또는 \(-\frac{1}{x^2}\)이라고 쓰는 실수가 흔한데, 앞의 것은 정의되지 않고 뒤의 것은 \(\frac{1}{x}\)를 미분한 결과이다. 또 \(\int_{-1}^1 \frac{1}{x^2}\,dx\)에 공식을 그대로 넣어 \(-2\)를 얻으면 안 된다. \(\frac{1}{x^2}\)은 \(x = 0\)에서 정의되지 않아 그 구간에서는 이 방법으로 정적분을 구할 수 없기 때문이다.

탐구 2

어느 후보가 \(e^x\), \(\sin x\)의 진짜 원시함수일까?

지수함수·삼각함수의 적분 · 조작
넓이로 잰 \(\int_a^b f(x)\,dx\)
—
후보 \(F(b) - F(a)\)
—
판정
—

초록은 \(x\)축 위, 주황은 아래쪽 넓이이다. 후보를 하나 고르고 구간을 여러 번 바꾸어도 두 값이 늘 같은지 보자.

  1. 질문\(\int e^x\,dx\), \(\int 2^x\,dx\), \(\int \sin x\,dx\)를 구하라고 할 때, 그럴듯한 후보 중 어느 것이 맞는지 어떻게 가릴 수 있을까?
  2. 복원\(F'(x) = f(x)\)이면 \(\int_a^b f(x)\,dx = F(b) - F(a)\)이다. 또 \((e^x)' = e^x\), \((a^x)' = a^x \ln a\), \((\sin x)' = \cos x\), \((\cos x)' = -\sin x\), \((\tan x)' = \sec^2 x\)이다.
  3. 설명도함수 공식을 거꾸로 읽으면 \(\int e^x\,dx = e^x + C\), \(\int a^x\,dx = \frac{a^x}{\ln a} + C\) \((a > 0, a \ne 1)\), \(\int \sin x\,dx = -\cos x + C\), \(\int \cos x\,dx = \sin x + C\), \(\int \sec^2 x\,dx = \tan x + C\), \(\int \csc^2 x\,dx = -\cot x + C\)를 얻는다. 후보가 맞는지는 미분해 보면 알 수 있고, 그림에서는 \(F(b) - F(a)\)가 어떤 구간에서도 넓이와 같은지로 확인할 수 있다.
  4. 연결적분 공식은 모두 미분 공식의 거울상이다. 그래서 새 함수의 적분을 만날 때마다 무엇을 미분하면 이것이 될지를 먼저 묻고, 바로 떠오르지 않는 함수는 다음 두 절의 치환적분법과 부분적분법으로 아는 꼴로 바꾼다.
  5. 적용\(e^x\)에서 두 후보를 번갈아 고르며 판정을 보고, 틀린 후보도 어떤 구간에서는 우연히 넓이와 가까울 수 있는지 생각해 보자. \(2^x\)에서는 \(2^x\)을 그대로 쓰면 넓이와 몇 배 차이가 나는지, 그 배수가 \(\ln 2\)와 어떤 관계인지 보자. \(\sin x\)에서 \(a = 0\), \(b = 3.15\) 근처로 놓으면 넓이는 2에 가까워진다.
  6. 판단\(\int e^x\,dx = \frac{e^{x+1}}{x + 1}\)처럼 거듭제곱 공식을 지수함수에 쓰는 실수가 흔한데, 거듭제곱 공식은 밑이 변수이고 지수가 상수일 때만 쓴다. 또 \(\int \sin x\,dx = \cos x\)로 부호를 놓치기 쉽다. \(0 < x < \pi\)에서 \(\sin x > 0\)이므로 원시함수는 증가해야 하는데 \(\cos x\)는 감소하기 때문이다.
