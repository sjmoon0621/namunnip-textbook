여러 가지 함수의 적분

미적분Ⅰ에서는 다항함수만 적분했습니다. 적분은 미분을 거꾸로 하는 일이므로, 앞 단원에서 구한 도함수 공식을 뒤집으면 새 함수들의 부정적분이 나옵니다. 이 절에서는 지수가 실수인 거듭제곱함수, 지수함수, 삼각함수를 적분합니다. 특히 xn의 공식이 통하지 않는 n = −1에서 자연로그가 나타나는 까닭을 넓이로 확인합니다.

먼저 알면 좋은 것 부정적분과 정적분지수함수·로그함수의 도함수삼각함수의 도함수

이 절의 카드

  1. 3.1.1xⁿ의 적분과 1/x의 적분
  2. 3.1.2지수함수·삼각함수의 적분

이 절을 개념 지도에서 보기

3.1.1

xn의 적분 공식은 n = −1에서 왜 멈출까?

거듭제곱함수의 적분 · 조작
넓이로 잰 ∫1b xn dx
—
(bn+1 − 1)/(n + 1)
—
ln b
—

그림을 끌면 위끝 b가 움직입니다. 첫 값은 칠한 넓이를 잘게 나누어 더한 값입니다(b < 1이면 부호가 음수).

  1. 질문∫xn dx = xn+1/(n + 1) + C는 n이 정수가 아닌 실수일 때도 맞을까요? 그리고 분모가 0이 되는 n = −1이면 1/x의 넓이는 어떻게 구할까요?
  2. 복원x > 0이고 n이 실수이면 (xn+1)′ = (n + 1)xn입니다. 또 (ln x)′ = 1/x입니다. 부정적분은 미분하면 피적분함수가 되는 함수입니다.
  3. 설명n ≠ −1이면 xn+1/(n + 1)을 미분해 xn이 되므로 ∫xn dx = xn+1/(n + 1) + C입니다. 예를 들어 ∫√x dx = (2/3)x3/2 + C, ∫1/x2 dx = −1/x + C입니다. n = −1이면 이 식은 0으로 나누게 되어 쓸 수 없습니다. 대신 (ln x)′ = 1/x이므로 ∫1/x dx = ln |x| + C입니다. x < 0에서도 (ln(−x))′ = 1/x이므로 절댓값을 씌웁니다.
  4. 연결n이 −1에 가까워지면 (bn+1 − 1)/(n + 1)은 앞 단원의 극한 (eh − 1)/h → 1과 같은 꼴이 되어 ln b로 다가갑니다. 그래서 1/x의 적분은 따로 떨어진 예외가 아니라 거듭제곱 적분이 이어지는 자리에 있습니다. 1/x의 넓이로 자연로그를 정의하는 교재도 있습니다.
  5. 적용n = −0.5, b = 4에서 넓이가 2인지 확인하세요. 이어서 n을 −1.1, −1.05로 옮기며 둘째 값과 ln b를 비교하세요. n = −1을 누르면 둘째 값은 어떻게 되고, 넓이는 무엇과 같아지나요? b를 1보다 작게 하면 부호는 어떻게 되나요?
  6. 판단∫1/x dx = x0/0 또는 −1/x2이라고 쓰는 실수가 흔합니다. 앞의 것은 정의되지 않고, 뒤의 것은 1/x를 미분한 결과입니다. 또 ∫−11 1/x2 dx에 공식을 그대로 넣어 −2를 얻으면 안 됩니다. 1/x2은 x = 0에서 정의되지 않아 그 구간에서는 이 방법으로 정적분을 구할 수 없습니다.

3.1.2

어느 후보가 ex, sin x의 진짜 원시함수일까?

지수함수·삼각함수의 적분 · 조작
넓이로 잰 ∫ab f(x) dx
—
후보 F(b) − F(a)
—
판정
—

초록은 x축 위, 주황은 아래쪽 넓이입니다. 후보를 하나 고르고 구간을 여러 번 바꾸어도 두 값이 늘 같은지 보세요.

  1. 질문∫ex dx, ∫2x dx, ∫sin x dx를 구하라고 할 때, 그럴듯한 후보 중 어느 것이 맞는지 어떻게 가릴 수 있을까요?
  2. 복원F′(x) = f(x)이면 ∫ab f(x) dx = F(b) − F(a)입니다. 또 (ex)′ = ex, (ax)′ = ax ln a, (sin x)′ = cos x, (cos x)′ = −sin x, (tan x)′ = sec2 x입니다.
  3. 설명도함수 공식을 거꾸로 읽으면 다음을 얻습니다. ∫ex dx = ex + C, ∫ax dx = ax/ln a + C (a > 0, a ≠ 1), ∫sin x dx = −cos x + C, ∫cos x dx = sin x + C, ∫sec2 x dx = tan x + C, ∫csc2 x dx = −cot x + C. 후보가 맞는지는 미분해 보면 알 수 있고, 그림에서는 F(b) − F(a)가 어떤 구간에서도 넓이와 같은지로 확인할 수 있습니다.
  4. 연결적분 공식은 모두 미분 공식의 거울상입니다. 그래서 새 함수의 적분을 만날 때마다 "무엇을 미분하면 이것이 될까?"를 먼저 묻습니다. 바로 떠오르지 않는 함수는 다음 두 절의 치환적분법과 부분적분법으로 아는 꼴로 바꿉니다.
  5. 적용ex에서 두 후보를 번갈아 고르며 판정을 보세요. 틀린 후보도 어떤 구간에서는 우연히 넓이와 가까울 수 있을까요? 2x에서는 2x을 그대로 쓰면 넓이와 몇 배 차이가 나나요? 그 배수는 ln 2와 어떤 관계인가요? sin x에서 a = 0, b = 3.15 근처로 놓으면 넓이는 2에 가까워집니다.
  6. 판단∫ex dx = ex+1/(x + 1)처럼 거듭제곱 공식을 지수함수에 쓰는 실수가 흔합니다. 거듭제곱 공식은 밑이 변수이고 지수가 상수일 때만 씁니다. 또 ∫sin x dx = cos x로 부호를 놓치기 쉽습니다. 0 < x < π에서 sin x > 0이므로 원시함수는 증가해야 하는데 cos x는 감소합니다.
