삼각함수의 덧셈정리

\(\cos(\alpha + \beta)\)는 \(\cos \alpha + \cos \beta\)가 아닙니다. 그러면 두 각의 합이나 차의 삼각함수는 각각의 삼각함수로 어떻게 나타낼까요? 이 절에서는 단위원 위의 두 점 사이의 거리가 회전해도 변하지 않는다는 사실로 덧셈정리를 증명합니다. 그리고 이를 이용해 특수각이 아닌 각의 값, 두 직선이 이루는 각, 사인과 코사인을 더한 그래프를 다룹니다. 덧셈정리는 다음 절에서 사인함수와 코사인함수를 미분할 때 다시 씁니다.

먼저 알면 좋은 것 일반각과 호도법삼각함수의 정의와 그래프두 점 사이의 거리

2.2.1

\(\cos(\alpha - \beta)\)를 \(\alpha\), \(\beta\)의 삼각함수로 나타낼 수 있을까?

덧셈정리 · 단계별 증명
\(PQ^2\) (좌표로)
—
\(AB^2 = 2 - 2\cos(\alpha-\beta)\)
—
\(\cos(\alpha - \beta)\)
—
\(\cos \alpha \cos \beta + \sin \alpha \sin \beta\)
—

—

\(P(\cos \alpha, \sin \alpha)\), \(Q(\cos \beta, \sin \beta)\), \(A(1, 0)\), \(B(\cos(\alpha - \beta), \sin(\alpha - \beta))\)입니다. 초록 현 \(PQ\)와 주황 현 \(AB\)의 길이를 비교하세요.

  1. 질문\(\cos 15^\circ\)는 특수각이 아닙니다. \(15^\circ = 45^\circ - 30^\circ\)이니 \(\cos 45^\circ\)와 \(\cos 30^\circ\)만으로 구할 수 있을까요? \(\cos(\alpha - \beta) = \cos \alpha - \cos \beta\)일까요?
  2. 복원단위원 위에서 각 \(\theta\)를 나타내는 점은 \((\cos \theta, \sin \theta)\)입니다. 두 점 사이의 거리는 \(\sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}\)이고, \(\sin^2 \theta + \cos^2 \theta = 1\)입니다.
  3. 설명① 좌표로 계산하면 \(PQ^2 = (\cos \alpha - \cos \beta)^2 + (\sin \alpha - \sin \beta)^2 = 2 - 2(\cos \alpha \cos \beta + \sin \alpha \sin \beta)\)입니다. ② 삼각형 \(OPQ\)를 원점을 중심으로 \(-\beta\)만큼 돌리면 \(Q\)는 \(A(1, 0)\)로, \(P\)는 \(B(\cos(\alpha - \beta), \sin(\alpha - \beta))\)로 갑니다. 돌려도 길이는 그대로이므로 \(PQ^2 = AB^2 = 2 - 2\cos(\alpha - \beta)\)입니다. ③ 두 식을 비교하면 \(\cos(\alpha - \beta) = \cos \alpha \cos \beta + \sin \alpha \sin \beta\)입니다. \(\beta\) 자리에 \(-\beta\)를 넣으면 \(\cos(\alpha + \beta) = \cos \alpha \cos \beta - \sin \alpha \sin \beta\), \(\sin \theta = \cos(90^\circ - \theta)\)를 쓰면 \(\sin(\alpha \pm \beta) = \sin \alpha \cos \beta \pm \cos \alpha \sin \beta\), 두 식을 나누면 \(\tan(\alpha \pm \beta) = \frac{\tan \alpha \pm \tan \beta}{1 \mp \tan \alpha \tan \beta}\)입니다. 이것을 덧셈정리라고 합니다.
  4. 연결\(\beta = \alpha\)로 두면 배각 공식 \(\sin 2\alpha = 2 \sin \alpha \cos \alpha\), \(\cos 2\alpha = \cos^2 \alpha - \sin^2 \alpha = 2\cos^2 \alpha - 1 = 1 - 2\sin^2 \alpha\), \(\tan 2\alpha = \frac{2\tan \alpha}{1 - \tan^2 \alpha}\)가 나옵니다. 다음 절에서는 \(\sin(x + h)\)를 덧셈정리로 펼쳐 \(\sin x\)의 도함수를 구합니다.
  5. 적용\(\alpha\)와 \(\beta\)를 여러 값으로 바꾸고 '돌리기'를 눌러 보세요. 초록 삼각형이 어디에 겹치나요? \(PQ^2\)과 \(AB^2\)은 언제나 같나요? '\(\alpha = 45^\circ\), \(\beta = 30^\circ\)'를 눌러 \(\cos 15^\circ\)의 값과 아래 식의 \(\cos \alpha - \cos \beta\)를 비교하세요.
  6. 판단삼각함수는 일차식이 아니므로 \(\cos(\alpha + \beta) = \cos \alpha + \cos \beta\), \(\sin 2\alpha = 2 \sin \alpha\) 같은 분배는 성립하지 않습니다. \(\alpha = \beta = 60^\circ\)이면 \(\cos 120^\circ = -\frac{1}{2}\)이지만 \(\cos 60^\circ + \cos 60^\circ = 1\)입니다. 또 \(\tan\)의 덧셈정리는 \(\tan \alpha\), \(\tan \beta\), \(\tan(\alpha \pm \beta)\)가 모두 정의될 때만 씁니다.

두 직선이 이루는 각을 기울기만으로 구할 수 있을까?

\(\tan\)의 덧셈정리 · 활용
\(\alpha\) (① 과 \(x\)축)
—
\(\beta\) (② 와 \(x\)축)
—
\(\theta\) (그림에서 잰 예각)
—
\(m_1 - m_2\)
—

—

그림을 누르고 끌면 가까운 직선이 그 점을 지나도록 돌아갑니다.

  1. 질문두 직선 \(y = 2x\)와 \(y = \frac{x}{2}\)는 몇 도로 만날까요? 각도기 없이 기울기만으로 구할 수 있을까요?
  2. 복원직선이 \(x\)축의 양의 방향과 이루는 각이 \(\alpha\)이면 기울기는 \(\tan \alpha\)입니다. \(\tan\)의 덧셈정리는 \(\tan(\alpha - \beta) = \frac{\tan \alpha - \tan \beta}{1 + \tan \alpha \tan \beta}\)입니다.
  3. 설명두 직선의 기울기를 \(m_1 = \tan \alpha\), \(m_2 = \tan \beta\)라 하면 두 직선이 이루는 각은 \(|\alpha - \beta|\) 또는 \(180^\circ - |\alpha - \beta|\)입니다. 두 경우의 탄젠트는 부호만 다르므로 예각 \(\theta\)는 \(\tan \theta = |\frac{m_1 - m_2}{1 + m_1m_2}|\)로 구합니다. 분모 \(1 + m_1m_2\)가 0이면 \(\tan \theta\)가 정의되지 않고 \(\theta = 90^\circ\)입니다. 이것이 두 직선이 수직일 조건 \(m_1m_2 = -1\)입니다.
  4. 연결두 곡선이 만나는 점에서 접선의 기울기를 구하면, 같은 공식으로 두 곡선이 이루는 각도 구할 수 있습니다. 접선의 기울기는 이 단원에서 배우는 미분법으로 얻습니다.
  5. 적용'2와 \(\frac{1}{2}\)'에서 \(\theta\)를 그림에서 잰 값과 공식으로 구한 값으로 비교하세요. '2와 \(-\frac{1}{2}\)'에서는 분모가 어떻게 되나요? '11과 10'에서는 기울기의 차가 1인데 \(\theta\)는 얼마인가요? 직선을 끌어 \(\theta = 45^\circ\)가 되는 짝을 하나 더 찾아보세요.
  6. 판단기울기의 차가 크다고 각이 큰 것은 아닙니다. 기울기 0과 1의 차도 1이고 10과 11의 차도 1이지만, 앞의 두 직선은 \(45^\circ\), 뒤의 두 직선은 약 \(0.52^\circ\)로 만납니다. 각을 정하는 것은 차가 아니라 \(\frac{m_1 - m_2}{1 + m_1m_2}\)입니다. 또 이 공식은 예각을 줍니다. 둔각이 필요하면 \(180^\circ - \theta\)를 씁니다.

2.2.3

\(a \sin x + b \cos x\)는 어떤 모양의 그래프일까?

삼각함수의 합성 · 조작
\(r = \sqrt{a^2 + b^2}\)
—
\(\varphi\)
—
그래프의 최댓값
—
\(a + b\)
—

—

  1. 질문\(\sin x\)의 최댓값도 1, \(\cos x\)의 최댓값도 1입니다. 그러면 \(\sin x + \cos x\)의 최댓값은 2일까요? 두 그래프를 더한 모양은 어떤 곡선일까요?
  2. 복원덧셈정리 \(\sin(x + \varphi) = \sin x \cos \varphi + \cos x \sin \varphi\). \(y = r \sin(x + \varphi)\)는 \(y = \sin x\)를 세로로 \(r\)배 늘리고 \(x\)축 방향으로 \(-\varphi\)만큼 옮긴 그래프입니다.
  3. 설명\(r \sin(x + \varphi) = (r \cos \varphi) \sin x + (r \sin \varphi) \cos x\)이므로, \(a = r \cos \varphi\), \(b = r \sin \varphi\)가 되도록 \(r\), \(\varphi\)를 잡으면 \(a \sin x + b \cos x = r \sin(x + \varphi)\)입니다. 여기서 \(r = \sqrt{a^2 + b^2}\), \(\cos \varphi = \frac{a}{r}\), \(\sin \varphi = \frac{b}{r}\)입니다. 곧 점 \((a, b)\)를 좌표평면에 찍었을 때 원점까지의 거리가 \(r\), 동경이 이루는 각이 \(\varphi\)입니다. 그래서 합은 주기가 \(2\pi\)인 사인 곡선이고, 최댓값은 \(r\), 최솟값은 \(-r\)입니다. 이렇게 바꾸는 것을 삼각함수의 합성이라고 합니다.
  4. 연결주기가 같은 두 진동을 더하면 같은 주기의 진동 하나가 됩니다. 소리나 교류 전압처럼 같은 진동수의 파동이 겹칠 때 진폭이 \(\sqrt{a^2 + b^2}\)로 정해지는 것도 이 계산입니다.
  5. 적용\(\sin x + \cos x\)에서 그래프의 최댓값을 읽고 \(a + b\)와 비교하세요. \(3 \sin x + 4 \cos x\)의 최댓값은 얼마인가요? \(b\)를 음수로 바꾸면 오른쪽 위 그림의 점과 \(\varphi\)는 어디로 가나요? 최댓값이 나오는 \(x\)는 \(\varphi\)와 어떤 관계인가요?
  6. 판단최댓값을 \(a + b\)로 계산하는 실수가 흔합니다. \(\sin x\)가 최대인 \(x\)와 \(\cos x\)가 최대인 \(x\)가 다르므로 두 최댓값이 한꺼번에 나오지 않습니다. 또 합성은 두 함수의 주기가 같을 때만 됩니다. \(\sin x + \cos 2x\)는 사인 곡선 하나로 바꿀 수 없습니다.
