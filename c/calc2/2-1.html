지수·로그함수의 극한과 미분

미적분Ⅰ에서는 다항함수만 미분했습니다. 이 절에서는 지수함수와 로그함수를 미분합니다. 먼저 (1 + h)1/h의 극한으로 새로운 수 e를 정의하고, 밑이 e인 자연로그 ln x를 도입합니다. 그러면 ex는 도함수가 자기 자신인 함수가 되고, ln x의 도함수는 1/x가 됩니다. 다른 밑의 지수·로그함수는 ln a를 곱하거나 나누어 처리합니다.

h = 1/n로 놓으면 (1 + h)1/h = (1 + 1/n)n입니다. 그림을 가로로 끌어도 h가 바뀝니다. e = 2.718281828…

  1. 질문연이율 100%를 1년에 n번 나누어 복리로 주면 원금 1은 1년 뒤 (1 + 1/n)n이 됩니다. n을 한없이 키우면 원리합계도 한없이 커질까요?
  2. 복원limh→0는 h = 0에서의 값이 아니라, h가 0에 한없이 가까워질 때 값이 다가가는 곳입니다. 로그에서는 loga Mk = k loga M, loga a = 1입니다.
  3. 설명h → 0일 때 (1 + h)1/h은 한 값 2.71828…에 수렴합니다. 이 값을 e로 나타냅니다. e = limh→0 (1 + h)1/h = limn→∞ (1 + 1/n)n이고, e는 무리수입니다. 밑이 e인 로그 loge x를 자연로그라 하고 ln x로 씁니다. 그러면 ln(1 + h)/h = ln (1 + h)1/h → ln e = 1입니다. 또 eh − 1 = t로 놓으면 h = ln(1 + t)이고, h → 0일 때 t → 0이므로 (eh − 1)/h = t/ln(1 + t) → 1입니다. 같은 방법으로 a > 0, a ≠ 1일 때 (ah − 1)/h → ln a, loga(1 + h)/h → 1/ln a입니다.
  4. 연결(eh − 1)/h는 곡선 y = ex 위의 점 (0, 1)에서 그은 할선의 기울기입니다. 그래서 이 극한이 1이라는 것은 y = ex의 x = 0에서의 접선의 기울기가 1이라는 뜻입니다. 이 사실에서 ex와 ln x의 도함수가 나옵니다.
  5. 적용'h ÷ 10'을 여러 번 누르며 e와의 차이가 어떻게 줄어드는지 보세요. h가 10분의 1이 되면 차이는 대략 얼마가 되나요? 부호를 바꾸어 h < 0에서도 같은 값으로 가는지 확인하세요. 아래 두 칸의 값은 어디로 가나요?
  6. 판단"밑 1 + h가 1로 가니까 1을 몇 번 곱해도 1"이라는 추론은 틀립니다. 밑이 1로 가는 동안 지수 1/h는 한없이 커지므로, 이런 1∞ 꼴은 값이 미리 정해지지 않습니다. 또 h = 0을 넣을 수는 없으므로 그래프에서 x = 0은 빈 점입니다. e는 함숫값이 아니라 극한값입니다.

접선의 기울기는 아주 작은 h(0.00001)로 잰 할선의 기울기입니다. 점 P는 그림을 가로로 끌어도 움직입니다.

  1. 질문지수함수 y = ax는 높을수록 가파릅니다. 접선의 기울기와 높이 사이에는 어떤 관계가 있을까요? 기울기가 높이와 꼭 같은 밑도 있을까요?
  2. 복원도함수는 f′(x) = limh→0 {f(x + h) − f(x)}/h입니다. 앞에서 limh→0 (eh − 1)/h = 1, limh→0 (ah − 1)/h = ln a를 얻었습니다.
  3. 설명{ax+h − ax}/h = ax · (ah − 1)/h입니다. ax는 h와 관계없으므로 극한을 취하면 (ax)′ = ax ln a입니다. 곧 어느 점에서나 기울기 ÷ 높이가 같은 값 ln a입니다. ln e = 1이므로 밑이 e이면 (ex)′ = ex, 기울기가 높이와 같습니다.
  4. 연결변화율이 지금의 양에 비례하는 현상, 예를 들어 세균의 증식이나 방사성 붕괴가 지수함수로 표현되는 까닭이 여기에 있습니다. 이 성질 때문에 미적분에서는 밑이 e인 지수함수를 주로 씁니다.
  5. 적용밑을 2로 두고 점 P를 여러 곳으로 옮겨 보세요. 기울기 ÷ 높이는 바뀌나요? 그 값은 ln 2와 같나요? 이번에는 밑을 움직여 기울기 ÷ 높이가 1이 되는 a를 찾아보세요. 그 값은 어떤 수에 가깝나요?
  6. 판단(ax)′을 x·ax−1로 쓰는 실수가 흔합니다. 거듭제곱 공식 (xn)′ = nxn−1은 밑이 변수이고 지수가 상수일 때의 공식입니다. 지수함수는 반대로 밑이 상수이고 지수가 변수입니다.

접선의 기울기는 아주 작은 h(0.00001)로 잰 할선의 기울기입니다. 점 P는 그림을 가로로 끌어도 움직입니다.

  1. 질문y = ln x는 x가 커질수록 점점 완만해집니다. 접선의 기울기는 x와 어떤 관계로 줄어들까요?
  2. 복원limt→0 ln(1 + t)/t = 1이었습니다. 로그의 성질 ln M − ln N = ln(M/N)과 밑 변환 공식 loga x = ln x/ln a도 씁니다.
  3. 설명x > 0일 때 {ln(x + h) − ln x}/h = (1/x) · ln(1 + h/x)/(h/x)입니다. h → 0이면 t = h/x → 0이므로 뒤의 분수는 1로 갑니다. 그래서 (ln x)′ = 1/x입니다. 밑 변환 공식으로 (loga x)′ = 1/(x ln a)입니다. 또 x < 0이면 ln|x| = ln(−x)이고 그래프가 ln x를 y축에 대칭시킨 것이므로, (ln|x|)′ = 1/x가 x ≠ 0인 모든 곳에서 성립합니다.
  4. 연결x × 기울기가 일정하다는 것은 x를 몇 배로 늘리든 ln x가 같은 양만큼 늘어난다는 로그의 성질과 같은 이야기입니다. 1/x는 미적분Ⅰ의 거듭제곱 공식으로는 얻을 수 없던 도함수입니다. 적분에서 ∫(1/x)dx = ln|x| + C로 다시 만납니다.
  5. 적용ln x에서 점 P를 옮기며 x × 기울기를 보세요. 어떤 값으로 일정한가요? log2 x로 바꾸면 그 값은 무엇이 되고, 1/ln 2와 비교하면 어떤가요? ln|x|에서 P를 음수 쪽으로 옮기면 기울기의 부호는 어떻게 되나요?
  6. 판단(ln|x|)′을 1/|x|로 쓰는 실수가 흔합니다. x < 0인 쪽에서는 x가 커질수록 그래프가 내려가므로 기울기가 음수입니다. 또 ln x는 x > 0에서만 정의되므로 1/x라는 식이 음수에서도 계산된다고 해서 ln x의 도함수가 음수 쪽에 있는 것은 아닙니다.
