등비수열의 극한

원금이 매년 1.05배가 되는 예금과 매번 절반씩 남기는 약 성분은 모두 등비수열입니다. 하나는 한없이 커지고 다른 하나는 0으로 줄어듭니다. 이 절에서는 공비 r의 값에 따라 등비수열 {rn}이 어디로 가는지 판정하고, 수렴할 때 그 극한값을 구합니다. 밑이 다른 거듭제곱이 섞인 식의 극한도 같은 원리로 구합니다.

아래 수직선에는 지금까지 고른 r가 판정 색으로 쌓입니다. 초록은 0에 수렴, 노랑은 1에 수렴, 빨강은 양의 무한대로 발산, 회색은 진동입니다.

  1. 질문0.9n과 1.1n은 공비가 0.2밖에 차이 나지 않습니다. 그런데 극한은 전혀 다릅니다. 공비 r의 어느 범위에서 등비수열 {rn}이 수렴할까요?
  2. 복원첫째항이 a, 공비가 r인 등비수열의 일반항은 an = arn−1입니다. 수열은 극한값 둘레의 띠에 끝까지 머물 때 수렴하고, 그렇지 않으면 양의 무한대·음의 무한대로 발산하거나 진동합니다.
  3. 설명등비수열 {rn}의 수렴, 발산은 다음과 같습니다. ① r > 1이면 lim rn = ∞ (발산) ② r = 1이면 lim rn = 1 (수렴) ③ −1 < r < 1이면 lim rn = 0 (수렴) ④ r ≤ −1이면 진동 (발산). 따라서 {rn}이 수렴할 조건은 −1 < r ≤ 1입니다. ①은 r = 1 + h (h > 0)로 두면 (1 + h)n ≥ 1 + nh이고, 1 + nh가 한없이 커지는 데서 나옵니다. ③은 |r| < 1이면 1/|r| > 1이므로 ①에서 1/|r|n → ∞, 곧 |r|n → 0입니다.
  4. 연결첫째항이 a인 등비수열 arn−1은 a ≠ 0이면 같은 조건 −1 < r ≤ 1에서 수렴합니다. rn → 0이라는 사실은 등비급수의 합 공식에서 부분합 a(1 − rn)/(1 − r)의 극한을 구할 때 바로 쓰입니다.
  5. 적용r를 −1.5에서 1.5까지 천천히 움직여 수직선을 채워 보세요. 색이 바뀌는 경계는 어디인가요? 경계 r = 1과 r = −1에서는 어떤 일이 일어나나요? r = 0.95와 r = −0.95에서 r30을 비교하고, 음수 공비에서 점이 0의 위아래를 번갈아 가는 이유를 설명해 보세요.
  6. 판단수렴 조건은 −1 < r < 1이 아니라 −1 < r ≤ 1입니다. r = 1이면 모든 항이 1인 상수수열이라 1에 수렴합니다. 반면 r = −1이면 −1, 1, −1, …로 진동합니다. 또 |r|가 1에 가까우면 0에 다가가는 속도가 느려서 처음 30개 항만으로는 수렴인지 알기 어렵습니다. 0.9930 ≈ 0.74입니다.

극한
—
  1. 질문(3n+1 + 2n)/(3n + 2n)은 분자와 분모가 모두 한없이 커집니다. 3n과 2n 가운데 어느 쪽이 극한값을 정할까요?
  2. 복원−1 < r < 1이면 lim rn = 0입니다. 분자와 분모가 모두 발산하는 분수식은 분모의 '가장 빨리 커지는 부분'으로 나누어 수렴하는 꼴로 바꾸었습니다.
  3. 설명밑이 다른 거듭제곱이 섞이면, 밑의 절댓값이 가장 큰 거듭제곱으로 분자와 분모를 나눕니다. 3n으로 나누면 (3 + (2/3)n)/(1 + (2/3)n)이 되고, 0 < 2/3 < 1이므로 (2/3)n → 0입니다. 그래서 극한값은 3/1 = 3입니다. 일반적으로 a > b > 0이면 bn/an = (b/a)n → 0이므로, 큰 밑의 거듭제곱 앞에 붙은 계수끼리의 비가 극한값이 됩니다.
  4. 연결이 방법은 ∞/∞ 꼴 다항식에서 최고차항으로 나눈 것과 같은 생각입니다. 다항식에서는 차수가 높은 항이, 거듭제곱에서는 밑이 큰 항이 결국 나머지를 압도합니다. 또 x가 들어간 lim (x2n+1 + 1)/(x2n + 1) 같은 식은 |x| < 1, |x| = 1, |x| > 1로 나누어 같은 방법으로 구합니다.
  5. 적용a = 3, b = 2에서 n을 30까지 옮기며 (2/3)n이 0에 가까워지는 것을 확인하세요. a와 b를 바꾸어 a < b로 만들면 극한은 왜 1이 되나요? a = b일 때 극한이 (a + 1)/2인 이유를 식으로 설명해 보세요. a = 4, b = 5처럼 두 밑이 가까우면 수렴이 느린 이유도 (작은 밑/큰 밑)n 값에서 찾아보세요.
  6. 판단작은 밑의 거듭제곱으로 나누면 (3/2)n처럼 발산하는 항이 남아 몫의 성질을 쓸 수 없습니다. 또 3n+1은 3 · 3n이므로, 나눈 뒤 남는 계수 3을 빠뜨리지 않아야 합니다. 22n처럼 지수에 계수가 붙으면 4n으로 고쳐 밑을 비교합니다.
