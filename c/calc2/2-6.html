매개변수 함수의 미분

원 위를 도는 점이나 굴러가는 바퀴 위의 한 점처럼, 움직이는 점의 위치는 시각 t에 대한 두 함수 x = f(t), y = g(t)로 나타내기 쉽습니다. 이렇게 매개변수로 나타낸 곡선은 y를 x의 식으로 고치기 어려울 때가 많습니다. 이 절에서는 식을 고치지 않고 dy/dt와 dx/dt의 비로 접선의 기울기를 구합니다. 다루는 곡선은 간단한 것으로 한정합니다.

화살표는 속도를 0.4배로 줄여 그렸습니다. 파란 화살표는 dx/dt, 주황 화살표는 dy/dt, 붉은 화살표는 두 성분을 합친 속도입니다. 점선은 접선입니다.

  1. 질문원 위를 도는 점의 위치가 x = 2cos t, y = 2sin t로 주어질 때, y를 x의 식으로 고치지 않고도 점에서의 접선의 기울기를 구할 수 있을까요?
  2. 복원기울기는 세로 변화량 ÷ 가로 변화량의 극한입니다. 합성함수의 미분법에 따르면 y가 x를 거쳐 t의 함수일 때 dy/dt = (dy/dx)(dx/dt)입니다.
  3. 설명x = f(t), y = g(t)처럼 두 변수를 제3의 변수 t로 나타낼 때 t를 매개변수라고 합니다. t가 Δt만큼 변할 때 Δy/Δx = (Δy/Δt)/(Δx/Δt)이므로, f, g가 미분가능하고 f′(t) ≠ 0이면 dy/dx = (dy/dt)/(dx/dt) = g′(t)/f′(t)입니다. 원에서는 dy/dx = 2cos t/(−2sin t) = −cot t입니다.
  4. 연결(dx/dt, dy/dt)는 움직이는 점의 속도입니다. 그래서 접선의 방향은 그 순간 점이 움직이는 방향과 같습니다. 바퀴 위의 한 점이 그리는 사이클로이드는 y를 x의 식으로 쓰기 어려워 이 방법이 특히 쓸모 있습니다.
  5. 적용원에서 t를 움직이며 접선이 수평이 되는 곳과 수직이 되는 곳을 찾으세요. 그때 dx/dt, dy/dt 가운데 어느 것이 0인가요? 사이클로이드에서 t를 0 가까이 보내면 접선은 어떻게 되나요? (t2, t3)에서 t = 0으로 가면 두 속도가 모두 0이 되는데, 넷째 칸은 어디로 가나요?
  6. 판단공식은 dx/dt ≠ 0일 때만 씁니다. dx/dt = 0이고 dy/dt ≠ 0이면 접선은 세로선이고 기울기가 없습니다. 둘 다 0이면 공식은 0/0이 되어 아무것도 알려 주지 않습니다. 이때는 t가 그 값에 가까워질 때 g′(t)/f′(t)의 극한을 따로 살핍니다. (t2, t3)에서는 3t/2 → 0입니다. 또 분자와 분모를 바꾸어 (dx/dt)/(dy/dt)로 쓰는 실수에 주의합니다.

2.6.2

화살표는 각 매개변수로 잰 속도 (dx/dt, dy/dt)를 0.15배로 줄여 그렸습니다. 파랑 A, 주황 B, 붉은색 C입니다. 점 P는 그림을 가로로 끌어도 움직입니다.

  1. 질문A: x = t, y = t2, B: x = 2t, y = 4t2, C: x = t3, y = t6은 모두 같은 곡선을 그립니다. 같은 점에서 세 방법으로 구한 dy/dx도 같을까요?
  2. 복원매개변수로 나타낸 함수에서 dx/dt ≠ 0이면 dy/dx = (dy/dt)/(dx/dt)입니다. y = x2의 도함수는 2x입니다.
  3. 설명세 식에서 t를 없애면 모두 y = x2이 됩니다. 이렇게 매개변수를 없애 x, y의 관계식을 얻는 것을 매개변수의 소거라고 합니다. 매개변수는 같은 길을 어떤 빠르기로 지나가는지를 정할 뿐이므로, dx/dt와 dy/dt는 매개변수마다 다르지만 두 값이 같은 비율로 커지고 작아집니다. 예를 들어 B에서는 dx/dt = 2, dy/dt = 8t이고 t = x/2이므로 dy/dx = 4t = 2x입니다. 그래서 접선의 기울기는 곡선이 정하는 값이고 매개변수를 고르는 방법과 상관없습니다.
  4. 연결매개변수를 쉽게 소거할 수 있으면 y를 x의 식으로 고쳐 미분해도 되고, 소거하기 어려우면 (dy/dt)/(dx/dt)를 씁니다. 두 방법의 결과는 같으므로 하나로 구하고 다른 하나로 검산할 수 있습니다.
  5. 적용P를 옮기며 세 줄의 dx/dt, dy/dt와 dy/dx를 비교하세요. 화살표의 길이는 다른데 방향은 어떤가요? P를 x = 0으로 옮기면 C의 줄은 어떻게 되나요? 그때도 접선은 있나요?
  6. 판단C에서 x = 0이면 dx/dt = dy/dt = 0이라 공식이 0/0이 됩니다. 그렇다고 접선이 없는 것은 아닙니다. 곡선은 같은 y = x2이고 원점의 접선은 x축입니다. 매개변수의 속도가 0이 된 것은 그 순간 점이 멈춘 것일 뿐, 곡선의 모양이 바뀐 것이 아닙니다. 또 매개변수를 소거할 때는 t의 범위에 따라 x의 범위가 제한될 수 있습니다. x = t2, y = t4이면 y = x2의 x ≥ 0인 부분만 그립니다.
