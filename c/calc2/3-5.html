넓이

미적분Ⅰ에서는 다항함수의 그래프로 둘러싸인 넓이를 구했습니다. 이 절에서는 앞에서 배운 적분법을 써서 지수함수, 로그함수, 삼각함수의 그래프로 둘러싸인 넓이를 구합니다. 같은 도형을 세로로 자를지 가로로 자를지에 따라 계산이 얼마나 쉬워지는지 비교하고, 두 곡선이 서로 엇갈릴 때는 교점에서 구간을 나누어야 하는 까닭을 확인합니다.

먼저 알면 좋은 것 정적분과 넓이두 곡선 사이의 넓이부분적분법역함수

3.5.1

세로로 자를까, 가로로 자를까?

곡선으로 둘러싸인 넓이 · 조작

—

띠 넓이의 합
—
정확한 넓이
—

띠의 길이는 띠 가운데에서 잰 값입니다. 세로 띠는 (위 곡선 − 아래 곡선), 가로 띠는 (오른쪽 곡선 − 왼쪽 곡선)입니다.

  1. 질문\(y = \ln x\), \(x\)축, 직선 \(x = e\)로 둘러싸인 도형의 넓이를 구하려면 꼭 \(x\)에 대해 적분해야 할까요?
  2. 복원\([a, b]\)에서 \(f(x) \ge g(x)\)이면 두 곡선 사이의 넓이는 \(\int_a^b \{f(x) - g(x)\}\,dx\)입니다. \(y = \ln x\)는 \(x = e^y\)와 같은 곡선입니다.
  3. 설명세로 띠는 너비 \(dx\), 길이 (위 − 아래)이므로 넓이는 \(\int_1^e \ln x\,dx\)이고, 부분적분으로 \([x \ln x - x]_1^e = 1\)입니다. 가로 띠는 높이 \(dy\), 길이 (오른쪽 − 왼쪽) = \(e - e^y\)이므로 \(\int_c^d \{(\text{오른쪽 } x) - (\text{왼쪽 } x)\}\,dy\) = \(\int_0^1 (e - e^y)\,dy = e - (e - 1) = 1\)입니다. 같은 도형이므로 값이 같고, 둘째 방법은 지수함수만 적분하면 됩니다. 둘째 보기는 세로로 자르면 \(x = 2\)에서 아래 경계가 \(x\)축에서 직선으로 바뀌어 두 조각으로 나누어야 하지만, 가로로 자르면 왼쪽은 늘 \(x = y^2\), 오른쪽은 늘 \(x = y + 2\)이므로 한 번에 됩니다.
  4. 연결\(y\)에 대해 적분하려면 경계 곡선을 \(x\) = (\(y\)의 식)으로 나타내야 하므로 역함수가 필요합니다. 다음 절의 부피에서도 '어느 방향으로 자를지'를 먼저 정하고, 자른 조각의 넓이를 적분합니다.
  5. 적용두 보기에서 방향을 바꾸어 띠를 늘려 보세요. 띠 넓이의 합이 같은 값으로 다가가나요? 둘째 보기의 세로 띠에서 아래 경계가 바뀌는 곳은 어디인가요? 띠가 1개일 때 어느 방향의 어림이 더 정확한가요?
  6. 판단가로 띠에서 '위 − 아래'를 쓰면 안 됩니다. \(y\)에 대해 적분할 때는 \(x\)값의 차인 '오른쪽 − 왼쪽'이 띠의 길이입니다. 또 세로 띠에서 경계가 중간에 바뀌는데도 한 식으로 적분하면, 도형 밖의 부분을 더하거나 빼게 됩니다.

3.5.2

두 곡선이 엇갈리면 넓이는 어떻게 구할까?

두 곡선 사이의 넓이 · 조작
\(\int_0^b \{f(x) - g(x)\}\,dx\)
—
넓이 \(\int_0^b |f(x) - g(x)|\,dx\)
—
구간 안의 교점
—

\(f\)는 첫째 곡선, \(g\)는 둘째 곡선입니다. 그림을 끌어도 \(b\)가 바뀝니다.

  1. 질문\(0 \le x \le \pi\)에서 \(y = \sin x\)와 \(y = \cos x\) 사이의 넓이를 \(\int_0^\pi (\sin x - \cos x)\,dx\) 하나로 구해도 될까요?
  2. 복원\(f(x) \ge g(x)\)인 구간에서 두 곡선 사이의 넓이는 \(\int \{f(x) - g(x)\}\,dx\)입니다. \(\int \sin x\,dx = -\cos x + C\), \(\int \cos x\,dx = \sin x + C\)입니다.
  3. 설명두 곡선 사이의 넓이는 어느 쪽이 위에 있든 \(\int_a^b |f(x) - g(x)|\,dx\)입니다. 절댓값을 풀려면 교점에서 구간을 나눕니다. \(\sin x = \cos x\)인 \(x = \frac{\pi}{4}\)에서 위아래가 바뀌므로 \(\int_0^{\frac{\pi}{4}} (\cos x - \sin x)\,dx + \int_{\frac{\pi}{4}}^\pi (\sin x - \cos x)\,dx = (\sqrt{2} - 1) + (1 + \sqrt{2}) = 2\sqrt{2}\)입니다. 나누지 않고 한 번에 적분하면 위아래가 바뀐 부분이 빼져서 2가 됩니다.
  4. 연결부호 있는 적분 \(\int(f - g)\,dx\)도 쓸모가 있습니다. 다음 절들의 변위처럼 '얼마나 앞섰는지'를 셀 때는 빼지는 것이 맞습니다. 넓이, 움직인 거리처럼 '얼마나 되는지'를 셀 때는 절댓값을 씌웁니다.
  5. 적용첫째 보기에서 \(b\)를 \(\frac{\pi}{4}\)(약 0.79)보다 작게 하면 두 값이 같은지, 크게 하면 언제부터 달라지는지 보세요. \(b = 2\pi\)(약 6.28)이면 부호 있는 적분은 얼마인가요? 둘째 보기의 교점 \(\frac{\pi}{3}\)(약 1.05)을 찾고, \(b = \pi\)에서 두 값 2와 \(\frac{5}{2}\)를 확인하세요.
  6. 판단"넓이 = 위 곡선의 적분 − 아래 곡선의 적분"은 위아래가 끝까지 바뀌지 않을 때만 맞습니다. 교점이 구간 안에 있는지 먼저 확인하세요. 또 \(x\)축과의 교점이 아니라 두 곡선의 교점에서 나누어야 합니다. 두 곡선이 모두 \(x\)축 아래로 내려가도 차 \(f - g\)의 부호만 보면 됩니다.
