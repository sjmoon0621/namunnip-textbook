넓이

미적분Ⅰ에서는 다항함수의 그래프로 둘러싸인 넓이를 구했습니다. 이 절에서는 앞에서 배운 적분법을 써서 지수함수, 로그함수, 삼각함수의 그래프로 둘러싸인 넓이를 구합니다. 같은 도형을 세로로 자를지 가로로 자를지에 따라 계산이 얼마나 쉬워지는지 비교하고, 두 곡선이 서로 엇갈릴 때는 교점에서 구간을 나누어야 하는 까닭을 확인합니다.

포물선 \(y = x^2\)과 직선 \(y = 2x\)는 원점과 점 \((2, 4)\)에서 만나 렌즈 모양의 영역을 만든다. 이 영역의 넓이는 어떻게 구할까? 또 \(y = \ln x\)처럼 \(x\)로 적분하기 불편한 곡선은 가로로 잘라서 \(y\)로 적분할 수도 있을까?

먼저 알아야 할 것정적분과 넓이, 두 곡선 사이의 넓이(미적분Ⅰ), 부분적분법(부분적분법), 역함수.

3.5.1두 곡선 사이의 넓이

구간 \([a, b]\)에서 \(f(x) \ge g(x)\)이면 두 곡선 사이에 세로로 가는 막대를 세울 수 있다. 막대의 높이는 \(f(x) - g(x)\), 폭은 \(dx\)이므로 넓이는 이 막대들을 모두 더한 정적분이다.

정리 3.5.1 두 곡선 사이의 넓이

\[S = \int_a^b |f(x) - g(x)|\,dx\] 두 곡선이 구간 안에서 엇갈리면 교점에서 구간을 나누어 위아래를 바꾸어 계산한다.

\(y = x^2\)과 \(y = ax\)의 교점은 \(x^2 = ax\)에서 \(x = 0, a\)이고, 그 사이에서 직선이 위에 있다. 넓이는 \(\int_0^a (ax - x^2)\,dx = \dfrac{a^3}{2} - \dfrac{a^3}{3} = \dfrac{a^3}{6}\)이다. 처음 질문처럼 \(a = 2\)이면 \(\dfrac{8}{6} = \dfrac{4}{3}\)이다. 그림 1에서 \(a\)를 두 배로 키우면 넓이는 8배가 된다.1

3.5.2가로로 자르기

곡선이 \(x = h(y)\) 꼴로 주어지거나 역함수가 다루기 쉬우면, 영역을 가로로 잘라 \(y\)에 대해 적분하는 것이 편하다. 곡선 \(x = h(y)\)와 \(y\)축, 두 직선 \(y = c\), \(y = d\)로 둘러싸인 넓이는 \(\int_c^d |h(y)|\,dy\)이다.

예를 들어 \(y = \ln x\)와 \(x\)축, 직선 \(x = e\)로 둘러싸인 넓이는 세로로 자르면 \(\int_1^e \ln x\,dx\)로 부분적분이 필요하다. 가로로 자르면 \(x = e^y\)이므로, 높이 \(y\)에서 막대의 길이는 \(e - e^y\)이고 넓이는 \(\int_0^1 (e - e^y)\,dy = e - (e - 1) = 1\)로 간단하다.

3.5.3예제 하나를 끝까지

예제 3.5.2

두 곡선 \(y = \sin x\)와 \(y = \cos x\), 그리고 두 직선 \(x = 0\), \(x = \pi\)로 둘러싸인 넓이를 구하여라.

두 곡선은 \(\sin x = \cos x\)에서 \(x = \dfrac{\pi}{4}\)에서 엇갈린다. \(0 \le x \le \dfrac{\pi}{4}\)에서는 \(\cos x \ge \sin x\), \(\dfrac{\pi}{4} \le x \le \pi\)에서는 \(\sin x \ge \cos x\)이다.

\[S = \int_0^{\pi/4} (\cos x - \sin x)\,dx + \int_{\pi/4}^{\pi} (\sin x - \cos x)\,dx\] 첫째 적분은 \(\Big[\sin x + \cos x\Big]_0^{\pi/4} = \sqrt{2} - 1\), 둘째 적분은 \(\Big[-\cos x - \sin x\Big]_{\pi/4}^{\pi} = 1 + \sqrt{2}\)이다. 넓이는 \(2\sqrt{2} \approx 2.83\)이다. 엇갈리는 점에서 나누지 않고 한 번에 적분하면 위아래가 상쇄되어 \(\int_0^{\pi}(\sin x - \cos x)\,dx = 2\)라는 틀린 값이 나온다.

아래 탐구 카드에서 세로와 가로로 자르는 방법을 비교하고, 엇갈리는 두 곡선의 넓이를 직접 구해 보자.

  1. 포물선과 직선으로 둘러싸인 넓이는 언제나 \(\dfrac{|k|}{6}(\beta - \alpha)^3\)이다(\(k\)는 포물선의 이차항 계수, \(\alpha\), \(\beta\)는 교점의 \(x\)좌표). 아르키메데스가 이미 기하로 구한 결과이다.
마무리

두 곡선 사이의 넓이는 위 곡선에서 아래 곡선을 뺀 막대 높이를 적분하여 구하고, 곡선이 엇갈리면 교점에서 구간을 나눈다. 계산이 쉬우면 가로로 잘라 \(y\)에 대해 적분한다. 그래서 처음 질문의 \(y = x^2\)과 \(y = 2x\) 사이 렌즈 모양의 넓이는 \(\int_0^2 (2x - x^2)dx = \frac{4}{3}\)이다.

띠의 길이는 띠 가운데에서 잰 값이다. 세로 띠는 (위 곡선 − 아래 곡선), 가로 띠는 (오른쪽 곡선 − 왼쪽 곡선)이다.

  1. 질문\(y = \ln x\), \(x\)축, 직선 \(x = e\)로 둘러싸인 도형의 넓이를 구하려면 꼭 \(x\)에 대해 적분해야 할까?
  2. 복원\([a, b]\)에서 \(f(x) \ge g(x)\)이면 두 곡선 사이의 넓이는 \(\int_a^b \{f(x) - g(x)\}\,dx\)이다. 그리고 \(y = \ln x\)는 \(x = e^y\)와 같은 곡선이다.
  3. 설명세로 띠는 너비 \(dx\), 길이 (위 − 아래)이므로 넓이는 \(\int_1^e \ln x\,dx\)이고, 부분적분으로 \([x \ln x - x]_1^e = 1\)이다. 가로 띠는 높이 \(dy\), 길이 (오른쪽 − 왼쪽) = \(e - e^y\)이므로 넓이는 \(\int_c^d \{(\text{오른쪽 } x) - (\text{왼쪽 } x)\}\,dy\) = \(\int_0^1 (e - e^y)\,dy = e - (e - 1) = 1\)이다. 같은 도형이므로 값이 같고, 둘째 방법은 지수함수만 적분하면 된다. 둘째 보기는 세로로 자르면 \(x = 2\)에서 아래 경계가 \(x\)축에서 직선으로 바뀌어 두 조각으로 나누어야 하지만, 가로로 자르면 왼쪽은 늘 \(x = y^2\), 오른쪽은 늘 \(x = y + 2\)이므로 한 번에 된다.
  4. 연결\(y\)에 대해 적분하려면 경계 곡선을 \(x\) = (\(y\)의 식)으로 나타내야 하므로 역함수가 필요하다. 다음 절의 부피에서도 어느 방향으로 자를지를 먼저 정하고, 자른 조각의 넓이를 적분한다.
  5. 적용두 보기에서 방향을 바꾸어 띠를 늘리며 띠 넓이의 합이 같은 값으로 다가가는지 보자. 그리고 둘째 보기의 세로 띠에서 아래 경계가 바뀌는 곳이 어디인지, 띠가 1개일 때 어느 방향의 어림이 더 정확한지 확인해 보자.
  6. 판단가로 띠에서 ‘위 − 아래’를 쓰면 안 되고, \(y\)에 대해 적분할 때는 \(x\)값의 차인 ‘오른쪽 − 왼쪽’이 띠의 길이이다. 또 세로 띠에서 경계가 중간에 바뀌는데도 한 식으로 적분하면, 도형 밖의 부분을 더하거나 빼게 된다.

두 곡선이 엇갈리면 넓이는 어떻게 구할까?

두 곡선 사이의 넓이 · 조작
\(\int_0^b \{f(x) - g(x)\}\,dx\)
—
넓이 \(\int_0^b |f(x) - g(x)|\,dx\)
—
구간 안의 교점
—

\(f\)는 첫째 곡선, \(g\)는 둘째 곡선이다. 그림을 끌어도 \(b\)가 바뀐다.

  1. 질문\(0 \le x \le \pi\)에서 \(y = \sin x\)와 \(y = \cos x\) 사이의 넓이를 \(\int_0^\pi (\sin x - \cos x)\,dx\) 하나로 구해도 될까?
  2. 복원\(f(x) \ge g(x)\)인 구간에서 두 곡선 사이의 넓이는 \(\int \{f(x) - g(x)\}\,dx\)이다. 그리고 \(\int \sin x\,dx = -\cos x + C\), \(\int \cos x\,dx = \sin x + C\)이다.
  3. 설명두 곡선 사이의 넓이는 어느 쪽이 위에 있든 \(\int_a^b |f(x) - g(x)|\,dx\)이고, 절댓값을 풀려면 교점에서 구간을 나눈다. \(\sin x = \cos x\)인 \(x = \frac{\pi}{4}\)에서 위아래가 바뀌므로 \(\int_0^{\frac{\pi}{4}} (\cos x - \sin x)\,dx + \int_{\frac{\pi}{4}}^\pi (\sin x - \cos x)\,dx = (\sqrt{2} - 1) + (1 + \sqrt{2}) = 2\sqrt{2}\)이다. 그런데 나누지 않고 한 번에 적분하면 위아래가 바뀐 부분이 빼져서 2가 된다.
  4. 연결부호 있는 적분 \(\int(f - g)\,dx\)도 쓸모가 있다. 다음 절들의 변위처럼 얼마나 앞섰는지를 셀 때는 빼지는 것이 맞고, 넓이나 움직인 거리처럼 얼마나 되는지를 셀 때는 절댓값을 씌운다.
  5. 적용첫째 보기에서 \(b\)를 \(\frac{\pi}{4}\)(약 0.79)보다 작게 하면 두 값이 같은지, 크게 하면 언제부터 달라지는지 보고, \(b = 2\pi\)(약 6.28)일 때 부호 있는 적분이 얼마인지 구해 보자. 그리고 둘째 보기의 교점 \(\frac{\pi}{3}\)(약 1.05)을 찾고, \(b = \pi\)에서 두 값 2와 \(\frac{5}{2}\)를 확인해 보자.
  6. 판단‘넓이 = 위 곡선의 적분 − 아래 곡선의 적분’은 위아래가 끝까지 바뀌지 않을 때만 맞으므로, 교점이 구간 안에 있는지 먼저 확인해야 한다. 또 \(x\)축과의 교점이 아니라 두 곡선의 교점에서 나누어야 하고, 두 곡선이 모두 \(x\)축 아래로 내려가도 차 \(f - g\)의 부호만 보면 된다.
