방정식과 부등식

\(\ln x = kx\)나 \(e^x = x + 2\) 같은 방정식은 식을 변형해 근을 구할 수 없습니다. 그래도 근이 몇 개인지, 대략 어디에 있는지는 그래프로 알 수 있습니다. 이 절에서는 앞 절에서 그린 개형을 써서 방정식의 실근의 개수를 세고, 차의 함수의 최솟값으로 부등식이 늘 성립하는지 판단합니다.

근은 이분법으로 수치 계산한 값입니다. 근이 그림 밖\((x > 10)\)에 있으면 표시만 하고 그리지 않습니다.

  1. 질문방정식 \(\ln x = kx\)는 식을 변형해 풀 수 없습니다. 그래도 \(k\)의 값에 따라 실근이 몇 개인지 알 수 있을까요?
  2. 복원방정식 \(f(x) = g(x)\)의 실근은 두 그래프의 교점의 \(x\)좌표입니다. 앞 절에서 \(y = \frac{\ln x}{x}\)는 \(x = e\)에서 최댓값 \(\frac{1}{e}\)를 갖고, \(x \to 0^+\)이면 \(-\infty\)로, \(x \to \infty\)이면 0으로 간다는 것을 보았습니다.
  3. 설명위 그림처럼 곡선과 기울어진 직선의 교점을 세면 \(k\)가 바뀔 때마다 직선이 돌아가서 판단하기 어렵습니다. \(x > 0\)이므로 양변을 \(x\)로 나누어 \(\frac{\ln x}{x} = k\)로 바꿉니다. 이렇게 \(k\)를 한쪽으로 떼어 내면 고정된 곡선과 가로선 \(y = k\)의 교점만 세면 됩니다. 결과는 \(k \le 0\)이면 1개, \(0 < k < \frac{1}{e}\)이면 2개, \(k = \frac{1}{e}\)이면 1개, \(k > \frac{1}{e}\)이면 0개입니다.
  4. 연결근이 2개에서 0개로 바뀌는 경계 \(k = \frac{1}{e}\)에서 직선 \(y = \frac{x}{e}\)는 곡선 \(y = \ln x\)에 점 \((e, 1)\)에서 접합니다. 근의 개수가 바뀌는 순간은 두 그래프가 접하는 순간이고, 이는 접선 문제와 같은 계산입니다.
  5. 적용\(k\)를 움직이며 위아래 그림의 교점이 늘 같은 \(x\)에서 생기는지 확인하세요. 근의 개수가 바뀌는 \(k\)를 모두 찾으세요. \(k = 0.05\)처럼 작은 양수에서는 위 그림에 교점이 하나만 보이는데 셋째 칸은 2입니다. 나머지 근은 어디에 있나요?
  6. 판단양변을 \(x\)로 나눌 수 있었던 것은 정의역이 \(x > 0\)이기 때문입니다. \(x\)가 0이나 음수가 될 수 있으면 나누기 전에 따로 확인해야 합니다. 또 그림의 범위 안에서만 교점을 세면 멀리 있는 근을 놓칩니다. 끝에서의 극한을 함께 봅니다.

2.10.2

\(e^x \ge kx\)가 모든 \(x\)에서 성립하려면 \(k\)는 얼마까지 될까?

부등식 · 조작
\(h\)의 최솟값
—
최소가 되는 \(x\)
—
모든 \(x\)에서 성립?
—

—

아래 그림의 주황 점은 \(h\)가 가장 낮은 곳입니다. \(h\)가 \(x\)축 아래로 내려가는 곳이 있으면 부등식이 깨집니다.

  1. 질문모든 실수 \(x\)에 대하여 \(e^x \ge kx\)가 성립하도록 하는 \(k\)의 범위는 무엇일까요? \(k\)를 키우면 언젠가 직선이 곡선을 뚫고 올라갈 것입니다.
  2. 복원'모든 \(x\)에서 \(f(x) \ge g(x)\)'는 '\(h(x) = f(x) - g(x) \ge 0\)'과 같습니다. \(h\)에 최솟값이 있으면 최솟값 \(\ge 0\)인지만 보면 됩니다.
  3. 설명\(h(x) = e^x - kx\)로 두면 \(h'(x) = e^x - k\)입니다. \(k > 0\)이면 \(x = \ln k\)에서 \(h'\)의 부호가 −에서 +로 바뀌므로 최솟값은 \(h(\ln k) = k(1 - \ln k)\)입니다. 이 값이 0 이상이려면 \(\ln k \le 1\), 곧 \(k \le e\)입니다. \(k = 0\)이면 \(e^x > 0\)이라 성립합니다. \(k < 0\)이면 \(x \to -\infty\)일 때 \(h(x) \to -\infty\)라 깨집니다. 따라서 답은 \(0 \le k \le e\)입니다.
  4. 연결\(k = e\)일 때 직선 \(y = ex\)는 곡선에 점 \((1, e)\)에서 접합니다. 아래로 볼록한 곡선은 접선보다 위에 있다는 사실과 같은 이야기입니다. 같은 방법으로 \(e^x \ge x + 1\)(점 \((0, 1)\)에서의 접선)과 \(\ln x \le x - 1\)(점 \((1, 0)\)에서의 접선)을 증명할 수 있습니다.
  5. 적용\(k\)를 키우며 셋째 칸이 '아니요'로 바뀌는 순간을 찾으세요. 그때 위 그림의 직선과 곡선은 어떤 관계인가요? \(k\)를 음수로 내리면 아래 그림의 어느 쪽에서 문제가 생기나요?
  6. 판단극솟값만 확인하고 끝내면 안 됩니다. \(k < 0\)이면 \(h' > 0\)이라 극값이 아예 없고, 왼쪽 끝에서 \(h\)가 한없이 작아집니다. 최솟값이 없는 함수는 끝에서의 극한까지 보아야 합니다. 또 \(\frac{e^x}{x} \ge k\)처럼 \(x\)로 나누면 \(x < 0\)일 때 부등호 방향이 바뀌므로 조심합니다.
