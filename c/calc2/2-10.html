본문

방정식 \(e^x = 3x\)는 근의 공식이 없어 정확한 근을 식으로 구할 수 없다. 그래도 근이 몇 개인지, 대략 어디쯤 있는지는 알고 싶다. 또 \(e^x \ge kx\)가 모든 실수 \(x\)에서 성립하도록 \(k\)를 최대한 크게 잡으면 얼마일까? 미분이 이런 물음에 어떻게 답할까?

먼저 알아야 할 것그래프의 개형(그래프의 개형), 함수의 최댓값과 최솟값(미적분Ⅰ), 접선의 방정식(여러 가지 곡선의 접선).

2.10.1방정식의 실근의 개수

방정식 \(f(x) = g(x)\)의 실근은 두 그래프 \(y = f(x)\), \(y = g(x)\)의 교점의 \(x\)좌표이다. 따라서 근을 직접 구하지 않아도 두 그래프를 그려 교점을 세면 실근의 개수를 알 수 있다. 문자 \(k\)가 들어 있으면 \(k\)만 따로 떼어 \(h(x) = k\) 꼴로 바꾸고, \(y = h(x)\)와 수평선 \(y = k\)의 교점을 세는 것이 편하다.

방법 2.10.1 실근의 개수 조사

방정식을 \(h(x) = k\) 꼴로 정리한다. \(h'(x)\)로 \(y = h(x)\)의 증감과 극값, 끝의 극한을 조사하여 그래프를 그린다. 수평선 \(y = k\)를 위아래로 움직이며 교점의 개수를 센다.

그림 1에서 \(k\)를 바꾸어 보자. \(k < 0\)이면 교점이 하나, \(0 \le k < e\)이면 직선이 곡선 아래를 지나 교점이 없고, \(k = e\)이면 한 점에서 접하며, \(k > e\)이면 두 점에서 만난다. 처음 질문의 \(e^x = 3x\)는 \(3 > e\)이므로 실근이 2개이다.1

2.10.2부등식의 증명

어떤 범위의 모든 \(x\)에서 \(f(x) \ge g(x)\)를 보이려면 \(h(x) = f(x) - g(x)\)로 놓고, 그 범위에서 \(h(x)\)의 최솟값이 0 이상임을 보인다. 최솟값은 \(h'(x)\)로 증감을 조사하여 구한다.

2.10.3예제 하나를 끝까지

예제 2.10.2

모든 실수 \(x\)에 대하여 \(e^x \ge x + 1\)임을 증명하여라. 또 \(x > 0\)일 때 \(e^x \ge kx\)가 항상 성립하도록 하는 \(k\)의 최댓값을 구하여라.

\(h(x) = e^x - x - 1\)이라 하면 \(h'(x) = e^x - 1\)이다. \(x < 0\)에서 \(h' < 0\), \(x > 0\)에서 \(h' > 0\)이므로 \(h(x)\)는 \(x = 0\)에서 최솟값 \(h(0) = 0\)을 갖는다. 따라서 모든 \(x\)에서 \(h(x) \ge 0\), 곧 \(e^x \ge x + 1\)이다. 등호는 \(x = 0\)일 때 성립하며, 직선 \(y = x + 1\)은 \(y = e^x\)의 \(x = 0\)에서의 접선이다.

\(x > 0\)이면 \(e^x \ge kx \iff \dfrac{e^x}{x} \ge k\)이다. \(p(x) = \dfrac{e^x}{x}\)의 도함수는 \(\dfrac{e^x(x - 1)}{x^2}\)이므로 \(x = 1\)에서 최솟값 \(p(1) = e\)를 갖는다. 모든 \(x > 0\)에서 \(p(x) \ge k\)이려면 \(k \le e\)이어야 하므로 \(k\)의 최댓값은 \(e\)이다.

아래 탐구 카드에서 풀 수 없는 방정식의 근의 개수와, 부등식이 항상 성립하는 조건을 직접 조사해 보자.

  1. 근의 대략적인 위치는 사잇값 정리로 좁힐 수 있다. \(h(x) = e^x - 3x\)에서 \(h(0) = 1 > 0\), \(h(1) = e - 3 < 0\), \(h(2) = e^2 - 6 > 0\)이므로 두 근은 각각 \((0, 1)\)과 \((1, 2)\)에 있다.
마무리

방정식의 실근의 개수는 두 그래프의 교점의 개수이며, 문자를 분리하여 \(y = h(x)\)와 수평선의 교점을 세면 편하다. 부등식은 차를 함수로 놓고 최솟값이 0 이상임을 보여 증명한다. 그래서 처음 질문의 \(e^x = 3x\)는 근을 구하지 못해도 실근이 2개임을 알 수 있고, \(e^x \ge kx\)가 \(x > 0\)에서 늘 성립하는 \(k\)의 최댓값은 \(e\)이다.

근은 이분법으로 수치 계산한 값이다. 근이 그림 밖\((x > 10)\)에 있으면 표시만 하고 그리지 않는다.

  1. 질문방정식 \(\ln x = kx\)는 식을 변형해 풀 수 없다. 그래도 \(k\)의 값에 따라 실근이 몇 개인지 알 수 있을까?
  2. 복원방정식 \(f(x) = g(x)\)의 실근은 두 그래프의 교점의 \(x\)좌표이다. 그리고 앞 절에서 \(y = \frac{\ln x}{x}\)는 \(x = e\)에서 최댓값 \(\frac{1}{e}\)를 갖고, \(x \to 0^+\)이면 \(-\infty\)로, \(x \to \infty\)이면 0으로 간다는 것을 보았다.
  3. 설명위 그림처럼 곡선과 기울어진 직선의 교점을 세면 \(k\)가 바뀔 때마다 직선이 돌아가서 판단하기 어렵다. 그런데 \(x > 0\)이므로 양변을 \(x\)로 나누어 \(\frac{\ln x}{x} = k\)로 바꾸면, \(k\)를 한쪽으로 떼어 낸 셈이어서 고정된 곡선과 가로선 \(y = k\)의 교점만 세면 된다. 결과는 \(k \le 0\)이면 1개, \(0 < k < \frac{1}{e}\)이면 2개, \(k = \frac{1}{e}\)이면 1개, \(k > \frac{1}{e}\)이면 0개이다.
  4. 연결근이 2개에서 0개로 바뀌는 경계 \(k = \frac{1}{e}\)에서 직선 \(y = \frac{x}{e}\)는 곡선 \(y = \ln x\)에 점 \((e, 1)\)에서 접한다. 즉 근의 개수가 바뀌는 순간은 두 그래프가 접하는 순간이고, 이는 접선 문제와 같은 계산이다.
  5. 적용\(k\)를 움직이며 위아래 그림의 교점이 늘 같은 \(x\)에서 생기는지 확인하고, 근의 개수가 바뀌는 \(k\)를 모두 찾아보자. 또 \(k = 0.05\)처럼 작은 양수에서는 위 그림에 교점이 하나만 보이는데 셋째 칸은 2인데, 나머지 근이 어디에 있는지 찾아보자.
  6. 판단양변을 \(x\)로 나눌 수 있었던 것은 정의역이 \(x > 0\)이기 때문이므로, \(x\)가 0이나 음수가 될 수 있으면 나누기 전에 따로 확인해야 한다. 또 그림의 범위 안에서만 교점을 세면 멀리 있는 근을 놓치므로, 끝에서의 극한을 함께 본다.

아래 그림의 주황 점은 \(h\)가 가장 낮은 곳이다. \(h\)가 \(x\)축 아래로 내려가는 곳이 있으면 부등식이 깨진다.

  1. 질문모든 실수 \(x\)에 대하여 \(e^x \ge kx\)가 성립하도록 하는 \(k\)의 범위는 무엇일까? \(k\)를 키우면 언젠가 직선이 곡선을 뚫고 올라갈 것이다.
  2. 복원‘모든 \(x\)에서 \(f(x) \ge g(x)\)’는 ‘\(h(x) = f(x) - g(x) \ge 0\)’과 같다. 그래서 \(h\)에 최솟값이 있으면 최솟값이 0 이상인지만 보면 된다.
  3. 설명\(h(x) = e^x - kx\)로 두면 \(h'(x) = e^x - k\)이다. \(k > 0\)이면 \(x = \ln k\)에서 \(h'\)의 부호가 −에서 +로 바뀌므로 최솟값은 \(h(\ln k) = k(1 - \ln k)\)이고, 이 값이 0 이상이려면 \(\ln k \le 1\), 곧 \(k \le e\)이다. \(k = 0\)이면 \(e^x > 0\)이라 성립하고, \(k < 0\)이면 \(x \to -\infty\)일 때 \(h(x) \to -\infty\)라 깨진다. 따라서 답은 \(0 \le k \le e\)이다.
  4. 연결\(k = e\)일 때 직선 \(y = ex\)는 곡선에 점 \((1, e)\)에서 접하는데, 이것은 아래로 볼록한 곡선이 접선보다 위에 있다는 사실과 같은 이야기이다. 같은 방법으로 \(e^x \ge x + 1\)(점 \((0, 1)\)에서의 접선)과 \(\ln x \le x - 1\)(점 \((1, 0)\)에서의 접선)을 증명할 수 있다.
  5. 적용\(k\)를 키우며 셋째 칸이 ‘아니요’로 바뀌는 순간을 찾고, 그때 위 그림의 직선과 곡선이 어떤 관계인지 보자. 그리고 \(k\)를 음수로 내리면 아래 그림의 어느 쪽에서 문제가 생기는지 확인해 보자.
  6. 판단극솟값만 확인하고 끝내면 안 된다. \(k < 0\)이면 \(h' > 0\)이라 극값이 아예 없고, 왼쪽 끝에서 \(h\)가 한없이 작아지기 때문이다. 그래서 최솟값이 없는 함수는 끝에서의 극한까지 보아야 하고, \(\frac{e^x}{x} \ge k\)처럼 \(x\)로 나누면 \(x < 0\)일 때 부등호 방향이 바뀌므로 조심해야 한다.
