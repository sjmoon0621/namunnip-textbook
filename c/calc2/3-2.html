치환적분법

\(2x \cos(x^2)\)처럼 합성함수와 그 속함수의 도함수가 곱해진 꼴은 앞 절의 공식만으로는 적분할 수 없습니다. 이 절에서는 합성함수의 미분법을 거꾸로 읽어, 속함수를 새 변수 \(u\)로 바꾸어 적분하는 치환적분법을 배웁니다. 정적분에서는 변수를 바꾸면 적분 구간도 함께 바뀐다는 점을 그림으로 확인합니다.

본문

\(\int_0^1 2x\cos(x^2)\,dx\)는 공식표에 바로 없는 모양이다. 그런데 자세히 보면 \(2x\)는 \(x^2\)의 도함수이다. 합성함수의 미분법을 거꾸로 쓰면 이 적분을 쉬운 적분으로 바꿀 수 있지 않을까? 그때 넓이는 그래프에서 어떻게 옮겨 갈까?

먼저 알아야 할 것합성함수의 미분법(합성함수의 미분법), 여러 가지 함수의 적분(여러 가지 함수의 적분), 정적분의 성질.

3.2.1치환적분법

\(F'(u) = f(u)\)이고 \(u = g(x)\)이면, 합성함수의 미분법에 의해 \(\{F(g(x))\}' = f(g(x))g'(x)\)이다. 이를 거꾸로 읽으면 \(\int f(g(x))g'(x)\,dx = F(g(x)) + C\)이다. 곧 적분할 식이 '속함수의 도함수 \(\times\) 속함수의 함수' 꼴이면, 속함수를 \(u\)로 바꾸어 \(\int f(u)\,du\)로 계산할 수 있다.

정리 3.2.1 치환적분법

\(u = g(x)\)로 놓으면 \(du = g'(x)\,dx\)이고 \[\int f(g(x))g'(x)\,dx = \int f(u)\,du,\qquad \int_a^b f(g(x))g'(x)\,dx = \int_{g(a)}^{g(b)} f(u)\,du\]

정적분에서는 적분 구간도 \(x\)의 범위에서 \(u\)의 범위로 바꾸어야 한다. \(x\)가 0에서 1까지 변하면 \(u = x^2\)은 0에서 1까지 변하므로 \(\int_0^1 2x\cos(x^2)\,dx = \int_0^1 \cos u\,du = \sin 1 \approx 0.841\)이다. 그림 1에서 위끝 \(b\)를 바꾸어 보면 두 넓이가 늘 같다.1

3.2.2자주 쓰는 꼴

분자가 분모의 도함수인 꼴 \(\int \dfrac{g'(x)}{g(x)}\,dx\)는 \(u = g(x)\)로 놓으면 \(\int \dfrac{du}{u} = \ln|g(x)| + C\)이다. 예를 들어 \(\int \tan x\,dx = \int \dfrac{\sin x}{\cos x}\,dx\)에서 분모 \(\cos x\)의 도함수는 \(-\sin x\)이므로 결과는 \(-\ln|\cos x| + C\)이다. 일차식이 들어간 \(\int f(ax + b)\,dx\)는 \(u = ax + b\)로 놓아 \(\dfrac{1}{a}F(ax + b) + C\)가 된다.

3.2.3예제 하나를 끝까지

예제 3.2.2

(1) \(\int_0^1 x e^{x^2}\,dx\)와 (2) \(\int_0^{\pi/2} \sin^3 x\cos x\,dx\)의 값을 구하여라.

(1) \(u = x^2\)으로 놓으면 \(du = 2x\,dx\), 곧 \(x\,dx = \dfrac{1}{2}du\)이다. \(x: 0 \to 1\)이면 \(u: 0 \to 1\)이므로 \(\int_0^1 \dfrac{1}{2}e^u\,du = \dfrac{1}{2}(e - 1) \approx 0.859\)이다.

(2) \(u = \sin x\)로 놓으면 \(du = \cos x\,dx\)이고, \(x: 0 \to \dfrac{\pi}{2}\)이면 \(u: 0 \to 1\)이다. 따라서 \(\int_0^1 u^3\,du = \dfrac{1}{4}\)이다. 구간을 바꾸지 않고 \(\int_0^{\pi/2} u^3\,du\)로 계산하면 틀린 값이 나온다. 구간을 바꾸기 싫다면 부정적분 \(\dfrac{\sin^4 x}{4}\)을 먼저 구해 원래 구간을 넣어도 같은 \(\dfrac{1}{4}\)이 나온다.

아래 탐구 카드에서 치환하면 넓이가 어디로 옮겨 가는지, 구간을 바꾸어야 하는 까닭을 직접 확인해 보자.

  1. \(du = g'(x)\,dx\)라는 표기는 '\(x\)가 조금 변할 때 \(u\)는 \(g'(x)\)배만큼 변한다'는 뜻으로 읽을 수 있다. 라이프니츠가 만든 이 표기 덕분에 치환이 분수 계산처럼 자연스러워진다.
마무리

적분할 식이 \(f(g(x))g'(x)\) 꼴이면 \(u = g(x)\), \(du = g'(x)dx\)로 바꾸어 \(\int f(u)du\)로 계산하고, 정적분에서는 구간도 \(g(a)\)에서 \(g(b)\)로 바꾼다. 그래서 처음 질문의 \(\int_0^1 2x\cos(x^2)dx\)는 \(u = x^2\)으로 바꾸면 \(\int_0^1\cos u\,du = \sin 1\)이 되며, 넓이는 가로가 늘어난 만큼 높이가 줄어든 모양으로 옮겨 간다.

탐구 1

속함수를 \(u\)로 바꾸면 넓이는 어디로 옮겨 갈까?

치환적분법 · 조작

—

위 그림 넓이 \(\int_0^b\,dx\)
—
아래 그림 넓이 \(\int\,du\)
—
\(F(g(b)) - F(g(0))\)
—

같은 색 띠끼리 짝이다. 위 그림을 끌어도 \(b\)가 바뀌고, 아래 그림의 띠가 왼쪽으로 되돌아가면 그 넓이는 빼진다.

  1. 질문\(\int_0^b 2x \cos(x^2)\,dx\)에서 \(x^2\)을 하나의 변수 \(u\)로 보면, 이 넓이는 \(u\)축 위의 어떤 넓이와 같아질까?
  2. 복원합성함수의 미분법에 따르면 \(\{F(g(x))\}' = F'(g(x)) \cdot g'(x)\)이고, \(F' = f\)이면 이것은 \(f(g(x))g'(x)\)이다.
  3. 설명따라서 \(\int f(g(x))g'(x)\,dx = F(g(x)) + C\)이고, \(u = g(x)\)로 놓고 \(du = g'(x)\,dx\)로 쓰면 \(\int f(u)\,du\)가 되는데, 이것이 치환적분법이다. 정적분에서는 \(\int_a^b f(g(x))g'(x)\,dx = \int_{g(a)}^{g(b)} f(u)\,du\)이다. 그림으로 보면 \(x\)축의 좁은 띠 \([x, x + \Delta x]\)는 \(u\)축의 띠 \([g(x), g(x + \Delta x)]\)로 옮겨지고, 너비는 약 \(g'(x)\)배가 되며 높이 \(f(g(x))\)는 그대로이다. 그래서 피적분함수에 곱해진 \(g'(x)\)는 바로 이 너비 변화를 미리 맞춰 둔 것이다.
  4. 연결\(f(u) = \frac{1}{u}\)인 경우가 자주 쓰여서, \(\int \frac{f'(x)}{f(x)}\,dx = \ln |f(x)| + C\)이고 예를 들어 \(\int \tan x\,dx = \int \frac{\sin x}{\cos x}\,dx = -\ln |\cos x| + C\)이다. 두 번째 보기 \(\frac{2x}{1 + x^2}\)가 이 꼴이므로 답은 \(\ln(1 + b^2)\)이다.
  5. 적용첫 보기에서 세 값이 늘 같은지 확인하고, 넓이가 0이 되는 \(b\)를 찾아 \(b^2\)이 어떤 수와 가까운지 계산해 보자. 세 번째 보기에서 \(b\)를 \(\frac{\pi}{2}\)보다 크게 하면 아래 그림의 띠가 어느 쪽으로 움직이는지 보고, \(b = \pi\)(약 3.14)에서 넓이가 0이 되는 까닭을 \(u\)의 구간으로 설명해 보자.
  6. 판단\(\int 2x \cos(x^2)\,dx\)를 \(\int \cos u\,dx\)로 쓰고 끝내면 안 되며, \(dx\)도 \(du\)로 바꾸어야 하고 그때 \(2x\)가 사라진다. 반대로 \(\int \cos(x^2)\,dx\)처럼 \(g'(x)\)에 해당하는 인수가 없으면 이 치환은 통하지 않는다. 또 정적분에서는 끝도 \(g(a)\), \(g(b)\)로 바꾸어야 한다.

치환할 때 적분 구간도 바꾸어야 할까?

정적분의 치환적분 · 단계

—
새 끝으로 계산
—
\(x\)의 끝을 그대로 쓰면
—

‘다음 단계’를 누를 때마다 풀이가 한 줄씩 열린다. 셋째 단계부터 아래 그림에 \(u\)의 함수가 나타난다.

  1. 질문\(\int_0^{\frac{\pi}{2}} \sin^3x \cos x\,dx\)를 \(u = \sin x\)로 치환해 \(\int u^3\,du\)로 바꾸었다. 이때 적분 구간은 여전히 0부터 \(\frac{\pi}{2}\)일까?
  2. 복원치환적분법은 \(\int_a^b f(g(x))g'(x)\,dx = \int_{g(a)}^{g(b)} f(u)\,du\)이다. 그리고 정적분의 끝은 그 적분 변수가 움직이는 범위이다.
  3. 설명풀이는 네 단계이다. 먼저 속함수 \(u = g(x)\)를 고르고, \(du = g'(x)\,dx\)를 써서 피적분함수를 모두 \(u\)로 바꾼다. 이어서 \(x = a\), \(x = b\)일 때의 \(u\) 값 \(g(a)\), \(g(b)\)를 새 끝으로 삼고, 마지막으로 \(u\)에 대한 정적분을 계산한다. 셋째 단계를 건너뛰면 \(u\)가 실제로 지나지 않는 구간의 넓이를 재게 되고, 새 끝을 쓰면 원래 변수 \(x\)로 되돌아갈 필요가 없다.
  4. 연결부정적분이라면 마지막에 \(u\) 대신 \(g(x)\)를 넣어 \(x\)의 식으로 되돌린다. 정적분은 끝을 바꾸거나, 부정적분을 \(x\)로 되돌린 뒤 원래 끝을 넣는 두 방법 중 하나를 쓰면 같은 값이 나온다. 넷째 보기처럼 \(g\)가 감소하면 새 끝의 위아래가 뒤바뀌는데, 이 순서를 그대로 지켜야 부호가 맞는다.
  5. 적용보기마다 네 단계를 끝까지 넘겨 세 값을 비교하고, 셋째 보기에서 \(x\)의 끝을 그대로 쓰면 왜 값이 나오지 않는지 보자. 넷째 보기에서는 새 끝이 1에서 0으로 내려가는데, 위아래를 바꾸어 0에서 1로 쓰려면 무엇을 바꾸어야 하는지 생각해 보자.
  6. 판단가장 흔한 실수는 피적분함수만 \(u\)로 바꾸고 끝은 \(x\)의 값으로 두는 것이다. 또 새 끝의 순서를 작은 수가 아래로 오게 마음대로 바꾸면 부호가 틀리므로, 바꾸려면 \(\int_1^0 = -\int_0^1\)을 써서 앞에 −를 붙인다.
