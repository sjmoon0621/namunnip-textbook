수열의 극한의 성질

수열의 극한값을 매번 띠를 그려 확인할 수는 없습니다. 이 절에서는 극한값을 아는 간단한 수열을 더하고, 빼고, 곱하고, 나누어 복잡한 수열의 극한값을 구하는 성질을 정리합니다. 이 성질을 쓸 수 있는 조건과, 분자와 분모가 모두 발산할 때 식의 모양을 바꾸는 방법도 다룹니다. 마지막으로 위아래 두 수열 사이에 끼인 수열의 극한을 정하는 대소 관계를 살펴봅니다.

회색은 an, 주황은 bn, 초록은 두 수열로 만든 cn입니다. 그림 밖으로 나간 항은 위아래 가장자리의 삼각형으로 표시합니다.

  1. 질문an이 2에, bn이 3에 수렴하면 an + bn은 5에, anbn은 6에 수렴할까요? 극한값끼리 계산해도 되는 조건은 무엇일까요?
  2. 복원함수의 극한에서 lim f(x)와 lim g(x)가 모두 존재하면 합, 차, 곱, 몫의 극한을 극한값끼리 계산할 수 있었습니다. 수열은 자연수에서 정의된 함수이므로 같은 성질을 기대할 수 있습니다.
  3. 설명두 수열 {an}, {bn}이 모두 수렴하고 lim an = α, lim bn = β일 때 다음이 성립합니다. ① lim kan = kα (k는 상수) ② lim (an ± bn) = α ± β ③ lim anbn = αβ ④ lim an/bn = α/β (단, bn ≠ 0, β ≠ 0). 예를 들어 |an + bn − (α + β)| ≤ |an − α| + |bn − β|이므로, 두 오차가 모두 0으로 가면 합의 오차도 0으로 갑니다. 이 성질을 쓰면 복잡한 수열을 극한값을 아는 간단한 수열로 쪼개 계산할 수 있습니다.
  4. 연결1/n → 0과 상수수열의 극한만 알면, 이 성질로 (2n + 1)/n = 2 + 1/n 같은 수열의 극한을 바로 구할 수 있습니다. ∞/∞ 꼴의 분수식은 먼저 모양을 바꾼 뒤 이 성질을 씁니다.
  5. 적용bn = 3 − 2/n에서 다섯 가지 연산을 차례로 고르고, n을 30까지 옮기며 초록 점이 점선에 다가가는지 보세요. 이번에는 bn = (−1)n/n으로 바꾸고 몫 an/bn을 고르세요. β = 0이면 무엇이 일어나나요? 같은 bn에서 곱 anbn은 어디로 가나요?
  6. 판단성질은 두 수열이 모두 수렴할 때만 씁니다. an = n, bn = −n이면 an + bn = 0이라 0에 수렴하지만, lim an + lim bn = ∞ + (−∞)로 계산할 수는 없습니다. ∞는 수가 아니기 때문입니다. 반대로 an + bn이 수렴해도 an과 bn이 각각 수렴한다고 할 수 없습니다. 다만 an과 an + bn이 모두 수렴하면 bn = (an + bn) − an도 수렴합니다.

그림은 n = 40까지의 항입니다. 항 번호 n은 106까지 옮길 수 있고, n ≤ 40이면 그 항을 큰 점으로 표시합니다.

  1. 질문(2n2 − 5)/(3n2 + 2)는 n이 커지면 분자와 분모가 모두 한없이 커집니다. 그렇다고 ∞/∞ = 1이라고 할 수 있을까요?
  2. 복원두 수열이 모두 수렴하면 몫의 극한은 극한값의 몫입니다(분모의 극한 ≠ 0). 또 c가 상수이고 r > 0이면 c/nr → 0입니다.
  3. 설명분자와 분모가 모두 발산하면 몫의 성질을 바로 쓸 수 없습니다. 이때 분모의 최고차항 nm으로 분자와 분모를 나누면 분모가 q + 2/nm → q로 수렴하는 꼴이 됩니다. 그 결과 ① 분자 차수 < 분모 차수이면 극한값 0 ② 차수가 같으면 최고차항 계수의 비 p/q ③ 분자 차수 > 분모 차수이면 발산(p > 0이면 ∞, p < 0이면 −∞)입니다. 차수가 같을 때 극한값을 정하는 것은 최고차항뿐이고, −5나 +2 같은 낮은 차수의 항은 n이 커질수록 영향이 사라집니다.
  4. 연결√가 들어간 ∞ − ∞ 꼴은 먼저 분자를 유리화해 분수 꼴로 바꿉니다. 예를 들어 √(n2 + n) − n = n/(√(n2 + n) + n)이고, 분자·분모를 n으로 나누면 1/(√(1 + 1/n) + 1) → 1/2입니다. 미적분Ⅰ에서 limx→∞을 구한 방법과 같습니다.
  5. 적용처음 상태(k = m = 2, p = 2, q = 3)에서 n을 106까지 옮기며 an이 2/3 ≈ 0.6667에 다가가는지 보세요. m만 3으로 올리면 극한은 어떻게 되나요? k를 3으로, m을 1로 두고 p를 음수로 바꾸면 그림의 항은 어느 쪽으로 빠져나가나요? 처음 몇 항의 부호가 극한과 다른 경우도 찾아보세요.
  6. 판단"∞/∞ = 1", "∞ − ∞ = 0"은 틀린 계산입니다. ∞는 수가 아니므로 이런 꼴은 식의 모양을 바꾼 뒤에야 극한을 알 수 있습니다. 또 분자의 최고차항으로 나누면 분모가 0으로 가는 꼴이 되어 몫의 성질을 쓸 수 없는 경우가 생깁니다. 분모의 최고차항으로 나누는 것이 안전합니다.

두 번째 수열은 cn = (3n + (−1)n)/(n + 1)입니다. 세 번째에서 rn은 n을 3으로 나눈 나머지(0, 1, 2)라서 항이 불규칙하게 튑니다.

  1. 질문cn = 2 + rn/n(rn은 n을 3으로 나눈 나머지)처럼 식이 규칙적이지 않으면 극한의 성질을 바로 쓰기 어렵습니다. 그래도 극한값을 정할 방법이 있을까요?
  2. 복원수렴하는 두 수열의 차 bn − an의 극한은 극한값의 차입니다. 수렴은 어떤 번호부터 모든 항이 극한값 둘레의 띠 안에 들어가는 것이었습니다.
  3. 설명두 수열 {an}, {bn}이 수렴하고 lim an = α, lim bn = β일 때 ① 모든 자연수 n에 대해 an ≤ bn이면 α ≤ β입니다. ② 수열 {cn}이 모든 n에 대해 an ≤ cn ≤ bn이고 α = β이면, lim cn = α입니다. 두 경계가 같은 값 α의 띠 안으로 들어가면, 그 사이에 끼인 cn도 같은 띠를 벗어날 수 없기 때문입니다. 간격 bn − an이 0으로 가는 것이 조이는 힘입니다.
  4. 연결이 성질은 (−1)n처럼 부호가 바뀌거나, 나머지처럼 불규칙한 부분이 섞인 수열에 씁니다. 함수의 극한에서도 같은 원리가 성립하며, 삼각함수의 극한 limx→0 (sin x)/x = 1을 보일 때 다시 쓰입니다.
  5. 적용네 경우마다 n을 1에서 40까지 옮기며 간격 bn − an이 어떻게 변하는지 보세요. 첫 세 경우와 마지막 경우의 차이는 무엇인가요? 마지막 경우에서 cn은 경계 안에 계속 있는데도 왜 결론을 낼 수 없나요?
  6. 판단부등식이 엄격해도 극한에서는 등호가 생길 수 있습니다. 1 − 1/n < 1 + 1/n이지만 두 극한은 모두 1입니다. 그래서 an < bn에서 얻는 결론도 α < β가 아니라 α ≤ β입니다. 또 조임으로 결론을 내려면 두 경계가 같은 값에 수렴해야 합니다. 경계의 극한이 다르면 가운데 수열은 수렴할 수도, 진동할 수도 있습니다.
