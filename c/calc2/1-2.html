수열의 극한의 성질

수열의 극한값을 매번 띠를 그려 확인할 수는 없습니다. 이 절에서는 극한값을 아는 간단한 수열을 더하고, 빼고, 곱하고, 나누어 복잡한 수열의 극한값을 구하는 성질을 정리합니다. 이 성질을 쓸 수 있는 조건과, 분자와 분모가 모두 발산할 때 식의 모양을 바꾸는 방법도 다룹니다. 마지막으로 위아래 두 수열 사이에 끼인 수열의 극한을 정하는 대소 관계를 살펴봅니다.

먼저 알면 좋은 것 수열의 수렴과 발산함수의 극한에 대한 성질무리식의 유리화

회색은 \(a_n\), 주황은 \(b_n\), 초록은 두 수열로 만든 \(c_n\)입니다. 그림 밖으로 나간 항은 위아래 가장자리의 삼각형으로 표시합니다.

  1. 질문\(a_n\)이 2에, \(b_n\)이 3에 수렴하면 \(a_n + b_n\)은 5에, \(a_nb_n\)은 6에 수렴할까요? 극한값끼리 계산해도 되는 조건은 무엇일까요?
  2. 복원함수의 극한에서 \(\lim f(x)\)와 \(\lim g(x)\)가 모두 존재하면 합, 차, 곱, 몫의 극한을 극한값끼리 계산할 수 있었습니다. 수열은 자연수에서 정의된 함수이므로 같은 성질을 기대할 수 있습니다.
  3. 설명두 수열 \(\{a_n\}\), \(\{b_n\}\)이 모두 수렴하고 \(\lim a_n = \alpha\), \(\lim b_n = \beta\)일 때 다음이 성립합니다. ① \(\lim ka_n = k\alpha\) (\(k\)는 상수) ② \(\lim (a_n \pm b_n) = \alpha \pm \beta\) ③ \(\lim a_nb_n = \alpha \beta\) ④ \(\lim \frac{a_n}{b_n} = \frac{\alpha}{\beta}\) (단, \(b_n \ne 0\), \(\beta \ne 0\)). 예를 들어 \(|a_n + b_n - (\alpha + \beta)| \le |a_n - \alpha| + |b_n - \beta|\)이므로, 두 오차가 모두 0으로 가면 합의 오차도 0으로 갑니다. 이 성질을 쓰면 복잡한 수열을 극한값을 아는 간단한 수열로 쪼개 계산할 수 있습니다.
  4. 연결\(\frac{1}{n} \to 0\)과 상수수열의 극한만 알면, 이 성질로 \(\frac{2n + 1}{n} = 2 + \frac{1}{n}\) 같은 수열의 극한을 바로 구할 수 있습니다. \(\infty/\infty\) 꼴의 분수식은 먼저 모양을 바꾼 뒤 이 성질을 씁니다.
  5. 적용\(b_n = 3 - \frac{2}{n}\)에서 다섯 가지 연산을 차례로 고르고, \(n\)을 30까지 옮기며 초록 점이 점선에 다가가는지 보세요. 이번에는 \(b_n = \frac{(-1)^n}{n}\)으로 바꾸고 몫 \(\frac{a_n}{b_n}\)을 고르세요. \(\beta = 0\)이면 무엇이 일어나나요? 같은 \(b_n\)에서 곱 \(a_nb_n\)은 어디로 가나요?
  6. 판단성질은 두 수열이 모두 수렴할 때만 씁니다. \(a_n = n\), \(b_n = -n\)이면 \(a_n + b_n = 0\)이라 0에 수렴하지만, \(\lim a_n + \lim b_n = \infty + (-\infty)\)로 계산할 수는 없습니다. \(\infty\)는 수가 아니기 때문입니다. 반대로 \(a_n + b_n\)이 수렴해도 \(a_n\)과 \(b_n\)이 각각 수렴한다고 할 수 없습니다. 다만 \(a_n\)과 \(a_n + b_n\)이 모두 수렴하면 \(b_n = (a_n + b_n) - a_n\)도 수렴합니다.

그림은 \(n = 40\)까지의 항입니다. 항 번호 \(n\)은 \(10^6\)까지 옮길 수 있고, \(n \le 40\)이면 그 항을 큰 점으로 표시합니다.

  1. 질문\(\frac{2n^2 - 5}{3n^2 + 2}\)는 \(n\)이 커지면 분자와 분모가 모두 한없이 커집니다. 그렇다고 \(\infty/\infty = 1\)이라고 할 수 있을까요?
  2. 복원두 수열이 모두 수렴하면 몫의 극한은 극한값의 몫입니다(분모의 극한 \(\ne 0\)). 또 \(c\)가 상수이고 \(r > 0\)이면 \(\frac{c}{n^r} \to 0\)입니다.
  3. 설명분자와 분모가 모두 발산하면 몫의 성질을 바로 쓸 수 없습니다. 이때 분모의 최고차항 \(n^m\)으로 분자와 분모를 나누면 분모가 \(q + \frac{2}{n^m} \to q\)로 수렴하는 꼴이 됩니다. 그 결과 ① 분자 차수 < 분모 차수이면 극한값 0 ② 차수가 같으면 최고차항 계수의 비 \(\frac{p}{q}\) ③ 분자 차수 > 분모 차수이면 발산(\(p > 0\)이면 \(\infty\), \(p < 0\)이면 \(-\infty\))입니다. 차수가 같을 때 극한값을 정하는 것은 최고차항뿐이고, \(-5\)나 \(+2\) 같은 낮은 차수의 항은 \(n\)이 커질수록 영향이 사라집니다.
  4. 연결√가 들어간 \(\infty - \infty\) 꼴은 먼저 분자를 유리화해 분수 꼴로 바꿉니다. 예를 들어 \(\sqrt{n^2 + n} - n = \frac{n}{\sqrt{n^2 + n} + n}\)이고, 분자·분모를 \(n\)으로 나누면 \(\frac{1}{\sqrt{1 + \frac{1}{n}} + 1} \to \frac{1}{2}\)입니다. 미적분Ⅰ에서 \(\lim_{x\to \infty}\)을 구한 방법과 같습니다.
  5. 적용처음 상태\((k = m = 2, p = 2, q = 3)\)에서 \(n\)을 \(10^6\)까지 옮기며 \(a_n\)이 \(\frac{2}{3} \approx 0.6667\)에 다가가는지 보세요. \(m\)만 3으로 올리면 극한은 어떻게 되나요? \(k\)를 3으로, \(m\)을 1로 두고 \(p\)를 음수로 바꾸면 그림의 항은 어느 쪽으로 빠져나가나요? 처음 몇 항의 부호가 극한과 다른 경우도 찾아보세요.
  6. 판단"\(\infty/\infty = 1\)", "\(\infty - \infty = 0\)"은 틀린 계산입니다. \(\infty\)는 수가 아니므로 이런 꼴은 식의 모양을 바꾼 뒤에야 극한을 알 수 있습니다. 또 분자의 최고차항으로 나누면 분모가 0으로 가는 꼴이 되어 몫의 성질을 쓸 수 없는 경우가 생깁니다. 분모의 최고차항으로 나누는 것이 안전합니다.

위아래에서 조이면 가운데 수열의 극한도 정해질까?

수열의 극한의 대소 관계 · 조임
아래 \(a_n\)
—
가운데 \(c_n\)
—
위 \(b_n\)
—
간격 \(b_n - a_n\)
—
결론
—

두 번째 수열은 \(c_n = \frac{3n + (-1)^n}{n + 1}\)입니다. 세 번째에서 \(r_n\)은 \(n\)을 3으로 나눈 나머지\((0, 1, 2)\)라서 항이 불규칙하게 튑니다.

  1. 질문\(c_n = 2 + \frac{r_n}{n}\)(\(r_n\)은 \(n\)을 3으로 나눈 나머지)처럼 식이 규칙적이지 않으면 극한의 성질을 바로 쓰기 어렵습니다. 그래도 극한값을 정할 방법이 있을까요?
  2. 복원수렴하는 두 수열의 차 \(b_n - a_n\)의 극한은 극한값의 차입니다. 수렴은 어떤 번호부터 모든 항이 극한값 둘레의 띠 안에 들어가는 것이었습니다.
  3. 설명두 수열 \(\{a_n\}\), \(\{b_n\}\)이 수렴하고 \(\lim a_n = \alpha\), \(\lim b_n = \beta\)일 때 ① 모든 자연수 \(n\)에 대해 \(a_n \le b_n\)이면 \(\alpha \le \beta\)입니다. ② 수열 \(\{c_n\}\)이 모든 \(n\)에 대해 \(a_n \le c_n \le b_n\)이고 \(\alpha = \beta\)이면, \(\lim c_n = \alpha\)입니다. 두 경계가 같은 값 \(\alpha\)의 띠 안으로 들어가면, 그 사이에 끼인 \(c_n\)도 같은 띠를 벗어날 수 없기 때문입니다. 간격 \(b_n - a_n\)이 0으로 가는 것이 조이는 힘입니다.
  4. 연결이 성질은 \((-1)^n\)처럼 부호가 바뀌거나, 나머지처럼 불규칙한 부분이 섞인 수열에 씁니다. 함수의 극한에서도 같은 원리가 성립하며, 삼각함수의 극한 \(\lim_{x\to 0} \frac{\sin x}{x} = 1\)을 보일 때 다시 쓰입니다.
  5. 적용네 경우마다 \(n\)을 1에서 40까지 옮기며 간격 \(b_n - a_n\)이 어떻게 변하는지 보세요. 첫 세 경우와 마지막 경우의 차이는 무엇인가요? 마지막 경우에서 \(c_n\)은 경계 안에 계속 있는데도 왜 결론을 낼 수 없나요?
  6. 판단부등식이 엄격해도 극한에서는 등호가 생길 수 있습니다. \(1 - \frac{1}{n} < 1 + \frac{1}{n}\)이지만 두 극한은 모두 1입니다. 그래서 \(a_n < b_n\)에서 얻는 결론도 \(\alpha < \beta\)가 아니라 \(\alpha \le \beta\)입니다. 또 조임으로 결론을 내려면 두 경계가 같은 값에 수렴해야 합니다. 경계의 극한이 다르면 가운데 수열은 수렴할 수도, 진동할 수도 있습니다.
