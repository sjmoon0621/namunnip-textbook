삼각함수의 극한과 미분

sin x를 미분하려면 {sin(x + h) − sin x}/h의 극한을 구해야 합니다. 덧셈정리로 펼치면 결국 sin h/h와 (cos h − 1)/h의 극한이 필요합니다. 이 절에서는 단위원에서 넓이를 비교해 limx→0 sin x/x = 1을 보이고, 이를 이용해 사인함수와 코사인함수의 도함수를 구합니다. 각은 모두 호도법(라디안)으로 잽니다.

넓이는 삼각형 OAP = ½ sin x, 부채꼴 OAP = ½ x, 삼각형 OAT = ½ tan x입니다(반지름 1).

  1. 질문x = 0을 넣으면 sin x/x는 0/0이 되어 값이 없습니다. x가 0에 가까워질 때는 어떤 값으로 다가갈까요?
  2. 복원호도법에서 반지름 1, 중심각 x인 부채꼴의 넓이는 ½x입니다. 세 함수가 g(x) ≤ f(x) ≤ h(x)이고 g와 h의 극한이 같으면 f의 극한도 그 값입니다.
  3. 설명0 < x < π/2일 때 그림의 세 도형은 차례로 포함되므로 ½ sin x < ½ x < ½ tan x입니다. 각 변을 ½ sin x로 나누고 역수를 취하면 cos x < sin x/x < 1입니다. x → 0+일 때 cos x → 1이므로 limx→0 sin x/x = 1입니다. sin(−x)/(−x) = sin x/x이므로 왼쪽에서 다가가도 같습니다. 또 (1 − cos x)/x = (sin x/x) · sin x/(1 + cos x) → 1 · 0/2 = 0입니다. 같은 방법으로 lim tan x/x = 1입니다.
  4. 연결sin x/x → 1은 x가 작을 때 sin x ≈ x라는 뜻입니다. 진자의 진동 주기를 구할 때 쓰는 근사도 이것입니다. 이 두 극한으로 다음 카드에서 사인함수와 코사인함수의 도함수를 구합니다.
  5. 적용'x ÷ 2'를 여러 번 눌러 세 도형의 넓이가 어떻게 가까워지는지 보세요. sin x/x는 아래 경계 cos x와 위 경계 1 사이에 늘 있나요? (1 − cos x)/x는 x가 절반이 될 때 대략 몇 배가 되나요?
  6. 판단이 극한은 x를 라디안으로 잴 때만 1입니다. 각을 도(°)로 재면 부채꼴의 넓이가 달라져 limx→0 sin x°/x = π/180입니다. 또 0/0 꼴이라고 곧바로 1이라고 답할 수는 없습니다. 같은 0/0 꼴인 (1 − cos x)/x는 0으로 갑니다. 극한값은 넓이 비교와 조임으로 얻은 것입니다.

P를 움직이면 그 x에서 잰 접선의 기울기가 아래 그림에 점으로 남습니다. 기울기는 아주 작은 h(0.00001)로 잰 값입니다.

  1. 질문y = sin x 위의 점마다 접선의 기울기를 재어, 그 값을 같은 x에 점으로 찍으면 어떤 곡선이 나타날까요?
  2. 복원덧셈정리 sin(x + h) = sin x cos h + cos x sin h, 그리고 극한 limh→0 sin h/h = 1, limh→0 (cos h − 1)/h = 0을 씁니다.
  3. 설명{sin(x + h) − sin x}/h = sin x · (cos h − 1)/h + cos x · sin h/h입니다. h → 0이면 sin x · 0 + cos x · 1이므로 (sin x)′ = cos x입니다. 같은 방법으로 cos(x + h) = cos x cos h − sin x sin h를 쓰면 (cos x)′ = −sin x입니다. 두 공식 모두 x를 라디안으로 잴 때 성립합니다.
  4. 연결sin x를 두 번 미분하면 −sin x로 돌아옵니다. 용수철에 매달린 물체처럼 가속도가 변위와 반대 방향으로 비례하는 운동이 사인 곡선을 그리는 까닭입니다. 다음 절에서는 몫의 미분법으로 tan x 같은 다른 삼각함수도 미분합니다.
  5. 적용'훑기'를 눌러 기울기 점들이 그리는 곡선을 보고 어떤 함수인지 짐작한 뒤 '후보 그래프 겹치기'로 확인하세요. 위 그래프가 가장 높은 곳에서 아래 점은 어디에 있나요? y = cos x로 바꾸면 기울기 점들은 어떤 곡선을 그리나요?
  6. 판단(cos x)′ = sin x로 부호를 빠뜨리는 실수가 흔합니다. 0 < x < π에서 cos x는 감소하므로 기울기가 음수여야 하고, 그래서 −sin x입니다. 또 각을 도로 잰 함수 y = sin x°의 도함수는 (π/180) cos x°입니다.
