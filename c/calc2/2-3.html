삼각함수의 극한과 미분

\(\sin x\)를 미분하려면 \(\frac{\sin(x + h) - \sin x}{h}\)의 극한을 구해야 합니다. 덧셈정리로 펼치면 결국 \(\frac{\sin h}{h}\)와 \(\frac{\cos h - 1}{h}\)의 극한이 필요합니다. 이 절에서는 단위원에서 넓이를 비교해 \(\lim_{x\to 0} \frac{\sin x}{x} = 1\)을 보이고, 이를 이용해 사인함수와 코사인함수의 도함수를 구합니다. 각은 모두 호도법(라디안)으로 잽니다.

2.3.1\(\frac{\sin x}{x}\)의 극한

반지름 1인 원에서 중심각 \(x\) (\(0 < x < \frac{\pi}{2}\))에 대한 세 도형의 넓이를 비교하자. 삼각형 \(OAP\)의 넓이는 \(\dfrac{1}{2}\sin x\), 부채꼴 \(OAP\)의 넓이는 \(\dfrac{1}{2}x\), 접선으로 만든 큰 삼각형의 넓이는 \(\dfrac{1}{2}\tan x\)이다. 그림에서 보듯 차례로 포함되므로 \(\sin x < x < \tan x\)이다.

각 변을 \(\sin x\)로 나누고 역수를 취하면 \(\cos x < \dfrac{\sin x}{x} < 1\)이다. \(x \to 0+\)일 때 \(\cos x \to 1\)이므로 조임 정리에 의해 \(\dfrac{\sin x}{x} \to 1\)이다. \(\dfrac{\sin x}{x}\)는 짝함수이므로 왼쪽 극한도 같다.

정리 2.3.1 삼각함수의 기본 극한

\[\lim_{x \to 0} \frac{\sin x}{x} = 1,\qquad \lim_{x \to 0} \frac{\tan x}{x} = 1,\qquad \lim_{x \to 0} \frac{1 - \cos x}{x} = 0\] (\(x\)의 단위는 라디안)

그림 1의 슬라이더로 \(x\)를 줄여 보면 \(\dfrac{\sin x}{x}\)가 \(\cos x\)와 1 사이에 끼인 채 1로 다가간다. 이 극한이 깔끔하게 1이 되는 것은 각을 라디안으로 쟀기 때문이다.1

2.3.2사인·코사인함수의 도함수

덧셈정리를 써서 \(y = \sin x\)의 도함수를 정의대로 구하면 \[\frac{\sin(x + h) - \sin x}{h} = \sin x \cdot \frac{\cos h - 1}{h} + \cos x \cdot \frac{\sin h}{h}\] 이고, \(h \to 0\)이면 \(\sin x \cdot 0 + \cos x \cdot 1 = \cos x\)이다.

정리 2.3.2 사인·코사인함수의 도함수

\[(\sin x)' = \cos x,\qquad (\cos x)' = -\sin x\]

2.3.3예제 하나를 끝까지

예제 2.3.3

\(\lim_{x \to 0} \dfrac{\sin 3x}{2x}\)와 \(\lim_{x \to 0} \dfrac{1 - \cos x}{x^2}\)을 구하여라.

\(\dfrac{\sin 3x}{2x} = \dfrac{3}{2} \cdot \dfrac{\sin 3x}{3x}\)이고 \(3x \to 0\)이므로 극한은 \(\dfrac{3}{2}\)이다.

분모와 분자에 \(1 + \cos x\)를 곱하면 \[\frac{1 - \cos x}{x^2} = \frac{1 - \cos^2 x}{x^2(1 + \cos x)} = \left(\frac{\sin x}{x}\right)^2 \cdot \frac{1}{1 + \cos x}\] 이고, \(x \to 0\)이면 \(1^2 \times \dfrac{1}{2} = \dfrac{1}{2}\)이다. 그러므로 0 근처에서 \(\cos x \approx 1 - \dfrac{x^2}{2}\)로 어림할 수 있다. 실제로 \(\cos 0.1 = 0.99500\)이고 \(1 - 0.005 = 0.995\)이다.

아래 탐구 카드에서 \(\dfrac{\sin x}{x}\)의 극한과 사인함수의 기울기 그래프를 직접 확인해 보자.

  1. 각을 도(°)로 재면 \(\lim_{x \to 0} \dfrac{\sin x°}{x} = \dfrac{\pi}{180}\)이 되어 도함수에도 \(\dfrac{\pi}{180}\)이 붙는다. 미적분에서 라디안을 쓰는 까닭이다.
마무리

단위원에서 넓이를 비교하면 \(\cos x < \frac{\sin x}{x} < 1\)이고, 조임 정리로 \(\lim_{x \to 0}\frac{\sin x}{x} = 1\)을 얻는다. 이 극한과 덧셈정리로 \((\sin x)' = \cos x\), \((\cos x)' = -\sin x\)가 나온다. 그래서 처음 질문의 작은 각에서 \(\sin x \approx x\)인 것은 우연이 아니라 라디안으로 잰 각의 기본 극한이며, 사인의 기울기를 모으면 코사인 그래프가 된다.

넓이는 삼각형 \(OAP = \frac{1}{2} \sin x\), 부채꼴 \(OAP = \frac{1}{2} x\), 삼각형 \(OAT = \frac{1}{2} \tan x\)이다(반지름 1).

  1. 질문\(x = 0\)을 넣으면 \(\frac{\sin x}{x}\)는 \(\frac{0}{0}\)이 되어 값이 없다. \(x\)가 0에 가까워질 때는 어떤 값으로 다가갈까?
  2. 복원호도법에서 반지름 1, 중심각 \(x\)인 부채꼴의 넓이는 \(\frac{1}{2}x\)이다. 그리고 세 함수가 \(g(x) \le f(x) \le h(x)\)이고 \(g\)와 \(h\)의 극한이 같으면 \(f\)의 극한도 그 값이다.
  3. 설명\(0 < x < \frac{\pi}{2}\)일 때 그림의 세 도형은 차례로 포함되므로 \(\frac{1}{2} \sin x < \frac{1}{2} x < \frac{1}{2} \tan x\)이고, 각 변을 \(\frac{1}{2} \sin x\)로 나누고 역수를 취하면 \(\cos x < \frac{\sin x}{x} < 1\)이다. \(x \to 0^+\)일 때 \(\cos x \to 1\)이므로 \(\lim_{x\to 0} \frac{\sin x}{x} = 1\)이고, \(\frac{\sin(-x)}{-x} = \frac{\sin x}{x}\)이므로 왼쪽에서 다가가도 같다. 또 \(\frac{1 - \cos x}{x} = (\frac{\sin x}{x}) \cdot \frac{\sin x}{1 + \cos x} \to 1 \cdot \frac{0}{2} = 0\)이고, 같은 방법으로 \(\lim \frac{\tan x}{x} = 1\)이다.
  4. 연결\(\frac{\sin x}{x} \to 1\)은 \(x\)가 작을 때 \(\sin x \approx x\)라는 뜻이며, 진자의 진동 주기를 구할 때 쓰는 근사도 이것이다. 이 두 극한으로 다음 카드에서 사인함수와 코사인함수의 도함수를 구한다.
  5. 적용‘\(x \div 2\)’를 여러 번 눌러 세 도형의 넓이가 어떻게 가까워지는지, \(\frac{\sin x}{x}\)가 아래 경계 \(\cos x\)와 위 경계 1 사이에 늘 있는지 보자. 그리고 \(\frac{1 - \cos x}{x}\)는 \(x\)가 절반이 될 때 대략 몇 배가 되는지 확인해 보자.
  6. 판단이 극한은 \(x\)를 라디안으로 잴 때만 1이다. 각을 도(°)로 재면 부채꼴의 넓이가 달라져 \(\lim_{x\to 0} \frac{\sin x^\circ}{x} = \frac{\pi}{180}\)이기 때문이다. 또 \(\frac{0}{0}\) 꼴이라고 곧바로 1이라고 답할 수는 없어서, 같은 \(\frac{0}{0}\) 꼴인 \(\frac{1 - \cos x}{x}\)는 0으로 간다. 극한값은 넓이 비교와 조임으로 얻은 것이다.

\(P\)를 움직이면 그 \(x\)에서 잰 접선의 기울기가 아래 그림에 점으로 남는다. 기울기는 아주 작은 \(h(0.00001)\)로 잰 값이다.

  1. 질문\(y = \sin x\) 위의 점마다 접선의 기울기를 재어, 그 값을 같은 \(x\)에 점으로 찍으면 어떤 곡선이 나타날까?
  2. 복원덧셈정리 \(\sin(x + h) = \sin x \cos h + \cos x \sin h\)와 극한 \(\lim_{h\to 0} \frac{\sin h}{h} = 1\), \(\lim_{h\to 0} \frac{\cos h - 1}{h} = 0\)을 쓴다.
  3. 설명\(\frac{\sin(x + h) - \sin x}{h} = \sin x \cdot \frac{\cos h - 1}{h} + \cos x \cdot \frac{\sin h}{h}\)이고, \(h \to 0\)이면 \(\sin x \cdot 0 + \cos x \cdot 1\)이므로 \((\sin x)' = \cos x\)이다. 같은 방법으로 \(\cos(x + h) = \cos x \cos h - \sin x \sin h\)를 쓰면 \((\cos x)' = -\sin x\)이며, 두 공식 모두 \(x\)를 라디안으로 잴 때 성립한다.
  4. 연결\(\sin x\)를 두 번 미분하면 \(-\sin x\)로 돌아온다. 용수철에 매달린 물체처럼 가속도가 변위와 반대 방향으로 비례하는 운동이 사인 곡선을 그리는 까닭이 이것이다. 다음 절에서는 몫의 미분법으로 \(\tan x\) 같은 다른 삼각함수도 미분한다.
  5. 적용‘훑기’를 눌러 기울기 점들이 그리는 곡선을 보고 어떤 함수인지 짐작한 뒤 ‘후보 그래프 겹치기’로 확인해 보자. 그리고 위 그래프가 가장 높은 곳에서 아래 점이 어디에 있는지, \(y = \cos x\)로 바꾸면 기울기 점들이 어떤 곡선을 그리는지 보자.
  6. 판단\((\cos x)' = \sin x\)로 부호를 빠뜨리는 실수가 흔하다. \(0 < x < \pi\)에서 \(\cos x\)는 감소하므로 기울기가 음수여야 하고, 그래서 \(-\sin x\)이다. 또 각을 도로 잰 함수 \(y = \sin x^\circ\)의 도함수는 \((\frac{\pi}{180}) \cos x^\circ\)이다.
