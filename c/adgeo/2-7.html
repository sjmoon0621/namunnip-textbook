단위속력곡선으로 재매개화

본문

나선 \(\vec r(t) = (\cos t, \sin t, t)\) 위를 움직이는 점은 빠르기가 \(\sqrt2\)이다. 이 점이 같은 나선을 따라가되 빠르기가 정확히 1이 되도록 식을 바꾸려 한다. 한 학생은 \(t\) 대신 \(\sqrt2\,s\)를 넣어 \((\cos\sqrt2 s, \sin\sqrt2 s, \sqrt2 s)\)로 썼는데, 미분해 보니 빠르기가 2가 되었다. 어디서 잘못되었을까? 곡선의 모양은 그대로 두고 빠르기만 1로 바꾸는 바른 방법은 무엇일까?

먼저 알아야 할 것호의 길이 함수(단위속력곡선과 호의 길이 매개변수), 역함수의 미분, 합성함수의 미분법.

2.7.1세 단계의 재매개화

같은 곡선을 다른 매개변수로 다시 나타내는 것을 재매개화라 한다. 예를 들어 정칙곡선을 단위속력곡선으로 재매개화하는 순서는 세 단계이다. 먼저 빠르기 \(|\vec r'(t)|\)를 구하고 적분해 호의 길이 함수 \(s(t)\)를 얻는다. 다음으로 \(s = s(t)\)를 \(t\)에 대해 풀어 \(t = t(s)\)를 구한다. 마지막으로 원래 식에 \(t = t(s)\)를 대입해 \(\vec r(t(s))\)를 쓴다. 이렇게 얻은 곡선은 모양과 방향이 원래와 같고, 빠르기만 1이 된다.

정리 2.7.1 단위속력 재매개화

정칙곡선 \(\vec r(t)\)의 호의 길이 함수를 \(s(t)\), 그 역함수를 \(t(s)\)라 하면 \(\tilde r(s) = \vec r(t(s))\)는 단위속력곡선이다. 합성함수와 역함수의 미분법으로 \[\left|\frac{d\tilde r}{ds}\right| = |\vec r'(t)|\cdot\frac{dt}{ds} = |\vec r'(t)|\cdot\frac{1}{s'(t)} = 1\]이다.

또 합성함수의 미분법으로 새 빠르기는 원래 빠르기에 \(dt/ds\)를 곱한 것이다. 원래 빠르기가 \(\sqrt2\)이면 새 빠르기를 1로 만들려면 \(dt/ds = 1/\sqrt2\)이어야 하고, 그러려면 \(t = s/\sqrt2\)이다. 처음 질문의 학생은 \(s = \sqrt2\,t\)라는 관계에서 \(t\)를 \(s\)로 나타내지 않고 거꾸로 \(t = \sqrt2\,s\)를 넣어, 빠르기에 \(\sqrt2\)를 한 번 더 곱해 2를 만들었다. 시간을 늘리는 대신 줄인 셈이다.1

2.7.2빠르기가 바뀌는 곡선의 재매개화

한편 빠르기가 일정하지 않은 곡선도 같은 방법으로 재매개화한다. 원 \((\cos t^2, \sin t^2)\)(\(t \ge 0\))는 빠르기가 \(2t\)이고 \(s(t) = t^2\)이므로 \(t = \sqrt s\)이다. 대입하면 \((\cos s, \sin s)\)로, 익숙한 단위원의 단위속력 매개변수가 된다. 그런데 호의 길이 함수의 적분이나 역함수를 식으로 구할 수 없는 곡선도 많다. 그런 곡선은 수치 계산으로 \(s\)와 \(t\)의 표를 만들어 재매개화한다.

2.7.3예제 하나를 끝까지

예제 2.7.2

나선 \(\vec r(t) = (3\cos t, 3\sin t, 4t)\)를 단위속력곡선으로 재매개화하고, 빠르기가 1인지 확인하여라. 출발점에서 호의 길이 \(10\pi\)인 곳의 좌표를 구하여라.

\(\vec r'(t) = (-3\sin t, 3\cos t, 4)\)이므로 빠르기는 \(\sqrt{9 + 16} = 5\)이고 \(s = 5t\), 곧 \(t = s/5\)이다. 대입하면 \(\tilde r(s) = \left(3\cos\dfrac s5, 3\sin\dfrac s5, \dfrac{4s}{5}\right)\)이다. 미분하면 \(\tilde r'(s) = \left(-\tfrac35\sin\tfrac s5, \tfrac35\cos\tfrac s5, \tfrac45\right)\)이고 크기는 \(\sqrt{\tfrac{9}{25} + \tfrac{16}{25}} = 1\)이다.

따라서 호의 길이 \(10\pi\)인 곳은 \(s = 10\pi\)이므로 \(\tilde r(10\pi) = (3\cos2\pi, 3\sin2\pi, 8\pi) = (3, 0, 8\pi)\)이다. 나선을 정확히 한 바퀴 돌아 \(8\pi \approx 25.1\)만큼 올라간 곳이다. 한 바퀴의 길이는 \(\sqrt{(6\pi)^2 + (8\pi)^2} = 10\pi\)로 맞는다. 즉 단위속력곡선으로 재매개화하려면 빠르기를 적분한 호의 길이 함수를 원래 매개변수에 대해 거꾸로 풀어 대입하며, 관계식의 방향을 바꾸어 넣으면 빠르기가 1이 아니게 된다.

아래 탐구 카드에서 나선 위를 속력 1로 움직이도록 매개변수를 바꾸어 보고, 재매개화 풀이의 틀린 곳을 찾아보자.

  1. 애니메이션에서 물체를 곡선 경로를 따라 일정한 빠르기로 움직이게 할 때도 이 재매개화를 쓴다. 베지에 곡선처럼 매개변수와 거리가 비례하지 않는 곡선을 그대로 쓰면, 물체가 굽은 곳에서 갑자기 빨라지거나 느려져 보이기 때문이다.
마무리

정칙곡선을 단위속력곡선으로 재매개화하려면 빠르기를 적분해 호의 길이 함수 \(s(t)\)를 구하고, 이를 \(t = t(s)\)로 거꾸로 풀어 원래 식에 대입한다. 합성함수와 역함수의 미분법으로 새 빠르기는 \(|\vec r'(t)|/s'(t) = 1\)이 된다. 처음 질문의 학생은 \(s = \sqrt2\,t\)를 거꾸로 풀지 않고 \(t = \sqrt2\,s\)를 넣어 빠르기가 2가 되었고, 바른 재매개화는 \(t = s/\sqrt2\)를 넣은 \((\cos(s/\sqrt2), \sin(s/\sqrt2), s/\sqrt2)\)이다.

나선 위를 속력 1로 움직이게 하려면 매개변수를 어떻게 바꿀까?

단위속력곡선으로 재매개화 · 만들기

점은 s = 0, 1, 2, …인 곳이고 주황 큰 점은 5마다 찍었다. 그림의 높이 방향은 보기 좋게 절반으로 줄였다.

  1. 질문나선 \(\vec{r}(t) = (a\cos t, a\sin t, bt)\)의 속력은 \(\sqrt{a^2 + b^2}\)로 일정하지만 1은 아니다. 매개변수를 \(t = \frac{s}{c}\)로 바꾸면 속력이 1이 되게 할 수 있을까? \(c\)는 얼마여야 할까?
  2. 복원연쇄법칙에 따르면 \(\frac{d\vec{r}}{ds} = \frac{d\vec{r}}{dt}\cdot\frac{dt}{ds}\)이다.
  3. 설명정칙곡선 \(\vec{r}(t)\)의 호의 길이 함수 \(s(t) = \int_{t_0}^{t}|\vec{r}\,'(u)|\,du\)는 증가함수이므로 역함수 \(t = t(s)\)가 있고, \(\vec{r}(t(s))\)는 \(\left|\frac{d\vec{r}}{ds}\right| = \frac{|\vec{r}\,'(t)|}{ds/dt} = 1\)인 단위속력곡선이 된다. 이것을 단위속력곡선으로 재매개화한다고 한다. 나선은 \(s = \sqrt{a^2 + b^2}\,t\)이므로 \(c = \sqrt{a^2 + b^2}\)이고, \(\vec{r}(s) = \left(a\cos\frac{s}{c}, a\sin\frac{s}{c}, \frac{bs}{c}\right)\)이다.
  4. 연결속력이 일정하지 않은 곡선은 \(s(t)\)의 역함수를 식으로 구하기 어려울 때가 많아, 앞 카드처럼 수치로 구한다. 다음 절의 곡률은 단위속력곡선에서 \(\kappa = \left|\frac{d^2\vec{r}}{ds^2}\right|\)로 간단히 정의된다.
  5. 적용\(c\)를 조절해 \(s\)를 1씩 늘린 점 사이의 곡선 거리가 1이 되게 해 보자. \(a\), \(b\)를 바꾸면 필요한 \(c\)는 어떻게 바뀌는가? 식 \(\sqrt{a^2 + b^2}\)과 비교해 보자.
  6. 판단재매개화는 곡선(그림)을 바꾸지 않고 "시간표"만 바꾼다. \(c\)를 아무 값으로 해도 같은 나선이 그려지지만, 단위속력이 되는 \(c\)는 하나뿐이다. 또 \(s\)의 시작점을 어디로 잡느냐에 따라 식이 평행이동만큼 달라질 수 있다.

이 재매개화 풀이는 어디서 틀렸을까?

재매개화의 계산 · 오류 찾기

처음 틀린 줄을 누르세요. 틀린 곳이 없으면 마지막 줄을 누르세요.

  1. \(\vec{r}(t) = (3\cos t, 3\sin t, 4t)\), \(t \ge 0\)을 단위속력곡선으로 재매개화한다.문제입니다.
  2. \(\vec{r}\,'(t) = (-3\sin t, 3\cos t, 4)\)이므로 \(|\vec{r}\,'(t)| = 3 + 4 = 7\)이다.여기가 틀렸습니다. 크기는 \(\sqrt{9\sin^2t + 9\cos^2t + 16} = 5\)입니다.
  3. \(s = 7t\)이므로 \(t = \frac{s}{7}\), \(\vec{r}(s) = \left(3\cos\frac{s}{7}, 3\sin\frac{s}{7}, \frac{4s}{7}\right)\)이다.앞 줄의 잘못을 이어받았습니다. 바르게는 \(t = \frac{s}{5}\)입니다.
  4. 틀린 곳이 없다.마지막 식의 속력을 직접 계산해 보세요.
  1. \(\vec{r}(t) = (e^t\cos t, e^t\sin t)\), \(t \ge 0\)을 \(t = 0\)에서부터 잰 호의 길이로 재매개화한다.문제입니다.
  2. \(|\vec{r}\,'(t)| = \sqrt{2}\,e^t\)이다.맞습니다. \(\vec{r}\,' = e^t(\cos t - \sin t, \sin t + \cos t)\)의 크기입니다.
  3. \(s = \int\sqrt2\,e^t\,dt = \sqrt2\,e^t\)이므로 \(t = \ln\frac{s}{\sqrt2}\)이다.여기가 틀렸습니다. \(t = 0\)에서부터 잰 길이는 정적분 \(s = \int_0^t\sqrt2\,e^u\,du = \sqrt2(e^t - 1)\)입니다. 그래서 \(t = \ln\left(1 + \frac{s}{\sqrt2}\right)\)입니다.
  4. 틀린 곳이 없다.\(t = 0\)일 때 \(s\)가 0이 되나요?
  1. 원 \(\vec{r}(t) = (2\cos 3t, 2\sin 3t)\)를 단위속력곡선으로 재매개화한다.문제입니다.
  2. \(|\vec{r}\,'(t)| = 6\)이므로 \(s = 6t\)이다.맞습니다.
  3. \(t = \frac{s}{6}\)을 넣으면 \(\vec{r}(s) = \left(2\cos\frac{s}{6}, 2\sin\frac{s}{6}\right)\)이다.여기가 틀렸습니다. \(3t = \frac{s}{2}\)이므로 \(\left(2\cos\frac{s}{2}, 2\sin\frac{s}{2}\right)\)입니다. 대입할 때 \(3t\) 전체를 바꿔야 합니다.
  4. 틀린 곳이 없다.결과의 속력이 1인지 확인해 보세요.
  1. 직선 \(\vec{r}(t) = (1 + 2t, 3 - t, 2t)\)를 단위속력곡선으로 재매개화한다.문제입니다.
  2. \(|\vec{r}\,'(t)| = \sqrt{4 + 1 + 4} = 3\)이므로 \(s = 3t\), \(t = \frac{s}{3}\)이다.맞습니다.
  3. \(\vec{r}(s) = \left(1 + \frac{2s}{3}, 3 - \frac{s}{3}, \frac{2s}{3}\right)\)이다.맞습니다. 방향 벡터가 단위벡터 \(\left(\frac{2}{3}, -\frac{1}{3}, \frac{2}{3}\right)\)가 되었습니다.
  4. 틀린 곳이 없다.맞습니다. 직선의 재매개화는 방향 벡터를 단위벡터로 바꾸는 것과 같습니다.

  1. 질문재매개화는 "속력 구하기 → 호의 길이 적분 → 역함수 → 대입" 네 단계이다. 단계는 단순하지만 실수가 자주 나온다. 어디서 틀리기 쉬울까?
  2. 복원\(|\vec{v}| = \sqrt{v_1^2 + v_2^2 + v_3^2}\), 정적분 \(\int_a^b f(u)\,du\)의 아래끝을 빼야 한다.
  3. 설명흔한 실수는 ① 속력을 성분의 합으로 계산하기, ② 호의 길이를 부정적분으로 써서 시작점을 놓치기(\(s(t_0) = 0\)이어야 함), ③ 역함수를 대입할 때 식의 일부만 바꾸기이다. 마지막에 \(\left|\frac{d\vec{r}}{ds}\right| = 1\)인지 확인하면 대부분의 실수를 잡을 수 있다.
  4. 연결재매개화한 곡선은 곡률 \(\kappa = \left|\frac{d^2\vec{r}}{ds^2}\right|\)을 바로 계산하는 데 쓴다(곡률).
  5. 적용네 풀이에서 처음 틀린 줄을 찾자. 찾으면 아래에 바른 결과와 속력 확인이 나타난다.
  6. 판단로그 나선처럼 \(s(t)\)의 역함수가 깔끔하게 나오는 경우는 드물다. 역함수를 식으로 쓸 수 없을 때는 수치로 구하고, 이론에서는 "단위속력 재매개화가 존재한다"는 사실만 쓴다.
