정규분포

키, 측정 오차, 시험 점수처럼 많은 자료가 평균 근처에 몰리고 양쪽으로 갈수록 드물어지는 종 모양을 이룹니다. 이 절에서는 이런 모양을 나타내는 정규분포가 평균과 표준편차 두 수로 정해지는 것을 보고, 어떤 정규분포든 표준정규분포 하나로 바꾸어 확률을 구하는 방법을 익힙니다. 시행 횟수가 많은 이항분포가 정규분포에 가까워지는 것도 확인합니다.

3.4.1

평균과 표준편차만으로 종 모양이 정해질까?

정규분포 · 곡선의 성질
곡선의 최댓값 1/(σ√2π)
—
P(m − σ ≤ X ≤ m + σ)
—
전체 넓이
1

점선은 비교를 위해 고정한 N(60, 102)입니다. 칠한 넓이는 수치 적분으로 계산합니다.

  1. 질문두 반의 수학 점수 분포가 모두 종 모양인데, 한 반은 평균이 더 높고 다른 반은 더 넓게 퍼져 있습니다. 이 두 종 모양은 서로 다른 모양일까요, 같은 모양을 옮기고 늘인 것일까요?
  2. 복원연속확률변수의 확률은 확률밀도함수 그래프 아래의 넓이이고, 전체 넓이는 1입니다. σ(aX + b) = |a|σ(X)이므로, 더하는 수는 위치만 옮기고 곱하는 수는 폭을 바꿉니다.
  3. 설명평균이 m, 표준편차가 σ인 연속확률변수 X의 확률밀도함수가 f(x) = 1/(σ√2π) · e−(x−m)²/(2σ²)일 때, X는 정규분포 N(m, σ2)을 따른다고 합니다. 곡선은 (1) 직선 x = m에 대하여 대칭이고 (2) x = m에서 최댓값을 가지며 (3) x축을 점근선으로 하고 (4) x축과의 사이 넓이가 1입니다. m이 바뀌면 곡선은 모양 그대로 옆으로 옮겨지고, σ가 커지면 낮고 넓게 퍼집니다. 넓이가 1로 고정되어 있으니 폭이 두 배가 되면 높이는 절반이 됩니다.
  4. 연결평균에서 표준편차의 몇 배 안에 있는지만 같으면 확률도 같다는 성질 덕분에, 모든 정규분포를 평균 0, 표준편차 1인 표준정규분포 하나로 바꾸어 다룰 수 있습니다. 이것이 표준화이며, 다음 카드에서 다룹니다.
  5. 적용'm ± σ'를 고른 채 m과 σ를 마음대로 바꾸어 보세요. 칠한 넓이의 확률은 바뀌나요? 'm ± 2σ', 'm ± 3σ'에서도 값이 각각 몇으로 고정되는지 읽어 보세요. σ를 4와 16으로 바꾸면 최댓값은 몇 배가 되나요?
  6. 판단N(m, σ2)의 둘째 자리는 분산입니다. N(50, 16)은 표준편차가 4이지 16이 아닙니다. 또 실제 자료가 정확히 정규분포인 경우는 드물고, 키나 측정값이 종 모양에 가깝다는 것을 정규분포로 근사하는 것입니다. 양 끝의 아주 드문 값까지 정규분포가 잘 맞는다고 믿으면 위험을 작게 볼 수 있습니다.

확인조건이 달라지면

X가 정규분포 N(50, 42)을 따를 때 P(42 ≤ X ≤ 58)은? (단, P(0 ≤ Z ≤ 0.5) = 0.1915, P(0 ≤ Z ≤ 2) = 0.4772)

3.4.2

정규분포표 하나로 모든 정규분포의 확률을 구할 수 있을까?

표준정규분포 · 표준화
z = (a − m)/σ
—
P(0 ≤ Z ≤ z)
—
P(X ≤ a)
—
P(X ≥ a)
—

어느 학교 학생의 키 X가 정규분포를 따른다고 가정한 예입니다. 두 번째 값은 표준정규분포표에서 읽는 값(z를 소수 둘째 자리까지)입니다.

  1. 질문키가 N(170, 62)을 따르는 학교에서 179 cm 이상인 학생의 비율을 알고 싶습니다. 평균과 표준편차가 다른 학교마다 표를 따로 만들어야 할까요?
  2. 복원E(aX + b) = aE(X) + b, σ(aX + b) = |a|σ(X)입니다. 정규분포에서 평균으로부터 표준편차의 몇 배 안에 들어갈 확률은 m, σ와 관계없이 같습니다.
  3. 설명평균이 0, 표준편차가 1인 정규분포 N(0, 1)을 표준정규분포라 하고, 이를 따르는 확률변수를 Z로 씁니다. X가 N(m, σ2)을 따르면 Z = (X − m)/σ는 N(0, 1)을 따릅니다. 이렇게 바꾸는 것을 표준화라고 합니다. 그러면 P(X ≤ a) = P(Z ≤ (a − m)/σ)이고, 값은 P(0 ≤ Z ≤ z)를 모아 둔 표준정규분포표에서 읽습니다. 표에는 양수 z만 있으므로, 곡선이 0에 대해 대칭이고 0의 양쪽 넓이가 각각 0.5라는 것을 함께 씁니다.
  4. 연결z는 '평균에서 표준편차 몇 개만큼 떨어져 있는가'를 나타내는 수라서, 평균과 표준편차가 다른 두 시험의 점수를 비교할 때도 씁니다. 다음 카드에서 이항분포의 확률을 근사할 때, 그리고 모평균을 추정할 때도 모두 이 표준화를 거칩니다.
  5. 적용처음 상태에서 z와 P(X ≥ 179)를 읽어 보세요. 대응선을 보면 m은 Z의 어디로 가나요? a를 평균보다 작게 하면 z는 음수가 되는데, 표 값으로 P(X ≤ a)를 어떻게 구하나요? m과 σ를 바꾸면서 z가 같게 유지되도록 a를 맞추면 확률은 어떻게 되나요?
  6. 판단표준화할 때 분산으로 나누는 실수가 잦습니다. N(170, 36)이면 σ = 6으로 나눠야 합니다. 또 표의 값 P(0 ≤ Z ≤ z)를 그대로 P(Z ≤ z)로 쓰면 0.5가 빠집니다. 그림으로 넓이를 먼저 그려 보면 이런 실수를 줄일 수 있습니다.

3.4.3

시행 횟수가 많아지면 이항분포는 어떤 모양에 가까워질까?

이항분포 · 정규분포 근사
평균 np
—
표준편차 √npq
—
P(X ≤ k)
—
정규분포 근사
—

막대는 B(n, p)의 확률, 곡선은 평균과 표준편차가 같은 정규분포 N(np, npq)입니다. 진한 막대는 X ≤ k인 부분이고, k는 np + √npq를 넘지 않는 가장 큰 정수입니다. P(X ≤ k)는 이항분포로 계산한 정확한 값, 근사값은 P(Z ≤ (k − np)/√npq)입니다.

  1. 질문동전을 100번 던져 앞면이 60번 이하로 나올 확률을 이항분포로 구하려면 100Ck(1/2)100을 61개나 더해야 합니다. 더 간단한 방법은 없을까요?
  2. 복원B(n, p)의 평균은 np, 표준편차는 √npq입니다(q = 1 − p). 정규분포 N(m, σ2)의 확률은 Z = (X − m)/σ로 표준화해 표준정규분포표에서 읽습니다.
  3. 설명n이 커지면 이항분포의 막대그래프는 평균 np를 중심으로 좌우가 거의 대칭인 종 모양이 됩니다. 그래서 X가 B(n, p)를 따르고 n이 충분히 크면, X는 근사적으로 정규분포 N(np, npq)를 따른다고 봅니다. 확률은 Z = (X − np)/√npq로 표준화해 구합니다. 앞의 동전은 m = 50, σ = 5이므로 P(X ≤ 60) ≈ P(Z ≤ 2) = 0.9772입니다.
  4. 연결이 근사 덕분에 표본비율처럼 '성공 횟수를 센 값'도 정규분포로 다룰 수 있습니다. 모비율을 추정하고 여론조사의 오차 범위를 계산하는 바탕이 이것입니다.
  5. 적용p = 0.2로 두고 n을 5에서 100까지 천천히 키워 보세요. n이 작을 때 막대는 어느 쪽으로 치우쳐 있나요? P(X ≤ k)와 '정규분포 근사'의 차이는 n이 커질수록 어떻게 되나요? p를 0.5로 바꾸면 더 작은 n에서도 곡선이 잘 맞나요?
  6. 판단근사는 n이 충분히 클 때만 씁니다. 흔히 np ≥ 5, nq ≥ 5를 기준으로 삼으며, p가 0이나 1에 가까울수록 더 큰 n이 필요합니다. 또 이항분포는 정수에만 확률이 있지만 정규분포는 연속이므로, n이 작으면 근사값이 정확한 값과 꽤 다릅니다.
