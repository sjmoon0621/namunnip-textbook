이항정리

\((a + b)^2, (a + b)^3\)은 직접 전개할 수 있습니다. 그러나 \((a + b)^{10}\)을 하나씩 곱해 나가기는 어렵습니다. 그런데 전개식의 계수는 사실 경우의 수입니다. 열 개의 인수에서 \(a\)와 \(b\) 가운데 무엇을 고를지 세면 계수가 나옵니다. 이 절에서는 이 생각으로 이항정리를 얻고, 계수들을 쌓은 파스칼의 삼각형의 성질을 찾은 뒤 특정한 항의 계수와 근삿값 계산에 써 봅니다.

먼저 알면 좋은 것 다항식의 곱셈과 곱셈 공식조합 \({}_{n}\mathrm{C}_{r}\)와 그 성질같은 것이 있는 순열

1.3.1

위 칸 하나가 인수 \((a + b)\) 하나입니다. 칸을 누르면 그 인수에서 고르는 문자가 바뀝니다.

  1. 질문\((a + b)^4\)를 전개하면 \(a^2b^2\)의 계수는 얼마일까요? 곱셈을 끝까지 하지 않고 알 수 있을까요?
  2. 복원\((a + b)(c + d) = ac + ad + bc + bd\)처럼, 다항식의 곱을 전개하면 인수마다 항을 하나씩 골라 곱한 것이 모두 나옵니다. 서로 다른 \(n\)개에서 순서 없이 \(r\)개를 고르는 방법은 \({}_{n}\mathrm{C}_{r}\)가지입니다.
  3. 설명\((a + b)^n = (a + b)(a + b)\cdots(a + b)\)에서 인수 \(n\)개마다 \(a\)나 \(b\)를 하나씩 골라 곱하면 항이 하나 생깁니다. 선택은 모두 \(2^n\)가지입니다. \(b\)를 \(r\)번, \(a\)를 \(n - r\)번 고르면 항은 \(a^{n-r}b^r\)이고, \(b\)를 고를 인수 \(r\)개를 정하는 방법이 \({}_{n}\mathrm{C}_{r}\)가지이므로 이 항은 \({}_{n}\mathrm{C}_{r}\)번 나옵니다. 따라서 \((a + b)^n = {}_{n}\mathrm{C}_{0}a^n + {}_{n}\mathrm{C}_{1}a^{n-1}b + \cdots + {}_{n}\mathrm{C}_{r}a^{n-r}b^r + \cdots + {}_{n}\mathrm{C}_{n}b^n\)입니다. 이것을 이항정리라 하고, 계수 \({}_{n}\mathrm{C}_{r}\)를 이항계수, \({}_{n}\mathrm{C}_{r}a^{n-r}b^r\)를 일반항이라고 합니다. \(\sum\) 기호로는 \((a + b)^n = \sum_{r=0}^n\) \({}_{n}\mathrm{C}_{r}a^{n-r}b^r\)로 씁니다.
  4. 연결고른 문자를 늘어놓은 abba 같은 문자열은 \(a\)가 \(n - r\)개, \(b\)가 \(r\)개인 같은 것이 있는 순열입니다. 그래서 계수는 \(\frac{n!}{(n - r)!r!} = {}_{n}\mathrm{C}_{r}\)로도 구해집니다. 바둑판 길의 최단 경로 수와 같은 수인 것도 이 때문입니다. 막대 높이를 \(n\)마다 한 줄씩 쌓으면 파스칼의 삼각형이 됩니다.
  5. 적용\(n = 4\)에서 칸을 눌러 \(b\)를 두 번 고르는 선택을 서로 다르게 여러 개 만들어 보세요. 모두 몇 가지이고, 가운데 막대의 높이와 같나요? '다음 선택'을 \(2^n\)번 누르면 모든 선택을 한 번씩 지나갑니다. 그동안 막대마다 몇 번씩 강조되나요? \(n\)을 바꾸며 막대 높이의 합이 얼마인지도 확인하세요.
  6. 판단\((a + b)^n\)을 \(a^n + b^n\)으로 쓰는 실수가 흔합니다. 그것은 인수마다 모두 \(a\)를 고르거나 모두 \(b\)를 고르는 두 경우만 센 것입니다. 또 일반항의 \(r\)는 \(b\)의 지수이므로 '\(r\)번째 항'이 아니라 '\(r + 1\)번째 항'입니다. \(a, b\) 자리에 \(2x\), \(-1\) 같은 식이 들어가면 계수에 \(2^{n-r}\)와 \((-1)^r\)도 곱해집니다.

1.3.2

이항계수를 삼각형으로 쌓으면 어떤 규칙이 보일까?

파스칼의 삼각형 · 이항계수의 성질

—

삼각형의 수를 눌러 고르세요. \(n\)행의 왼쪽에서 \(r\)번째(0부터 셈) 수가 \({}_{n}\mathrm{C}_{r}\)입니다.

  1. 질문\((a + b)^0, (a + b)^1, (a + b)^2, \cdots\)의 계수를 한 줄씩 쌓으면, 전개하지 않고도 다음 줄을 쓸 수 있을까요?
  2. 복원\((a + b)^n\)의 전개식에서 \(a^{n-r}b^r\)의 계수는 이항계수 \({}_{n}\mathrm{C}_{r}\)입니다. 또 \({}_{n}\mathrm{C}_{r} = {}_{n}\mathrm{C}_{n-r}\)입니다.
  3. 설명이항계수를 \(n = 0\)부터 차례로 쌓은 것을 파스칼의 삼각형이라고 합니다. 각 행의 양 끝은 1이고, 나머지 수는 바로 위 왼쪽과 오른쪽 두 수의 합입니다. 이것이 \({}_{n}\mathrm{C}_{r} = {}_{n-1}\mathrm{C}_{r-1} + {}_{n-1}\mathrm{C}_{r}\)입니다. \((a + b)^n = (a + b)^{n-1}(a + b)\)에서 \(a^{n-r}b^r\)는 앞 줄의 \(a^{n-r}b^{r-1}\)에 \(b\)를 곱하거나 \(a^{n-1-r}b^r\)에 \(a\)를 곱해서만 생기기 때문입니다. 각 행이 좌우 대칭인 것은 \({}_{n}\mathrm{C}_{r} = {}_{n}\mathrm{C}_{n-r}\)를 뜻합니다.
  4. 연결이항정리에 \(a = b = 1\)을 넣으면 \({}_{n}\mathrm{C}_{0} + {}_{n}\mathrm{C}_{1} + \cdots + {}_{n}\mathrm{C}_{n} = 2^n\)이고, \(a = 1\), \(b = -1\)을 넣으면 번갈아 더하고 뺀 값이 0입니다\((n \ge 1)\). 두 식을 더하고 2로 나누면 짝수 번째 수들의 합이 \(2^{n-1}\)입니다. 대각선을 따라 더한 합은 그 끝에서 한 칸 아래 오른쪽(또는 왼쪽)의 수가 됩니다. 예를 들어 \({}_{2}\mathrm{C}_{2} + {}_{3}\mathrm{C}_{2} + {}_{4}\mathrm{C}_{2} = {}_{5}\mathrm{C}_{3}\)입니다. 위의 두 수 규칙을 맨 아래 칸부터 거듭 쓰면 이 식이 나옵니다.
  5. 적용'위의 두 수'에서 여러 수를 눌러 덧셈 규칙을 확인하세요. '행의 합'으로 바꾸어 \(N\)을 늘리면서 합이 어떻게 변하는지, 번갈아 더한 값은 얼마인지 보세요. '대각선 합'에서는 아래쪽 수를 눌러 위로 이어지는 대각선의 합이 어느 수와 같은지 찾으세요. '홀수만 칠하기'를 켜고 \(N\)을 12까지 늘리면 어떤 무늬가 보이나요?
  6. 판단행 번호와 자리 번호는 0부터 셉니다. 맨 위 1은 0행이고, 각 행의 첫 1은 \({}_{n}\mathrm{C}_{0}\)입니다. 1부터 세면 계수가 한 칸씩 어긋납니다. 또 홀수 무늬는 \(N\)이 작을 때 보이는 모양에서 짐작한 것입니다. 그림에서 짐작한 규칙은 덧셈 규칙이나 이항정리로 따져 보아야 성질이라고 말할 수 있습니다.
