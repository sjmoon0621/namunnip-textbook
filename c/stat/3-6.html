표본평균과 표본비율

같은 모집단에서 표본을 다시 뽑으면 표본평균은 조금 다른 값이 나옵니다. 표본평균은 정해진 수가 아니라 뽑힌 표본에 따라 값이 달라지는 확률변수입니다. 이 절에서는 표본을 수없이 뽑아 표본평균과 표본비율의 분포를 직접 쌓아 보고, 그 분포의 평균과 표준편차가 모평균, 모비율, 표본의 크기와 어떤 관계인지 찾습니다.

먼저 알면 좋은 것 임의추출이항분포의 평균과 표준편차정규분포와 표준화

3.6.1

표본을 크게 뽑으면 표본평균은 덜 흔들릴까?

표본평균의 분포 · σ/√n
뽑은 표본 수
—
x̄들의 평균
—
x̄들의 표준편차
—
σ/√n
—

사과 한 개의 무게(g)가 정규분포 N(300, 202)을 따른다고 가정한 모식입니다. 점선은 모집단의 분포, 막대는 지금까지 뽑은 x̄들의 히스토그램(넓이 합 1), 초록 곡선은 N(300, 202/n)입니다. 주황 삼각형은 마지막 x̄입니다.

  1. 질문사과 4개의 평균 무게와 64개의 평균 무게 중 어느 쪽이 과수원 전체의 평균 무게에 더 가까울까요? '더 가깝다'를 수로 나타낼 수 있을까요?
  2. 복원확률변수의 평균, 분산, 표준편차를 구할 수 있고, E(aX + b) = aE(X) + b, V(aX + b) = a2V(X)입니다. 정규분포의 확률은 표준화해서 구합니다.
  3. 설명모집단의 평균, 분산, 표준편차를 각각 모평균 m, 모분산 σ2, 모표준편차 σ라고 합니다. 모집단에서 임의추출한 크기가 n인 표본 X1, X2, …, Xn에 대하여 X̄ = (X1 + X2 + ⋯ + Xn)/n을 표본평균, S2 = {(X1 − X̄)2 + ⋯ + (Xn − X̄)2}/(n − 1)을 표본분산, S를 표본표준편차라고 합니다. X̄는 표본마다 값이 다른 확률변수이며 E(X̄) = m, V(X̄) = σ2/n, σ(X̄) = σ/√n입니다. 특히 모집단이 정규분포 N(m, σ2)을 따르면 X̄는 정규분포 N(m, σ2/n)을 따릅니다.
  4. 연결표본의 크기를 4배로 늘리면 σ(X̄)는 절반이 됩니다. 임의추출한 표본이면 x̄가 n이 클수록 m 가까이 모이므로, 다음 절에서는 x̄ 하나로 m이 있을 만한 범위를 추정합니다.
  5. 적용n = 4에서 '표본 100개'를 여러 번 눌러 x̄들의 표준편차를 σ/√n과 비교해 보세요. n을 16, 64로 바꾸면 표준편차는 몇 배가 되나요? x̄들의 평균은 n에 따라 달라지나요? n = 1이면 막대는 어느 곡선과 겹치나요?
  6. 판단표본분산은 n이 아니라 n − 1로 나눕니다. n으로 나누면 평균적으로 모분산보다 작게 나오기 때문입니다. 또 σ(X̄) = σ/√n은 복원추출이거나 모집단이 표본보다 충분히 클 때의 식입니다. 모집단이 정규분포가 아니어도 n이 크면 X̄의 분포는 정규분포에 가까워지지만, 여기서는 모집단이 정규분포인 경우만 다룹니다.

확인조건이 달라지면

정규분포 N(60, 102)을 따르는 모집단에서 크기가 25인 표본을 임의추출할 때, 표본평균 X̄에 대하여 P(X̄ ≥ 64)는? (단, P(0 ≤ Z ≤ 0.4) = 0.1554, P(0 ≤ Z ≤ 1) = 0.3413, P(0 ≤ Z ≤ 2) = 0.4772)

3.6.2

100명에게 물으면 찬성 비율은 얼마나 흔들릴까?

표본비율의 분포 · √(pq/n)
뽑은 표본 수
—
p̂들의 평균
—
p̂들의 표준편차
—
√(pq/n)
—

모비율이 p인 모집단에서 크기가 n인 표본을 임의추출해 표본비율 p̂를 기록합니다. 막대는 p̂들의 히스토그램(넓이 합 1), 초록 곡선은 N(p, pq/n), 주황 점선은 p의 위치입니다.

  1. 질문어느 도시 유권자의 30%가 한 정책에 찬성한다고 합시다. 100명을 임의추출해 물으면 찬성 비율이 꼭 30%로 나올까요? 몇 %p 정도까지 벗어날 수 있을까요?
  2. 복원성공 확률이 p인 독립시행을 n번 할 때 성공 횟수 X는 B(n, p)를 따르고 E(X) = np, V(X) = npq입니다(q = 1 − p). n이 충분히 크면 B(n, p)는 N(np, npq)에 가깝습니다.
  3. 설명모집단에서 어떤 특성을 가진 대상의 비율을 모비율 p, 크기가 n인 표본에서 그 특성을 가진 대상의 비율을 표본비율 p̂ = X/n이라고 합니다. X가 B(n, p)를 따르므로 E(p̂) = p, V(p̂) = pq/n, σ(p̂) = √(pq/n)입니다. V(p̂) = V(X)/n2 = npq/n2이기 때문입니다. n이 충분히 크면 p̂는 근사적으로 정규분포 N(p, pq/n)을 따릅니다.
  4. 연결표본평균과 마찬가지로 표본비율도 평균은 모비율과 같고, 표준편차는 √n에 반비례합니다. 여론조사가 결과와 함께 '표본 오차'를 밝히는 까닭이 이것이며, 다음 절에서 이 값으로 모비율의 범위를 추정합니다.
  5. 적용n = 25와 n = 400에서 p̂들의 표준편차를 비교해 보세요. 몇 배 차이가 나나요? p를 0.5와 0.1로 바꾸면 같은 n에서 더 넓게 퍼지는 쪽은 어디인가요? n = 25, p = 0.1일 때 막대가 곡선과 잘 맞나요?
  6. 판단정규분포 근사는 n이 클 때만 씁니다. np나 nq가 작으면(대략 5보다 작으면) p̂의 분포는 한쪽으로 치우쳐 종 모양이 아닙니다. 또 p̂의 퍼짐은 표본의 크기 n에 달려 있고 모집단의 크기와는 거의 상관없습니다. 모집단이 표본보다 충분히 크다면, 같은 n으로 조사할 때 나라 전체와 한 도시의 정밀도가 비슷합니다.
