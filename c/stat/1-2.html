중복조합

과일 가게에서 사과, 배, 감 가운데 5개를 산다고 합시다. 같은 과일을 여러 개 골라도 되고, 고르는 순서는 상관없습니다. 이처럼 중복을 허락하되 순서를 따지지 않는 선택이 중복조합입니다. 이 절에서는 중복조합을 공과 칸막이의 배열로 바꾸어 그 수가 n+r−1Cr가 되는 까닭을 확인합니다. 같은 생각으로 방정식의 정수해 개수를 세 봅니다.

세로 막대(칸막이)를 끌어서 다른 칸으로 옮겨 보세요. 칸막이는 서로 지나칠 수 없습니다.

  1. 질문사과, 배, 감 세 종류에서 과일 5개를 사려고 합니다. 같은 과일을 여러 개 사도 되고, 한 종류를 사지 않아도 됩니다. 담는 순서는 상관없다면 살 수 있는 방법은 몇 가지일까요?
  2. 복원서로 다른 n개에서 순서 없이 r개를 고르는 조합의 수는 nCr입니다. 같은 것이 있는 순열에서는 공 r개와 막대 k개를 한 줄로 늘어놓는 방법이 (r + k)!/(r!k!)가지입니다.
  3. 설명서로 다른 n종류에서 중복을 허락하여 순서 없이 r개를 택하는 조합을 중복조합이라 하고, 그 수를 nHr로 나타냅니다. 고른 결과는 '종류마다 몇 개'만으로 정해집니다. 그래서 고른 r개를 공으로 그리고, 종류 사이에 칸막이 n − 1개를 세우면 고르는 방법 하나가 공과 칸막이의 배열 하나와 짝지어집니다. 첫 칸막이 앞의 공 수가 첫째 종류의 개수, 두 칸막이 사이의 공 수가 다음 종류의 개수입니다. 이 배열의 수는 r + n − 1개의 자리에서 공이 놓일 r자리를 고르는 수와 같으므로 nHr = n+r−1Cr입니다. 사과·배·감 5개이면 3H5 = 7C5 = 21가지입니다.
  4. 연결중복을 허락하므로 nHr에서는 r가 n보다 커도 됩니다. 여기에 순서까지 따지면 중복순열 nΠr = nr가 됩니다. 똑같은 사탕 r개를 n명에게 나누어 주는 방법, 같은 색 공 r개를 서로 다른 상자 n개에 넣는 방법도 모두 nHr가지입니다. 또 집합 {1, 2, …, r}에서 {1, 2, …, n}으로 가는 함수 가운데 f(1) ≤ f(2) ≤ ⋯ ≤ f(r)인 것의 개수도 nHr입니다. 함숫값 r개를 중복을 허락해 고르면 크기 순서는 저절로 정해지기 때문입니다.
  5. 적용n = 3, r = 5로 두고 칸막이를 끌어 '사과 0, 배 5, 감 0'을 만들어 보세요. 칸막이가 맨 앞에 붙어 있을 때 무엇을 뜻하나요? '다음 경우'를 계속 눌러 마지막 경우가 몇 번째인지 보고 3H5와 비교하세요. r를 n보다 작게 했을 때와 크게 했을 때 nCr, nHr, nΠr는 각각 어떻게 되나요?
  6. 판단nHr를 n+r−1Cn으로 쓰는 실수가 흔합니다. 전체 자리 n + r − 1개 가운데 고르는 것은 공 r자리 또는 칸막이 n − 1자리입니다. 그래서 n+r−1Cr = n+r−1Cn−1입니다. 또 '종류마다 적어도 하나씩' 같은 조건이 붙으면 그만큼 먼저 하나씩 담아 두고, 남은 개수로 중복조합을 셉니다.

1.2.2

x + y + z = r를 만족하는 정수해는 몇 개일까?

중복조합 · 방정식의 해 세기
고른 해 (x, y, z)
—
이 x에서 가능한 y의 개수
—
해의 개수 (점의 수)
—
중복조합으로 계산
—

진한 점이 조건을 만족하는 해이고, 흐린 점은 음이 아닌 정수해 가운데 조건을 만족하지 않는 것입니다. 진한 점을 끌어 다른 해를 골라 보세요.

  1. 질문방정식 x + y + z = 6을 만족하는 음이 아닌 정수 x, y, z의 순서쌍은 몇 개일까요? 자연수해만 세면 몇 개로 줄어들까요?
  2. 복원서로 다른 n종류에서 중복을 허락하여 r개를 고르는 방법의 수는 nHr = n+r−1Cr입니다. 고른 결과는 종류마다 몇 개를 골랐는지로 정해집니다.
  3. 설명해 (x, y, z)를 'x, y, z 세 종류에서 모두 r개를 고를 때, x를 x개, y를 y개, z를 z개 고른 것'으로 읽으면 해 하나가 중복조합 하나와 짝지어집니다. 그래서 음이 아닌 정수해의 개수는 3Hr이고, r = 6이면 3H6 = 8C6 = 28개입니다. 그림에서도 셀 수 있습니다. x를 정하면 y는 0부터 r − x까지 r − x + 1개이므로 1 + 2 + ⋯ + (r + 1)개입니다. 자연수해처럼 변수마다 최솟값 k가 있으면 x = x′ + k처럼 바꾸어 x′ + y′ + z′ = r − 3k의 음이 아닌 정수해를 셉니다. 자연수해(k = 1)는 3Hr−3개입니다.
  4. 연결변수가 n개인 x1 + x2 + ⋯ + xn = r의 음이 아닌 정수해는 nHr개입니다. 이것은 똑같은 공 r개를 서로 다른 상자 n개에 나누어 넣는 방법의 수와 같은 문제입니다. 부등식 x + y + z ≤ r은 남는 양을 w ≥ 0으로 두고 x + y + z + w = r로 바꾸어 4Hr로 셉니다.
  5. 적용r = 6, k = 0에서 점을 하나씩 끌어 x를 바꾸어 가며 '이 x에서 가능한 y의 개수'를 적어 보세요. 그 합이 중복조합 값과 같나요? k를 1로 올리면 진한 점의 삼각형은 어떻게 줄어들고, 그 삼각형은 r가 얼마일 때의 그림과 같은 모양인가요?
  6. 판단3H6을 6H3으로 바꾸어 쓰는 실수가 흔합니다. H 앞의 수는 고를 종류의 수(변수의 개수)이고, 뒤의 수는 고르는 개수(합)입니다. 3H6 = 28이고 6H3 = 56이어서 값이 다릅니다. 또 조건이 'x ≥ 1'처럼 일부 변수에만 붙으면 그 변수만 바꾸어 합에서 빼야 합니다.
