기댓값과 표준편차

복권 한 장을 사면 평균 얼마를 받을까요? 확률분포를 알면 값마다 확률을 곱해 더하는 것으로 '평균적으로 기대되는 값'을 구할 수 있습니다. 이 절에서는 기댓값을 분포의 무게중심으로 보고, 값들이 평균에서 얼마나 퍼져 있는지를 분산과 표준편차로 잽니다. 단위를 바꾸거나 점수를 환산할 때 이 값들이 어떻게 변하는지도 확인합니다.

막대를 위아래로 끌어 비율을 바꿉니다. 막대 위의 수가 확률이며, 모든 막대의 확률 합은 늘 1이 되도록 맞춥니다.

  1. 질문값이 0부터 4까지인 두 확률변수가 있습니다. 어느 쪽이 '평균적으로' 더 큰 값을 내고, 어느 쪽이 더 들쑥날쑥한지 확률분포만 보고 수 하나로 말할 수 있을까요?
  2. 복원자료의 평균은 (변량의 합) ÷ (자료 수)이고, 도수분포표에서는 ∑(계급값 × 도수) ÷ (도수의 합)입니다. 분산은 편차의 제곱의 평균, 표준편차는 그 양의 제곱근입니다.
  3. 설명이산확률변수 X가 x1, …, xn을 확률 p1, …, pn로 가질 때, 기댓값(평균)은 E(X) = ∑xipi입니다. 상대도수가 확률로 바뀐 평균이라고 보면 됩니다. 평균을 m이라 하면 분산은 V(X) = ∑(xi − m)2pi이고, 전개하면 V(X) = E(X2) − {E(X)}2입니다. 표준편차는 σ(X) = √V(X)로, X와 단위가 같습니다. 막대를 무게로 보면 E(X)는 시소가 수평을 이루는 받침점, 곧 무게중심입니다.
  4. 연결기댓값은 게임이 공정한지, 보험료가 적절한지 판단하는 데 씁니다. 뒤에서 배울 이항분포와 정규분포도 평균과 표준편차 두 수로 모양이 정해집니다.
  5. 적용'대칭'에서 x = 0과 x = 4의 막대만 같은 만큼 키워 보세요. 받침점은 그대로인데 무엇이 커지나요? '한쪽으로 치우침'에서 받침점은 가장 높은 막대와 같은 곳에 있나요? '한 값'에서 σ(X)는 얼마인가요?
  6. 판단기댓값은 '가장 자주 나오는 값'이나 '실제로 나올 수 있는 값'이 아닙니다. 주사위 눈의 기댓값 3.5는 한 번도 나오지 않습니다. 또 V(X) = E(X2) − {E(X)}2에서 E(X2)를 {E(X)}2로 착각하면 분산이 늘 0이 되는 이상한 결과가 나옵니다.

X는 주사위 한 개의 눈으로 E(X) = 3.5, V(X) = 35/12, σ(X) ≈ 1.708입니다. E(Y)와 σ(Y)는 Y의 여섯 값으로 직접 계산한 값입니다.

  1. 질문시험 점수를 모두 2배로 하고 5점을 빼서 환산하면 평균은 쉽게 짐작됩니다. 점수가 흩어진 정도, 곧 표준편차도 2배에서 5를 뺀 값이 될까요?
  2. 복원E(X) = ∑xipi, V(X) = ∑(xi − m)2pi, σ(X) = √V(X)입니다. 확률의 합 ∑pi는 1입니다.
  3. 설명Y = aX + b는 X의 값마다 axi + b를 같은 확률 pi로 갖습니다. 그래서 E(Y) = ∑(axi + b)pi = a∑xipi + b∑pi = aE(X) + b입니다. 편차는 (axi + b) − (am + b) = a(xi − m)로 b가 사라지므로 V(aX + b) = a2V(X), σ(aX + b) = |a|σ(X)입니다. 모든 값을 똑같이 옮기는 b는 퍼짐을 바꾸지 못하고, 간격을 늘리는 a만 퍼짐을 바꿉니다.
  4. 연결섭씨온도를 화씨온도로 바꾸는 F = 1.8C + 32, 원을 달러로 바꾸는 환산도 모두 aX + b 꼴입니다. 뒤에서 정규분포를 표준화할 때 쓰는 Z = (X − m)/σ도 a = 1/σ, b = −m/σ인 경우로, 평균 0, 표준편차 1이 되는 까닭이 이 성질입니다.
  5. 적용a를 1에 두고 b만 움직여 보세요. 분포는 어떻게 움직이고, σ(Y)는 변하나요? a를 −2로 하면 분포가 어떻게 놓이고, σ(Y)는 음수가 되나요? a = 0이면 무엇이 보이나요?
  6. 판단"σ(2X − 5) = 2σ(X) − 5"나 "V(2X) = 2V(X)"는 흔한 실수입니다. 더하는 수는 퍼짐과 무관하고, 분산은 제곱 단위라서 a2배가 됩니다. 표준편차는 0 이상이므로 a가 음수여도 |a|배입니다.
