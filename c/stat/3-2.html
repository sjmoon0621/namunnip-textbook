기댓값과 표준편차

복권 한 장을 사면 평균 얼마를 받을까요? 확률분포를 알면 값마다 확률을 곱해 더하는 것으로 '평균적으로 기대되는 값'을 구할 수 있습니다. 이 절에서는 기댓값을 분포의 무게중심으로 보고, 값들이 평균에서 얼마나 퍼져 있는지를 분산과 표준편차로 잽니다. 단위를 바꾸거나 점수를 환산할 때 이 값들이 어떻게 변하는지도 확인합니다.

3.2.1

확률분포의 '가운데'와 '퍼짐'은 어디서 읽을까?

기댓값 · 분산 · 표준편차
\(E(X) = \sum xP\)
—
\(E(X^2) = \sum x^2P\)
—
\(V(X)\)
—
\(\sigma(X) = \sqrt{V(X)}\)
—

막대를 위아래로 끌어 비율을 바꿉니다. 막대 위의 수가 확률이며, 모든 막대의 확률 합은 늘 1이 되도록 맞춥니다.

  1. 질문값이 0부터 4까지인 두 확률변수가 있습니다. 어느 쪽이 '평균적으로' 더 큰 값을 내고, 어느 쪽이 더 들쑥날쑥한지 확률분포만 보고 수 하나로 말할 수 있을까요?
  2. 복원자료의 평균은 \((\text{변량의 합}) \div (\text{자료 수})\)이고, 도수분포표에서는 \(\sum(\text{계급값} \times \text{도수}) \div (\text{도수의 합})\)입니다. 분산은 편차의 제곱의 평균, 표준편차는 그 양의 제곱근입니다.
  3. 설명이산확률변수 \(X\)가 \(x_1, \cdots, x_n\)을 확률 \(p_1, \cdots, p_n\)로 가질 때, 기댓값(평균)은 \(E(X) = \sum x_ip_i\)입니다. 상대도수가 확률로 바뀐 평균이라고 보면 됩니다. 평균을 \(m\)이라 하면 분산은 \(V(X) = \sum(x_i - m)^2p_i\)이고, 전개하면 \(V(X) = E(X^2) - \{E(X)\}^2\)입니다. 표준편차는 \(\sigma(X) = \sqrt{V(X)}\)로, \(X\)와 단위가 같습니다. 막대를 무게로 보면 \(E(X)\)는 시소가 수평을 이루는 받침점, 곧 무게중심입니다.
  4. 연결기댓값은 게임이 공정한지, 보험료가 적절한지 판단하는 데 씁니다. 뒤에서 배울 이항분포와 정규분포도 평균과 표준편차 두 수로 모양이 정해집니다.
  5. 적용'대칭'에서 \(x = 0\)과 \(x = 4\)의 막대만 같은 만큼 키워 보세요. 받침점은 그대로인데 무엇이 커지나요? '한쪽으로 치우침'에서 받침점은 가장 높은 막대와 같은 곳에 있나요? '한 값'에서 \(\sigma(X)\)는 얼마인가요?
  6. 판단기댓값은 '가장 자주 나오는 값'이나 '실제로 나올 수 있는 값'이 아닙니다. 주사위 눈의 기댓값 3.5는 한 번도 나오지 않습니다. 또 \(V(X) = E(X^2) - \{E(X)\}^2\)에서 \(E(X^2)\)를 \(\{E(X)\}^2\)로 착각하면 분산이 늘 0이 되는 이상한 결과가 나옵니다.

3.2.2

점수를 두 배 하고 5점을 더하면 표준편차는?

\(E(aX + b) \cdot \sigma(aX + b)\)
\(E(Y)\)
—
\(aE(X) + b\)
—
\(\sigma(Y)\)
—
\(|a|\sigma(X)\)
—

\(X\)는 주사위 한 개의 눈으로 \(E(X) = 3.5\), \(V(X) = \frac{35}{12}\), \(\sigma(X) \approx 1.708\)입니다. \(E(Y)\)와 \(\sigma(Y)\)는 \(Y\)의 여섯 값으로 직접 계산한 값입니다.

  1. 질문시험 점수를 모두 2배로 하고 5점을 빼서 환산하면 평균은 쉽게 짐작됩니다. 점수가 흩어진 정도, 곧 표준편차도 2배에서 5를 뺀 값이 될까요?
  2. 복원\(E(X) = \sum x_ip_i\), \(V(X) = \sum(x_i - m)^2p_i\), \(\sigma(X) = \sqrt{V(X)}\)입니다. 확률의 합 \(\sum p_i\)는 1입니다.
  3. 설명\(Y = aX + b\)는 \(X\)의 값마다 \(ax_i + b\)를 같은 확률 \(p_i\)로 갖습니다. 그래서 \(E(Y) = \sum(ax_i + b)p_i = a\sum x_ip_i + b\sum p_i\) = \(aE(X) + b\)입니다. 편차는 \((ax_i + b) - (am + b) = a(x_i - m)\)로 \(b\)가 사라지므로 \(V(aX + b) = a^2V(X)\), \(\sigma(aX + b) = |a|\sigma(X)\)입니다. 모든 값을 똑같이 옮기는 \(b\)는 퍼짐을 바꾸지 못하고, 간격을 늘리는 \(a\)만 퍼짐을 바꿉니다.
  4. 연결섭씨온도를 화씨온도로 바꾸는 \(F = 1.8C + 32\), 원을 달러로 바꾸는 환산도 모두 \(aX + b\) 꼴입니다. 뒤에서 정규분포를 표준화할 때 쓰는 \(Z = \frac{X - m}{\sigma}\)도 \(a = \frac{1}{\sigma}\), \(b = -\frac{m}{\sigma}\)인 경우로, 평균 0, 표준편차 1이 되는 까닭이 이 성질입니다.
  5. 적용\(a\)를 1에 두고 \(b\)만 움직여 보세요. 분포는 어떻게 움직이고, \(\sigma(Y)\)는 변하나요? \(a\)를 \(-2\)로 하면 분포가 어떻게 놓이고, \(\sigma(Y)\)는 음수가 되나요? \(a = 0\)이면 무엇이 보이나요?
  6. 판단"\(\sigma(2X - 5) = 2\sigma(X) - 5\)"나 "\(V(2X) = 2V(X)\)"는 흔한 실수입니다. 더하는 수는 퍼짐과 무관하고, 분산은 제곱 단위라서 \(a^2\)배가 됩니다. 표준편차는 0 이상이므로 \(a\)가 음수여도 \(|a|\)배입니다.
