동전을 세 번 던지면 '앞뒤앞', '뒤뒤앞'처럼 결과가 8가지이다. 이 결과들은 그대로는 더하거나 평균을 낼 수 없다. 그런데 각 결과에 '앞면의 개수'라는 수를 붙이면 0, 1, 2, 3 가운데 하나가 되어 계산할 수 있다. 결과에 수를 붙이면 무엇이 달라질까?

먼저 알아야 할 것표본공간과 사건, 수학적 확률(확률의 뜻과 기본 성질), 독립시행의 확률(확률의 곱셈정리), 함수의 뜻.

3.1.1확률변수

동전을 세 번 던지는 시행의 표본공간은 앞앞앞, 앞앞뒤, …, 뒤뒤뒤의 8가지이다. 각 결과에 앞면의 개수를 대응시키면, 앞앞앞은 3, 앞뒤앞은 2, 뒤뒤뒤는 0이 된다. 다시 말해 표본공간의 각 원소에 실수 하나를 대응시키는 함수를 만든 것이다. 이런 함수를 확률변수라 하고 보통 \(X\)처럼 대문자로 쓴다.

확률변수 \(X\)가 어떤 값을 가질 확률도 정할 수 있다. \(X = 2\)인 결과는 앞앞뒤, 앞뒤앞, 뒤앞앞의 3가지이므로 \(P(X = 2) = \tfrac{3}{8}\)이다. 같은 방법으로 \(P(X = 0) = \tfrac{1}{8}\), \(P(X = 1) = \tfrac{3}{8}\), \(P(X = 3) = \tfrac{1}{8}\)이다.

정의 3.1.1 이산확률변수와 확률분포

확률변수 \(X\)가 가질 수 있는 값이 \(x_1, x_2, \ldots, x_n\)처럼 셀 수 있을 때 \(X\)를 이산확률변수라 한다. 각 값과 그 값을 가질 확률 \(P(X = x_i) = p_i\)의 대응을 \(X\)의 확률분포라 하며, \(0 \le p_i \le 1\)이고 \(p_1 + p_2 + \cdots + p_n = 1\)이다.

그림 1의 슬라이더로 동전 개수를 바꾸어 보자. 막대의 개수는 \(n + 1\)개이고, 가운데가 가장 높은 대칭 모양이 된다. 막대 높이의 합이 언제나 1인 것은, 어떤 결과든 \(X\)의 값 가운데 정확히 하나를 갖기 때문이다.

3.1.2연속확률변수

버스를 기다리는 시간처럼 0분부터 10분 사이의 모든 실수 값을 가질 수 있는 확률변수도 있다. 이런 확률변수를 연속확률변수라 한다. 값이 셀 수 없이 많으므로 '정확히 3분'일 확률은 0이고, 대신 '2분에서 4분 사이'처럼 범위의 확률을 생각한다. 이때 확률은 확률밀도함수의 그래프 아래 넓이로 나타내며, 전체 넓이는 1이다.1

3.1.3예제 하나를 끝까지

예제 3.1.2

한 개의 주사위를 두 번 던져 나온 눈 가운데 큰 값을 \(X\)라 할 때(같으면 그 값), \(X\)의 확률분포를 구하고 \(P(X \ge 5)\)를 구하여라.

\(X \le k\)는 두 눈이 모두 \(k\) 이하인 경우이므로 \(P(X \le k) = \dfrac{k^2}{36}\)이다. 그러면 \(P(X = k) = P(X \le k) - P(X \le k - 1) = \dfrac{k^2 - (k - 1)^2}{36} = \dfrac{2k - 1}{36}\)이다.

따라서 \(X\)가 1, 2, 3, 4, 5, 6일 확률은 \(\tfrac{1}{36}, \tfrac{3}{36}, \tfrac{5}{36}, \tfrac{7}{36}, \tfrac{9}{36}, \tfrac{11}{36}\)이다. 합은 \(\tfrac{36}{36} = 1\)로 맞는다.

\(P(X \ge 5) = \dfrac{9 + 11}{36} = \dfrac{5}{9}\)이다. 여사건으로 확인하면 \(1 - P(X \le 4) = 1 - \tfrac{16}{36} = \tfrac{20}{36}\)으로 같다. 큰 값을 취하면 큰 수가 나오기 쉬워져 분포가 오른쪽으로 기운다. 아래 탐구 카드에서 결과에 수를 붙여 확률분포를 직접 만들어 보자.

  1. 0분부터 10분까지 어느 시각이든 같은 가능성으로 버스가 온다면 확률밀도함수는 높이 \(\tfrac{1}{10}\)인 직선이고, 2분에서 4분 사이일 확률은 넓이 \(2 \times \tfrac{1}{10} = 0.2\)이다.
마무리

확률변수는 시행의 결과마다 수를 하나씩 대응시킨 함수이고, 그 값과 확률의 대응이 확률분포이다. 이산확률변수는 값마다 확률을 갖고 그 합이 1이며, 연속확률변수는 범위의 확률을 넓이로 나타낸다. 그래서 처음 질문의 동전 결과에 앞면의 개수를 붙이면 0, 1, 2, 3이 각각 \(\tfrac{1}{8}, \tfrac{3}{8}, \tfrac{3}{8}, \tfrac{1}{8}\)의 확률을 갖는 분포가 되어 평균 같은 계산을 할 수 있다.

막대는 확률, 검은 눈금은 지금까지 던진 결과의 상대도수이다. '처음 앞면이 나온 순서'는 앞면이 한 번도 없으면 0으로 정한다.

  1. 질문동전 세 개를 던지면 결과는 '앞앞뒤', '뒤앞뒤' 같은 글자 8가지이다. 이 글자들로 평균이나 그래프를 만들 수 있을까?
  2. 복원시행에서 일어날 수 있는 모든 결과의 집합이 표본공간이다. 동전 세 개의 표본공간은 원소가 8개이고, 각 결과의 확률은 \(\frac{1}{8}\)로 같다. 그리고 함수는 정의역의 원소마다 값을 하나씩 정해 주는 대응이다.
  3. 설명표본공간의 각 결과에 실수 하나를 대응시키는 함수를 확률변수라 하고 대문자 \(X\)로 쓴다. 그래서 같은 표본공간에서도 무엇을 세느냐에 따라 확률변수가 달라진다. \(X\)가 0, 1, 2, 3처럼 셀 수 있는 값을 가지면 이산확률변수이다. 값 \(x\)마다 그 값을 갖는 결과들의 확률을 더한 \(P(X = x)\)를 정리한 것이 확률분포이고, 이 대응을 함수로 보면 확률질량함수라고 한다. 확률분포는 언제나 \(0 \le P(X = x) \le 1\)이고 모든 값의 확률을 더하면 1이며, \(P(a \le X \le b)\)는 \(a\)부터 \(b\)까지의 값의 확률을 더한 것이다.
  4. 연결확률분포를 알면 결과를 일일이 보지 않고 수만으로 평균과 흩어진 정도를 계산할 수 있다. 또 시행을 많이 되풀이하면 상대도수가 확률에 가까워지므로, 실제 자료의 도수분포와 확률분포를 나란히 비교할 수 있다.
  5. 적용세 확률변수를 차례로 고르고 화살표를 따라가 보면, 여러 결과가 같은 값으로 모이는 곳의 막대가 길다. '\(\text{앞면 수} - \text{뒷면 수}\)'가 가질 수 없는 값을 찾아보고, '100번 던지기'를 여러 번 눌러 상대도수의 눈금이 막대 끝으로 다가가는지도 확인해 보자.
  6. 판단"\(X\)의 값이 0, 1, 2, 3의 네 가지이므로 확률은 각각 \(\frac{1}{4}\)"이라고 생각하기 쉽다. 하지만 값마다 대응되는 결과의 개수가 다르므로 확률도 다르다. 또 확률변수는 이름과 달리 '변하는 수'가 아니라 결과에 수를 붙이는 함수이다.

  1. 질문버스를 기다리는 시간은 0분과 10분 사이의 어떤 값이든 될 수 있다. 가능한 값이 셀 수 없이 많으면, 값 하나하나에 확률을 어떻게 나누어 줄 수 있을까?
  2. 복원이산확률변수는 값마다 확률이 있고, 그 합이 1이다. 그리고 그래프 아래 넓이는 직사각형, 삼각형, 사다리꼴로 계산할 수 있다.
  3. 설명시간, 길이, 무게처럼 어떤 구간의 모든 실수 값을 가질 수 있는 확률변수를 연속확률변수라고 한다. 연속확률변수는 값 하나가 아니라 구간에 확률을 준다. 함수 \(f(x)\)가 \(f(x) \ge 0\)이고, 그래프와 \(x\)축 사이의 전체 넓이가 1이며, \(P(a \le X \le b)\)가 \(x = a\)부터 \(x = b\)까지 그래프 아래 넓이와 같을 때, \(f(x)\)를 \(X\)의 확률밀도함수라고 한다. 그런데 폭이 0인 구간의 넓이는 0이므로 \(P(X = a) = 0\)이고, 그래서 \(P(a \le X \le b) = P(a < X < b)\)이다.
  4. 연결도수분포다각형에서 계급의 폭을 줄이고 자료 수를 늘리면 매끄러운 곡선에 가까워지는데, 그 곡선이 확률밀도함수이다. 키나 측정 오차처럼 종 모양을 이루는 연속확률변수는 이 단원 뒤쪽의 정규분포로 다룬다.
  5. 적용폭을 2분으로 두고 \(a\)를 옮겨 보면 균등 그래프에서는 확률이 그대로이고, 감소 그래프에서는 달라진다. 폭을 0까지 줄여 확률이 얼마가 되는지 보고, 폭을 10으로 하고 \(a = 0\)이면 무엇이 보이는지도 확인해 보자.
  6. 판단높이 \(f(a)\)를 \(P(X = a)\)로 읽는 실수가 많다. 높이는 '그 근처에 값이 얼마나 몰려 있는가'를 나타낼 뿐 확률이 아니다. 그래서 값의 범위가 0부터 0.5까지처럼 좁으면 넓이가 1이 되도록 높이가 2가 되기도 하고, 높이는 1보다 클 수도 있다.
