확률변수와 확률분포

동전 세 개를 던진 결과는 '앞뒤앞' 같은 글자입니다. 그런데 우리가 궁금한 것은 대개 '앞면이 몇 개인가' 같은 수입니다. 이 절에서는 결과마다 수를 하나씩 붙이는 확률변수를 만들고, 그 수가 어떤 확률로 나오는지 정리한 확률분포를 표와 그래프로 봅니다. 대기 시간처럼 값이 연속으로 변하면 확률을 넓이로 잽니다.

막대는 확률, 검은 눈금은 지금까지 던진 결과의 상대도수입니다. '처음 앞면이 나온 순서'는 앞면이 한 번도 없으면 0으로 정합니다.

  1. 질문동전 세 개를 던지면 결과는 '앞앞뒤', '뒤앞뒤' 같은 글자 8가지입니다. 이 글자들로 평균이나 그래프를 만들 수 있을까요?
  2. 복원시행에서 일어날 수 있는 모든 결과의 집합이 표본공간입니다. 동전 세 개의 표본공간은 원소가 8개이고, 각 결과의 확률은 1/8로 같습니다. 함수는 정의역의 원소마다 값을 하나씩 정해 주는 대응입니다.
  3. 설명표본공간의 각 결과에 실수 하나를 대응시키는 함수를 확률변수라 하고 대문자 X로 씁니다. 같은 표본공간에서도 무엇을 세느냐에 따라 확률변수가 달라집니다. X가 0, 1, 2, 3처럼 셀 수 있는 값을 가지면 이산확률변수입니다. 값 x마다 그 값을 갖는 결과들의 확률을 더한 P(X = x)를 정리한 것이 확률분포이고, 이 대응을 함수로 보면 확률질량함수라고 합니다. 확률분포는 언제나 0 ≤ P(X = x) ≤ 1이고, 모든 값의 확률을 더하면 1입니다. 또 P(a ≤ X ≤ b)는 a부터 b까지의 값의 확률을 더한 것입니다.
  4. 연결확률분포를 알면 결과를 일일이 보지 않고 수만으로 평균과 흩어진 정도를 계산할 수 있습니다. 시행을 많이 되풀이하면 상대도수가 확률에 가까워지므로, 실제 자료의 도수분포와 확률분포를 나란히 비교할 수 있습니다.
  5. 적용세 확률변수를 차례로 고르고 화살표를 따라가 보세요. 여러 결과가 같은 값으로 모이는 곳의 막대가 깁니다. '앞면 수 − 뒷면 수'는 어떤 값을 가질 수 없나요? '100번 던지기'를 여러 번 눌러 상대도수의 눈금이 막대 끝으로 다가가는지 확인하세요.
  6. 판단"X의 값이 0, 1, 2, 3의 네 가지이므로 확률은 각각 1/4"이라고 생각하기 쉽습니다. 값마다 대응되는 결과의 개수가 다르므로 확률도 다릅니다. 또 확률변수는 이름과 달리 '변하는 수'가 아니라 결과에 수를 붙이는 함수입니다.

버스가 10분 간격으로 오는 정류장에서 기다리는 시간 X(분)입니다. '감소' 그래프는 짧게 기다리는 경우가 많은 상황을 나타낸 모식입니다.

  1. 질문버스를 기다리는 시간은 0분과 10분 사이의 어떤 값이든 될 수 있습니다. 가능한 값이 셀 수 없이 많으면, 값 하나하나에 확률을 어떻게 나누어 줄 수 있을까요?
  2. 복원이산확률변수는 값마다 확률이 있고, 그 합이 1입니다. 그래프 아래 넓이는 직사각형, 삼각형, 사다리꼴로 계산할 수 있습니다.
  3. 설명시간, 길이, 무게처럼 어떤 구간의 모든 실수 값을 가질 수 있는 확률변수를 연속확률변수라고 합니다. 연속확률변수는 값 하나가 아니라 구간에 확률을 줍니다. 함수 f(x)가 (1) f(x) ≥ 0이고 (2) 그래프와 x축 사이의 전체 넓이가 1이며 (3) P(a ≤ X ≤ b)가 x = a부터 x = b까지 그래프 아래 넓이와 같을 때, f(x)를 X의 확률밀도함수라고 합니다. 폭이 0인 구간의 넓이는 0이므로 P(X = a) = 0이고, 그래서 P(a ≤ X ≤ b) = P(a < X < b)입니다.
  4. 연결도수분포다각형에서 계급의 폭을 줄이고 자료 수를 늘리면 매끄러운 곡선에 가까워집니다. 그 곡선이 확률밀도함수입니다. 키, 측정 오차처럼 종 모양을 이루는 연속확률변수는 이 단원 뒤쪽의 정규분포로 다룹니다.
  5. 적용폭을 2분으로 두고 a를 옮겨 보세요. 균등 그래프에서는 확률이 바뀌나요? 감소 그래프에서는 어떤가요? 폭을 0까지 줄이면 확률은 얼마가 되나요? 폭을 10으로 하고 a = 0이면 무엇이 보이나요?
  6. 판단높이 f(a)를 P(X = a)로 읽는 실수가 많습니다. 높이는 '그 근처에 값이 얼마나 몰려 있는가'를 나타낼 뿐 확률이 아닙니다. 값의 범위가 0부터 0.5까지처럼 좁으면 넓이가 1이 되도록 높이가 2가 되기도 하므로, 높이는 1보다 클 수도 있습니다.
