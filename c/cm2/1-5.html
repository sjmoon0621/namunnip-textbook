원과 직선의 위치 관계

원과 직선은 두 점에서 만나거나, 한 점에서 닿거나(접함), 만나지 않습니다. 이 절에서는 그림을 그리지 않고 이 셋을 구별하는 방법 두 가지를 비교합니다. 하나는 방정식을 연립해 판별식을 보는 방법이고, 다른 하나는 중심에서 직선까지의 거리를 반지름과 비교하는 방법입니다. 마지막으로 원에 접하는 직선의 방정식을 구합니다.

1.5.1

원과 직선이 만나는지 그리지 않고 알 수 있을까?

원과 직선의 위치 관계 · 판별식과 거리

—

판별식 \(\frac{D}{4}\)
—
거리 \(d\)와 \(r\)
—
위치 관계
—
  1. 질문원 \(x^2 + y^2 = 9\)와 직선 \(y = x + 2\)는 몇 개의 점에서 만날까요? 그래프를 그리지 않고 판단할 수 있을까요?
  2. 복원두 그래프의 교점은 두 방정식을 연립한 해입니다. 이차방정식 \(ax^2 + 2b'x + c = 0\)은 \(\frac{D}{4} = b'^2 - ac\)가 양수이면 서로 다른 두 실근, 0이면 중근, 음수이면 실근이 없습니다. 점 \((x_1, y_1)\)과 직선 \(ax + by + c = 0\) 사이의 거리는 \(\frac{|ax_1 + by_1 + c|}{\sqrt{a^2 + b^2}}\)입니다.
  3. 설명방법 1 (판별식) \(y = mx + n\)을 원의 방정식에 넣으면 \(x\)에 대한 이차방정식 \((1 + m^2)x^2 + 2mnx + n^2 - r^2 = 0\)이 됩니다. 실근의 개수가 교점의 개수이므로 \(D > 0\)이면 두 점에서 만나고, \(D = 0\)이면 한 점에서 만나며(접한다, 이 직선이 접선, 그 점이 접점), \(D < 0\)이면 만나지 않습니다. 방법 2 (거리) 중심에서 직선까지의 거리를 \(d\)라 하면 \(d < r\)이면 두 점, \(d = r\)이면 접하고, \(d > r\)이면 만나지 않습니다. 실제로 계산하면 \(\frac{D}{4} = (1 + m^2)(r^2 - d^2)\)이어서 두 방법의 판정은 언제나 같습니다.
  4. 연결거리 방법은 중심이 원점이 아닌 원에도 계산이 간단하고, 접선을 구할 때 그대로 쓰입니다. 판별식 방법은 교점의 좌표까지 구해 줍니다. 이차함수의 그래프와 직선의 위치 관계도 판별식으로 판단합니다.
  5. 적용\(n\)을 바꾸면서 \(\frac{D}{4}\)와 \(d - r\)의 부호가 언제 함께 바뀌는지 보세요. '접하는 예'에서 \(\frac{D}{4}\)와 \(d\)는 얼마인가요? \(r = 3, m = 0\)일 때 직선이 원에 접하는 \(n\)을 모두 찾아보세요.
  6. 판단\(\frac{D}{4} < 0\)이면 '실수 범위에서' 교점이 없다는 뜻입니다. 중근은 두 교점이 하나로 겹친 것입니다. 또 판별식 방법에서는 직선의 식을 원의 식에 넣어 한 문자에 대한 이차방정식을 만든 뒤에 판별식을 써야 합니다. \(y\)축에 평행한 직선 \(x = k\)는 \(y\)에 대한 이차방정식이 됩니다.

1.5.2

원 위의 한 점에서 그은 접선의 방정식은?

접점 \(P\)를 원을 따라 끌어 보세요. 좌표가 정수인 점 가까이에서는 그 점에 붙습니다.

  1. 질문원 \(x^2 + y^2 = 25\) 위의 점 \((3, 4)\)에서 원에 닿기만 하고 들어가지 않는 직선을 긋습니다. 이 접선의 방정식은 무엇일까요? 기울기가 1인 접선은 어디에 몇 개 있을까요?
  2. 복원원의 접선은 접점을 지나는 반지름과 수직입니다(중학교). 기울기가 \(m_1, m_2\)인 두 직선이 수직이면 \(m_1m_2 = -1\)입니다. 원과 직선이 접할 조건은 중심에서 직선까지의 거리가 반지름과 같다는 것입니다.
  3. 설명접점 \(P(x_1, y_1)\)이 주어질 때 반지름 \(OP\)의 기울기는 \(\frac{y_1}{x_1}\)이므로 접선의 기울기는 \(-\frac{x_1}{y_1}\)입니다. \(y - y_1 = -(\frac{x_1}{y_1})(x - x_1)\)를 정리하면 \(x_1x + y_1y = x_1^2 + y_1^2\)이고, \(P\)가 원 위에 있으므로 우변이 \(r^2\)입니다. 곧 \(x_1x + y_1y = r^2\)입니다(\(x_1 = 0\) 또는 \(y_1 = 0\)이어도 성립합니다). 기울기 \(m\)이 주어질 때 접선을 \(y = mx + n\), 곧 \(mx - y + n = 0\)으로 놓으면 원점에서의 거리 \(\frac{|n|}{\sqrt{m^2 + 1}}\)이 \(r\)과 같아야 하므로 \(y = mx \pm r\sqrt{m^2 + 1}\)입니다. 기울기가 같은 접선은 원의 양쪽에 하나씩, 두 개입니다.
  4. 연결원 밖의 한 점에서 그은 접선은 기울기를 \(m\)으로 놓고 거리 조건(또는 판별식 \(= 0\))으로 \(m\)을 구합니다. 보통 두 개가 나옵니다. 중심이 \((a, b)\)인 원은 평행이동을 이용하면 접점에서의 접선이 \((x_1 - a)(x - a) + (y_1 - b)(y - b) = r^2\)입니다.
  5. 적용\(r = 5\)에서 \(P\)를 \((3, 4), (-4, 3), (0, 5)\)로 옮기고 접선의 방정식을 확인하세요. 반지름의 기울기와 접선의 기울기의 곱은 얼마인가요? '기울기가 주어질 때'로 바꾸어 \(m\)을 바꾸면 두 접점은 어떤 위치 관계에 있나요?
  6. 판단\(x_1x + y_1y = r^2\)은 중심이 원점인 원에서, \(P\)가 원 위에 있을 때만 쓸 수 있습니다. 원 밖의 점을 넣으면 접선이 아닌 다른 직선이 나옵니다. 또 기울기 공식 \(y = mx \pm r\sqrt{m^2 + 1}\)로는 \(y\)축에 평행한 접선 \(x = \pm r\)을 얻을 수 없습니다.
