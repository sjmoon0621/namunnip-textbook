원과 직선의 위치 관계

원과 직선은 두 점에서 만나거나, 한 점에서 닿거나(접함), 만나지 않습니다. 이 절에서는 그림을 그리지 않고 이 셋을 구별하는 방법 두 가지를 비교합니다. 하나는 방정식을 연립해 판별식을 보는 방법이고, 다른 하나는 중심에서 직선까지의 거리를 반지름과 비교하는 방법입니다. 마지막으로 원에 접하는 직선의 방정식을 구합니다.

원 \(x^2 + y^2 = 5\)와 직선 \(y = 2x + k\)가 있다. \(k\)를 바꾸면 직선이 평행하게 움직이며 원을 가르다가, 한 점에서 스치고, 결국 원에서 떨어진다. 스치는 순간의 \(k\)를 계산하는 방법은 몇 가지일까?

먼저 알아야 할 것원의 방정식(원의 방정식), 점과 직선 사이의 거리(점과 직선 사이의 거리), 이차방정식의 판별식(공통수학1).

1.5.1교점을 구하는 식으로 보기

원과 직선이 만나는 점은 두 식을 함께 만족한다. 그래서 직선의 식 \(y = 2x + k\)를 원의 식에 넣으면 \(x^2 + (2x + k)^2 = 5\), 곧 \(5x^2 + 4kx + k^2 - 5 = 0\)이다. 이 이차방정식의 실근이 교점의 \(x\)좌표이므로, 실근의 개수가 교점의 개수이다.

판별식을 계산하면 \(\dfrac{D}{4} = 4k^2 - 5(k^2 - 5) = 25 - k^2\)이다. 따라서 \(-5 < k < 5\)이면 두 점, \(k = \pm 5\)이면 한 점, \(|k| > 5\)이면 만나지 않는다. 공통수학1에서 포물선과 직선에 쓴 방법을 그대로 원에 쓴 것이다.

1.5.2거리로 보기

원에는 포물선에 없는 성질이 하나 있다. 원 위의 점은 모두 중심에서 거리가 \(r\)이고, 원의 안쪽 점은 \(r\)보다 가깝다. 그러면 직선이 원과 만나는지는 '직선이 중심에 얼마나 가까이 오는가'로 정해진다. 직선 위에서 중심에 가장 가까운 점은 수선의 발이고, 그 거리가 점과 직선 사이의 거리 \(d\)이다.

\(d < r\)이면 직선 위에 원 안쪽의 점이 있으므로 직선은 원을 가로질러 두 점에서 만난다. \(d = r\)이면 수선의 발 하나만 원 위에 있으므로 한 점에서 만나고, \(d > r\)이면 직선 위의 모든 점이 원 밖에 있다. 그림 1의 슬라이더로 \(k\)를 바꾸며 \(d\)와 \(r\)을 비교해 보자.

정리 1.5.1 원과 직선의 위치 관계

반지름이 \(r\)인 원의 중심과 직선 사이의 거리를 \(d\)라 하면, \(d < r\)일 때 서로 다른 두 점에서 만나고, \(d = r\)일 때 한 점에서 만나며(접하며), \(d > r\)일 때 만나지 않는다. 이는 대입한 이차방정식의 판별식이 \(D > 0\), \(D = 0\), \(D < 0\)인 경우와 같다.

처음 질문에 쓰면 직선은 \(2x - y + k = 0\)이므로 \(d = \dfrac{|k|}{\sqrt{5}}\), 반지름은 \(\sqrt{5}\)이다. 접할 조건 \(d = r\)은 \(|k| = 5\)로, 1의 판별식과 같은 답이 나온다. 계산은 거리 쪽이 훨씬 짧다.

1.5.3원 위의 점에서 그은 접선

원이 직선에 접할 때 접점과 중심을 잇는 반지름은 접선에 수직이다. 접점이 수선의 발이기 때문이다. 이 성질로 원 위의 점에서의 접선을 바로 쓸 수 있다. 원 \(x^2 + y^2 = r^2\) 위의 점 \((x_1, y_1)\)에서 반지름의 기울기는 \(\dfrac{y_1}{x_1}\)이므로 접선의 기울기는 \(-\dfrac{x_1}{y_1}\)이고, 정리하면 접선은 \(x_1x + y_1y = r^2\)이다.1

예제 1.5.2

원 \((x - 1)^2 + (y - 2)^2 = 9\)와 직선 \(3x + 4y + k = 0\)이 만나서 생기는 현의 길이가 \(4\sqrt{2}\)일 때, 양수 \(k\)의 값을 구하여라.

중심 \(C(1, 2)\)에서 현에 내린 수선은 현을 이등분한다. 그래서 현의 절반 \(2\sqrt{2}\), 중심에서 직선까지의 거리 \(d\), 반지름 3은 직각삼각형을 이루고 \(d^2 + (2\sqrt{2})^2 = 3^2\)이다. 따라서 \(d^2 = 1\), \(d = 1\)이다.

한편 거리 공식으로 \(d = \dfrac{|3 + 8 + k|}{5} = \dfrac{|11 + k|}{5}\)이다. 이것이 1이므로 \(|11 + k| = 5\)이고, \(k = -6\) 또는 \(k = -16\)이다. 그런데 문제는 양수 \(k\)를 물었다. 두 값이 모두 음수이므로 조건을 만족하는 양수 \(k\)는 없다.

답이 '없음'으로 나왔으니 그림으로 다시 보자. \(k > 0\)이면 직선 \(3x + 4y = -k\)는 원점보다 아래쪽에 놓이고, 중심 \((1, 2)\)에서 거리가 \(\dfrac{11 + k}{5} > \dfrac{11}{5}\)이다. 거리가 1이 될 수 없으므로 정말 양수 \(k\)는 없다. 조건을 '\(k\)의 값'으로 바꾸면 답은 \(-6\)과 \(-16\)이다. 아래 탐구 카드에서 직선을 옮기며 \(d\)와 \(r\), 판별식이 함께 바뀌는 모습을 직접 확인해 보자.

  1. \(y - y_1 = -\tfrac{x_1}{y_1}(x - x_1)\)의 양변에 \(y_1\)을 곱해 정리하면 \(x_1x + y_1y = x_1^2 + y_1^2 = r^2\)이다. \(y_1 = 0\)이면 접선은 세로 직선 \(x = x_1\)이고, 이 식도 같은 꼴에 들어간다.
마무리

원과 직선의 위치 관계는 대입한 이차방정식의 판별식으로도, 중심에서 직선까지의 거리 \(d\)와 반지름 \(r\)의 비교로도 가릴 수 있고, 두 방법은 같은 답을 준다. 접할 때는 반지름이 접선에 수직이다. 처음 질문에서 직선이 원에 접하는 순간은 \(d = \tfrac{|k|}{\sqrt{5}} = \sqrt{5}\), 곧 \(k = \pm 5\)이다.

거리 \(d\)와 \(r\)
—
위치 관계
—
  1. 질문원 \(x^2 + y^2 = 9\)와 직선 \(y = x + 2\)는 몇 개의 점에서 만날까? 그래프를 그리지 않고 판단할 수 있을까?
  2. 복원두 그래프의 교점은 두 방정식을 연립한 해이다. 이차방정식 \(ax^2 + 2b'x + c = 0\)은 \(\frac{D}{4} = b'^2 - ac\)가 양수이면 서로 다른 두 실근, 0이면 중근, 음수이면 실근이 없다. 또 점 \((x_1, y_1)\)과 직선 \(ax + by + c = 0\) 사이의 거리는 \(\frac{|ax_1 + by_1 + c|}{\sqrt{a^2 + b^2}}\)이다.
  3. 설명판단하는 방법은 두 가지이다. 첫째로 \(y = mx + n\)을 원의 방정식에 넣으면 \(x\)에 대한 이차방정식 \((1 + m^2)x^2 + 2mnx + n^2 - r^2 = 0\)이 된다. 실근의 개수가 교점의 개수이므로 \(D > 0\)이면 두 점에서 만나고, \(D = 0\)이면 한 점에서 만나며(접한다고 하고, 이 직선을 접선, 그 점을 접점이라 한다), \(D < 0\)이면 만나지 않는다. 둘째로 중심에서 직선까지의 거리를 \(d\)라 하면, \(d < r\)이면 두 점, \(d = r\)이면 접하고, \(d > r\)이면 만나지 않는다. 실제로 계산하면 \(\frac{D}{4} = (1 + m^2)(r^2 - d^2)\)이어서 두 방법의 판정은 언제나 같다.
  4. 연결거리를 쓰는 방법은 중심이 원점이 아닌 원에도 계산이 간단하고, 접선을 구할 때 그대로 쓰인다. 반면 판별식을 쓰는 방법은 교점의 좌표까지 구해 준다. 이차함수의 그래프와 직선의 위치 관계도 판별식으로 판단했다.
  5. 적용\(n\)을 바꾸면서 \(\frac{D}{4}\)와 \(d - r\)의 부호가 언제 함께 바뀌는지 보자. '접하는 예'에서는 \(\frac{D}{4} = 0\)이고 \(d = r\)이다. \(r = 3, m = 0\)일 때 직선이 원에 접하는 \(n\)은 \(\pm3\) 두 개이다.
  6. 판단\(\frac{D}{4} < 0\)은 '실수 범위에서' 교점이 없다는 뜻이고, 중근은 두 교점이 하나로 겹친 것이다. 또 판별식을 쓰려면 직선의 식을 원의 식에 넣어 한 문자에 대한 이차방정식을 만든 뒤여야 한다. \(y\)축에 평행한 직선 \(x = k\)를 넣으면 \(y\)에 대한 이차방정식이 된다.

접점 \(P\)를 원을 따라 끌어 보세요. 좌표가 정수인 점 가까이에서는 그 점에 붙습니다.

  1. 질문원 \(x^2 + y^2 = 25\) 위의 점 \((3, 4)\)에서 원에 닿기만 하고 들어가지 않는 직선을 긋는다. 이 접선의 방정식은 무엇일까? 기울기가 1인 접선은 어디에 몇 개 있을까?
  2. 복원원의 접선은 접점을 지나는 반지름과 수직이다(중학교). 또 기울기가 \(m_1, m_2\)인 두 직선이 수직이면 \(m_1m_2 = -1\)이고, 원과 직선이 접할 조건은 중심에서 직선까지의 거리가 반지름과 같다는 것이다.
  3. 설명먼저 접점 \(P(x_1, y_1)\)이 주어진 경우를 보자. 반지름 \(OP\)의 기울기는 \(\frac{y_1}{x_1}\)이므로 접선의 기울기는 \(-\frac{x_1}{y_1}\)이다. \(y - y_1 = -(\frac{x_1}{y_1})(x - x_1)\)를 정리하면 \(x_1x + y_1y = x_1^2 + y_1^2\)이고, \(P\)가 원 위에 있으므로 우변이 \(r^2\)이 되어 \(x_1x + y_1y = r^2\)이다(\(x_1 = 0\) 또는 \(y_1 = 0\)이어도 성립한다). 다음으로 기울기 \(m\)이 주어진 경우에는 접선을 \(y = mx + n\), 곧 \(mx - y + n = 0\)으로 놓는다. 원점에서의 거리 \(\frac{|n|}{\sqrt{m^2 + 1}}\)이 \(r\)과 같아야 하므로 \(y = mx \pm r\sqrt{m^2 + 1}\)이고, 기울기가 같은 접선은 원의 양쪽에 하나씩 두 개이다.
  4. 연결원 밖의 한 점에서 그은 접선은 기울기를 \(m\)으로 놓고 거리 조건이나 판별식 \(= 0\)으로 \(m\)을 구하며, 보통 두 개가 나온다. 또 중심이 \((a, b)\)인 원은 평행이동을 이용하면 접점에서의 접선이 \((x_1 - a)(x - a) + (y_1 - b)(y - b) = r^2\)이다.
  5. 적용\(r = 5\)에서 \(P\)를 \((3, 4), (-4, 3), (0, 5)\)로 옮기고 접선의 방정식을 확인해 보자. 반지름의 기울기와 접선의 기울기의 곱은 언제나 \(-1\)이다. '기울기가 주어질 때'로 바꾸어 \(m\)을 바꾸면 두 접점이 원점에 대해 서로 대칭인 자리에 놓인다.
  6. 판단\(x_1x + y_1y = r^2\)은 중심이 원점인 원에서, \(P\)가 원 위에 있을 때만 쓸 수 있다. 원 밖의 점을 넣으면 접선이 아닌 다른 직선이 나온다. 또 기울기 공식 \(y = mx \pm r\sqrt{m^2 + 1}\)로는 \(y\)축에 평행한 접선 \(x = \pm r\)을 얻을 수 없다.
