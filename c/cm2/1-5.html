원과 직선의 위치 관계

원과 직선은 두 점에서 만나거나, 한 점에서 닿거나(접함), 만나지 않습니다. 이 절에서는 그림을 그리지 않고 이 셋을 구별하는 방법 두 가지를 비교합니다. 하나는 방정식을 연립해 판별식을 보는 방법이고, 다른 하나는 중심에서 직선까지의 거리를 반지름과 비교하는 방법입니다. 마지막으로 원에 접하는 직선의 방정식을 구합니다.

1.5.1

원과 직선이 만나는지 그리지 않고 알 수 있을까?

원과 직선의 위치 관계 · 판별식과 거리

—

판별식 D/4
—
거리 d와 r
—
위치 관계
—
  1. 질문원 x2 + y2 = 9와 직선 y = x + 2는 몇 개의 점에서 만날까요? 그래프를 그리지 않고 판단할 수 있을까요?
  2. 복원두 그래프의 교점은 두 방정식을 연립한 해입니다. 이차방정식 ax2 + 2b′x + c = 0은 D/4 = b′2 − ac가 양수이면 서로 다른 두 실근, 0이면 중근, 음수이면 실근이 없습니다. 점 (x₁, y₁)과 직선 ax + by + c = 0 사이의 거리는 |ax₁ + by₁ + c|/√(a2 + b2)입니다.
  3. 설명방법 1 (판별식) y = mx + n을 원의 방정식에 넣으면 x에 대한 이차방정식 (1 + m2)x2 + 2mnx + n2 − r2 = 0이 됩니다. 실근의 개수가 교점의 개수이므로 D > 0이면 두 점에서 만나고, D = 0이면 한 점에서 만나며(접한다, 이 직선이 접선, 그 점이 접점), D < 0이면 만나지 않습니다. 방법 2 (거리) 중심에서 직선까지의 거리를 d라 하면 d < r이면 두 점, d = r이면 접하고, d > r이면 만나지 않습니다. 실제로 계산하면 D/4 = (1 + m2)(r2 − d2)이어서 두 방법의 판정은 언제나 같습니다.
  4. 연결거리 방법은 중심이 원점이 아닌 원에도 계산이 간단하고, 접선을 구할 때 그대로 쓰입니다. 판별식 방법은 교점의 좌표까지 구해 줍니다. 이차함수의 그래프와 직선의 위치 관계도 판별식으로 판단합니다.
  5. 적용n을 바꾸면서 D/4와 d − r의 부호가 언제 함께 바뀌는지 보세요. '접하는 예'에서 D/4와 d는 얼마인가요? r = 3, m = 0일 때 직선이 원에 접하는 n을 모두 찾아보세요.
  6. 판단D/4 < 0이면 '실수 범위에서' 교점이 없다는 뜻입니다. 중근은 두 교점이 하나로 겹친 것입니다. 또 판별식 방법에서는 직선의 식을 원의 식에 넣어 한 문자에 대한 이차방정식을 만든 뒤에 판별식을 써야 합니다. y축에 평행한 직선 x = k는 y에 대한 이차방정식이 됩니다.

접점 P를 원을 따라 끌어 보세요. 좌표가 정수인 점 가까이에서는 그 점에 붙습니다.

  1. 질문원 x2 + y2 = 25 위의 점 (3, 4)에서 원에 닿기만 하고 들어가지 않는 직선을 긋습니다. 이 접선의 방정식은 무엇일까요? 기울기가 1인 접선은 어디에 몇 개 있을까요?
  2. 복원원의 접선은 접점을 지나는 반지름과 수직입니다(중학교). 기울기가 m₁, m₂인 두 직선이 수직이면 m₁m₂ = −1입니다. 원과 직선이 접할 조건은 중심에서 직선까지의 거리가 반지름과 같다는 것입니다.
  3. 설명접점 P(x₁, y₁)이 주어질 때 반지름 OP의 기울기는 y₁/x₁이므로 접선의 기울기는 −x₁/y₁입니다. y − y₁ = −(x₁/y₁)(x − x₁)를 정리하면 x₁x + y₁y = x₁2 + y₁2이고, P가 원 위에 있으므로 우변이 r2입니다. 곧 x₁x + y₁y = r2입니다(x₁ = 0 또는 y₁ = 0이어도 성립합니다). 기울기 m이 주어질 때 접선을 y = mx + n, 곧 mx − y + n = 0으로 놓으면 원점에서의 거리 |n|/√(m2 + 1)이 r과 같아야 하므로 y = mx ± r√(m2 + 1)입니다. 기울기가 같은 접선은 원의 양쪽에 하나씩, 두 개입니다.
  4. 연결원 밖의 한 점에서 그은 접선은 기울기를 m으로 놓고 거리 조건(또는 판별식 = 0)으로 m을 구합니다. 보통 두 개가 나옵니다. 중심이 (a, b)인 원은 평행이동을 이용하면 접점에서의 접선이 (x₁ − a)(x − a) + (y₁ − b)(y − b) = r2입니다.
  5. 적용r = 5에서 P를 (3, 4), (−4, 3), (0, 5)로 옮기고 접선의 방정식을 확인하세요. 반지름의 기울기와 접선의 기울기의 곱은 얼마인가요? '기울기가 주어질 때'로 바꾸어 m을 바꾸면 두 접점은 어떤 위치 관계에 있나요?
  6. 판단x₁x + y₁y = r2은 중심이 원점인 원에서, P가 원 위에 있을 때만 쓸 수 있습니다. 원 밖의 점을 넣으면 접선이 아닌 다른 직선이 나옵니다. 또 기울기 공식 y = mx ± r√(m2 + 1)로는 y축에 평행한 접선 x = ±r을 얻을 수 없습니다.
