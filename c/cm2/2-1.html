집합의 뜻과 표현

수학은 "이런 성질을 가진 것들"을 한 덩어리로 묶어 다루는 일이 많습니다. 방정식의 해, 함수의 정의역, 확률의 사건이 모두 그렇습니다. 이 절에서는 그런 묶음을 집합이라는 이름으로 정확히 정하고, 원소를 늘어놓거나 조건으로 적어 나타내는 방법을 익힙니다.

2.1.1

어떤 모임을 집합이라 하고, 어떻게 적을까?

집합 · 원소나열법과 조건제시법

—

원소의 개수 n(A)
—
집합의 종류
—
고른 수
—

칸을 누르면 그 수가 A의 원소인지(∈) 아닌지(∉) 알려 줍니다.

  1. 질문'12의 약수의 모임'과 '키가 큰 학생의 모임'은 무엇이 다를까요? 어느 쪽을 수학에서 하나의 대상으로 다룰 수 있을까요?
  2. 복원약수는 어떤 수를 나누어떨어지게 하는 자연수이고, 배수는 어떤 수에 자연수를 곱한 수입니다. 소수는 1과 자기 자신만을 약수로 가지는 1보다 큰 자연수입니다.
  3. 설명대상을 분명하게 정할 수 있는 기준이 있을 때, 그 기준에 맞는 것들의 모임을 집합이라 하고, 집합을 이루는 대상 하나하나를 원소라고 합니다. '키가 큰'은 사람마다 기준이 달라 집합이 되지 않습니다. a가 집합 A의 원소이면 a ∈ A, 아니면 a ∉ A로 씁니다. 집합은 원소를 모두 늘어놓는 원소나열법 {1, 2, 3, 4, 6, 12}나, 원소의 조건을 적는 조건제시법 {x | x는 12의 약수}로 나타냅니다. 원소가 유한개이면 유한집합, 무한히 많으면 무한집합입니다. 원소가 하나도 없는 집합은 공집합 ∅입니다. 유한집합 A의 원소의 개수는 n(A)로 쓰고, n(∅) = 0입니다.
  4. 연결방정식의 해 전체, 함수의 정의역과 치역, 확률에서 일어날 수 있는 결과 전체가 모두 집합입니다. 벤 다이어그램은 집합을 그림으로 나타내는 셋째 방법으로, 다음 절부터 씁니다.
  5. 적용n = 12로 두고 '약수'와 '36 이하의 배수'를 번갈아 눌러 원소나열법이 어떻게 바뀌는지 보세요. 'n의 배수 전체'에서는 원소를 모두 적을 수 없습니다. 원소나열법은 어떻게 적혀 있나요? 'n보다 작은 자연수'에서 n = 1로 두면 무엇이 나오나요?
  6. 판단{0}은 공집합이 아닙니다. 원소 0이 하나 있으므로 n({0}) = 1입니다. 원소나열법에서는 같은 원소를 두 번 쓰지 않고, 원소의 순서는 상관이 없습니다. {1, 2, 3}과 {3, 1, 2}는 같은 집합입니다.

2.1.2

같은 범위인데 원소가 몇 개인지가 왜 달라질까?

원소의 개수 · 유한집합과 무한집합

—

n(A)
—
집합의 종류
—
b − a
—
  1. 질문−2 ≤ x ≤ 3을 만족하는 정수는 몇 개일까요? 정수가 아니라 실수라면요?
  2. 복원부등식 a ≤ x ≤ b는 수직선에서 a와 b를 포함하는 범위이고, a < x < b는 양 끝을 빼는 범위입니다. 끝을 포함하면 속이 찬 점, 빼면 빈 점으로 그립니다.
  3. 설명조건이 같은 모양이어도 x가 어떤 수인지에 따라 집합이 달라집니다. 정수만 고르면 범위 안의 눈금만 원소가 되어 유한집합이고, a, b가 정수이면 n(A) = b − a + 1입니다. 실수를 고르면 아무리 좁은 범위에도 수가 끝없이 있어 무한집합입니다. a > b이면 조건을 만족하는 수가 없어 공집합 ∅입니다.
  4. 연결부등식의 해를 집합으로 적는 일, 함수의 정의역을 정하는 일이 이 생각을 그대로 씁니다. 원소의 개수 n(A)는 경우의 수와 확률을 셀 때 다시 나옵니다.
  5. 적용a = −2, b = 3에서 정수의 개수를 세고 b − a와 비교하세요. 끝을 빼면 몇 개가 줄어드나요? a = 0.5처럼 끝이 정수가 아니면 공식이 그대로 맞나요? '실수'로 바꾸고 a = b로 맞추면 두 끝 모양에서 각각 무엇이 남나요?
  6. 판단"범위가 짧으면 유한집합"은 틀린 생각입니다. 0 < x < 0.001인 실수도 무한히 많습니다. 유한과 무한을 가르는 것은 범위의 길이가 아니라 원소를 끝까지 셀 수 있는지입니다. 또 n(A) = b − a + 1은 양 끝이 정수이고 끝을 포함할 때만 맞습니다.
