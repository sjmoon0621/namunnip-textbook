집합의 연산

두 집합으로 새 집합을 만드는 방법은 몇 가지일까?

n(A), n(B)
—
n(A ∩ B)

—

  1. 질문12 이하의 자연수 가운데 2의 배수이거나 3의 배수인 수는 몇 개일까요? 2의 배수 6개와 3의 배수 4개를 더해 10개라고 하면 맞을까요?
  2. 복원A ⊂ B는 A의 모든 원소가 B에 있다는 뜻입니다. 벤 다이어그램에서 사각형은 생각하는 대상 전체, 원은 각 집합입니다.
  3. 설명A 또는 B에 속하는 원소 전체가 합집합 A ∪ B, A와 B에 모두 속하는 원소 전체가 교집합 A ∩ B입니다. A ∩ B = ∅이면 A와 B는 서로소입니다. 생각하는 대상 전체를 전체집합 U라 할 때, U의 원소 가운데 A에 속하지 않는 것 전체가 여집합 AC이고, A에는 속하지만 B에는 속하지 않는 것 전체가 차집합 A − B입니다. A − B = A ∩ BC입니다. 합집합의 원소를 셀 때 A와 B를 그냥 더하면 A ∩ B를 두 번 세므로 n(A ∪ B) = n(A) + n(B) − n(A ∩ B)입니다.
  4. 연결이 개수 공식은 확률의 덧셈정리 P(A ∪ B) = P(A) + P(B) − P(A ∩ B)와 같은 모양입니다. 여집합은 명제에서 조건의 부정 '~p'의 진리집합이 됩니다.
  5. 적용첫 번째 집합 쌍에서 A ∪ B를 고르고 n(A) + n(B)와 n(A ∪ B)의 차이를 확인하세요. A − B와 A ∩ BC를 번갈아 눌러 보고, (A ∪ B)C와 AC ∩ BC도 비교해 보세요. 세 번째 쌍에서는 무엇이 달라지나요? 네 번째 쌍에서 A − B는 무엇인가요?
  6. 판단여집합은 전체집합이 정해져야 뜻이 생깁니다. 같은 A = {2, 4}라도 U = {1, 2, 3, 4}이면 AC = {1, 3}이고, U = {1, 2, …, 12}이면 원소가 10개입니다. 또 A − B와 B − A는 일반적으로 다릅니다.

2.3.2

두 식이 같은 집합인지 그림으로 어떻게 확인할까?

연산 법칙 · 드모르간의 법칙

—

누른 영역
그림을 눌러 보세요
두 변의 영역
—
  1. 질문수에서는 a(b + c) = ab + ac가 성립합니다. 집합에서도 A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)가 성립할까요? 그렇다면 ∩와 ∪를 바꾼 식은요?
  2. 복원∪는 '또는', ∩는 '그리고', 여집합은 '아니다'입니다. 두 집합이 같다는 것은 원소가 모두 같다는 뜻이고, 벤 다이어그램에서는 칠한 영역이 같다는 뜻입니다.
  3. 설명세 집합의 벤 다이어그램은 공간을 8개의 작은 영역으로 나눕니다. 두 식의 영역을 단계별로 칠해서 8개 영역이 모두 일치하면 두 식은 어떤 집합을 넣어도 같습니다. 이렇게 확인되는 법칙은 다음과 같습니다. 교환법칙 A ∪ B = B ∪ A, A ∩ B = B ∩ A. 결합법칙 (A ∪ B) ∪ C = A ∪ (B ∪ C), (A ∩ B) ∩ C = A ∩ (B ∩ C). 분배법칙 A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C), A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C). 드모르간의 법칙 (A ∪ B)C = AC ∩ BC, (A ∩ B)C = AC ∪ BC.
  4. 연결드모르간의 법칙은 명제에서 'p 그리고 q'의 부정이 '~p 또는 ~q'가 된다는 사실과 같은 내용입니다. 컴퓨터의 논리 회로를 간단히 할 때도 이 법칙을 씁니다.
  5. 적용분배법칙 ①을 고르고 '다음 단계'를 눌러 두 그림이 어떻게 채워지는지 보세요. 분배법칙 ②는 수에서는 성립하지 않는 모양(a + bc ≠ (a + b)(a + c))인데 집합에서는 어떤가요? '가짜 법칙?'에서는 그림의 한 곳을 눌러, 한쪽에만 칠해진 영역을 찾아보세요.
  6. 판단원소 몇 개를 넣어 두 식이 같게 나왔다고 법칙이 증명된 것은 아닙니다. 그 예에 비어 있는 영역이 있으면 차이를 놓칠 수 있습니다. 8개 영역을 모두 비교하거나, 원소 하나를 잡아 '이 원소가 좌변에 있으면 우변에도 있다'를 양쪽으로 보여야 합니다. 또 (A ∪ B)C를 AC ∪ BC로 쓰는 실수가 흔합니다. 여집합을 괄호 안으로 넣으면 ∪와 ∩가 서로 바뀝니다.
