반 학생 30명 가운데 축구를 좋아하는 학생이 18명, 농구를 좋아하는 학생이 12명, 둘 다 좋아하는 학생이 7명이다. 둘 중 하나라도 좋아하는 학생과 둘 다 좋아하지 않는 학생은 몇 명일까? 두 모임을 '합치고', '겹치고', '빼는' 일을 집합의 언어로 어떻게 쓸까?

먼저 알아야 할 것부분집합과 벤 다이어그램(집합 사이의 포함관계), 원소의 개수 \(n(A)\)(집합의 뜻과 표현).

2.3.1합치기와 겹치기

축구를 좋아하는 학생의 집합을 \(A\), 농구를 좋아하는 학생의 집합을 \(B\)라 하자. '둘 중 하나라도 좋아하는 학생'은 \(A\)에 속하거나 \(B\)에 속하는 학생이다. 이 집합을 \(A\)와 \(B\)의 합집합이라 하고 \(A \cup B\)로 쓴다. '둘 다 좋아하는 학생'은 \(A\)에도 \(B\)에도 속하는 학생이고, 이 집합을 교집합이라 하며 \(A \cap B\)로 쓴다.

그림 1의 슬라이더로 합집합과 교집합을 차례로 골라 보자. 합집합은 두 원 전체이고, 교집합은 두 원이 겹친 렌즈 모양이다. 교집합이 공집합인 두 집합, 곧 겹치는 원소가 없는 두 집합을 서로소라 한다.

2.3.2빼기와 바깥

'축구만 좋아하는 학생'은 \(A\)에는 속하지만 \(B\)에는 속하지 않는다. 이것을 \(A\)에 대한 \(B\)의 차집합이라 하고 \(A - B\)로 쓴다. 한편 반 학생 전체처럼 생각하는 대상을 모두 모은 집합을 전체집합 \(U\)라 하면, \(U\)의 원소 가운데 \(A\)에 속하지 않는 것의 집합을 \(A\)의 여집합이라 하고 \(A^C\)로 쓴다.

정의 2.3.1 집합의 연산

\(A \cup B = \{x \mid x \in A\ \text{또는}\ x \in B\}\), \(A \cap B = \{x \mid x \in A\ \text{그리고}\ x \in B\}\), \(A - B = \{x \mid x \in A\ \text{그리고}\ x \notin B\}\), \(A^C = \{x \mid x \in U\ \text{그리고}\ x \notin A\}\)

정의를 보면 차집합은 여집합과 교집합으로 바꾸어 쓸 수 있다. '\(A\)에 속하고 \(B\)에 속하지 않는다'는 '\(A\)에 속하고 \(B^C\)에 속한다'와 같으므로 \(A - B = A \cap B^C\)이다. 그림 1에서 (A - B)와 (B^C)를 번갈아 칠해 보면, \(A - B\)는 \(A\) 안에서 \(B^C\)인 부분이다.

그림 2처럼 벤 다이어그램을 그려 칠한 영역을 비교하면 집합의 연산 법칙을 확인할 수 있다. 두 원 바깥은 '\(A\)에도 \(B\)에도 속하지 않는' 영역이므로 \((A \cup B)^C = A^C \cap B^C\)이고, 같은 방법으로 \((A \cap B)^C = A^C \cup B^C\)이다. 교환법칙, 결합법칙, 분배법칙 \(A \cap (B \cup C) = (A \cap B) \cup (A \cap C)\)도 같은 방식으로 확인된다.1

2.3.3원소의 개수

합집합의 원소를 세려고 \(n(A)\)와 \(n(B)\)를 더하면, 교집합의 원소는 양쪽에 다 들어 있어서 두 번 세어진다. 따라서 한 번을 빼야 한다.

정리 2.3.2 합집합의 원소의 개수

\(n(A \cup B) = n(A) + n(B) - n(A \cap B)\), \(n(A^C) = n(U) - n(A)\), \(n(A - B) = n(A) - n(A \cap B)\)

2.3.4예제 하나를 끝까지

예제 2.3.3

처음 질문에서 축구나 농구를 좋아하는 학생 수, 둘 다 좋아하지 않는 학생 수, 축구만 좋아하는 학생 수를 구하여라.

\(n(U) = 30\), \(n(A) = 18\), \(n(B) = 12\), \(n(A \cap B) = 7\)이다. 축구나 농구를 좋아하는 학생은 \(n(A \cup B) = 18 + 12 - 7 = 23\)명이다.

둘 다 좋아하지 않는 학생은 \((A \cup B)^C\)이므로 \(30 - 23 = 7\)명이다. 축구만 좋아하는 학생은 \(A - B\)이므로 \(18 - 7 = 11\)명이다.

벤 다이어그램의 네 영역으로 확인해 보자. 축구만 11명, 둘 다 7명, 농구만 \(12 - 7 = 5\)명, 둘 다 아님 7명이고, 합은 \(11 + 7 + 5 + 7 = 30\)명이다. 영역마다 한 번씩만 세었으니 합이 전체와 같다. 아래 탐구 카드에서 원소를 직접 옮기며 각 연산의 결과가 어떻게 바뀌는지 확인해 보자.

  1. 벤 다이어그램은 확인하는 도구이고 증명은 아니다. 증명하려면 '\(x\)가 왼쪽 집합의 원소이면 오른쪽 집합의 원소이고, 그 역도 성립함'을 보인다.

  1. 질문12 이하의 자연수 가운데 2의 배수이거나 3의 배수인 수는 몇 개일까? 2의 배수 6개와 3의 배수 4개를 더해 10개라고 하면 맞을까?
  2. 복원\(A \subset B\)는 \(A\)의 모든 원소가 \(B\)에 있다는 뜻이다. 또 벤 다이어그램에서 사각형은 생각하는 대상 전체, 원은 각 집합이다.
  3. 설명\(A\) 또는 \(B\)에 속하는 원소 전체가 합집합 \(A \cup B\), \(A\)와 \(B\)에 모두 속하는 원소 전체가 교집합 \(A \cap B\)이고, \(A \cap B = \varnothing\)이면 \(A\)와 \(B\)는 서로소이다. 생각하는 대상 전체를 전체집합 \(U\)라 할 때, \(U\)의 원소 가운데 \(A\)에 속하지 않는 것 전체가 여집합 \(A^C\)이고, \(A\)에는 속하지만 \(B\)에는 속하지 않는 것 전체가 차집합 \(A - B\)이므로 \(A - B = A \cap B^C\)이다. 그런데 합집합의 원소를 셀 때 \(A\)와 \(B\)를 그냥 더하면 \(A \cap B\)를 두 번 세므로 \(n(A \cup B) = n(A) + n(B) - n(A \cap B)\)이다. 그래서 처음 질문의 답은 6과 12를 한 번씩 빼서 8개이다.
  4. 연결이 개수 공식은 확률의 덧셈정리 \(P(A \cup B) = P(A) + P(B) - P(A \cap B)\)와 같은 모양이다. 또 여집합은 명제에서 조건의 부정 '\({\sim}p\)'의 진리집합이 된다.
  5. 적용첫 번째 집합 쌍에서 \(A \cup B\)를 고르고 \(n(A) + n(B)\)와 \(n(A \cup B)\)의 차이를 확인해 보자. \(A - B\)와 \(A \cap B^C\)를 번갈아 누르면 같은 영역이 칠해지고, \((A \cup B)^C\)와 \(A^C \cap B^C\)도 마찬가지이다. 세 번째 쌍과 네 번째 쌍에서는 \(A - B\)가 어떻게 달라지는지도 보자.
  6. 판단여집합은 전체집합이 정해져야 뜻이 생긴다. 같은 \(A = \{2, 4\}\)라도 \(U = \{1, 2, 3, 4\}\)이면 \(A^C = \{1, 3\}\)이고, \(U = \{1, 2, \cdots, 12\}\)이면 원소가 10개이다. 또 \(A - B\)와 \(B - A\)는 일반적으로 다르다.

두 식이 같은 집합인지 그림으로 어떻게 확인할까?

—

누른 영역
그림을 눌러 보세요
두 변의 영역
—
  1. 질문수에서는 \(a(b + c) = ab + ac\)가 성립한다. 집합에서도 \(A \cap (B \cup C) = (A \cap B) \cup (A \cap C)\)가 성립할까? 그렇다면 \(\cap\)와 \(\cup\)를 바꾼 식은 어떨까?
  2. 복원\(\cup\)는 '또는', \(\cap\)는 '그리고', 여집합은 '아니다'이다. 두 집합이 같다는 것은 원소가 모두 같다는 뜻이고, 벤 다이어그램에서는 칠한 영역이 같다는 뜻이다.
  3. 설명세 집합의 벤 다이어그램은 공간을 8개의 작은 영역으로 나눈다. 그래서 두 식의 영역을 단계별로 칠해 8개 영역이 모두 일치하면 두 식은 어떤 집합을 넣어도 같다. 이렇게 확인되는 법칙에는 교환법칙 \(A \cup B = B \cup A, A \cap B = B \cap A\), 결합법칙 \((A \cup B) \cup C = A \cup (B \cup C), (A \cap B) \cap C = A \cap (B \cap C)\), 분배법칙 \(A \cap (B \cup C) = (A \cap B) \cup (A \cap C), A \cup (B \cap C) = (A \cup B) \cap (A \cup C)\), 드모르간의 법칙 \((A \cup B)^C = A^C \cap B^C, (A \cap B)^C = A^C \cup B^C\)이 있다.
  4. 연결드모르간의 법칙은 명제에서 '\(p\) 그리고 \(q\)'의 부정이 '\({\sim}p\) 또는 \({\sim}q\)'가 된다는 사실과 같은 내용이다. 컴퓨터의 논리 회로를 간단히 할 때도 이 법칙을 쓴다.
  5. 적용첫째 분배법칙을 고르고 '다음 단계'를 눌러 두 그림이 같은 영역으로 채워지는 것을 보자. 둘째 분배법칙은 수에서는 성립하지 않는 모양\((a + bc \ne (a + b)(a + c))\)인데, 집합에서는 두 그림이 똑같이 채워진다. '가짜 법칙?'에서는 그림의 한 곳을 눌러, 한쪽에만 칠해진 영역을 찾아보자.
  6. 판단원소 몇 개를 넣어 두 식이 같게 나왔다고 법칙이 증명된 것은 아니다. 그 예에 비어 있는 영역이 있으면 차이를 놓칠 수 있기 때문이다. 그래서 8개 영역을 모두 비교하거나, 원소 하나를 잡아 '이 원소가 좌변에 있으면 우변에도 있다'를 양쪽으로 보여야 한다. 또 \((A \cup B)^C\)를 \(A^C \cup B^C\)로 쓰는 실수가 흔한데, 여집합을 괄호 안으로 넣으면 \(\cup\)와 \(\cap\)가 서로 바뀐다.
