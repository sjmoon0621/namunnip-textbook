원의 방정식

원은 한 점에서 같은 거리에 있는 점들의 모임입니다. 두 점 사이의 거리 공식을 쓰면 이 성질을 x, y에 대한 방정식 하나로 적을 수 있습니다. 이 절에서는 중심과 반지름으로 원의 방정식을 세우고, 전개된 식에서 거꾸로 중심과 반지름을 찾아 그래프를 그립니다.

1.4.1

원 위의 점들은 어떤 식을 만족할까?

원의 방정식 · 중심과 반지름

—

P를 넣은 좌변
—
r²
—
점 P의 위치
—

중심 C, 반지름 손잡이(원 오른쪽 점), 점 P를 끌어 보세요. P를 식에 넣은 값과 r²을 비교합니다.

  1. 질문중심이 (1, −1)이고 반지름이 3인 원을 그렸습니다. 이 원 위의 점들만 만족하고, 원 밖이나 안의 점은 만족하지 않는 식을 세울 수 있을까요?
  2. 복원원은 평면 위의 한 점(중심)에서 일정한 거리(반지름)에 있는 점들의 모임입니다. 두 점 (x₁, y₁), (x₂, y₂) 사이의 거리는 √((x₂ − x₁)2 + (y₂ − y₁)2)입니다.
  3. 설명중심 C(a, b), 반지름 r(r > 0)인 원 위의 점 P(x, y)는 CP = r을 만족합니다. 거리 공식으로 쓰면 √((x − a)2 + (y − b)2) = r이고, 양변이 모두 0 이상이므로 제곱해도 같은 조건입니다. 그래서 (x − a)2 + (y − b)2 = r2이 이 원의 방정식입니다. 거꾸로 이 식을 만족하는 점은 모두 원 위에 있습니다. 중심이 원점이면 x2 + y2 = r2입니다.
  4. 연결좌변의 값은 CP2입니다. 그래서 좌변이 r2보다 작으면 P는 원의 내부, 크면 외부에 있습니다. 원과 직선의 위치 관계, 원의 평행이동과 대칭이동도 모두 이 식에서 출발합니다.
  5. 적용P를 끌어 식의 값이 r2과 같아지는 곳을 찾으세요. 그곳은 늘 원 위인가요? 중심을 원점에, 반지름을 5로 놓고 원 위의 격자점을 모두 찾아보세요. 몇 개인가요? 중심을 옮기면 식의 어느 부분이 바뀌나요?
  6. 판단(x + 2)2은 (x − (−2))2이므로 중심의 x좌표는 −2입니다. 부호를 그대로 읽으면 안 됩니다. 또 우변은 반지름의 제곱입니다. (x − 1)2 + y2 = 4의 반지름은 4가 아니라 2입니다.

중심이 (−2, 3)이고 점 (1, −1)을 지나는 원의 방정식은?

1.4.2

x² + y² + Ax + By + C = 0은 언제 원이 될까?

원의 방정식 · 완전제곱식

—

중심
—
(A² + B² − 4C)/4
—
그래프
—
  1. 질문x2 + y2 − 4x + 6y − 3 = 0은 원의 방정식을 전개한 모양입니다. 중심과 반지름이 보이지 않는 이 식에서 어떻게 그래프를 그릴까요? 또 이런 꼴의 식은 언제나 원일까요?
  2. 복원x2 − 4x = (x − 2)2 − 4처럼, 일차항 계수의 절반을 제곱해 더하고 빼면 완전제곱식을 만들 수 있습니다. 실수의 제곱은 0 이상입니다.
  3. 설명x2 + y2 + Ax + By + C = 0을 완전제곱식으로 고치면 (x + A/2)2 + (y + B/2)2 = (A2 + B2 − 4C)/4입니다. 우변이 양수이면 중심이 (−A/2, −B/2)이고 반지름이 √(A2 + B2 − 4C)/2인 원입니다. 우변이 0이면 좌변이 0인 점 (−A/2, −B/2) 하나뿐이고, 음수이면 두 제곱의 합이 음수가 될 수 없으므로 만족하는 점이 없습니다. 그래서 이 식이 원을 나타낼 조건은 A2 + B2 − 4C > 0입니다.
  4. 연결일반형은 세 점을 지나는 원을 구할 때 편리합니다. 세 점의 좌표를 넣으면 A, B, C에 대한 연립일차방정식이 나오기 때문입니다. 또 원과 직선의 교점을 구할 때도 일반형에 직선의 식을 넣어 이차방정식을 얻습니다.
  5. 적용A, B는 두고 C만 늘려 보세요. 원은 어떻게 변하나요? A = −4, B = 6일 때 원이 점 하나로 줄어드는 C의 값을 찾고, 식으로도 확인해 보세요. A를 바꾸면 중심은 어느 방향으로 움직이나요?
  6. 판단x2과 y2의 계수가 같고 xy항이 없어야 원이 될 수 있습니다. x2 + 2y2 = 4는 원이 아닙니다. 2x2 + 2y2 + … = 0처럼 계수가 1이 아니면 먼저 양변을 그 계수로 나눕니다. 꼴이 맞아도 우변이 0 이하이면 원이 아닙니다.
