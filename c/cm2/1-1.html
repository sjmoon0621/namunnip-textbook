두 점 사이의 거리와 내분점

본문

지도 위 두 마을 \(A(-3, -1)\)과 \(B(5, 3)\)을 곧은 길로 잇고, \(A\)에서 \(B\)까지의 \(\tfrac{1}{4}\) 지점에 정류장을 세우려 한다. 길의 길이와 정류장의 좌표를 자를 대지 않고 좌표만으로 구할 수 있을까?

먼저 알아야 할 것중학교의 순서쌍과 좌표, 피타고라스 정리, 삼각형의 닮음과 평행선이 만드는 비.

1.1.1거리는 직각삼각형의 빗변

두 점을 잇는 선분은 보통 축에 비스듬하다. 그런데 \(A\)에서 오른쪽으로, \(B\)에서 아래쪽으로 선을 그어 만나는 점 \(C(5, -1)\)을 잡으면, 선분 \(AB\)는 직각삼각형 \(ABC\)의 빗변이 된다. 가로 변 \(AC\)의 길이는 \(5 - (-3) = 8\), 세로 변 \(BC\)의 길이는 \(3 - (-1) = 4\)이다.

따라서 피타고라스 정리에 따라 \(AB = \sqrt{8^2 + 4^2} = \sqrt{80} = 4\sqrt{5}\)이다. 같은 방법을 문자로 쓰면 다음 공식이 된다.

정리 1.1.1 두 점 사이의 거리

두 점 \(A(x_1, y_1)\), \(B(x_2, y_2)\) 사이의 거리는 \[AB = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\]

차를 제곱하므로 어느 점을 먼저 빼도 결과는 같다. 두 점의 \(y\)좌표가 같으면 세로 변이 0이 되어 수직선 위의 거리 \(|x_2 - x_1|\)로 돌아간다. 즉 이 공식은 중학교에서 배운 수직선 위의 거리를 평면으로 넓힌 것이다.

1.1.2수직선에서 선분 나누기

먼저 수직선에서 생각하자. \(A(1)\)과 \(B(9)\) 사이를 \(1 : 3\)으로 나누는 점 \(P\)는 \(A\)에서 전체 길이 8의 \(\tfrac{1}{4}\)만큼 간 곳이므로 \(1 + 8 \times \tfrac{1}{4} = 3\)이다. 일반적으로 \(A(x_1)\), \(B(x_2)\)를 \(m : n\)으로 나누는 점은 \(x_1 + (x_2 - x_1) \cdot \dfrac{m}{m + n}\)이다.

이 식을 정리하면 \(\dfrac{mx_2 + nx_1}{m + n}\)이다. 여기서 \(m\)은 \(B\)의 좌표에, \(n\)은 \(A\)의 좌표에 곱해진다. 처음에는 짝이 거꾸로 된 것처럼 보이지만, \(m\)이 클수록 \(P\)가 \(B\) 쪽으로 끌려가야 하므로 이렇게 짝지어지는 것이 맞다.

정의 1.1.2 내분점

선분 \(AB\) 위의 점 \(P\)가 \(AP : PB = m : n\ (m > 0, n > 0)\)을 만족할 때, \(P\)는 선분 \(AB\)를 \(m : n\)으로 내분한다고 하고, \(P\)를 내분점이라 한다.

1.1.3평면에서는 가로와 세로를 따로

그림 1에서 \(P\)를 지나 축에 평행한 선을 그어 보자. 평행선이 만드는 닮은 삼각형 때문에, \(P\)는 가로 변도 \(m : n\)으로, 세로 변도 \(m : n\)으로 나눈다. 그러면 \(P\)의 \(x\)좌표는 \(x_1\)과 \(x_2\)를, \(y\)좌표는 \(y_1\)과 \(y_2\)를 각각 수직선에서처럼 나눈 값이다.

정리 1.1.3 좌표평면 위의 내분점

두 점 \(A(x_1, y_1)\), \(B(x_2, y_2)\)를 잇는 선분 \(AB\)를 \(m : n\)으로 내분하는 점은 \[P\left(\frac{mx_2 + nx_1}{m + n},\ \frac{my_2 + ny_1}{m + n}\right)\] 특히 중점은 \(m = n\)인 경우로 \(\left(\dfrac{x_1 + x_2}{2}, \dfrac{y_1 + y_2}{2}\right)\)이다.

이 공식으로 그림 2의 무게중심도 구할 수 있다. 꼭짓점 \(A(x_1, y_1)\)과 변 \(BC\)의 중점 \(M\)을 잇는 선분을 \(2 : 1\)로 내분하면 \(x\)좌표는 \(\dfrac{2 \cdot \frac{x_2 + x_3}{2} + x_1}{3} = \dfrac{x_1 + x_2 + x_3}{3}\)이다. \(y\)좌표도 같은 꼴이다.1

1.1.4예제 하나를 끝까지

예제 1.1.4

처음 질문의 \(A(-3, -1)\), \(B(5, 3)\)에서 정류장 \(P\)의 좌표를 구하고, \(AP\)가 정말 \(AB\)의 \(\tfrac{1}{4}\)인지 확인하여라.

\(A\)에서 \(B\)까지의 \(\tfrac{1}{4}\) 지점은 \(AP : PB = 1 : 3\)인 점이다. 그러면 \(m = 1\), \(n = 3\)이므로 \(x = \dfrac{1 \cdot 5 + 3 \cdot (-3)}{4} = -1\), \(y = \dfrac{1 \cdot 3 + 3 \cdot (-1)}{4} = 0\)이다. 따라서 \(P(-1, 0)\)이다.

확인은 거리 공식으로 한다. \(AP = \sqrt{2^2 + 1^2} = \sqrt{5}\)이고, 1에서 구한 \(AB = 4\sqrt{5}\)의 정확히 \(\tfrac{1}{4}\)이다. \(PB = \sqrt{6^2 + 3^2} = 3\sqrt{5}\)이므로 \(AP : PB = 1 : 3\)도 맞는다. 그림 1의 슬라이더를 \(m = 1\), \(n = 3\)에 두면 같은 점이 보인다. 아래 탐구 카드에서 두 점을 직접 움직이며 거리와 내분점이 어떻게 바뀌는지 확인해 보자.

  1. 세 중선이 한 점에서 만난다는 것도 이 계산으로 보인다. 어느 꼭짓점에서 출발해 \(2 : 1\)로 내분해도 같은 좌표 \(\left(\tfrac{x_1 + x_2 + x_3}{3}, \tfrac{y_1 + y_2 + y_3}{3}\right)\)이 나오기 때문이다.
마무리

두 점 사이의 거리는 가로와 세로의 차를 두 변으로 하는 직각삼각형의 빗변이고, 선분을 \(m : n\)으로 나누는 점은 가로와 세로를 각각 같은 비로 나눈 자리에 있다. 그래서 처음 질문의 길은 \(4\sqrt{5}\)이고, 정류장은 \(1 : 3\) 내분점 \((-1, 0)\)이다.

두 점 사이의 거리는 어떻게 잴까?

두 점 사이의 거리 · 피타고라스 정리

—

가로 \(|x_2 - x_1|\)
—
세로 \(|y_2 - y_1|\)
—
거리 \(AB\)
—

점 \(A, B\)를 끌 수 있고, 두 점은 격자점에 맞춰 움직인다.

  1. 질문지도 위 두 지점 \(A, B\)의 좌표를 알 때, 자로 재지 않고 두 지점 사이의 곧은 거리를 계산할 수 있을까?
  2. 복원수직선 위의 두 점 \(a, b\) 사이의 거리는 \(|b - a|\)이다. 또 직각삼각형에서 빗변의 길이를 \(c\), 나머지 두 변을 \(a, b\)라 하면 \(a^2 + b^2 = c^2\)이다(피타고라스 정리).
  3. 설명두 점 \(A(x_1, y_1), B(x_2, y_2)\)에 대해 점 \((x_2, y_1)\)을 잡으면, 선분 \(AB\)를 빗변으로 하고 두 변이 축에 평행한 직각삼각형이 생긴다. 가로 변의 길이는 \(|x_2 - x_1|\), 세로 변의 길이는 \(|y_2 - y_1|\)이므로 \(AB = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\)이다. 제곱을 하므로 절댓값도, 두 점의 순서도 결과에 영향을 주지 않는다. 특히 원점 \(O\)와 점 \((x, y)\) 사이의 거리는 \(\sqrt{x^2 + y^2}\)이다.
  4. 연결두 점의 \(y\)좌표가 같으면 세로 변이 0이 되어 수직선 위의 거리 \(|x_2 - x_1|\)로 돌아간다. 이 거리 공식은 내분점이 선분을 정말 주어진 비로 나누는지 확인할 때, 그리고 중심에서 거리가 일정한 점들로 원의 방정식을 세울 때 그대로 쓰인다.
  5. 적용\(A\)와 \(B\)를 움직여 가로와 세로가 3과 4가 되게 하면 거리는 5이다. \(A\)를 \((0, 0)\)에 두고 거리가 5인 격자점을 모두 세어 보자. 거리가 \(\sqrt{2}, \sqrt{5}\)처럼 정수가 아닌 경우도 만들어 볼 수 있다.
  6. 판단가로와 세로를 그냥 더한 \(|x_2 - x_1| + |y_2 - y_1|\)는 격자를 따라 걷는 거리이지 곧은 거리가 아니다. 또 \(\sqrt{a^2 + b^2}\)를 \(a + b\)로 계산하면 안 된다. 그리고 이 공식은 가로축과 세로축의 눈금 간격이 같은 좌표평면에서 성립한다.

선분을 \(m : n\)으로 나누는 점은 어디에 있을까?

내분점 · 수직선에서 좌표평면으로

—

내분점 \(P\)
—
\(AP\)
—
\(PB\)
—

\(A, B\)를 끌 수 있다. 선분 위의 작은 점은 \(AB\)를 \(m + n\)등분한 자리이다.

  1. 질문두 도시 \(A, B\)를 잇는 곧은 도로에서 \(A\)부터 \(B\)까지의 \(\frac{2}{3}\) 되는 곳에 휴게소를 지으려고 한다. 두 도시의 좌표만으로 휴게소의 좌표를 구할 수 있을까?
  2. 복원수직선 위 두 점 사이의 거리는 좌표의 차이고, 비례식 \(a : b = c : d\)에서는 \(ad = bc\)이다. 또 평행선으로 잘린 삼각형의 변은 같은 비로 나뉜다(닮음).
  3. 설명선분 \(AB\) 위의 점 \(P\)가 \(AP : PB = m : n (m > 0, n > 0)\)을 만족할 때, 점 \(P\)는 선분 \(AB\)를 \(m : n\)으로 내분한다고 하고 \(P\)를 내분점이라고 한다. 수직선에서 \(A(x_1), B(x_2), P(x)\)이고 \(x_1 < x_2\)이면 \((x - x_1) : (x_2 - x) = m : n\)이므로 \(x = \frac{mx_2 + nx_1}{m + n}\)이다(\(x_1 > x_2\)여도 같은 식이 나온다). 좌표평면에서는 \(A, P, B\)에서 \(x\)축에 수선을 내리면 평행선 때문에 발끼리도 \(m : n\)으로 나뉜다. 그래서 \(x\)좌표와 \(y\)좌표 각각에 같은 식을 쓰면 \(P(\frac{mx_2 + nx_1}{m + n}, \frac{my_2 + ny_1}{m + n})\)이고, \(m = n\)이면 중점 \((\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2})\)이다.
  4. 연결삼각형의 무게중심은 중선을 꼭짓점에서부터 2 : 1로 내분하는 점이다. 그래서 이 식을 쓰면 무게중심이 \((\frac{x_1 + x_2 + x_3}{3}, \frac{y_1 + y_2 + y_3}{3})\)임을 얻는다. 중점은 대칭이동에서 대칭축을 찾는 데에도 쓰인다.
  5. 적용먼저 '수직선 위에서'로 \(A, B\)를 놓고 \(m, n\)을 바꾸어 \(P\)가 몇 번째 작은 점에 오는지 보자. 그다음 '좌표평면 위에서'로 바꾸면 축 위의 발들도 같은 비로 나뉘는 것을 확인할 수 있다. \(m = n\)이면 \(P\)는 중점이고, \(m\)과 \(n\)을 서로 바꾸면 \(P\)는 중점에 대해 반대쪽으로 옮겨 간다.
  6. 판단\(m : n\)은 \(A\)에서부터 잰 비이다. 그래서 분자에서 \(m\)은 \(B\)의 좌표 \(x_2\)에, \(n\)은 \(A\)의 좌표 \(x_1\)에 곱한다. 가까운 쪽이 아니라 먼 쪽 점에 큰 수가 곱해지는 것이 헷갈리기 쉬운데, \(m\)이 클수록 \(P\)는 \(B\)에 가까워진다고 기억하면 된다. 또 내분점은 항상 선분 위, 두 점 사이에 있다.
