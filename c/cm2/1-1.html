선분의 내분점

좌표평면에서는 점의 위치를 수의 쌍으로 나타내므로, 길이와 위치를 계산으로 구할 수 있습니다. 이 절에서는 먼저 두 점 사이의 거리를 구하고, 이어서 선분을 주어진 비로 나누는 점의 좌표를 수직선에서 좌표평면으로 넓혀 가며 구합니다.

1.1.1

두 점 사이의 거리는 어떻게 잴까?

두 점 사이의 거리 · 피타고라스 정리

—

가로 \(|x_2 - x_1|\)
—
세로 \(|y_2 - y_1|\)
—
거리 \(AB\)
—

점 \(A, B\)를 끌어 보세요. 두 점은 격자점에 맞춰 움직입니다.

  1. 질문지도 위 두 지점 \(A, B\)의 좌표를 알 때, 자로 재지 않고 두 지점 사이의 곧은 거리를 계산할 수 있을까요?
  2. 복원수직선 위의 두 점 \(a, b\) 사이의 거리는 \(|b - a|\)입니다. 직각삼각형에서 빗변의 길이를 \(c\), 나머지 두 변을 \(a, b\)라 하면 \(a^2 + b^2 = c^2\)입니다(피타고라스 정리).
  3. 설명두 점 \(A(x_1, y_1), B(x_2, y_2)\)에 대해 점 \((x_2, y_1)\)을 잡으면, 선분 \(AB\)를 빗변으로 하고 두 변이 축에 평행한 직각삼각형이 생깁니다. 가로 변의 길이는 \(|x_2 - x_1|\), 세로 변의 길이는 \(|y_2 - y_1|\)이므로 \(AB = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\)입니다. 제곱을 하므로 절댓값도, 두 점의 순서도 결과에 영향을 주지 않습니다. 특히 원점 \(O\)와 점 \((x, y)\) 사이의 거리는 \(\sqrt{x^2 + y^2}\)입니다.
  4. 연결두 점의 \(y\)좌표가 같으면 세로 변이 0이 되어 수직선 위의 거리 \(|x_2 - x_1|\)로 돌아갑니다. 이 거리 공식은 내분점이 선분을 정말 주어진 비로 나누는지 확인할 때, 그리고 원의 방정식(중심에서 거리가 일정한 점)을 세울 때 그대로 쓰입니다.
  5. 적용\(A\)와 \(B\)를 움직여 가로와 세로가 3과 4가 되게 해 보세요. 거리는 얼마인가요? \(A\)를 \((0, 0)\)에 두고 거리가 5인 격자점을 몇 개나 찾을 수 있는지 세어 보세요. 거리가 \(\sqrt{2}, \sqrt{5}\)처럼 정수가 아닌 경우도 만들어 보세요.
  6. 판단가로와 세로를 그냥 더한 \(|x_2 - x_1| + |y_2 - y_1|\)는 격자를 따라 걷는 거리이지 곧은 거리가 아닙니다. 또 \(\sqrt{a^2 + b^2}\)를 \(a + b\)로 계산하면 안 됩니다. 이 공식은 가로축과 세로축의 눈금 간격이 같은 좌표평면에서 성립합니다.

1.1.2

선분을 \(m : n\)으로 나누는 점은 어디에 있을까?

내분점 · 수직선에서 좌표평면으로

—

내분점 \(P\)
—
\(AP\)
—
\(PB\)
—

\(A, B\)를 끌어 보세요. 선분 위의 작은 점은 \(AB\)를 \(m + n\)등분한 자리입니다.

  1. 질문두 도시 \(A, B\)를 잇는 곧은 도로에서 \(A\)부터 \(B\)까지의 \(\frac{2}{3}\) 되는 곳에 휴게소를 지으려고 합니다. 두 도시의 좌표만으로 휴게소의 좌표를 구할 수 있을까요?
  2. 복원수직선 위 두 점 사이의 거리는 좌표의 차입니다. 비례식 \(a : b = c : d\)에서는 \(ad = bc\)입니다. 평행선으로 잘린 삼각형의 변은 같은 비로 나뉩니다(닮음).
  3. 설명선분 \(AB\) 위의 점 \(P\)가 \(AP : PB = m : n (m > 0, n > 0)\)을 만족할 때, 점 \(P\)는 선분 \(AB\)를 \(m : n\)으로 내분한다고 하고 \(P\)를 내분점이라고 합니다. 수직선에서 \(A(x_1), B(x_2), P(x)\)이고 \(x_1 < x_2\)이면 \((x - x_1) : (x_2 - x) = m : n\)이므로 \(x = \frac{mx_2 + nx_1}{m + n}\)입니다(\(x_1 > x_2\)여도 같은 식이 나옵니다). 좌표평면에서는 \(A, P, B\)에서 \(x\)축에 수선을 내리면 평행선 때문에 발끼리도 \(m : n\)으로 나뉩니다. 그래서 \(x\)좌표와 \(y\)좌표 각각에 같은 식을 쓰면 \(P(\frac{mx_2 + nx_1}{m + n}, \frac{my_2 + ny_1}{m + n})\)입니다. \(m = n\)이면 중점 \((\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2})\)입니다.
  4. 연결삼각형의 무게중심은 중선을 꼭짓점에서부터 2 : 1로 내분하는 점입니다. 이 식을 쓰면 무게중심이 \((\frac{x_1 + x_2 + x_3}{3}, \frac{y_1 + y_2 + y_3}{3})\)임을 얻습니다. 중점은 대칭이동에서 대칭축을 찾는 데에도 쓰입니다.
  5. 적용먼저 '수직선 위에서'로 \(A, B\)를 놓고 \(m, n\)을 바꾸어 \(P\)가 몇 번째 작은 점에 오는지 보세요. 그다음 '좌표평면 위에서'로 바꾸어 축 위의 발들도 같은 비로 나뉘는지 확인하세요. \(m = n\)일 때의 \(P\)는 무엇인가요? \(m\)과 \(n\)을 서로 바꾸면 \(P\)는 어디로 가나요?
  6. 판단\(m : n\)은 \(A\)에서부터 잰 비입니다. 분자에서 \(m\)은 \(B\)의 좌표 \(x_2\)에, \(n\)은 \(A\)의 좌표 \(x_1\)에 곱합니다. 가까운 쪽이 아니라 먼 쪽 점에 큰 수가 곱해지는 것이 헷갈리기 쉽습니다. \(m\)이 클수록 \(P\)는 \(B\)에 가까워집니다. 또 내분점은 항상 선분 위, 두 점 사이에 있습니다.
