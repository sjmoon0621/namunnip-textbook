2.7.1

n2이 짝수이면 n도 짝수임을 어떻게 증명할까?

대우를 이용한 증명 · 넓이 모형

—

n을 m으로 나눈 나머지
—
n²을 m으로 나눈 나머지
—
구석 r² 조각
—

—

  1. 질문"자연수 n에 대하여 n2이 짝수이면 n은 짝수이다"를 증명하고 싶습니다. n2 = 2k로 놓으면 n = √(2k)가 되어 더 나아갈 수 없습니다. 어떻게 해야 할까요?
  2. 복원명제와 그 대우는 참·거짓이 같습니다. 자연수 n을 m으로 나누면 n = mk + r (0 ≤ r < m)로 쓸 수 있습니다.
  3. 설명원래 명제 대신 대우 "n이 홀수이면 n2은 홀수이다"를 증명합니다. n = 2k + 1이면 n2 = 4k2 + 4k + 1 = 2(2k2 + 2k) + 1이므로 홀수입니다. 대우가 참이므로 원래 명제도 참입니다. 이것이 대우를 이용한 증명법입니다. 그림에서 한 변이 n = mk + r인 정사각형은 (mk)2 조각, mk × r 띠 두 개, r × r 구석으로 나뉩니다. 앞의 세 조각은 넓이가 모두 m의 배수이므로, n2을 m으로 나눈 나머지는 구석 r2이 정합니다.
  4. 연결이 결과는 바로 다음 카드의 귀류법에서 "p2이 짝수이므로 p도 짝수"라는 단계로 쓰입니다. 결론이 '~가 아니다' 꼴이거나 가정에서 결론으로 가는 길이 막힐 때 대우를 떠올리면 좋습니다.
  5. 적용m = 2에서 n을 바꾸며 구석 조각을 보세요. n이 홀수이면 구석은 늘 몇 칸인가요? m = 3으로 바꾸어 r = 1, 2일 때 구석의 넓이를 3으로 나눈 나머지를 확인하세요. m = 4에서 n = 2, 6, 10은 무엇을 알려 주나요? 각 경우에 '증명 다음 단계'를 끝까지 눌러 보세요.
  6. 판단대우를 이용한 증명이 언제나 통하는 것은 아닙니다. 명제가 거짓이면 대우도 거짓이어서 증명이 막힙니다. m = 4에서 n = 2이면 n2 = 4는 4의 배수이지만 2는 4의 배수가 아니므로, "n2이 4의 배수이면 n은 4의 배수"는 거짓입니다. 증명 단계에서 막히면 반례를 찾아보세요.

2.7.2

√2가 분수가 아니라는 것을 어떻게 증명할까?

귀류법 · 무리수

—

p²
—
2q²
—
p² − 2q²
—

—

  1. 질문√2 = 1.41421…은 7/5 = 1.4, 17/12 = 1.4166…처럼 분수에 아주 가까워질 수 있습니다. 그렇다면 정확히 √2와 같은 분수는 정말 없을까요? 어떻게 '없다'를 증명할 수 있을까요?
  2. 복원유리수는 서로소인 두 정수 p, q(q ≠ 0)로 p/q처럼 나타낼 수 있는 수입니다. "n2이 짝수이면 n은 짝수"는 대우로 증명한 사실입니다.
  3. 설명'없다'는 하나하나 확인해서 보일 수 없습니다. 그래서 결론을 부정해 √2 = p/q(p, q는 서로소인 자연수)라고 가정합니다. 제곱하면 p2 = 2q2이므로 p2은 짝수, 따라서 p도 짝수입니다. p = 2m을 넣으면 q2 = 2m2이 되어 q도 짝수입니다. p, q가 모두 2로 나누어떨어지므로 서로소라는 가정과 모순입니다. 이처럼 결론을 부정했을 때 모순이 생김을 보여 원래 명제가 참임을 증명하는 방법을 귀류법이라 합니다.
  4. 연결같은 방법으로 √3, √5가 무리수임도 증명할 수 있습니다. 이때는 "p2이 3의 배수이면 p도 3의 배수"가 필요합니다. 귀류법은 '무한히 많다', '존재하지 않는다'처럼 하나씩 확인할 수 없는 명제를 증명할 때 자주 씁니다.
  5. 적용점을 누르거나 슬라이더로 p, q를 골라 p2 − 2q2 = 0인 점을 찾아보세요. 직선에 가장 가까운 점들(테두리 점)에서 차이는 얼마인가요? 찾지 못했다면 그것이 증명인지 생각해 본 뒤 '증명 다음 단계'를 끝까지 눌러 보세요.
  6. 판단격자에서 p2 = 2q2인 점을 찾지 못한 것은 증명이 아닙니다. 더 큰 수에서 있을지도 모르기 때문입니다. 귀류법은 모든 경우를 한 번에 다룹니다. 또 '서로소'라는 가정을 빼면 모순이 생기지 않습니다. 모순이 어느 가정과 부딪히는지 분명히 해야 합니다.

2.7.3

어떤 명제에 어떤 증명법을 쓸까?

읽기 · 증명법 · 유클리드

같은 명제라도 어떤 길로 증명하느냐에 따라 쉽기도 하고 막히기도 합니다. 세 가지 증명법을 비교하고, 2천 년 넘게 쓰여 온 귀류법의 대표 예를 따라가 봅니다.

1세 가지 길

증명법하는 일잘 맞는 명제
직접 증명가정 p에서 출발해 결론 q까지 이어 간다두 짝수의 합은 짝수이다
대우를 이용한 증명~q에서 출발해 ~p를 이끈다n2이 짝수이면 n은 짝수이다

대우를 이용한 증명과 귀류법은 모두 결론을 부정한 데서 출발합니다. 차이는 도착점입니다. 대우는 정해진 목표 ~p에 도착해야 하고, 귀류법은 가정이든 이미 아는 사실이든 무엇과든 모순이 생기면 됩니다.

2유클리드: 소수는 무한히 많다

기원전 300년 무렵 유클리드의 『원론』에 실린 증명을 지금의 말로 옮기면 다음과 같습니다.

  • 결론을 부정해, 소수가 유한개 p1, p2, …, pk뿐이라고 가정합니다.
  • N = p1p2 ⋯ pk + 1을 만듭니다. N은 1보다 큰 자연수이므로 소인수를 적어도 하나 가집니다.
  • N을 p1, …, pk 가운데 어느 것으로 나누어도 나머지가 1입니다. 따라서 N의 소인수는 목록에 없는 소수입니다.
  • 목록이 모든 소수라는 가정과 모순이므로, 소수는 무한히 많습니다.

판단이 증명은 "N이 소수이다"라고 말하지 않습니다. 2 × 3 × 5 × 7 × 11 × 13 + 1 = 30031 = 59 × 509처럼 N이 합성수일 수도 있습니다. 증명에 필요한 것은 N의 소인수가 목록 밖에 있다는 사실뿐입니다.
