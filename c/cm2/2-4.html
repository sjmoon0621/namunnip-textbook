명제와 조건

2.4.1

'모든'과 '어떤'이 붙으면 참·거짓은 어떻게 정해질까?

조건과 진리집합 · 모든 · 어떤

—

모든 x에 대하여 p(x)
—
어떤 x에 대하여 p(x)
—

—

  1. 질문"x2 ≥ x"는 참일까요, 거짓일까요? 앞에 '모든 자연수 x에 대하여'를 붙이면 어떻게 되고, '어떤 정수 x에 대하여'를 붙이면 어떻게 될까요?
  2. 복원집합 U의 원소 가운데 어떤 성질을 만족하는 것만 모으면 U의 부분집합이 됩니다. 여집합 PC는 U에서 P에 속하지 않는 원소 전체입니다.
  3. 설명참인지 거짓인지 분명하게 판별할 수 있는 문장이나 식을 명제, 변수의 값에 따라 참·거짓이 정해지는 문장이나 식을 조건이라 합니다. 전체집합 U의 원소 가운데 조건 p(x)를 참이 되게 하는 것 전체를 p의 진리집합 P라 합니다. 'p가 아니다'를 p의 부정 ~p라 하고, ~p의 진리집합은 PC입니다. 조건 앞에 '모든'이나 '어떤'을 붙이면 명제가 됩니다. "모든 x에 대하여 p(x)"는 P = U일 때만 참이고, 거짓임을 보이려면 반례 하나면 됩니다. "어떤 x에 대하여 p(x)"는 P ≠ ∅이면 참이고, 참임을 보이려면 예 하나면 됩니다.
  4. 연결"모든 x에 대하여 p(x)"의 부정은 "어떤 x에 대하여 ~p(x)"이고, "어떤 x에 대하여 p(x)"의 부정은 "모든 x에 대하여 ~p(x)"입니다. 집합으로 쓰면 P = U의 부정이 PC ≠ ∅입니다. 이 장 끝의 절대부등식은 '모든 실수 x에 대하여' 성립하는 부등식입니다.
  5. 적용조건 x2 ≥ x에서 두 전체집합을 비교해 보세요. 칸을 눌러 x = 0, −2에서의 계산을 확인하세요. x2 = 4는 전체집합에 따라 진리집합이 어떻게 달라지나요? x2 < 0에서 '모든'과 '어떤' 명제는 각각 참인가요?
  6. 판단조건의 참·거짓은 전체집합을 정해야 결정됩니다. 같은 조건도 U가 바뀌면 진리집합이 바뀝니다. 또 "모든 x에 대하여 p"의 부정을 "모든 x에 대하여 ~p"로 쓰는 실수가 많습니다. '모두 그렇다'를 부정하면 '그렇지 않은 것이 하나는 있다'입니다.

2.4.2

'p이면 q이다'가 참인지 집합으로 어떻게 판단할까?

명제 p → q · 진리집합의 포함관계

—

P ⊂ Q
—
명제 p → q
—
  1. 질문"−1 ≤ x ≤ 1이면 x2 ≤ 4이다"는 참일까요? 무한히 많은 실수를 하나씩 넣어 볼 수 없는데 어떻게 확신할 수 있을까요?
  2. 복원조건 p를 참이 되게 하는 값 전체가 진리집합 P입니다. 부등식의 해는 수직선 위의 구간으로 나타납니다. 끝점이 포함되면 속이 찬 점, 포함되지 않으면 빈 점으로 그립니다.
  3. 설명'p이면 q이다'를 기호로 p → q라 쓰고, p를 가정, q를 결론이라 합니다. 이 명제는 p를 만족하는 값이 언제나 q도 만족할 때 참입니다. 진리집합으로 말하면 P ⊂ Q일 때 참이고, P ⊄ Q일 때 거짓입니다. 거짓일 때 P에는 속하지만 Q에는 속하지 않는 값, 곧 P ∩ QC의 원소가 반례입니다. 명제가 참이면 p ⇒ q로 씁니다.
  4. 연결이 판단법은 다음 절의 역과 대우, 그 다음 절의 충분조건·필요조건에서 그대로 쓰입니다. 모두 진리집합 사이의 포함관계를 묻는 질문입니다.
  5. 적용q: x2 ≤ 4에서 명제가 참이 되도록 b를 가장 크게 하면 얼마인가요? q: x > 0에서 a = 0, b = 2로 두면 반례는 무엇인가요? q: x2 − 1 > 0에서 명제가 참이 되는 구간은 어디에 있어야 하나요?
  6. 판단P에 속하는 값 몇 개가 Q에 들어간다고 명제가 참이 되지는 않습니다. P의 모든 원소가 Q에 있어야 합니다. 반대로 거짓임을 보일 때는 반례 하나로 충분합니다. 끝점 하나가 반례가 되는 경우를 특히 조심해야 합니다. 또 가정이 공집합이면(P = ∅) 반례가 없으므로 명제는 참으로 봅니다.

2.4.3

정의와 정리는 어떻게 다르고, 조건은 어떻게 부정할까?

읽기 · 정의 · 정리 · 부정

교과서의 문장은 "~라 한다"로 끝나기도 하고 "~이다"로 끝나기도 합니다. 두 문장은 하는 일이 다릅니다. 수학의 문장을 읽고 부정하는 규칙을 정리해 봅니다.

1정의는 약속, 정리는 증명된 참인 명제

용어의 뜻을 명확하게 정한 문장을 정의라 합니다. "2로 나누어떨어지는 정수를 짝수라 한다"는 정의입니다. 정의는 약속이므로 증명하지 않습니다. 정의와 이미 참으로 밝혀진 성질을 근거로 어떤 명제가 참임을 논리적으로 밝히는 과정을 증명이라 하고, 증명된 명제 가운데 기본이 되는 것을 정리라 합니다. "두 짝수의 합은 짝수이다"는 정리입니다. 2m + 2n = 2(m + n)으로 증명됩니다.

2가정과 결론

명제 'p이면 q이다'(p → q)에서 p가 가정, q가 결론입니다. 정리를 쓸 때는 가정이 성립하는지 먼저 확인해야 합니다. 예를 들어 "삼각형이 직각삼각형이면 a2 + b2 = c2이다"를 직각삼각형이 아닌 삼각형에 쓸 수 없습니다.

3부정하는 규칙

조건 p의 부정 ~p의 진리집합은 PC이고, ~(~p)는 다시 p입니다. '그리고'와 '또는'이 들어간 조건은 드모르간의 법칙대로 부정합니다. (P ∩ Q)C = PC ∪ QC이므로 'p 그리고 q'의 부정은 '~p 또는 ~q'입니다.

조건 또는 명제부정
x = 1x ≠ 1
x > 2x ≤ 2
x > 0 그리고 y > 0x ≤ 0 또는 y ≤ 0
x = 0 또는 y = 0x ≠ 0 그리고 y ≠ 0
모든 x에 대하여 p(x)어떤 x에 대하여 ~p(x)

판단"x > 2"의 부정을 "x < 2"로 쓰면 x = 2가 어느 쪽에도 속하지 않습니다. 조건과 그 부정의 진리집합은 합치면 전체집합, 겹치면 공집합이 되어야 합니다.
