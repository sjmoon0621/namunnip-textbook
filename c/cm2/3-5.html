무리함수

본문

정사각형 모양의 텃밭 넓이가 \(x\ \text{m}^2\)이면 한 변의 길이는 \(\sqrt{x}\) m이다. 넓이가 늘어날 때 변의 길이는 어떻게 늘어날까? 그리고 \(y = \sqrt{x}\)의 그래프는 왜 원점에서 시작해 한쪽으로만 뻗을까?

먼저 알아야 할 것제곱근과 근호, 역함수의 그래프(역함수), 그래프의 평행이동과 대칭이동(평행이동, 대칭이동).

3.5.1근호 안이 0 이상인 곳에서만

근호 안에 문자가 있는 식 가운데 유리식으로 나타낼 수 없는 것을 무리식이라 한다. \(y = f(x)\)에서 \(f(x)\)가 \(x\)에 대한 무리식이면 이 함수를 무리함수라 한다. 실수 범위에서는 음수의 제곱근을 생각하지 않으므로, 정의역을 따로 말하지 않으면 근호 안이 0 이상인 실수 전체를 정의역으로 본다.

\(y = \sqrt{x}\)의 정의역은 \(x \ge 0\)이고, 값도 0 이상이다. 그래서 그래프는 원점에서 시작해 제1사분면으로만 뻗는다. \(x\)가 0, 1, 4, 9일 때 \(y\)는 0, 1, 2, 3이므로, 넓이가 네 배가 되어야 변의 길이가 두 배가 된다. 그래프는 오른쪽으로 갈수록 점점 완만해진다.

3.5.2\(y = x^2\)의 절반을 돌린 것

\(y = \sqrt{x}\)는 \(y = x^2\ (x \ge 0)\)의 역함수이다. \(y = x^2\)을 \(x\)에 대해 풀면 \(x = \sqrt{y}\)이고, \(x\)와 \(y\)를 바꾸면 \(y = \sqrt{x}\)이기 때문이다. 따라서 \(y = \sqrt{x}\)의 그래프는 포물선의 오른쪽 절반을 직선 \(y = x\)에 대칭이동한 모양이다.

나머지 모양은 대칭이동과 평행이동으로 얻는다. \(y = -\sqrt{x}\)는 \(x\)축에 대칭, \(y = \sqrt{-x}\)는 \(y\)축에 대칭이다. 그리고 \(y = \sqrt{a(x - p)} + q\)는 \(y = \sqrt{ax}\)를 \(x\)축 방향으로 \(p\), \(y\)축 방향으로 \(q\)만큼 옮긴 것이다.

정리 3.5.1 \(y = \sqrt{a(x - p)} + q\)의 그래프

\(a > 0\)이면 정의역은 \(\{x \mid x \ge p\}\), \(a < 0\)이면 \(\{x \mid x \le p\}\)이고, 치역은 \(\{y \mid y \ge q\}\)이다. 그래프는 점 \((p, q)\)에서 시작한다.

그림 1에서 \(a\)의 부호를 바꾸면 그래프가 시작점에서 왼쪽으로 뻗고, \(p\)와 \(q\)를 바꾸면 시작점이 옮겨 간다. 근호 안이 0이 되는 \(x = p\)에서 출발한다는 것만 기억하면 그래프의 위치가 바로 정해진다.1

3.5.3예제 하나를 끝까지

예제 3.5.2

함수 \(y = \sqrt{2x - 4} + 1\)의 정의역과 치역을 구하고, 직선 \(y = x\)와의 교점을 구하여라.

근호 안을 묶으면 \(\sqrt{2(x - 2)} + 1\)이므로 \(a = 2\), \(p = 2\), \(q = 1\)이다. 따라서 정의역은 \(\{x \mid x \ge 2\}\), 치역은 \(\{y \mid y \ge 1\}\)이고, 그래프는 점 \((2, 1)\)에서 오른쪽 위로 뻗는다.

교점은 \(\sqrt{2x - 4} + 1 = x\)를 풀어 구한다. \(\sqrt{2x - 4} = x - 1\)의 양변을 제곱하면 \(2x - 4 = x^2 - 2x + 1\), 곧 \(x^2 - 4x + 5 = 0\)이다. 그런데 판별식이 \(\dfrac{D}{4} = 4 - 5 = -1 < 0\)이므로 실근이 없다. 따라서 그래프와 직선 \(y = x\)는 만나지 않는다.

그래프로 확인하면, 시작점 \((2, 1)\)은 직선 \(y = x\)보다 아래에 있고 \(x\)가 커질수록 그래프의 기울기는 1보다 작아지므로 끝까지 직선 아래에 머문다. 양변을 제곱하는 풀이에서는 원래 식의 해가 아닌 값이 끼어들 수 있으니, 해가 나오면 반드시 원래 식에 넣어 확인해야 한다.2 아래 탐구 카드에서 시작점과 방향을 바꾸며 그래프와 직선이 몇 번 만나는지 직접 확인해 보자.

  1. \(y = \sqrt{ax + b} + c\)꼴은 근호 안을 \(a\)로 묶어 \(\sqrt{a\left(x + \tfrac{b}{a}\right)} + c\)로 바꾸면 \(p = -\tfrac{b}{a}\)가 보인다.
  2. 가령 \(\sqrt{x} = x - 2\)를 제곱하면 \(x^2 - 5x + 4 = 0\)에서 \(x = 1, 4\)가 나오지만, \(x = 1\)은 우변이 \(-1\)이라 원래 식을 만족하지 않는다.
마무리

무리함수는 근호 안이 0 이상인 곳에서만 정의되므로, \(y = \sqrt{a(x - p)} + q\)의 그래프는 근호 안이 0이 되는 점 \((p, q)\)에서 시작해 한쪽으로만 뻗는다. 기본형 \(y = \sqrt{x}\)는 \(y = x^2\ (x \ge 0)\)의 역함수이다. 그래서 처음 질문의 텃밭은 넓이가 네 배가 되어야 변의 길이가 두 배가 되고, 그래프는 원점에서 시작해 점점 완만해진다.

치역

뻗는 방향
—

빨간 시작점을 끌면 그래프가 평행이동한다. 점선은 시작점이 원점인 \(y = \pm\sqrt{ax}\)이다. \(a = 0\)은 무리함수가 아니라서 건너뛴다.

  1. 질문진자의 주기는 길이의 제곱근에 비례하고, 자유 낙하하는 물체가 떨어진 시간은 낙하 거리의 제곱근에 비례한다. \(y = \sqrt{x}\) 같은 함수의 그래프는 어디서 시작해서 어느 쪽으로 뻗을까?
  2. 복원\(\sqrt{A}\)는 \(A \ge 0\)일 때만 실수이고, 그 값은 0 이상이다. 또 \(y = \sqrt{x}\)는 \(y = x^2(x \ge 0)\)의 역함수이므로, 그 그래프는 포물선의 오른쪽 절반을 직선 \(y = x\)에 대하여 대칭이동한 모양이다.
  3. 설명근호 안에 문자가 있는 식 가운데 유리식으로 나타낼 수 없는 식을 무리식이라 하고, \(y = f(x)\)에서 \(f(x)\)가 무리식일 때 무리함수라 한다. 따로 말이 없으면 정의역은 근호 안을 0 이상으로 만드는 실수 전체이다. 그래서 \(y = \sqrt{ax}(a \ne 0)\)는 \(a > 0\)이면 \(x \ge 0\)에서, \(a < 0\)이면 \(x \le 0\)에서 정의되고, 치역은 \(y \ge 0\)이다. \(y = -\sqrt{ax}\)는 이것을 \(x\)축에 대하여 대칭이동한 것으로 치역이 \(y \le 0\)이다. 또 \(y = \sqrt{a(x - p)} + q\)는 \(y = \sqrt{ax}\)를 \(x\)축 방향으로 \(p, y\)축 방향으로 \(q\)만큼 평행이동한 것이라 점 \((p, q)\)에서 시작한다.
  4. 연결\(a\)의 부호는 그래프가 시작점에서 오른쪽과 왼쪽 중 어디로 뻗는지를, 근호 앞의 부호는 위와 아래 중 어디로 뻗는지를 정한다. 또 \(|a|\)가 클수록 그래프가 더 빨리 벌어진다. \(y = \sqrt{ax + b} + c\)는 \(y = \sqrt{a(x + \frac{b}{a})} + c\)로 고치면 시작점이 \((-\frac{b}{a}, c)\)임을 알 수 있다.
  5. 적용\(a\)를 양수에서 음수로 바꾸고 근호 앞 부호를 바꾸어 네 방향을 모두 만들어 보고, 정의역과 치역이 어떻게 바뀌는지 보자. 시작점을 \((3, -2)\)로 옮기고 그래프가 원점 쪽으로 오도록 하려면 \(a\)는 음수, 근호 앞은 양수여야 한다. \(a = 1\)과 \(a = 4\)에서 점 \((p + 1, \cdots)\)의 높이를 비교하면 2배 차이가 난다.
  6. 판단\(\sqrt{x^2}\)은 \(x\)가 아니라 \(|x|\)이다. 그래서 근호를 그냥 지우면 \(x < 0\)에서 틀린다. 또 무리함수의 그래프에는 점근선이 없다. \(y = \sqrt{x}\)는 한없이 커지지만 점점 완만해질 뿐, 어떤 가로선에 가까워지지 않는다.

무리함수의 그래프와 직선은 몇 번 만날까?

무리함수 · 교점의 개수

—

교점의 개수
—
\(u\)에 대한 판별식 \(9 - 4k\)
—
교점
—

\(k\)를 0.25씩 바꾸며 교점의 개수가 바뀌는 곳을 찾을 수 있다. 판별식이 양수인데도 교점이 하나뿐인 때가 있다.

  1. 질문직선 \(y = x + k\)를 위아래로 옮기면 곡선 \(y = \sqrt{x + 2}\)와 만나는 점의 개수는 어떻게 달라질까? 개수가 바뀌는 \(k\)를 그래프와 식으로 찾을 수 있을까?
  2. 복원\(y = \sqrt{x + 2}\)는 점 \((-2, 0)\)에서 시작해 오른쪽 위로 뻗고, 치역은 \(y \ge 0\)이다. 또 이차방정식 \(at^2 + bt + c = 0\)의 실근의 개수는 판별식 \(b^2 - 4ac\)의 부호로 정해진다.
  3. 설명교점의 \(x\)좌표는 방정식 \(x + k = \sqrt{x + 2}\)의 실근이다. \(u = \sqrt{x + 2}\)로 놓으면 \(x = u^2 - 2\)이므로 \(u^2 - u + (k - 2) = 0\)이 된다. 그런데 \(u\)는 근호의 값이므로 \(u \ge 0\)인 근만 교점이 된다. 판별식 \(1 - 4(k - 2) = 9 - 4k\)가 0이 되는 \(k = \frac{9}{4}\)에서 접하고, 두 근의 곱이 \(k - 2\)이므로 \(k < 2\)이면 근 하나가 음수라 교점은 하나뿐이다. 정리하면 \(k < 2\)에서 1개, \(2 \le k < \frac{9}{4}\)에서 2개, \(k = \frac{9}{4}\)에서 1개(접점), \(k > \frac{9}{4}\)에서 0개이다. \(k = 2\)는 직선이 시작점 \((-2, 0)\)을 지나는 경계이다.
  4. 연결양변을 제곱해 \((x + k)^2 = x + 2\)로 풀면, 직선이 \(y < 0\)에서 만나는 아래쪽 반쪽 곡선 \(y = -\sqrt{x + 2}\)과의 교점까지 섞여 나온다. 또 \(y = \sqrt{x + 2}\)는 \(y = x^2 - 2(x \ge 0)\)의 역함수이므로, 두 곡선은 직선 \(y = x\)에 대하여 대칭이다.
  5. 적용\(k = 0\)에서 교점이 하나인 것을 확인하고, 교점이 두 개가 되는 처음 \(k\)를 찾아보자. \(k = 2\)일 때 직선이 시작점 \((-2, 0)\)을 지나고, \(k = 2.25\)에서는 두 교점이 하나로 합쳐져 접한다. \(k = 1\)에서는 판별식이 양수인데도 근 하나가 음수라서 교점이 하나뿐이다.
  6. 판단무리방정식을 제곱해서 풀면 원래 식을 만족하지 않는 근이 생길 수 있다. 그래서 구한 근을 원래 식에 넣어 확인하거나, \(u \ge 0\) 같은 조건을 처음부터 붙여야 한다. 판별식만으로 교점의 개수를 정하면 시작점이 있는 무리함수에서는 틀리기 쉽다.
