무리함수

진자의 주기나 물체가 떨어지는 시간처럼 어떤 양의 제곱근에 따라 정해지는 양이 있습니다. 이 절에서는 근호 안에 문자가 들어 있는 무리함수의 그래프가 어디서 시작해 어느 쪽으로 뻗는지 찾고, 그 그래프가 직선과 만나는 점의 개수를 따져 봅니다.

3.5.1

무리함수의 그래프는 어디서 시작해 어디로 뻗을까?

무리함수 · 정의역과 치역 · 평행이동
근호 앞 부호

—

정의역
—
치역
—
뻗는 방향
—

빨간 시작점을 끌면 그래프가 평행이동합니다. 점선은 시작점이 원점인 \(y = \pm\sqrt{ax}\)입니다. \(a = 0\)은 무리함수가 아니라서 건너뜁니다.

  1. 질문진자의 주기는 길이의 제곱근에 비례하고, 자유 낙하하는 물체가 떨어진 시간은 낙하 거리의 제곱근에 비례합니다. \(y = \sqrt{x}\) 같은 함수의 그래프는 어디서 시작해서 어느 쪽으로 뻗을까요?
  2. 복원\(\sqrt{A}\)는 \(A \ge 0\)일 때만 실수이고, 그 값은 0 이상입니다. \(y = \sqrt{x}\)는 \(y = x^2(x \ge 0)\)의 역함수이므로, 그 그래프는 포물선의 오른쪽 절반을 직선 \(y = x\)에 대하여 대칭이동한 모양입니다.
  3. 설명근호 안에 문자가 있는 식 가운데 유리식으로 나타낼 수 없는 식을 무리식이라 하고, \(y = f(x)\)에서 \(f(x)\)가 무리식일 때 무리함수라 합니다. 따로 말이 없으면 정의역은 근호 안을 0 이상으로 만드는 실수 전체입니다. \(y = \sqrt{ax}(a \ne 0)\)는 \(a > 0\)이면 \(x \ge 0, a < 0\)이면 \(x \le 0\)에서 정의되고, 치역은 \(y \ge 0\)입니다. \(y = -\sqrt{ax}\)는 이것을 \(x\)축에 대하여 대칭이동한 것으로 치역이 \(y \le 0\)입니다. \(y = \sqrt{a(x - p)} + q\)는 \(y = \sqrt{ax}\)를 \(x\)축 방향으로 \(p, y\)축 방향으로 \(q\)만큼 평행이동한 것이라 점 \((p, q)\)에서 시작합니다.
  4. 연결\(a\)의 부호는 그래프가 시작점에서 오른쪽과 왼쪽 중 어디로 뻗는지를, 근호 앞의 부호는 위와 아래 중 어디로 뻗는지를 정합니다. \(|a|\)가 클수록 그래프가 더 빨리 벌어집니다. \(y = \sqrt{ax + b} + c\)는 \(y = \sqrt{a(x + \frac{b}{a})} + c\)로 고치면 시작점이 \((-\frac{b}{a}, c)\)임을 알 수 있습니다.
  5. 적용\(a\)를 양수에서 음수로 바꾸고 근호 앞 부호를 바꾸어 네 방향을 모두 만들어 보세요. 정의역과 치역은 어떻게 바뀌나요? 시작점을 \((3, -2)\)로 옮기고 그래프가 원점 쪽으로 오도록 \(a\)의 부호와 근호 앞 부호를 정해 보세요. \(a = 1\)과 \(a = 4\)에서 점 \((p + 1, \cdots)\)의 높이를 비교해 보세요.
  6. 판단\(\sqrt{x^2}\)은 \(x\)가 아니라 \(|x|\)입니다. 근호를 그냥 지우면 \(x < 0\)에서 틀립니다. 또 무리함수의 그래프에는 점근선이 없습니다. \(y = \sqrt{x}\)는 한없이 커지지만 점점 완만해질 뿐, 어떤 가로선에 가까워지지 않습니다.

3.5.2

무리함수의 그래프와 직선은 몇 번 만날까?

무리함수 · 교점의 개수

—

교점의 개수
—
\(u\)에 대한 판별식 \(9 - 4k\)
—
교점
—

\(k\)를 0.25씩 바꾸며 교점의 개수가 바뀌는 곳을 찾아보세요. 판별식이 양수인데도 교점이 하나뿐인 때가 있습니다.

  1. 질문직선 \(y = x + k\)를 위아래로 옮기면 곡선 \(y = \sqrt{x + 2}\)와 만나는 점의 개수는 어떻게 달라질까요? 개수가 바뀌는 \(k\)를 그래프와 식으로 찾을 수 있을까요?
  2. 복원\(y = \sqrt{x + 2}\)는 점 \((-2, 0)\)에서 시작해 오른쪽 위로 뻗고, 치역은 \(y \ge 0\)입니다. 이차방정식 \(at^2 + bt + c = 0\)의 실근의 개수는 판별식 \(b^2 - 4ac\)의 부호로 정해집니다.
  3. 설명교점의 \(x\)좌표는 방정식 \(x + k = \sqrt{x + 2}\)의 실근입니다. \(u = \sqrt{x + 2}\)로 놓으면 \(x = u^2 - 2\)이므로 \(u^2 - u + (k - 2) = 0\)이 됩니다. 단, \(u\)는 근호의 값이므로 \(u \ge 0\)인 근만 교점이 됩니다. 판별식 \(1 - 4(k - 2) = 9 - 4k\)가 0이면 \(k = \frac{9}{4}\)에서 접합니다. 두 근의 곱은 \(k - 2\)이므로 \(k < 2\)이면 근 하나가 음수라 교점은 하나뿐입니다. 정리하면 \(k < 2\)에서 1개, \(2 \le k < \frac{9}{4}\)에서 2개, \(k = \frac{9}{4}\)에서 1개(접점), \(k > \frac{9}{4}\)에서 0개입니다. \(k = 2\)는 직선이 시작점 \((-2, 0)\)을 지나는 경계입니다.
  4. 연결양변을 제곱해 \((x + k)^2 = x + 2\)로 풀면, 직선이 \(y < 0\)에서 만나는 아래쪽 반쪽 곡선 \(y = -\sqrt{x + 2}\)과의 교점까지 섞여 나옵니다. \(y = \sqrt{x + 2}\)는 \(y = x^2 - 2(x \ge 0)\)의 역함수이므로, 두 곡선은 직선 \(y = x\)에 대하여 대칭입니다.
  5. 적용\(k = 0\)에서 교점이 하나인 것을 확인하고, 교점이 두 개가 되는 처음 \(k\)를 찾으세요. 그때 직선은 어느 점을 지나나요? \(k = 2.25\)에서는 무엇이 보이나요? \(k = 1\)에서 판별식은 양수인데 교점이 하나뿐인 까닭을 설명해 보세요.
  6. 판단무리방정식을 제곱해서 풀면 원래 식을 만족하지 않는 근이 생길 수 있습니다. 그래서 구한 근을 원래 식에 넣어 확인하거나, \(u \ge 0\) 같은 조건을 처음부터 붙여야 합니다. 판별식만으로 교점의 개수를 정하면 시작점이 있는 무리함수에서는 틀리기 쉽습니다.
