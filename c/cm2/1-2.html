두 직선의 평행과 수직

중학교에서 일차함수의 그래프는 기울기와 y절편으로 정해진다고 배웠습니다. 이 절에서는 두 직선의 기울기를 비교해서 평행한지, 겹치는지, 수직으로 만나는지를 판단합니다. 그리고 ax + by + c = 0 꼴로 쓴 직선에서도 같은 판단을 할 수 있게 조건을 넓힙니다.

1.2.1

—
위치 관계
—
교점
—
  1. 질문두 직선 y = 2x + 1과 y = 2x − 3은 아무리 길게 그어도 만나지 않습니다. 두 직선이 만나지 않으려면, 또 완전히 겹치려면 무엇이 같아야 할까요?
  2. 복원직선 y = mx + n에서 m은 x가 1 늘 때 y가 늘어나는 양(기울기)이고, n은 y축과 만나는 점의 y좌표(y절편)입니다. 두 직선의 교점은 두 방정식을 연립한 해입니다.
  3. 설명두 직선 y = m₁x + n₁, y = m₂x + n₂를 연립하면 (m₁ − m₂)x = n₂ − n₁입니다. m₁ ≠ m₂이면 해가 하나라서 한 점에서 만납니다. m₁ = m₂이면 좌변이 0이 되므로, n₁ ≠ n₂일 때는 해가 없어 평행하고, n₁ = n₂일 때는 모든 x가 해여서 일치합니다. 정리하면 평행 ⇔ m₁ = m₂, n₁ ≠ n₂입니다. 직선을 ax + by + c = 0, a′x + b′y + c′ = 0으로 쓰면 평행 조건은 a/a′ = b/b′ ≠ c/c′, 일치 조건은 a/a′ = b/b′ = c/c′입니다.
  4. 연결평행·일치·한 점에서 만남은 연립일차방정식의 해가 없음·무수히 많음·하나인 경우와 정확히 대응합니다. 그래프와 방정식이 같은 사실을 두 가지 말로 하고 있는 것입니다. 기울기의 곱이 −1이면 두 직선은 수직으로 만나는데, 그 까닭은 다음 카드에서 봅니다.
  5. 적용'평행한 예'를 누른 뒤 n₂만 바꾸어 보세요. 교점이 생기나요? n₂를 n₁과 같게 하면 무엇이 달라지나요? 이번에는 m₂를 m₁에 조금씩 가까이 가져가면서 교점이 어디로 달아나는지 보세요.
  6. 판단y축에 평행한 직선 x = k는 기울기가 없어서 y = mx + n 꼴로 쓸 수 없습니다. 그래도 두 직선 x = 1과 x = 3은 평행합니다. 일반형 조건을 쓰면 이런 경우도 다룰 수 있습니다. 다만 분모가 0이 되는 계수가 있으면 비의 꼴 대신 ab′ − a′b = 0처럼 곱의 꼴로 확인합니다.

수직인 두 직선의 기울기는 어떤 관계일까?

—

ℓ₁ 기울기 m₁
—
ℓ₂ 기울기 m₂
—
m₁ × m₂
—

점 Q를 끌어 직선 ℓ₁의 방향을 바꾸세요. Q′은 Q를 원점을 중심으로 90° 돌린 점이고, ℓ₂는 원점과 Q′을 지납니다.

  1. 질문기울기가 2인 직선에 수직인 직선의 기울기는 얼마일까요? −2일까요, 1/2일까요, 아니면 다른 수일까요?
  2. 복원기울기는 (세로 변화량)/(가로 변화량)입니다. 직각삼각형을 90° 돌리면 가로 변과 세로 변이 서로 자리를 바꾼, 합동인 직각삼각형이 됩니다.
  3. 설명원점을 지나는 직선 ℓ₁ 위의 점 Q(p, q)를 원점을 중심으로 90° 돌리면 Q′(−q, p)가 됩니다. 그림의 두 직각삼각형은 합동이고, 가로와 세로가 바뀌면서 한쪽 부호가 바뀝니다. 그래서 m₁ = q/p, m₂ = p/(−q)이고 m₁m₂ = −1입니다. 거꾸로 기울기의 곱이 −1이면 두 직선은 수직입니다. 원점을 지나지 않는 직선도 평행이동하면 기울기가 그대로이므로 같은 조건이 성립합니다. 일반형 ax + by + c = 0과 a′x + b′y + c′ = 0에서는 수직 ⇔ aa′ + bb′ = 0입니다.
  4. 연결수직 조건은 선분의 수직이등분선을 구할 때, 점에서 직선에 내린 수선의 발을 구할 때 쓰입니다. 점과 직선 사이의 거리, 원의 접선(접점에서 반지름과 수직), 대칭이동에서 대칭축을 찾는 일이 모두 이 조건 위에 있습니다.
  5. 적용Q를 (2, 1), (1, 3), (−3, 2)로 옮기며 m₁ × m₂가 늘 −1인지 보세요. Q를 x축 위 (3, 0)으로 옮기면 무엇이 달라지나요? 아래 식에서 aa′ + bb′도 함께 확인하세요.
  6. 판단역수만 취해 1/2로 답하는 실수가 흔합니다. 수직인 직선의 기울기는 역수에 부호까지 바꾼 −1/m₁입니다. 또 m₁m₂ = −1은 두 기울기가 모두 있을 때만 쓸 수 있습니다. x축(기울기 0)과 y축(기울기 없음)도 수직이지만 곱을 만들 수 없습니다. 이럴 때는 aa′ + bb′ = 0으로 확인합니다.
