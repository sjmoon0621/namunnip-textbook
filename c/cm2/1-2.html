두 직선의 평행과 수직

중학교에서 일차함수의 그래프는 기울기와 \(y\)절편으로 정해진다고 배웠습니다. 이 절에서는 두 직선의 기울기를 비교해서 평행한지, 겹치는지, 수직으로 만나는지를 판단합니다. 그리고 \(ax + by + c = 0\) 꼴로 쓴 직선에서도 같은 판단을 할 수 있게 조건을 넓힙니다.

1.2.1

두 직선이 만나지 않으려면 무엇이 같아야 할까?

두 직선의 평행 · 일치 · 교점

—

기울기 비교
—
위치 관계
—
교점
—
  1. 질문두 직선 \(y = 2x + 1\)과 \(y = 2x - 3\)은 아무리 길게 그어도 만나지 않습니다. 두 직선이 만나지 않으려면, 또 완전히 겹치려면 무엇이 같아야 할까요?
  2. 복원직선 \(y = mx + n\)에서 \(m\)은 \(x\)가 1 늘 때 \(y\)가 늘어나는 양(기울기)이고, \(n\)은 \(y\)축과 만나는 점의 \(y\)좌표(\(y\)절편)입니다. 두 직선의 교점은 두 방정식을 연립한 해입니다.
  3. 설명두 직선 \(y = m_1x + n_1, y = m_2x + n_2\)를 연립하면 \((m_1 - m_2)x = n_2 - n_1\)입니다. \(m_1 \ne m_2\)이면 해가 하나라서 한 점에서 만납니다. \(m_1 = m_2\)이면 좌변이 0이 되므로, \(n_1 \ne n_2\)일 때는 해가 없어 평행하고, \(n_1 = n_2\)일 때는 모든 \(x\)가 해여서 일치합니다. 정리하면 평행 \(\Leftrightarrow m_1 = m_2, n_1 \ne n_2\)입니다. 직선을 \(ax + by + c = 0, a'x + b'y + c' = 0\)으로 쓰면 평행 조건은 \(\frac{a}{a'} = \frac{b}{b'} \ne \frac{c}{c'}\), 일치 조건은 \(\frac{a}{a'} = \frac{b}{b'} = \frac{c}{c'}\)입니다.
  4. 연결평행·일치·한 점에서 만남은 연립일차방정식의 해가 없음·무수히 많음·하나인 경우와 정확히 대응합니다. 그래프와 방정식이 같은 사실을 두 가지 말로 하고 있는 것입니다. 기울기의 곱이 \(-1\)이면 두 직선은 수직으로 만나는데, 그 까닭은 다음 카드에서 봅니다.
  5. 적용'평행한 예'를 누른 뒤 \(n_2\)만 바꾸어 보세요. 교점이 생기나요? \(n_2\)를 \(n_1\)과 같게 하면 무엇이 달라지나요? 이번에는 \(m_2\)를 \(m_1\)에 조금씩 가까이 가져가면서 교점이 어디로 달아나는지 보세요.
  6. 판단\(y\)축에 평행한 직선 \(x = k\)는 기울기가 없어서 \(y = mx + n\) 꼴로 쓸 수 없습니다. 그래도 두 직선 \(x = 1\)과 \(x = 3\)은 평행합니다. 일반형 조건을 쓰면 이런 경우도 다룰 수 있습니다. 다만 분모가 0이 되는 계수가 있으면 비의 꼴 대신 \(ab' - a'b = 0\)처럼 곱의 꼴로 확인합니다.

1.2.2

수직인 두 직선의 기울기는 어떤 관계일까?

두 직선의 수직 · 기울기의 곱

—

\(\ell_1\) 기울기 \(m_1\)
—
\(\ell_2\) 기울기 \(m_2\)
—
\(m_1 \times m_2\)
—

점 \(Q\)를 끌어 직선 \(\ell_1\)의 방향을 바꾸세요. \(Q'\)은 \(Q\)를 원점을 중심으로 \(90^\circ\) 돌린 점이고, \(\ell_2\)는 원점과 \(Q'\)을 지납니다.

  1. 질문기울기가 2인 직선에 수직인 직선의 기울기는 얼마일까요? \(-2\)일까요, \(\frac{1}{2}\)일까요, 아니면 다른 수일까요?
  2. 복원기울기는 (세로 변화량)/(가로 변화량)입니다. 직각삼각형을 \(90^\circ\) 돌리면 가로 변과 세로 변이 서로 자리를 바꾼, 합동인 직각삼각형이 됩니다.
  3. 설명원점을 지나는 직선 \(\ell_1\) 위의 점 \(Q(p, q)\)를 원점을 중심으로 \(90^\circ\) 돌리면 \(Q'(-q, p)\)가 됩니다. 그림의 두 직각삼각형은 합동이고, 가로와 세로가 바뀌면서 한쪽 부호가 바뀝니다. 그래서 \(m_1 = \frac{q}{p}, m_2 = \frac{p}{-q}\)이고 \(m_1m_2 = -1\)입니다. 거꾸로 기울기의 곱이 \(-1\)이면 두 직선은 수직입니다. 원점을 지나지 않는 직선도 평행이동하면 기울기가 그대로이므로 같은 조건이 성립합니다. 일반형 \(ax + by + c = 0\)과 \(a'x + b'y + c' = 0\)에서는 수직 \(\Leftrightarrow aa' + bb' = 0\)입니다.
  4. 연결수직 조건은 선분의 수직이등분선을 구할 때, 점에서 직선에 내린 수선의 발을 구할 때 쓰입니다. 점과 직선 사이의 거리, 원의 접선(접점에서 반지름과 수직), 대칭이동에서 대칭축을 찾는 일이 모두 이 조건 위에 있습니다.
  5. 적용\(Q\)를 \((2, 1), (1, 3), (-3, 2)\)로 옮기며 \(m_1 \times m_2\)가 늘 \(-1\)인지 보세요. \(Q\)를 \(x\)축 위 \((3, 0)\)으로 옮기면 무엇이 달라지나요? 아래 식에서 \(aa' + bb'\)도 함께 확인하세요.
  6. 판단역수만 취해 \(\frac{1}{2}\)로 답하는 실수가 흔합니다. 수직인 직선의 기울기는 역수에 부호까지 바꾼 \(-\frac{1}{m_1}\)입니다. 또 \(m_1m_2 = -1\)은 두 기울기가 모두 있을 때만 쓸 수 있습니다. \(x\)축(기울기 0)과 \(y\)축(기울기 없음)도 수직이지만 곱을 만들 수 없습니다. 이럴 때는 \(aa' + bb' = 0\)으로 확인합니다.
