두 직선의 평행과 수직

본문

직선 \(y = 2x + 1\)과 만나지 않는 직선은 어떤 식일까? 또 이 직선과 직각으로 만나는 직선의 기울기는 \(-2\)일까, \(\tfrac{1}{2}\)일까, 아니면 다른 수일까?

먼저 알아야 할 것중학교의 일차함수의 기울기와 \(y\)절편, 연립일차방정식의 해와 그래프의 교점, 두 점 사이의 거리(선분의 내분점).

1.2.1만나지 않는 두 직선

두 직선 \(y = 2x + 1\)과 \(y = 2x - 3\)의 교점을 구하려고 두 식을 같다고 놓으면 \(2x + 1 = 2x - 3\), 곧 \(0 = -4\)가 된다. 이 식을 만족하는 \(x\)는 없으므로 두 직선은 만나지 않는다. 기울기가 같아서 \(x\)가 지워졌기 때문이다.

일반적으로 \(y = m_1x + n_1\)과 \(y = m_2x + n_2\)를 연립하면 \((m_1 - m_2)x = n_2 - n_1\)이다. 그러면 \(m_1 \ne m_2\)이면 해가 하나이므로 한 점에서 만나고, \(m_1 = m_2\)이면서 \(n_1 \ne n_2\)이면 해가 없으므로 평행하며, 둘 다 같으면 모든 \(x\)가 해이므로 일치한다. 즉 처음 질문의 답은 기울기가 2이고 \(y\)절편이 1이 아닌 모든 직선이다.

정리 1.2.1 두 직선의 평행과 일치

두 직선 \(y = m_1x + n_1\), \(y = m_2x + n_2\)가 평행하면 \(m_1 = m_2,\ n_1 \ne n_2\)이고, 일치하면 \(m_1 = m_2,\ n_1 = n_2\)이다. 역도 성립한다.

1.2.2수직인 두 직선

수직 조건은 직선을 돌려서 찾는다. 원점을 지나고 기울기가 2인 직선 위에 점 \(Q(1, 2)\)를 잡자. 원점에서 오른쪽으로 1, 위로 2 가는 직각삼각형이 기울기를 만든다. 이 직각삼각형을 원점을 중심으로 \(90^\circ\) 돌리면, 가로 1이 세로 1로, 세로 2가 왼쪽으로 2 가는 가로로 바뀐다. 따라서 \(Q\)는 \(Q'(-2, 1)\)로 옮겨 간다.

돌린 직선의 기울기는 \(\dfrac{1}{-2} = -\dfrac{1}{2}\)이다. 다시 말해 역수를 취하고 부호를 바꾼 값이고, 두 기울기의 곱은 \(2 \times (-\tfrac{1}{2}) = -1\)이다. 그림 1의 슬라이더로 \(m\)을 바꾸어도 곱은 언제나 \(-1\)이다. 일반적으로 \(Q(p, q)\)가 \(Q'(-q, p)\)로 가므로 \(\dfrac{q}{p} \times \dfrac{p}{-q} = -1\)이기 때문이다.

정리 1.2.2 두 직선의 수직

두 직선 \(y = m_1x + n_1\), \(y = m_2x + n_2\)가 수직이면 \(m_1m_2 = -1\)이고, 역도 성립한다.

원점을 지나지 않는 직선도 평행이동하면 원점을 지나게 할 수 있고, 평행이동은 기울기를 바꾸지 않는다. 그래서 이 정리는 \(y\)절편과 상관없이 성립한다.1

1.2.3일반형으로 쓴 직선

직선은 \(ax + by + c = 0\)꼴로 쓸 때가 많다. \(b \ne 0\)이면 \(y = -\dfrac{a}{b}x - \dfrac{c}{b}\)이므로 기울기는 \(-\dfrac{a}{b}\)이다. 두 직선 \(ax + by + c = 0\), \(a'x + b'y + c' = 0\)이 수직이려면 \(\left(-\dfrac{a}{b}\right)\left(-\dfrac{a'}{b'}\right) = -1\)이어야 하고, 정리하면 \(aa' + bb' = 0\)이다. 이 꼴은 \(b = 0\)인 세로 직선에도 그대로 쓸 수 있다.

1.2.4예제 하나를 끝까지

예제 1.2.3

두 점 \(A(1, 2)\), \(B(5, 4)\)를 잇는 선분의 수직이등분선의 방정식을 구하여라.

수직이등분선은 선분의 중점을 지나고 선분에 수직인 직선이다. 중점은 \(\left(\dfrac{1 + 5}{2}, \dfrac{2 + 4}{2}\right) = (3, 3)\)이다. 직선 \(AB\)의 기울기는 \(\dfrac{4 - 2}{5 - 1} = \dfrac{1}{2}\)이므로, 수직인 직선의 기울기는 곱해서 \(-1\)이 되는 \(-2\)이다.

따라서 수직이등분선은 점 \((3, 3)\)을 지나고 기울기가 \(-2\)인 직선 \(y - 3 = -2(x - 3)\), 곧 \(y = -2x + 9\)이다.

확인해 보자. 이 직선 위의 점 \((4, 1)\)에서 \(A\)까지의 거리는 \(\sqrt{9 + 1} = \sqrt{10}\), \(B\)까지의 거리는 \(\sqrt{1 + 9} = \sqrt{10}\)으로 같다. 수직이등분선 위의 점은 두 끝점에서 같은 거리에 있어야 하므로 답이 맞는다. 아래 탐구 카드에서 기울기와 \(y\)절편을 바꾸며 교점이 생기고 사라지는 모습과, 직선을 돌릴 때 기울기의 곱을 직접 확인해 보자.

  1. \(m_1m_2 = -1\)은 두 기울기가 모두 있을 때만 쓸 수 있다. \(x\)축(기울기 0)과 \(y\)축(기울기가 없음)도 수직이지만 이 식으로는 확인할 수 없고, 일반형의 조건 \(aa' + bb' = 0\)을 쓰면 확인된다.
마무리

두 직선을 연립하면 기울기가 같을 때 \(x\)가 지워져 해가 없거나 무수히 많아지므로, 평행과 일치는 기울기와 \(y\)절편으로 가린다. 직선을 \(90^\circ\) 돌리면 가로와 세로가 바뀌고 부호 하나가 바뀌므로 수직인 두 직선의 기울기의 곱은 \(-1\)이다. 그래서 처음 질문의 직선 \(y = 2x + 1\)에 수직인 직선의 기울기는 \(-\tfrac{1}{2}\)이다.

교점

  1. 질문두 직선 \(y = 2x + 1\)과 \(y = 2x - 3\)은 아무리 길게 그어도 만나지 않는다. 두 직선이 만나지 않으려면, 또 완전히 겹치려면 무엇이 같아야 할까?
  2. 복원직선 \(y = mx + n\)에서 \(m\)은 \(x\)가 1 늘 때 \(y\)가 늘어나는 양(기울기)이고, \(n\)은 \(y\)축과 만나는 점의 \(y\)좌표(\(y\)절편)이다. 또 두 직선의 교점은 두 방정식을 연립한 해이다.
  3. 설명두 직선 \(y = m_1x + n_1, y = m_2x + n_2\)를 연립하면 \((m_1 - m_2)x = n_2 - n_1\)이다. \(m_1 \ne m_2\)이면 해가 하나라서 한 점에서 만난다. 반면 \(m_1 = m_2\)이면 좌변이 0이 되므로, \(n_1 \ne n_2\)일 때는 해가 없어 평행하고, \(n_1 = n_2\)일 때는 모든 \(x\)가 해여서 일치한다. 정리하면 평행 \(\Leftrightarrow m_1 = m_2, n_1 \ne n_2\)이다. 직선을 \(ax + by + c = 0, a'x + b'y + c' = 0\)으로 쓰면 평행 조건은 \(\frac{a}{a'} = \frac{b}{b'} \ne \frac{c}{c'}\), 일치 조건은 \(\frac{a}{a'} = \frac{b}{b'} = \frac{c}{c'}\)이다.
  4. 연결평행, 일치, 한 점에서 만남은 연립일차방정식의 해가 없음, 무수히 많음, 하나인 경우와 정확히 대응한다. 즉 그래프와 방정식이 같은 사실을 두 가지 말로 하고 있다. 기울기의 곱이 \(-1\)이면 두 직선은 수직으로 만나는데, 그 까닭은 다음 카드에서 본다.
  5. 적용'평행한 예'를 누른 뒤 \(n_2\)만 바꾸면 교점이 생기지 않는다. \(n_2\)를 \(n_1\)과 같게 하면 두 직선이 겹친다. 이번에는 \(m_2\)를 \(m_1\)에 조금씩 가까이 가져가면 교점이 그림 밖으로 멀리 달아나는 것을 볼 수 있다.
  6. 판단\(y\)축에 평행한 직선 \(x = k\)는 기울기가 없어서 \(y = mx + n\) 꼴로 쓸 수 없다. 그래도 두 직선 \(x = 1\)과 \(x = 3\)은 평행하고, 일반형 조건을 쓰면 이런 경우도 다룰 수 있다. 다만 분모가 0이 되는 계수가 있으면 비의 꼴 대신 \(ab' - a'b = 0\)처럼 곱의 꼴로 확인한다.

수직인 두 직선의 기울기는 어떤 관계일까?

두 직선의 수직 · 기울기의 곱

—

\(\ell_1\) 기울기 \(m_1\)
—
\(\ell_2\) 기울기 \(m_2\)
—
\(m_1 \times m_2\)
—

점 \(Q\)를 끌어 직선 \(\ell_1\)의 방향을 바꿀 수 있다. \(Q'\)은 \(Q\)를 원점을 중심으로 \(90^\circ\) 돌린 점이고, \(\ell_2\)는 원점과 \(Q'\)을 지난다.

  1. 질문기울기가 2인 직선에 수직인 직선의 기울기는 얼마일까? \(-2\)일까, \(\frac{1}{2}\)일까, 아니면 다른 수일까?
  2. 복원기울기는 (세로 변화량)/(가로 변화량)이다. 또 직각삼각형을 \(90^\circ\) 돌리면 가로 변과 세로 변이 서로 자리를 바꾼, 합동인 직각삼각형이 된다.
  3. 설명원점을 지나는 직선 \(\ell_1\) 위의 점 \(Q(p, q)\)를 원점을 중심으로 \(90^\circ\) 돌리면 \(Q'(-q, p)\)가 된다. 그림의 두 직각삼각형은 합동이고, 가로와 세로가 바뀌면서 한쪽 부호가 바뀐다. 그래서 \(m_1 = \frac{q}{p}, m_2 = \frac{p}{-q}\)이고 \(m_1m_2 = -1\)이다. 거꾸로 기울기의 곱이 \(-1\)이면 두 직선은 수직이다. 원점을 지나지 않는 직선도 평행이동하면 기울기가 그대로이므로 같은 조건이 성립하고, 일반형 \(ax + by + c = 0\)과 \(a'x + b'y + c' = 0\)에서는 수직 \(\Leftrightarrow aa' + bb' = 0\)이다.
  4. 연결수직 조건은 선분의 수직이등분선을 구할 때, 점에서 직선에 내린 수선의 발을 구할 때 쓰인다. 점과 직선 사이의 거리, 접점에서 반지름과 수직인 원의 접선, 대칭이동에서 대칭축을 찾는 일이 모두 이 조건 위에 있다.
  5. 적용\(Q\)를 \((2, 1), (1, 3), (-3, 2)\)로 옮기며 \(m_1 \times m_2\)가 늘 \(-1\)인지 보자. \(Q\)를 \(x\)축 위 \((3, 0)\)으로 옮기면 \(\ell_2\)가 세로선이 되어 기울기를 쓸 수 없지만, 아래 식의 \(aa' + bb'\)는 여전히 0이다.
  6. 판단역수만 취해 \(\frac{1}{2}\)로 답하는 실수가 흔하다. 수직인 직선의 기울기는 역수에 부호까지 바꾼 \(-\frac{1}{m_1}\)이다. 또 \(m_1m_2 = -1\)은 두 기울기가 모두 있을 때만 쓸 수 있다. \(x\)축(기울기 0)과 \(y\)축(기울기 없음)도 수직이지만 곱을 만들 수 없으므로, 이럴 때는 \(aa' + bb' = 0\)으로 확인한다.
