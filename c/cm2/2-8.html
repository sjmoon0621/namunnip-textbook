절대부등식

x2 ≥ x는 x = 1/2에서 깨지지만, x2 + 1 ≥ 2x는 어떤 실수를 넣어도 깨지지 않습니다. 이 절에서는 변수에 어떤 실수를 넣어도 성립하는 부등식을 구별하고, 그 사실을 완전제곱식과 평균의 비교로 증명합니다.

2.8.1

어떤 실수를 넣어도 성립하는 부등식은 어떻게 알아볼까?

절대부등식 · 완전제곱식

—

넣은 값에서
—
(좌변 − 우변)의 최솟값
—
그림 범위의 판정
—

—

  1. 질문x2 ≥ x와 x2 + 1 ≥ 2x는 비슷해 보입니다. 둘 가운데 어느 것이 모든 실수 x에 대하여 성립할까요? 그것을 어떻게 확신할 수 있을까요?
  2. 복원실수의 제곱은 0 이상입니다. '모든 x에 대하여'가 붙은 명제는 반례 하나로 거짓이 됩니다.
  3. 설명문자에 어떤 실수를 대입해도 항상 성립하는 부등식을 절대부등식이라 합니다. 특정한 값에서만 성립하는 부등식과 구별합니다. 절대부등식은 (좌변) − (우변)을 완전제곱식의 합처럼 0 이상임이 분명한 꼴로 바꾸어 증명합니다. 예를 들어 x2 + 1 − 2x = (x − 1)2 ≥ 0입니다. 등호는 x = 1일 때만 성립하므로, 같은 식에 등호를 뺀 x2 + 1 > 2x는 절대부등식이 아닙니다. 절댓값이 있는 부등식은 양변이 0 이상일 때 제곱의 차를 비교합니다.
  4. 연결이차부등식에서 판별식이 음수이면 이차식의 값이 늘 양수라는 사실도 절대부등식입니다. 다음 카드의 산술평균과 기하평균의 관계는 (√a − √b)2 ≥ 0에서 나옵니다.
  5. 적용여섯 부등식을 하나씩 골라 그래프가 0 아래로 내려가는 곳이 있는지 보세요. 반례가 있으면 슬라이더를 그 값에 맞추어 확인하세요. 두 변수 부등식은 b도 여러 값으로 바꾸어 보아야 합니다. 마지막으로 '증명 보기'를 눌러 식으로 확인하세요.
  6. 판단그래프에서 −3부터 3까지 반례가 보이지 않는다고 절대부등식이 증명되지는 않습니다. 그림 밖이나 다른 b에서 깨질 수 있기 때문입니다. 그림은 반례를 찾는 도구이고, 증명은 식으로 합니다. 또 '≥'와 '>'를 구별해야 합니다. 등호가 성립하는 값이 하나라도 있으면 '>'인 부등식은 절대부등식이 아닙니다.

2.8.2

두 양수의 산술평균과 기하평균 가운데 어느 쪽이 클까?

절대부등식 · 산술평균 ≥ 기하평균

—

산술평균 (a + b)/2
—
기하평균 √(ab)
—
차 (√a − √b)²/2
—

지름 위의 점을 끌거나 슬라이더로 a를 바꾸세요. 초록 수선이 기하평균, 주황 반지름이 산술평균입니다.

  1. 질문둘레가 16 cm인 직사각형 가운데 넓이가 가장 큰 것은 무엇일까요? 두 변을 a, b라 하면 a + b = 8일 때 ab가 가장 커지는 경우를 찾는 문제입니다.
  2. 복원지름에 대한 원주각은 직각입니다. 직각삼각형에서 빗변에 내린 수선의 길이 h는 빗변을 나눈 두 길이 a, b와 h2 = ab의 관계가 있습니다.
  3. 설명a > 0, b > 0일 때 (a + b)/2를 산술평균, √(ab)를 기하평균이라 합니다. (a + b)/2 − √(ab) = (√a − √b)2/2 ≥ 0이므로 (a + b)/2 ≥ √(ab)가 항상 성립하고, 등호는 a = b일 때만 성립합니다. 그림에서 반지름은 (a + b)/2이고 수선 CD는 √(ab)입니다. 수선은 반원 안의 현의 절반이므로 반지름보다 길 수 없고, C가 중심에 올 때만 반지름과 같아집니다.
  4. 연결합 a + b가 일정하면 곱 ab는 a = b일 때 최대이고, 곱이 일정하면 합은 a = b일 때 최소입니다. 예를 들어 x > 0이면 x + 1/x ≥ 2√(x · 1/x) = 2입니다.
  5. 적용a + b = 8로 두고 점을 움직여 기하평균이 가장 커지는 곳을 찾으세요. 그때 ab는 얼마인가요? 처음 질문의 답과 비교해 보세요. a가 0에 가까워지면 두 평균의 차는 어떻게 되나요?
  6. 판단이 부등식은 a, b가 양수일 때만 씁니다. x + 1/x ≥ 2는 x = −1에서 깨집니다. 또 최솟값을 구할 때는 등호가 실제로 성립하는 값이 있는지 확인해야 합니다. 등호 조건을 만족하는 값이 없으면 2√(ab)는 최솟값이 아니라 그보다 작은 하한일 뿐입니다.
