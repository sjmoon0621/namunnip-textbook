절대부등식

본문

둘레가 20 cm인 직사각형 가운데 넓이가 가장 큰 것은 정사각형이라고 한다. 이것을 '가로와 세로의 평균은 넓이의 제곱근보다 작지 않다'는 부등식으로 바꾸어 말할 수 있다. 어떤 양수를 넣어도 성립하는 이런 부등식은 어떻게 확인할까?

먼저 알아야 할 것'모든'이 붙은 명제(명제와 조건), 완전제곱식과 실수의 제곱은 0 이상이라는 성질, 절댓값.

2.8.1절대부등식

\(x^2 - 2x + 1 \ge 0\)은 \(x\)에 어떤 실수를 넣어도 성립한다. 좌변이 \((x - 1)^2\)이고 실수의 제곱은 0 이상이기 때문이다. 반면 \(x^2 - 4 > 0\)은 \(x = 3\)에서는 성립하지만 \(x = 1\)에서는 성립하지 않는다.

앞의 것처럼 문자에 어떤 실수를 넣어도 항상 성립하는 부등식을 절대부등식이라 한다. 공통수학1에서 배운 이차부등식의 해가 모든 실수인 경우가 바로 절대부등식이다. 증명할 때는 '양변의 차를 제곱식으로 바꾸어 0 이상임을 보이는' 방법을 가장 많이 쓴다.1

2.8.2산술평균과 기하평균

두 양수 \(a\), \(b\)의 산술평균은 \(\dfrac{a + b}{2}\), 기하평균은 \(\sqrt{ab}\)이다. 두 값의 차를 계산해 보자. \(\dfrac{a + b}{2} - \sqrt{ab} = \dfrac{a - 2\sqrt{ab} + b}{2}\)인데, 분자는 \((\sqrt{a})^2 - 2\sqrt{a}\sqrt{b} + (\sqrt{b})^2 = (\sqrt{a} - \sqrt{b})^2\)이다.

따라서 차는 \(\dfrac{(\sqrt{a} - \sqrt{b})^2}{2} \ge 0\)이고, 산술평균은 기하평균보다 작지 않다. 등호는 \(\sqrt{a} = \sqrt{b}\), 곧 \(a = b\)일 때만 성립한다.

정리 2.8.1 산술평균과 기하평균의 관계

\(a > 0\), \(b > 0\)일 때 \[\frac{a + b}{2} \ge \sqrt{ab}\] 이고, 등호는 \(a = b\)일 때 성립한다.

그림 1은 같은 사실을 원으로 보여 준다. 지름을 \(a\)와 \(b\)로 나누는 점에서 수직으로 세운 선분은, 닮은 직각삼각형 때문에 길이의 제곱이 \(ab\)가 된다. 이 선분은 반원 안에 있으므로 반지름보다 길 수 없고, \(a = b\)일 때 정확히 반지름이 된다. 슬라이더로 \(a\)를 5에 가깝게 옮기면 두 길이가 같아지는 순간이 보인다.

예제 2.8.2

둘레가 20 cm인 직사각형의 넓이의 최댓값을 구하여라. 또 \(x > 0\)일 때 \(x + \dfrac{9}{x}\)의 최솟값과 그때의 \(x\)를 구하여라.

가로를 \(a\), 세로를 \(b\)라 하면 \(a + b = 10\)이다. 산술평균과 기하평균의 관계에서 \(\dfrac{a + b}{2} \ge \sqrt{ab}\)이므로 \(5 \ge \sqrt{ab}\), 곧 \(ab \le 25\)이다. 등호는 \(a = b = 5\)일 때 성립하므로 넓이의 최댓값은 25 \(\text{cm}^2\)이다.

두 번째 식은 \(x\)와 \(\dfrac{9}{x}\)가 모두 양수이므로 같은 관계를 쓸 수 있다. \(x + \dfrac{9}{x} \ge 2\sqrt{x \cdot \dfrac{9}{x}} = 2\sqrt{9} = 6\)이다. 곱이 상수 9가 되도록 짝지은 것이 요령이다.

등호는 \(x = \dfrac{9}{x}\), 곧 \(x^2 = 9\)에서 \(x = 3\)일 때 성립한다. 따라서 최솟값은 6이다. 확인해 보면 \(x = 3\)에서 \(3 + 3 = 6\)이고, \(x = 2\)에서 \(2 + 4.5 = 6.5\), \(x = 4\)에서 \(4 + 2.25 = 6.25\)로 모두 6보다 크다. 아래 탐구 카드에서 그래프로 두 평균을 비교하며 등호가 성립하는 순간을 직접 찾아보자.

  1. 양변이 모두 0 이상이면 제곱해서 비교해도 된다. 가령 \(|a| + |b| \ge |a + b|\)는 양변을 제곱한 차가 \(2(|ab| - ab) \ge 0\)이므로 성립하고, 등호는 \(ab \ge 0\)일 때이다.
마무리

절대부등식은 양변의 차를 제곱식으로 바꾸어 0 이상임을 보이면 증명된다. 이 방법으로 두 양수의 산술평균이 기하평균보다 작지 않다는 것을 얻고, 등호는 두 수가 같을 때만 성립한다. 그래서 처음 질문에서 둘레가 20 cm인 직사각형의 넓이는 가로와 세로가 모두 5 cm인 정사각형일 때 25 \(\text{cm}^2\)로 가장 크다.

  1. 질문\(x^2 \ge x\)와 \(x^2 + 1 \ge 2x\)는 비슷해 보인다. 둘 가운데 어느 것이 모든 실수 \(x\)에 대하여 성립할까? 그것을 어떻게 확신할 수 있을까?
  2. 복원실수의 제곱은 0 이상이다. 또 '모든 \(x\)에 대하여'가 붙은 명제는 반례 하나로 거짓이 된다.
  3. 설명문자에 어떤 실수를 대입해도 항상 성립하는 부등식을 절대부등식이라 하여, 특정한 값에서만 성립하는 부등식과 구별한다. 절대부등식은 (좌변) \(-\) (우변)을 완전제곱식의 합처럼 0 이상임이 분명한 꼴로 바꾸어 증명한다. 예를 들어 \(x^2 + 1 - 2x = (x - 1)^2 \ge 0\)이다. 그런데 등호는 \(x = 1\)일 때만 성립하므로, 같은 식에 등호를 뺀 \(x^2 + 1 > 2x\)는 절대부등식이 아니다. 반면 \(x^2 \ge x\)는 \(x = \frac{1}{2}\)에서 깨진다. 절댓값이 있는 부등식은 양변이 0 이상일 때 제곱의 차를 비교한다.
  4. 연결이차부등식에서 판별식이 음수이면 이차식의 값이 늘 양수라는 사실도 절대부등식이다. 또 다음 카드의 산술평균과 기하평균의 관계는 \((\sqrt{a} - \sqrt{b})^2 \ge 0\)에서 나온다.
  5. 적용여섯 부등식을 하나씩 골라 그래프가 0 아래로 내려가는 곳이 있는지 보자. 반례가 있으면 슬라이더를 그 값에 맞추어 확인하고, 두 변수 부등식에서는 \(b\)도 여러 값으로 바꾸어 보아야 한다. 마지막으로 '증명 보기'를 눌러 식으로 확인하자.
  6. 판단그래프에서 \(-3\)부터 3까지 반례가 보이지 않는다고 절대부등식이 증명되지는 않는다. 그림 밖이나 다른 \(b\)에서 깨질 수 있기 때문이다. 그래서 그림은 반례를 찾는 도구로 쓰고, 증명은 식으로 한다. 또 '\(\ge\)'와 '\(>\)'를 구별해야 한다. 등호가 성립하는 값이 하나라도 있으면 '\(>\)'인 부등식은 절대부등식이 아니다.

두 양수의 산술평균과 기하평균 가운데 어느 쪽이 클까?

절대부등식 · 산술평균 \(\ge\) 기하평균

—

산술평균 \(\frac{a + b}{2}\)
—
기하평균 \(\sqrt{ab}\)
—
차 \(\frac{(\sqrt{a} - \sqrt{b})^2}{2}\)
—

지름 위의 점을 끌거나 슬라이더로 \(a\)를 바꿀 수 있다. 초록 수선이 기하평균, 주황 반지름이 산술평균이다.

  1. 질문둘레가 16 cm인 직사각형 가운데 넓이가 가장 큰 것은 무엇일까? 두 변을 \(a, b\)라 하면 \(a + b = 8\)일 때 \(ab\)가 가장 커지는 경우를 찾는 문제이다.
  2. 복원지름에 대한 원주각은 직각이다. 그래서 직각삼각형에서 빗변에 내린 수선의 길이 \(h\)는 빗변을 나눈 두 길이 \(a, b\)와 \(h^2 = ab\)의 관계가 있다.
  3. 설명\(a > 0, b > 0\)일 때 \(\frac{a + b}{2}\)를 산술평균, \(\sqrt{ab}\)를 기하평균이라 한다. \(\frac{a + b}{2} - \sqrt{ab} = \frac{(\sqrt{a} - \sqrt{b})^2}{2} \ge 0\)이므로 \(\frac{a + b}{2} \ge \sqrt{ab}\)가 항상 성립하고, 등호는 \(a = b\)일 때만 성립한다. 그림으로 보면 반지름이 \(\frac{a + b}{2}\)이고 수선 \(CD\)가 \(\sqrt{ab}\)이다. 수선은 반원 안의 현의 절반이므로 반지름보다 길 수 없고, \(C\)가 중심에 올 때만 반지름과 같아진다.
  4. 연결그래서 합 \(a + b\)가 일정하면 곱 \(ab\)는 \(a = b\)일 때 최대이고, 곱이 일정하면 합은 \(a = b\)일 때 최소이다. 예를 들어 \(x > 0\)이면 \(x + \frac{1}{x} \ge 2\sqrt{x \cdot \frac{1}{x}} = 2\)이다.
  5. 적용\(a + b = 8\)로 두고 점을 움직이면 기하평균은 \(a = 4\)에서 가장 커지고, 그때 \(ab = 16\)이다. 처음 질문의 답이 한 변 4 cm인 정사각형이라는 것과 같다. \(a\)를 0에 가깝게 하면 두 평균의 차가 점점 커지는 것도 확인해 보자.
  6. 판단이 부등식은 \(a, b\)가 양수일 때만 쓴다. 예를 들어 \(x + \frac{1}{x} \ge 2\)는 \(x = -1\)에서 깨진다. 또 최솟값을 구할 때는 등호가 실제로 성립하는 값이 있는지 확인해야 한다. 등호 조건을 만족하는 값이 없으면 \(2\sqrt{ab}\)는 최솟값이 아니라 그보다 작은 하한일 뿐이다.
