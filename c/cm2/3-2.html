합성함수

하나의 함수에서 나온 값을 다른 함수에 다시 넣으면 새로운 함수가 생깁니다. 이 절에서는 화살표 그림으로 두 함수를 이어 붙이는 과정을 따라가며 합성함수의 뜻을 익히고, 순서를 바꾸면 결과가 달라지는지 확인합니다. 이어서 일차함수와 이차함수를 합성해 식과 값을 구하고, 그래프 위에서도 그 값을 찾아봅니다.

3.2.1

두 함수를 이어 붙이면 무엇이 될까?

순서
\(f\) 바꾸기
\(g\) 바꾸기

—

값

합성함수의 치역
—
\(g\circ f\)와 \(f\circ g\)
—

왼쪽 \(X\)의 원소를 누르면 그 원소가 지나가는 길이 노란 화살표로 보입니다. 값 단추를 누를 때마다 그 값이 \(1 \to 2 \to 3 \to 1\) 순서로 바뀝니다.

  1. 질문원화를 달러로 바꾸는 함수와 달러를 엔으로 바꾸는 함수가 있습니다. 두 번 바꾸는 과정을 하나의 함수로 볼 수 있을까요? 바꾸는 순서를 뒤집어도 같은 결과일까요?
  2. 복원함수 \(f : X \to Y\)는 \(X\)의 각 원소에 \(Y\)의 원소를 하나씩 대응시킵니다. 함숫값 \(f(x)\)는 다시 다른 함수에 넣을 수 있는 하나의 원소입니다.
  3. 설명두 함수 \(f : X \to Y, g : Y \to Z\)가 있으면 \(X\)의 원소 \(x\)를 먼저 \(f\)로 보내고, 그 결과 \(f(x)\)를 다시 \(g\)로 보내 \(Z\)의 원소 \(g(f(x))\)를 얻습니다. 이렇게 만든 \(X\)에서 \(Z\)로의 함수를 \(f\)와 \(g\)의 합성함수라 하고 \(g\circ f\)로 나타냅니다. 곧 \((g\circ f)(x) = g(f(x))\)입니다. 기호에서는 \(g\)가 앞에 쓰여 있지만 먼저 작용하는 것은 오른쪽의 \(f\)입니다. 합성이 되려면 \(f\)의 치역이 \(g\)의 정의역에 들어 있어야 합니다.
  4. 연결합성함수는 결합법칙 \(h\circ(g\circ f) = (h\circ g)\circ f\)를 만족합니다. 어느 쪽이든 \(f, g, h\) 순서로 작용하기 때문입니다. 또 항등함수 \(I\)와는 \(f\circ I = I\circ f = f\)입니다. 다음 절의 역함수는 \(f\)와 합성해서 항등함수가 되는 함수입니다.
  5. 적용처음 상태에서 \(X\)의 2를 눌러 \((g\circ f)(2)\)를 읽은 뒤, 순서를 바꿔 \((f\circ g)(2)\)와 비교하세요. \(g\)를 항등함수로 바꾸면 \(g\circ f\)와 \(f\circ g\)가 같아지나요? \(f\)의 값을 바꾸어 \(g\circ f\)와 \(f\circ g\)가 같아지는 다른 경우도 찾아보세요.
  6. 판단일반적으로 \(g\circ f \ne f\circ g\)입니다. 곧 합성에는 교환법칙이 성립하지 않습니다. 같아지는 경우가 있더라도 그것은 특별한 경우입니다. 또 \((g\circ f)(x)\)를 \(g(x) \times f(x)\)로 읽는 실수가 흔합니다. \(\circ\)는 곱셈이 아니라 "넣은 결과를 다시 넣는다"는 뜻입니다.

━ \(y = f(x)\)━ \(y = g(x)\)━ 합성함수┅ \(y = x\)

\(x\)축 위의 점 \(x_0\)을 끌어 보세요. 점선 화살표는 첫 함수의 그래프로 올라간 뒤, 직선 \(y = x\)에서 그 값을 다시 \(x\)좌표로 옮겨 두 번째 함수로 가는 길입니다.

  1. 질문\(f(x) = x - 1, g(x) = x^2 - 2\)일 때 \((g\circ f)(x)\)를 하나의 식으로 쓸 수 있을까요? 그래프만 보고 \((g\circ f)(2)\)를 찾을 수도 있을까요?
  2. 복원\((g\circ f)(x) = g(f(x))\)이고, 먼저 작용하는 것은 \(f\)입니다. 함수 \(y = f(x)\)의 그래프에서 \(x = a\)일 때의 높이가 \(f(a)\)입니다.
  3. 설명식으로 구할 때는 \(g(x)\)의 \(x\) 자리에 \(f(x)\)를 통째로 넣습니다. \(g(f(x)) = (x - 1)^2 - 2 = x^2 - 2x - 1\)입니다. 반대로 \((f\circ g)(x) = f(x^2 - 2) = x^2 - 3\)입니다. 일반적으로 \(f(x) = ax + b, g(x) = x^2 + c\)이면 \((g\circ f)(x) = a^2x^2 + 2abx + b^2 + c, (f\circ g)(x) = ax^2 + ac + b\)입니다. 그래프로 구할 때는 \(x_0\)에서 \(f\)의 그래프로 올라가 높이 \(f(x_0)\)를 얻고, 직선 \(y = x\)를 거쳐 그 높이를 \(x\)좌표로 옮긴 다음 \(g\)의 그래프로 가면 높이가 \(g(f(x_0))\)입니다.
  4. 연결값 하나만 필요하면 식 전체를 구하지 않고 안쪽부터 차례로 계산하는 편이 빠릅니다. 함수를 여러 번 거듭하는 계산\((f\circ f\circ f\cdots)\)이나 수열의 점화식도 같은 원리이고, 미적분에서는 합성함수의 미분으로 이어집니다.
  5. 적용처음 상태에서 \(x_0 = 2\)로 놓고 '먼저'와 '다음'의 값을 읽으세요. 식 \(x^2 - 2x - 1\)에 2를 넣은 값과 같나요? 순서를 \(f\circ g\)로 바꾸면 경로와 값이 어떻게 달라지나요? \(a = 1, b = 0\)으로 놓아 \(f\)를 항등함수로 만들면 두 합성함수가 어떻게 되나요?
  6. 판단합성함수의 식을 구할 때 \(g(x) = x^2 + c\)의 \(x\)에 \(f(x)\)를 넣으면서 괄호를 빠뜨리면 \(x - 1^2 - 2\)처럼 전혀 다른 식이 됩니다. 넣는 식은 반드시 괄호로 감쌉니다. 또 합성하려면 안쪽 함수의 값이 바깥 함수의 정의역에 들어가야 합니다. 바깥 함수가 \(\sqrt{x}\)처럼 정의역이 제한되면 이 조건을 따로 확인해야 합니다.
