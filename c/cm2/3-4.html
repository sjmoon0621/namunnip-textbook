3.4.1유리식과 유리함수

두 다항식 \(A\), \(B\ (B \ne 0)\)로 \(\dfrac{A}{B}\)꼴로 나타낸 식을 유리식이라 한다. \(y = f(x)\)에서 \(f(x)\)가 \(x\)에 대한 유리식이면 이 함수를 유리함수라 하고, 특히 \(f(x)\)가 다항식이면 다항함수라 한다. 정의역을 따로 말하지 않으면 분모가 0이 되지 않는 실수 전체를 정의역으로 본다.

가장 단순한 유리함수는 반비례 \(y = \dfrac{k}{x}\)이다. \(x\)가 커질수록 \(y\)는 0에 가까워지고, \(x\)가 0에 가까워질수록 \(|y|\)는 한없이 커진다. 그래서 그래프는 \(x\)축과 \(y\)축에 한없이 가까워지지만 닿지 않는다. 이렇게 그래프가 한없이 가까워지는 직선을 점근선이라 한다.

3.4.2평행이동으로 보기

\(y = \dfrac{k}{x}\)를 \(x\)축 방향으로 \(p\), \(y\)축 방향으로 \(q\)만큼 평행이동하면 \(y - q = \dfrac{k}{x - p}\), 곧 \(y = \dfrac{k}{x - p} + q\)이다. 모양은 그대로이고, 점근선도 함께 옮겨 가서 \(x = p\)와 \(y = q\)가 된다.

정리 3.4.1 \(y = \tfrac{k}{x - p} + q\)의 그래프

\(y = \dfrac{k}{x - p} + q\ (k \ne 0)\)의 그래프는 \(y = \dfrac{k}{x}\)의 그래프를 \(x\)축 방향으로 \(p\)만큼, \(y\)축 방향으로 \(q\)만큼 평행이동한 것이다. 정의역은 \(\{x \mid x \ne p\}\), 치역은 \(\{y \mid y \ne q\}\)이고, 점근선은 \(x = p\), \(y = q\)이다. 그래프는 점 \((p, q)\)에 대하여 대칭이다.

그림 1의 슬라이더로 \(p\)와 \(q\)를 바꾸면 두 점근선이 만나는 점 \((p, q)\)를 중심으로 그래프 전체가 움직인다. \(k\)의 부호를 바꾸면 그래프가 놓이는 사분면이 바뀌고, \(|k|\)가 커지면 그래프가 중심에서 멀어진다.

3.4.3\(\dfrac{ax + b}{cx + d}\)꼴은 나눗셈으로

처음 질문의 \(y = \dfrac{2x + 1}{x - 1}\)은 정리의 꼴이 아니다. 그런데 분자를 분모로 나누면 \(2x + 1 = 2(x - 1) + 3\)이므로 \(y = 2 + \dfrac{3}{x - 1}\)이다. 즉 \(k = 3\), \(p = 1\), \(q = 2\)인 경우이고, 그림 1의 처음 모습이 바로 이 그래프이다.

일반적으로 \(y = \dfrac{ax + b}{cx + d}\ (c \ne 0)\)의 점근선은 분모가 0이 되는 \(x = -\dfrac{d}{c}\)와, \(x\)가 커질 때 다가가는 값 \(y = \dfrac{a}{c}\)이다.1

함수 \(y = \dfrac{-x + 5}{x - 2}\)의 점근선과 정의역, 치역을 구하고, \(3 \le x \le 6\)에서의 최댓값과 최솟값을 구하여라.

분자를 분모로 나누면 \(-x + 5 = -(x - 2) + 3\)이므로 \(y = \dfrac{3}{x - 2} - 1\)이다. 따라서 점근선은 \(x = 2\), \(y = -1\)이고, 정의역은 \(\{x \mid x \ne 2\}\), 치역은 \(\{y \mid y \ne -1\}\)이다.

\(k = 3 > 0\)이므로 \(x > 2\)인 부분에서 그래프는 \(x\)가 커질수록 내려간다. 범위 \(3 \le x \le 6\)은 이 부분 안에 있으므로, 최댓값은 왼쪽 끝 \(x = 3\)에서 \(\dfrac{3}{1} - 1 = 2\)이고, 최솟값은 오른쪽 끝 \(x = 6\)에서 \(\dfrac{3}{4} - 1 = -\dfrac{1}{4}\)이다.

원래 식에 넣어 확인하면 \(x = 3\)에서 \(\dfrac{2}{1} = 2\), \(x = 6\)에서 \(\dfrac{-1}{4}\)로 같다. 범위가 점근선 \(x = 2\)를 가로질렀다면 그래프가 끊기므로 이렇게 끝점만 보아서는 안 된다. 아래 탐구 카드에서 \(p\), \(q\), \(k\)를 바꾸며 그래프와 점근선이 함께 움직이는 모습을 확인해 보자.

  1. \(ad - bc = 0\)이면 분자가 분모의 상수배가 되어 \(y = \tfrac{a}{c}\ (x \ne -\tfrac{d}{c})\)인 직선의 일부가 된다. 가령 \(y = \tfrac{2x + 2}{x + 1}\)은 \(x \ne -1\)에서 \(y = 2\)이다.

탐구 1

\(y = \frac{k}{x - p} + q\)의 그래프는 어떻게 생겼을까?

유리함수 · 점근선 · 평행이동

—

점근선
—
대칭의 중심
—
그래프가 놓인 쪽
—

점선 곡선은 \(y = \frac{k}{x}\), 빨간 점선은 점근선이다. 노란 손잡이를 끌면 대칭의 중심에 대하여 대칭인 점이 함께 움직인다. \(k = 0\)이면 유리함수가 아닌 상수함수가 된다.

  1. 질문넓이가 2인 직사각형의 가로를 \(x\), 세로를 \(y\)라 하면 \(y = \frac{2}{x}\)이다. 가로가 0에 가까워지거나 아주 커지면 그래프는 어떻게 될까? 이 그래프를 옮기면 식은 어떻게 바뀔까?
  2. 복원두 다항식 \(A, B(B \ne 0)\)에 대하여 \(\frac{A}{B}\) 꼴의 식을 유리식이라 하고, \(B\)가 상수이면 다항식이다. 또 그래프 \(y = f(x)\)를 \(x\)축 방향으로 \(p, y\)축 방향으로 \(q\)만큼 평행이동하면 \(y - q = f(x - p)\)가 된다.
  3. 설명\(y = f(x)\)에서 \(f(x)\)가 \(x\)에 대한 유리식일 때 유리함수라 하고, 다항식이면 다항함수라 한다. 따로 말이 없으면 유리함수의 정의역은 분모를 0으로 만들지 않는 실수 전체이다. 그런데 \(y = \frac{k}{x}(k \ne 0)\)의 그래프는 \(x = 0\)에서 끊기고, \(|x|\)가 커질수록 \(x\)축에, \(x\)가 0에 가까워질수록 \(y\)축에 한없이 가까워진다. 이렇게 곡선이 한없이 가까워지는 직선을 점근선이라 한다. 이 그래프를 평행이동한 \(y = \frac{k}{x - p} + q\)는 점근선이 \(x = p, y = q\)이고, 정의역은 \(\{x \mid x \ne p\}\), 치역은 \(\{y \mid y \ne q\}\)이며, 두 점근선의 교점 \((p, q)\)에 대하여 대칭이다.
  4. 연결\(k > 0\)이면 그래프는 점근선이 나눈 네 영역 가운데 오른쪽 위와 왼쪽 아래에, \(k < 0\)이면 왼쪽 위와 오른쪽 아래에 놓인다. 또 \(|k|\)가 클수록 곡선은 점근선의 교점에서 멀어진다. 온도가 일정한 기체의 압력과 부피, 일정한 거리를 가는 속력과 걸린 시간처럼 반비례하는 양이 모두 이 꼴이다.
  5. 적용\(p\)와 \(q\)만 움직여 곡선의 모양은 그대로이고 점근선만 따라 움직이는 것을 확인해 보자. \(k\)의 부호를 바꾸면 그래프가 반대쪽 두 영역으로 옮겨 간다. 노란 점을 끌어 짝이 되는 점이 늘 \((p, q)\)에 대하여 대칭인지도 보고, \(k = 2\)일 때 그래프가 제3사분면을 지나지 않도록 \(p, q\)를 정해 보자.
  6. 판단점근선은 그래프의 일부가 아니어서, 그래프는 점근선 \(x = p, y = q\)와 만나지 않는다. 또 "\(x\)가 커지면 \(y\)가 줄어든다"는 말은 구간마다 따로 해야 한다. \(k > 0\)일 때 \(x < p\)와 \(x > p\)에서 각각 감소하지만, \(x = p\)를 건너가면 값이 아래에서 위로 뛰므로 정의역 전체에서 감소하는 것은 아니다.

탐구 2

\(y = \frac{ax + b}{cx + d}\)의 점근선은 어떻게 찾을까?

유리함수 · 표준형으로 고치기

—

종류
—
점근선
—
대칭의 중심
—

'다음 단계'를 눌러 식을 \(y = \frac{k}{x - p} + q\) 꼴로 고치면 점근선이 나타난다. 계수를 바꾼 뒤 처음부터 다시 따라가 볼 수 있다.

  1. 질문\(y = \frac{2x + 1}{x - 1}\)의 그래프를 그리려고 한다. 그런데 이 식만 보고는 점근선이 바로 보이지 않는다. 이미 아는 꼴로 바꿀 수 있을까?
  2. 복원\(y = \frac{k}{x - p} + q(k \ne 0)\)의 그래프는 \(y = \frac{k}{x}\)를 평행이동한 것으로, 점근선은 \(x = p, y = q\)이다. 또 다항식의 나눗셈 \(A = BQ + R\)에서 양변을 \(B\)로 나누면 \(\frac{A}{B} = Q + \frac{R}{B}\)이다.
  3. 설명그래서 분자를 분모로 나누어 몫과 나머지로 쓴다. 예를 들어 \(2x + 1 = 2(x - 1) + 3\)이므로 \(\frac{2x + 1}{x - 1} = 2 + \frac{3}{x - 1}\)이고, 점근선은 \(x = 1, y = 2\)이다. 일반적으로 \(c \ne 0\)이면 세로 점근선은 분모가 0이 되는 \(x = -\frac{d}{c}\)이고, 가로 점근선은 \(x\)의 계수의 비 \(y = \frac{a}{c}\)이다. 이때 \(k = \frac{bc - ad}{c^2}\)이므로, \(bc - ad = 0\)이면 분자가 분모의 상수배라 \(y\)는 상수 \(\frac{a}{c}\)가 된다. 이 경우 그래프는 직선에서 \(x = -\frac{d}{c}\)인 한 점이 빠진 모양이다.
  4. 연결이 방법은 다항식의 나눗셈 그대로이다. \(c = 0\)이면 분모가 상수라 다항함수(일차함수)가 된다. 유리식의 덧셈, 뺄셈과 약분도 같은 도구로 다룬다.
  5. 적용처음 식에서 단계를 끝까지 넘겨 점근선 \(x = 1, y = 2\)를 확인해 보자. \(a\)만 바꾸면 가로 점근선이, \(d\)만 바꾸면 세로 점근선이 움직인다. \(a = 2, c = 1, d = -1\)일 때 \(b = -2\)로 두면 그래프가 직선으로 바뀌는데, 그때 빠지는 점의 좌표도 읽어 보자.
  6. 판단가로 점근선을 "상수항의 비 \(\frac{b}{d}\)"로 잡는 실수가 흔하다. \(\frac{b}{d}\)는 \(x = 0\)일 때의 값, 곧 \(y\)절편이다. \(|x|\)가 아주 커지면 상수항은 무시되고 \(\frac{ax}{cx} = \frac{a}{c}\)에 가까워진다. 또 약분해서 상수가 되더라도 원래 식의 분모를 0으로 만드는 \(x\)는 정의역에서 빠진다.
