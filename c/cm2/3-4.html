유리함수

반비례 관계 \(y = \frac{k}{x}\)는 중학교에서 그려 보았습니다. 이 절에서는 분모에 \(x\)가 들어 있는 식, 곧 유리식으로 정해지는 함수를 다룹니다. 그래프가 한없이 가까워지는 직선인 점근선을 찾고, 평행이동과 식 고치기로 어떤 유리함수의 그래프든 \(y = \frac{k}{x}\)에서 출발해 그려 봅니다.

먼저 알면 좋은 것 반비례 관계다항식의 나눗셈그래프의 평행이동정의역과 치역

3.4.1

\(y = \frac{k}{x - p} + q\)의 그래프는 어떻게 생겼을까?

유리함수 · 점근선 · 평행이동

—

점근선
—
대칭의 중심
—
그래프가 놓인 쪽
—

점선 곡선은 \(y = \frac{k}{x}\), 빨간 점선은 점근선입니다. 노란 손잡이를 끌면 대칭의 중심에 대하여 대칭인 점이 함께 움직입니다. \(k = 0\)이면 유리함수가 아닌 상수함수가 됩니다.

  1. 질문넓이가 2인 직사각형의 가로를 \(x\), 세로를 \(y\)라 하면 \(y = \frac{2}{x}\)입니다. 가로가 0에 가까워지거나 아주 커지면 그래프는 어떻게 될까요? 이 그래프를 옮기면 식은 어떻게 바뀔까요?
  2. 복원두 다항식 \(A, B(B \ne 0)\)에 대하여 \(\frac{A}{B}\) 꼴의 식을 유리식이라 합니다. \(B\)가 상수이면 다항식입니다. 그래프 \(y = f(x)\)를 \(x\)축 방향으로 \(p, y\)축 방향으로 \(q\)만큼 평행이동하면 \(y - q = f(x - p)\)가 됩니다.
  3. 설명\(y = f(x)\)에서 \(f(x)\)가 \(x\)에 대한 유리식일 때 유리함수라 하고, 다항식이면 다항함수라 합니다. 따로 말이 없으면 유리함수의 정의역은 분모를 0으로 만들지 않는 실수 전체입니다. \(y = \frac{k}{x}(k \ne 0)\)의 그래프는 \(x = 0\)에서 끊기고, \(|x|\)가 커질수록 \(x\)축에, \(x\)가 0에 가까워질수록 \(y\)축에 한없이 가까워집니다. 이렇게 곡선이 한없이 가까워지는 직선을 점근선이라 합니다. 이 그래프를 평행이동한 \(y = \frac{k}{x - p} + q\)는 점근선이 \(x = p, y = q\)이고, 정의역은 \(\{x \mid x \ne p\}\), 치역은 \(\{y \mid y \ne q\}\)이며, 두 점근선의 교점 \((p, q)\)에 대하여 대칭입니다.
  4. 연결\(k > 0\)이면 그래프는 점근선이 나눈 네 영역 가운데 오른쪽 위와 왼쪽 아래에, \(k < 0\)이면 왼쪽 위와 오른쪽 아래에 놓입니다. \(|k|\)가 클수록 곡선은 점근선의 교점에서 멀어집니다. 부피가 일정한 기체의 압력과 부피, 일정한 거리를 가는 속력과 걸린 시간처럼 반비례하는 양이 모두 이 꼴입니다.
  5. 적용\(p\)와 \(q\)만 움직여 곡선의 모양은 그대로이고 점근선만 따라 움직이는 것을 확인하세요. \(k\)의 부호를 바꾸면 그래프가 어느 영역으로 옮겨 가나요? 노란 점을 끌어 짝이 되는 점이 늘 \((p, q)\)에 대하여 대칭인지 보세요. 그래프가 제3사분면을 지나지 않게 하려면 \(k = 2\)일 때 \(p, q\)를 어떻게 정해야 하나요?
  6. 판단점근선은 그래프의 일부가 아닙니다. 그래프는 점근선 \(x = p, y = q\)와 만나지 않습니다. 또 "\(x\)가 커지면 \(y\)가 줄어든다"는 말은 구간마다 따로 해야 합니다. \(k > 0\)일 때 \(x < p\)와 \(x > p\)에서 각각 감소하지만, 정의역 전체에서 감소하는 것은 아닙니다. \(x = p\)를 건너가면 값이 아래에서 위로 뛰기 때문입니다.

3.4.2

\(y = \frac{ax + b}{cx + d}\)의 점근선은 어떻게 찾을까?

유리함수 · 표준형으로 고치기

—

종류
—
점근선
—
대칭의 중심
—

'다음 단계'를 눌러 식을 \(y = \frac{k}{x - p} + q\) 꼴로 고치면 점근선이 나타납니다. 계수를 바꾼 뒤 처음부터 다시 따라가 보세요.

  1. 질문\(y = \frac{2x + 1}{x - 1}\)의 그래프를 그리려고 합니다. 이 식만 보고는 점근선이 바로 보이지 않습니다. 이미 아는 꼴로 바꿀 수 있을까요?
  2. 복원\(y = \frac{k}{x - p} + q(k \ne 0)\)의 그래프는 \(y = \frac{k}{x}\)를 평행이동한 것으로, 점근선은 \(x = p, y = q\)입니다. 다항식의 나눗셈 \(A = BQ + R\)에서 양변을 \(B\)로 나누면 \(\frac{A}{B} = Q + \frac{R}{B}\)입니다.
  3. 설명분자를 분모로 나누어 몫과 나머지로 씁니다. 예를 들어 \(2x + 1 = 2(x - 1) + 3\)이므로 \(\frac{2x + 1}{x - 1} = 2 + \frac{3}{x - 1}\)입니다. 그래서 점근선은 \(x = 1, y = 2\)입니다. 일반적으로 \(c \ne 0\)이면 세로 점근선은 분모가 0이 되는 \(x = -\frac{d}{c}\), 가로 점근선은 \(x\)의 계수의 비 \(y = \frac{a}{c}\)입니다. 이때 \(k = \frac{bc - ad}{c^2}\)이므로, \(bc - ad = 0\)이면 분자가 분모의 상수배라 \(y\)는 상수 \(\frac{a}{c}\)가 됩니다. 이 경우 그래프는 직선에서 \(x = -\frac{d}{c}\)인 한 점이 빠진 모양입니다.
  4. 연결이 방법은 다항식의 나눗셈 그대로입니다. \(c = 0\)이면 분모가 상수라 다항함수(일차함수)가 됩니다. 유리식의 덧셈·뺄셈과 약분도 같은 도구로 다룹니다.
  5. 적용처음 식에서 단계를 끝까지 넘겨 점근선 \(x = 1, y = 2\)를 확인하세요. \(a\)만 바꾸면 어느 점근선이 움직이나요? \(d\)만 바꾸면요? \(a = 2, c = 1, d = -1\)일 때 그래프가 직선으로 바뀌는 \(b\)를 찾고, 그때 빠지는 점의 좌표를 읽어 보세요.
  6. 판단가로 점근선을 "상수항의 비 \(\frac{b}{d}\)"로 잡는 실수가 흔합니다. \(\frac{b}{d}\)는 \(x = 0\)일 때의 값, 곧 \(y\)절편입니다. \(|x|\)가 아주 커지면 상수항은 무시되고 \(\frac{ax}{cx} = \frac{a}{c}\)에 가까워집니다. 또 약분해서 상수가 되더라도 원래 식의 분모를 0으로 만드는 \(x\)는 정의역에서 빠집니다.
