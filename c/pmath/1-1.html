음악실의 소리굽쇠 두 개를 함께 두드렸다. 하나는 440 Hz, 다른 하나는 444 Hz로 거의 같은 높이인데, 둘을 함께 울리니 소리가 커졌다 작아지기를 1초에 네 번씩 되풀이했다. 두 소리는 각각 \(\sin(2\pi\cdot440t)\)와 \(\sin(2\pi\cdot444t)\)로 나타낼 수 있고, 함께 울린 소리는 두 식의 합이다. 사인 두 개를 더한 식에서 1초에 네 번이라는 박자가 어떻게 나올까? 그리고 그런 식을 바꾸는 공식은 어디서 나올까?

먼저 알아야 할 것삼각함수의 뜻, 삼각함수의 덧셈정리, \(\sin^2\theta + \cos^2\theta = 1\), 두 점 사이의 거리.

1.1.1공식 하나를 증명해 두면

단위원 위의 두 점 \(P(\cos\alpha, \sin\alpha)\), \(Q(\cos\beta, \sin\beta)\) 사이의 거리를 두 가지로 구해 보자. 두 점 사이의 거리 공식으로 계산하면 \(PQ^2 = (\cos\alpha - \cos\beta)^2 + (\sin\alpha - \sin\beta)^2 = 2 - 2(\cos\alpha\cos\beta + \sin\alpha\sin\beta)\)이다. 한편 두 점을 함께 \(\beta\)만큼 돌리면 \(Q\)는 \((1, 0)\)으로, \(P\)는 \((\cos(\alpha - \beta), \sin(\alpha - \beta))\)로 가고 거리는 그대로이다. 이 거리의 제곱은 \(2 - 2\cos(\alpha - \beta)\)이므로, 두 식을 같다고 놓으면 코사인의 덧셈정리가 나온다.

정리 1.1.1 덧셈정리에서 나오는 공식

\(\cos(\alpha - \beta) = \cos\alpha\cos\beta + \sin\alpha\sin\beta\)에서 \(\beta\) 대신 \(-\beta\), \(\tfrac{\pi}{2} - \alpha\)를 넣으면 나머지 덧셈정리가 나온다. 두 각을 같게 하면 배각 공식 \(\cos 2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha\)가, 두 덧셈정리를 더하거나 빼면 합을 곱으로 바꾸는 공식 \[\sin A + \sin B = 2\sin\frac{A + B}{2}\cos\frac{A - B}{2}\]가 나온다.

배각 공식을 고쳐 쓰면 \(\cos^2\alpha = \tfrac12(1 + \cos 2\alpha)\)이다. 그래서 \(\cos^2 x\)의 그래프는 코사인 곡선을 세로로 절반 줄이고 위로 \(\tfrac12\) 올린 뒤 가로로 절반 줄인 모양이다. 제곱이 들어간 식을 제곱이 없는 식으로 바꾸어 주므로, 적분을 계산할 때 자주 쓴다. 이렇게 공식 하나만 증명해 두면 나머지는 대입과 덧셈으로 모두 꺼낼 수 있다.1

1.1.2합이 곱으로 바뀌면 보이는 것

합을 곱으로 바꾸는 공식은 진동수가 비슷한 두 파동의 합을 이해하는 데 쓰인다. \(A\)와 \(B\)가 거의 같으면 \(\sin\frac{A + B}{2}\)는 원래 소리와 거의 같은 빠른 떨림이고, \(\cos\frac{A - B}{2}\)는 아주 느리게 변하는 인자이다. 그래서 합한 소리는 빠른 떨림의 크기가 느린 코사인을 따라 커졌다 작아지는 모양이 되며, 이것이 맥놀이이다. 소리의 세기는 진폭의 크기로 느끼므로, 느린 코사인이 한 번 오르내리는 동안 소리는 두 번 커진다.

덧셈정리로 \(\cos 15°\)의 값을 구하여라. 처음 질문의 두 소리의 합 \(\sin(2\pi\cdot440t) + \sin(2\pi\cdot444t)\)를 곱의 꼴로 바꾸고, 1초에 소리가 커지는 횟수를 구하여라.

\(\cos 15° = \cos(45° - 30°) = \cos45°\cos30° + \sin45°\sin30° = \dfrac{\sqrt2}{2}\cdot\dfrac{\sqrt3}{2} + \dfrac{\sqrt2}{2}\cdot\dfrac12 = \dfrac{\sqrt6 + \sqrt2}{4} \approx 0.966\)이다.

합을 곱으로 바꾸면 \(2\sin(2\pi\cdot442t)\cos(2\pi\cdot2t)\)이다. 앞의 인자는 442 Hz로 떨리는 소리이고, 뒤의 인자 \(\cos(2\pi\cdot2t)\)는 1초에 2번 오르내린다. 그런데 소리의 크기는 이 인자의 절댓값을 따르므로, \(|\cos(2\pi\cdot2t)|\)가 1이 되는 순간은 1초에 4번이다. 그래서 두 소리굽쇠의 진동수 차 4 Hz만큼 1초에 네 번 웅웅거린다. 즉 덧셈정리에서 꺼낸 합을 곱으로 바꾸는 공식은 비슷한 두 떨림의 합을 빠른 떨림과 느린 변화로 나누어 보여 주어, 맥놀이의 박자가 진동수의 차와 같다는 것을 알려 준다.

\(\cos(\alpha - \beta)\)

  1. 단위원 위에 \(\mathrm{P}(\cos\alpha, \sin\alpha)\), \(\mathrm{Q}(\cos\beta, \sin\beta)\)를 잡는다.
  2. 두 점 사이의 거리 공식으로 \(\overline{\mathrm{PQ}}^2 = (\cos\alpha - \cos\beta)^2 + (\sin\alpha - \sin\beta)^2 = 2 - 2(\cos\alpha\cos\beta + \sin\alpha\sin\beta)\)이다.P와 Q의 좌표가 먼저 정해져야 거리를 계산할 수 있습니다.
  3. 그림 전체를 원점을 중심으로 \(-\beta\)만큼 돌리면 Q는 \(\mathrm{A}(1, 0)\)으로, P는 \(\mathrm{P'}(\cos(\alpha - \beta), \sin(\alpha - \beta))\)로 간다. 회전은 길이를 바꾸지 않으므로 \(\overline{\mathrm{PQ}} = \overline{\mathrm{P'A}}\)이다.돌리기 전에 원래 자리에서 \(\overline{\mathrm{PQ}}\)를 한 번 계산해 두어야, 돌린 뒤의 길이와 비교할 수 있습니다.
  4. \(\overline{\mathrm{P'A}}^2 = (\cos(\alpha - \beta) - 1)^2 + \sin^2(\alpha - \beta) = 2 - 2\cos(\alpha - \beta)\)이다.P′과 A는 그림을 돌린 뒤에야 생기는 점입니다.
  5. 두 식을 같게 놓으면 \(\cos(\alpha - \beta) = \cos\alpha\cos\beta + \sin\alpha\sin\beta\)이다.같게 놓을 두 식이 아직 모두 나오지 않았습니다.
  6. \(\cos(\alpha - \beta) = \cos\alpha - \cos\beta\)이므로 이것을 정리한다.각을 빼는 것과 코사인 값을 빼는 것은 다릅니다. \(\alpha = \beta = 60^\circ\)이면 왼쪽은 \(\cos 0 = 1\), 오른쪽은 0입니다.

단계를 하나 놓을 때마다 그림이 그 단계까지 그려진다. 각을 바꾸어도 \(\overline{\mathrm{PQ}}^2\)과 \(\overline{\mathrm{P'A}}^2\)이 언제나 같은지 보자.

  1. 질문\(\cos 75^\circ\)는 표를 보지 않고 구할 수 있을까? \(75^\circ = 45^\circ + 30^\circ\)이지만 \(\cos 45^\circ + \cos 30^\circ\)은 1보다 커서 답이 될 수 없다. 두 각의 합이나 차의 코사인은 어떻게 구해야 할까?
  2. 복원단위원 위에서 각 \(\theta\)를 나타내는 점의 좌표는 \((\cos\theta, \sin\theta)\)이다. 두 점 \((x_1, y_1)\), \((x_2, y_2)\) 사이 거리의 제곱은 \((x_1 - x_2)^2 + (y_1 - y_2)^2\)이고, \(\sin^2\theta + \cos^2\theta = 1\)이다.
  3. 설명같은 길이를 두 가지 방법으로 계산하는 것이 증명의 핵심이다. 원래 자리에서 \(\overline{\mathrm{PQ}}\)를 계산하면 \(\cos\alpha\cos\beta + \sin\alpha\sin\beta\)가 나오고, 그림 전체를 돌려 Q를 \(\mathrm{A}(1, 0)\)에 놓고 계산하면 \(\cos(\alpha - \beta)\)가 나온다. 회전은 길이를 바꾸지 않으므로 두 값이 같다. 이렇게 얻은 \(\cos(\alpha - \beta) = \cos\alpha\cos\beta + \sin\alpha\sin\beta\)에서 \(\beta\) 대신 \(-\beta\)를 넣으면 \(\cos(\alpha + \beta)\)가, \(\alpha\) 대신 \(\frac{\pi}{2} - \alpha\)를 넣으면 사인의 덧셈정리가 나온다.
  4. 연결이 공식 하나에서 배각 공식, 반각 공식, 합을 곱으로 바꾸는 공식이 모두 나온다. 다음 카드들은 모두 이 공식에 값을 바꾸어 넣은 것이다. 또 미분에서 \((\sin x)' = \cos x\)를 증명할 때도 사인의 덧셈정리가 쓰인다.
  5. 적용단계를 순서대로 쌓아 증명을 완성해 보자. 그다음 \(\alpha\)와 \(\beta\)를 바꾸며 \(\overline{\mathrm{PQ}}^2\)과 \(\overline{\mathrm{P'A}}^2\)이 늘 같은지 확인해 보자. \(\alpha < \beta\)여서 \(\alpha - \beta\)가 음수일 때도 증명이 그대로 통하는가?
  6. 판단이 증명은 각의 크기에 대해 아무것도 가정하지 않았다. 그래서 둔각이나 음의 각에서도 성립한다. 교과서에 흔한 "예각인 삼각형으로 그린 증명"은 그림이 한 경우만 다루므로, 그 증명만으로는 모든 각에서 성립한다고 말할 수 없다.

\(\cos^2 x\)의 그래프는 왜 코사인 곡선과 똑같이 생겼을까?

배각·반각 공식 · 조작
\(\cos 2\theta\)
—
\(\cos^2\theta - \sin^2\theta\)
—
\(2\sin\theta\cos\theta\)
—

왼쪽 원에서 점 \(2\theta\)는 점 \(\theta\)보다 두 배 빨리 돈다. 오른쪽 그래프에서 고른 함수의 높이, 가운데 선, 진폭, 주기를 읽어 보자.

  1. 질문\(y = \cos^2 x\)를 그려 보면 0과 1 사이를 오가는 물결이 나온다. 제곱했는데도 왜 포물선처럼 뾰족해지지 않고 매끄러운 코사인 곡선 모양이 될까?
  2. 복원덧셈정리 \(\cos(\alpha + \beta) = \cos\alpha\cos\beta - \sin\alpha\sin\beta\), \(\sin(\alpha + \beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta\)와 \(\sin^2\theta + \cos^2\theta = 1\)을 쓴다.
  3. 설명덧셈정리에 \(\alpha = \beta = \theta\)를 넣으면 배각 공식 \(\sin 2\theta = 2\sin\theta\cos\theta\), \(\cos 2\theta = \cos^2\theta - \sin^2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta\)이 나온다. 이것을 거꾸로 풀면 반각 공식 \(\cos^2\theta = \frac{1 + \cos 2\theta}{2}\), \(\sin^2\theta = \frac{1 - \cos 2\theta}{2}\)이다. 곧 \(\cos^2 x\)는 \(\cos 2x\)를 반으로 줄이고 \(\frac{1}{2}\)만큼 올린 곡선이라서, 진폭 \(\frac{1}{2}\), 주기 \(\pi\)인 코사인 곡선이다.
  4. 연결반각 공식은 제곱을 없애고 각을 두 배로 바꾼다. 그래서 \(\int \cos^2 x\,dx\)처럼 바로 적분할 수 없는 식을 \(\int \frac{1 + \cos 2x}{2}\,dx\)로 바꾸어 적분할 수 있다. 교류 전력의 평균이 최댓값의 절반인 이유도 이 공식에서 나온다.
  5. 적용\(\theta\)를 움직이며 세 값이 늘 같은 관계를 지키는지 보자. 세 함수 칩을 차례로 누르고 "겹치기"를 켜서 고른 함수와 배각 공식으로 바꾼 곡선이 정확히 겹치는지 확인해 보자. \(\sin x\cos x\)의 진폭과 주기는 얼마인가?
  6. 판단"\(\cos 2\theta = 2\cos\theta\)"는 흔한 착각이다. \(\theta = 60^\circ\)이면 \(\cos 120^\circ = -\frac{1}{2}\)인데 \(2\cos 60^\circ = 1\)이다. 각을 두 배로 하는 것은 값을 두 배로 하는 것과 다르다.

  1. 질문기타 줄을 맞출 때 두 줄을 함께 튕기면 "와우와우" 하고 소리가 커졌다 작아지기를 되풀이한다. 두 줄이 같은 음이 되면 이 울림이 사라진다. 울림은 어디에서 생길까?
  2. 복원진동수 \(f\)인 소리는 \(\sin(2\pi f t)\)로 나타낼 수 있다. 덧셈정리 \(\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta\)를 쓴다.
  3. 설명덧셈정리의 두 식을 더하면 \(\sin(\alpha + \beta) + \sin(\alpha - \beta) = 2\sin\alpha\cos\beta\)이다. \(A = \alpha + \beta\), \(B = \alpha - \beta\)로 놓으면 합을 곱으로 바꾸는 공식 \(\sin A + \sin B = 2\sin\frac{A + B}{2}\cos\frac{A - B}{2}\)이 나온다. 두 소리의 합은 평균 진동수 \(\frac{f_1 + f_2}{2}\)로 빠르게 떨리는 소리에, 아주 느리게 변하는 크기 \(2\cos\left(\pi(f_1 - f_2)t\right)\)가 곱해진 것이다. 이 크기는 1초에 \(|f_1 - f_2|\)번 커졌다 작아지므로 그만큼 울림이 들린다.
  4. 연결거꾸로 곱을 합으로 바꾸는 공식 \(2\sin\alpha\cos\beta = \sin(\alpha + \beta) + \sin(\alpha - \beta)\)는 라디오가 소리를 전파에 싣는 원리(진폭 변조)를 설명한다. 곱을 합으로 바꾸면 적분도 쉬워진다.
  5. 적용소리를 켜고 \(f_2\)를 440에 가깝게 움직이며 울림이 느려지는 것을 들어 보자. 그래프의 테두리 간격과 "울림 한 번의 시간"이 함께 바뀌는가? 그다음 조율 도전으로 숨겨진 기준음을 맞춰 보자.
  6. 판단포락선 \(2\cos(\pi \Delta f\, t)\)의 주기는 \(\frac{2}{\Delta f}\)이지만, 우리 귀에는 그 절반마다 울림이 한 번씩 들린다. 크기는 양과 음을 가리지 않기 때문이다. 그래서 맥놀이 진동수는 \(\frac{\Delta f}{2}\)가 아니라 \(\Delta f\)이다.
