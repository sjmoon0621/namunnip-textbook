1.7.1식의 모양을 보고 방법을 고르다

적분은 미분처럼 정해진 순서대로 하면 끝나는 계산이 아니어서, 식의 모양을 보고 방법을 먼저 골라야 한다. 피적분함수 안에 어떤 식과 그 도함수가 함께 있으면 그 식을 한 문자로 바꾸는 치환적분을 쓴다. 다항식과 지수함수나 삼각함수의 곱이면 부분적분으로 다항식의 차수를 낮춘다. 분모가 인수분해되는 분수식이면 간단한 분수의 합으로 쪼개는 부분분수를 쓴다. 그리고 \(\sqrt{1 - x^2}\)처럼 제곱의 차의 제곱근이 있으면 \(x = \sin\theta\)로 바꾸어 근호를 없애는 삼각치환을 쓴다.

정리 1.7.1 삼각치환과 부분분수

\(x = \sin\theta\)로 놓으면 \(dx = \cos\theta\,d\theta\), \(\sqrt{1 - x^2} = \cos\theta\)이므로 \[\int\sqrt{1 - x^2}\,dx = \int\cos^2\theta\,d\theta = \frac12(\theta + \sin\theta\cos\theta) + C\]이다. 또 \(\dfrac{1}{x(x - 1)} = \dfrac{1}{x - 1} - \dfrac1x\)처럼 분모의 인수마다 분수 하나씩으로 쪼갤 수 있다.

삼각치환의 결과를 그림 1과 견주어 보자. \(x = \sin\theta\)이면 \(\theta\)는 원 위의 점을 \(y\)축에서 잰 중심각이다. \(\tfrac12\theta\)는 반지름 1, 중심각 \(\theta\)인 부채꼴의 넓이이고, \(\tfrac12\sin\theta\cos\theta\)는 밑변 \(\sin\theta\), 높이 \(\cos\theta\)인 직각삼각형의 넓이이다. 그래서 식의 각 항이 그림의 각 조각과 정확히 맞아떨어진다. 치환은 계산 기술이기 전에 원을 각으로 다시 보는 일이다.1

1.7.2쪼개면 아는 꼴이 된다

부분분수는 복잡한 분수식을 이미 적분할 줄 아는 \(1/(x - a)\) 꼴의 합으로 바꾼다. 예를 들어 \(\dfrac{1}{x(x - 1)}\)의 그래프는 \(x = 0\)과 \(x = 1\)에 점근선이 있는 복잡한 모양이지만, \(\dfrac{1}{x - 1}\)과 \(-\dfrac1x\) 두 그래프를 더한 것과 정확히 겹친다. 각 조각을 적분하면 로그가 나오므로, 원래 적분은 로그의 차가 된다. 쪼갤 때의 분자는 양변에 분모를 곱한 뒤 \(x\)에 분모를 0으로 만드는 값을 넣어 쉽게 구한다.

1.7.3예제 하나를 끝까지

예제 1.7.2

삼각치환으로 \(\int_0^{1/2}\sqrt{1 - x^2}\,dx\)를 구해 그림 1의 값과 비교하여라. 또 부분분수로 \(\int_2^3\dfrac{dx}{x(x - 1)}\)을 구하여라.

\(x = \sin\theta\)로 놓으면 \(x = 0\)일 때 \(\theta = 0\), \(x = 1/2\)일 때 \(\theta = \pi/6\)이다. 적분은 \(\dfrac12\left[\theta + \sin\theta\cos\theta\right]_0^{\pi/6} = \dfrac12\left(\dfrac{\pi}{6} + \dfrac12\cdot\dfrac{\sqrt3}{2}\right) = \dfrac{\pi}{12} + \dfrac{\sqrt3}{8} \approx 0.2618 + 0.2165 = 0.4783\)이다. 부채꼴 \(\pi/12\)과 삼각형 \(\sqrt3/8\)의 합인 그림 1의 값과 같다.

부분분수로 쪼개면 \(\int_2^3\left(\dfrac{1}{x - 1} - \dfrac1x\right)dx = \left[\ln(x - 1) - \ln x\right]_2^3 = (\ln2 - \ln3) - (0 - \ln2) = \ln\dfrac43 \approx 0.288\)이다. 그래서 복잡해 보이는 분수식도 로그 두 개의 차로 바뀐다. 즉 적분은 식의 모양을 보고 알맞은 방법을 골라 아는 꼴로 바꾸는 일이며, 삼각치환은 원의 부채꼴과 삼각형으로, 부분분수는 간단한 분수의 합으로 그 뜻을 그림으로 확인할 수 있다.

아래 탐구 카드에서 여러 적분을 보고 알맞은 방법을 골라 보고, 삼각치환과 부분분수가 그림으로 무엇을 뜻하는지 확인해 보자.

  1. 같은 적분을 \(x = \cos\theta\)로 치환해도 답은 같지만, 그때는 각을 \(x\)축에서 재게 되어 부채꼴과 삼각형의 위치가 바뀐다. 치환을 어떻게 고르느냐에 따라 같은 넓이를 다른 그림으로 보게 된다.
마무리

적분은 식의 모양을 보고 치환적분, 부분적분, 부분분수, 삼각치환 가운데 알맞은 방법을 골라 이미 아는 꼴로 바꾼다. \(x = \sin\theta\)로 바꾸는 삼각치환의 결과 \(\tfrac12(\theta + \sin\theta\cos\theta)\)는 원 아래의 부채꼴과 삼각형의 넓이와 같고, 부분분수는 복잡한 분수식을 \(1/(x - a)\) 꼴의 합으로 쪼갠다. 처음 질문의 적분은 그림으로 구해도 식으로 구해도 \(\pi/12 + \sqrt3/8 \approx 0.478\)이다.

처음 고른 답으로 점수를 매긴다. 방법이 둘 이상 통하는 문제는 가장 짧은 길을 정답으로 하고, 다른 길도 설명에 적었다.

  1. 질문미분은 규칙만 따르면 어떤 식이든 계산이 끝난다. 그런데 적분은 같은 모양처럼 보이는 \(\int x e^{x^2}dx\)와 \(\int x e^x dx\)도 푸는 방법이 전혀 다르다. 무엇을 보고 방법을 고를까?
  2. 복원치환적분은 합성함수의 미분법을, 부분적분은 곱의 미분법을 거꾸로 쓴 것이다. 분수식은 간단한 분수의 합으로 쪼갤 수 있고, \(\sqrt{a^2 - x^2}\)은 \(x = a\sin\theta\)로 바꾸면 근호가 사라진다.
  3. 설명식에서 먼저 찾을 신호는 네 가지이다. ① 어떤 식과 그 도함수가 함께 있다 → 치환적분 (\(x e^{x^2}\)에서 \(x^2\)과 \(2x\)). ② 성격이 다른 두 함수의 곱이다 → 부분적분 (\(x e^x\), \(\ln x = 1 \cdot \ln x\)). ③ 분모가 인수분해되는 분수식이다 → 부분분수. ④ \(\sqrt{a^2 - x^2}\)이 있다 → 삼각치환. 어느 신호도 없고 표의 꼴과 같으면 공식을 그대로 쓴다.
  4. 연결방법을 고른 뒤에도 미분해서 원래 식이 나오는지 확인하는 습관이 중요하다. 적분은 거꾸로 가는 계산이라 실수를 확인할 방법이 미분뿐이다.
  5. 적용여덟 문제에서 신호를 찾아 방법을 고르자. 틀린 문제는 설명을 읽고 어떤 신호를 놓쳤는지 확인해 보자. 문제 7은 분자가 분모의 도함수라는 신호가 숨어 있다.
  6. 판단신호가 둘 이상인 식도 있다. \(\int\frac{2x + 3}{x^2 + 3x + 2}dx\)는 부분분수로도 풀리지만 치환이 훨씬 짧다. 또 \(e^{x^2}\)처럼 어떤 방법으로도 기본 함수로 적분할 수 없는 식이 있다는 것도 알아 두어야 한다.

복잡한 분수식을 간단한 분수 두 개로 쪼갤 수 있을까?

부분분수 · 조작

—

  1. 질문\(\int\frac{1}{x^2 - 1}dx\)는 치환도 부분적분도 통하지 않는다. 하지만 \(\int\frac{1}{x - 1}dx = \ln|x - 1| + C\)는 바로 할 수 있다. 복잡한 분수를 이런 간단한 분수의 합으로 바꿀 수 있다면 어떨까?
  2. 복원통분은 \(\frac{A}{x - a} + \frac{B}{x - b} = \frac{A(x - b) + B(x - a)}{(x - a)(x - b)}\)이다. 항등식은 모든 \(x\)에서 성립하므로 아무 값이나 넣어도 된다.
  3. 설명통분을 거꾸로 하는 것이 부분분수 분해이다. \(\frac{px + q}{(x - a)(x - b)} = \frac{A}{x - a} + \frac{B}{x - b}\)에서 양변에 \((x - a)(x - b)\)를 곱하면 \(px + q = A(x - b) + B(x - a)\)이고, 이것은 항등식이므로 \(x = a\)를 넣으면 \(B\)가 사라져 \(A = \frac{pa + q}{a - b}\), \(x = b\)를 넣으면 \(B = \frac{pb + q}{b - a}\)이다. 원래 식에서 \(x - a\)를 손으로 가리고 나머지에 \(x = a\)를 넣는 것과 같아 "가림 방법"이라고도 한다. 그러면 \(\int\frac{px + q}{(x - a)(x - b)}dx = A\ln|x - a| + B\ln|x - b| + C\)이다.
  4. 연결그래프로 보면 원래 함수의 점근선 \(x = a\), \(x = b\) 근처에서의 모양은 각각 \(\frac{A}{x - a}\), \(\frac{B}{x - b}\)가 정한다. 분해는 "어느 점근선 근처에서 얼마나 세게 튀는가"를 나눠 적은 것이다. 이 방법은 로지스틱 미분방정식을 풀 때도 다시 쓰인다.
  5. 적용\(A\)와 \(B\)를 움직여 색 곡선을 회색 곡선에 정확히 겹쳐 보자. 먼저 한 점근선 근처만 맞추고 다른 쪽을 맞추면 쉽다. 겹친 뒤에는 가림 방법으로 구한 값과 비교해 보자.
  6. 판단이 방법은 분자의 차수가 분모보다 낮을 때만 바로 쓸 수 있다. \(\frac{x^2}{x^2 - 1}\)처럼 차수가 같거나 높으면 먼저 나눗셈으로 \(1 + \frac{1}{x^2 - 1}\)처럼 바꾸어야 한다. 또 분모가 \((x - 1)^2\)처럼 겹치면 \(\frac{A}{x - 1} + \frac{B}{(x - 1)^2}\) 꼴로 둔다.

왼쪽의 초록 넓이와 오른쪽의 초록 넓이는 같은 적분이다. 오른쪽은 \(x = \sin\theta\)로 바꾼 뒤의 모습이고, 가로축이 \(x\) 대신 \(\theta\)이다.

  1. 질문\(\sqrt{1 - x^2}\)의 원시함수는 표에 없고, 치환 \(u = 1 - x^2\)도 \(du = -2x\,dx\)라서 \(x\)가 남아 쓸 수 없다. 그런데 \(y = \sqrt{1 - x^2}\)은 단위원의 윗부분이다. 원의 그림을 쓰면 어떨까?
  2. 복원반지름 1, 중심각 \(\theta\)인 부채꼴의 넓이는 \(\frac{1}{2}\theta\)이다. \(1 - \sin^2\theta = \cos^2\theta\), \(\cos^2\theta = \frac{1 + \cos 2\theta}{2}\)이다.
  3. 설명그림으로 보면 넓이는 직각삼각형 \(\frac{1}{2}a\sqrt{1 - a^2}\)과 중심각 \(\arcsin a\)인 부채꼴 \(\frac{1}{2}\arcsin a\)의 합이다. 계산으로는 삼각치환 \(x = \sin\theta\)를 쓴다. \(dx = \cos\theta\,d\theta\), \(\sqrt{1 - \sin^2\theta} = \cos\theta\)이므로 \(\int_0^a\sqrt{1 - x^2}\,dx = \int_0^{\arcsin a}\cos^2\theta\,d\theta = \left[\frac{\theta}{2} + \frac{\sin 2\theta}{4}\right]_0^{\arcsin a}\)이고, \(\frac{\sin 2\theta}{4} = \frac{\sin\theta\cos\theta}{2} = \frac{1}{2}a\sqrt{1 - a^2}\)이 바로 삼각형이다. 두 방법의 답이 \(\frac{1}{2}a\sqrt{1 - a^2} + \frac{1}{2}\arcsin a\)로 같다.
  4. 연결\(\sqrt{a^2 - x^2}\)은 \(x = a\sin\theta\), \(\frac{1}{a^2 + x^2}\)은 \(x = a\tan\theta\)로 바꾼다. 근호나 분모 속의 "\(a^2 \pm x^2\)"이 삼각함수의 관계식 \(1 - \sin^2\theta = \cos^2\theta\), \(1 + \tan^2\theta = \sec^2\theta\)로 한 항이 되기 때문이다.
  5. 적용\(a\)를 0부터 1까지 움직이며 삼각형과 부채꼴이 어떻게 나눠 갖는지 보자. \(a = 1\)이면 삼각형이 사라지고 넓이는 사분원 \(\frac{\pi}{4}\)가 된다. 오른쪽 그림의 넓이가 왼쪽과 늘 같은지 표로 확인해 보자.
  6. 판단치환하면 적분 구간도 바꾸어야 한다. \(x\)가 0에서 \(a\)까지 갈 때 \(\theta\)는 0에서 \(\arcsin a\)까지 간다. 또 \(\sqrt{\cos^2\theta} = \cos\theta\)로 쓸 수 있는 것은 이 구간에서 \(\cos\theta \ge 0\)이기 때문이다.
