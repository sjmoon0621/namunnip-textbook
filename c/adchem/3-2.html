엔탈피와 헤스 법칙

대부분의 화학 반응은 대기압 아래 열린 그릇에서 일어나고, 기체가 생기거나 사라지면 계는 대기를 밀거나 대기에 밀리며 일을 주고받습니다. 이 일까지 장부에 미리 넣어 둔 상태 함수가 엔탈피입니다. 엔탈피는 상태 함수이므로, 표준 생성 엔탈피 표 하나만 있으면 아직 해 보지 않은 반응의 반응열도 계산할 수 있습니다.

3.2.1

잴 수 없는 반응의 열을 어떻게 알아낼까?

헤스 법칙 · 엔탈피 도표

25 °C, 1기압 대략값. 연소 열은 실험으로 잴 수 있는 값입니다.

  1. 질문탄소를 산소 속에서 태우면 일산화 탄소와 이산화 탄소가 섞여 나옵니다. 그래서 탄소가 일산화 탄소만 되는 반응의 열은 직접 재기가 어렵습니다. 어떻게 알아낼 수 있을까요?
  2. 복원ΔH는 반응물과 생성물의 엔탈피 차이입니다. 반응식을 거꾸로 쓰면 부호가, 계수를 바꾸면 크기가 바뀝니다.
  3. 설명엔탈피는 산의 높이처럼 처음 상태와 나중 상태만으로 정해지고, 어떤 길로 갔는지와 관계없습니다. 그래서 반응이 한 번에 일어나든 여러 단계로 일어나든 전체 ΔH는 같습니다. 이것이 헤스 법칙입니다.
  4. 연결탄소가 이산화 탄소가 되는 길을 ① 한 번에(ΔH₁ = −393.5 kJ), ② 일산화 탄소를 거쳐 두 단계로(ΔH₂ + ΔH₃) 나누면 ΔH₁ = ΔH₂ + ΔH₃입니다. 일산화 탄소가 타는 열 ΔH₃ = −283.0 kJ은 잴 수 있으므로, 잴 수 없던 ΔH₂를 뺄셈으로 구합니다.
  5. 적용“모르는 ΔH 계산하기”를 누르기 전에 직접 계산해 보세요. 메테인의 생성 열 예에서는 탄소, 수소, 메테인의 연소 열 세 개를 어떻게 더하고 빼야 할까요? 도표에서 두 경로의 화살표 길이의 합을 비교해 보세요.
  6. 판단헤스 법칙은 에너지 보존에서 나옵니다. 만약 경로에 따라 ΔH가 달랐다면, 한 길로 가서 다른 길로 돌아오는 것만으로 에너지를 공짜로 얻는 영구 기관을 만들 수 있을 것입니다. 단, 계산할 때 물질의 상태(물이 액체인지 기체인지)를 모든 식에서 맞춰야 합니다.

확인조건이 달라지면

A → C의 ΔH = −100 kJ이고, A → B의 ΔH = −30 kJ입니다. B → C의 ΔH는?

3.2.2

표준 생성 엔탈피 표 하나로 모든 반응열을 구할 수 있을까?

25 °C, 1 bar의 표준 생성 엔탈피(kJ/mol): CH₄(g) −74.6, C₂H₅OH(l) −277.6, C₆H₁₂O₆(s) −1273.3, CO₂(g) −393.5, H₂O(l) −285.8, H₂O(g) −241.8, NH₃(g) −45.9, CaCO₃(s, 방해석) −1207.6, CaO(s) −634.9, NO(g) +91.3 (CRC Handbook). 홑원소 물질은 0입니다. ΔU는 기체를 이상 기체로, 고체·액체의 부피 변화를 무시하고 계산했습니다(RT = 2.48 kJ/mol).

  1. 질문화학 반응은 수백만 가지인데, 반응열을 모두 열량계로 잴 수는 없습니다. 탄소를 태워 일산화 탄소만 얻는 반응처럼 깔끔하게 일으킬 수 없는 반응도 있습니다. 물질마다 숫자 하나씩만 적어 둔 표로 모든 반응의 반응열을 구할 수 있을까요?
  2. 복원ΔU = q + w이고, 압력 P가 일정할 때 계가 받은 일은 w = −PΔV입니다. 헤스 법칙에 따르면 반응을 여러 단계로 나누어도 전체 반응열은 같습니다.
  3. 설명엔탈피를 H = U + PV로 정의하면 압력이 일정할 때 ΔH = ΔU + PΔV = qP, 곧 열린 그릇에서 잰 열이 그대로 ΔH가 됩니다. H도 상태 함수이므로 기준점을 하나 정하면 됩니다. 표준 상태(1 bar)의 가장 안정한 홑원소 물질을 0으로 두고, 그 원소들로 화합물 1 mol을 만들 때의 ΔH를 표준 생성 엔탈피 ΔfH°라 합니다. 그러면 어떤 반응이든 원소를 거쳐 가는 길로 돌아갈 수 있어 ΔH°반응 = Σν ΔfH°(생성물) − Σν ΔfH°(반응물)입니다.
  4. 연결기체의 몰수가 Δn기체만큼 바뀌면 PΔV ≈ Δn기체RT이므로 ΔH = ΔU + Δn기체RT입니다. 메테인이 타면 기체 3 mol이 1 mol로 줄어, 대기가 계를 눌러 약 5 kJ의 일을 해 줍니다. 그래서 봄베 열량계(부피 일정)에서 잰 ΔU와 열린 그릇의 ΔH가 조금 다릅니다. 실제 반응은 대부분 압력이 일정한 조건에서 일어나므로, 이 일을 따로 계산하지 않아도 되는 ΔH가 더 쓸모 있습니다.
  5. 적용반응을 바꿔 가며 도표의 두 화살표(원소 → 반응물, 원소 → 생성물)의 차이가 ΔH°임을 확인하세요. 메테인 연소에서 물을 수증기로 바꾸면 ΔH°가 얼마나 달라지고, 그 차이는 무엇인가요? ΔH°와 ΔU°가 같아지는 반응은 어느 것이며 왜 그런가요? 석회석 분해는 ΔU°가 ΔH°보다 큰가요, 작은가요?
  6. 판단ΔfH°가 0이라고 그 물질의 엔탈피가 실제로 0인 것은 아닙니다. 엔탈피의 절댓값은 알 수 없고, 0은 해발 고도의 해수면처럼 정한 기준일 뿐입니다. 또 ΔfH°는 25 °C 값이라 고온 반응에는 근삿값입니다. 표의 값을 쓸 때는 물질의 상태(g, l, s)와 동소체(흑연과 다이아몬드)를 반드시 맞춰야 합니다.

디지털 온도계 분해능 0.1 °C, 전자저울 0.01 g. 용액 밀도는 1.00 g/mL, 비열은 물과 같은 4.18 J/(g·°C)로 둡니다. ①·③은 NaOH 약 2.00 g(0.0500 mol), ②는 1.00 M 용액 50.0 mL씩, ③의 염산은 0.500 M 100 mL입니다. 섞는 때는 1분(60 s)입니다.

  1. 탐구 문제NaOH(s)이 물에 녹는 열(ΔH₁), NaOH 수용액과 염산의 중화열(ΔH₂), NaOH(s)이 염산과 바로 반응하는 열(ΔH₃)을 각각 잽니다. ΔH₃ = ΔH₁ + ΔH₂가 실험값으로도 성립할까요?
  2. 복원용액이 얻은 열은 q = mcΔT입니다. 반응에서 나온 열이 모두 용액을 데웠다면 반응 엔탈피는 ΔH = −q/n(kJ/mol)입니다. 엔탈피는 처음과 나중 상태만으로 정해지므로, 같은 출발과 도착을 잇는 두 길의 ΔH 합은 같아야 합니다(헤스 법칙).
  3. 설계스타이로폼 컵 두 개를 겹치고 뚜껑에 온도계와 젓개를 꽂아 열이 덜 빠져나가게 합니다. 섞기 전 1분 동안 처음 온도를 재고, 섞은 뒤에도 5분 더 10초 간격으로 기록합니다. 세 반응 모두 NaOH 0.0500 mol이 반응하도록 맞춥니다. 조작 변인은 반응의 경로, 종속 변인은 ΔT, 통제 변인은 NaOH의 양·용액의 부피·처음 온도·열량계입니다.
  4. 분석고체가 녹는 동안에도 열이 새어 나가므로 최고 온도는 실제 ΔT보다 낮습니다. 온도가 떨어지는 뒷부분에 직선을 맞추고 섞은 순간(60 s)까지 거꾸로 늘이면(외삽), 열 손실이 없었을 때의 온도를 얻습니다. 열화학 반응식은 NaOH(s) → Na⁺(aq) + OH⁻(aq) ΔH₁ ≈ −44 kJ, H⁺(aq) + OH⁻(aq) → H₂O(l) ΔH₂ ≈ −56 kJ처럼 씁니다(문헌값 기준).
  5. 측정세 반응을 두 번 이상씩 재세요. 아래 네 칸에서 ΔH₁ + ΔH₂와 ΔH₃를 비교하고, 차이가 몇 %인지 구하세요. 그다음 "뚜껑 없이"와 "외삽 없이"를 켜고 다시 재 보세요. 어느 쪽 ΔH가 더 크게 작아지나요?
  6. 오차·안전컵과 온도계도 열을 조금 흡수하는데 q = mcΔT에는 빠져 있어 |ΔH|가 작게 나옵니다(계통 오차). NaOH은 공기 중 수분과 이산화 탄소를 흡수하므로 빨리 재고 마개를 닫습니다. 고체 NaOH은 피부를 부식시키고 녹을 때 뜨거워지므로 보안경과 장갑을 끼고 약숟가락으로 다룹니다. 남은 용액은 중화한 뒤 폐액통에 버립니다.
