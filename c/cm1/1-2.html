본문

\(x^3 - 2x^2 - 5x + 6\)을 \(x - 3\)으로 나눈 나머지는 얼마일까? 긴 나눗셈을 끝까지 하지 않고, \(x\)에 수 하나만 넣어서 알아낼 수는 없을까?

먼저 알아야 할 것다항식의 나눗셈 \(A = BQ + R\)과 나머지의 차수 조건(다항식의 연산), 중학교의 방정식과 해.

1.2.1언제나 참인 등식

두 등식 \(x^2 - 1 = (x + 1)(x - 1)\)과 \(2x - 4 = 0\)을 비교해 보자. 앞의 등식은 \(x\)에 5를 넣으면 양변이 24, \(-3\)을 넣으면 양변이 8로 언제나 맞는다. 그런데 뒤의 등식은 \(x = 2\)일 때만 맞는다. 둘 다 등호로 이어져 있지만 하는 일이 다르다.

뒤의 등식처럼 특정한 값에서만 참인 등식이 방정식이다. 앞의 것처럼 문자에 어떤 값을 넣어도 성립하는 등식을 그 문자에 대한 항등식이라 한다. 다항식을 전개하거나 인수분해해서 얻은 등식은 모두 항등식이다. 같은 식을 모양만 바꾸어 썼기 때문이다.

1.2.2항등식이면 계수가 같다

\(ax^2 + bx + c = 0\)이 \(x\)에 대한 항등식이라고 하자. \(x = 0\)을 넣으면 \(c = 0\)이다. 남은 식 \(ax^2 + bx = 0\)에 \(x = 1\)과 \(x = -1\)을 넣으면 \(a + b = 0\), \(a - b = 0\)이므로 \(a = b = 0\)이다. 따라서 항등식 \(ax^2 + bx + c = 0\)의 계수는 모두 0이어야 한다.

이 사실을 두 식의 차에 쓰면 더 쓸모 있는 꼴이 된다. \(ax^2 + bx + c = a'x^2 + b'x + c'\)이 항등식이면 우변을 옮긴 \((a - a')x^2 + (b - b')x + (c - c') = 0\)도 항등식이다. 즉 같은 차수의 계수끼리 같아야 한다.

정리 1.2.1 항등식의 성질

\(ax^2 + bx + c = a'x^2 + b'x + c'\)이 \(x\)에 대한 항등식이면 \(a = a',\ b = b',\ c = c'\)이다. 역도 성립한다.

그래프로 보면 이 정리의 뜻이 분명해진다. 두 이차 이하의 식이 다르다면 그 차는 0이 아닌 이차 이하의 식이고, 이런 식이 0이 되는 \(x\)는 많아야 두 개다.1 그래서 두 그래프가 세 점 이상에서 만나면 둘은 같은 그래프이다.

항등식 속의 모르는 계수를 이 성질로 정하는 방법을 미정계수법이라 한다. 양변을 전개해 계수를 맞추는 방법(계수비교법)과, 계산이 쉬운 수를 \(x\)에 넣는 방법(수치대입법)이 있다. 가령 \(x^2 + 3x + 1 = a(x - 1)^2 + b(x - 1) + c\)에서 \(x = 1\)을 넣으면 \(c = 5\)가 바로 나온다. 다른 두 값 \(x = 0, 2\)를 넣으면 \(a - b + 5 = 1\), \(a + b + 5 = 11\)이므로 \(a = 1\), \(b = 5\)이다.

1.2.3나눗셈의 결과도 항등식이다

다항식 \(P(x)\)를 \(x - a\)로 나눈 몫을 \(Q(x)\), 나머지를 \(R\)이라 하면 \(P(x) = (x - a)Q(x) + R\)이다. 일차식으로 나누었으므로 \(R\)은 상수이다. 이 등식은 나눗셈을 정리해 쓴 것이므로 \(x\)에 대한 항등식이다.

그러면 \(x\)에 아무 수나 넣어도 된다. 여기서 \(x = a\)를 고르면 \(x - a\)가 0이 되어 몫 \(Q(a)\)가 무엇이든 곱이 사라진다. 따라서 \(P(a) = 0 \cdot Q(a) + R = R\)이다. 몫을 몰라도 나머지를 구한 셈이다.

정리 1.2.2 나머지정리와 인수정리

다항식 \(P(x)\)를 \(x - a\)로 나눈 나머지는 \(P(a)\)이다. 특히 \(P(a) = 0\)이면 \(P(x)\)는 \(x - a\)로 나누어떨어지고, 거꾸로 \(x - a\)로 나누어떨어지면 \(P(a) = 0\)이다(인수정리).

그림 1의 슬라이더로 \(a\)를 옮겨 보자. 점의 높이가 곧 나머지이다. 높이가 0인 곳, 곧 그래프가 \(x\)축과 만나는 \(a = -2, 1, 3\)에서는 나머지가 0이므로 \(x + 2\), \(x - 1\), \(x - 3\)이 모두 \(P(x)\)의 인수이다. 실제로 \(P(x) = (x + 2)(x - 1)(x - 3)\)이다.

1.2.4조립제법으로 계수만 계산하기

나머지와 함께 몫도 필요할 때가 많다. 일차식 \(x - a\)로 나눌 때는 긴 나눗셈에서 \(x\)를 지우고 계수만 남겨 계산할 수 있는데, 이것이 조립제법이다. 첫 계수를 내려 쓰고, 방금 내려 쓴 수에 \(a\)를 곱해 다음 계수에 더하는 일을 되풀이한다.

그림 2에서 아래 줄은 \(1, 1, -2, 0\)이다. 즉 몫은 \(x^2 + x - 2\), 나머지는 0이다. 나머지정리로 구한 \(P(3) = 27 - 18 - 15 + 6 = 0\)과 맞는다.

예제 1.2.3

다항식 \(P(x)\)를 \(x - 1\)로 나눈 나머지는 3이고, \(x + 2\)로 나눈 나머지는 \(-6\)이다. \(P(x)\)를 \((x - 1)(x + 2)\)로 나눈 나머지를 구하여라.

이차식으로 나누므로 나머지는 일차 이하의 식이다. 그래서 몫을 \(Q(x)\), 나머지를 \(mx + n\)이라 두면 \(P(x) = (x - 1)(x + 2)Q(x) + mx + n\)이고, 이 등식은 항등식이다.

\(x = 1\)을 넣으면 앞의 곱이 사라져 \(P(1) = m + n\)이다. 나머지정리에 따라 \(P(1) = 3\)이므로 \(m + n = 3\)이다. 같은 방법으로 \(x = -2\)를 넣으면 \(P(-2) = -2m + n = -6\)이다. 두 식을 빼면 \(3m = 9\)이므로 \(m = 3\), \(n = 0\)이다.

따라서 나머지는 \(3x\)이다. 확인해 보면 \(x = 1\)에서 \(3x = 3\), \(x = -2\)에서 \(3x = -6\)으로 두 조건이 모두 맞는다. 몫 \(Q(x)\)는 끝내 구하지 않았는데, 나눗셈의 결과가 항등식이라는 사실 하나로 나머지를 정할 수 있었다.2 아래 탐구 카드에서 두 그래프를 겹쳐 보고 \(a\)를 움직이며 나머지와 높이가 함께 변하는지 직접 확인해 보자.

  1. 이차식 \(f(x)\)가 세 값 \(p, q, r\)에서 0이면 인수정리에 따라 \((x - p)(x - q)(x - r)\)로 나누어떨어져야 하는데, 이차식이 삼차식으로 나누어떨어지려면 \(f(x) = 0\)이어야 한다.
  2. \(x + 2 = x - (-2)\)이므로 \(x + 2\)로 나눈 나머지는 \(P(2)\)가 아니라 \(P(-2)\)이다. 일차식 \(px + q\)로 나누면 나머지는 \(P(-\tfrac{q}{p})\)이다.
마무리

항등식은 어떤 값을 넣어도 성립하므로, 양변의 같은 차수 계수가 같고 아무 수나 골라 넣을 수 있다. 다항식의 나눗셈 \(P(x) = (x - a)Q(x) + R\)도 항등식이라서, \(x = a\)를 넣으면 몫이 사라지고 나머지 \(R = P(a)\)만 남는다. 그래서 처음 질문의 나머지는 \(P(3) = 0\)이고, \(x - 3\)은 이 식의 인수이다.

어떤 \(x\)를 넣어도 성립하는 등식은 무엇이 다를까?

—

좌변
—
우변
—
두 그래프가 만나는 점
—

초록 실선은 좌변, 주황 점선은 우변의 그래프이다. 두 그래프가 완전히 겹치면 모든 \(x\)에서 두 값이 같다.

  1. 질문\(x^2 - 1 = (x + 1)(x - 1)\)은 \(x\)에 5를 넣어도 \(-3\)을 넣어도 맞는다. 반면 \(2x - 4 = 0\)은 \(x = 2\)일 때만 맞는다. 둘 다 등식인데 무엇이 다를까?
  2. 복원방정식은 특정한 \(x\)의 값에서만 참이 되는 등식이고, 그 값을 해라고 한다. 또 다항식을 전개하면 차수별 계수로 정리할 수 있다.
  3. 설명문자에 어떤 값을 넣어도 항상 성립하는 등식을 그 문자에 대한 항등식이라 한다. \(ax^2 + bx + c = 0\)이 \(x\)에 대한 항등식이면 \(a = b = c = 0\)이고, 그 역도 성립한다. 그래서 \(ax^2 + bx + c = a'x^2 + b'x + c'\)이 항등식이면 \(a = a'\), \(b = b'\), \(c = c'\)이다. 까닭은 0이 아닌 이차 이하의 다항식은 0이 되는 \(x\)가 많아야 2개뿐이기 때문이다. 다시 말해 이차 이하인 두 식의 그래프가 세 점 이상에서 만나면 완전히 겹친다. 이 성질로 항등식 속의 모르는 계수를 정하는 방법을 미정계수법이라 하며, 양변을 전개해 같은 차수의 계수를 맞추는 계수비교법과 계산이 쉬운 \(x\)의 값을 넣는 수치대입법이 있다.
  4. 연결다항식의 나눗셈 결과 \(A = BQ + R\)도 \(x\)에 대한 항등식이다. 그래서 \(B\)가 0이 되는 \(x\)를 넣으면 몫을 몰라도 나머지를 구할 수 있고, 이것이 나머지정리이다.
  5. 적용수치대입법부터 해 보자. \(x = 1\)을 넣으면 우변에서 \(a\)와 \(b\)가 붙은 항이 0이 되어 \(c\)만 남는다. 대입할 \(x\)를 1에 두고 \(c\)를 좌변 값에 맞춘 뒤, \(a\), \(b\)를 움직여 두 그래프를 겹쳐 보자. 완전히 겹치기 직전에는 두 그래프가 많아야 두 점에서 만나고, 위 줄의 계수 비교로도 같은 답이 나온다.
  6. 판단어떤 \(x\) 몇 개에서 양변이 같다고 해서 항등식인 것은 아니다. 이차식끼리는 서로 다른 세 값에서 같아야 항등식이고, 두 값에서만 같으면 그래프가 두 점에서 만나는 것에 그친다. 그래서 수치대입법으로 모르는 수 세 개를 정하려면 서로 다른 \(x\) 세 개를 넣어야 한다.

나누어 보지 않고 나머지를 알 수 있을까?

나머지정리 · 인수정리

—

나눗셈의 나머지 \(R\)
—
\(P(a)\)
—
\(x - a\)는 인수인가
—

나머지 \(R\)은 긴 나눗셈(조립제법)으로 따로 계산한 값이고, \(P(a)\)는 그래프의 높이이다. 두 값을 비교해 보자.

  1. 질문\(x^3 - 2x^2 - 5x + 6\)을 \(x - 3\)으로 나눈 나머지를 긴 나눗셈 없이 구할 수 있을까?
  2. 복원다항식 \(P(x)\)를 \(B\)로 나눈 결과 \(P = BQ + R\)은 \(x\)에 대한 항등식이다. 그리고 일차식으로 나누면 나머지 \(R\)은 상수이다.
  3. 설명그래서 \(P(x) = (x - a)Q(x) + R\)에 \(x = a\)를 넣어도 등식이 성립하고, \((a - a)Q(a) = 0\)이므로 \(R = P(a)\)이다. 이것이 나머지정리이다. 일차식 \(px + q\)로 나누면 나머지는 \(P(-q/p)\)이다. 특히 \(P(a) = 0\)이면 나머지가 0이므로 \(P(x)\)는 \(x - a\)로 나누어떨어지고, \(x - a\)는 \(P(x)\)의 인수이다. 거꾸로 \(x - a\)가 인수이면 \(P(a) = 0\)이며, 이것이 인수정리이다. 그래프에서 \(P(a)\)는 \(x = a\)에서의 높이이므로, 나머지가 0인 곳은 그래프가 \(x\)축과 만나는 곳이다.
  4. 연결인수정리는 삼차식과 사차식을 인수분해할 때 첫 인수를 찾는 도구가 된다. 또 방정식 \(P(x) = 0\)의 해가 그래프와 \(x\)축의 교점이라는 생각은 이차방정식과 이차함수, 삼차방정식으로 이어진다.
  5. 적용\(a\)를 움직이며 나머지 \(R\)과 \(P(a)\)가 언제나 같은지 확인해 보자. 첫 번째 식에서는 나머지가 0이 되는 \(a\)가 세 개 있다. 두 번째 식에서는 \(a = -1.5\)를 살펴보고, 세 번째 식에서는 \(a\)를 0.5 간격으로 바꾸어서는 나머지가 0이 되는 곳을 찾을 수 없지만 그래프가 \(x\)축을 지나는 위치는 알려 준다.
  6. 판단"\(x + 2\)로 나눈 나머지는 \(P(2)\)"라고 하는 실수가 흔하다. \(x + 2 = x - (-2)\)이므로 \(P(-2)\)를 계산해야 한다. 또 나머지정리가 나머지를 바로 알려 주는 것은 일차식으로 나눌 때이다. 이차식으로 나누면 나머지가 일차식 \(mx + n\)이라 값 두 개가 필요하다.

  1. 질문\(x^3 - 7x + 6\)을 \(x - 2\)로 긴 나눗셈을 하면 \(x\)를 여러 번 쓰지만, 실제로 계산에 쓰이는 것은 계수뿐이다. 계수만 남기면 나눗셈을 얼마나 짧게 쓸 수 있을까?
  2. 복원긴 나눗셈은 최고차항끼리 나누어 몫의 항을 얻고, 나누는 식에 곱해 빼는 일을 되풀이한다. 빠진 차수에는 0을 적어 자리를 맞춘다. 중학교에서 다항식을 단항식으로 나눌 때 각 항의 계수를 나누었던 것처럼, 나누는 식이 단순하면 계수만으로 계산할 수 있다.
  3. 설명나누는 식이 \(x - a\)일 때 쓰는 조립제법은 이렇다. 계수를 차수 순서로 한 줄에 쓰고(빠진 차수는 0), 첫 계수를 그대로 아래로 내린다. 그다음 방금 내려 쓴 수에 \(a\)를 곱해 다음 칸 위에 쓰고, 그 칸의 계수와 더해 아래에 쓴다. 이 곱하고 더하기를 끝까지 되풀이하면 아래 줄의 마지막 수가 나머지이고, 그 앞의 수들이 몫의 계수이다. 긴 나눗셈에서는 \((x - a)\) × (몫의 항)을 빼지만, 조립제법에서는 \(-a\) 대신 \(a\)를 곱해 더하므로 같은 결과가 나온다.
  4. 연결아래 줄의 마지막 수는 나머지정리에 따라 \(P(a)\)와 같다. 그래서 조립제법은 \(P(a)\)를 빠르게 계산하는 방법이기도 하다. 마지막 수가 0이 되는 \(a\)를 찾으면 인수정리로 \(x - a\)라는 인수를 얻고, 몫으로 차수를 하나 낮춘 식이 남는다. 인수분해와 고차방정식 풀이에서 이 과정을 쓴다.
  5. 적용'처음부터'를 누르고 '다음 칸'으로 한 칸씩 진행하며 곱하고 더하는 순서를 따라가 보자. \(x^4 - 5x^2 + 4\)에서 \(a\)를 \(-2\)부터 2까지 바꾸면 나머지가 0이 되는 \(a\)가 \(\pm1\), \(\pm2\)의 네 개라는 것을 확인할 수 있다.
  6. 판단빠진 차수의 0을 빼먹으면 몫과 나머지가 모두 틀린다. 또 나누는 식이 \(2x - 1\)처럼 최고차항 계수가 1이 아니면, \(x - 1/2\)로 조립제법을 한 뒤 몫을 2로 나누어야 하고 나머지는 그대로이다. 예를 들어 \(2x^3 - 3x^2 - 11x + 6\)을 \(x - 1/2\)로 나누면 몫이 \(2x^2 - 2x - 12\), 나머지가 0이므로 \((2x - 1)(x^2 - x - 6)\)이다.
