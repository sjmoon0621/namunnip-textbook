조합

대표 3명을 뽑을 때는 누가 먼저 뽑혔는지가 중요하지 않습니다. 이렇게 순서를 따지지 않고 뽑는 경우의 수가 조합입니다. 이 절에서는 순열 목록에서 같은 사람들로 이루어진 나열을 한데 묶어, 조합의 수가 순열의 수를 r!로 나눈 값인 까닭을 확인합니다. 이어서 r를 바꿀 때 조합의 수가 어떻게 변하는지 보고, 대칭과 '특정한 하나를 넣느냐 빼느냐'로 나누는 관계를 찾습니다.

3.3.1

순서 없이 뽑는 수는 왜 순열의 수를 r!로 나눌까?

조합 · 순열 묶기
nPr
—
r!
—
nCr
—

칸 하나를 눌러 보세요.

  1. 질문A, B, C, D, E 다섯 명 가운데 대표 3명을 뽑는 방법은 몇 가지일까요? 세 명을 뽑아 한 줄로 세우는 방법 60가지와는 어떻게 다를까요?
  2. 복원5명 가운데 3명을 뽑아 한 줄로 세우는 방법은 5P3 = 5 × 4 × 3 = 60가지입니다. 3명을 한 줄로 세우는 방법은 3! = 6가지입니다.
  3. 설명서로 다른 n개에서 순서를 생각하지 않고 r개를 택하는 것을 n개에서 r개를 택하는 조합이라 하고, 그 수를 nCr로 나타냅니다. 같은 r명으로 이루어진 조합 하나는 줄 세우는 방법이 r!가지이므로, 순열 목록에 정확히 r!번 나타납니다. 그래서 nPr = nCr × r!이고 nCr = nPr/r! = n!/(r!(n − r)!) (단, 0 ≤ r ≤ n)입니다. 0! = 1로 정했으므로 nC0 = nCn = 1입니다.
  4. 연결식 nPr = nCr × r!은 곱의 법칙 그대로입니다. 순서대로 세우는 일은 '누구를 뽑을지 정하기'(nCr가지)와 '뽑은 사람을 줄 세우기'(r!가지)를 잇달아 하는 일이기 때문입니다.
  5. 적용n = 5, r = 3에서 ACE 칸을 누르면 같은 세 사람으로 된 칸이 모두 표시됩니다. 몇 칸인가요? '같은 모임끼리 묶기'를 눌러 묶음이 몇 개 생기는지 세고 5P3 ÷ 3!과 비교하세요. r를 바꾸어도 묶음 하나의 크기가 늘 r!인지 확인하세요.
  6. 판단대표 3명을 뽑는 것과 회장·부회장·총무를 뽑는 것은 다릅니다. 역할이 정해지면 순서가 생기므로 순열입니다. 뽑힌 것끼리 자리를 바꾸어도 같은 결과인지 물어보면 순열과 조합을 가를 수 있습니다.

3.3.2

뽑는 수 r가 바뀌면 조합의 수는 어떻게 변할까?

조합 · 대칭과 나누어 세기
nCr
—
nCn−r
—
막대 높이의 합
—

—

  1. 질문10명 가운데 2명을 뽑는 방법과 8명을 뽑는 방법은 어느 쪽이 더 많을까요? 많이 뽑을수록 방법도 많아질까요?
  2. 복원nCr = n!/(r!(n − r)!)이고, 서로 겹치지 않는 경우로 나누어 세면 합의 법칙으로 더할 수 있습니다.
  3. 설명① r명을 뽑는 일은 뽑히지 않을 n − r명을 정하는 일과 같습니다. 그래서 nCr = nCn−r입니다. 공식에서도 r!과 (n − r)!이 자리만 바꿉니다. ② 특정한 한 사람 A를 기준으로 나누면, A가 뽑히는 경우는 나머지 n − 1명에서 r − 1명을 더 뽑는 n−1Cr−1가지이고, A가 빠지는 경우는 n−1Cr가지입니다. 두 경우는 겹치지 않으므로 nCr = n−1Cr−1 + n−1Cr (1 ≤ r ≤ n − 1)입니다. ③ 막대를 모두 더하면 몇 명을 뽑든 상관없이 뽑는 방법 전체입니다. 사람마다 '뽑힘'과 '빠짐' 2가지를 고르므로 곱의 법칙에 따라 2n입니다.
  4. 연결②의 관계로 수를 한 줄씩 쌓은 표가 파스칼의 삼각형입니다. 이 수들은 다음 과목에서 (a + b)n을 전개할 때 계수(이항정리)로 다시 나옵니다.
  5. 적용n을 바꾸며 막대 모양이 좌우 대칭인지 보고, r와 n − r의 막대 높이를 비교하세요. 'A를 넣느냐 빼느냐로 나누기'를 켜고 두 조각의 값을 적은 뒤, n을 1 줄여 그 값이 어느 막대에 있는지 찾아보세요. n이 1 늘 때 막대 높이의 합은 어떻게 변하나요?
  6. 판단nCr는 r가 n/2에 가까울 때 가장 큽니다. '많이 뽑을수록 방법이 많다'는 생각은 r ≤ n/2인 범위에서만 맞습니다. nCr = nCn−r를 쓰면 20C18 같은 계산을 20C2 = 190으로 줄일 수 있습니다.
