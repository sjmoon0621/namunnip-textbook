삼차방정식과 사차방정식

이차방정식은 근의 공식으로 언제나 풀 수 있습니다. 차수가 3, 4로 올라가면 고등학교에서 쓸 만한 공식이 없으므로, 인수분해해서 차수를 낮추는 방법을 씁니다. 이 절에서는 인수정리로 근 하나를 찾고 조립제법으로 나누어 이차방정식으로 줄이는 과정을 따라가고, x2을 한 문자로 바꾸어 사차방정식을 이차방정식처럼 푸는 방법을 그래프로 확인합니다.

2.7.1

근의 공식이 없는 삼차방정식은 어떻게 풀까?

  1. 질문x3 − 2x2 − 5x + 6 = 0은 근의 공식으로 풀 수 없습니다. 그래도 근을 모두 구할 수 있을까요?
  2. 복원인수정리에 따르면 P(a) = 0일 때 P(x)는 x − a로 나누어떨어집니다. 조립제법은 x − a로 나눈 몫을 계수만으로 빠르게 구합니다. 이차방정식은 근의 공식으로 복소수 범위에서 언제나 풀립니다.
  3. 설명계수가 정수인 방정식이 유리수 근 p/q를 가지면, p는 상수항의 약수이고 q는 최고차항 계수의 약수입니다. 그래서 근의 후보는 ±(상수항의 약수)/(최고차항 계수의 약수)로 한정됩니다. ① 후보를 대입해 P(a) = 0인 a를 찾고 ② 조립제법으로 P(x) = (x − a)Q(x)를 얻으면 ③ 남은 Q(x) = 0은 차수가 하나 낮습니다. 이차식이 남을 때까지 되풀이한 뒤 근의 공식을 씁니다. x3 − 8처럼 인수분해 공식 a3 − b3 = (a − b)(a2 + ab + b2)이 바로 보이면 그것을 써도 됩니다.
  4. 연결실근은 그래프 y = P(x)가 x축과 만나는 점의 x좌표입니다. 허근은 그래프에 나타나지 않지만, 계수가 실수이면 a + bi와 켤레 a − bi가 짝으로 나옵니다. 그래서 삼차방정식은 실근을 적어도 하나 가집니다. 중근을 겹쳐 세면 n차방정식의 근은 복소수 범위에서 n개입니다.
  5. 적용첫 번째 식에서 후보를 하나씩 눌러 보세요. 값이 0인 후보를 찾으면 '조립제법으로 나누기'를 누릅니다. x3 − 8에서는 실근이 몇 개 나오나요? 2x3 − 5x2 + x + 2에서 −1/2을 먼저 골라 보고, 사차식에서는 나누기를 두 번 해야 하는지 확인하세요.
  6. 판단후보를 모두 대입해도 0이 안 나오면 유리수 근이 없다는 뜻입니다. 이때는 이 방법으로 풀리지 않으며, 교과서에서는 인수정리·조립제법·인수분해 공식으로 풀리는 방정식만 다룹니다. 또 그래프에서 실근만 세고 "삼차방정식의 근은 1개"라고 하면 안 됩니다. 복소수 범위의 근 3개 가운데 허근 2개가 그래프에 보이지 않을 뿐입니다.

사차방정식을 이차방정식처럼 풀 수 있을까?

왼쪽 그림의 회색 띠는 t < 0인 곳입니다. t = x2이 음수이면 x는 허수입니다.

  1. 질문x4 − 5x2 + 4 = 0에는 x4과 x2만 있고 홀수 차수 항이 없습니다. 이 모양을 이용하면 더 쉽게 풀 수 있을까요?
  2. 복원이차방정식 t2 + pt + q = 0은 인수분해나 근의 공식으로 풉니다. 또 x2 = k의 근은 k > 0이면 ±√k, k = 0이면 0, k < 0이면 ±√(−k)i입니다.
  3. 설명x2 = t로 놓으면 x4 + px2 + q = 0은 t2 + pt + q = 0이 됩니다. 이 식을 풀어 t를 구한 뒤 x2 = t를 다시 풉니다. x4 − 5x2 + 4 = 0이면 (t − 1)(t − 4) = 0이므로 x2 = 1 또는 x2 = 4, 곧 x = ±1, ±2입니다. t에 대한 식이 인수분해되지 않을 때는 A2 − B2 꼴로 바꿉니다. x4 + x2 + 1 = (x2 + 1)2 − x2 = (x2 + x + 1)(x2 − x + 1)처럼 완전제곱식에서 제곱식을 빼면 합차 공식으로 인수분해됩니다.
  4. 연결양수 t 하나는 실근 두 개(±√t)를, 음수 t 하나는 허근 두 개를 줍니다. 그래서 오른쪽 그래프가 x축과 만나는 횟수는 왼쪽 그래프의 근 가운데 양수인 것의 두 배입니다. 오른쪽 그래프는 y축에 대칭인데, x와 −x를 넣은 값이 같기 때문입니다.
  5. 적용p와 q를 움직이며 실근이 4개, 3개, 2개, 1개, 0개가 되는 경우를 하나씩 찾아보세요. 실근이 3개일 때 t의 값에는 어떤 공통점이 있나요? 네 번째 식에서 t는 어떤 수인가요?
  6. 판단t의 값을 구하고 끝내면 안 됩니다. t = 4는 x의 값이 아니라 x2의 값입니다. 또 t가 음수라고 버리면 허근을 잃습니다. 문제가 실근만 묻는지, 복소수 범위의 근을 모두 묻는지 확인하세요.
