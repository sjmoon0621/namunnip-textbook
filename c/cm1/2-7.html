삼차방정식과 사차방정식

이차방정식은 근의 공식으로 언제나 풀 수 있습니다. 차수가 3, 4로 올라가면 고등학교에서 쓸 만한 공식이 없으므로, 인수분해해서 차수를 낮추는 방법을 씁니다. 이 절에서는 인수정리로 근 하나를 찾고 조립제법으로 나누어 이차방정식으로 줄이는 과정을 따라가고, \(x^2\)을 한 문자로 바꾸어 사차방정식을 이차방정식처럼 푸는 방법을 그래프로 확인합니다.

삼차방정식과 사차방정식

본문

상자를 만들려고 가로 10 cm, 세로 8 cm인 종이의 네 귀퉁이에서 한 변이 \(x\) cm인 정사각형을 잘라 냈더니 부피가 48 \(\text{cm}^3\)이었다. \(x\)는 얼마일까? 식을 세우면 삼차방정식이 되는데, 이차방정식처럼 쓸 근의 공식이 없다면 어떻게 풀어야 할까?

먼저 알아야 할 것인수정리와 조립제법(항등식과 나머지정리), 인수분해(인수분해), 이차방정식의 근과 판별식(이차방정식의 판별식).

2.7.1식 세우기

귀퉁이를 잘라 접으면 상자의 밑면은 가로 \(10 - 2x\), 세로 \(8 - 2x\)이고 높이는 \(x\)이다. 그러면 부피는 \(x(10 - 2x)(8 - 2x)\)이고, 이것이 48이므로 전개해서 정리하면 \(4x^3 - 36x^2 + 80x - 48 = 0\)이다. 양변을 4로 나누면 \(x^3 - 9x^2 + 20x - 12 = 0\)이다.

최고차항이 삼차인 방정식을 삼차방정식, 사차인 방정식을 사차방정식이라 한다. 삼차와 사차 방정식에도 근의 공식이 있기는 하지만 너무 복잡해서 고등학교에서는 쓰지 않는다.1 그 대신 인수분해를 이용한다.

2.7.2곱이 0이면 어느 하나가 0

이차방정식을 인수분해로 풀 때 쓴 원리는 '\(AB = 0\)이면 \(A = 0\) 또는 \(B = 0\)'이었다. 이 원리는 곱해진 식이 셋이든 넷이든 그대로 통한다. 따라서 삼차식을 일차식과 이차식의 곱으로 쪼개면, 일차방정식 하나와 이차방정식 하나를 푸는 문제가 된다.

인수를 찾는 단서는 인수정리이다. \(P(x) = x^3 - 9x^2 + 20x - 12\)에서 상수항 \(-12\)의 약수를 넣어 보면 \(P(1) = 1 - 9 + 20 - 12 = 0\)이다. 그림 1의 슬라이더를 \(x = 1\)에 두면 부피가 정확히 48이 되는 것도 확인된다.

그러면 \(x - 1\)이 인수이다. 조립제법으로 나누면 몫이 \(x^2 - 8x + 12\)이므로 \(P(x) = (x - 1)(x^2 - 8x + 12) = (x - 1)(x - 2)(x - 6)\)이다. 따라서 해는 \(x = 1, 2, 6\)이다.

방법 2.7.1 삼차방정식과 사차방정식의 풀이

\(P(x) = 0\)에서 \(P(x)\)를 인수분해 공식, 인수정리와 조립제법, 치환 등으로 일차식과 이차식의 곱으로 나타낸 뒤, 각 인수가 0이 되는 \(x\)를 구한다.

여기서 문제의 뜻을 다시 보아야 한다. 세로가 8 cm이므로 \(8 - 2x > 0\), 곧 \(0 < x < 4\)이다. 해 가운데 6은 이 조건을 어기므로 버리고, 상자의 높이는 1 cm 또는 2 cm이다. \(x = 2\)이면 \(2 \times 6 \times 4 = 48\)로 맞는다.

2.7.3사차방정식과 치환

사차방정식 가운데 \(x^4 - 5x^2 + 4 = 0\)처럼 \(x^2\)의 식으로만 이루어진 것을 복이차방정식이라 한다. \(x^2 = X\)로 두면 \(X^2 - 5X + 4 = 0\)이라는 이차방정식이 되고, \(X = 1\) 또는 \(X = 4\)이다. 다시 \(x^2 = 1\), \(x^2 = 4\)를 풀면 \(x = \pm 1, \pm 2\)이다.

그런데 \(x^4 + x^2 + 1 = 0\)처럼 치환해도 바로 인수분해되지 않는 경우가 있다. 이때는 적당한 항을 더하고 빼서 \(A^2 - B^2\)꼴을 만든다. \(x^4 + x^2 + 1 = (x^4 + 2x^2 + 1) - x^2 = (x^2 + 1)^2 - x^2 = (x^2 + x + 1)(x^2 - x + 1)\)이다. 그러면 두 이차방정식을 풀어 \(x = \dfrac{-1 \pm \sqrt{3}i}{2}\), \(\dfrac{1 \pm \sqrt{3}i}{2}\)를 얻는다.

2.7.4예제 하나를 끝까지

예제 2.7.2

삼차방정식 \(x^3 - 1 = 0\)의 한 허근을 \(\omega\)라 할 때, \(\omega^2 + \omega + 1\)과 \(\omega^{10} + \omega^5 + 1\)의 값을 구하여라.

인수분해 공식으로 \(x^3 - 1 = (x - 1)(x^2 + x + 1)\)이다. 실근은 \(x = 1\)이고, 허근은 \(x^2 + x + 1 = 0\)의 근이다. \(\omega\)는 허근이므로 이 이차방정식을 만족하고, 따라서 \(\omega^2 + \omega + 1 = 0\)이다.

또 \(\omega\)는 원래 방정식의 근이므로 \(\omega^3 = 1\)이다. 이 사실로 거듭제곱을 줄일 수 있다. \(\omega^{10} = (\omega^3)^3 \cdot \omega = \omega\)이고, \(\omega^5 = \omega^3 \cdot \omega^2 = \omega^2\)이다. 그러면 \(\omega^{10} + \omega^5 + 1 = \omega + \omega^2 + 1 = 0\)이다.

근을 직접 넣어 확인할 수도 있다. \(\omega = \dfrac{-1 + \sqrt{3}i}{2}\)로 두면 \(\omega^2 = \dfrac{1 - 2\sqrt{3}i - 3}{4} = \dfrac{-1 - \sqrt{3}i}{2}\)이고, \(\omega^2 + \omega + 1 = \dfrac{-1 - \sqrt{3}i - 1 + \sqrt{3}i + 2}{2} = 0\)이다. 근을 구하지 않고 '\(\omega\)가 만족하는 식'만으로 계산한 쪽이 훨씬 짧다. 아래 탐구 카드에서 그래프와 조립제법을 함께 보며 삼차식이 쪼개지는 과정을 직접 따라가 보자.

  1. 삼차방정식의 근의 공식은 16세기 이탈리아의 타르탈리아와 카르다노, 사차방정식의 공식은 페라리가 찾았다. 오차 이상의 방정식에는 계수의 사칙연산과 거듭제곱근만으로 된 일반적인 근의 공식이 없다는 것이 19세기에 아벨과 갈루아에 의해 밝혀졌다.
마무리

삼차방정식과 사차방정식은 인수정리, 인수분해 공식, 치환으로 좌변을 일차식과 이차식의 곱으로 쪼갠 뒤, 곱이 0이면 어느 인수가 0이라는 원리로 푼다. 처음 질문의 상자는 \((x - 1)(x - 2)(x - 6) = 0\)에서 나온 세 해 가운데 조건 \(0 < x < 4\)에 맞는 1 cm와 2 cm가 답이다.

  1. 질문\(x^3 - 2x^2 - 5x + 6 = 0\)은 근의 공식으로 풀 수 없다. 그래도 근을 모두 구할 방법이 있을까?
  2. 복원인수정리에 따르면 \(P(a) = 0\)일 때 \(P(x)\)는 \(x - a\)로 나누어떨어진다. 조립제법은 \(x - a\)로 나눈 몫을 계수만으로 빠르게 구한다. 또 이차방정식은 근의 공식으로 복소수 범위에서 언제나 풀린다.
  3. 설명계수가 정수인 방정식이 유리수 근 \(p/q\)를 가지면 \(p\)는 상수항의 약수이고 \(q\)는 최고차항 계수의 약수이다. 그래서 근의 후보는 ±(상수항의 약수)/(최고차항 계수의 약수)로 좁혀진다. 후보를 대입해 \(P(a) = 0\)인 \(a\)를 찾고, 조립제법으로 \(P(x) = (x - a)Q(x)\)를 얻으면, 남은 \(Q(x) = 0\)은 차수가 하나 낮다. 이것을 이차식이 남을 때까지 되풀이한 뒤 근의 공식을 쓴다. 물론 \(x^3 - 8\)처럼 인수분해 공식 \(a^3 - b^3 = (a - b)(a^2 + ab + b^2)\)이 바로 보이면 그것을 써도 된다.
  4. 연결실근은 그래프 \(y = P(x)\)가 \(x\)축과 만나는 점의 \(x\)좌표이다. 허근은 그래프에 나타나지 않지만, 계수가 실수이면 \(a + bi\)와 켤레 \(a - bi\)가 짝으로 나온다. 그래서 삼차방정식은 실근을 적어도 하나 가진다. 중근을 겹쳐 세면 \(n\)차방정식의 근은 복소수 범위에서 \(n\)개이다.
  5. 적용첫 번째 식에서 후보를 하나씩 눌러 보고, 값이 0인 후보를 찾으면 '조립제법으로 나누기'를 누르자. \(x^3 - 8\)에서는 실근이 하나뿐이라는 것을 볼 수 있다. \(2x^3 - 5x^2 + x + 2\)에서는 \(-1/2\)을 먼저 골라 보고, 사차식에서는 나누기를 두 번 해야 하는지도 확인해 보자.
  6. 판단후보를 모두 대입해도 0이 나오지 않으면 유리수 근이 없다는 뜻이고, 이때는 이 방법으로 풀리지 않는다. 교과서에서는 인수정리, 조립제법, 인수분해 공식으로 풀리는 방정식만 다룬다. 또 그래프에서 실근만 세고 "삼차방정식의 근은 1개"라고 하면 안 된다. 복소수 범위의 근 3개 가운데 허근 2개가 그래프에 보이지 않을 뿐이다.

왼쪽 그림의 회색 띠는 \(t < 0\)인 곳이다. \(t = x^2\)이 음수이면 \(x\)는 허수이다.

  1. 질문\(x^4 - 5x^2 + 4 = 0\)에는 \(x^4\)과 \(x^2\)만 있고 홀수 차수의 항이 없다. 이 모양을 이용하면 사차방정식을 더 쉽게 풀 수 있지 않을까?
  2. 복원이차방정식 \(t^2 + pt + q = 0\)은 인수분해나 근의 공식으로 푼다. 또 \(x^2 = k\)의 근은 \(k > 0\)이면 \(\pm\sqrt{k}\), \(k = 0\)이면 0, \(k < 0\)이면 \(\pm\sqrt{-k}i\)이다.
  3. 설명그래서 \(x^2 = t\)로 놓으면 \(x^4 + px^2 + q = 0\)은 \(t^2 + pt + q = 0\)이 된다. 이 식에서 \(t\)를 구한 뒤 \(x^2 = t\)를 다시 풀면 된다. 예를 들어 \(x^4 - 5x^2 + 4 = 0\)은 \((t - 1)(t - 4) = 0\)이므로 \(x^2 = 1\) 또는 \(x^2 = 4\), 곧 \(x = \pm1\), \(\pm2\)이다. 그런데 \(t\)에 대한 식이 인수분해되지 않으면 \(A^2 - B^2\) 꼴로 바꾸어 본다. \(x^4 + x^2 + 1 = (x^2 + 1)^2 - x^2 = (x^2 + x + 1)(x^2 - x + 1)\)처럼 완전제곱식에서 제곱식을 빼면 합차 공식으로 인수분해된다.
  4. 연결양수 \(t\) 하나는 실근 두 개 \(\pm\sqrt{t}\)를, 음수 \(t\) 하나는 허근 두 개를 준다. 따라서 오른쪽 그래프가 \(x\)축과 만나는 횟수는 왼쪽 그래프의 근 가운데 양수인 것의 두 배이다. 또 오른쪽 그래프가 \(y\)축에 대칭인 것은 \(x\)와 \(-x\)를 넣은 값이 같기 때문이다.
  5. 적용\(p\)와 \(q\)를 움직이며 실근이 4개, 3개, 2개, 1개, 0개가 되는 경우를 하나씩 찾아보자. 실근이 3개일 때는 \(t\)의 값 하나가 꼭 0이라는 공통점이 보인다. 네 번째 식에서는 \(t\)가 어떤 수인지도 확인해 보자.
  6. 판단\(t\)의 값을 구하고 끝내면 안 된다. \(t = 4\)는 \(x\)의 값이 아니라 \(x^2\)의 값이기 때문이다. 또 \(t\)가 음수라고 버리면 허근을 잃는다. 그래서 문제가 실근만 묻는지, 복소수 범위의 근을 모두 묻는지 먼저 확인해야 한다.
