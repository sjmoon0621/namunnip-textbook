이차함수의 최대·최소

이차함수는 꼭짓점에서 가장 크거나 가장 작은 값을 가집니다. 그런데 실제 문제에서는 \(x\)가 아무 값이나 될 수 없습니다. 길이는 양수여야 하고, 벽의 길이나 재료의 양에도 한계가 있습니다. 이 절에서는 \(x\)의 범위가 정해졌을 때 최댓값과 최솟값이 어디서 생기는지 구간을 움직여 확인하고, 울타리로 가장 넓은 땅을 둘러싸는 문제에 적용합니다.

\(y = x^2 - 4x + 1\)은 꼭짓점 \(x = 2\)에서 가장 작은 값 \(-3\)을 갖는다. 그런데 \(x\)가 \(3 \le x \le 5\)처럼 꼭짓점을 비켜 간 범위에서만 움직인다면, 가장 작은 값과 가장 큰 값은 어디서 나올까?

먼저 알아야 할 것중학교의 이차함수 \(y = a(x - p)^2 + q\)의 꼭짓점과 축, 완전제곱식 만들기, 이차함수의 그래프(이차방정식과 이차함수).

2.6.1범위가 없을 때의 최대·최소

\(y = x^2 - 4x + 1\)을 완전제곱식으로 바꾸면 \(y = (x - 2)^2 - 3\)이다. 제곱 \((x - 2)^2\)은 0 이상이므로 \(y\)는 \(-3\) 이상이고, \(x = 2\)일 때 정확히 \(-3\)이 된다. 따라서 최솟값은 \(-3\)이다. 그런데 \(x\)가 2에서 멀어질수록 \(y\)는 한없이 커지므로 최댓값은 없다.

함수가 가질 수 있는 값 가운데 가장 큰 값을 최댓값, 가장 작은 값을 최솟값이라 한다. \(x\)의 범위에 제한이 없으면 \(y = a(x - p)^2 + q\)는 \(a > 0\)일 때 최솟값 \(q\)만, \(a < 0\)일 때 최댓값 \(q\)만 갖는다. 꼭짓점이 그래프의 맨 아래나 맨 위이기 때문이다.

2.6.2범위가 정해지면 끝점이 후보가 된다

이제 \(x\)를 \(3 \le x \le 5\)로 제한하자. 그림 1에서 \(p = 3\)에 두면 이 범위의 그래프는 꼭짓점의 오른쪽 부분이라 계속 올라가기만 한다. 그러면 가장 낮은 점은 왼쪽 끝 \(x = 3\)이고, 가장 높은 점은 오른쪽 끝 \(x = 5\)이다. 값을 계산하면 \(x = 3\)일 때 \(y = -2\), \(x = 5\)일 때 \(y = 6\)이므로 최솟값은 \(-2\), 최댓값은 6이다.

슬라이더로 \(p\)를 1로 옮겨 범위를 \(1 \le x \le 3\)으로 바꾸면 사정이 달라진다. 꼭짓점 \(x = 2\)가 범위 안에 들어오므로 최솟값은 꼭짓점의 \(-3\)이다. 최댓값은 두 끝 \(x = 1\)과 \(x = 3\)에서의 값 가운데 큰 것인데, 둘 다 \(-2\)로 같다. 두 끝이 축 \(x = 2\)에서 같은 거리에 있기 때문이다.

정리 2.6.1 제한된 범위에서의 최대·최소

\(\alpha \le x \le \beta\)에서 이차함수 \(f(x) = a(x - p)^2 + q\)의 최댓값과 최솟값은 \(f(\alpha)\), \(f(\beta)\), 그리고 꼭짓점이 범위 안에 있을 때의 \(f(p) = q\) 가운데에서 나온다.

정리가 후보를 세 개로 줄여 주는 까닭은 그래프의 모양에 있다. 포물선은 축의 한쪽에서는 계속 내려가거나 계속 올라가기만 한다. 그래서 범위 안에서 방향이 바뀔 수 있는 곳은 꼭짓점뿐이고, 나머지 가장 높거나 낮은 점은 범위가 끊기는 끝에서 생긴다.

2.6.3예제 하나를 끝까지

예제 2.6.2

길이가 40 m인 철망으로 한쪽 면이 담장인 직사각형 밭을 두르려고 한다. 담장에 수직인 변의 길이를 \(x\) m라 할 때, 밭의 넓이가 가장 큰 경우를 구하여라. 또 담장의 길이가 16 m여서 담장과 평행한 변이 16 m를 넘을 수 없다면 어떻게 되는지 구하여라.

담장에 수직인 두 변이 각각 \(x\)이므로 담장과 평행한 변은 \(40 - 2x\)이다. 변의 길이는 양수여야 하므로 \(0 < x < 20\)이다. 넓이는 \(S = x(40 - 2x) = -2x^2 + 40x\)이고, 완전제곱식으로 바꾸면 \(S = -2(x - 10)^2 + 200\)이다.

\(a = -2 < 0\)이므로 그래프는 위로 볼록하고, 꼭짓점 \(x = 10\)이 범위 \(0 < x < 20\) 안에 있다. 따라서 \(x = 10\)일 때 넓이가 최대 \(200\ \text{m}^2\)이고, 이때 밭은 \(10 \times 20\)이다.

그런데 담장이 16 m뿐이면 \(40 - 2x \le 16\), 곧 \(x \ge 12\)라는 조건이 붙는다. 범위는 \(12 \le x < 20\)이 되어 꼭짓점 \(x = 10\)이 범위의 왼쪽 밖으로 나간다. 이 범위에서 그래프는 내려가기만 하므로 최댓값은 왼쪽 끝 \(x = 12\)에서 나온다. 따라서 \(S = 12 \times 16 = 192\ \text{m}^2\)이 최대이다.1 같은 식이라도 범위가 바뀌자 답이 꼭짓점에서 끝점으로 옮겨 갔다. 아래 탐구 카드에서 범위를 옮기며 최댓값과 최솟값이 어디로 이동하는지 직접 확인해 보자.

  1. 범위가 \(12 \le x < 20\)처럼 한쪽 끝을 포함하지 않으면, 그쪽에서는 값이 한없이 가까워지기만 하고 도달하지 않는다. 그래서 이 예제에서 최솟값은 없다.
마무리

포물선은 축의 한쪽에서는 한 방향으로만 움직이므로, 범위가 정해진 이차함수의 최댓값과 최솟값은 양 끝점과 범위 안의 꼭짓점 가운데에서만 나온다. 처음 질문의 \(3 \le x \le 5\)는 꼭짓점 \(x = 2\)를 포함하지 않으므로, 최솟값 \(-2\)는 왼쪽 끝에서, 최댓값 6은 오른쪽 끝에서 나온다.

  1. 질문\(f(x) = x^2 - 4x + 1\)은 \(x = 2\)에서 가장 작은 값 \(-3\)을 가진다. 그런데 \(x\)가 3 이상 5 이하로 정해져 있다면 최솟값도 \(-3\)일까? 최댓값은 있을까?
  2. 복원\(f(x) = a(x - p)^2 + q\)에서 \(a > 0\)이면 꼭짓점에서 최솟값 \(q\)를 가지고 최댓값은 없다. 그래프는 축 \(x = p\)에서 멀어질수록 높아진다.
  3. 설명\(\alpha \le x \le \beta\)에서 그래프는 끊기지 않는 한 조각이므로 최댓값과 최솟값이 모두 있다. 그리고 그 후보는 범위 안에 있을 때의 꼭짓점과 양 끝 \(f(\alpha)\), \(f(\beta)\)뿐이다. \(a > 0\)일 때 꼭짓점이 범위 안이면 최솟값은 \(q\), 최댓값은 양 끝 가운데 축에서 더 먼 쪽의 값이다. 반면 꼭짓점이 범위 밖이면 범위 안에서 그래프가 한쪽으로만 올라가거나 내려가므로, 최댓값과 최솟값이 모두 양 끝에서 생긴다. \(a < 0\)이면 최대와 최소의 역할이 바뀐다.
  4. 연결꼭짓점은 완전제곱식으로 고쳐 찾는다. 범위가 정해진 최대와 최소는 길이, 넓이, 이익처럼 \(x\)에 현실적인 제한이 있는 문제를 풀 때 쓰이고, 미적분에서 닫힌 구간의 최대와 최소를 찾는 방법도 같은 생각이다.
  5. 적용범위를 \(0 \le x \le 3\)으로 두면 최솟값이 꼭짓점에서 생긴다. 왼쪽 끝을 3으로 옮기면 꼭짓점이 범위 밖으로 나가 최솟값이 왼쪽 끝으로 옮겨 간다. 범위가 축 \(x = 2\)를 사이에 두고 한쪽으로 더 길게 뻗을 때 최댓값이 어느 끝에서 생기는지 확인하고, 위로 볼록한 두 번째 함수에서도 같은 규칙이 통하는지 보자.
  6. 판단꼭짓점의 값을 무조건 답으로 쓰는 실수가 흔하다. 꼭짓점이 범위 밖에 있으면 그 값은 \(f(x)\)가 범위 안에서 가지지 않는 값이다. 또 \(3 < x < 5\)처럼 끝점이 포함되지 않으면 최댓값이나 최솟값이 없을 수 있다. 그래서 꼭짓점이 범위 안인지, 끝점이 포함되는지를 먼저 확인한다.

벽 쪽에는 울타리를 치지 않는다. 벽과 평행한 변은 벽보다 길 수 없다고 가정한 모식이다.

  1. 질문길이 40 m인 울타리로 길이 12 m인 벽에 붙은 직사각형 텃밭을 만들려고 한다. 벽 쪽에는 울타리가 필요 없다. 텃밭을 가장 넓게 하려면 각 변을 몇 m로 해야 할까?
  2. 복원\(f(x) = a(x - p)^2 + q(a < 0)\)는 꼭짓점에서 최댓값을 가진다. 그런데 범위가 정해져 있으면 꼭짓점이 범위 안인지 먼저 보고, 밖이면 범위의 끝에서 최대가 생긴다.
  3. 설명벽과 수직인 변을 \(x\) m라 하면 벽과 평행한 변은 \((L - 2x)\) m이고, 넓이는 \(A = x(L - 2x) = -2(x - L/4)^2 + L^2/8\)이다. 그런데 \(x\)는 아무 값이나 될 수 없다. 평행한 변은 양수이면서 벽보다 길 수 없으므로 \(0 < L - 2x \le W\), 곧 \((L - W)/2 \le x < L/2\)이다. \(L = 40\), \(W = 12\)이면 \(14 \le x < 20\)인데 꼭짓점 \(x = 10\)은 이 범위 밖이다. 범위 안에서 \(A\)는 \(x\)가 커질수록 줄어들므로 최대는 \(x = 14\)일 때 \(14 \times 12 = 168 \text{ m}^2\)이다. 꼭짓점의 값 \(200 \text{ m}^2\)를 얻으려면 벽이 20 m 이상이어야 한다.
  4. 연결그래서 실생활 문제는 변수를 정하고, 식을 세우고, 변수의 범위를 정한 뒤, 그 범위에서 최대와 최소를 찾는 순서로 푼다. 둘레가 정해진 직사각형은 정사각형일 때 넓이가 가장 크다는 결과와 같은 생각이 여기서는 벽 하나가 빠진 모양으로 나타난다.
  5. 적용\(L = 40\), \(W = 12\)에서 \(x\)를 움직여 넓이가 가장 큰 곳을 찾아보자. 그다음 \(W\)를 키우며 최대가 생기는 자리가 범위 끝에서 꼭짓점으로 바뀌는 \(W\)를 찾으면, 그 값이 \(L\)의 절반인 20이라는 것을 알 수 있다.
  6. 판단꼭짓점에서 최대라는 결론을 바로 쓰면 벽보다 긴 변처럼 현실에서 불가능한 답이 나올 수 있다. 그러므로 식을 세운 뒤에는 반드시 변수의 범위를 함께 적는다. 또 이 카드는 벽과 울타리를 선분으로 보고 두께, 문, 땅 모양을 무시한 모식이다.
