연립이차방정식

두 식을 함께 만족하는 (x, y)를 찾을 때, 식 하나가 이차식이면 해가 여러 개일 수 있습니다. 이 절에서는 일차식을 이차식에 대입해 미지수를 하나로 줄이는 방법과, 인수분해되는 이차식을 일차식 두 개로 나누어 푸는 방법을 익힙니다. 해의 개수는 그래프의 교점의 개수와 같습니다.

2.8.1

일차식과 이차식을 함께 만족하는 해는 몇 개일까?

연립이차방정식 · 대입법과 판별식

—

판별식 D
—
해의 개수
—
해 (x, y)
—
  1. 질문연립방정식 x + y = 3, x2 + y2 = 5를 만족하는 (x, y)는 몇 쌍일까요? 일차방정식끼리의 연립과 무엇이 다를까요?
  2. 복원연립일차방정식은 한 식을 y = (x의 식)으로 고쳐 다른 식에 대입하면 미지수가 하나인 방정식이 됩니다. 이차방정식 ax2 + bx + c = 0의 실근의 개수는 판별식 D = b2 − 4ac의 부호로 정해집니다.
  3. 설명미지수가 2개이고 차수가 가장 높은 식이 이차인 연립방정식을 연립이차방정식이라고 합니다. 일차식이 하나 있으면 그 식을 y = mx + k로 고쳐 이차식에 대입합니다. 그러면 x에 대한 이차방정식이 되고, 그 근마다 y = mx + k로 y를 하나씩 구합니다. 질문의 식은 x2 + (3 − x)2 = 5, 곧 2x2 − 6x + 4 = 0이므로 x = 1, 2이고 해는 (1, 2), (2, 1)입니다.
  4. 연결각 식을 만족하는 점을 모으면 그래프가 됩니다. 그래서 연립방정식의 실수 해는 두 그래프의 교점이고, 대입해서 얻은 이차방정식의 판별식이 D > 0이면 교점 2개, D = 0이면 1개(접함), D < 0이면 0개입니다. 이차함수의 그래프와 직선의 위치 관계에서 본 것과 같은 판단입니다.
  5. 적용세 곡선마다 m과 k를 움직여 해가 2개, 1개, 0개인 경우를 찾아보세요. 원에서 m = 2일 때 접하는 k는 무엇인가요? xy = 2에서 m = 0으로 두면 대입한 식은 몇 차식이 되나요?
  6. 판단x만 구하고 끝내면 안 됩니다. 연립방정식의 해는 (x, y) 순서쌍이고, y는 반드시 일차식에 대입해 짝을 맞춥니다. 이차식에 대입하면 y가 두 개씩 나와 해가 아닌 쌍이 섞입니다. 또 대입한 식의 이차항 계수가 0이 되면 판별식을 쓸 수 없으니 일차방정식으로 따로 풀어야 합니다.

2.8.2

이차식 두 개로 된 연립방정식은 어떻게 풀까?

  1. 질문x2 − 3xy + 2y2 = 0과 x2 + y2 = 10은 둘 다 이차식이라 한 식을 y = (x의 일차식)으로 고칠 수 없습니다. 어떻게 미지수를 줄일까요?
  2. 복원AB = 0이면 A = 0 또는 B = 0입니다. 또 x2 − 3xy + 2y2은 x에 대한 이차식으로 보고 인수분해할 수 있습니다. 일차식과 이차식의 연립은 대입으로 풉니다.
  3. 설명① x2 − 3xy + 2y2 = (x − y)(x − 2y) = 0이므로 x = y 또는 x = 2y입니다. 그러면 처음 연립방정식은 두 개의 '일차식 + 이차식' 연립방정식으로 나뉩니다. x = y를 ②에 넣으면 2y2 = 10이라 y = ±√5이고, x = 2y를 넣으면 5y2 = 10이라 y = ±√2, x = ±2√2입니다. 해는 모두 4쌍입니다.
  4. 연결상수항이 없는 이차식 ax2 + bxy + cy2 = 0이 인수분해되면 그 그래프는 원점을 지나는 직선 두 개입니다. 그래서 이 연립방정식의 해는 '직선 두 개와 원의 교점'이고, 대입법으로 푸는 연립방정식을 두 번 푸는 셈입니다.
  5. 적용'다음 단계'를 눌러 인수분해, 경우 1, 경우 2를 차례로 따라가세요. c를 바꾸면 해의 개수는 달라지나요, 해의 위치만 달라지나요? 두 번째 식 x2 − y2 = 0에서 c = 18로 두면 해가 정수가 됩니다. 해를 확인하세요.
  6. 판단경우 하나만 풀고 멈추면 해의 절반을 잃습니다. 'A = 0 또는 B = 0'이므로 두 경우의 해를 모두 모아야 합니다. 또 두 이차식 중 어느 것도 인수분해되지 않으면 이 방법은 쓸 수 없으며, 교육과정에서는 한 식이 간단히 인수분해되는 경우만 다룹니다.
