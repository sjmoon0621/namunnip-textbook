근과 계수의 관계

이차방정식의 근을 구하지 않아도 두 근을 더한 값과 곱한 값은 계수만 보고 바로 알 수 있습니다. 이 절에서는 근을 직접 움직이며 계수가 어떻게 따라 바뀌는지 보고, 그 관계를 거꾸로 써서 합과 곱이 주어진 두 수를 찾습니다. 근이 허근이어도 이 관계는 그대로 성립합니다.

두 근의 합과 곱은 계수 어디에 숨어 있을까?

—

\(\alpha + \beta\)
—
\(-b/a\)
—
\(\alpha\beta\)
—
\(c/a\)
—

실근 모드에서는 \(x\)축 위의 두 점 \(\alpha\), \(\beta\)를 끌어 옮기세요(0.5 간격).

  1. 질문\(2x^2 - 6x + 1 = 0\)의 근은 무리수라 계산이 번거롭습니다. 근을 구하지 않고 두 근의 합과 곱을 알 수 있을까요?
  2. 복원인수정리에 따르면 \(\alpha\), \(\beta\)가 이차방정식 \(ax^2 + bx + c = 0\)의 두 근이면 \(ax^2 + bx + c = a(x - \alpha)(x - \beta)\)는 항등식입니다. 항등식은 같은 차수의 계수끼리 같습니다.
  3. 설명오른쪽을 전개하면 \(ax^2 - a(\alpha + \beta)x + a\alpha\beta\)입니다. 계수를 비교하면 \(b = -a(\alpha + \beta)\), \(c = a\alpha\beta\)이므로 \(\alpha + \beta = -b/a\), \(\alpha\beta = c/a\)입니다. 이것을 근과 계수의 관계라 합니다. 근의 공식으로 나온 두 근을 더하고 곱해도 같은 결과가 나오므로, 두 근이 허근이어도 성립합니다.
  4. 연결합과 곱을 알면 \(\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta\), \((\alpha - \beta)^2 = (\alpha + \beta)^2 - 4\alpha\beta\), \(1/\alpha + 1/\beta = (\alpha + \beta)/\alpha\beta\)처럼 \(\alpha\), \(\beta\)를 바꾸어도 그대로인 식의 값을 근 없이 구합니다. \((\alpha - \beta)^2 = D/a^2\)이어서 판별식과도 이어집니다.
  5. 적용\(\alpha\), \(\beta\)를 끌어 옮기며 \(\alpha + \beta\)와 \(-b/a\), \(\alpha\beta\)와 \(c/a\)가 항상 같은지 보세요. \(a\)를 바꾸면 \(b\), \(c\)는 바뀌는데 두 비는 왜 그대로인가요? 두 근의 곱이 음수가 되게 놓으면 두 근은 어디에 있나요? 허근 모드에서 \(q\)를 움직이면 합과 곱 중 어느 것이 바뀌나요?
  6. 판단부호를 자주 틀립니다. 두 근의 합은 \(b/a\)가 아니라 \(-b/a\)입니다. 또 관계식은 \(ax^2 + bx + c = 0\) 꼴로 정리한 뒤에 씁니다. \(2x^2 = 6x - 1\)처럼 항이 양쪽에 있으면 먼저 한쪽으로 옮기세요.

2.3.2

둘레와 넓이만 알면 직사각형의 가로, 세로를 알 수 있을까?

근과 계수의 관계 · 두 수를 근으로 하는 이차방정식

—

판별식 \(D = s^2 - 4p\)
—
두 수
—
직사각형
—

점선 정사각형은 합이 \(s\)일 때 넓이가 가장 큰 경우(한 변 \(s/2\))입니다.

  1. 질문둘레가 20 m, 넓이가 \(21 \text{ m}^2\)인 직사각형 꽃밭이 있습니다. 가로와 세로는 각각 몇 m일까요? 둘레를 조금 줄이거나 넓이를 키우면 언제나 그런 직사각형이 있을까요?
  2. 복원이차방정식 \(ax^2 + bx + c = 0\)의 두 근을 \(\alpha\), \(\beta\)라 하면 \(\alpha + \beta = -b/a\), \(\alpha\beta = c/a\)입니다. 판별식 \(D\)의 부호가 실근인지 허근인지를 정합니다.
  3. 설명두 수 \(\alpha\), \(\beta\)를 근으로 하고 \(x^2\)의 계수가 1인 이차방정식은 \((x - \alpha)(x - \beta) = 0\), 곧 \(x^2 - (\alpha + \beta)x + \alpha\beta = 0\)입니다. 그래서 합이 \(s\), 곱이 \(p\)인 두 수는 \(t^2 - st + p = 0\)의 두 근입니다. 가로 + 세로 = 10, 가로 × 세로 = 21이면 \(t^2 - 10t + 21 = (t - 3)(t - 7) = 0\)이므로 가로와 세로는 3 m, 7 m입니다.
  4. 연결두 수가 실수이려면 \(D = s^2 - 4p \ge 0\), 곧 \(p \le s^2/4\)여야 합니다. 둘레가 정해진 직사각형의 넓이는 정사각형일 때(\(D = 0\), 두 수가 같을 때) 가장 크다는 뜻입니다. 이 최댓값은 이차함수의 최대·최소에서 다시 만납니다.
  5. 적용\(s = 10\)에 두고 \(p\)를 키우며 직사각형이 정사각형에 가까워지는 것을 보세요. 직사각형이 사라지는 것은 \(p\)가 얼마를 넘을 때인가요? 그때 오른쪽 그래프는 \(t\)축과 어떻게 되고, 두 수는 어떤 수가 되나요?
  6. 판단\(D < 0\)이어도 합이 \(s\), 곱이 \(p\)인 두 수는 있습니다. 다만 서로 켤레인 허수라서 길이로 쓸 수 없습니다. 실생활 문제에서는 방정식의 근이 문제의 조건(양수, 실수 등)을 만족하는지 마지막에 꼭 확인하세요. 또 \(x^2\)의 계수가 1이 아니어도 되므로 같은 두 수를 근으로 하는 방정식은 \(2(x^2 - sx + p) = 0\)처럼 여러 개입니다.
