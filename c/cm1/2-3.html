근과 계수의 관계

이차방정식의 근을 구하지 않아도 두 근을 더한 값과 곱한 값은 계수만 보고 바로 알 수 있습니다. 이 절에서는 근을 직접 움직이며 계수가 어떻게 따라 바뀌는지 보고, 그 관계를 거꾸로 써서 합과 곱이 주어진 두 수를 찾습니다. 근이 허근이어도 이 관계는 그대로 성립합니다.

2.3.1근에서 식으로

그림 1에서 두 근을 \(\alpha = 1\), \(\beta = 3\)에 두자. 1과 3이 근이 되는 가장 간단한 이차방정식은 \((x - 1)(x - 3) = 0\)이고, 전개하면 \(x^2 - 4x + 3 = 0\)이다. 일차항의 계수 \(-4\)는 두 근의 합 4에 음의 부호를 붙인 것이고, 상수항 3은 두 근의 곱이다.

근을 \(\alpha\), \(\beta\)라는 문자로 바꾸어도 같은 일이 일어난다. \((x - \alpha)(x - \beta)\)를 전개하면 \(x^2 - (\alpha + \beta)x + \alpha\beta\)이다. 즉 최고차항 계수가 1인 이차식에서 일차항의 계수는 두 근의 합의 반대 부호, 상수항은 두 근의 곱이다. 슬라이더로 두 근을 바꾸어 보면 아래 계수가 이 규칙을 따라 변한다.

2.3.2근과 계수의 관계

최고차항 계수가 \(a\)이면 어떻게 될까? 이차방정식 \(ax^2 + bx + c = 0\)의 두 근이 \(\alpha\), \(\beta\)이면 인수정리에 따라 \(ax^2 + bx + c = a(x - \alpha)(x - \beta)\)로 쓸 수 있다.1 우변을 전개하면 \(ax^2 - a(\alpha + \beta)x + a\alpha\beta\)이고, 이것이 항등식이므로 계수를 비교할 수 있다.

일차항을 비교하면 \(b = -a(\alpha + \beta)\)이고, 상수항을 비교하면 \(c = a\alpha\beta\)이다. 따라서 두 근의 합과 곱은 계수의 비로 정해진다.

정리 2.3.1 근과 계수의 관계

이차방정식 \(ax^2 + bx + c = 0\)의 두 근을 \(\alpha\), \(\beta\)라 하면 \[\alpha + \beta = -\frac{b}{a}, \qquad \alpha\beta = \frac{c}{a}\]

근의 공식으로도 확인할 수 있다. 두 근 \(\dfrac{-b + \sqrt{D}}{2a}\)와 \(\dfrac{-b - \sqrt{D}}{2a}\)를 더하면 \(\pm\sqrt{D}\)가 지워져 \(-\dfrac{b}{a}\)가 남는다. 곱하면 합차 공식에 따라 분자가 \(b^2 - D = 4ac\)이므로 \(\dfrac{4ac}{4a^2} = \dfrac{c}{a}\)이다. 근호가 서로 지워지기 때문에, 근이 무리수나 허수여도 합과 곱은 계수만으로 깔끔한 수가 된다.

2.3.3합과 곱으로 다른 식 만들기

두 근의 합과 곱만 알면 \(\alpha\), \(\beta\)로 만든 대칭인 식은 대부분 계산할 수 있다. \(\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta\), \(\dfrac{1}{\alpha} + \dfrac{1}{\beta} = \dfrac{\alpha + \beta}{\alpha\beta}\), \((\alpha - \beta)^2 = (\alpha + \beta)^2 - 4\alpha\beta\)처럼 곱셈 공식을 거꾸로 쓰는 것이다.

거꾸로 두 수의 합과 곱을 알면 그 두 수를 근으로 갖는 이차방정식을 바로 쓸 수 있다. 1에서 본 대로 \(x^2 - (\text{합})x + (\text{곱}) = 0\)이다. 가령 합이 2, 곱이 5인 두 수는 \(x^2 - 2x + 5 = 0\)의 근 \(1 \pm 2i\)이다.

예제 2.3.2

이차방정식 \(2x^2 - 6x + 3 = 0\)의 두 근을 \(\alpha\), \(\beta\)라 할 때, \(\alpha^2 + \beta^2\)과 \(\dfrac{\beta}{\alpha} + \dfrac{\alpha}{\beta}\)의 값을 구하여라.

근과 계수의 관계에서 \(\alpha + \beta = -\dfrac{-6}{2} = 3\), \(\alpha\beta = \dfrac{3}{2}\)이다. 그러면 \(\alpha^2 + \beta^2 = 3^2 - 2 \cdot \dfrac{3}{2} = 9 - 3 = 6\)이다.

두 번째 식은 통분하면 \(\dfrac{\alpha^2 + \beta^2}{\alpha\beta}\)이다. 따라서 앞에서 구한 값을 넣어 \(\dfrac{6}{3/2} = 4\)이다.

근을 직접 구해 확인해 보자. 근의 공식으로 \(\alpha, \beta = \dfrac{3 \pm \sqrt{3}}{2}\)이다. 제곱하면 \(\dfrac{12 \pm 6\sqrt{3}}{4}\)이고, 두 값을 더하면 \(\sqrt{3}\)이 든 항이 지워져 \(\dfrac{24}{4} = 6\)이 된다. 계산은 길어졌지만 결과는 같다. 여기서 근호가 서로 지워진 것이 바로 합과 곱이 깔끔한 수로 나오는 이유이다. 아래 탐구 카드에서 두 근을 움직이며 계수와 그래프가 함께 변하는 모습을 직접 보자.

  1. 중근이면 \(\alpha = \beta\)로 보고 같은 식을 쓴다. 계수가 실수이고 허근을 가지면 두 근은 서로 켤레복소수이다.
마무리

이차식을 두 근으로 인수분해한 \(a(x - \alpha)(x - \beta)\)를 전개해 계수를 비교하면, 두 근의 합은 \(-\tfrac{b}{a}\), 곱은 \(\tfrac{c}{a}\)이다. 근의 공식에서 근호 부분이 서로 지워지므로 근이 무리수나 허수여도 이 관계는 그대로 성립한다. 그래서 처음 질문에서 합 5와 곱 3이 계수에 보인 것은 우연이 아니다.

실근 모드에서는 \(x\)축 위의 두 점 \(\alpha\), \(\beta\)를 끌어 0.5 간격으로 옮길 수 있다.

  1. 질문\(2x^2 - 6x + 1 = 0\)의 근은 무리수라 계산이 번거롭다. 근을 구하지 않고 두 근의 합과 곱을 알 수 있을까?
  2. 복원인수정리에 따르면 \(\alpha\), \(\beta\)가 이차방정식 \(ax^2 + bx + c = 0\)의 두 근이면 \(ax^2 + bx + c = a(x - \alpha)(x - \beta)\)는 항등식이다. 그리고 항등식은 같은 차수의 계수끼리 같다.
  3. 설명오른쪽을 전개하면 \(ax^2 - a(\alpha + \beta)x + a\alpha\beta\)이다. 계수를 비교하면 \(b = -a(\alpha + \beta)\), \(c = a\alpha\beta\)이므로 \(\alpha + \beta = -b/a\), \(\alpha\beta = c/a\)이고, 이것을 근과 계수의 관계라 한다. 근의 공식으로 나온 두 근을 더하고 곱해도 같은 결과가 나오므로, 두 근이 허근이어도 성립한다.
  4. 연결합과 곱을 알면 \(\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta\), \((\alpha - \beta)^2 = (\alpha + \beta)^2 - 4\alpha\beta\), \(1/\alpha + 1/\beta = (\alpha + \beta)/\alpha\beta\)처럼 \(\alpha\), \(\beta\)를 바꾸어도 그대로인 식의 값을 근 없이 구할 수 있다. 또 \((\alpha - \beta)^2 = D/a^2\)이어서 판별식과도 이어진다.
  5. 적용\(\alpha\), \(\beta\)를 끌어 옮기며 \(\alpha + \beta\)와 \(-b/a\), \(\alpha\beta\)와 \(c/a\)가 항상 같은지 보자. \(a\)를 바꾸면 \(b\), \(c\)도 같은 배수로 바뀌어 두 비는 그대로이다. 두 근의 곱이 음수가 되게 놓으면 두 근은 0을 사이에 두고 양쪽에 놓이고, 허근 모드에서 \(q\)를 움직이면 합은 그대로인 채 곱만 바뀐다.
  6. 판단부호를 자주 틀린다. 두 근의 합은 \(b/a\)가 아니라 \(-b/a\)이다. 또 관계식은 \(ax^2 + bx + c = 0\) 꼴로 정리한 뒤에 쓰므로, \(2x^2 = 6x - 1\)처럼 항이 양쪽에 있으면 먼저 한쪽으로 옮긴다.

점선 정사각형은 합이 \(s\)일 때 넓이가 가장 큰 경우(한 변 \(s/2\))이다.

  1. 질문둘레가 20 m, 넓이가 \(21 \text{ m}^2\)인 직사각형 꽃밭이 있다. 가로와 세로는 각각 몇 m일까? 둘레를 조금 줄이거나 넓이를 키워도 언제나 그런 직사각형이 있을까?
  2. 복원이차방정식 \(ax^2 + bx + c = 0\)의 두 근을 \(\alpha\), \(\beta\)라 하면 \(\alpha + \beta = -b/a\), \(\alpha\beta = c/a\)이다. 또 판별식 \(D\)의 부호가 실근인지 허근인지를 정한다.
  3. 설명거꾸로 두 수 \(\alpha\), \(\beta\)를 근으로 하고 \(x^2\)의 계수가 1인 이차방정식은 \((x - \alpha)(x - \beta) = 0\), 곧 \(x^2 - (\alpha + \beta)x + \alpha\beta = 0\)이다. 그래서 합이 \(s\), 곱이 \(p\)인 두 수는 \(t^2 - st + p = 0\)의 두 근이다. 가로 + 세로 = 10, 가로 × 세로 = 21이면 \(t^2 - 10t + 21 = (t - 3)(t - 7) = 0\)이므로 가로와 세로는 3 m, 7 m이다.
  4. 연결두 수가 실수이려면 \(D = s^2 - 4p \ge 0\), 곧 \(p \le s^2/4\)여야 한다. 다시 말해 둘레가 정해진 직사각형의 넓이는 두 수가 같은 정사각형일 때(\(D = 0\)) 가장 크다. 이 최댓값은 이차함수의 최대, 최소에서 다시 만난다.
  5. 적용\(s = 10\)에 두고 \(p\)를 키우며 직사각형이 정사각형에 가까워지는 것을 보자. \(p\)가 25를 넘으면 직사각형이 사라지는데, 그때 오른쪽 그래프는 \(t\)축과 만나지 않고 두 수는 허수가 된다.
  6. 판단\(D < 0\)이어도 합이 \(s\), 곱이 \(p\)인 두 수는 있다. 다만 서로 켤레인 허수라서 길이로 쓸 수 없다. 그래서 실생활 문제에서는 방정식의 근이 양수, 실수 같은 문제의 조건을 만족하는지 마지막에 꼭 확인한다. 또 \(x^2\)의 계수가 1이 아니어도 되므로 같은 두 수를 근으로 하는 방정식은 \(2(x^2 - sx + p) = 0\)처럼 여러 개이다.
