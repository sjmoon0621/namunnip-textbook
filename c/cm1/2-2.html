이차방정식의 판별식

근의 공식에서 √ 안의 값이 음수가 되면 실수 범위에서는 근이 없습니다. 하지만 복소수까지 수를 넓히면 그 이차방정식도 근을 갖습니다. 이 절에서는 √ 안의 값 b2 − 4ac 하나로 근이 실근인지 허근인지, 서로 다른지 같은지를 판별하고, 계수를 바꿀 때 두 실근이 만나 허근으로 갈라지는 모습을 봅니다.

2.2.1

근의 공식의 √ 안이 음수이면 근이 없는 걸까?

판별식 · 실근과 허근

—

판별식 D = b2 − 4ac
—
근의 종류
—
근
—

그래프는 y = ax2 + bx + c입니다. 실근은 그래프가 x축과 만나는 점으로 보이지만, 허근은 그래프에 나타나지 않습니다.

  1. 질문x2 − 2x + 5 = 0을 근의 공식에 넣으면 x = (2 ± √−16)/2가 됩니다. √ 안이 음수이면 이 방정식은 근이 없다고 해야 할까요?
  2. 복원ax2 + bx + c = 0(a ≠ 0)을 완전제곱식으로 고치면 (x + b/2a)2 = (b2 − 4ac)/4a2이고, 여기서 근의 공식 x = (−b ± √(b2 − 4ac))/2a가 나옵니다. 음수 −k의 제곱근은 ±√k i입니다.
  3. 설명복소수 범위에서는 √−16 = 4i이므로 x = 1 ± 2i입니다. 실수인 근을 실근, 허수인 근을 허근이라 합니다. 근이 어떤 수인지는 √ 안의 값 D = b2 − 4ac가 정하므로 이것을 판별식이라 합니다. 계수가 실수일 때 D > 0이면 서로 다른 두 실근, D = 0이면 중근(서로 같은 두 실근), D < 0이면 서로 다른 두 허근을 가집니다. b = 2b′처럼 일차항의 계수가 짝수이면 D/4 = b′2 − ac로 계산해도 부호가 같습니다.
  4. 연결어떤 경우든 근의 공식으로 근이 나오므로, 계수가 실수인 이차방정식은 복소수 범위에서 항상 근을 가집니다(중근은 두 번 셉니다). D < 0일 때 두 허근 p + qi, p − qi는 서로 켤레복소수입니다. D의 부호는 그래프가 x축과 만나는 점의 개수와도 이어집니다.
  5. 적용세 번째 예(x2 − 2x + 5)에서 c를 줄이며 D가 0이 되는 c를 찾으세요. 그때 그래프는 x축과 어떻게 만나나요? c를 더 줄이면 근은 어떻게 바뀌나요? a를 음수로 바꾸어도 같은 판별이 통하는지, a = 0이면 무엇이 달라지는지 보세요.
  6. 판단"D < 0이면 근이 없다"는 실수 범위에서만 맞는 말입니다. 복소수 범위에서는 두 허근이 있습니다. 또 판별식으로 근을 가르는 방법은 계수가 실수인 이차방정식에만 씁니다. a = 0이면 이차방정식이 아니므로 판별식을 쓰지 않습니다. 실근을 가질 조건은 D ≥ 0입니다. 중근도 실근입니다.

2.2.2

두 실근이 허근으로 바뀌는 순간 무슨 일이 생길까?

판별식 · 켤레인 두 허근
판별식 D
—
두 근
—
두 근의 합 · 곱
—

오른쪽 평면의 가로는 실수부분, 세로는 허수부분입니다. 회색 선은 c가 −4에서 6까지 변할 때 두 근이 지나는 길입니다.

  1. 질문x2 − 2x + c = 0에서 c를 조금씩 키우면 두 실근은 어떻게 움직일까요? D가 0을 지나 음수가 되는 순간, 근이 갑자기 사라지는 걸까요?
  2. 복원근의 공식으로 x = −b/2 ± √D/2(D = b2 − 4c)입니다. D < 0이면 √D = √(−D) i입니다.
  3. 설명두 근의 가운데는 언제나 −b/2이고, 가운데에서 떨어진 거리는 √D/2입니다. c가 커지면 D가 줄어 두 실근이 가운데로 모이고, D = 0에서 하나(중근)로 만납니다. D < 0이 되면 떨어진 거리가 허수 √(−D)/2 · i가 되어, 두 근은 실수축을 벗어나 위아래로 갈라집니다. 이때 두 근은 −b/2 + qi, −b/2 − qi로 서로 켤레복소수입니다. 근은 사라지지 않고 실수가 아닌 곳으로 옮겨 갈 뿐입니다.
  4. 연결근이 어디에 있든 두 근의 합은 −b, 곱은 c로 계수와 같습니다. 이 관계는 다음 절의 근과 계수의 관계입니다. 또 근의 가운데 −b/2는 포물선의 축이므로, 허근의 실수부분도 그래프에서 읽을 수 있습니다.
  5. 적용c를 −4에서 6까지 천천히 움직이며 오른쪽 점 두 개가 어디서 만나고 어느 방향으로 갈라지는지 보세요. b를 바꾸면 만나는 자리는 어디로 옮겨 가나요? 근이 어디에 있든 "두 근의 합"이 바뀌지 않는지 확인하세요.
  6. 판단허근이 켤레로 짝지어 나오는 것은 계수가 모두 실수이기 때문입니다. 계수에 허수가 있으면 짝이 맞지 않을 수 있지만, 고등학교에서는 계수가 실수인 경우만 다룹니다. 복소수를 평면의 점으로 나타내는 것은 이해를 돕는 그림이고, 허근의 크기를 비교한다는 뜻은 아닙니다.
