이차방정식의 판별식

본문

이차방정식 \(x^2 - 2x + c = 0\)은 \(c\)가 얼마일 때 서로 다른 두 실근을 갖고, 언제 근이 하나로 겹치며, 언제 실근이 사라질까? 근의 공식의 어느 부분이 이것을 결정할까?

먼저 알아야 할 것중학교의 근의 공식과 완전제곱식, 복소수와 음수의 제곱근(복소수).

2.2.1근의 공식에서 근호 안을 보기

이차방정식 \(ax^2 + bx + c = 0\ (a \ne 0)\)의 근은 \(x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}\)이다. 이 식에서 \(a\), \(b\)는 그냥 계산하면 되는 수이지만, 근호 안의 \(b^2 - 4ac\)는 사정이 다르다. 근호 안이 양수이면 실수의 제곱근이 두 개 나오고, 0이면 \(\pm\)가 같은 값을 주며, 음수이면 실수 범위에서 계산할 수 없다.

복소수를 배운 지금은 근호 안이 음수여도 계산이 멈추지 않는다. 가령 \(\sqrt{-4} = 2i\)이므로 근은 허수가 된다. 따라서 이차방정식은 복소수 범위에서 언제나 근을 갖고, 근호 안의 부호는 그 근이 실수인지 허수인지를 가른다.

2.2.2판별식

정의 2.2.1 판별식

계수가 실수인 이차방정식 \(ax^2 + bx + c = 0\)에서 \(D = b^2 - 4ac\)를 판별식이라 한다.

\(D > 0\)이면 서로 다른 두 실근, \(D = 0\)이면 중근(서로 같은 두 실근), \(D < 0\)이면 서로 다른 두 허근을 갖는다.

정의의 세 경우는 1에서 근호 안을 보며 한 이야기를 그대로 옮긴 것이다. 근의 공식을 끝까지 계산하지 않고 \(D\)의 부호만 보면 근의 종류를 알 수 있으므로, '판별'식이라는 이름이 붙었다. \(b\)가 짝수 \(2b'\)이면 \(D = 4(b'^2 - ac)\)이므로 \(\dfrac{D}{4} = b'^2 - ac\)의 부호만 보아도 된다.

그림 1의 \(x^2 - 2x + c = 0\)에서 \(\dfrac{D}{4} = 1 - c\)이다. 그러면 \(c < 1\)일 때 두 실근, \(c = 1\)일 때 중근, \(c > 1\)일 때 두 허근이다. 슬라이더로 \(c\)를 키우면 포물선이 위로 올라가다가 \(c = 1\)에서 \(x\)축에 닿고, 그 뒤로는 \(x\)축과 만나지 않는다.1

2.2.3완전제곱식으로 보는 이유

근의 공식은 완전제곱식에서 나왔으므로, 판별식이 무엇을 재는지도 그 과정에서 보인다. \(ax^2 + bx + c = 0\)의 양변을 \(a\)로 나누고 정리하면 \(\left(x + \dfrac{b}{2a}\right)^2 = \dfrac{b^2 - 4ac}{4a^2}\)이다.

여기서 좌변은 어떤 수의 제곱이다. 우변의 분모 \(4a^2\)은 언제나 양수이므로 우변의 부호는 \(D\)의 부호와 같다. 즉 \(D > 0\)이면 제곱해서 양수가 되는 수는 두 개, \(D = 0\)이면 제곱해서 0이 되는 수는 0 하나, \(D < 0\)이면 제곱해서 음수가 되는 실수는 없다. 판별식은 '어떤 수의 제곱이 얼마여야 하는가'를 묻는 셈이다.

그림 2는 이 세 경우를 그래프로 나란히 놓은 것이다. 이차방정식의 실근은 \(y = ax^2 + bx + c\)의 그래프가 \(x\)축과 만나는 점의 \(x\)좌표이므로, 실근의 개수가 곧 교점의 개수이다. 이 연결은 뒤의 '이차방정식과 이차함수'에서 다시 쓴다.

2.2.4예제 하나를 끝까지

예제 2.2.2

이차방정식 \(x^2 + 2(k - 1)x + k^2 - 3 = 0\)이 서로 다른 두 실근을 갖도록 하는 실수 \(k\)의 값의 범위를 구하여라. 또 중근을 가질 때의 근을 구하여라.

\(x\)의 계수가 짝수 꼴이므로 \(\dfrac{D}{4}\)를 쓴다. \(b' = k - 1\)이므로 \(\dfrac{D}{4} = (k - 1)^2 - (k^2 - 3) = k^2 - 2k + 1 - k^2 + 3 = -2k + 4\)이다.

서로 다른 두 실근을 가지려면 \(-2k + 4 > 0\)이어야 하므로 \(k < 2\)이다. 중근을 가지려면 \(-2k + 4 = 0\), 곧 \(k = 2\)이다. 이때 방정식은 \(x^2 + 2x + 1 = 0\), 즉 \((x + 1)^2 = 0\)이므로 중근은 \(x = -1\)이다.

답이 맞는지 \(k\)를 하나 골라 보자. \(k = 0\)이면 방정식은 \(x^2 - 2x - 3 = 0\)이고 \((x + 1)(x - 3) = 0\)이므로 실근 두 개가 나온다. \(k = 3\)이면 \(x^2 + 4x + 6 = 0\)이고 \(\dfrac{D}{4} = 4 - 6 = -2 < 0\)이므로 허근이다. 범위의 경계 \(k = 2\)를 지나며 근의 종류가 바뀌는 모습은 그림 1에서 \(c\)가 1을 지날 때와 같다. 아래 탐구 카드에서 계수를 바꾸며 근이 움직이는 길을 직접 따라가 보자.

  1. 판별식으로 근을 실근과 허근으로 나누는 것은 계수가 실수일 때만 뜻이 있다. 계수에 허수가 있으면 \(D\)가 실수가 아닐 수 있다.
마무리

근의 공식에서 근호 안의 \(D = b^2 - 4ac\)는 '제곱해서 얼마가 되어야 하는가'를 정하므로, 그 부호만으로 두 실근, 중근, 두 허근을 가를 수 있다. 처음 질문의 \(x^2 - 2x + c = 0\)은 \(\tfrac{D}{4} = 1 - c\)이므로 \(c < 1\)이면 두 실근, \(c = 1\)이면 중근, \(c > 1\)이면 두 허근을 갖는다.

그래프는 \(y = ax^2 + bx + c\)이다. 실근은 그래프가 \(x\)축과 만나는 점으로 보이지만, 허근은 그래프에 나타나지 않는다.

  1. 질문\(x^2 - 2x + 5 = 0\)을 근의 공식에 넣으면 \(x = (2 \pm \sqrt{-16})/2\)가 된다. √ 안이 음수이면 이 방정식은 근이 없다고 해야 할까?
  2. 복원\(ax^2 + bx + c = 0(a \ne 0)\)을 완전제곱식으로 고치면 \((x + b/2a)^2 = (b^2 - 4ac)/4a^2\)이고, 여기서 근의 공식 \(x = (-b \pm \sqrt{b^2 - 4ac})/2a\)가 나온다. 또 음수 \(-k\)의 제곱근은 \(\pm\sqrt{k} i\)이다.
  3. 설명그러면 복소수 범위에서는 \(\sqrt{-16} = 4i\)이므로 \(x = 1 \pm 2i\)이다. 실수인 근을 실근, 허수인 근을 허근이라 한다. 그런데 근이 어떤 수인지는 √ 안의 값 \(D = b^2 - 4ac\)가 정하므로, 이것을 판별식이라 한다. 계수가 실수일 때 \(D > 0\)이면 서로 다른 두 실근, \(D = 0\)이면 중근(서로 같은 두 실근), \(D < 0\)이면 서로 다른 두 허근을 가진다. \(b = 2b'\)처럼 일차항의 계수가 짝수이면 \(D/4 = b'^2 - ac\)로 계산해도 부호가 같다.
  4. 연결어떤 경우든 근의 공식으로 근이 나오므로, 계수가 실수인 이차방정식은 복소수 범위에서 항상 근을 가진다(중근은 두 번 센다). 특히 \(D < 0\)일 때 두 허근 \(p + qi\), \(p - qi\)는 서로 켤레복소수이다. 또 \(D\)의 부호는 그래프가 \(x\)축과 만나는 점의 개수와도 이어진다.
  5. 적용세 번째 예 \(x^2 - 2x + 5\)에서 \(c\)를 줄이며 \(D\)가 0이 되는 \(c\)를 찾아보자. 그때 그래프는 \(x\)축에 한 점에서 닿고, \(c\)를 더 줄이면 근이 서로 다른 두 실근으로 갈라진다. 이어서 \(a\)를 음수로 바꾸어도 같은 판별이 통하는지, \(a = 0\)이면 무엇이 달라지는지도 살펴보자.
  6. 판단"\(D < 0\)이면 근이 없다"는 실수 범위에서만 맞는 말이고, 복소수 범위에서는 두 허근이 있다. 또 판별식으로 근을 가르는 방법은 계수가 실수인 이차방정식에만 쓴다. \(a = 0\)이면 이차방정식이 아니므로 판별식을 쓰지 않는다. 실근을 가질 조건은 \(D \ge 0\)이며, 중근도 실근에 들어간다.

두 실근이 허근으로 바뀌는 순간 무슨 일이 생길까?

두 근의 합 · 곱
—

오른쪽 평면의 가로는 실수부분, 세로는 허수부분이다. 회색 선은 \(c\)가 \(-4\)에서 6까지 변할 때 두 근이 지나는 길이다.

  1. 질문\(x^2 - 2x + c = 0\)에서 \(c\)를 조금씩 키우면 두 실근은 어떻게 움직일까? \(D\)가 0을 지나 음수가 되는 순간, 근이 갑자기 사라지는 걸까?
  2. 복원근의 공식으로 \(x = -b/2 \pm \sqrt{D}/2(D = b^2 - 4c)\)이다. 또 \(D < 0\)이면 \(\sqrt{D} = \sqrt{-D} i\)이다.
  3. 설명이 식에서 두 근의 가운데는 언제나 \(-b/2\)이고, 가운데에서 떨어진 거리는 \(\sqrt{D}/2\)이다. 그래서 \(c\)가 커지면 \(D\)가 줄어 두 실근이 가운데로 모이고, \(D = 0\)에서 하나(중근)로 만난다. \(D < 0\)이 되면 떨어진 거리가 허수 \(\sqrt{-D}/2 \cdot i\)가 되어, 두 근은 실수축을 벗어나 위아래로 갈라진다. 이때 두 근은 \(-b/2 + qi\), \(-b/2 - qi\)로 서로 켤레복소수이다. 즉 근은 사라지지 않고 실수가 아닌 곳으로 옮겨 갈 뿐이다.
  4. 연결근이 어디에 있든 두 근의 합은 \(-b\), 곱은 \(c\)로 계수와 같다. 이 관계가 다음 절의 근과 계수의 관계이다. 또 근의 가운데 \(-b/2\)는 포물선의 축이므로, 허근의 실수부분도 그래프에서 읽을 수 있다.
  5. 적용\(c\)를 \(-4\)에서 6까지 천천히 움직이며 오른쪽 점 두 개가 \(c = 1\)에서 만나 위아래로 갈라지는 것을 보자. \(b\)를 바꾸면 만나는 자리가 \(-b/2\)로 옮겨 간다. 근이 어디에 있든 두 근의 합이 바뀌지 않는다는 것도 확인해 보자.
  6. 판단허근이 켤레로 짝지어 나오는 것은 계수가 모두 실수이기 때문이다. 계수에 허수가 있으면 짝이 맞지 않을 수 있지만, 고등학교에서는 계수가 실수인 경우만 다룬다. 또 복소수를 평면의 점으로 나타내는 것은 이해를 돕는 그림일 뿐이고, 허근의 크기를 비교한다는 뜻은 아니다.
