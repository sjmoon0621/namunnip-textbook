복소수

제곱해서 \(-1\)이 되는 실수는 없습니다. 그래서 \(x^2 = -1\) 같은 방정식은 실수 범위에서 풀리지 않습니다. 이 절에서는 제곱하면 \(-1\)이 되는 새로운 수 \(i\)를 약속하고, \(a + bi\) 꼴의 복소수로 수의 범위를 넓힙니다. 넓힌 수에서도 실수에서 쓰던 계산 법칙이 그대로 통하는지 직접 계산해 보고, 나눗셈은 켤레복소수로 해결합니다.

2.1.1

제곱해서 \(-1\)이 되는 수에 \(i\)를 계속 곱하면 어디로 갈까?

허수단위 · 복소수의 뜻
곱한 횟수 \(n\)
0
\(i^n\)
1
처음 수 \(\times i^n\)
1

—

가로 위치는 실수부분, 세로 위치는 허수부분입니다. 이런 평면(복소평면)은 교육과정 밖이지만, 계산 결과를 한눈에 비교하는 데 씁니다.

  1. 질문실수는 제곱하면 0 이상이므로 \(x^2 = -1\)을 만족하는 실수는 없습니다. 그래도 이 방정식의 해가 되는 수를 하나 약속하면 무슨 일이 생길까요?
  2. 복원양수 \(a\)의 제곱근은 \(\pm\sqrt{a}\)이고, \(\sqrt{a} \times \sqrt{a} = a\)입니다. 다항식은 같은 문자끼리 묶어 계산하고, 문자에 수를 넣어 값을 구합니다.
  3. 설명제곱해서 \(-1\)이 되는 수를 허수단위 \(i\)라 하고 \(i^2 = -1\), \(i = \sqrt{-1}\)로 씁니다. 양수 \(a\)에 대해 \(\sqrt{-a} = \sqrt{a} i\)이므로 \(-a\)의 제곱근은 \(\pm\sqrt{a} i\)입니다. 실수 \(a\), \(b\)로 \(a + bi\) 꼴로 나타낸 수를 복소수라 하고, \(a\)를 실수부분, \(b\)를 허수부분이라 합니다. \(b = 0\)이면 실수이고, \(b \ne 0\)이면 허수, 특히 \(a = 0\), \(b \ne 0\)이면 순허수입니다. 두 복소수는 실수부분끼리, 허수부분끼리 각각 같을 때만 서로 같습니다. \(a + bi = c + di \Leftrightarrow a = c\), \(b = d\)입니다.
  4. 연결\(i\)를 곱할 때마다 \(i^2 = -1\)을 써서 정리하면 \(i\), \(-1\), \(-i\), 1이 차례로 되풀이됩니다. 그래서 \(i^n\)은 \(n\)을 4로 나눈 나머지만 알면 됩니다. 이 수를 쓰면 실수 범위에서 풀리지 않던 이차방정식도 근을 갖게 되고, 다음 절의 허근으로 이어집니다.
  5. 적용처음 수 1에서 "\(\times i\)"를 네 번 눌러 처음 자리로 돌아오는지 보세요. 처음 수를 \(2 + i\)로 바꾸고 한 번 누르면 \((2 + i)i = 2i + i^2 = -1 + 2i\)가 나오는지 확인하세요. 점은 원점을 중심으로 몇 도씩 돌아가나요?
  6. 판단\(\sqrt{a}\sqrt{b} = \sqrt{ab}\)는 \(a\), \(b\)가 둘 다 음수일 때는 성립하지 않습니다. \(\sqrt{-2} \times \sqrt{-3} = \sqrt{2}i \times \sqrt{3}i = \sqrt{6}i^2 = -\sqrt{6}\)이지, \(\sqrt{6}\)이 아닙니다. 음수의 제곱근은 먼저 \(i\)를 꺼낸 뒤 계산하세요. 또 허수에는 크기 순서가 없습니다. "\(i > 0\)"이나 "\(2i > i\)"는 참도 거짓도 아닌, 정할 수 없는 문장입니다.

2.1.2

복소수로 나눗셈은 어떻게 할까?

복소수의 사칙연산 · 켤레복소수

—

\(z\)
—
\(w\)
—
결과
—

\(z\) \(w\) 결과 · 점선은 켤레복소수 \(\overline{z}\)

  1. 질문\((1 + 2i) + (1 - i)\)나 \((1 + 2i)(1 - i)\)는 \(i\)를 문자처럼 두고 계산하면 됩니다. 그런데 \((1 + 2i) \div (1 - i)\)는 어떻게 \(a + bi\) 꼴로 만들까요?
  2. 복원실수의 덧셈과 곱셈에는 교환법칙, 결합법칙, 분배법칙이 성립합니다. 분모에 \(1 + \sqrt{2}\)가 있으면 \(1 - \sqrt{2}\)를 분모와 분자에 곱해 분모를 유리수로 만들었습니다.
  3. 설명복소수도 \(i\)를 문자처럼 계산하고 \(i^2\)은 \(-1\)로 바꿉니다. \((a + bi) \pm (c + di) = (a \pm c) + (b \pm d)i\), \((a + bi)(c + di) = (ac - bd) + (ad + bc)i\)입니다. \(z = a + bi\)에서 허수부분의 부호만 바꾼 \(a - bi\)를 켤레복소수라 하고 \(\overline{z}\)로 씁니다. \(z + \overline{z} = 2a\), \(z \overline{z} = a^2 + b^2\)으로 둘 다 실수입니다. 그래서 나눗셈은 분모의 켤레복소수를 분모와 분자에 곱해 분모를 실수로 만듭니다. \((a + bi)/(c + di)\) = {\((ac + bd) + (bc - ad)i\)}/\((c^2 + d^2)\)입니다(단, \(c + di \ne 0\)).
  4. 연결켤레복소수로 나누는 방법은 분모의 유리화와 같은 생각입니다. 복소수끼리 더하고 빼고 곱하고 (0이 아닌 수로) 나눈 결과는 다시 복소수이므로, 실수에서 쓰던 계산 법칙을 그대로 쓸 수 있습니다. 켤레복소수는 계수가 실수인 이차방정식의 두 허근으로 다시 나옵니다.
  5. 적용"\(z \div w\)"를 고르고 \(z = 1 + 2i\), \(w = 1 - i\)로 두어 결과를 읽으세요. 그다음 "\(z \times \overline{z}\)"를 고르고 \(a\), \(b\)를 움직여 결과 점이 늘 실수축 위에 있는지 보세요. 결과가 0이 되는 것은 언제인가요? \(w\)를 0으로 만들면 나눗셈은 어떻게 되나요?
  6. 판단나눗셈에서 실수부분끼리, 허수부분끼리 따로 나누면 안 됩니다. \((1 + 2i)/(1 - i)\)는 \(1/1 + (2/-1)i = 1 - 2i\)가 아닙니다. 곱해 보면 \((1 - 2i)(1 - i) = -1 - 3i\)로 \(1 + 2i\)가 나오지 않습니다. 계산이 끝나면 결과에 \(w\)를 곱해 \(z\)로 돌아오는지 검산하세요.
