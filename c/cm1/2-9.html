연립일차부등식

부등식은 등식과 거의 같은 방법으로 풀지만, 음수를 곱하거나 나눌 때 부등호의 방향이 바뀝니다. 이 절에서는 그 이유를 그래프로 확인하고, 부등식 두 개를 함께 만족하는 범위를 수직선 위의 공통부분으로 찾습니다. 해가 한 점이거나 아예 없는 경우도 살펴봅니다.

  1. 질문−2x > 4를 풀 때 양변을 −2로 나누면 x > −2일까요, x < −2일까요? x = 0을 넣어 보면 어느 쪽이 맞는지 알 수 있습니다.
  2. 복원부등식의 성질: 양변에 같은 수를 더하거나 빼도, 양수를 곱하거나 나누어도 부등호 방향은 그대로입니다. 음수를 곱하거나 나누면 방향이 바뀝니다. 예를 들어 2 < 3인데 −2 > −3입니다.
  3. 설명일차부등식은 이항해서 ax > b 꼴로 정리한 뒤 a로 나눕니다. a > 0이면 x > b/a, a < 0이면 x < b/a입니다. a = 0이면 0 · x > b가 되어, b < 0이면 모든 실수가 해이고 b ≥ 0이면 해가 없습니다. 그림에서 ax > b의 해는 직선 y = ax가 수평선 y = b보다 위에 있는 x의 범위입니다.
  4. 연결직선의 기울기 a가 음수이면 x가 커질수록 ax가 작아집니다. 그래서 'b보다 큰' 쪽이 경계의 왼쪽이 되고, 이것이 부등호 방향이 바뀌는 이유입니다. 이 성질은 연립부등식, 절댓값 부등식, 이차부등식을 풀 때 모두 쓰입니다.
  5. 적용부등호를 >로 두고 a를 양수에서 음수로 넘겨 보세요. 해가 경계의 어느 쪽으로 옮겨 가나요? a = 0에서 b를 −1, 0, 1로 바꾸면 해는 어떻게 되나요? >와 ≥를 바꾸면 수직선의 경계 점이 어떻게 달라지나요?
  6. 판단문자 계수로 나눌 때 가장 많이 틀립니다. ax > b를 곧바로 x > b/a로 쓰면 a < 0이거나 a = 0인 경우를 놓칩니다. 계수의 부호를 모르면 a > 0, a = 0, a < 0으로 나누어 풀어야 합니다.

연립부등식의 해
—
  1. 질문2x − 1 > 3과 x + 4 ≤ 9를 동시에 만족하는 x는 어떤 범위일까요? 두 해를 '또는'으로 합칠까요, '그리고'로 겹칠까요?
  2. 복원일차부등식은 이항해서 ax > b 꼴로 정리한 뒤 a로 나누어 풉니다. a가 음수이면 부등호 방향이 바뀝니다. 수직선에서 경계를 포함하면 색칠한 점(●), 포함하지 않으면 빈 점(○)으로 나타냅니다.
  3. 설명부등식 두 개 이상을 한 쌍으로 묶은 것을 연립부등식이라 하고, 모두 일차부등식이면 연립일차부등식이라 합니다. 연립부등식의 해는 각 부등식의 해의 공통부분입니다. 순서는 ① 각 부등식을 따로 풀고 ② 해를 한 수직선 위에 나타낸 뒤 ③ 겹치는 부분을 읽습니다. 2x − 1 > 3에서 x > 2, x + 4 ≤ 9에서 x ≤ 5이므로 해는 2 < x ≤ 5입니다.
  4. 연결A < B < C 꼴의 부등식은 A < B와 B < C를 함께 만족한다는 뜻이므로 연립부등식 {A < B, B < C}로 풉니다. 공통부분을 찾는 이 방법은 이차부등식이 섞인 연립부등식에서도 그대로 쓰입니다.
  5. 적용다섯 예를 차례로 눌러 해가 구간, 한 점, 공집합이 되는 경우를 확인하세요. 세 번째 예에서 ①의 부등호를 ≥에서 >로 바꾸면 해는 어떻게 되나요? 두 부등호가 같은 쪽(>, >)을 향하면 공통부분은 어느 경계가 정하나요?
  6. 판단A < B < C를 A < C로 풀면 틀립니다. A < C는 B를 거치지 않은 다른 부등식입니다. 또 공통부분이 없으면 '해가 없다'고 답해야 하며, 두 해를 이어 붙인 범위를 답으로 쓰면 안 됩니다.
