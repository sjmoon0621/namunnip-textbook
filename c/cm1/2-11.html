이차부등식

이차부등식 \(x^2 - x - 6 < 0\)의 해는 이차함수 \(y = x^2 - x - 6\)의 그래프가 \(x\)축보다 아래에 있는 \(x\)의 범위입니다. 이 절에서는 계수를 바꾸며 그래프와 \(x\)축의 위치에서 해를 읽고, 판별식에 따라 해가 어떻게 달라지는지 정리합니다. 마지막으로 이차부등식이 섞인 연립부등식을 공통부분으로 풉니다.

2.11.1

이차부등식의 해는 그래프의 어디에 있을까?

이차부등식 · 이차함수와 판별식

—

판별식 \(D\)
—
그래프와 \(x\)축
—
해
—
  1. 질문\(x^2 - x - 6 > 0\)을 만족하는 \(x\)는 어떤 범위일까요? 이차방정식 \(x^2 - x - 6 = 0\)의 근 \(-2\), 3은 해와 어떤 관계일까요?
  2. 복원이차방정식 \(ax^2 + bx + c = 0\)의 실근은 이차함수 \(y = ax^2 + bx + c\)의 그래프가 \(x\)축과 만나는 점의 \(x\)좌표입니다. 판별식 \(D = b^2 - 4ac\)가 양수, 0, 음수이면 그래프는 \(x\)축과 각각 두 점에서 만나고, 접하고, 만나지 않습니다.
  3. 설명이차부등식 \(ax^2 + bx + c > 0\)의 해는 그래프가 \(x\)축보다 위에 있는 \(x\)의 범위이고, \(< 0\)의 해는 아래에 있는 범위입니다. \(a > 0\)이고 두 근이 \(\alpha < \beta\)이면 \((x - \alpha)(x - \beta) > 0\)의 해는 \(x < \alpha\) 또는 \(x > \beta\), \((x - \alpha)(x - \beta) < 0\)의 해는 \(\alpha < x < \beta\)입니다. \(D = 0\)이면 그래프가 \(x\)축에 접하므로 \(x\)축 아래로 내려가지 않습니다. 그래서 \(> 0\)의 해는 접점만 뺀 모든 실수, \(< 0\)의 해는 없습니다. \(D < 0\)이면 그래프가 늘 \(x\)축 위에 있어서 \(> 0\)의 해는 모든 실수, \(< 0\)의 해는 없습니다. \(a < 0\)이면 양변에 \(-1\)을 곱해 \(a > 0\)으로 바꾸고 부등호 방향도 바꿉니다.
  4. 연결질문의 식은 \((x + 2)(x - 3) > 0\)이므로 해는 \(x < -2\) 또는 \(x > 3\)입니다. 방정식의 근은 해의 경계가 됩니다. 모든 실수 \(x\)에 대하여 \(ax^2 + bx + c > 0\)이 성립하려면 그래프 전체가 \(x\)축 위에 있어야 하므로 \(a > 0\)이고 \(D < 0\)이어야 합니다.
  5. 적용\(c\)를 키우면서 판별식이 양수에서 0, 음수로 바뀔 때 네 부등호의 해가 각각 어떻게 바뀌는지 확인하세요. \(a = -1\)을 고르면 \(> 0\)의 해는 두 근의 바깥과 안쪽 중 어디에 있나요? \(b = 2\), \(c = 1\)로 두고 \(\le 0\)과 \(< 0\)의 해를 비교하세요.
  6. 판단"\(> 0\)이면 해는 두 근 바깥"이라고 외우면 \(a < 0\)일 때 틀립니다. 위로 볼록한 그래프에서는 \(> 0\)의 해가 두 근 사이입니다. 또 근이 허수일 때 "해가 없다"고 단정하면 안 됩니다. \(D < 0\)이고 \(a > 0\)이면 \(> 0\)의 해는 오히려 모든 실수입니다.

2.11.2

이차부등식이 섞인 연립부등식은 어떻게 풀까?

연립이차부등식 · 공통부분

—

①의 해
—
②의 해
—
공통부분
—
  1. 질문\(x^2 - x - 6 \le 0\)과 \(x^2 - 4x > 0\)을 동시에 만족하는 \(x\)의 범위는 어떻게 구할까요?
  2. 복원연립부등식의 해는 각 부등식의 해의 공통부분입니다. 이차부등식은 그래프가 \(x\)축보다 위나 아래에 있는 범위로 풀고, 근이 해의 경계가 됩니다.
  3. 설명연립부등식 가운데 차수가 가장 높은 부등식이 이차부등식이면 연립이차부등식이라고 합니다. 푸는 순서는 연립일차부등식과 같습니다. ① \(x^2 - x - 6 \le 0\)은 \((x + 2)(x - 3) \le 0\)이므로 \(-2 \le x \le 3\)입니다. ② \(x^2 - 4x > 0\)은 \(x(x - 4) > 0\)이므로 \(x < 0\) 또는 \(x > 4\)입니다. 두 해를 수직선에 겹치면 공통부분은 \(-2 \le x < 0\)입니다.
  4. 연결이차부등식의 해는 구간 하나일 수도, 둘로 떨어질 수도 있습니다. 그래서 공통부분도 두 조각이 될 수 있습니다. 이 방법은 '삼각형의 세 변이 될 조건'이나 '넓이가 일정 범위에 들도록 하는 길이'처럼 조건이 여러 개인 문제를 풀 때 그대로 쓰입니다.
  5. 적용②의 \(c\)를 바꾸어 ②의 해가 두 조각, 모든 실수, 해 없음이 되는 경우를 만들고 공통부분이 어떻게 변하는지 보세요. ①로 \(x^2 - 4 > 0\)을 고르고 ②를 <로 바꾸면 공통부분이 두 조각이 되는 \(b\), \(c\)를 찾을 수 있나요?
  6. 판단두 해를 '또는'으로 합치면 안 됩니다. 연립부등식은 두 조건을 모두 만족해야 하므로 겹치는 곳만 해입니다. 경계값은 두 부등식에서 모두 허용될 때만 해에 넣습니다. 예를 들어 \(x = 0\)은 ①을 만족하지만 ②에서 \(0 > 0\)이 거짓이라 빠집니다.
