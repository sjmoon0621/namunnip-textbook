이차부등식

이차부등식 \(x^2 - x - 6 < 0\)의 해는 이차함수 \(y = x^2 - x - 6\)의 그래프가 \(x\)축보다 아래에 있는 \(x\)의 범위입니다. 이 절에서는 계수를 바꾸며 그래프와 \(x\)축의 위치에서 해를 읽고, 판별식에 따라 해가 어떻게 달라지는지 정리합니다. 마지막으로 이차부등식이 섞인 연립부등식을 공통부분으로 풉니다.

먼저 알면 좋은 것 이차방정식과 이차함수판별식연립일차부등식

2.11.1부호를 그래프로 읽기

정리하면 \(-5t^2 + 20t - 15 > 0\)이고, 양변을 \(-5\)로 나누면 부등호가 뒤집혀 \(t^2 - 4t + 3 < 0\)이다. 이차식의 값이 음수인 \(t\)를 찾는 문제가 되었다.

그림 1의 슬라이더를 \(k = 3\)에 두면 \(y = x^2 - 4x + 3\)의 그래프가 보인다. 그래프는 \(x = 1\)과 \(x = 3\)에서 \(x\)축과 만나고, 그 사이에서는 \(x\)축보다 아래에 있다. \(y\)좌표가 음수라는 것은 이차식의 값이 음수라는 뜻이므로, \(x^2 - 4x + 3 < 0\)의 해는 \(1 < x < 3\)이다. 처음 질문의 공은 1초부터 3초까지 15 m보다 높이 있다.

이렇게 이차식을 포함한 부등식 가운데 정리했을 때 \(ax^2 + bx + c > 0\)꼴이 되는 것을 이차부등식이라 한다(부등호는 \(<, \ge, \le\)도 된다). 이차방정식의 근이 \(x\)축과의 교점이었다면, 이차부등식의 해는 그래프가 \(x\)축의 위나 아래에 있는 범위이다.

2.11.2판별식에 따른 세 경우

\(a > 0\)인 이차식 \(ax^2 + bx + c\)의 그래프는 아래로 볼록하다. 판별식이 양수이면 두 근 \(\alpha < \beta\)에서 \(x\)축을 가로지르므로, 두 근 사이에서는 음수이고 바깥에서는 양수이다. 슬라이더로 \(k\)를 4로 올리면 그래프가 \(x\)축에 접하고, 그보다 올리면 \(x\)축보다 완전히 위로 떠서 음수인 곳이 사라진다.

정리 2.11.1 이차부등식의 해 (\(a > 0\))
\(D > 0\) (두 근 \(\alpha < \beta\))\(D = 0\) (중근 \(\alpha\))\(D < 0\)
\(ax^2 + bx + c > 0\)\(x < \alpha\) 또는 \(x > \beta\)\(x \ne \alpha\)인 모든 실수모든 실수
\(ax^2 + bx + c \ge 0\)\(x \le \alpha\) 또는 \(x \ge \beta\)모든 실수모든 실수
\(ax^2 + bx + c < 0\)\(\alpha < x < \beta\)해가 없다해가 없다
\(ax^2 + bx + c \le 0\)\(\alpha \le x \le \beta\)\(x = \alpha\)해가 없다

그런데 이 표를 외울 필요는 없다. 표의 칸마다 그림 1의 그래프를 떠올리고 '\(x\)축 위인가, 아래인가'만 물으면 된다. \(a < 0\)이면 양변에 \(-1\)을 곱해 \(a > 0\)으로 바꾸어 생각한다.1

2.11.3예제 하나를 끝까지

예제 2.11.2

모든 실수 \(x\)에 대하여 \(x^2 - 2kx + 2k + 3 > 0\)이 성립하도록 하는 실수 \(k\)의 값의 범위를 구하여라. 또 연립부등식 \(\begin{cases} x^2 - x - 6 \le 0 \\ x^2 - 4x > 0 \end{cases}\)을 풀어라.

최고차항 계수가 양수이므로, 모든 \(x\)에서 양수이려면 그래프가 \(x\)축보다 완전히 위에 있어야 한다. 즉 \(x\)축과 만나지 않아야 하므로 \(\dfrac{D}{4} = k^2 - (2k + 3) < 0\)이다. \(k^2 - 2k - 3 = (k + 1)(k - 3) < 0\)이므로 \(-1 < k < 3\)이다. 접하는 경우(\(D = 0\))에는 접점에서 값이 0이 되어 '\(> 0\)'이 깨지므로 등호는 들어가지 않는다.

이제 연립부등식은 각각 푼다. \(x^2 - x - 6 = (x + 2)(x - 3) \le 0\)에서 \(-2 \le x \le 3\)이다. \(x^2 - 4x = x(x - 4) > 0\)에서 \(x < 0\) 또는 \(x > 4\)이다. 따라서 두 해를 수직선에 겹치면 공통부분은 \(-2 \le x < 0\)이다.

그러면 값 하나로 확인해 보자. \(x = -1\)이면 \(1 + 1 - 6 = -4 \le 0\)이고 \(1 + 4 = 5 > 0\)이므로 두 부등식을 모두 만족한다. \(x = 1\)이면 둘째 부등식이 \(-3 > 0\)으로 깨진다. 아래 탐구 카드에서 그래프를 위아래로 움직이며 해의 범위가 넓어지고 줄어드는 모습을 직접 보자.

  1. \(a < 0\)인 채로 생각해도 된다. 그래프가 위로 볼록하므로 두 근 사이에서 양수, 바깥에서 음수가 되어 표의 부호가 서로 바뀐다.
마무리

이차부등식은 이차함수의 그래프가 \(x\)축의 위에 있는지 아래에 있는지를 묻는 문제이다. 경계는 이차방정식의 실근이고, 판별식이 경계의 개수를 정한다. 처음 질문의 \(t^2 - 4t + 3 < 0\)은 그래프가 \(x\)축 아래에 있는 \(1 < t < 3\)이 해이므로, 공은 1초부터 3초까지 15 m보다 높이 있다.

  1. 질문\(x^2 - x - 6 > 0\)을 만족하는 \(x\)는 어떤 범위일까? 이차방정식 \(x^2 - x - 6 = 0\)의 근 \(-2\), 3은 그 해와 어떤 관계일까?
  2. 복원이차방정식 \(ax^2 + bx + c = 0\)의 실근은 이차함수 \(y = ax^2 + bx + c\)의 그래프가 \(x\)축과 만나는 점의 \(x\)좌표이다. 또 판별식 \(D = b^2 - 4ac\)가 양수, 0, 음수이면 그래프는 \(x\)축과 각각 두 점에서 만나고, 접하고, 만나지 않는다.
  3. 설명같은 눈으로 보면 이차부등식 \(ax^2 + bx + c > 0\)의 해는 그래프가 \(x\)축보다 위에 있는 \(x\)의 범위이고, \(< 0\)의 해는 아래에 있는 범위이다. \(a > 0\)이고 두 근이 \(\alpha < \beta\)이면 \((x - \alpha)(x - \beta) > 0\)의 해는 \(x < \alpha\) 또는 \(x > \beta\)이고, \((x - \alpha)(x - \beta) < 0\)의 해는 \(\alpha < x < \beta\)이다. \(D = 0\)이면 그래프가 \(x\)축에 접할 뿐 아래로 내려가지 않으므로 \(> 0\)의 해는 접점만 뺀 모든 실수이고 \(< 0\)의 해는 없다. \(D < 0\)이면 그래프가 늘 \(x\)축 위에 있어서 \(> 0\)의 해는 모든 실수, \(< 0\)의 해는 없다. \(a < 0\)이면 양변에 \(-1\)을 곱해 \(a > 0\)으로 바꾸고 부등호 방향도 바꾼다.
  4. 연결그래서 질문의 식은 \((x + 2)(x - 3) > 0\)이므로 해는 \(x < -2\) 또는 \(x > 3\)이고, 방정식의 근은 해의 경계가 된다. 또 모든 실수 \(x\)에 대하여 \(ax^2 + bx + c > 0\)이 성립하려면 그래프 전체가 \(x\)축 위에 있어야 하므로 \(a > 0\)이고 \(D < 0\)이어야 한다.
  5. 적용\(c\)를 키우면서 판별식이 양수에서 0, 음수로 바뀔 때 네 부등호의 해가 각각 어떻게 바뀌는지 확인해 보자. \(a = -1\)을 고르면 \(> 0\)의 해가 두 근 사이로 옮겨 간다. \(b = 2\), \(c = 1\)로 두고 \(\le 0\)과 \(< 0\)의 해를 비교하면 접점 하나의 차이가 보인다.
  6. 판단"\(> 0\)이면 해는 두 근 바깥"이라고 외우면 \(a < 0\)일 때 틀린다. 위로 볼록한 그래프에서는 \(> 0\)의 해가 두 근 사이이다. 또 근이 허수일 때 "해가 없다"고 단정하면 안 된다. \(D < 0\)이고 \(a > 0\)이면 \(> 0\)의 해는 오히려 모든 실수이다.

이차부등식이 섞인 연립부등식은 어떻게 풀까?

연립이차부등식 · 공통부분

—

①의 해
—
②의 해
—
공통부분
—
  1. 질문\(x^2 - x - 6 \le 0\)과 \(x^2 - 4x > 0\)을 동시에 만족하는 \(x\)의 범위는 어떻게 구할까?
  2. 복원연립부등식의 해는 각 부등식의 해의 공통부분이다. 또 이차부등식은 그래프가 \(x\)축보다 위나 아래에 있는 범위로 풀고, 근이 해의 경계가 된다.
  3. 설명연립부등식 가운데 차수가 가장 높은 부등식이 이차부등식이면 연립이차부등식이라고 하며, 푸는 순서는 연립일차부등식과 같다. 첫째 부등식은 \((x + 2)(x - 3) \le 0\)이므로 \(-2 \le x \le 3\)이다. 둘째 부등식은 \(x(x - 4) > 0\)이므로 \(x < 0\) 또는 \(x > 4\)이다. 두 해를 수직선에 겹치면 공통부분은 \(-2 \le x < 0\)이다.
  4. 연결이차부등식의 해는 구간 하나일 수도, 둘로 떨어질 수도 있다. 그래서 공통부분도 두 조각이 될 수 있다. 이 방법은 '삼각형의 세 변이 될 조건'이나 '넓이가 일정 범위에 들도록 하는 길이'처럼 조건이 여러 개인 문제에서 그대로 쓰인다.
  5. 적용둘째 부등식의 \(c\)를 바꾸어 그 해가 두 조각, 모든 실수, 해 없음이 되는 경우를 만들고 공통부분이 어떻게 변하는지 보자. 첫째로 \(x^2 - 4 > 0\)을 고르고 둘째를 <로 바꾸면, 공통부분이 두 조각이 되는 \(b\), \(c\)도 찾을 수 있다.
  6. 판단두 해를 '또는'으로 합치면 안 된다. 연립부등식은 두 조건을 모두 만족해야 하므로 겹치는 곳만 해이다. 또 경계값은 두 부등식에서 모두 허용될 때만 해에 넣는다. 예를 들어 \(x = 0\)은 첫째 부등식을 만족하지만, 둘째에서 \(0 > 0\)이 거짓이라 빠진다.
