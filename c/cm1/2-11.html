이차부등식

이차부등식 x2 − x − 6 < 0의 해는 이차함수 y = x2 − x − 6의 그래프가 x축보다 아래에 있는 x의 범위입니다. 이 절에서는 계수를 바꾸며 그래프와 x축의 위치에서 해를 읽고, 판별식에 따라 해가 어떻게 달라지는지 정리합니다. 마지막으로 이차부등식이 섞인 연립부등식을 공통부분으로 풉니다.

  2. 복원이차방정식 ax2 + bx + c = 0의 실근은 이차함수 y = ax2 + bx + c의 그래프가 x축과 만나는 점의 x좌표입니다. 판별식 D = b2 − 4ac가 양수, 0, 음수이면 그래프는 x축과 각각 두 점에서 만나고, 접하고, 만나지 않습니다.
  3. 설명이차부등식 ax2 + bx + c > 0의 해는 그래프가 x축보다 위에 있는 x의 범위이고, < 0의 해는 아래에 있는 범위입니다. a > 0이고 두 근이 α < β이면 (x − α)(x − β) > 0의 해는 x < α 또는 x > β, (x − α)(x − β) < 0의 해는 α < x < β입니다. D = 0이면 그래프가 x축에 접하므로 x축 아래로 내려가지 않습니다. 그래서 > 0의 해는 접점만 뺀 모든 실수, < 0의 해는 없습니다. D < 0이면 그래프가 늘 x축 위에 있어서 > 0의 해는 모든 실수, < 0의 해는 없습니다. a < 0이면 양변에 −1을 곱해 a > 0으로 바꾸고 부등호 방향도 바꿉니다.
  4. 연결질문의 식은 (x + 2)(x − 3) > 0이므로 해는 x < −2 또는 x > 3입니다. 방정식의 근은 해의 경계가 됩니다. 모든 실수 x에 대하여 ax2 + bx + c > 0이 성립하려면 그래프 전체가 x축 위에 있어야 하므로 a > 0이고 D < 0이어야 합니다.
  5. 적용c를 키우면서 판별식이 양수에서 0, 음수로 바뀔 때 네 부등호의 해가 각각 어떻게 바뀌는지 확인하세요. a = −1을 고르면 > 0의 해는 두 근의 바깥과 안쪽 중 어디에 있나요? b = 2, c = 1로 두고 ≤ 0과 < 0의 해를 비교하세요.
  6. 판단"> 0이면 해는 두 근 바깥"이라고 외우면 a < 0일 때 틀립니다. 위로 볼록한 그래프에서는 > 0의 해가 두 근 사이입니다. 또 근이 허수일 때 "해가 없다"고 단정하면 안 됩니다. D < 0이고 a > 0이면 > 0의 해는 오히려 모든 실수입니다.

2.11.2

이차부등식이 섞인 연립부등식은 어떻게 풀까?

②의 해
—
공통부분

  1. 질문x2 − x − 6 ≤ 0과 x2 − 4x > 0을 동시에 만족하는 x의 범위는 어떻게 구할까요?
  2. 복원연립부등식의 해는 각 부등식의 해의 공통부분입니다. 이차부등식은 그래프가 x축보다 위나 아래에 있는 범위로 풀고, 근이 해의 경계가 됩니다.
  3. 설명연립부등식 가운데 차수가 가장 높은 부등식이 이차부등식이면 연립이차부등식이라고 합니다. 푸는 순서는 연립일차부등식과 같습니다. ① x2 − x − 6 ≤ 0은 (x + 2)(x − 3) ≤ 0이므로 −2 ≤ x ≤ 3입니다. ② x2 − 4x > 0은 x(x − 4) > 0이므로 x < 0 또는 x > 4입니다. 두 해를 수직선에 겹치면 공통부분은 −2 ≤ x < 0입니다.
  4. 연결이차부등식의 해는 구간 하나일 수도, 둘로 떨어질 수도 있습니다. 그래서 공통부분도 두 조각이 될 수 있습니다. 이 방법은 '삼각형의 세 변이 될 조건'이나 '넓이가 일정 범위에 들도록 하는 길이'처럼 조건이 여러 개인 문제를 풀 때 그대로 쓰입니다.
  5. 적용②의 c를 바꾸어 ②의 해가 두 조각, 모든 실수, 해 없음이 되는 경우를 만들고 공통부분이 어떻게 변하는지 보세요. ①로 x2 − 4 > 0을 고르고 ②를 <로 바꾸면 공통부분이 두 조각이 되는 b, c를 찾을 수 있나요?
  6. 판단두 해를 '또는'으로 합치면 안 됩니다. 연립부등식은 두 조건을 모두 만족해야 하므로 겹치는 곳만 해입니다. 경계값은 두 부등식에서 모두 허용될 때만 해에 넣습니다. 예를 들어 x = 0은 ①을 만족하지만 ②에서 0 > 0이 거짓이라 빠집니다.
