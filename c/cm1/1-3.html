인수분해

인수분해는 곱셈 공식을 거꾸로 읽는 일입니다. 중학교에서 다룬 이차식의 인수분해에 더해, 항이 셋인 식의 제곱과 세제곱 꼴의 공식을 넓이와 부피로 확인합니다. 공식에 맞지 않는 삼차식과 사차식은 인수정리로 인수를 하나씩 찾아 차수를 낮추어 갑니다.

먼저 알면 좋은 것 곱셈 공식공통인수로 묶기인수정리조립제법

그림 속 세로 가르는 선을 좌우로 끌면 이웃한 두 길이가 바뀝니다(합은 그대로). 슬라이더로는 한 길이씩 바꿀 수 있습니다. 넓이는 상대값입니다.

  1. 질문(a + b)2은 정사각형을 네 조각으로 나눈 그림이었습니다. 항이 셋이면 몇 조각이 생기고, 어떤 조각끼리 모일까요? 거꾸로 x2 + y2 + 1 + 2xy + 2y + 2x는 한 식의 제곱으로 볼 수 있을까요?
  2. 복원인수분해는 하나의 다항식을 두 개 이상의 다항식의 곱으로 나타내는 것으로, 전개(곱셈 공식)를 거꾸로 하는 과정입니다. 중학교에서 a2 + 2ab + b2 = (a + b)2, 공통인수로 묶기를 배웠습니다.
  3. 설명한 변을 a, b, c로 자르면 조각이 9개 생깁니다. 대각선 위의 정사각형 셋은 a2, b2, c2이고, 나머지 여섯 조각은 같은 직사각형이 둘씩 짝을 이룹니다(ab, bc, ca). 그래서 a2 + b2 + c2 + 2ab + 2bc + 2ca = (a + b + c)2입니다. 인수분해할 때는 제곱인 항 셋과 '두 배의 곱' 항 셋을 찾습니다. 두 배의 곱 항의 부호가 a, b, c의 부호를 정합니다. 예를 들어 x2 + y2 + 1 − 2xy − 2y + 2x에서 2xy와 2y가 음수이므로 y 쪽을 −y로 잡아 (x − y + 1)2입니다.
  4. 연결인수분해의 첫 단계는 언제나 공통인수로 묶는 것입니다. 식이 길면 같은 덩어리를 한 문자로 바꾸는 치환을 씁니다. 예를 들어 (x2 + x)2 + 2(x2 + x) + 1은 x2 + x = X로 두면 (X + 1)2 = (x2 + x + 1)2입니다. 세제곱 공식도 같은 방식으로 부피 모형을 만들 수 있습니다.
  5. 적용세로 선을 끌어 b를 가장 작게 만들어 보세요. 남는 그림은 어떤 공식의 그림과 닮았나요? ab 조각 두 개는 놓인 방향이 달라도 넓이가 늘 같은지, 세 수의 합이 언제나 (a + b + c)2과 같은지 확인하세요.
  6. 판단(a + b + c)2 = a2 + b2 + c2으로 쓰는 실수는 직사각형 여섯 조각을 버린 것입니다. 넓이 모형은 a, b, c가 양수일 때만 그릴 수 있지만, 등식 자체는 전개로 확인되므로 음수나 문자식을 넣어도 성립합니다.

1.3.2

a3 − b3은 왜 (a − b)(a2 + ab + b2)일까?

부피는 상대값입니다. a3 − b3 모드에서 점선 상자는 떼어 낸 작은 정육면체 b3입니다. b는 a보다 작게만 놓을 수 있습니다.

  1. 질문한 변이 a인 정육면체의 한 모서리에서 한 변이 b인 작은 정육면체를 떼어 내면 남는 부피는 a3 − b3입니다. 이 울퉁불퉁한 입체를 직육면체 몇 개로 나누면 곱의 꼴이 보일까요?
  2. 복원직육면체의 부피는 (가로) × (세로) × (높이)입니다. 다항식의 곱셈에서 (a − b)(a2 + ab + b2)을 전개하면 a3 − b3이 나왔습니다. 인수분해는 이 전개를 거꾸로 읽는 것입니다.
  3. 설명남은 입체는 두께가 모두 a − b인 세 판으로 나뉩니다. 부피는 (a − b) · a · a, (a − b) · a · b, (a − b) · b · b이고, 공통인수 a − b로 묶으면 a3 − b3 = (a − b)(a2 + ab + b2)입니다. (a + b)3 모드에서는 세 방향을 모두 a와 b로 잘라 조각이 8개 생기고, a3이 1개, a2b가 3개, ab2이 3개, b3이 1개입니다. 그래서 a3 + 3a2b + 3ab2 + b3 = (a + b)3입니다. 두 공식의 b에 −b를 넣으면 a3 + b3 = (a + b)(a2 − ab + b2), a3 − 3a2b + 3ab2 − b3 = (a − b)3도 얻습니다.
  4. 연결수에서도 같은 일이 일어납니다. 103 − 13 = 999 = 9 × 111 = (10 − 1)(100 + 10 + 1)입니다. 문자식에서는 27x3 − 8 = (3x)3 − 23 = (3x − 2)(9x2 + 6x + 4)처럼 각 항을 세제곱 꼴로 본 뒤 공식에 넣습니다.
  5. 적용떼어 놓기를 100%로 하고 세 판의 모양을 비교하세요. 세 판에 공통인 길이는 무엇인가요? b를 a에 가깝게 키우면 판들은 어떻게 변하나요? (a + b)3 모드에서 a2b 조각 세 개가 놓인 방향을 찾아보세요.
  6. 판단a2 + ab + b2을 (a + b)2으로 착각하기 쉽습니다. 가운데 항이 ab이지 2ab가 아닙니다. 또 a3 + b3은 (a + b)3이 아닙니다. 부피 모형은 a > b > 0일 때만 그릴 수 있지만, 공식은 전개로 확인되므로 모든 수와 식에서 성립합니다.

공식에 맞지 않는 삼차식은 어떻게 인수분해할까?

후보 단추는 지금 남은 식의 (상수항의 약수) / (최고차항 계수의 약수)에 ± 부호를 붙인 값입니다. 하나를 누르면 남은 식에 그 값을 넣고, 0이 되면 조립제법으로 나눕니다.

  1. 질문x3 − 2x2 − 5x + 6은 세제곱 공식에도, 완전제곱 꼴에도 맞지 않습니다. 이런 식은 어디서부터 쪼개야 할까요?
  2. 복원인수정리: P(a) = 0이면 x − a는 P(x)의 인수입니다. 조립제법으로 P(x)를 x − a로 나누면 몫을 빠르게 얻습니다.
  3. 설명계수가 모두 정수인 P(x)에서 유리수 p/q(기약분수)를 넣어 0이 된다면, p는 상수항의 약수이고 q는 최고차항 계수의 약수입니다. 그래서 0이 되는 값을 찾을 때는 ±(상수항의 약수)/(최고차항 계수의 약수)만 넣어 보면 됩니다. 0이 되는 값 a를 찾으면 ① 조립제법으로 x − a로 나누어 차수를 하나 낮추고, ② 남은 식에서 같은 일을 되풀이합니다. 남은 식이 이차식이면 인수분해 공식이나 같은 방법을 씁니다. a = 1/2처럼 분수가 나오면 인수를 2x − 1로 쓰고 몫을 2로 나눕니다. x4 − 5x2 + 4처럼 x2만 있는 사차식은 x2 = X로 치환해 X2 − 5X + 4 = (X − 1)(X − 4)로 풀어도 됩니다.
  4. 연결P(a) = 0인 a는 그래프 y = P(x)가 x축과 만나는 점의 x좌표입니다. 인수분해를 끝내면 삼차방정식, 사차방정식 P(x) = 0의 해를 바로 읽을 수 있으므로, 다음 단원의 고차방정식 풀이가 이 과정 그대로입니다.
  5. 적용첫 번째 식에서 후보를 눌러 0이 되는 값을 찾고, 남은 이차식을 끝까지 쪼개 보세요. x3 − 3x2 + 4에서는 같은 인수가 두 번 나옵니다. 그래프는 그 점에서 어떤 모양인가요? 마지막 식에서는 인수를 하나 찾은 뒤 남은 이차식에 후보를 모두 넣어 보세요.
  6. 판단후보 목록은 '유리수 근이 있다면 이 안에 있다'는 뜻이지, 반드시 근이 있다는 뜻이 아닙니다. x2 + 2x + 3처럼 후보를 다 넣어도 0이 되지 않으면 유리수 계수 범위에서는 더 인수분해되지 않습니다. x2 − 2처럼 근이 무리수인 식도 이 방법으로는 찾을 수 없습니다.
