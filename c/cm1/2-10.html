절댓값을 포함한 부등식

\(|x - 1| < 3\)은 '\(x\)와 1 사이의 거리가 3보다 작다'는 뜻입니다. 이렇게 거리로 읽으면 해가 바로 보입니다. 절댓값이 두 개 이상이면 거리만으로는 어렵기 때문에, 절댓값 기호 안이 0이 되는 값을 경계로 범위를 나누고 각 범위에서 일차부등식을 풉니다. 이 절에서는 두 방법을 그래프와 수직선으로 비교합니다.

2.10.1절댓값은 거리이다

중학교에서 \(|x|\)는 수직선 위에서 \(x\)를 나타내는 점과 원점 사이의 거리라고 배웠다. 그러면 \(|x - a|\)는 무엇일까? \(x - a\)는 \(x\)를 \(a\)만큼 왼쪽으로 옮긴 수이므로, \(|x - a|\)는 \(x\)와 \(a\) 사이의 거리이다. 가령 \(|7 - 4| = 3\)은 7과 4가 3만큼 떨어져 있다는 뜻이다.

이렇게 읽으면 처음 질문의 \(|x - 500| \le 3\)은 '\(x\)와 500 사이의 거리가 3 이하'라는 말이다. 500에서 왼쪽으로 3, 오른쪽으로 3까지가 그 범위이므로 \(497 \le x \le 503\)이다. 그림 1에서 \(a\)와 \(r\)을 바꾸어 보면, 범위는 언제나 \(a\)를 가운데에 둔 길이 \(2r\)인 구간이다.

정리 2.10.1 절댓값을 포함한 일차부등식

\(r > 0\)일 때 \(|x - a| < r \iff a - r < x < a + r\)이고, \(|x - a| > r \iff x < a - r\) 또는 \(x > a + r\)이다.

두 번째 경우는 거리가 \(r\)보다 큰 점들이므로 구간의 바깥, 두 쪽으로 갈라진 범위이다. '또는'이 붙는 까닭이 여기에 있다. 연립부등식의 해가 공통부분이었다면, 이 경우의 해는 합친 범위이다.

2.10.2범위를 나누어 기호를 벗기기

거리로 읽기 어려운 식도 있다. \(|x - 1| + |x + 2| < 5\)처럼 절댓값이 두 개이거나, \(|2x - 3| < x\)처럼 오른쪽에 \(x\)가 있으면 그렇다. 이때는 절댓값의 정의로 돌아간다. \(|A|\)는 \(A \ge 0\)이면 \(A\), \(A < 0\)이면 \(-A\)이다. 따라서 절댓값 안이 0이 되는 \(x\)를 경계로 범위를 나누면, 각 범위에서 기호를 확실하게 벗길 수 있다.

그림 2는 \(|x - 1| + |x + 2|\)의 경계 \(x = -2\)와 \(x = 1\)로 나눈 세 범위이다. 각 범위에서 기호를 벗겨 부등식을 풀고, 그 해가 그 범위 안에 있는 것만 남긴다. 마지막으로 세 범위의 해를 모두 합친다.

예제 2.10.2

부등식 \(|x - 1| + |x + 2| < 5\)를 풀어라.

먼저 \(x < -2\)이면 두 식이 모두 음수이므로 \(-(x - 1) - (x + 2) < 5\), 곧 \(-2x - 1 < 5\)이다. 따라서 \(x > -3\)이고, 범위 \(x < -2\)와 겹치는 부분은 \(-3 < x < -2\)이다.

다음으로 \(-2 \le x < 1\)이면 \(-(x - 1) + (x + 2) = 3 < 5\)로 언제나 성립한다. 그래서 이 범위 전체 \(-2 \le x < 1\)이 해이다. 마지막으로 \(x \ge 1\)이면 \((x - 1) + (x + 2) = 2x + 1 < 5\)에서 \(x < 2\)이므로 \(1 \le x < 2\)이다.

세 결과를 합치면 \(-3 < x < 2\)이다. 거리로 읽어 확인할 수도 있다. \(|x - 1| + |x + 2|\)는 \(x\)에서 1까지의 거리와 \(-2\)까지의 거리의 합이다. 두 점 사이에 있으면 합이 늘 3이고, 바깥으로 1만큼 나가면 합이 2만큼 늘어 5가 된다. 그래서 경계가 \(-3\)과 2인 것이다.1 아래 탐구 카드에서 기준점과 거리를 바꾸며 해가 되는 구간을 직접 확인해 보자.

  1. \(|x - a| < r\)에서 \(r \le 0\)이면 거리는 음수가 될 수 없으므로 해가 없다. 반대로 \(|x - a| > r\)에서 \(r < 0\)이면 모든 실수가 해이다.
마무리

\(|x - a|\)는 수직선 위에서 \(x\)와 \(a\) 사이의 거리이므로, \(|x - a| \le r\)은 \(a\)를 가운데에 둔 구간이 되고 \(|x - a| > r\)은 그 바깥이 된다. 거리로 읽기 어려운 식은 절댓값 안이 0이 되는 점에서 범위를 나누어 기호를 벗긴다. 그래서 처음 질문의 합격 범위는 \(497 \le x \le 503\)이다.

해
—
  1. 질문\(|x - 1| < 3\)을 만족하는 \(x\)는 어떤 수일까? 절댓값 기호를 없애는 방법을 찾아보자.
  2. 복원\(|A|\)는 \(A \ge 0\)이면 \(A\), \(A < 0\)이면 \(-A\)이다. 수직선에서 \(|x - a|\)는 \(x\)와 \(a\) 사이의 거리이다. 예를 들어 \(|5 - 1| = |-3 - 1| = 4\)이므로 5와 \(-3\)은 모두 1에서 4만큼 떨어져 있다.
  3. 설명그러면 \(r > 0\)일 때 \(|x - a| < r\)은 '\(a\)에서 거리가 \(r\)보다 가까운 점'이므로 \(a - r < x < a + r\)이다. 반대로 \(|x - a| > r\)은 '거리가 \(r\)보다 먼 점'이므로 \(x < a - r\) 또는 \(x > a + r\)이다. 다시 말해 \(|A| < r \Leftrightarrow -r < A < r\)이고 \(|A| > r \Leftrightarrow A < -r\) 또는 \(A > r\)이다. 그래서 \(|x - 1| < 3\)의 해는 \(-2 < x < 4\)이다.
  4. 연결그래프로 보면 \(y = |x - a|\)는 \(x = a\)에서 꺾이는 V자이고, 부등식의 해는 V자가 수평선 \(y = r\)보다 아래나 위에 있는 \(x\)의 범위이다. 이때 V자의 두 갈래 \(y = x - a\)와 \(y = -(x - a)\)는 범위를 나누어 풀 때의 두 경우와 똑같다.
  5. 적용\(a\)를 움직여 해의 구간이 함께 옮겨 가는 것을 확인해 보자. 이번에는 \(r\)을 0으로, 다시 음수로 내리면서 <, ≤, >, ≥ 네 경우의 해를 비교해 보자. \(r = 0\)일 때 '해가 한 점', '해가 없음', '한 점만 빼고 모두'가 각각 어느 부등호에서 나오는지 찾을 수 있다.
  6. 판단\(|x - a| > r\)의 해를 '\(a - r > x > a + r\)'처럼 한 줄로 쓰면 틀린다. 그런 \(x\)는 없기 때문이다. 해는 두 부분으로 떨어져 있으므로 '또는'으로 써야 한다. 또 우변이 음수이면 절댓값은 음수가 될 수 없으므로, <이면 해가 없고 >이면 모든 실수가 해이다.

절댓값이 두 개면 어디서 나누어 풀까?

절댓값 부등식 · 범위 나누기
    부등식
    —
    해 (각 범위의 해를 모두 합친 것)
    —
    1. 질문\(|x + 1| + |x - 2| < 5\)에는 절댓값이 두 개 있어서, 거리 하나로 읽어 내기가 어렵다. 그렇다면 절댓값 기호를 어떻게 없애야 할까?
    2. 복원\(|A|\)는 \(A \ge 0\)이면 \(A\), \(A < 0\)이면 \(-A\)이다. 그래서 \(|x + 1|\)은 \(x = -1\)을 경계로, \(|x - 2|\)는 \(x = 2\)를 경계로 식의 모양이 바뀐다. 또 연립부등식의 해는 각 부등식의 해의 공통부분이다.
    3. 설명절댓값 기호 안을 0으로 만드는 \(-1\)과 2로 수직선을 세 범위로 나누어 보자. \(x < -1\)이면 식은 \(-(x + 1) - (x - 2) = -2x + 1\)이므로 \(-2x + 1 < 5\)에서 \(x > -2\)이고, 범위와 겹치면 \(-2 < x < -1\)이다. \(-1 \le x < 2\)이면 식이 늘 3이 되어 \(3 < 5\)가 참이므로 범위 전체가 해이다. 마지막으로 \(x \ge 2\)이면 \(2x - 1 < 5\)에서 \(x < 3\)이므로 \(2 \le x < 3\)이다. 이제 세 범위의 해를 합치면 \(-2 < x < 3\)을 얻는다.
    4. 연결각 범위 안에서는 절댓값이 사라져 일차부등식이 되고, 그 해를 범위와 겹치는 일은 연립일차부등식을 푸는 일과 같다. 그래프로 보면 \(y = f(x)\)는 경계에서 꺾이는 꺾은선이고, 범위마다 직선 한 조각이다. 그래서 해는 꺾은선이 \(y = k\)보다 아래에 놓이는 \(x\)의 범위로 읽을 수도 있다.
    5. 적용'다음 범위'를 눌러 범위마다 식이 어떻게 바뀌는지 따라가 보자. \(k\)를 3으로 내리면 가운데 범위에서는 \(3 < 3\)이 거짓이 되어 해가 사라진다. 세 번째 식 \(|x| - |x - 2|\)에서 <를 고르고 \(k\)를 2보다 크게, 또 \(-2\) 이하로 바꾸어 보면 해가 모든 실수에서 공집합까지 달라지는 것을 볼 수 있다.
    6. 판단각 범위에서 구한 해를 범위와 겹치지 않고 그대로 답으로 쓰면 틀린다. 예를 들어 \(x > -2\)는 \(x < -1\)이라는 가정 아래서만 뜻이 있다. 또 범위 안에서는 '그리고'로 겹치고, 범위끼리는 '또는'으로 합친다. 경계값 \(-1\)과 2가 빠지거나 두 번 들어가지 않도록 등호는 한쪽 범위에만 붙인다.
