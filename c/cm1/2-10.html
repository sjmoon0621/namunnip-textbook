절댓값을 포함한 부등식

\(|x - 1| < 3\)은 '\(x\)와 1 사이의 거리가 3보다 작다'는 뜻입니다. 이렇게 거리로 읽으면 해가 바로 보입니다. 절댓값이 두 개 이상이면 거리만으로는 어렵기 때문에, 절댓값 기호 안이 0이 되는 값을 경계로 범위를 나누고 각 범위에서 일차부등식을 풉니다. 이 절에서는 두 방법을 그래프와 수직선으로 비교합니다.

2.10.1

\(|x - a| < r\)은 수직선에서 어떤 범위일까?

절댓값 부등식 · 거리로 읽기

—

경계 \(a - r\)
—
경계 \(a + r\)
—
해
—
  1. 질문\(|x - 1| < 3\)을 만족하는 \(x\)는 어떤 수일까요? 절댓값 기호를 어떻게 없애야 할까요?
  2. 복원\(|A|\)는 \(A \ge 0\)이면 \(A\), \(A < 0\)이면 \(-A\)입니다. 수직선에서 \(|x - a|\)는 \(x\)와 \(a\) 사이의 거리입니다. 예를 들어 \(|5 - 1| = |-3 - 1| = 4\)입니다.
  3. 설명\(r > 0\)일 때 \(|x - a| < r\)은 '\(a\)에서 거리가 \(r\)보다 가까운 점'이므로 \(a - r < x < a + r\)입니다. \(|x - a| > r\)은 '거리가 \(r\)보다 먼 점'이므로 \(x < a - r\) 또는 \(x > a + r\)입니다. 정리하면 \(|A| < r \Leftrightarrow -r < A < r\), \(|A| > r \Leftrightarrow A < -r\) 또는 \(A > r\)입니다. 그래서 \(|x - 1| < 3\)의 해는 \(-2 < x < 4\)입니다.
  4. 연결그래프로 보면 \(y = |x - a|\)는 \(x = a\)에서 꺾이는 V자이고, 부등식의 해는 V자가 수평선 \(y = r\)보다 아래(또는 위)에 있는 \(x\)의 범위입니다. V자의 두 갈래 \(y = x - a\)와 \(y = -(x - a)\)는 범위를 나누어 푸는 방법의 두 경우와 같습니다.
  5. 적용\(a\)를 움직이면 해의 구간은 어떻게 움직이나요? \(r\)을 0으로, 그리고 음수로 내리면서 <, ≤, >, ≥ 네 경우의 해가 어떻게 되는지 확인하세요. \(r = 0\)일 때 '해가 한 점', '해가 없음', '한 점만 빼고 모두'가 각각 어느 부등호에서 나오나요?
  6. 판단\(|x - a| > r\)을 '\(a - r > x > a + r\)'처럼 한 줄로 쓰면 틀립니다. 그런 \(x\)는 없습니다. 해는 두 부분으로 떨어져 있으므로 '또는'으로 씁니다. 또 우변이 음수이면 절댓값은 음수가 될 수 없으므로, <이면 해가 없고 >이면 모든 실수가 해입니다.

2.10.2

절댓값이 두 개면 어디서 나누어 풀까?

절댓값 부등식 · 범위 나누기
    부등식
    —
    해 (각 범위의 해를 모두 합친 것)
    —
    1. 질문\(|x + 1| + |x - 2| < 5\)에는 절댓값이 두 개 있어 거리 하나로 읽기 어렵습니다. 절댓값 기호를 어떻게 없앨까요?
    2. 복원\(|A|\)는 \(A \ge 0\)이면 \(A\), \(A < 0\)이면 \(-A\)입니다. 그래서 \(|x + 1|\)의 모양은 \(x = -1\)을 경계로 바뀌고, \(|x - 2|\)는 \(x = 2\)를 경계로 바뀝니다. 연립부등식의 해는 공통부분입니다.
    3. 설명절댓값 기호 안이 0이 되는 값 \(-1\), 2로 수직선을 세 범위로 나눕니다. ① \(x < -1\)이면 \(-(x + 1) - (x - 2) = -2x + 1\)이므로 \(-2x + 1 < 5\), \(x > -2\)입니다. 범위와 함께 쓰면 \(-2 < x < -1\)입니다. ② \(-1 \le x < 2\)이면 식이 3이 되어 \(3 < 5\)는 늘 참이므로 범위 전체가 해입니다. ③ \(x \ge 2\)이면 \(2x - 1 < 5\), \(x < 3\)이므로 \(2 \le x < 3\)입니다. 세 범위의 해를 합치면 \(-2 < x < 3\)입니다.
    4. 연결각 범위에서는 절댓값이 사라져 일차부등식이 되고, 그 해를 범위와 겹치는 것은 연립일차부등식입니다. 그래프로 보면 \(y = f(x)\)는 경계에서 꺾이는 꺾은선이고, 범위마다 직선 한 조각입니다. 해는 꺾은선이 \(y = k\)보다 아래에 있는 \(x\)의 범위입니다.
    5. 적용'다음 범위'를 눌러 범위마다 식이 어떻게 바뀌는지 따라가세요. \(k\)를 3으로 내리면 가운데 범위의 결과가 어떻게 되나요? 세 번째 식 \(|x| - |x - 2|\)에서 <를 고르고 \(k\)를 2보다 크게, \(-2\) 이하로 바꾸면 해는 어떻게 되나요?
    6. 판단각 범위에서 구한 해를 범위와 겹치지 않고 그대로 답으로 쓰면 틀립니다. ①에서 \(x > -2\)는 \(x < -1\)이라는 가정 아래서만 의미가 있습니다. 또 범위끼리는 '또는'으로 합치고, 범위 안에서는 '그리고'로 겹칩니다. 경계값\((-1, 2)\)이 빠지거나 두 번 들어가지 않게 한쪽 범위에만 등호를 붙이세요.
