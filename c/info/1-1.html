함수는 어떻게 값을 받고, 무엇을 돌려줄까?
읽기 · 함수 정의 · 매개변수의 종류 · 반환값 · 유효 범위
        

        

          
같은 계산을 프로그램 여러 곳에서 쓰면 코드를 복사해 붙이기 쉽습니다. 그런데 계산에 실수가 있으면 붙여 넣은 곳을 모두 찾아 고쳐야 합니다. 함수는 이 문제를 어떻게 해결하고, 함수를 쓸 때 무엇을 정해야 할까요?


          
1함수로 나누는 까닭

          
함수는 일을 하는 코드에 이름을 붙인 것입니다. 한 번 정의하면 이름으로 몇 번이든 부를 수 있고, 고칠 곳도 한 곳뿐입니다. 더 중요한 점은 추상화입니다. sorted(xs)를 쓸 때 정렬이 안에서 어떻게 일어나는지 몰라도 되는 것처럼, 함수를 쓰는 쪽은 “무엇을 넣으면 무엇이 나오는가”만 알면 됩니다. 큰 문제를 작은 함수로 나누면 각 함수를 따로 시험하고 고칠 수 있습니다.

          
def bmi(weight, height):          # 정의: 이름, 매개변수
          return weight / height ** 2    # 몸체와 반환값

      print(bmi(60, 1.7))               # 호출: 인자 60, 1.7 → 20.76…

          
정의할 때 괄호 안에 쓴 이름(weight, height)이 매개변수이고, 호출할 때 넘기는 값(60, 1.7)이 인자입니다. 함수가 받을 값과 돌려줄 값을 먼저 정하고 나서 몸체를 쓰면, 함수의 쓰임이 분명해집니다.

방식예뜻

            
              
위치 인자power(2, 10)순서대로 매개변수에 짝지어집니다. base=2, exp=10

              
키워드 인자power(exp=10, base=2)이름으로 짝짓므로 순서를 바꿔도 됩니다.

              
기본값def power(base, exp=2):인자를 생략하면 기본값을 씁니다. power(5) → 25

              
가변 인자def total(*nums):넘긴 위치 인자들을 튜플 하나로 받습니다. total(1, 2, 3)에서 nums = (1, 2, 3)

            
          

          
기본값이 있는 매개변수는 기본값이 없는 매개변수 뒤에 써야 합니다. def f(a=1, b):는 문법 오류입니다.


          
3반환값

          
    
            
  • return을 만나면 함수는 그 자리에서 끝나고 값을 호출한 곳으로 돌려줍니다. 그 아래 코드는 실행되지 않습니다.
    • 
            
  • return이 없거나 값 없이 return만 쓰면 None을 돌려줍니다. 화면에 print하는 것과 값을 돌려주는 것은 다릅니다. print한 값은 다른 계산에 쓸 수 없습니다.
    • 
            
  • return q, r처럼 쓰면 튜플 하나를 돌려주고, 받는 쪽에서 q, r = f(…)처럼 나누어 받을 수 있습니다. 내장 함수 divmod(17, 5)가 (3, 2)를 돌려주는 것과 같은 방식입니다.

4유효 범위: 이름은 어디에서 보일까

          
함수 안에서 대입한 이름은 그 함수의 지역 변수입니다. 호출할 때 생겨서 함수가 끝나면 사라집니다. 파이썬은 이름을 찾을 때 지역 → 바깥 함수 → 전역 → 내장 순서로 찾습니다. 그래서 함수 안에서 전역 변수를 읽기는 할 수 있지만, 대입하는 순간 그 이름은 지역 변수가 됩니다.

          
count = 0
      def inc():
          count = count + 1     # UnboundLocalError: 지역 변수 count를 값이 생기기 전에 읽음

      def inc2():
          global count          # 전역 count를 쓰겠다고 밝힘
          count = count + 1

          
global은 꼭 필요할 때만 씁니다. 여러 함수가 전역 변수를 고치면 어디서 값이 바뀌었는지 추적하기 어렵습니다. 대개는 값을 매개변수로 받고 결과를 return하는 편이 낫습니다.


          
판단기본값은 함수를 정의할 때 한 번 계산됩니다. def add(x, xs=[]):처럼 리스트를 기본값으로 쓰면, 호출할 때마다 같은 리스트 객체가 재사용되어 이전 호출에서 넣은 값이 남아 있습니다. 바뀔 수 있는 객체가 기본값으로 필요하면 xs=None으로 두고 함수 안에서 if xs is None: xs = []로 새로 만듭니다.
