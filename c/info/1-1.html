1.1.1함수 호출과 스택 프레임

함수는 이름을 붙인 코드 묶음이다. 함수를 부르면 컴퓨터는 지금 실행하던 위치를 기억해 두고, 그 함수만을 위한 작업 공간을 새로 만든다. 이 작업 공간을 스택 프레임이라 한다. 프레임에는 넘겨받은 값을 담는 매개변수, 함수 안에서 만든 지역 변수, 끝나고 돌아갈 위치가 들어 있다. 함수 안에서 또 다른 함수를 부르면 그 위에 새 프레임이 쌓인다. 함수가 값을 돌려주며 끝나면 맨 위 프레임이 사라지고, 기억해 둔 위치로 돌아가 이어서 실행한다. 프레임들이 쌓인 모습을 호출 스택이라 한다.

정리 1.1.1 매개변수에 넘겨지는 것

함수를 부를 때 인수의 값이 매개변수라는 새 이름에 연결된다. 매개변수에 새 값을 대입하면 그 이름이 새 값을 가리킬 뿐, 밖의 변수는 바뀌지 않는다. 그런데 리스트처럼 바뀔 수 있는 객체를 넘기면 매개변수와 밖의 변수가 같은 객체를 가리키므로, 함수 안에서 객체 자체를 고치면(예를 들어 append) 밖에서도 바뀐 모습이 보인다.

그림 1에서 호출 깊이를 바꾸어 보자. main이 평균(점수)을 부르면 평균의 프레임이 쌓이고, 평균이 합계(점수)를 부르면 그 위에 또 쌓인다. 각 프레임의 지역 변수는 그 프레임 안에서만 쓰여, 이름이 같아도 서로 섞이지 않는다. 그래서 함수를 나누어 만들어도 변수 이름이 부딪치지 않는다. 그리고 함수가 끝나면 그 지역 변수도 프레임과 함께 사라진다. 처음 질문의 숫자는 함수 안의 매개변수만 새 값을 가리키다가 프레임과 함께 사라진 것이다.1

1.1.2좋은 함수의 조건

함수를 잘 나누면 같은 코드를 되풀이해 쓰지 않아도 되고, 고칠 곳이 한 군데로 모인다. 좋은 함수는 한 가지 일만 하고, 이름만 보고도 무엇을 하는지 알 수 있다. 필요한 값은 매개변수로 받고 결과는 return으로 돌려주어, 함수 밖의 변수에 몰래 기대지 않는다. 그러면 같은 입력에 늘 같은 출력이 나와 시험하기 쉽다. 함수 안에서 넘겨받은 리스트를 고쳐야 한다면, 그 사실을 함수 이름이나 설명에 밝혀 두어야 부르는 쪽이 헷갈리지 않는다. 기본값을 준 매개변수는 자주 쓰는 값을 생략하게 해 준다.

덧붙이기(a)는 값을 생략했으므로 기본값 0이 쓰여 a는 [1, 2, 5, 0], k는 4가 된다. 따라서 a = [1, 2, 5, 0], b = 3, n = 3, m = 6, k = 4이다. 즉 함수 밖의 값을 바꾸고 싶다면 결과를 return으로 돌려받아 다시 대입하는 것이 가장 분명하다. 그래서 b를 바꾸려면 b = 두배(b)처럼 쓴다.

같은 계산을 프로그램 여러 곳에서 쓰면 코드를 복사해 붙이기 쉽다. 그런데 계산에 실수가 있으면 붙여 넣은 곳을 모두 찾아 고쳐야 한다. 함수는 이 문제를 어떻게 해결하고, 함수를 쓸 때 무엇을 정해야 할까?


          
1함수로 나누는 까닭

          
함수는 일을 하는 코드에 이름을 붙인 것이다. 한 번 정의하면 이름으로 몇 번이든 부를 수 있고, 고칠 곳도 한 곳뿐이다. 더 큰 쓸모는 추상화이다. sorted(xs)를 쓸 때 정렬이 안에서 어떻게 일어나는지 몰라도 되는 것처럼, 함수를 쓰는 쪽은 “무엇을 넣으면 무엇이 나오는가”만 알면 된다. 큰 문제를 작은 함수로 나누면 각 함수를 따로 시험하고 고칠 수 있다.

          
def bmi(weight, height):          # 정의: 이름, 매개변수
          return weight / height ** 2    # 몸체와 반환값

      print(bmi(60, 1.7))               # 호출: 인자 60, 1.7 → 20.76…

          
정의할 때 괄호 안에 쓴 이름(weight, height)이 매개변수이고, 호출할 때 넘기는 값(60, 1.7)이 인자이다. 함수가 받을 값과 돌려줄 값을 먼저 정하고 나서 몸체를 쓰면, 함수의 쓰임이 분명해진다.

return이 없거나 값 없이 return만 쓰면 None을 돌려준다. 화면에 print하는 것과 값을 돌려주는 것은 다르다. print한 값은 다른 계산에 쓸 수 없다.

          
return q, r처럼 쓰면 튜플 하나를 돌려주고, 받는 쪽에서 q, r = f(…)처럼 나누어 받을 수 있다. 내장 함수 divmod(17, 5)가 (3, 2)를 돌려주는 것과 같은 방식이다.


          
4유효 범위, 이름은 어디에서 보일까

          
함수 안에서 대입한 이름은 그 함수의 지역 변수이다. 호출할 때 생겨서 함수가 끝나면 사라진다. 파이썬은 이름을 찾을 때 지역 → 바깥 함수 → 전역 → 내장 순서로 찾는다. 그래서 함수 안에서 전역 변수를 읽기는 할 수 있지만, 대입하는 순간 그 이름은 지역 변수가 된다.

          
count = 0
      def inc():
          count = count + 1     # UnboundLocalError: 지역 변수 count를 값이 생기기 전에 읽음

      def inc2():
          global count          # 전역 count를 쓰겠다고 밝힘
          count = count + 1

          
global은 꼭 필요할 때만 쓴다. 여러 함수가 전역 변수를 고치면 어디서 값이 바뀌었는지 추적하기 어렵다. 대개는 값을 매개변수로 받고 결과를 return하는 편이 낫다.


          
판단기본값은 함수를 정의할 때 한 번 계산된다. def add(x, xs=[]):처럼 리스트를 기본값으로 쓰면, 호출할 때마다 같은 리스트 객체가 재사용되어 이전 호출에서 넣은 값이 남아 있다. 바뀔 수 있는 객체가 기본값으로 필요하면 xs=None으로 두고 함수 안에서 if xs is None: xs = []로 새로 만든다.
