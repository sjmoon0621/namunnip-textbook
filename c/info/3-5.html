3.5.1욕심쟁이 방법의 함정

지금 당장 가장 좋아 보이는 선택을 거듭하는 방법을 욕심쟁이(탐욕) 알고리즘이라 한다. 빠르고 간단하지만, 지금의 최선이 전체의 최선을 보장하지는 않는다. 동전 {1, 4, 5}로 8원을 만들 때 5원을 먼저 고르면 남은 3원은 1원 셋으로만 채울 수 있다. 처음의 '좋아 보이는' 선택이 남은 문제를 나쁘게 만든 것이다. 확실한 답을 찾으려면 마지막 동전이 1원, 4원, 5원인 경우를 모두 따져 보아야 한다. 마지막 동전이 4원이면 남은 4원을 가장 적게 만드는 문제가 되고, 그 답은 이미 구해 두었을 수 있다.

정리 3.5.1 거스름돈의 동적 계획법

금액 \(a\)를 만드는 최소 동전 수를 \(d[a]\)라 하면 \(d[0] = 0\)이고 \[d[a] = 1 + \min_{c \le a} d[a - c]\]이다(\(c\)는 동전의 액면). \(a = 1, 2, 3, \dots\)의 순서로 표를 채우면, 각 칸을 계산할 때 필요한 더 작은 금액의 답이 이미 표에 있다. 금액 \(A\)까지 채우는 데 \(A \times (\text{동전 종류 수})\)번 계산한다.

그림 1에서 금액을 바꾸어 보자. 8원은 동적 계획법으로 4원 둘, 곧 2개이고 욕심쟁이 방법은 4개이다. 12원은 4원 셋으로 3개인데 욕심쟁이 방법은 5 + 5 + 1 + 1로 4개이다. 주황 점이 찍힌 금액마다 욕심쟁이 방법이 틀린다. 동적 계획법은 표를 한 칸씩 채우기만 하면 어떤 금액이든 확실한 최솟값을 준다. 한 번 구한 작은 금액의 답을 표에 적어 두고 다시 쓰기 때문에, 같은 계산을 되풀이하지 않는다.1

3.5.2동적 계획법을 쓰는 조건

동적 계획법은 두 조건이 맞을 때 쓴다. 첫째, 큰 문제의 최적해가 작은 문제의 최적해로 이루어져야 한다. 8원을 가장 적게 만드는 방법에서 마지막 동전을 빼면, 남은 금액도 가장 적은 방법이어야 한다. 이것을 최적 부분 구조라 한다. 둘째, 같은 작은 문제가 여러 번 쓰여야 한다. 3원을 만드는 방법은 7원, 8원, 4원을 만들 때 모두 쓰인다. 이것을 중복 부분 문제라 한다. 두 조건이 맞으면, 작은 문제부터 표를 채우는 상향식이나 재귀에 표를 더한 메모이제이션으로 지수적인 계산을 선형으로 줄일 수 있다.

3.5.3예제 하나를 끝까지

예제 3.5.2

동전 1원, 4원, 5원으로 13원을 만드는 최소 동전 수를 동적 계획법으로 구하여라. 그림 2의 표에 9원부터 13원까지를 이어 채우고, 욕심쟁이 방법과 비교하여라.

\(d[9] = 1 + \min(d[8], d[5], d[4]) = 1 + 1 = 2\)(5 + 4)이다. \(d[10] = 1 + \min(d[9], d[6], d[5]) = 2\)(5 + 5), \(d[11] = 1 + \min(d[10], d[7], d[6]) = 3\), \(d[12] = 1 + \min(d[11], d[8], d[7]) = 3\)(4 + 4 + 4)이다.

\(d[13] = 1 + \min(d[12], d[9], d[8]) = 1 + 2 = 3\)이고, 5 + 4 + 4가 한 방법이다. 욕심쟁이 방법은 5 + 5 + 1 + 1 + 1로 5개이다. 동적 계획법은 13원까지 표를 채우는 데 13 × 3 = 39번 비교했을 뿐이다. 즉 작은 문제의 답을 표에 모아 두면, 모든 경우를 따지면서도 계산은 금액에 비례할 뿐이다. 그래서 동적 계획법은 최단 경로, 가방 문제, 문자열 비교 같은 많은 최적화 문제의 기본 도구이다.

1공통점, 부분 문제의 답으로 전체를 만든다

          
두 방법 모두 문제를 같은 모양의 작은 부분 문제로 나누고, 부분 문제의 답을 조합해 전체의 답을 만든다. 그래서 둘 다 재귀식(점화식)으로 쓸 수 있다. 차이는 부분 문제들이 서로 겹치는가에 있다. 병합 정렬은 배열의 왼쪽 절반과 오른쪽 절반을 따로 정렬하므로, 같은 부분 배열을 두 번 정렬하는 일이 없다. 계단 오르기에서는 ways(5)를 구하려고 부른 ways(4)와 ways(3)이 둘 다 다시 ways(2)를 부른다.

시간 복잡도를 셈하는 법나누기·합치기 비용의 점화식 (병합 정렬: T(n) = 2T(n/2) + O(n) → O(n log n))(부분 문제의 수) × (부분 문제 하나를 푸는 비용) (배낭: (n+1)(W+1)칸 × O(1))

2예, 두 DNA 서열이 얼마나 닮았을까

          
생명과학에서는 두 DNA 서열이 얼마나 닮았는지 비교한다. 가장 간단한 척도가 최장 공통 부분 수열(LCS)이다. 순서는 지키되 중간을 건너뛰어도 되는 공통 문자열 가운데 가장 긴 것이다. GATTACA와 TACGCA의 LCS는 길이 4인 TACA이다.

          
X의 앞 i글자와 Y의 앞 j글자의 LCS 길이를 L[i][j]라 하면, 두 마지막 글자가 같을 때 L[i][j] = L[i−1][j−1] + 1, 다를 때 L[i][j] = max(L[i−1][j], L[i][j−1])이다. 한 글자를 빼고 비교하는 부분 문제들이 서로 겹치므로 표에 저장한다.

          

            
∅TACGCA
∅0000000
G0000111

T0111112

C0123333
A0123334

          

          
def lcs(X, Y):
          n, m = len(X), len(Y)
          L = [[0] * (m + 1) for _ in range(n + 1)]
          for i in range(1, n + 1):
              for j in range(1, m + 1):
                  if X[i - 1] == Y[j - 1]:
                      L[i][j] = L[i - 1][j - 1] + 1
                  else:
                      L[i][j] = max(L[i - 1][j], L[i][j - 1])
          return L[n][m]

      print(lcs("GATTACA", "TACGCA"))   # 4

          
행은 GATTACA, 열은 TACGCA의 글자이다. 주황 칸은 두 글자가 같아 대각선 위 칸에서 1을 더한 곳으로, 오른쪽 아래에서 거꾸로 따라가면 T, A, C, A를 얻는다. 표의 칸은 (n+1)(m+1)개이므로 시간은 O(nm)이다. 모든 부분 수열을 비교하는 완전 탐색이라면 길이 n인 서열의 부분 수열만 2ⁿ개이다.
