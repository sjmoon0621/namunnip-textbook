2.5.1구의 방정식

구는 공간에서 한 점(중심)으로부터 거리가 일정한 점들의 집합이다. 원의 방정식이 평면에서의 거리 공식에서 나왔듯이, 구의 방정식은 공간의 거리 공식에서 나온다.

정리 2.5.1 구의 방정식

중심이 \(C(a, b, c)\)이고 반지름이 \(r\)인 구의 방정식은 \[(x - a)^2 + (y - b)^2 + (z - c)^2 = r^2\] 이다. 전개한 꼴 \(x^2 + y^2 + z^2 + Ax + By + Cz + D = 0\)은 완전제곱식으로 고쳐 중심과 반지름을 찾는다.

전개한 식에서 \(x^2\), \(y^2\), \(z^2\)의 계수가 모두 같고 \(xy\) 같은 항이 없어야 구가 된다. 완전제곱식으로 고친 뒤 우변이 양수이면 구, 0이면 한 점, 음수이면 그런 점이 없다.

2.5.2구와 평면의 교선

구 \(x^2 + y^2 + z^2 = r^2\)을 평면 \(z = k\)로 자르면, \(z = k\)를 대입하여 \(x^2 + y^2 = r^2 - k^2\)이다. 따라서 \(|k| < r\)이면 단면은 평면 \(z = k\) 위의 반지름 \(\sqrt{r^2 - k^2}\)인 원이다. 이는 중심에서 평면까지의 거리 \(|k|\), 단면의 반지름, 구의 반지름 \(r\)이 직각삼각형을 이루기 때문이다.1

그림 1에서 \(k\)를 0에서 4까지 움직여 보자. \(k = 0\)이면 단면이 반지름 4인 가장 큰 원이고, \(k\)가 커질수록 작아지다가 \(k = 4\)에서 한 점이 된다. 지구의 위도선이 극으로 갈수록 작아지는 것과 같다.

2.5.3예제 하나를 끝까지

예제 2.5.2

구 \(x^2 + y^2 + z^2 - 2x + 4y - 6z - 11 = 0\)의 중심과 반지름을 구하고, 이 구를 \(xy\)평면으로 자른 단면의 넓이를 구하여라.

완전제곱식으로 고치면 \((x - 1)^2 + (y + 2)^2 + (z - 3)^2 = 11 + 1 + 4 + 9 = 25\)이다. 중심은 \((1, -2, 3)\), 반지름은 5이다.

\(xy\)평면은 \(z = 0\)이고, 중심에서 \(xy\)평면까지의 거리는 \(z\)좌표의 절댓값 3이다. 단면의 반지름은 \(\sqrt{25 - 9} = 4\)이므로 넓이는 \(16\pi\)이다. 대입으로 확인하면 \(z = 0\)일 때 \((x - 1)^2 + (y + 2)^2 = 16\)으로 같다.

아래 탐구 카드에서 구의 방정식을 쓰고, 전개된 식에서 중심과 반지름을 되찾고, 단면의 크기를 직접 구해 보자.

  1. 구 위의 점에서 중심까지 그은 반지름에 수직인 평면은 구에 한 점에서만 닿는다. 이를 접평면이라 하며, 원의 접선이 반지름에 수직인 것을 공간으로 넓힌 것이다.
마무리

중심이 \((a, b, c)\), 반지름이 \(r\)인 구의 방정식은 \((x - a)^2 + (y - b)^2 + (z - c)^2 = r^2\)이며, 전개한 식은 완전제곱식으로 고쳐 읽는다. 중심에서 거리 \(d\)인 평면으로 자른 단면은 반지름 \(\sqrt{r^2 - d^2}\)인 원이다. 그래서 처음 질문의 수박 단면은 중심에서 멀리 자를수록 작아지며, 그 반지름은 피타고라스 정리로 정해진다.

Q의 좌표를 식의 좌변에 넣은 값과 \(r^2\)을 비교해 보자. 그림을 옆으로 끌면 돌려 볼 수 있다.

  1. 질문원은 중심에서 거리가 \(r\)인 점들이라는 말을 \((x - a)^2 + (y - b)^2 = r^2\)으로 바꾸어 썼다. 공간에서 같은 말을 하면 어떤 식이 될까?
  2. 복원좌표공간의 두 점 \(A(x_1, y_1, z_1), B(x_2, y_2, z_2)\) 사이의 거리는 \(\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}\)이다.
  3. 설명공간에서 한 점 C로부터 일정한 거리 \(r\)에 있는 점 전체의 도형을 구라 하고, C를 구의 중심, \(r\)을 반지름이라고 한다. 점 \(P(x, y, z)\)가 중심 \(C(a, b, c)\), 반지름 \(r\)인 구 위에 있을 조건은 \(CP = r\), 곧 \(CP^2 = r^2\)이므로 \((x - a)^2 + (y - b)^2 + (z - c)^2 = r^2\)이고, 이것을 구의 방정식이라고 한다. 중심이 원점이면 \(x^2 + y^2 + z^2 = r^2\)이며, 거꾸로 이 식을 만족하는 점은 모두 구 위에 있으므로 식과 도형이 정확히 대응한다.
  4. 연결식을 전개하면 \(x^2 + y^2 + z^2 + Ax + By + Cz + D = 0\) 꼴이 되고, 다음 카드에서는 이 꼴에서 거꾸로 중심과 반지름을 찾는다. 또 점 Q에 대하여 CQ와 \(r\)을 비교하면 Q가 구의 안쪽(CQ < \(r\)), 구 위\((CQ = r)\), 바깥쪽(CQ > \(r\)) 중 어디에 있는지 알 수 있다.
  5. 적용\(Q(3, 2, 2)\)를 고르고 중심을 \((1, 0, 1)\)로 둔 채 반지름을 바꾸어, Q가 구 위에 놓이는 반지름과 그때의 CQ를 찾아보자. 이번에는 반지름 3인 구가 원점을 지나도록 중심을 움직이고, 중심의 좌표에 어떤 조건이 있는지 보자.
  6. 판단\((x + 1)^2\)은 \(x - (-1)\)의 제곱이므로 중심의 \(x\)좌표는 \(-1\)인데, 부호를 그대로 읽는 실수가 흔하다. 또 우변은 반지름이 아니라 반지름의 제곱이어서, 우변이 8이면 반지름은 8이 아니라 \(2\sqrt{2}\)이다.

전개된 식에서 구의 중심과 반지름을 되찾을 수 있을까?

구의 방정식의 일반형 · 완전제곱식

—

중심
—
\(r^2 = \frac{A^2 + B^2 + C^2}{4} - D\)
—
나타내는 도형
—

식은 \(x^2 + y^2 + z^2 + Ax + By + Cz + D = 0\)이다. 그림을 옆으로 끌면 돌려 볼 수 있다.

  1. 질문\(x^2 + y^2 + z^2 - 2x + 4y - 6z + 5 = 0\)은 구일까? 구라면 중심과 반지름은 무엇일까? 상수항이 커지면 무슨 일이 생길까?
  2. 복원\(x^2 + px = (x + \frac{p}{2})^2 - \frac{p^2}{4}\)처럼 이차식은 완전제곱식과 상수로 바꿀 수 있다. 그리고 원의 방정식 \(x^2 + y^2 + Ax + By + C = 0\)에서도 같은 방법으로 중심과 반지름을 찾았다.
  3. 설명\(x^2 + y^2 + z^2 + Ax + By + Cz + D = 0\)을 문자별로 묶어 완전제곱식을 만들면 \((x + \frac{A}{2})^2 + (y + \frac{B}{2})^2 + (z + \frac{C}{2})^2 = \frac{A^2 + B^2 + C^2 - 4D}{4}\)이다. 우변이 양수이면 이 식은 중심 \((-\frac{A}{2}, -\frac{B}{2}, -\frac{C}{2})\), 반지름 \(\frac{\sqrt{A^2 + B^2 + C^2 - 4D}}{2}\)인 구이다. 따라서 이 꼴의 식이 구를 나타낼 조건은 \(A^2 + B^2 + C^2 - 4D\) > 0이다.
  4. 연결이 방법은 \(x^2, y^2, z^2\)의 계수가 모두 같고 \(xy, yz, zx\) 항이 없어야 쓰며, 계수가 모두 2이면 먼저 양변을 2로 나눈다. 그리고 네 점을 지나는 구를 구할 때는 이 일반형에 네 점을 넣어 \(A, B, C, D\)에 대한 연립방정식을 푼다.
  5. 적용첫 번째 식을 고르고 ‘다음 단계’를 눌러 완전제곱식을 만드는 과정을 따라가 보자. 그다음 \(D\)를 키우며 구의 크기가 어떻게 변하는지 보고, \(r^2\)이 0이 되는 \(D\)가 얼마이며 그때 그림에 무엇이 남는지, \(D\)가 그보다 크면 어떻게 되는지 확인해 보자.
  6. 판단모든 이차식이 구를 나타내지는 않는다. 우변이 0이면 중심 한 점만 식을 만족하고, 우변이 음수이면 제곱의 합이 음수가 될 수 없으므로 식을 만족하는 점이 없다. 또 반지름을 구할 때 \(A^2 + B^2 + C^2\)을 4로 나누는 것을 잊으면 조건이 크게 틀어진다.

탐구 3

구를 평면 \(z = k\)로 자르면 단면의 크기는 어떻게 정해질까?

구의 단면 · 좌표평면과 접하는 구
중심과 평면 사이 거리 \(d\)
—
단면의 반지름 \(\sqrt{r^2 - d^2}\)
—
단면의 넓이
—

\(k = 0\)이면 자르는 평면은 \(xy\)평면이다. 그림을 옆으로 끌면 돌려 볼 수 있다.

  1. 질문수박을 바닥과 평행하게 썰면 단면은 원이고, 중심에서 멀리 썰수록 원이 작아진다. 썬 높이와 단면의 반지름 사이에는 어떤 식이 있을까?
  2. 복원중심이 \(C(a, b, c)\)이고 반지름이 \(r\)인 구의 방정식은 \((x - a)^2 + (y - b)^2 + (z - c)^2 = r^2\)이다. 그리고 평면 \(z = k\) 위의 점은 \(z\)좌표가 모두 \(k\)이다.
  3. 설명구의 방정식에 \(z = k\)를 넣으면 \((x - a)^2 + (y - b)^2 = r^2 - (k - c)^2\)이다. 중심에서 평면까지의 거리를 \(d = |k - c|\)라 하면, \(d\) < \(r\)일 때 단면은 평면 \(z = k\) 위에서 중심이 \((a, b, k)\), 반지름이 \(\sqrt{r^2 - d^2}\)인 원이다. \(d = r\)이면 한 점에서 만나 구는 평면에 접한다고 하고, \(d\) > \(r\)이면 만나지 않는다. 그리고 반지름 공식은 구의 중심, 단면의 중심, 단면 위의 한 점이 이루는 직각삼각형의 피타고라스 정리와 같다.
  4. 연결구가 \(xy\)평면에 접하면 \(|c| = r\), yz평면에 접하면 \(|a| = r\), zx평면에 접하면 \(|b| = r\)이므로, 세 좌표평면에 모두 접하는 구는 \(|a| = |b| = |c| = r\)이다. 구를 \(x = k, y = k\)로 잘라도 같은 방법으로 단면을 구한다.
  5. 적용\(C(1, -1, 2)\)에서 \(k\)를 움직여 단면이 가장 큰 높이와 그때 단면의 반지름을 찾아보자. 그리고 반지름을 2로 두고 \(k = 0\)으로 맞추면 무슨 일이 생기는지, 구가 \(xy\)평면과 만나지 않게 하려면 \(r\)이 어떤 범위여야 하는지 확인해 보자.
  6. 판단단면의 반지름을 \(r - d\)로 계산하는 실수가 흔한데, \(r, d\), 단면의 반지름은 직각삼각형의 세 변이므로 제곱끼리 빼야 한다. 또 구가 \(xy\)평면에 접할 조건은 중심의 \(z\)좌표가 반지름과 같은 것이지, 중심이 원점에서 \(r\)만큼 떨어진 것이 아니다.
