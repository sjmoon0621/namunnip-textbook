쌍곡선

타원에서 거리의 합을 차로 바꾸면 전혀 다른 곡선이 나옵니다. 서로 떨어진 두 가지가 끝없이 뻗어 나가며, 멀리 갈수록 두 직선에 붙어 갑니다. 이 절에서는 쌍곡선의 방정식을 타원과 같은 방법으로 세우고, 타원과 무엇이 같고 무엇이 다른지 비교합니다. 이어서 곡선이 가까워지는 직선인 점근선을 식에서 찾습니다.

먼저 알면 좋은 것 타원의 방정식두 점 사이의 거리점과 직선 사이의 거리도형의 평행이동

빨간 점 P를 위아래로 끌고, 반대쪽으로도 옮겨 보세요. 거리의 차가 \(2a\)로 유지되는 길만 따라갑니다. \(c\)는 \(a\)보다 커야 합니다.

  1. 질문두 점 \(F(3, 0), F'(-3, 0)\)이 있습니다. 두 점까지 거리의 차가 4인 점을 모두 모으면 어떤 곡선이 될까요? 타원처럼 닫힌 곡선이 될까요?
  2. 복원타원은 두 초점까지 거리의 합이 일정한 점의 모임이었고, 근호를 두 번 없애 \(\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1(b^2 = a^2 - c^2)\)을 얻었습니다. 삼각형에서 두 변의 길이의 차는 나머지 한 변보다 작습니다.
  3. 설명평면 위의 두 점 F, F'에서 거리의 차가 일정한 점들의 모임을 쌍곡선이라 하고, F, F'을 초점이라고 합니다. 초점이 \(F(c, 0), F'(-c, 0)\)이고 거리의 차가 \(2a\)(\(c\) > \(a\) > 0)이면 \(|PF - PF'| = 2a\), 곧 \(\sqrt{(x - c)^2 + y^2} - \sqrt{(x + c)^2 + y^2} = \pm2a\)입니다. 타원과 같은 방법으로 두 번 제곱하면 \((c^2 - a^2)x^2 - a^2y^2 = a^2(c^2 - a^2)\)이고, \(b^2 = c^2 - a^2\)(\(b\) > 0)로 놓으면 \(\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1\)입니다. 두 초점을 지나는 직선과 쌍곡선이 만나는 두 점 \((\pm a, 0)\)을 꼭짓점, 두 꼭짓점을 잇는 선분을 주축, 주축의 중점을 중심이라고 합니다. 주축의 길이는 거리의 차와 같은 \(2a\)입니다. 초점이 \((0, \pm c)\)이면 \(\frac{x^2}{b^2} - \frac{y^2}{a^2} = -1\)입니다.
  4. 연결\(PF - PF' = 2a\)인 점들과 \(PF - PF' = -2a\)인 점들이 서로 떨어진 두 가지를 이룹니다. 그래서 쌍곡선은 닫히지 않고 두 갈래로 끝없이 뻗습니다. 타원은 \(a^2 = b^2 + c^2\), 쌍곡선은 \(c^2 = a^2 + b^2\)입니다. 두 곡선에서 가장 긴 것이 다르다는 점을 기억하세요.
  5. 적용P를 오른쪽 가지에서 위아래로 끌며 PF, \(PF'\)은 바뀌어도 차가 4로 그대로인지 보세요. 왼쪽 가지로 옮기면 PF와 \(PF'\) 중 어느 쪽이 더 긴가요? \(c\)는 그대로 두고 \(2a\)를 줄이면 두 가지는 어떻게 바뀌나요? \(2a\)를 \(2c\)에 가깝게 늘리면 어떻게 되나요?
  6. 판단쌍곡선에서 \(a\)는 \(x^2\)의 분모가 아니라 양의 항의 분모에서 나옵니다. \(\frac{x^2}{16} - \frac{y^2}{9} = -1\)은 \(\frac{y^2}{9} - \frac{x^2}{16} = 1\)과 같으므로 주축이 \(y\)축 위에 있고, 꼭짓점은 \((0, \pm3)\)입니다. 또 타원과 달리 \(a\)가 \(b\)보다 클 필요가 없습니다. 거리의 차 \(2a\)는 \(2c\)보다 작아야 합니다. 같으면 초점 바깥쪽으로 뻗은 두 반직선이 되고, 크면 그런 점이 없습니다.

1.3.2

쌍곡선은 어떤 직선에 한없이 가까워질까?

점근선 · 쌍곡선의 방정식

—

점근선
—
꼭짓점
—
초점
—
P에서 점근선까지
—

빨간 점 P를 곡선을 따라 멀리 끌어 보세요. 초록 중심을 끌면 쌍곡선 전체가 옮겨 갑니다.

  1. 질문쌍곡선 \(\frac{x^2}{4} - y^2 = 1\)을 멀리까지 그리면 점점 곧은 선처럼 보입니다. 이 곡선은 어떤 직선에 가까워질까요? 그 직선과 만나기도 할까요?
  2. 복원쌍곡선 \(\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1\)의 꼭짓점은 \((\pm a, 0)\), 초점은 \((\pm c, 0)\)이고 \(c^2 = a^2 + b^2\)입니다. 점 \((x_1, y_1)\)에서 직선 \(px + qy + r = 0\)까지의 거리는 \(\frac{|px_1 + qy_1 + r|}{\sqrt{p^2 + q^2}}\)입니다.
  3. 설명식을 \(y^2 = \frac{b^2}{a^2}x^2 - b^2\)으로 고치면, \(|x|\)가 커질수록 \(-b^2\)은 \(x^2\)항에 비해 무시할 만큼 작아집니다. 그래서 곡선은 두 직선 \(y = \pm\frac{b}{a}x\)에 한없이 가까워지지만 만나지는 않습니다. 이런 직선을 점근선이라고 합니다. 점근선은 꼭짓점을 지나는 가로 \(2a\), 세로 \(2b\)인 직사각형의 대각선을 늘인 직선입니다. \(\frac{x^2}{a^2} - \frac{y^2}{b^2} = -1\)은 같은 점근선을 가지면서 꼭짓점이 \((0, \pm b)\), 초점이 \((0, \pm\sqrt{a^2 + b^2})\)이고 주축이 \(y\)축 위에 있습니다. 중심을 \((m, n)\)으로 옮기면 \(\frac{(x - m)^2}{a^2} - \frac{(y - n)^2}{b^2} = \pm1\)이고, 점근선도 \(y - n = \pm\frac{b}{a}(x - m)\)으로 옮겨 갑니다.
  4. 연결점근선은 우변을 0으로 바꾼 식 \(\frac{x^2}{a^2} - \frac{y^2}{b^2} = 0\)에서도 바로 나옵니다. 인수분해하면 \((\frac{x}{a} - \frac{y}{b})(\frac{x}{a} + \frac{y}{b}) = 0\)입니다. 전개형으로 보면 \(x^2\)과 \(y^2\)의 계수 부호가 서로 다른 식이 쌍곡선입니다. 부호가 같으면 타원, 한쪽만 있으면 포물선입니다.
  5. 적용P를 꼭짓점에서 멀리 끌면서 점근선까지의 거리가 어떻게 줄어드는지 보세요. 0이 되는 곳이 있나요? 우변을 \(-1\)로 바꾸면 직사각형과 점근선은 그대로인데 무엇이 바뀌나요? \(a = b\)로 놓으면 두 점근선은 어떤 각을 이루나요?
  6. 판단점근선의 기울기는 늘 ±√(\(y^2\)의 분모)/√(\(x^2\)의 분모)입니다. 주축이 어느 쪽이든, 우변이 1이든 \(-1\)이든 같습니다. \(\frac{x^2}{4} - \frac{y^2}{9} = 1\)의 점근선을 \(y = \pm\frac{2}{3}x\)로 쓰는 실수가 많습니다. 바르게는 \(\pm\frac{3}{2}x\)입니다. 또 점근선은 곡선의 일부가 아니므로 쌍곡선 위의 점은 점근선 위에 놓이지 않습니다.
