평면과 구의 방정식

좌표평면에서 점 하나와 법선벡터로 쓴 식은 직선이었습니다. 같은 식을 좌표공간에서 쓰면 무엇이 될까요? 또 원을 '중심에서 거리가 일정한 점'으로 나타냈듯이, 공간에서 같은 조건은 구가 됩니다. 이 절에서는 벡터의 내적과 크기로 평면과 구를 짧은 식 하나로 나타내고, 그 식을 좌표로 풀어 봅니다.

3.5.1

공간에서 수직인 벡터 하나는 무엇을 정할까?

평면의 방정식 · 법선벡터

—

n·AP
—
점 P
—
좌표축과 만나는 점
—

점 A(1, 1, 1)은 고정입니다. 법선벡터 n = (a, b, c)를 바꾸고, P를 평면 위에서 돌려 보세요. 그림을 끌면 돌아갑니다.

  1. 질문책상 위에 연필을 수직으로 세우면 책상면의 방향이 정해집니다. 공간에서 평면을 '한 점'과 '수직인 방향 하나'로 나타낼 수 있을까요?
  2. 복원점 A를 지나고 법선벡터가 n인 좌표평면의 직선은 n·(p − a) = 0이었습니다. 공간에서 내적은 a1b1 + a2b2 + a3b3이고, 한 벡터에 수직인 벡터는 한 평면을 이룰 만큼 많습니다.
  3. 설명점 A를 지나고 영벡터가 아닌 벡터 n에 수직인 평면을 α라 합니다. 점 P가 α 위에 있을 필요충분조건은 AP ⊥ n 또는 P = A, 곧
    n·(p − a) = 0
    입니다. n을 평면의 법선벡터라고 합니다. n = (a, b, c), A(x1, y1, z1)이면 a(x − x1) + b(y − y1) + c(z − z1) = 0, 정리하면 ax + by + cz + d = 0입니다. 거꾸로 일차방정식 ax + by + cz + d = 0((a, b, c) ≠ (0, 0, 0))은 언제나 평면이고, 계수 (a, b, c)가 그 법선벡터입니다.
  4. 연결좌표평면에서 직선이던 식이 좌표공간에서는 평면이 됩니다. 식이 같아도 사는 공간의 차원이 다르면 나타내는 도형이 달라집니다. 두 평면이 이루는 각은 두 법선벡터가 이루는 각으로 구하고, 직선과 평면이 평행한지는 방향벡터와 법선벡터의 내적이 0인지로 판단합니다.
  5. 적용P를 한 바퀴 돌리는 동안 n·AP가 늘 0인지 확인하세요. a = 0으로 두면 평면은 어느 축과 평행해지나요? a = b = 0이면 평면은 어떻게 놓이고 식은 무엇인가요? n을 (2, 2, 4)처럼 2배로 바꿀 수 있다면 평면은 달라질까요?
  6. 판단평면 위의 점을 모두 담으려면 '한 점과 법선벡터' 두 가지가 필요합니다. 법선벡터만으로는 서로 평행한 평면들 가운데 어느 것인지 정해지지 않습니다. 또 ax + by + cz + d = 0에서 (a, b, c)는 평면 위의 방향이 아니라 평면에 수직인 방향입니다.

3.5.2

중심에서 거리가 같은 점을 벡터로 쓰면?

구의 방정식 · 벡터방정식, 단면

—

|CP|
—
xy평면과 만나는 모양
—
단면 원의 반지름
—

중심과 반지름을 바꾸어 보세요. 초록 원은 구를 xy평면(z = 0)으로 자른 단면입니다. 그림을 끌면 돌아갑니다.

  1. 질문원은 '한 점에서 거리가 일정한 평면 위의 점'입니다. 같은 조건을 공간에서 쓰면 어떤 도형이 되고, 그 식은 벡터로 어떻게 쓸까요?
  2. 복원벡터의 크기는 |a| = √(a·a)이고, 두 점 C, P 사이의 거리는 |CP| = |p − c|입니다. 좌표공간에서 두 점 사이의 거리는 √((Δx)2 + (Δy)2 + (Δz)2)입니다.
  3. 설명중심 C, 반지름 r인 구 위의 점 P는 |CP| = r을 만족하므로 구의 벡터방정식은
    |p − c| = r, 또는 (p − c)·(p − c) = r2
    입니다. C(a, b, c)로 성분을 쓰면 (x − a)2 + (y − b)2 + (z − c)2 = r2이고, 전개하면 x2 + y2 + z2 + Ax + By + Cz + D = 0 꼴이 됩니다. 구를 평면 z = 0으로 자르면 z = 0을 넣은 (x − a)2 + (y − b)2 = r2 − c2이므로, |c| < r이면 반지름 √(r2 − c2)인 원, |c| = r이면 한 점에서 접하고, |c| > r이면 만나지 않습니다.
  4. 연결평면의 원 |p − c| = r과 공간의 구는 같은 식입니다. 직선과 평면에서 보았듯이 벡터방정식은 차원을 바꾸어도 모양이 그대로이고, 성분의 개수만 달라집니다. 구와 평면의 위치 관계는 중심에서 평면까지의 거리와 반지름을 비교해 판단합니다.
  5. 적용중심의 높이 c3을 0에서 2까지 올리며 단면의 원이 어떻게 작아지다 사라지는지 보세요. r = 2일 때 c3 = 2이면 무엇이 일어나나요? r을 1.5로 줄이면요? 전개한 식의 상수항이 중심과 반지름으로 어떻게 정해지는지 확인하세요.
  6. 판단x2 + y2 + z2 + Ax + By + Cz + D = 0이 언제나 구인 것은 아닙니다. 완전제곱식으로 고친 우변이 양수일 때만 구이고, 0이면 한 점, 음수이면 아무 점도 없습니다. 또 단면 원의 반지름은 구의 반지름 r이 아니라 √(r2 − c2)입니다.
