벡터의 내적

비스듬히 끄는 수레는 힘의 일부만 앞으로 가는 데 쓰입니다. 두 벡터가 '같은 쪽을 얼마나 향하는지'를 하나의 실수로 나타낸 것이 내적입니다. 이 절에서는 내적을 그림의 길이와 각으로 정의하고, 그것이 성분의 곱의 합과 언제나 같다는 것을 확인한 뒤, 두 벡터가 이루는 각과 수직 조건을 구합니다.

두 끝점을 끌어 보세요. 굵은 초록(또는 주황) 선분은 b를 a 방향으로 내린 정사영이고, 그 부호 있는 길이가 |b|cos θ입니다.

  1. 질문수레를 줄로 끌 때 줄이 비스듬하면 힘의 일부만 수레를 앞으로 옮깁니다. 힘 F와 이동 s가 '얼마나 같은 쪽인지'까지 담은 곱은 어떻게 정할까요?
  2. 복원삼각형에서 cos θ는 빗변에 대한 밑변의 비이고, θ가 90°보다 크면 음수입니다. 코사인법칙은 c2 = a2 + b2 − 2ab cos C입니다.
  3. 설명영벡터가 아닌 두 벡터 a, b의 시점을 맞추었을 때 이루는 각을 θ(0 ≤ θ ≤ π)라고 하면, 내적을 a·b = |a||b|cos θ로 정합니다. 둘 중 하나가 0이면 a·b = 0입니다. |b|cos θ는 b를 a 방향으로 내린 그림자(정사영)의 부호 있는 길이이므로, 내적은 '|a| × 그림자 길이'입니다. 코사인법칙으로 |b − a|2 = |a|2 + |b|2 − 2|a||b|cos θ를 쓰고 양변을 성분으로 풀면 a·b = a1b1 + a2b2를 얻습니다. 그래서 cos θ = a·b / (|a||b|)로 두 벡터가 이루는 각을 구할 수 있습니다. 성질: a·a = |a|2, a·b = b·a, a·(b + c) = a·b + a·c, (ka)·b = k(a·b).
  4. 연결물리에서 힘이 한 일 W = F·s가 바로 내적입니다. 또 영벡터가 아닌 두 벡터가 수직일 필요충분조건 a·b = 0은 직선과 평면의 방정식에서 법선벡터를 쓰는 근거가 됩니다.
  5. 적용두 값 |a||b|cos θ와 a1b1 + a2b2가 언제나 같은지 확인하세요. a = (4, 1)일 때 b를 어디에 두면 내적이 0이 되나요? θ가 90°를 넘으면 내적의 부호는 어떻게 되나요? b를 a와 같은 방향으로 두면 내적은 무엇과 같아지나요?
  6. 판단내적의 결과는 벡터가 아니라 실수입니다. 그래서 (a·b)c와 a(b·c)는 일반적으로 다릅니다. 또 a·b = 0이라고 해서 a = 0이거나 b = 0인 것은 아닙니다. 두 벡터가 수직이어도 내적은 0입니다.

b의 성분을 바꾸어 내적이 0이 되는 경우를 찾고, 그림을 끌어 돌려서 정말 직각인지 보세요.

  1. 질문공간에서는 화면에 비친 각이 실제 각과 다르게 보입니다. 두 막대가 수직인지 눈으로 확신하기 어렵다면 무엇으로 판단할까요?
  2. 복원평면에서 a·b = |a||b|cos θ = a1b1 + a2b2였습니다. 공간벡터의 크기는 √(a12 + a22 + a32)입니다.
  3. 설명두 공간벡터도 시점을 맞추면 한 평면 위에 놓이므로 내적의 정의 a·b = |a||b|cos θ가 그대로 쓰입니다. 코사인법칙으로 같은 계산을 하면 a·b = a1b1 + a2b2 + a3b3입니다. 따라서 영벡터가 아닌 두 벡터에 대하여
    cos θ = (a·b) / (|a||b|),
    a ⊥ b ⇔ a·b = 0, a ∥ b ⇔ b = ka(k ≠ 0)입니다.
  4. 연결공간에서 수직 조건을 수식 하나로 확인할 수 있으므로, 다음 절들에서 직선의 방향벡터와 평면의 법선벡터가 수직인지 판단할 때 이 식을 씁니다.
  5. 적용a = (1, 2, 2)에서 내적이 0이 되는 b를 두 개 이상 찾아보세요. 예를 들어 (2, −1, 0), (0, 1, −1)은 어떤가요? b를 a의 2배로 두면 θ는 얼마가 되나요? 그림을 돌려서 같은 θ가 화면에서는 다르게 보이는 것도 확인하세요.
  6. 판단한 벡터에 수직인 벡터가 하나뿐이라고 생각하기 쉽습니다. 공간에서 a에 수직인 벡터는 한 평면을 이룰 만큼 많습니다. 이 사실이 다음 절의 '법선벡터 하나로 평면을 정한다'는 생각의 바탕입니다.
