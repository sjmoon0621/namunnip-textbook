벡터의 내적

본문

상자를 끈으로 비스듬히 끌면, 같은 힘을 주어도 끈을 바닥과 나란하게 당길 때보다 덜 움직인다. 힘 가운데 이동 방향을 향하는 부분만 일을 하기 때문이다. 두 벡터가 같은 방향을 얼마나 향하는지를 수 하나로 나타낼 수 있다면, 일의 양도, 두 벡터가 수직인지도 쉽게 알 수 있지 않을까?

먼저 알아야 할 것벡터의 성분(위치벡터), 코사인의 뜻, 코사인법칙(대수).

3.3.1내적의 정의

정의 3.3.1 벡터의 내적

영벡터가 아닌 두 벡터 \(\vec a\), \(\vec b\)가 이루는 각이 \(\theta\) (\(0 \le \theta \le \pi\))일 때 \[\vec a \cdot \vec b = |\vec a||\vec b|\cos\theta\] 를 두 벡터의 내적이라 한다. 내적은 벡터가 아니라 실수이다.

\(|\vec b|\cos\theta\)는 \(\vec b\)를 \(\vec a\) 방향으로 정사영한 길이이다. 따라서 내적은 '\(\vec a\)의 크기 \(\times\) \(\vec b\) 가운데 \(\vec a\) 방향 부분'이다. 그림 1에서 각을 바꾸어 보자. 0°이면 내적이 최대인 12, 90°이면 0, 180°이면 최소인 \(-12\)이다. 영벡터가 아닌 두 벡터가 수직일 필요충분조건은 \(\vec a \cdot \vec b = 0\)이다.

이번에는 \(\vec a\)를 고정하고 \(\vec b\)를 바꾸어 가며, 내적이 같은 값이 되는 \(\vec b\)들이 어디에 있는지 보자. 내적은 \(|\vec a|\)와 정사영의 길이를 곱한 것이므로, 정사영의 길이가 같은 \(\vec b\)들은 내적도 같다. 정사영의 길이가 같다는 것은 \(\vec b\)의 끝점에서 \(\vec a\)가 놓인 직선에 내린 수선의 발이 같다는 뜻이다. 그래서 내적이 같은 \(\vec b\)들의 끝점은 \(\vec a\)에 수직인 한 직선 위에 늘어서고, 내적의 값을 바꾸면 이 직선이 \(\vec a\) 방향으로 나란히 옮겨 간다. 지도의 등고선처럼 \(\vec a\)에 수직인 평행선들이 내적의 값을 매기는 셈이다. 뒤에서 배울 직선과 평면의 방정식에서 법선벡터가 바로 이 \(\vec a\)의 역할을 한다.

3.3.2성분으로 구하는 내적

\(\vec a = (a_1, a_2)\), \(\vec b = (b_1, b_2)\)가 이루는 삼각형에 코사인법칙을 쓰면 \(|\vec b - \vec a|^2 = |\vec a|^2 + |\vec b|^2 - 2|\vec a||\vec b|\cos\theta\)이다. 좌변과 \(|\vec a|^2\), \(|\vec b|^2\)를 성분으로 전개하여 정리하면 \(|\vec a||\vec b|\cos\theta = a_1b_1 + a_2b_2\)가 나온다.

정리 3.3.2 성분으로 나타낸 내적

\[\vec a \cdot \vec b = a_1b_1 + a_2b_2\quad (\text{공간에서는 } a_1b_1 + a_2b_2 + a_3b_3)\] 따라서 \(\cos\theta = \dfrac{\vec a \cdot \vec b}{|\vec a||\vec b|}\)로 두 벡터가 이루는 각을 구할 수 있다.

내적은 교환법칙 \(\vec a \cdot \vec b = \vec b \cdot \vec a\)와 분배법칙이 성립하고, \(\vec a \cdot \vec a = |\vec a|^2\)이다. 물리에서 힘 \(\vec F\)가 물체를 \(\vec s\)만큼 옮길 때 한 일이 \(W = \vec F \cdot \vec s\)이다.1

3.3.3예제 하나를 끝까지

예제 3.3.3

\(\vec a = (1, 2, 2)\), \(\vec b = (3, 0, 4)\)가 이루는 각 \(\theta\)에 대하여 \(\cos\theta\)를 구하여라. 또 \(\vec c = (2, k, -1)\)이 \(\vec a\)와 수직이 되도록 \(k\)를 구하여라.

\(\vec a \cdot \vec b = 3 + 0 + 8 = 11\), \(|\vec a| = \sqrt{1 + 4 + 4} = 3\), \(|\vec b| = \sqrt{9 + 0 + 16} = 5\)이다. 따라서 \(\cos\theta = \dfrac{11}{15}\)이고 \(\theta \approx 43°\)이다.

\(\vec a \cdot \vec c = 2 + 2k - 2 = 2k = 0\)이므로 \(k = 0\)이다. 공간에서 각도기로 직각을 재지 않아도, 성분 계산 한 번으로 수직인지 판정할 수 있다.

  1. 끈으로 상자를 바닥과 30° 각도로 100 N의 힘으로 당겨 10 m 옮겼다면 일은 \(100 \times 10 \times \cos 30° \approx 866\) J이다. 같은 힘을 바닥과 나란히 주었다면 1000 J이다.
마무리

두 벡터의 내적 \(\vec a \cdot \vec b = |\vec a||\vec b|\cos\theta\)는 한 벡터의 크기에 다른 벡터의 그 방향 정사영 길이를 곱한 실수이며, 성분으로는 \(a_1b_1 + a_2b_2 + a_3b_3\)이다. 내적이 0이면 두 벡터는 수직이다. 그래서 처음 질문의 '같은 쪽을 얼마나 향하는지'는 내적 하나로 나타나고, 끈이 한 일도 힘과 이동의 내적이다.

두 끝점을 끌어 보자. 굵은 초록(또는 주황) 선분은 \(\vec{b}\)를 \(\vec{a}\) 방향으로 내린 정사영이고, 그 부호 있는 길이가 \(|\vec{b}|\cos \theta\)이다.

  1. 질문수레를 줄로 끌 때 줄이 비스듬하면 힘의 일부만 수레를 앞으로 옮긴다. 힘 \(\vec{F}\)와 이동 \(\vec{s}\)가 얼마나 같은 쪽인지까지 담은 곱은 어떻게 정할까?
  2. 복원삼각형에서 \(\cos \theta\)는 빗변에 대한 밑변의 비이고, \(\theta\)가 \(90^\circ\)보다 크면 음수이다. 그리고 코사인법칙은 \(c^2 = a^2 + b^2 - 2ab \cos C\)이다.
  3. 설명영벡터가 아닌 두 벡터 \(\vec{a}, \vec{b}\)의 시점을 맞추었을 때 이루는 각을 \(\theta(0 \le \theta \le \pi)\)라고 하면, 내적을 \(\vec{a}\cdot\vec{b} = |\vec{a}||\vec{b}|\cos \theta\)로 정하고, 둘 중 하나가 \(\vec{0}\)이면 \(\vec{a}\cdot\vec{b} = 0\)이다. \(|\vec{b}|\cos \theta\)는 \(\vec{b}\)를 \(\vec{a}\) 방향으로 내린 그림자(정사영)의 부호 있는 길이이므로, 내적은 \(|\vec{a}|\)에 그림자 길이를 곱한 값이다. 코사인법칙으로 \(|\vec{b} - \vec{a}|^2 = |\vec{a}|^2 + |\vec{b}|^2 - 2|\vec{a}||\vec{b}|\cos \theta\)를 쓰고 양변을 성분으로 풀면 \(\vec{a}\cdot\vec{b} = a_1b_1 + a_2b_2\)를 얻으므로, \(\cos \theta = \frac{\vec{a}\cdot\vec{b}}{|\vec{a}||\vec{b}|}\)로 두 벡터가 이루는 각을 구할 수 있다. 또 내적은 \(\vec{a}\cdot\vec{a} = |\vec{a}|^2, \vec{a}\cdot\vec{b} = \vec{b}\cdot\vec{a}, \vec{a}\cdot(\vec{b} + \vec{c}) = \vec{a}\cdot\vec{b} + \vec{a}\cdot\vec{c}, (k\vec{a})\cdot\vec{b} = k(\vec{a}\cdot\vec{b})\)를 만족한다.
  4. 연결물리에서 힘이 한 일 \(W = \vec{F}\cdot\vec{s}\)가 바로 내적이다. 또 영벡터가 아닌 두 벡터가 수직일 필요충분조건 \(\vec{a}\cdot\vec{b} = 0\)은 직선과 평면의 방정식에서 법선벡터를 쓰는 근거가 된다.
  5. 적용두 값 \(|\vec{a}||\vec{b}|\cos \theta\)와 \(a_1b_1 + a_2b_2\)가 언제나 같은지 확인하고, \(\vec{a} = (4, 1)\)일 때 \(\vec{b}\)를 어디에 두면 내적이 0이 되는지 찾아보자. 그리고 \(\theta\)가 \(90^\circ\)를 넘으면 내적의 부호가 어떻게 되는지, \(\vec{b}\)를 \(\vec{a}\)와 같은 방향으로 두면 내적이 무엇과 같아지는지 보자.
  6. 판단내적의 결과는 벡터가 아니라 실수이다. 그래서 \((\vec{a}\cdot\vec{b})\vec{c}\)와 \(\vec{a}(\vec{b}\cdot\vec{c})\)는 일반적으로 다르다. 또 \(\vec{a}\cdot\vec{b} = 0\)이라고 해서 \(\vec{a} = \vec{0}\)이거나 \(\vec{b} = \vec{0}\)인 것은 아니며, 두 벡터가 수직이어도 내적은 0이다.

\(\vec{b}\)의 성분을 바꾸어 내적이 0이 되는 경우를 찾고, 그림을 끌어 돌려서 정말 직각인지 보자.

  1. 질문공간에서는 화면에 비친 각이 실제 각과 다르게 보인다. 두 막대가 수직인지 눈으로 확신하기 어렵다면 무엇으로 판단할까?
  2. 복원평면에서 \(\vec{a}\cdot\vec{b} = |\vec{a}||\vec{b}|\cos \theta = a_1b_1 + a_2b_2\)였다. 그리고 공간벡터의 크기는 \(\sqrt{a_1^2 + a_2^2 + a_3^2}\)이다.
  3. 설명두 공간벡터도 시점을 맞추면 한 평면 위에 놓이므로 내적의 정의 \(\vec{a}\cdot\vec{b} = |\vec{a}||\vec{b}|\cos \theta\)가 그대로 쓰이고, 코사인법칙으로 같은 계산을 하면 \(\vec{a}\cdot\vec{b} = a_1b_1 + a_2b_2 + a_3b_3\)이다. 따라서 영벡터가 아닌 두 벡터에 대하여 \(\cos \theta = \frac{\vec{a}\cdot\vec{b}}{|\vec{a}||\vec{b}|}\)이고, \(\vec{a} \perp \vec{b} \Leftrightarrow \vec{a}\cdot\vec{b} = 0, \vec{a} \parallel \vec{b} \Leftrightarrow \vec{b} = k\vec{a}(k \ne 0)\)이다.
  4. 연결공간에서 수직 조건을 수식 하나로 확인할 수 있으므로, 다음 절들에서 직선의 방향벡터와 평면의 법선벡터가 수직인지 판단할 때 이 식을 쓴다.
  5. 적용\(\vec{a} = (1, 2, 2)\)에서 \((2, -1, 0), (0, 1, -1)\)처럼 내적이 0이 되는 \(\vec{b}\)를 두 개 이상 찾아보자. 그리고 \(\vec{b}\)를 \(\vec{a}\)의 2배로 두면 \(\theta\)가 얼마가 되는지 보고, 그림을 돌려 같은 \(\theta\)가 화면에서는 다르게 보이는 것도 확인해 보자.
  6. 판단한 벡터에 수직인 벡터가 하나뿐이라고 생각하기 쉽다. 그런데 공간에서 \(\vec{a}\)에 수직인 벡터는 한 평면을 이룰 만큼 많고, 이 사실이 다음 절의 법선벡터 하나로 평면을 정한다는 생각의 바탕이다.
