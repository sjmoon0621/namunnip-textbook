타원

두 핀에 끈을 걸고 연필로 팽팽하게 당기며 돌리면 둥글지만 원은 아닌 곡선이 나옵니다. 이 곡선이 타원입니다. 이 절에서는 두 초점까지 거리의 합이 일정하다는 조건을 방정식으로 바꾸고, 식의 분모에서 장축의 방향과 초점의 위치를 읽어 냅니다. 행성의 궤도와 속삭이는 회랑이 이 곡선으로 설명됩니다.

타원

본문

종이에 핀 두 개를 꽂고 그보다 긴 끈의 양 끝을 핀에 묶은 뒤, 연필로 끈을 팽팽하게 당기며 한 바퀴 돌리면 길쭉한 원 모양이 그려진다. 정원사들이 화단을 이렇게 그렸다고 해서 '정원사의 타원'이라고도 한다. 이 곡선은 어떤 식으로 나타날까? 핀 사이를 좁히면 어떻게 될까?

먼저 알아야 할 것두 점 사이의 거리, 원의 방정식(공통수학2), 포물선의 방정식(포물선), 피타고라스 정리.

1.2.1타원의 정의와 방정식

정의 1.2.1 타원

평면 위의 서로 다른 두 점 F, F′에서의 거리의 합이 일정한 점들의 집합을 타원이라 한다. 두 점 F, F′을 타원의 초점이라 한다.

두 초점을 \(F(c, 0)\), \(F'(-c, 0)\)으로, 거리의 합을 \(2a\) (\(a > c > 0\))로 놓자. 점 \(P(x, y)\)에 대하여 \(\sqrt{(x - c)^2 + y^2} + \sqrt{(x + c)^2 + y^2} = 2a\)이다. 근호 하나를 넘기고 제곱하기를 두 번 하면 \((a^2 - c^2)x^2 + a^2y^2 = a^2(a^2 - c^2)\)이 된다. \(b^2 = a^2 - c^2\)으로 놓으면 다음을 얻는다.

정리 1.2.2 타원의 방정식

\[\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\quad (a > b > 0),\qquad c^2 = a^2 - b^2\] 초점은 \((\pm c, 0)\), 장축의 길이는 \(2a\), 단축의 길이는 \(2b\)이다.

그림 1에서 점 P를 돌려 보면 두 거리는 달라져도 합은 늘 \(2a\)이다. \(a\)를 \(b = 3\)에 가깝게 줄이면 \(c\)가 0에 다가가 두 초점이 가운데로 모이고, 타원은 원에 가까워진다. 원은 두 초점이 겹친 타원인 셈이다.1

1.2.2방정식에서 초점 찾기

\(\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1\)에서 분모가 큰 쪽이 장축 방향이다. \(x^2\)의 분모가 크면 장축이 \(x\)축 위에, \(y^2\)의 분모가 크면 \(y\)축 위에 놓인다. 초점까지의 거리 \(c\)는 큰 분모에서 작은 분모를 뺀 값의 제곱근이다. 단축의 끝점에서 초점까지의 거리가 \(a\)이므로, \(a\), \(b\), \(c\)는 빗변이 \(a\)인 직각삼각형을 이룬다.

1.2.3예제 하나를 끝까지

예제 1.2.3

타원 \(9x^2 + 25y^2 = 225\)의 초점, 장축과 단축의 길이를 구하여라. 또 지구는 태양을 한 초점으로 하는 타원 궤도를 도는데, 근일점 거리가 1.471억 km, 원일점 거리가 1.521억 km이다. 궤도 장축의 절반 \(a\)와 초점 거리 \(c\)를 구하여라.

양변을 225로 나누면 \(\dfrac{x^2}{25} + \dfrac{y^2}{9} = 1\)이다. \(a = 5\), \(b = 3\)이고 \(c = \sqrt{25 - 9} = 4\)이므로 초점은 \((\pm 4, 0)\), 장축 10, 단축 6이다.

근일점과 원일점은 장축의 양 끝이므로 두 거리의 합이 장축 \(2a\)이다. \(2a = 1.471 + 1.521 = 2.992\)억 km에서 \(a = 1.496\)억 km이다. 원일점 거리는 \(a + c\)이므로 \(c = 1.521 - 1.496 = 0.025\)억 km, 곧 250만 km이다. \(\dfrac{c}{a} \approx 0.017\)로 매우 작아, 지구 궤도는 원에 아주 가까운 타원이다.

아래 탐구 카드에서 두 핀과 끈으로 타원을 그리고, 방정식만 보고 초점과 장축을 찾아보자.

  1. \(\dfrac{c}{a}\)를 이심률이라 하며, 0에 가까울수록 원에 가깝고 1에 가까울수록 길쭉하다. 핼리 혜성 궤도의 이심률은 약 0.97로 매우 길쭉하다.
마무리

타원은 두 초점에서의 거리의 합이 일정한 점들의 집합이며, 방정식은 \(\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1\), 초점은 \((\pm c, 0)\), \(c^2 = a^2 - b^2\)이다. 분모가 큰 쪽이 장축 방향이다. 그래서 처음 질문의 두 핀은 타원의 초점이고 끈의 길이가 장축의 길이 \(2a\)이며, 핀 사이를 좁히면 타원이 원에 가까워진다.

빨간 연필 P를 끌어 한 바퀴 돌려 보자. 끈이 늘 팽팽하므로 P는 정해진 길로만 움직이며, 지금까지 그린 정도는 0%이다. \(c\)는 \(a\)보다 작아야 한다.

  1. 질문판자에 핀 두 개를 꽂고 길이 8인 끈의 양 끝을 묶은 뒤, 연필로 끈을 팽팽하게 당기며 한 바퀴 돌린다. 어떤 곡선이 그려질까? 두 핀 사이를 넓히면 곡선은 어떻게 바뀔까?
  2. 복원두 점 사이의 거리 공식을 쓴다. 그리고 근호가 들어 있는 등식은 근호 하나를 한쪽에 남기고 제곱하는 일을 두 번 하면 근호를 없앨 수 있다.
  3. 설명평면 위의 두 점 F, F'에서 거리의 합이 일정한 점들의 모임을 타원이라 하고, F, F'을 초점이라고 한다. 초점이 \(F(c, 0), F'(-c, 0)\)이고 거리의 합이 \(2a\)(\(a\) > \(c\) > 0)이면 \(PF + PF' = 2a\)에서 \(\sqrt{(x - c)^2 + y^2} = 2a - \sqrt{(x + c)^2 + y^2}\)이고, 제곱하여 정리하면 \(a\sqrt{(x + c)^2 + y^2} = a^2 + cx\), 한 번 더 제곱하면 \((a^2 - c^2)x^2 + a^2y^2 = a^2(a^2 - c^2)\)이다. 여기서 \(b^2 = a^2 - c^2\)(\(b\) > 0)로 놓고 양변을 \(a^2b^2\)으로 나누면 \(\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\)(\(a\) > \(b\) > 0)이다. 타원이 축과 만나는 네 점 \((\pm a, 0), (0, \pm b)\)을 꼭짓점, 두 초점을 잇는 선분의 중점을 중심, 길이 \(2a\)인 선분을 장축, 길이 \(2b\)인 선분을 단축이라 하며, 초점이 \(y\)축 위의 \((0, \pm c)\)이면 \(\frac{x^2}{b^2} + \frac{y^2}{a^2} = 1\)이고 장축이 \(y\)축 위에 놓인다.
  4. 연결단축의 끝 \((0, b)\)에서 두 초점까지의 거리는 같으므로 각각 \(a\)이다. 그래서 그림의 점선 직각삼각형에서 \(b^2 + c^2 = a^2\)이 보이고, \(c = 0\)이면 두 초점이 겹쳐 \(b = a\)가 되어 식은 원 \(x^2 + y^2 = a^2\)이 된다.
  5. 적용연필을 끌어 한 바퀴 돌리는 동안 \(PF + PF'\)이 바뀌는지 보고, 곡선이 완성되면 ‘곡선 보기’로 식과 비교해 보자. 그리고 끈 길이는 그대로 두고 \(c\)를 0에서 4.5까지 늘리며 \(b\)와 곡선의 모양이 어떻게 바뀌는지, 초점을 \(y\)축 위로 옮기면 식의 분모가 어떻게 바뀌는지 확인해 보자.
  6. 판단표준형에서 분모가 큰 쪽이 장축 방향이다. 그래서 \(\frac{x^2}{16} + \frac{y^2}{25} = 1\)은 \(y^2\)의 분모가 크므로 초점이 \(y\)축 위에 있고 \(c^2 = 25 - 16 = 9\)인데, 타원에서는 \(c^2 = a^2 - b^2\)이므로 더하면 안 된다. 또 끈의 길이 \(2a\)가 두 핀 사이 거리 \(2c\)보다 길어야 곡선이 생기고, 같으면 선분 \(FF'\)만 남는다.

초록 중심을 끌어 타원을 옮기고, 두 반지름의 크기를 바꾸어 보자.

  1. 질문방정식 \(\frac{x^2}{9} + \frac{y^2}{4} = 1\)과 \(\frac{x^2}{4} + \frac{y^2}{9} = 1\)은 같은 모양일까? 두 타원의 초점은 각각 어디에 있을까?
  2. 복원타원 \(\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\)(\(a\) > \(b\) > 0)의 초점은 \((\pm c, 0)\)이고 \(c^2 = a^2 - b^2\)이다. 그리고 도형을 \((m, n)\)만큼 평행이동하면 식에서 \(x, y\)가 \(x - m, y - n\)으로 바뀐다.
  3. 설명표준형 \(\frac{x^2}{A} + \frac{y^2}{B} = 1\)(\(A, B\) > \(0, A \ne B\))에서 \(\sqrt{A}\)는 가로 반지름, \(\sqrt{B}\)는 세로 반지름이다. 그리고 분모가 큰 쪽 문자의 축 위에 장축과 초점이 있고, 중심에서 초점까지의 거리는 \(c = \sqrt{|A - B|}\)이다. 그래서 질문의 두 타원은 모양이 같지만 하나는 가로로, 하나는 세로로 놓여 초점이 \((\pm\sqrt{5}, 0)\)과 \((0, \pm\sqrt{5})\)로 다르다. 중심이 \((m, n)\)이면 \(\frac{(x - m)^2}{A} + \frac{(y - n)^2}{B} = 1\)이고 중심, 초점, 꼭짓점이 모두 같은 만큼 옮겨 가며, 이 식을 전개하면 \(px^2 + qy^2 + rx + sy + t = 0\)에서 \(p, q\)의 부호가 같은 꼴이 된다.
  4. 연결전개된 식이 주어지면 \(x\)끼리, \(y\)끼리 묶어 완전제곱식을 만들고 우변을 1로 맞추면 표준형이 되는데, 포물선에서 한 일과 같은 순서이다. 또 두 분모가 같으면 원이 되므로, 원은 두 초점이 겹친 특별한 타원으로 볼 수 있다.
  5. 적용가로 반지름 3, 세로 반지름 2로 두고 초점을 읽은 뒤, 3과 2를 서로 맞바꾸면 무엇이 달라지는지 보자. 그리고 중심을 \((2, -1)\)로 옮겼을 때 전개한 식에서 \(x^2, y^2\)의 계수가 바뀌는지, 두 반지름을 같게 하면 초점이 어디로 가는지 확인해 보자.
  6. 판단표준형의 분모는 반지름이 아니라 반지름의 제곱이어서, \(\frac{x^2}{9} + \frac{y^2}{4} = 1\)의 장축 길이는 18이 아니라 \(2 \times 3 = 6\)이다. 또 전개형을 완전제곱식으로 고칠 때 \(x^2\)의 계수를 먼저 묶고 괄호 안을 완성해야 하며, 빠뜨리면 더하고 빼는 상수가 틀린다. 그리고 우변이 0이나 음수가 되면 그 식은 타원이 아니라 한 점이거나 그래프가 없다.
