벡터의 연산

학교에서 동쪽으로 300 m, 다시 북쪽으로 400 m를 걸으면 걸은 거리는 700 m이지만 학교에서는 500 m 떨어져 있습니다. 이동처럼 크기와 방향을 함께 가진 양을 벡터라고 합니다. 이 절에서는 벡터를 화살표로 나타내고, 더하고 빼고 실수배하는 규칙을 직접 화살표를 옮기며 확인합니다.

3.1.1

크기만으로는 왜 부족할까?

읽기 · 벡터의 뜻과 용어

기온 25 ℃, 질량 3 kg은 수 하나로 충분합니다. 그런데 "바람이 초속 5 m로 분다"는 말만으로는 연을 어느 쪽으로 날려야 할지 알 수 없습니다. 방향까지 알려 주는 양은 어떻게 나타낼까요?

1스칼라와 벡터

길이, 넓이, 질량, 온도처럼 크기만으로 정해지는 양을 스칼라라고 합니다. 변위, 속도, 힘처럼 크기와 방향을 함께 가진 양을 벡터라고 합니다. 벡터는 방향이 있는 선분, 곧 화살표로 나타냅니다. 점 A에서 점 B로 향하는 화살표가 나타내는 벡터를 AB로 쓰고, A를 시점, B를 종점이라고 합니다. 한 문자로 a, b처럼 쓰기도 합니다.

벡터의 크기는 화살표의 길이이고 |AB|, |a|로 씁니다. 크기는 언제나 0 이상의 실수입니다. 크기가 1인 벡터를 단위벡터, 시점과 종점이 같아 크기가 0인 벡터를 영벡터 0이라고 합니다. 영벡터의 방향은 생각하지 않습니다.

2같은 벡터, 크기는 같고 방향이 반대인 벡터

두 벡터의 크기와 방향이 모두 같으면 시점이 달라도 서로 같다고 하고 a = b로 씁니다. 그래서 벡터는 평행이동해서 원하는 곳에 옮겨 놓을 수 있습니다. 이 사실이 덧셈과 뺄셈의 출발점입니다. a와 크기가 같고 방향이 반대인 벡터를 −a로 씁니다. 예를 들어 BA = −AB입니다.

3평면벡터와 공간벡터

평면 위에서 생각하는 벡터를 평면벡터, 공간에서 생각하는 벡터를 공간벡터라고 합니다. 뜻과 연산 규칙은 같습니다. 이 단원에서 배우는 덧셈, 실수배, 내적은 평면과 공간에서 똑같이 성립합니다.

4연산 법칙 한눈에 보기

법칙식
교환법칙a + b = b + a
결합법칙(a + b) + c = a + (b + c)
영벡터, 역벡터a + 0 = a, a + (−a) = 0
실수배k(la) = (kl)a, (k + l)a = ka + la, k(a + b) = ka + kb

판단"크기가 같으면 같은 벡터"가 아닙니다. 정삼각형의 세 변 AB, BC, CA는 크기가 모두 같지만 방향이 달라서 서로 다른 벡터입니다. 거꾸로 위치가 달라도 크기와 방향이 같으면 같은 벡터입니다.

3.1.2

두 이동을 하나로 합치면 어떤 화살표가 될까?

벡터의 연산 · 덧셈, 뺄셈
|a|
—
|b|
—
|a + b|
—
|a| + |b|
—

화살표 끝의 큰 점을 끌어 보세요. 점은 격자점에 붙습니다. 한 칸의 길이는 1입니다.

  1. 질문동쪽으로 4칸, 북쪽으로 1칸 간 다음 다시 동쪽으로 1칸, 북쪽으로 3칸 갔습니다. 처음부터 한 번에 갔다면 어떤 화살표 하나로 나타낼 수 있을까요?
  2. 복원벡터는 크기와 방향만으로 정해지므로 평행이동해도 같은 벡터입니다. AB는 A에서 B로 가는 이동이고, −a는 a와 크기가 같고 방향이 반대인 벡터입니다.
  3. 설명a의 종점에 b의 시점을 이어 붙였을 때 a의 시점에서 b의 종점으로 가는 벡터를 a + b라고 합니다. 식으로는 AB + BC = AC입니다(삼각형법). 두 벡터의 시점을 맞추면 두 벡터가 만드는 평행사변형의 대각선이 a + b입니다(평행사변형법). 이 그림에서 a + b = b + a(교환법칙)가 바로 보입니다. 뺄셈은 a − b = a + (−b)로 정합니다. 시점을 맞춘 두 화살표에서 a − b는 b의 종점에서 a의 종점으로 가는 벡터입니다. 그래서 OA − OB = BA입니다.
  4. 연결물리에서 두 힘의 합력, 이동한 변위의 합이 이 덧셈입니다. 뺄셈 OB − OA = AB는 다음 절에서 위치벡터로 두 점 사이의 벡터를 구할 때 그대로 쓰입니다.
  5. 적용a와 b를 같은 방향으로 놓아 |a + b| = |a| + |b|가 되게 해 보세요. 이때 말고 두 값이 같아지는 경우가 있나요? 평행사변형 보기에서 a와 b를 수직으로 놓고, 뺄셈 보기로 바꾸어 |a + b|와 |a − b|를 비교해 보세요.
  6. 판단벡터의 덧셈은 크기의 덧셈이 아닙니다. 삼각형의 두 변의 길이의 합은 나머지 한 변보다 크므로 |a + b| ≤ |a| + |b|이고, 등호는 두 벡터의 방향이 같을 때(또는 하나가 0일 때)만 성립합니다. 또 a − b의 방향을 거꾸로 그리는 실수가 많습니다. a − b는 'b에 더하면 a가 되는 벡터'이므로 b의 종점에서 출발합니다.

3.1.3

벡터에 음수를 곱하면 무엇이 바뀔까?

벡터의 연산 · 실수배, 단위벡터, 평행
|a|
—
|ka|
—
|k| × |a|
—
ka의 방향
—

a의 끝점을 끌고, k를 움직여 보세요. 점선은 a와 평행한 직선입니다. 가는 검은 화살표는 a 방향의 단위벡터입니다.

  1. 질문a를 두 번 더한 a + a는 어떤 벡터일까요? 그렇다면 −a를 세 번 더한 것, 또는 a의 절반은 어떻게 나타낼까요?
  2. 복원벡터는 크기와 방향을 가집니다. −a는 a와 크기가 같고 방향이 반대인 벡터입니다. 크기 |a|는 0 이상의 실수입니다.
  3. 설명실수 k와 벡터 a에 대하여 ka를 이렇게 정합니다. k > 0이면 a와 같은 방향이고 크기가 k|a|인 벡터, k < 0이면 a와 반대 방향이고 크기가 |k||a|인 벡터, k = 0이면 0입니다. 어느 경우든 |ka| = |k||a|입니다. a ≠ 0이면 a/|a|는 a와 방향이 같은 단위벡터입니다. 또 0이 아닌 두 벡터 a, b가 평행할 필요충분조건은 b = ka(k ≠ 0)를 만족하는 실수 k가 있는 것입니다.
  4. 연결실수배와 덧셈을 섞은 ka + lb는 다음 절의 위치벡터와 내분점, 그리고 직선의 방정식 p = a + tu의 바탕이 됩니다. 점 P가 직선 위를 움직이는 모습이 바로 실수 t를 바꾸는 실수배입니다.
  5. 적용k를 −2에서 2까지 움직이면 ka의 끝이 어떤 선 위를 지나가나요? k = 0일 때와 k = −1일 때를 확인하세요. a를 오른쪽으로 2칸인 벡터로 두고, ka가 단위벡터와 겹치는 k를 찾아보세요.
  6. 판단−2a의 크기를 −2|a|로 쓰면 안 됩니다. 크기는 음수가 될 수 없으므로 |−2a| = 2|a|입니다. 음수를 곱하면 크기가 줄어드는 것이 아니라 방향이 뒤집힙니다. 또 '평행'에는 같은 방향과 반대 방향이 모두 들어갑니다.
