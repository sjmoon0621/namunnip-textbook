직선의 방정식

직선은 '한 점'과 '나아가는 방향'만 알면 정해집니다. 이 두 가지를 위치벡터와 방향벡터로 쓰면 직선 위의 모든 점을 실수 하나 \(t\)로 나타낼 수 있습니다. 이 절에서는 좌표평면에서 직선을 벡터로 표현하는 두 방법을 익히고, 같은 식이 좌표공간의 직선에도 그대로 쓰인다는 것을 확인합니다.

평면에서는 직선을 \(y = mx + n\)처럼 기울기로 나타냈다. 그런데 공간의 직선에는 '기울기' 하나로 나타낼 수 있는 방향이 없다. 비행기가 한 점에서 출발하여 일정한 방향으로 곧게 날아간다면, 그 경로의 모든 점을 어떻게 나타낼까? 출발점과 방향만 알면 충분할까?

3.4.1방향벡터로 나타낸 직선

점 A를 지나고 벡터 \(\vec u\)에 평행한 직선 위의 점 P에 대하여, \(\overrightarrow{AP}\)는 \(\vec u\)와 평행하므로 어떤 실수 \(t\)에 대해 \(\overrightarrow{AP} = t\vec u\)이다. 위치벡터로 쓰면 \(\vec p - \vec a = t\vec u\)이다. 이 \(\vec u\)를 직선의 방향벡터라 한다.

정리 3.4.1 직선의 벡터방정식

점 \(A(x_1, y_1, z_1)\)을 지나고 방향벡터가 \(\vec u = (a, b, c)\)인 직선은 \[\vec p = \vec a + t\vec u\] 이다. 성분으로 쓰면 \(x = x_1 + at\), \(y = y_1 + bt\), \(z = z_1 + ct\)이고, \(t\)를 없애면 \[\frac{x - x_1}{a} = \frac{y - y_1}{b} = \frac{z - z_1}{c}\ (abc \ne 0)\]

그림 1에서 \(t\)를 움직여 보자. \(t = 0\)이면 P가 A에 있고, \(t > 0\)이면 \(\vec u\) 방향으로, \(t < 0\)이면 반대 방향으로 간다. 평면이든 공간이든 같은 식을 쓰며, 성분의 개수만 다르다. 두 점 A, B를 지나는 직선은 방향벡터로 \(\overrightarrow{AB}\)를 쓴다.1

3.4.2법선벡터로 나타낸 직선과 두 직선의 각

평면 위의 직선은 방향 대신 그에 수직인 벡터로도 정할 수 있다. 점 A를 지나고 벡터 \(\vec n = (a, b)\)에 수직인 직선 위의 점 P는 \(\vec n \cdot (\vec p - \vec a) = 0\)을 만족한다. 성분으로 쓰면 \(a(x - x_1) + b(y - y_1) = 0\)이다. 이 \(\vec n\)을 법선벡터라 한다. 곧 직선 \(ax + by + c = 0\)의 법선벡터는 \((a, b)\)이다.

두 직선이 이루는 각은 방향벡터 \(\vec u_1\), \(\vec u_2\)가 이루는 각으로 구한다. 예각을 택하므로 \(\cos\theta = \dfrac{|\vec u_1 \cdot \vec u_2|}{|\vec u_1||\vec u_2|}\)이다.

예제 3.4.2

두 점 \(A(1, 0, 2)\), \(B(3, 1, 0)\)을 지나는 직선의 방정식을 구하고, 이 직선이 \(xy\)평면과 만나는 점을 구하여라.

방향벡터는 \(\overrightarrow{AB} = (2, 1, -2)\)이므로 직선은 \(x = 1 + 2t\), \(y = t\), \(z = 2 - 2t\)이다. \(t\)를 없애면 \(\dfrac{x - 1}{2} = y = \dfrac{z - 2}{-2}\)이다.

\(xy\)평면은 \(z = 0\)이므로 \(2 - 2t = 0\), 곧 \(t = 1\)이다. 그때 \(x = 3\), \(y = 1\)이므로 만나는 점은 \((3, 1, 0)\), 곧 B 자신이다. B가 처음부터 \(z\)좌표가 0인 점이었기 때문이다. 같은 방법으로 \(yz\)평면(\(x = 0\))과는 \(t = -\dfrac{1}{2}\)에서 \(\left(0, -\dfrac{1}{2}, 3\right)\)에서 만난다.

점 P

\(\overrightarrow{AP} = t\vec{u}\)
—
지나온 자취
—

점 A와 \(\vec{u}\)의 끝점을 끌고, \(t\)를 움직여 보자. \(t\)를 바꾼 자리마다 P가 남긴 점이 쌓인다.

  1. 질문점 \(A(1, 2)\)를 지나고 오른쪽으로 2, 위로 1씩 나아가는 직선이 있다. 이 직선 위의 점을 모두, 빠짐없이 나타내는 식은 무엇일까?
  2. 복원점 A의 위치벡터를 \(\vec{a}\)라고 한다. 영벡터가 아닌 두 벡터 \(\overrightarrow{AP}, \vec{u}\)가 평행하면 \(\overrightarrow{AP} = t\vec{u}\)인 실수 \(t\)가 있고, \(\overrightarrow{AP} = \vec{p} - \vec{a}\)이다.
  3. 설명점 A를 지나고 \(\vec{u}\)에 평행한 직선을 \(l\)이라 하면, 점 P가 \(l\) 위에 있을 필요충분조건은 \(\overrightarrow{AP} = t\vec{u}\)인 실수 \(t\)가 있는 것이므로 \(\vec{p} = \vec{a} + t\vec{u}\)(\(t\)는 실수)이다. 이것을 직선의 벡터방정식, \(\vec{u}\)를 방향벡터라고 한다. \(A(x_1, y_1), \vec{u} = (u_1, u_2)\)로 성분을 쓰면 \(x = x_1 + u_1t, y = y_1 + u_2t\)(매개변수 방정식)이고, \(u_1u_2 \ne 0\)이면 \(t\)를 없애 \(\frac{x - x_1}{u_1} = \frac{y - y_1}{u_2}\)를 얻는다. 그리고 두 점 A, B를 지나는 직선은 \(\vec{u} = \vec{b} - \vec{a}\)로 두면 된다.
  4. 연결기울기 \(m\)인 직선의 방향벡터는 \((1, m)\)이다. 그런데 방향벡터는 기울기가 없는 세로 직선도 \((0, 1)\)로 똑같이 다루고, 성분을 하나 늘리기만 하면 좌표공간의 직선에도 그대로 쓰인다. 또 매개변수 \(t\)를 시간으로 보면 P는 속도 \(\vec{u}\)로 움직이는 물체의 위치이다.
  5. 적용\(t\)를 \(-3\)에서 3까지 끝까지 움직여 P의 자취가 직선이 되는지, \(t = 0, 1\)일 때 P가 어디인지 보자. 그리고 \(\vec{u}\)의 길이를 2배로 늘리면 같은 \(t\)에서 P가 어떻게 되고 직선 자체는 바뀌는지, \(\vec{u}\)를 세로 방향으로 두면 식이 어떻게 바뀌는지 확인해 보자.
  6. 판단한 직선의 방향벡터는 하나가 아니다. \(\vec{u}\) 대신 \(2\vec{u}\)나 \(-\vec{u}\)를 써도 같은 직선이고, 지나는 점도 직선 위의 어느 점이든 되므로, 겉모양이 다른 두 식이 같은 직선일 수 있다. 또 대칭형 식에서 분모가 0인 경우는 쓸 수 없으므로 \(u_1 = 0\)이면 \(x = x_1\)로 따로 쓴다.

공간의 직선도 같은 식으로 나타낼 수 있을까?

직선의 방정식 · 좌표공간

—

점 P
—
\(xy\)평면과 만나는 점
—
\(|\vec{u}|\)
—

점 \(A(1, 2, 1)\)은 고정이다. 방향벡터의 성분과 \(t\)를 바꾸고, 그림을 끌어 돌려 보자.

  1. 질문공간에서는 기울기 하나로 직선의 방향을 나타낼 수 없다. 그러면 공간의 직선은 무엇으로 정할까?
  2. 복원좌표평면에서 점 A를 지나고 방향벡터가 \(\vec{u}\)인 직선은 \(\vec{p} = \vec{a} + t\vec{u}\)였다. 그리고 공간벡터의 연산도 성분끼리 한다.
  3. 설명벡터방정식 \(\vec{p} = \vec{a} + t\vec{u}\)에는 차원이 들어 있지 않으므로 좌표공간에서도 그대로 성립한다. 그래서 \(A(x_1, y_1, z_1), \vec{u} = (u_1, u_2, u_3)\)이면 \(x = x_1 + u_1t, y = y_1 + u_2t, z = z_1 + u_3t\)이고, \(u_1u_2u_3 \ne 0\)이면 \(\frac{x - x_1}{u_1} = \frac{y - y_1}{u_2} = \frac{z - z_1}{u_3}\)이다. 공간에서 등호가 두 개인 이 식은 방정식 두 개, 곧 두 평면의 교선을 뜻한다.
  4. 연결두 직선이 이루는 각은 방향벡터의 내적으로 구하고, 직선과 평면의 관계는 방향벡터와 법선벡터의 내적으로 판단한다. 그리고 다음 절에서 평면의 방정식을 배우면 직선과 평면의 교점도 \(t\)를 대입해 구할 수 있다.
  5. 적용\(t\)를 움직여 P가 직선 위를 지나가는지 보고, P가 \(xy\)평면에 닿는 \(t\)를 찾아 표의 교점과 비교해 보자. 그리고 \(u_3 = 0\)으로 두면 직선이 어떻게 놓이고 교점이 어떻게 되는지, 성분 하나가 0일 때 식의 모양이 어떤지 확인해 보자.
  6. 판단평면에서 \(\frac{x - x_1}{u_1} = \frac{y - y_1}{u_2}\)는 직선이었지만, 공간에서 이 식 하나만 쓰면 \(z\)가 자유로워서 평면이 된다. 그래서 공간의 직선에는 조건이 두 개 필요하다. 또 그림은 평면에 비친 모습이라 직선이 축과 만나 보여도 실제로는 만나지 않을 수 있으니, 교점은 식으로 확인해야 한다.

탐구 3

방향 대신 수직인 벡터로 직선을 정할 수 있을까?

직선의 방정식 · 법선벡터

—

\(\vec{n}\cdot(\vec{q} - \vec{a})\)
—
점 Q의 위치
—
Q에서 직선까지 거리
—

점 A, \(\vec{n}\)의 끝점, 그리고 시험점 Q를 끌어 보자. Q가 직선 위에 오면 내적이 0이 된다.

  1. 질문직선 위의 점 A에서 직선 위의 다른 점 P로 가는 벡터는 모두 같은 방향(또는 반대 방향)이다. 그렇다면 이 벡터들과 모두 수직인 벡터 하나로 직선을 정할 수 있지 않을까?
  2. 복원영벡터가 아닌 두 벡터가 수직일 필요충분조건은 내적이 0인 것이다. 그리고 \(\overrightarrow{AP} = \vec{p} - \vec{a}\)이고, 내적은 성분으로 \(a_1b_1 + a_2b_2\)이다.
  3. 설명점 A를 지나고 영벡터가 아닌 벡터 \(\vec{n}\)에 수직인 직선 위의 점 P는 \(\overrightarrow{AP} \perp \vec{n}\) 또는 \(P = A\)이므로 \(\vec{n}\cdot(\vec{p} - \vec{a}) = 0\)을 만족하며, 이런 \(\vec{n}\)을 직선의 법선벡터라고 한다. \(\vec{n} = (a, b), A(x_1, y_1)\)로 쓰면 \(a(x - x_1) + b(y - y_1) = 0\), 곧 \(ax + by + c = 0\) 꼴이다. 거꾸로 직선 \(ax + by + c = 0\)을 보면 계수 \((a, b)\)가 바로 법선벡터이고, 방향벡터는 법선벡터에 수직이므로 \((b, -a)\)로 잡을 수 있다.
  4. 연결두 직선이 이루는 각은 두 방향벡터(또는 두 법선벡터)가 이루는 각으로 구하고, 두 직선이 수직이면 법선벡터끼리 내적이 0이다. 그리고 다음 절에서는 같은 식 \(\vec{n}\cdot(\vec{p} - \vec{a}) = 0\)이 좌표공간에서는 직선이 아니라 평면을 나타낸다.
  5. 적용Q를 직선의 한쪽에서 반대쪽으로 끌며 내적의 부호가 어떻게 바뀌는지 보자. 그리고 \(\vec{n}\)을 2배로 늘리면 직선이 바뀌는지 식이 어떻게 바뀌는지, A를 직선을 따라 옮기면 식의 상수항이 그대로인지 확인해 보자.
  6. 판단\(ax + by + c = 0\)에서 \((a, b)\)를 방향벡터로 착각하는 실수가 많은데, \((a, b)\)는 직선에 수직이다. 또 이 그림의 내적 값 자체는 거리가 아니며, Q에서 직선까지의 거리는 \(\frac{|\vec{n}\cdot(\vec{q} - \vec{a})|}{|\vec{n}|}\)이다.
