직선의 방정식

직선은 '한 점'과 '나아가는 방향'만 알면 정해집니다. 이 두 가지를 위치벡터와 방향벡터로 쓰면 직선 위의 모든 점을 실수 하나 t로 나타낼 수 있습니다. 이 절에서는 좌표평면에서 직선을 벡터로 표현하는 두 방법을 익히고, 같은 식이 좌표공간의 직선에도 그대로 쓰인다는 것을 확인합니다.

먼저 알면 좋은 것 위치벡터벡터의 실수배벡터의 내적과 수직 조건

3.4.1

한 점과 방향만으로 직선 위의 모든 점을 가리킬 수 있을까?

직선의 방정식 · 방향벡터, 매개변수

—

점 P
—
AP = tu
—
지나온 자취
—

점 A와 u의 끝점을 끌고, t를 움직여 보세요. t를 바꾼 자리마다 P가 남긴 점이 쌓입니다.

  1. 질문점 A(1, 2)를 지나고 오른쪽으로 2, 위로 1씩 나아가는 직선이 있습니다. 이 직선 위의 점을 모두, 빠짐없이 나타내는 식은 무엇일까요?
  2. 복원점 A의 위치벡터를 a라고 합니다. 영벡터가 아닌 두 벡터 AP, u가 평행하면 AP = tu인 실수 t가 있습니다. 또 AP = p − a입니다.
  3. 설명점 A를 지나고 u에 평행한 직선을 l이라 합니다. 점 P가 l 위에 있을 필요충분조건은 AP = tu인 실수 t가 있는 것이므로
    p = a + tu (t는 실수)
    입니다. 이것을 직선의 벡터방정식, u를 방향벡터라고 합니다. A(x1, y1), u = (u1, u2)로 성분을 쓰면 x = x1 + u1t, y = y1 + u2t(매개변수 방정식)이고, u1u2 ≠ 0이면 t를 없애 (x − x1)/u1 = (y − y1)/u2를 얻습니다. 두 점 A, B를 지나는 직선은 u = b − a로 두면 됩니다.
  4. 연결기울기 m인 직선의 방향벡터는 (1, m)입니다. 그런데 방향벡터는 기울기가 없는 세로 직선도 (0, 1)로 똑같이 다루고, 성분을 하나 늘리기만 하면 좌표공간의 직선에도 그대로 쓰입니다. 매개변수 t를 시간으로 보면 P는 속도 u로 움직이는 물체의 위치입니다.
  5. 적용t를 −3에서 3까지 끝까지 움직여 P의 자취가 직선이 되는지 보세요. t = 0, 1일 때 P는 어디인가요? u의 길이를 2배로 늘리면 같은 t에서 P는 어떻게 되고, 직선 자체는 바뀌나요? u를 세로 방향으로 두면 식이 어떻게 바뀌나요?
  6. 판단한 직선의 방향벡터는 하나가 아닙니다. u 대신 2u나 −u를 써도 같은 직선이고, 지나는 점도 직선 위의 어느 점이든 됩니다. 그래서 겉모양이 다른 두 식이 같은 직선일 수 있습니다. 또 대칭형 식에서 분모가 0인 경우는 쓸 수 없으므로 u1 = 0이면 x = x1로 따로 씁니다.

점 (2, −1)을 지나고 방향벡터가 (3, 2)인 직선 위의 점은?

3.4.2

방향 대신 수직인 벡터로 직선을 정할 수 있을까?

직선의 방정식 · 법선벡터

—

n·(q − a)
—
점 Q의 위치
—
Q에서 직선까지 거리
—

점 A, n의 끝점, 그리고 시험점 Q를 끌어 보세요. Q가 직선 위에 오면 내적이 0이 됩니다.

  1. 질문직선 위의 점 A에서 직선 위의 다른 점 P로 가는 벡터는 모두 같은 방향(또는 반대 방향)입니다. 그렇다면 이 벡터들과 모두 수직인 벡터 하나로 직선을 정할 수 있지 않을까요?
  2. 복원영벡터가 아닌 두 벡터가 수직일 필요충분조건은 내적이 0인 것입니다. AP = p − a이고, 내적은 성분으로 a1b1 + a2b2입니다.
  3. 설명점 A를 지나고 영벡터가 아닌 벡터 n에 수직인 직선 위의 점 P는 AP ⊥ n 또는 P = A이므로
    n·(p − a) = 0
    을 만족합니다. 이런 n을 직선의 법선벡터라고 합니다. n = (a, b), A(x1, y1)로 쓰면 a(x − x1) + b(y − y1) = 0, 곧 ax + by + c = 0 꼴입니다. 거꾸로 직선 ax + by + c = 0을 보면 계수 (a, b)가 바로 법선벡터입니다. 방향벡터는 법선벡터에 수직이므로 (b, −a)로 잡을 수 있습니다.
  4. 연결두 직선이 이루는 각은 두 방향벡터(또는 두 법선벡터)가 이루는 각으로 구합니다. 두 직선이 수직이면 법선벡터끼리 내적이 0입니다. 다음 절에서는 같은 식 n·(p − a) = 0이 좌표공간에서는 직선이 아니라 평면을 나타냅니다.
  5. 적용Q를 직선의 한쪽에서 반대쪽으로 끌어 보세요. 내적의 부호는 어떻게 바뀌나요? n을 2배로 늘리면 직선은 바뀌나요, 식은 어떻게 바뀌나요? A를 직선을 따라 옮기면 식의 상수항은 그대로인가요?
  6. 판단ax + by + c = 0에서 (a, b)를 방향벡터로 착각하는 실수가 많습니다. (a, b)는 직선에 수직입니다. 또 이 그림의 내적 값 자체는 거리가 아닙니다. Q에서 직선까지의 거리는 |n·(q − a)| / |n|입니다.

3.4.3

공간의 직선도 같은 식으로 나타낼 수 있을까?

직선의 방정식 · 좌표공간

—

점 P
—
xy평면과 만나는 점
—
|u|
—

점 A(1, 2, 1)은 고정입니다. 방향벡터의 성분과 t를 바꾸고, 그림을 끌어 돌려 보세요.

  1. 질문공간에서는 기울기 하나로 직선의 방향을 나타낼 수 없습니다. 그러면 공간의 직선은 무엇으로 정할까요?
  2. 복원좌표평면에서 점 A를 지나고 방향벡터가 u인 직선은 p = a + tu였습니다. 공간벡터의 연산도 성분끼리 합니다.
  3. 설명벡터방정식 p = a + tu에는 차원이 들어 있지 않으므로 좌표공간에서도 그대로 성립합니다. A(x1, y1, z1), u = (u1, u2, u3)이면
    x = x1 + u1t, y = y1 + u2t, z = z1 + u3t
    이고, u1u2u3 ≠ 0이면 (x − x1)/u1 = (y − y1)/u2 = (z − z1)/u3입니다. 공간에서 등호가 두 개인 이 식은 방정식 두 개, 곧 두 평면의 교선을 뜻합니다.
  4. 연결두 직선이 이루는 각은 방향벡터의 내적으로 구하고, 직선과 평면의 관계는 방향벡터와 법선벡터의 내적으로 판단합니다. 다음 절에서 평면의 방정식을 배우면 직선과 평면의 교점도 t를 대입해 구할 수 있습니다.
  5. 적용t를 움직여 P가 직선 위를 지나가는지 보고, P가 xy평면에 닿는 t를 찾아 표의 교점과 비교하세요. u3 = 0으로 두면 직선은 어떻게 놓이고, 교점은 어떻게 되나요? 성분 하나가 0일 때 식의 모양도 확인하세요.
  6. 판단평면에서 (x − x1)/u1 = (y − y1)/u2는 직선이었지만, 공간에서 이 식 하나만 쓰면 z가 자유로워서 평면이 됩니다. 공간의 직선에는 조건이 두 개 필요합니다. 그림은 평면에 비친 모습이라 직선이 축과 만나 보여도 실제로는 만나지 않을 수 있으니, 교점은 식으로 확인하세요.
