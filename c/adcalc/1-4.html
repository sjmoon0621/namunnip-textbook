쌍곡선함수의 부정적분

도함수를 거꾸로 읽으면 \(\int \cosh x\,dx = \sinh x + C\), \(\int \sinh x\,dx = \cosh x + C\)입니다. 쓰임새가 더 큰 것은 치환입니다. \(\sqrt{x^2 + 1}\)이 들어간 적분은 \(x = \sinh t\)로 놓으면 \(\cosh^2 t - \sinh^2 t = 1\) 덕분에 근호가 사라집니다. 이 절에서는 근호의 꼴에 맞는 치환을 고르고, 두 전봇대 사이에 늘어진 전선의 길이를 쌍곡선함수의 적분으로 구합니다.

1.4.1미분을 거꾸로 읽다

쌍곡선함수의 부정적분은 도함수 공식을 거꾸로 읽으면 얻는다. \((\sinh x)' = \cosh x\)이므로 \(\int\cosh x\,dx = \sinh x + C\)이고, \(\int\sinh x\,dx = \cosh x + C\)이다. 역쌍곡선함수의 도함수에서는 \(\int\dfrac{dx}{\sqrt{x^2 + 1}} = \sinh^{-1}x + C = \ln(x + \sqrt{x^2 + 1}) + C\)를 얻는다. 이 적분은 삼각치환으로도 풀 수 있지만, \(x = \sinh t\)로 치환하면 \(\sqrt{x^2 + 1} = \cosh t\), \(dx = \cosh t\,dt\)가 되어 피적분함수가 1로 바뀌므로 훨씬 간단하다.

정리 1.4.1 쌍곡선함수의 적분과 쌍곡치환

\(\int\cosh x\,dx = \sinh x + C\), \(\int\sinh x\,dx = \cosh x + C\), \(\int\dfrac{dx}{\sqrt{x^2 + a^2}} = \sinh^{-1}\dfrac{x}{a} + C\)이다. \(\sqrt{x^2 + a^2}\)이 있으면 \(x = a\sinh t\)로 치환하여 \(\cosh^2 t - \sinh^2 t = 1\)로 근호를 없앤다.

원의 \(\sqrt{1 - x^2}\)을 \(x = \sin\theta\)로 없앴듯, \(\sqrt{x^2 + 1}\)은 \(x = \sinh t\)로, \(\sqrt{x^2 - 1}\)은 \(x = \cosh t\)로 없앤다. 각 경우 쓰는 항등식이 \(1 - \sin^2 = \cos^2\), \(1 + \sinh^2 = \cosh^2\), \(\cosh^2 - 1 = \sinh^2\)이다. 그래서 근호 속 식의 모양을 보면 어떤 치환을 쓸지 알 수 있다. 특히 현수선 \(y = a\cosh(x/a)\)의 길이를 구할 때 \(\sqrt{1 + y'^2} = \sqrt{1 + \sinh^2(x/a)} = \cosh(x/a)\)가 되어 적분이 바로 끝난다.1

1.4.2현수선의 길이

가운데가 가장 낮은 현수선 \(y = a\cosh(x/a)\)에서 \(x = -L\)부터 \(L\)까지의 길이는 \(\int_{-L}^{L}\cosh\dfrac{x}{a}\,dx = 2a\sinh\dfrac{L}{a}\)이다. 가운데가 처진 깊이는 양 끝의 높이에서 가운데 높이를 뺀 \(a\cosh(L/a) - a\)이다. 매개변수 \(a\)가 크면 곡선이 평평하고 작으면 깊게 처진다. 간격과 길이가 주어지면 \(2a\sinh(L/a)\)가 그 길이가 되도록 \(a\)를 정하고, 그 \(a\)로 처짐을 계산한다.

1.4.3예제 하나를 끝까지

예제 1.4.2

처음 질문의 전선에서 \(L = 50\)이고 길이는 101이다. \(u = 50/a\)로 놓고 \(\sinh u \approx u + u^3/6\)을 써서 \(a\)를 어림하고, 처짐을 구하여라. \(\cosh u \approx 1 + u^2/2\)이다.

길이의 식은 \(2a\sinh u = 101\)이고 \(a = 50/u\)이므로 \(\dfrac{\sinh u}{u} = 1.01\)이다. \(\sinh u/u \approx 1 + u^2/6\)이므로 \(u^2/6 \approx 0.01\), 곧 \(u^2 \approx 0.06\), \(u \approx 0.245\)이다. 그래서 \(a \approx 50/0.245 \approx 204\) m이다.

처짐은 \(a(\cosh u - 1) \approx a\cdot\dfrac{u^2}{2} = \dfrac{50}{u}\cdot\dfrac{u^2}{2} = 25u \approx 25\times0.245 \approx 6.1\) m이다. 길이를 1 m 늘렸을 뿐인데 가운데가 6 m 넘게 처지는 것은, 처짐이 작을 때 늘어난 길이가 처짐의 제곱에 비례하기 때문이다. 거꾸로 말하면 처짐은 늘어난 길이의 제곱근에 비례하므로 작은 여유가 큰 처짐을 만든다. 즉 쌍곡선함수의 적분은 도함수를 거꾸로 읽어 얻고, \(\sqrt{1 + \sinh^2} = \cosh\)를 쓰면 현수선의 길이가 바로 계산되어 전선의 처짐을 구할 수 있다.

  1. 고압 송전선은 여름에 열로 늘어나 더 처지고, 겨울에는 줄어들어 팽팽해진다. 그래서 전선을 걸 때는 한여름에 처진 전선이 아래의 나무나 건물에 닿지 않도록 처짐을 미리 계산해 여유를 둔다.

  1. 질문\(\int\frac{dx}{\sqrt{1 - x^2}}\)은 \(x = \sin t\)로 치환하면 \(1 - \sin^2 t = \cos^2 t\) 덕분에 근호가 사라졌다. \(\sqrt{x^2 + 1}\)이나 \(\sqrt{x^2 - 1}\)도 사라지게 하는 치환이 있을까?
  2. 복원\(\cosh^2 t - \sinh^2 t = 1\), \((\sinh t)' = \cosh t\), \((\cosh t)' = \sinh t\). 치환적분법에서는 \(x = g(t)\)이면 \(dx = g'(t)\,dt\)이다.
  3. 설명항등식을 두 가지로 읽으면 된다. \(1 + \sinh^2 t = \cosh^2 t\)이므로 \(x = \sinh t\)이면 \(\sqrt{x^2 + 1} = \cosh t\)이다. \(\cosh^2 t - 1 = \sinh^2 t\)이므로 \(x = \cosh t\ (t \ge 0)\)이면 \(\sqrt{x^2 - 1} = \sinh t\)이다. 예를 들어 \(dx = \cosh t\,dt\)이므로 \[\int\frac{dx}{\sqrt{x^2 + 1}} = \int\frac{\cosh t}{\cosh t}\,dt = t + C\]이고, \(t = \sinh^{-1} x = \ln\left(x + \sqrt{x^2 + 1}\right)\)이다. 넷째 적분은 \(\int\cosh^2 t\,dt = \int\frac{1 + \cosh 2t}{2}\,dt\)가 되어 \(\frac{1}{2}\left(x\sqrt{x^2 + 1} + \sinh^{-1} x\right) + C\)이다.
  4. 연결기본 적분 공식 \(\int\cosh x\,dx = \sinh x + C\), \(\int\sinh x\,dx = \cosh x + C\), \(\int\frac{dx}{\cosh^2 x} = \tanh x + C\)는 도함수 공식을 거꾸로 읽은 것이다. \(\sqrt{x^2 + 1}\)은 \(x = \tan t\)로도 없앨 수 있지만, 그러면 \(\int\sec t\,dt\) 같은 더 까다로운 적분이 남는다.
  5. 적용네 적분마다 근호를 없애는 치환을 고르자. 맞히면 구한 식이 나타난다. \(b\)를 움직이며 칠한 넓이(수치)와 식의 값이 같은지 확인해 보자. 셋째 적분에서 \(b\)를 1에 가깝게 하면 피적분함수는 어떻게 되는가?
  6. 판단\(x = \cosh t\)로 치환할 때는 \(x \ge 1\)이어야 하고, \(\sqrt{\sinh^2 t} = \sinh t\)가 되려면 \(t \ge 0\)으로 잡아야 한다. 치환의 범위를 확인하지 않으면 부호가 틀린 답이 나온다.

  1. 질문두 기둥 사이가 100 m인데 전선을 101 m로, 곧 1 %만 길게 걸었다. 전선 한가운데는 얼마나 처질까? 확인하기 전에 짐작해서 예측 막대를 맞추어 보자.
  2. 복원곡선 \(y = f(x)\)의 \(x = p\)부터 \(q\)까지의 길이는 \(\int_p^q\sqrt{1 + \{f'(x)\}^2}\,dx\)이다. \(\cosh^2 u - \sinh^2 u = 1\)이고 \(\int\cosh\frac{x}{a}\,dx = a\sinh\frac{x}{a} + C\)이다.
  3. 설명\(y = a\cosh\frac{x}{a}\)이면 \(y' = \sinh\frac{x}{a}\)이고 \(\sqrt{1 + \sinh^2\frac{x}{a}} = \cosh\frac{x}{a}\)이므로 근호가 깨끗이 사라진다. 그래서 \(-d\)부터 \(d\)까지의 길이는 \[L = \int_{-d}^{d}\cosh\frac{x}{a}\,dx = 2a\sinh\frac{d}{a}\]이고, 처짐은 \(s = a\left(\cosh\frac{d}{a} - 1\right)\)이다. 처짐이 작으면 \(L \approx 2d + \frac{8s^2}{3 \cdot 2d}\)로 어림할 수 있어, 늘어난 길이는 처짐의 제곱에 비례한다. 거꾸로 말하면 처짐은 늘어난 길이의 제곱근에 비례해 생각보다 크게 생긴다.
  4. 연결현수선의 길이가 이렇게 간단한 식으로 나오는 것은 \(\cosh\)의 도함수와 적분이 다시 쌍곡선함수이기 때문이다. 송전선, 현수교 주케이블을 설계할 때 처짐과 길이, 장력의 관계를 이 식으로 계산한다.
  5. 적용101 m에서 예측한 뒤 확인해 보자. 처짐은 약 6 m이다. 예측과 얼마나 달랐는가? 길이를 100.1 m(0.1 % 길게)로 바꾸면 처짐은 1 m보다 클까요, 작을까? 예측한 다음 확인해 보자.
  6. 판단실제 전선은 무게 때문에 조금 늘어나고, 여름에는 열팽창으로 길이가 늘어 더 처진다. 늘어난 길이가 아주 작아도 처짐이 크게 바뀌므로, 송전선은 계절별 온도를 고려해 처짐을 계산한다. 이 카드는 늘어나지 않는 전선을 가정한 모형이다.
