극곡선의 길이와 넓이

극곡선이 둘러싼 넓이는 극에서 뻗은 얇은 부채꼴로 잘라 \(\frac{1}{2}\int r^2\,d\theta\)로 구하고, 길이는 \(\int\sqrt{r^2 + (r')^2}\,d\theta\)로 구합니다. 이 절에서는 부채꼴의 합이 적분으로 다가가는 것을 보고, 곡선이 두 번 그려지는 범위로 적분해 넓이를 두 배로 세는 실수를 찾고, 꺾은선으로 카디오이드의 길이 8을 확인한 뒤 두루마리 휴지에 감긴 종이의 길이를 계산합니다.

먼저 알아야 할 것부채꼴의 호의 길이와 넓이, 정적분과 급수의 합, 곡선의 길이, 극곡선의 그래프(극곡선의 대칭성과 그래프).

2.5.1부채꼴로 잘라 넓이를 구하다

극곡선 \(r = f(\theta)\)가 \(\theta = \alpha\)부터 \(\beta\)까지 극과 함께 둘러싼 넓이를 구하려면, 넓이를 극에서 퍼져 나가는 가는 부채꼴로 자른다. 중심각 \(\Delta\theta\)인 부채꼴의 넓이는 반지름이 거의 \(f(\theta)\)로 일정하므로 \(\tfrac12f(\theta)^2\Delta\theta\)이다. 이것을 모두 더하고 극한을 취하면 넓이가 된다. 직사각형으로 자르지 않는 것은 극곡선이 각마다 거리를 주는 곡선이어서, 같은 각의 폭으로 자를 때 각 조각의 모양이 가장 간단해지기 때문이다.

정리 2.5.1 극곡선의 넓이와 길이

극곡선 \(r = f(\theta)\)와 두 반직선 \(\theta = \alpha\), \(\theta = \beta\)로 둘러싸인 넓이와 곡선의 길이는 \[S = \frac12\int_\alpha^\beta r^2\,d\theta,\qquad L = \int_\alpha^\beta\sqrt{r^2 + r'^2}\,d\theta\]이다.

길이의 식은 매개변수 곡선 \(x = r\cos\theta\), \(y = r\sin\theta\)의 길이 공식에서 나온다. \(\left(\dfrac{dx}{d\theta}\right)^2 + \left(\dfrac{dy}{d\theta}\right)^2\)을 전개하면 교차하는 항이 지워지고 \(r^2 + r'^2\)만 남는다. 뜻으로 보면, 각이 \(\Delta\theta\)만큼 변할 때 원 방향으로 \(r\Delta\theta\), 반지름 방향으로 \(r'\Delta\theta\)만큼 움직이므로 피타고라스 정리로 움직인 거리가 \(\sqrt{r^2 + r'^2}\,\Delta\theta\)이다.1

2.5.2휴지의 나선

휴지의 단면은 한 바퀴 돌 때마다 반지름이 두께 \(t\)만큼 커지는 아르키메데스 나선 \(r = r_0 + \dfrac{t}{2\pi}\theta\)이다. \(r' = t/2\pi\)는 0.004 cm 정도로 \(r\)에 비해 아주 작으므로 \(\sqrt{r^2 + r'^2} \approx r\)로 볼 수 있다. 그러면 길이는 \(\int r\,d\theta\)이고, 한 바퀴마다 반지름이 거의 일정한 원의 둘레를 더하는 셈이 된다. 이렇게 어림하면 길이는 휴지 단면의 고리 넓이를 두께로 나눈 값과 같아진다. 종이를 펼친 넓이가 길이와 두께의 곱이므로 당연한 결과이다.

2.5.3예제 하나를 끝까지

예제 2.5.2

처음 질문의 휴지에서 \(r_0 = 2\), 바깥 반지름 5.5, \(t = 0.025\)(cm)이다. 감긴 바퀴 수를 구하고, \(\sqrt{r^2 + r'^2} \approx r\)로 어림하여 휴지의 길이를 구하여라. 이 값을 단면 넓이를 두께로 나눈 값과 비교하여라.

바퀴 수는 \((5.5 - 2)/0.025 = 140\)이므로 \(\theta\)는 0부터 \(280\pi\)까지 간다. 길이는 \(\int_0^{280\pi}\left(2 + \dfrac{0.025}{2\pi}\theta\right)d\theta = 2\times280\pi + \dfrac{0.025}{4\pi}(280\pi)^2 = 560\pi + 490\pi = 1050\pi \approx 3299\) cm이다. 곧 약 33 m이다.

단면의 고리 넓이는 \(\pi(5.5^2 - 2^2) = 26.25\pi\) cm²이고, 두께 0.025로 나누면 \(1050\pi\) cm로 같다. 무시한 \(r'^2\)의 몫은 \(r'/r\)이 0.002 이하이므로 전체 길이의 백만분의 몇 정도여서 1 mm도 되지 않는다. 그래서 휴지 포장에 적힌 길이는 지름과 두께만 재도 확인할 수 있다. 즉 극곡선의 넓이는 부채꼴로 잘라 \(\tfrac12\int r^2\,d\theta\)로, 길이는 원 방향과 반지름 방향의 변화를 합쳐 \(\int\sqrt{r^2 + r'^2}\,d\theta\)로 구한다.

그림 안쪽의 실제 넓이
—
  1. 질문직교좌표에서는 넓이를 세로로 긴 직사각형으로 잘라 구했다. 카디오이드처럼 극을 둘러싼 곡선도 그렇게 잘라야 할까?
  2. 복원반지름 \(r\), 중심각 \(\Delta\theta\)(라디안)인 부채꼴의 넓이는 \(\frac{1}{2}r^2\Delta\theta\)이다. 넓이를 잘게 나눈 조각의 합의 극한이 정적분이다.
  3. 설명극곡선은 극에서 뻗은 방향마다 \(r\)이 정해지므로, 극을 꼭짓점으로 하는 얇은 부채꼴로 자르는 것이 자연스럽다. 중심각 \(\Delta\theta\)인 조각은 반지름이 거의 \(f(\theta)\)로 일정한 부채꼴이라 넓이가 \(\frac{1}{2}f(\theta)^2\Delta\theta\)이고, 합의 극한은 \[S = \frac{1}{2}\int_\alpha^\beta \{f(\theta)\}^2\,d\theta\]이다. 카디오이드 \(1 + \cos\theta\)는 \(\frac{1}{2}\int_0^{2\pi}(1 + \cos\theta)^2d\theta = \frac{3\pi}{2}\)이다.
  4. 연결\(r^2\)으로 계산하므로 \(r\)이 음수인 부분도 양의 넓이로 센다. 그래서 \(\cos 2\theta\)의 꽃잎 4장은 \(0 \le \theta \le 2\pi\)에서 한 번씩 계산되어 \(\frac{\pi}{2}\)가 된다.
  5. 적용\(n\)을 늘려 부채꼴의 합이 적분값에 다가가는지 보자. 그다음 원 \(2\cos\theta\)와 \(\cos 3\theta\)를 \(0 \le \theta \le 2\pi\)로 두고 적분값과 실제 넓이를 비교해 보자. 왜 두 배가 되는가? 범위를 \(0 \le \theta \le \pi\)로 바꾸면 어떻게 되는가?
  6. 판단적분 범위는 곡선이 한 번 그려지는 범위로 잡아야 한다. 원 \(r = 2\cos\theta\)는 \(0 \le \theta \le \pi\)에서 한 바퀴를 다 그리므로, \(2\pi\)까지 적분하면 같은 넓이를 두 번 세어 \(2\pi\)라는 틀린 답이 나온다. 넓이 공식을 쓰기 전에 그래프부터 그려 보아야 하는 까닭이다.

두루마리는 심의 반지름 2 cm, 종이가 한 바퀴에 두께만큼 바깥으로 감긴다고 본 모식이다. 그림은 감긴 수를 줄여서 그린다.

  1. 질문두루마리 휴지 한 롤에 몇 m의 종이가 감겨 있을까? 풀어서 재면 다시 감기 어렵다. 바깥 반지름과 종이 두께만 알면 계산할 수 있을까?
  2. 복원매개변수 곡선의 길이는 \(\int\sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2}\,dt\)이다. 극곡선은 \(x = r\cos\theta\), \(y = r\sin\theta\)인 매개변수 곡선이다.
  3. 설명\(x = f(\theta)\cos\theta\), \(y = f(\theta)\sin\theta\)를 미분해 제곱하여 더하면 교차항이 지워져 \(\left(\frac{dx}{d\theta}\right)^2 + \left(\frac{dy}{d\theta}\right)^2 = f(\theta)^2 + f'(\theta)^2\)이 된다. 그래서 극곡선의 길이는 \[L = \int_\alpha^\beta\sqrt{f(\theta)^2 + f'(\theta)^2}\,d\theta\]이다. 카디오이드는 \(\sqrt{2 + 2\cos\theta} = 2\left|\cos\frac{\theta}{2}\right|\)이므로 길이가 정확히 8이다. 두루마리의 단면은 한 바퀴마다 두께 \(d\)만큼 커지는 아르키메데스 나선 \(r = r_0 + \frac{d}{2\pi}\theta\)이다.
  4. 연결나선의 적분은 손으로 계산하기 번거롭지만, \(r'\)이 \(r\)에 비해 아주 작으므로 \(L \approx \int r\,d\theta\)이고, 이는 "단면의 넓이 ÷ 두께" \(\frac{\pi(R^2 - r_0^2)}{d}\)과 거의 같다. 종이를 펼쳐 얇은 띠로 놓아도 넓이는 같다는 생각과 맞다.
  5. 적용카디오이드에서 마디 수를 늘려 꺾은선의 길이가 8에 다가가는지 보자. 두루마리에서는 적분값과 넓이 어림이 몇 % 다른지 보자. 두께를 두 배로 하면 길이는 어떻게 되는가?
  6. 판단꺾은선은 언제나 곡선보다 짧으므로 마디 수를 늘리면 아래에서 참값에 다가간다. 실제 휴지는 눌리거나 느슨하게 감겨 두께가 일정하지 않으므로, 이 계산은 대략적인 값이다.
