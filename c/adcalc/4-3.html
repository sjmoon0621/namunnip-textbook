미분방정식의 풀이

\(y' = f(x)g(y)\)꼴의 미분방정식은 \(x\)와 \(y\)를 양쪽으로 갈라 각각 적분하면 풀립니다. 이것이 변수분리형 미분방정식입니다. 풀이에 나오는 상수는 해 곡선의 가족에서 하나를 고르는 꼬리표이고, 초기 조건이 그 값을 정합니다. 이 절에서는 풀이의 단계를 순서대로 조립하고, 적분상수를 잘못 다루거나 상수해를 잃어버리는 흔한 오류를 찾습니다.

미분방정식의 풀이

본문

미분방정식 \(y' = 2xy\), \(y(0) = 3\)을 풀던 학생이 \(\dfrac{dy}{y} = 2x\,dx\)로 변수를 나누고 양변을 적분해 \(\ln|y| = x^2\)을 얻었다. 그런 다음 \(y = e^{x^2}\)으로 쓰고 적분상수 \(C\)를 붙여 \(y = e^{x^2} + C\)로 놓은 뒤, \(y(0) = 3\)에서 \(C = 2\)를 얻었다. 그런데 \(y = e^{x^2} + 2\)를 원래 식에 넣어 보니 \(y' = 2xe^{x^2}\)이고 \(2xy = 2xe^{x^2} + 4x\)로 서로 달랐다. 어디서 잘못되었을까?

먼저 알아야 할 것치환적분법, 자연로그, 지수함수의 도함수, 방향장(미분방정식과 방향장).

4.3.1변수를 양쪽으로 나누다

\(y' = g(x)h(y)\)처럼 \(x\)만의 식과 \(y\)만의 식의 곱으로 쓸 수 있는 미분방정식을 변수분리형이라 한다. \(h(y) \ne 0\)이면 양변을 \(h(y)\)로 나누어 \(\dfrac{1}{h(y)}\dfrac{dy}{dx} = g(x)\)로 쓰고, 양변을 \(x\)로 적분한다. 왼쪽은 치환적분법에 따라 \(\int\dfrac{dy}{h(y)}\)가 된다. 그래서 \(y\)에 대한 적분과 \(x\)에 대한 적분을 따로 계산해 같다고 놓으면 해의 관계식을 얻는다. 이때 두 부정적분의 적분상수는 하나로 모아 한쪽에 붙인다.

정리 4.3.1 변수분리형 미분방정식의 풀이

\(\dfrac{dy}{dx} = g(x)h(y)\)이면 \[\int\frac{dy}{h(y)} = \int g(x)\,dx + C\]이다. 적분상수 \(C\)는 적분하는 단계에서 붙이고, 초기 조건으로 정한다. \(h(y_0) = 0\)인 \(y_0\)이 있으면 상수함수 \(y = y_0\)도 해이므로 따로 확인한다.

\(y' = 2xy\)에서는 \(\int\dfrac{dy}{y} = \int2x\,dx\)이므로 \(\ln|y| = x^2 + C\)이다. 지수로 바꾸면 \(|y| = e^{x^2 + C} = e^Ce^{x^2}\)이고, 부호까지 합쳐 \(y = Ae^{x^2}\)이다. 적분상수 \(C\)는 지수에 들어가 곱하는 상수 \(A\)로 바뀐다. 나누는 과정에서 \(y = 0\)을 제외했지만 \(y = 0\)도 \(y' = 2xy\)를 만족하므로, \(A = 0\)까지 허용하면 모든 해가 \(y = Ae^{x^2}\)에 들어간다.1

4.3.2끝없이 커지는 해

변수분리형의 해는 모든 \(x\)에서 정의되지 않을 수도 있다. \(y' = y^2\), \(y(0) = 1\)을 풀면 \(\int\dfrac{dy}{y^2} = \int dx\)에서 \(-\dfrac1y = x + C\)이고, 초기 조건으로 \(C = -1\)이므로 \(y = \dfrac{1}{1 - x}\)이다. 이 해는 \(x\)가 1에 다가가면 끝없이 커진다. \(y' = y\)의 해 \(e^x\)는 빨리 커져도 모든 \(x\)에서 유한한데, \(y' = y^2\)은 \(y\)가 클수록 훨씬 빠르게 커져 유한한 시간 안에 무한대가 된다. 그래서 풀이를 마친 뒤에는 해가 정의되는 구간도 함께 적어야 한다.

예제 4.3.2

\(y' = 2xy\), \(y(0) = 3\)의 해를 구하고 \(y(1)\)을 구하여라. 구한 해를 원래 식에 넣어 확인하여라.

변수를 나누어 적분하면 \(\ln|y| = x^2 + C\)이고, 지수로 바꾸면 \(y = Ae^{x^2}\)이다. \(y(0) = A = 3\)이므로 해는 \(y = 3e^{x^2}\)이고, \(y(1) = 3e \approx 8.15\)이다.

확인하면 \(y' = 3e^{x^2}\cdot2x = 6xe^{x^2}\)이고 \(2xy = 2x\cdot3e^{x^2} = 6xe^{x^2}\)이므로 같다. 또 \(y(0) = 3\)이다. 처음 질문의 학생은 적분할 때 상수를 빠뜨리고 지수로 바꾼 뒤에 더해서, 곱하는 상수여야 할 것을 더하는 상수로 만들었다. \(y = e^{x^2} + C\)는 \(C = 0\)일 때만 해이다. 즉 변수분리형 미분방정식은 \(x\)와 \(y\)를 양쪽으로 나누어 각각 적분해 풀고, 적분상수는 적분하는 단계에서 붙여야 하며, 구한 해는 원래 식에 넣어 확인하고 정의되는 구간도 살핀다.

아래 탐구 카드에서 \(y' = 2xy\)를 변수분리로 풀어 방향장과 비교하고, 초기 조건을 넣은 풀이에서 틀린 곳을 찾아보자.

  1. 변수를 나누는 방법은 1691년 라이프니츠가 처음 썼고, 변수분리라는 이름은 1694년 요한 베르누이가 붙였다. \(dy/dx\)를 분수처럼 나누어 쓰는 라이프니츠의 기호가 이 풀이를 자연스럽게 만들어 주었다.
마무리

변수분리형 미분방정식 \(y' = g(x)h(y)\)은 \(\int dy/h(y) = \int g(x)\,dx + C\)로 풀며, 적분상수는 적분하는 단계에서 붙이고 초기 조건으로 정한다. \(h(y) = 0\)인 상수 해를 따로 확인하고, 해가 유한한 \(x\)에서 무한대가 될 수 있으므로 정의되는 구간도 적는다. 처음 질문의 해는 \(y = e^{x^2} + 2\)가 아니라 \(y = 3e^{x^2}\)이며, 상수를 지수로 바꾼 뒤에 더한 것이 잘못이었다.

탐구 1

\(y' = 2xy\)의 해를 식으로 구하려면?

변수분리형 미분방정식 · 증명 조립
  1. \(y = 0\)(모든 \(x\)에서)은 \(y' = 0 = 2x \cdot 0\)이므로 해이다. 이제 \(y \ne 0\)인 해를 찾는다.
  2. 양변을 \(y\)로 나누면 \(\frac{1}{y}\frac{dy}{dx} = 2x\)이다. 왼쪽에는 \(y\)만, 오른쪽에는 \(x\)만 남았다.\(y\)로 나누기 전에 \(y = 0\)인 경우를 따로 살펴 두어야 합니다.
  3. 양변을 \(x\)에 대해 적분하면, 왼쪽은 치환적분으로 \(\int\frac{1}{y}\,dy\)가 되어 \(\ln|y| = x^2 + C\)이다.변수를 분리한 식이 있어야 양변을 따로 적분할 수 있습니다.
  4. \(|y| = e^{C}e^{x^2}\)이므로 \(y = Ae^{x^2}\)이다(\(A = \pm e^C \ne 0\)). 처음의 해 \(y = 0\)까지 합치면 \(A\)는 모든 실수이다.\(\ln|y|\)에 대한 식이 먼저 나와야 지수를 취할 수 있습니다.
  5. 초기 조건 \(y(0) = 1\)을 넣으면 \(A = 1\), 곧 \(y = e^{x^2}\)이다.해의 일반형이 나온 다음에 초기 조건으로 \(A\)를 정합니다.
  6. \(\ln|y| = x^2 + C\)이므로 \(y = e^{x^2} + C\)이다.적분상수는 지수의 안에 있습니다. \(e^{x^2 + C} = e^C e^{x^2}\)이므로 더하는 상수가 아니라 곱하는 상수가 됩니다.

단계를 놓을 때마다 그림에 그 단계까지 알게 된 해가 그려진다.

  1. 질문방향장과 오일러의 방법은 해의 모양과 근삿값을 알려 주지만 식은 알려 주지 않는다. \(y' = 2xy\)처럼 \(x\)의 식과 \(y\)의 식의 곱으로 된 미분방정식은 정확한 해를 식으로 구할 수 있을까?
  2. 복원치환적분법에 따르면 \(\int g(y(x))\,y'(x)\,dx = \int g(y)\,dy\)이다. 또 \(\int\frac{1}{y}dy = \ln|y| + C\), \(e^{a + b} = e^a e^b\)이다.
  3. 설명\(y' = f(x)g(y)\)꼴의 방정식을 변수분리형이라고 한다. \(g(y) \ne 0\)일 때 양변을 \(g(y)\)로 나누면 \(\frac{1}{g(y)}\frac{dy}{dx} = f(x)\)이고, 양변을 \(x\)로 적분하면 \[\int\frac{1}{g(y)}\,dy = \int f(x)\,dx + C\]가 된다. 흔히 "\(\frac{dy}{g(y)} = f(x)\,dx\)로 놓고 양변을 적분한다"고 줄여 쓴다. 나누기 전에 \(g(y) = 0\)인 상수해를 따로 챙겨야 한다.
  4. 연결답에 들어 있는 상수 \(A\)는 해 곡선 하나하나를 고르는 꼬리표이다. 방향장 위의 모든 해 곡선이 \(y = Ae^{x^2}\) 가운데 하나이고, 초기 조건이 그중 하나를 고른다. 다음 절의 냉각, 방사성 붕괴, 로지스틱 모형이 모두 변수분리형이다.
  5. 적용단계를 순서대로 쌓아 풀이를 완성해 보자. 함정 단계가 왜 틀렸는지도 확인해 보자. 그림에서 \(A\)가 음수인 해는 어디에 있는가?
  6. 판단\(\frac{dy}{dx}\)를 분수처럼 나누어 \(dy\)와 \(dx\)를 양쪽으로 보내는 것은 치환적분을 줄여 쓴 표기일 뿐이다. 근거는 치환적분법에 있다. 또 \(y\)로 나눌 때 잃어버린 해(\(y = 0\))가 없는지 늘 확인해야 한다.

초기 조건을 넣었는데 해가 맞지 않는 이 풀이, 어디가 틀렸을까?

미분방정식의 풀이 · 오류 찾기

처음 틀린 줄을 누르세요. 틀린 곳이 없으면 마지막 줄을 누르세요. 검정은 실제 해, 주황은 풀이의 답입니다.

  1. \(y' = 3y\), \(y(0) = 2\)를 푼다. \(\frac{1}{y}dy = 3\,dx\)이다.맞습니다(\(y \ne 0\)).
  2. 양변을 적분하면 \(\ln|y| = 3x + C\)이다.맞습니다.
  3. 따라서 \(y = e^{3x} + C\)이고, \(y(0) = 2\)에서 \(C = 1\)이므로 \(y = e^{3x} + 1\)이다.여기가 틀렸습니다. \(e^{3x + C} = e^C e^{3x}\)이므로 상수는 곱해집니다. \(y = Ae^{3x}\)에서 \(A = 2\), 곧 \(y = 2e^{3x}\)입니다. 검산: \(y = e^{3x} + 1\)이면 \(y' = 3e^{3x} \ne 3y\)입니다.
  4. 이 풀이에는 틀린 곳이 없다.답을 원래 식에 넣어 보세요.
  1. \(y' = \frac{x}{y}\), \(y(0) = 1\)을 푼다. \(y\,dy = x\,dx\)이다.맞습니다.
  2. 양변을 적분하면 \(\frac{y^2}{2} = \frac{x^2}{2} + C\), 곧 \(y^2 = x^2 + 2C\)이다.맞습니다.
  3. 양변의 제곱근을 취하면 \(y = x + \sqrt{2C}\)이고, \(y(0) = 1\)에서 \(y = x + 1\)이다.여기가 틀렸습니다. \(\sqrt{x^2 + 2C} \ne x + \sqrt{2C}\)입니다. \(y(0) = 1\)이면 \(2C = 1\)이고 \(y = \sqrt{x^2 + 1}\)입니다.
  4. 이 풀이에는 틀린 곳이 없다.\(x = 0\) 근처에서 두 그래프의 기울기를 비교하세요.
  1. \(y' = y^2\), \(y(0) = 1\)을 푼다. \(\frac{1}{y^2}dy = dx\)이다.맞습니다.
  2. 양변을 적분하면 \(-\frac{1}{y} = x + C\)이고, \(y(0) = 1\)에서 \(C = -1\)이다.맞습니다.
  3. 따라서 \(y = \frac{1}{1 - x}\)이고, 이 해는 \(x \to 1\)일 때 무한대로 커진다.맞습니다. 해가 유한한 시간에 무한대로 가는 "폭발"이 실제로 일어납니다.
  4. 이 풀이에는 틀린 곳이 없다.맞습니다. 방정식은 단순해 보여도 해는 \(x = 1\)에서 끝납니다.
  1. \(y' = y - 1\), \(y(0) = 1\)을 푼다.문제를 옮겼습니다.
  2. 양변을 \(y - 1\)로 나누어 적분하면 \(\ln|y - 1| = x + C\), 곧 \(y = 1 + Ae^x\ (A \ne 0)\)이다.계산은 맞습니다. 다만 나누기 전에 \(y - 1 = 0\)인 경우를 빠뜨렸습니다.
  3. \(y(0) = 1\)이면 \(A = 0\)이어야 하는데 \(A \ne 0\)이므로, 이 초기값 문제는 해가 없다.여기가 틀렸습니다. 상수함수 \(y = 1\)은 \(y' = 0 = y - 1\)이므로 해이고, \(y(0) = 1\)도 만족합니다. 나누면서 잃어버린 상수해입니다.
  4. 이 풀이에는 틀린 곳이 없다.방향장에서 \(y = 1\) 위의 선분은 어느 쪽을 향하나요?
  1. 질문변수분리형 미분방정식은 "나누고, 적분하고, 정리한다"로 풀린다. 짧은 풀이이지만 틀리기 쉬운 곳이 몇 군데 있다. 어디일까?
  2. 복원\(e^{a + b} = e^a e^b\). 미분방정식의 해는 원래 식에 넣어 성립하는지로 검산할 수 있다.
  3. 설명틀리기 쉬운 곳은 세 군데이다. ① 첫째는 적분상수의 위치이다. \(\ln|y| = 3x + C\)에서 \(C\)는 지수로 올라가 곱하는 상수가 된다(풀이 1). ② 둘째는 식 정리로, 제곱근이나 역수를 취할 때 항별로 계산하면 안 된다(풀이 2). ③ 셋째는 상수해로, \(g(y)\)로 나누면 \(g(y) = 0\)인 해를 잃는다(풀이 4). 가장 확실한 점검은 답을 미분해 원래 식에 넣어 보는 것이다.
  4. 연결풀이 3처럼 해가 유한한 \(x\)에서 끝나는 경우도 있다. 방향장만 보면 해가 영원히 이어질 것 같지만, 식으로 풀어 보면 그렇지 않을 수 있다. 방향장, 수치 해, 식으로 구한 해는 서로를 점검하는 도구이다.
  5. 적용네 풀이에서 처음 틀린 줄을 찾자. 그래프에서 실제 해와 풀이의 답이 어디서 갈라지는가? 풀이 3의 실제 해는 \(x = 1\)에 다가갈 때 어떻게 되는가?
  6. 판단초기 조건을 만족한다고 해가 맞는 것은 아니다. 풀이 1의 \(y = e^{3x} + 1\)도 \(y(0) = 2\)를 만족하지만 방정식을 만족하지 않는다. 초기 조건과 방정식을 둘 다 확인해야 한다.
