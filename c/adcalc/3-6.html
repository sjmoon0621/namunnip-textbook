테일러다항식과 테일러급수

본문

\(\cos x\)의 그래프는 \(x = 0\)에서 높이 1, 기울기 0인 봉우리를 이룬다. 이 봉우리를 이차식 \(a + bx + cx^2\)으로 흉내 내려면, 높이와 기울기를 맞추는 것만으로는 부족하고 휘어진 정도까지 맞추어야 한다. 그렇게 정한 이차식은 \(1 - x^2/2\)인데, \(x = 0.5\)에서 0.875로 \(\cos0.5 = 0.8776\)과 아주 가깝다. 차수를 하나씩 올리면 다항식은 \(\cos x\)를 어디까지 따라갈까? 그리고 오차는 얼마나 될까?

먼저 알아야 할 것접선의 기울기, 합성함수의 미분법, 삼각함수의 도함수, 지수함수의 도함수, 멱급수(멱급수의 성질과 함수의 표현).

3.6.1도함수를 차례로 맞추다

함수 \(f\)를 \(x = 0\) 근처에서 \(n\)차 다항식 \(p(x) = c_0 + c_1x + \cdots + c_nx^n\)으로 흉내 내려면, 0에서 함숫값과 1계부터 \(n\)계까지의 도함수가 모두 같도록 계수를 정한다. \(p\)를 \(k\)번 미분해 \(x = 0\)을 넣으면 \(k!\,c_k\)만 남으므로, \(c_k = f^{(k)}(0)/k!\)이다. 함숫값을 맞추면 높이가, 1계 도함수를 맞추면 기울기가, 2계 도함수를 맞추면 휘어진 정도가 같아진다. 이렇게 만든 다항식을 테일러다항식이라 하며, 1차 테일러다항식이 곧 접선이다.

정리 3.6.1 테일러다항식과 나머지

\(f\)의 \(x = 0\)에서의 \(n\)차 테일러다항식은 \[p_n(x) = \sum_{k=0}^{n}\frac{f^{(k)}(0)}{k!}x^k\]이다. 오차 \(R_n(x) = f(x) - p_n(x)\)는 0과 \(x\) 사이의 어떤 \(c\)에 대해 \(R_n(x) = \dfrac{f^{(n+1)}(c)}{(n+1)!}x^{n+1}\)이다. \(n \to \infty\)일 때 \(R_n \to 0\)이면 \(f\)는 테일러급수와 같다.

\(\cos x\)의 도함수는 \(\cos, -\sin, -\cos, \sin\)이 되풀이되므로 0에서의 값은 \(1, 0, -1, 0, 1, \ldots\)이다. 그래서 \(\cos x = 1 - \dfrac{x^2}{2!} + \dfrac{x^4}{4!} - \cdots\)이고, 짝수 차 항만 나오는 것은 \(\cos x\)가 우함수이기 때문이다. \(e^x\)는 모든 도함수가 \(e^x\)여서 0에서 모두 1이므로 \(e^x = 1 + x + \dfrac{x^2}{2!} + \cdots\)이다. 나머지의 식에서 \((n+1)!\)이 \(x^{n+1}\)보다 훨씬 빨리 커지므로, 이 두 함수는 모든 \(x\)에서 테일러급수와 같다.1

3.6.2오차의 크기를 미리 알다

테일러다항식으로 어림할 때는 나머지 식으로 오차의 상한을 구할 수 있다. \(\cos x\)는 모든 도함수의 절댓값이 1 이하이므로 \(|R_n(x)| \le \dfrac{|x|^{n+1}}{(n+1)!}\)이다. 그래서 \(x = 0.5\)에서 2차 다항식의 오차는 \(\dfrac{0.5^3}{6} \approx 0.021\) 이하인데, \(\cos\)는 3차 항이 0이므로 사실 3차 다항식과 같아 오차는 \(\dfrac{0.5^4}{24} \approx 0.0026\) 이하이다. 실제 오차 0.0026과 거의 같다. 이렇게 오차를 미리 알 수 있어서, 원하는 정확도에 필요한 차수를 정할 수 있다.

예제 3.6.2

\(e^x\)의 3차 테일러다항식으로 \(e^{0.5}\)를 구하고, 나머지 식으로 오차의 상한을 구하여라. \(e^{0.5} < 1.65\)를 써도 된다. 오차를 \(10^{-5}\) 이하로 하려면 몇 차까지 필요한가?

\(p_3(0.5) = 1 + 0.5 + \dfrac{0.25}{2} + \dfrac{0.125}{6} = 1 + 0.5 + 0.125 + 0.0208333 = 1.6458333\)이다. 나머지는 \(R_3 = \dfrac{e^c}{4!}0.5^4\)이고 \(0 < c < 0.5\)이므로 \(e^c < 1.65\)이다. 그래서 \(R_3 < \dfrac{1.65\times0.0625}{24} \approx 0.0043\)이다. 실제 오차는 \(1.6487213 - 1.6458333 \approx 0.0029\)로 상한 안에 든다.

\(\dfrac{1.65\times0.5^{n+1}}{(n+1)!} \le 10^{-5}\)이 되는 \(n\)을 찾으면, \(n = 5\)일 때 \(1.65\times0.015625/720 \approx 3.6\times10^{-5}\)이고, \(n = 6\)일 때 \(1.65\times0.0078/5040 \approx 2.6\times10^{-6}\)이다. 그래서 6차면 충분하다. 즉 테일러다항식은 한 점에서 함숫값과 도함수들을 차례로 맞추어 함수를 흉내 내는 다항식이고, 나머지 식이 오차의 크기를 미리 알려 주어 필요한 차수를 정할 수 있다.

마무리

\(f\)의 \(n\)차 테일러다항식은 한 점에서 함숫값과 \(n\)계까지의 도함수를 모두 맞춘 다항식으로, 계수는 \(f^{(k)}(0)/k!\)이며 1차 테일러다항식이 접선이다. 오차는 나머지 \(f^{(n+1)}(c)x^{n+1}/(n+1)!\)로 미리 어림할 수 있고, 나머지가 0으로 가면 함수는 테일러급수와 같다. 처음 질문의 이차식 \(1 - x^2/2\)는 \(\cos x\)의 2차 테일러다항식이어서 \(x = 0.5\)에서 오차가 0.003보다 작고, 차수를 올릴수록 더 멀리까지 맞는다.

이차식 하나로 \(\cos x\)를 가장 잘 흉내 내려면?

테일러다항식 · 만들기 · 예측 → 확인
\(x = 0.1\)에서 오차 (내 식)
—
\(x = 0.1\)에서 오차 (테일러)
?
\([-1, 1]\)에서 최대 오차 (내 식)
—
  1. 질문계산기에는 \(\cos\) 표가 없다. 덧셈과 곱셈만으로 계산하는 다항식으로 \(\cos x\)를 흉내 낼 수 있다면 편리하다. \(x = 0\) 근처에서 \(\cos x\)와 가장 비슷한 이차식 \(c_0 + c_1x + c_2x^2\)은 무엇일까? 막대로 직접 맞춰 보자.
  2. 복원접선 \(y = f(a) + f'(a)(x - a)\)는 \(x = a\)에서 함숫값과 기울기가 \(f\)와 같은 일차식이다. 이계도함수는 그래프가 휘는 정도를 나타낸다.
  3. 설명"0 근처에서 가장 비슷하다"는 것을 "0에서 함숫값, 기울기, 휘는 정도가 모두 같다"로 정하면 \(p(0) = f(0)\), \(p'(0) = f'(0)\), \(p''(0) = f''(0)\)이고, \(p''(0) = 2c_2\)이므로 \[c_0 = f(0),\quad c_1 = f'(0),\quad c_2 = \frac{f''(0)}{2}\]이다. 일반적으로 \(n\)계도함수까지 맞춘 \(T_n(x) = \sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(x - a)^k\)을 테일러다항식이라고 한다. \(\cos x\)에서는 \(T_2(x) = 1 - \frac{x^2}{2}\)이다.
  4. 연결테일러다항식의 차수를 끝없이 늘린 급수 \(\sum\frac{f^{(k)}(a)}{k!}(x - a)^k\)을 테일러급수라고 한다. \(\cos x = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots\), \(e^x = 1 + x + \frac{x^2}{2!} + \cdots\)은 모든 \(x\)에서 원래 함수와 같다.
  5. 적용막대로 \(\cos x\)에 가장 잘 맞는 이차식을 만든 다음 테일러다항식과 비교해 보자. \(x = 0.1\)에서는 어느 쪽 오차가 작은가? \([-1, 1]\) 전체의 최대 오차는 어떤가? \(e^x\)로도 해 보자.
  6. 판단테일러다항식은 중심 근처에서 가장 잘 맞도록 만든 것이지, 넓은 구간 전체에서 최대 오차가 가장 작은 다항식은 아니다. 막대로 맞춘 식이 \([-1, 1]\)의 최대 오차는 더 작을 수도 있다. 구간 전체를 고르게 맞추는 다항식은 다른 방법(최소최대 근사)으로 만든다.

차수를 올리면 테일러다항식은 어디까지 함수를 따라갈까?

테일러다항식과 테일러급수 · 조작

  1. 질문\(\sin x\)의 테일러다항식은 차수를 올릴수록 더 넓은 범위에서 \(\sin x\)를 따라간다. 차수를 끝없이 올리면 모든 함수를 어디서나 따라갈 수 있을까?
  2. 복원\(T_n(x) = \sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(x - a)^k\)는 \(x = a\)에서 \(n\)계도함수까지 \(f\)와 같은 다항식이다.
  3. 설명오차 \(R_n(x) = f(x) - T_n(x)\)는 \(a\)와 \(x\) 사이의 어떤 \(c\)에 대해 \[R_n(x) = \frac{f^{(n+1)}(c)}{(n + 1)!}(x - a)^{n+1}\]이다(테일러 정리). \(\sin x\), \(e^x\)는 도함수가 제한되거나 천천히 커지므로 \((n + 1)!\)이 이겨서 모든 \(x\)에서 \(R_n \to 0\)이고, 테일러급수가 원래 함수와 같다. \(\ln(1 + x)\)는 \(f^{(n+1)}\)이 \(n!\)처럼 커져서 \(|x| < 1\)에서만 따라가고, \(x > 1\)에서는 차수를 올릴수록 오히려 크게 벗어난다.
  4. 연결아래 그림은 오차를 로그 눈금으로 보여 준다. 오차의 골짜기가 중심 \(a\)에 있고, 차수를 올릴 때 골짜기가 넓어지면 테일러급수가 그 범위에서 함수로 수렴하는 것이다. 중심을 옮기면 같은 차수라도 맞는 곳이 옮겨 간다.
  5. 적용\(\sin x\)에서 \(n\)을 1, 3, 5, …로 올리며 맞는 범위가 넓어지는지 보자. \(\ln(1 + x)\)에서는 \(x = 1.5\) 근처가 어떻게 되는가? 중심을 \(a = 1\)로 옮기면 어떻게 바뀌는가? 마지막 보기 \(e^{-1/x^2}\)의 테일러다항식은 무엇인가?
  6. 판단\(f(x) = e^{-1/x^2}\ (f(0) = 0)\)은 \(x = 0\)에서 모든 계도함수가 0이라 테일러급수가 \(0 + 0 + \cdots = 0\)이다. 급수는 모든 \(x\)에서 수렴하지만 \(x \ne 0\)에서 원래 함수와 다르다. "테일러급수가 수렴한다"와 "테일러급수가 그 함수와 같다"는 다른 말이다.
