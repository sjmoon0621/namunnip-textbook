\(\displaystyle\lim_{x \to 2}(x^2 + 3x)\)는 2를 넣어 10이라고 답하면 된다. 그런데 \(\displaystyle\lim_{x \to 2}\frac{x^2 - 4}{x - 2}\)에 2를 넣으면 \(\tfrac{0}{0}\)이 된다. \(\tfrac{0}{0}\)은 값이 아니므로 다른 방법이 필요하다. 언제 그냥 넣어도 되고, 언제 식을 바꾸어야 할까?

먼저 알아야 할 것함수의 극한, 좌극한과 우극한(함수의 극한), 다항식의 인수분해(공통수학1), 분모의 유리화.

1.2.1극한의 성질

두 함수가 각각 수렴하면, 그 합과 곱의 극한은 극한값의 합과 곱이다. \(x\)가 \(a\)에 가까워질 때 \(f(x)\)가 \(L\)에, \(g(x)\)가 \(M\)에 가까워지면 \(f(x) + g(x)\)는 \(L + M\)에 가까워지는 것이 자연스럽다.

정리 1.2.1 함수의 극한의 성질

\(\displaystyle\lim_{x \to a} f(x) = L\), \(\displaystyle\lim_{x \to a} g(x) = M\)(\(L\), \(M\)은 실수)일 때 \[\lim (f \pm g) = L \pm M,\quad \lim cf = cL,\quad \lim fg = LM,\quad \lim \frac{f}{g} = \frac{L}{M}\ (M \ne 0)\]

이 성질에 따르면 다항함수는 \(x\)에 \(a\)를 넣은 값이 극한값이다. \(x^2 + 3x\)는 \(x\)와 상수를 곱하고 더해 만든 식이고, \(x\)의 극한이 \(a\)이기 때문이다. 분수식도 분모의 극한이 0이 아니면 넣으면 된다.

1.2.2\(\tfrac{0}{0}\) 꼴: 공통인수를 약분한다

분모의 극한이 0이면 나눗셈의 성질을 쓸 수 없다. 특히 분자도 0으로 가는 \(\tfrac{0}{0}\) 꼴은 분자와 분모가 '얼마나 빨리 0으로 가는가'를 비교해야 한다. 그림 1의 슬라이더로 \(x\)를 2에 가까이 옮기면, 분자와 분모가 함께 0으로 줄어드는데 비는 4 근처에 머문다.

까닭은 분자를 인수분해하면 보인다. \(x^2 - 4 = (x - 2)(x + 2)\)이므로 \(x \ne 2\)이면 \(\dfrac{x^2 - 4}{x - 2} = x + 2\)이다. 극한은 \(x = 2\)에서의 값을 따지지 않으므로, 약분한 식에 넣어 \(\displaystyle\lim_{x \to 2}(x + 2) = 4\)를 얻는다. 즉 분자와 분모의 0을 만드는 공통인수 \(x - 2\)를 지우는 것이 요령이다.

근호가 있으면 유리화로 공통인수를 드러낸다. \(\displaystyle\lim_{x \to 0}\frac{\sqrt{x + 9} - 3}{x}\)은 분자와 분모에 \(\sqrt{x + 9} + 3\)을 곱하면 \(\dfrac{x}{x(\sqrt{x + 9} + 3)} = \dfrac{1}{\sqrt{x + 9} + 3}\)이 되어 극한값 \(\dfrac{1}{6}\)을 얻는다.1

예제 1.2.2

\(\displaystyle\lim_{x \to 1}\frac{x^3 - 1}{x^2 - 1}\)을 구하여라. 또 \(\displaystyle\lim_{x \to 2}\frac{x^2 + ax + b}{x - 2} = 5\)일 때 상수 \(a\), \(b\)를 구하여라.

첫 식에 1을 넣으면 \(\tfrac{0}{0}\)이다. 분자는 \((x - 1)(x^2 + x + 1)\), 분모는 \((x - 1)(x + 1)\)이므로 약분하면 \(\dfrac{x^2 + x + 1}{x + 1}\)이고, 극한값은 \(\dfrac{3}{2}\)이다.

두 번째 식은 분모가 0으로 가는데 극한값이 5로 존재한다. 만약 분자가 0이 아닌 값으로 가면 비가 한없이 커지므로, 분자도 0으로 가야 한다. 따라서 \(4 + 2a + b = 0\)이고, \(b = -2a - 4\)이다.

그러면 분자는 \(x^2 + ax - 2a - 4 = (x - 2)(x + 2 + a)\)로 인수분해되고, 극한값은 \(\displaystyle\lim_{x \to 2}(x + 2 + a) = 4 + a\)이다. 이것이 5이므로 \(a = 1\), \(b = -6\)이다. 확인하면 \(\dfrac{x^2 + x - 6}{x - 2} = \dfrac{(x - 2)(x + 3)}{x - 2}\)이고 극한값은 5이다. 아래 탐구 카드에서 분자와 분모가 0으로 가는 빠르기를 직접 비교해 보자.

  1. \(\tfrac{\infty}{\infty}\) 꼴, 가령 \(\displaystyle\lim_{x \to \infty}\frac{2x^2 + 1}{x^2 - 3}\)은 분자와 분모를 가장 높은 차수 \(x^2\)으로 나누어 \(\displaystyle\lim\frac{2 + 1/x^2}{1 - 3/x^2} = 2\)를 얻는다.
마무리

수렴하는 함수의 합, 차, 곱, 몫의 극한은 극한값의 합, 차, 곱, 몫이므로 다항함수와 분모가 0으로 가지 않는 분수식은 값을 넣어 극한값을 얻는다. 넣어서 \(\tfrac{0}{0}\)이 되면 인수분해나 유리화로 0을 만드는 공통인수를 지운 뒤 넣는다. 그래서 처음 질문의 \(\tfrac{x^2 - 4}{x - 2}\)는 \(x + 2\)로 약분해 극한값 4를 얻는다.

  1. 질문\(\lim_{x \to 2} (x + 1) = 3, \lim_{x \to 2} (x^2 - 1) = 3\)이다. 그렇다면 두 식의 합, 곱, 몫의 극한값도 \(3 + 3, 3 \times 3, 3 \div 3\)으로 바로 얻을 수 있을까? 언제나 그럴까?
  2. 복원\(\lim_{x \to a} f(x) = \alpha\)는 \(x\)가 \(a\)에 가까워질 때 \(f(x)\)가 실수 \(\alpha\)에 한없이 가까워진다는 뜻이다. 그래서 \(f(x)\)가 \(\alpha\)에, \(g(x)\)가 \(\beta\)에 가까우면 두 값을 더하거나 곱한 수도 \(\alpha + \beta, \alpha\beta\)에 가깝다.
  3. 설명\(\lim_{x \to a} f(x) = \alpha, \lim_{x \to a} g(x) = \beta\) (\(\alpha, \beta\)는 실수)일 때 상수 \(c\)에 대하여 \(\lim cf(x) = c\alpha\)이고, \(\lim \{f(x) \pm g(x)\} = \alpha \pm \beta\), \(\lim f(x)g(x) = \alpha\beta\)이며, \(\beta \ne 0\)이면 \(\lim \frac{f(x)}{g(x)} = \frac{\alpha}{\beta}\)이다. 이 성질은 \(x \to a^+, x \to a^-, x \to \infty, x \to -\infty\)일 때도 성립한다. 그리고 다항함수 \(p(x)\)는 \(\lim_{x \to a} x = a\)와 이 성질을 거듭 써서 \(\lim_{x \to a} p(x) = p(a)\)임을 보일 수 있다.
  4. 연결다만 성질을 쓰려면 두 극한값이 모두 실수로 존재해야 하고, 몫에서는 분모의 극한값이 0이 아니어야 한다. 이 조건이 깨지면 성질로는 답을 낼 수 없을 뿐이고, 극한이 없다는 뜻은 아니다. 그때는 식을 고쳐 다시 구한다. 또 극한값은 크기 비교도 지킨다. \(a\) 근처에서 \(f(x) \le g(x)\)이면 \(\alpha \le \beta\)이고, \(f(x) \le h(x) \le g(x)\)이며 \(\alpha = \beta\)이면 \(\lim_{x \to a} h(x) = \alpha\)이다. 하지만 \(f(x) < g(x)\)여도 \(\alpha < \beta\)라고는 할 수 없고 \(\alpha = \beta\)일 수 있다.
  5. 적용\(a = 2\)에서 다섯 가지 계산을 차례로 눌러 '값'과 '성질로 계산'이 같은지 보자. 그다음 \(f / g\)를 고르고 \(a\)를 1과 \(-1\)로 옮겨 보면, 두 경우 모두 \(\lim g = 0\)인데 실제 값은 다르게 움직인다.
  6. 판단\(a = -1\)에서는 \(\lim f = 0, \lim g = 0\)이라 성질로는 \(0/0\)을 얻지만, 실제로는 \(\frac{f}{g} = \frac{1}{x - 1}\ (x \ne \pm 1)\)이므로 극한값 \(-\frac{1}{2}\)이 있다. 반면 \(a = 1\)에서는 분자가 2로 가고 분모가 0으로 가서 발산한다. 또 각각 발산하는 두 함수의 합이 수렴할 수도 있다. \(\frac{1}{x^2}\)과 \(-\frac{1}{x^2}\)은 \(x \to 0\)에서 발산하지만 합은 0이다. 그래서 성질은 두 극한값이 있을 때에만 쓴다.

—
  1. 질문\(\lim_{x \to 2} \frac{x^2 - x - 2}{x - 2}\)에 2를 넣으면 \(0/0\)이 된다. 분모의 극한값이 0이라 몫의 성질을 쓸 수 없다. 그래프를 보면 값이 한 곳으로 모이는데, 그 값을 계산으로 확실히 얻으려면 어떻게 해야 할까?
  2. 복원극한의 성질은 두 극한값이 실수로 존재하고, 몫에서는 분모의 극한값이 0이 아닐 때만 쓴다. 또 극한은 \(x = a\)가 아닌 \(x\)에서의 값만 보므로, \(x \ne a\)에서 같은 값을 갖는 식으로 바꾸어도 극한값은 그대로이다.
  3. 설명대입했을 때 \(0/0, \infty/\infty, \infty - \infty, 0 \times \infty\)가 되는 꼴은 그 자체로는 값이 정해지지 않는다. 같은 \(0/0\) 꼴이라도 극한이 3일 수도, 발산할 수도 있기 때문이다. 그래서 식을 고쳐 성질을 쓸 수 있는 꼴로 만든다. 다항식의 \(0/0\) 꼴은 인수분해하여 0이 되는 인수를 약분하고, 근호가 있는 \(0/0\) 꼴은 분자나 분모를 유리화한다. \(x \to \infty\)일 때 \(\infty/\infty\) 꼴은 분모의 최고차항으로 분자와 분모를 나누고, \(\infty - \infty\) 꼴은 근호가 있으면 유리화하여 분수 꼴로 바꾼다.
  4. 연결약분이 허용되는 까닭은 \(x \to 2\)에서 \(x \ne 2\)이기 때문이다. \(\frac{(x - 2)(x + 1)}{x - 2}\)와 \(x + 1\)은 \(x = 2\)에서만 다르고, 극한은 그 점을 보지 않는다. 또 \(\infty/\infty\) 꼴에서 분자와 분모의 차수가 같으면 극한값은 최고차항 계수의 비이고, 분모의 차수가 더 크면 0, 분자의 차수가 더 크면 발산이다.
  5. 적용식을 하나 고르고 '다음 단계'를 눌러 고치는 과정을 따라가 보자. 식이 바뀌면 고친 식의 그래프가 처음 그래프와 겹치고 구멍을 채운다. 슬라이더로 \(x\)를 보내며 두 식의 값이 같은지, 극한값으로 모이는지도 확인해 보자.
  6. 판단\(0/0\)을 1로, \(\infty - \infty\)를 0으로 두는 것은 틀린다. 넷째 식은 \(\infty - \infty\) 꼴이지만 극한값이 1이다. 또 \(\sqrt{x^2}\)은 \(x\)가 아니라 \(|x|\)이다. 그래서 \(x \to -\infty\)에서 같은 식을 다루면 부호가 바뀌므로, 나누기 전에 \(x\)의 부호를 확인해야 한다.

\(\lim_{x \to 1} \frac{x^2 + ax + b}{x - 1} = 3\)이 되게 하기

분자의 \(x \to 1\) 극한
—
\(f(0.999) / f(1.001)\)
—
\(\lim_{x \to 1}\)
—

—

  1. 질문\(\lim_{x \to 1} \frac{x^2 + ax + b}{x - 1} = 3\)이 되도록 상수 \(a, b\)를 정하려고 한다. 분모가 0으로 가는데 몫이 3이라는 유한한 값으로 간다면, 분자에 대해 무엇을 알 수 있을까?
  2. 복원\(\lim f = \alpha, \lim g = \beta\)가 실수로 존재하면 \(\lim f \cdot g = \alpha\beta\)이다. 그리고 다항함수는 \(\lim_{x \to a} p(x) = p(a)\)이다.
  3. 설명\(\lim_{x \to a} \frac{f(x)}{g(x)} = \alpha\) (\(\alpha\)는 실수)이고 \(\lim_{x \to a} g(x) = 0\)이면 \(\lim_{x \to a} f(x) = 0\)이다. \(f(x) = \{\frac{f(x)}{g(x)}\} \times g(x)\)로 쓰면, 곱의 성질에서 \(\lim f = \alpha \times 0 = 0\)이기 때문이다. 이 카드의 식에서는 분자의 극한 \(1 + a + b\)가 0이어야 하므로 \(b = -1 - a\)이다. 그러면 분자는 \((x - 1)(x + 1 + a)\)로 인수분해되고, 약분하면 극한값은 \(2 + a\)이다.
  4. 연결따라서 \(2 + a = 3\)에서 \(a = 1, b = -2\)이다. 첫 조건(분자가 0으로 감)은 '극한이 있을 수 있는 후보'를 한 직선 위로 좁히고, 둘째 조건(약분한 값이 3)이 그 가운데 하나를 고른다. 같은 생각을 거꾸로 쓰면, 분자가 0으로 가고 몫의 극한값이 0이 아닌 실수이면 분모도 0으로 가야 한다.
  5. 적용먼저 \(a = 0\)으로 두고 \(b\)를 움직여 그래프가 \(x = 1\) 양쪽으로 갈라지지 않는 \(b\)를 찾고, 그때 극한값이 얼마인지 보자. 이번에는 분자의 극한이 0을 지키도록 \(a\)와 \(b\)를 함께 바꾸어 극한값이 3이 되는 경우를 찾아보자.
  6. 판단분자의 극한이 0이라는 조건만으로 답을 끝내면 안 된다. 그 조건은 극한이 존재하기 위한 필요조건일 뿐이고, \(1 + a + b = 0\)을 만족하는 \((a, b)\)는 무수히 많다. 반대로 분자의 극한이 0이 아니면 몫은 \(x = 1\) 양쪽에서 부호가 다른 무한대로 발산하여 어떤 극한값도 가질 수 없다.
