극한의 성질과 극한값

극한값을 매번 표를 만들어 짐작할 수는 없습니다. 이 절에서는 극한값이 있는 두 함수를 더하고 곱하고 나눌 때 극한값도 그대로 더하고 곱하고 나누어진다는 성질을 확인합니다. 그리고 그대로 대입하면 0/0이나 ∞/∞이 되는 식을 약분, 유리화, 최고차항으로 나누기로 고쳐 극한값을 구합니다.

  1. 질문limx→2 (x + 1) = 3, limx→2 (x2 − 1) = 3입니다. 그렇다면 두 식의 합, 곱, 몫의 극한값도 3 + 3, 3 × 3, 3 ÷ 3으로 바로 얻을 수 있을까요? 언제나 그럴까요?
  2. 복원limx→a f(x) = α는 x가 a에 가까워질 때 f(x)가 실수 α에 한없이 가까워진다는 뜻입니다. f(x)가 α에, g(x)가 β에 가까우면 두 값을 더하거나 곱한 수도 α + β, αβ에 가깝습니다.
  3. 설명limx→a f(x) = α, limx→a g(x) = β (α, β는 실수)일 때 ① lim cf(x) = cα (c는 상수) ② lim {f(x) ± g(x)} = α ± β ③ lim f(x)g(x) = αβ ④ β ≠ 0이면 lim f(x)/g(x) = α/β입니다. 이 성질은 x → a+, x → a−, x → ∞, x → −∞일 때도 성립합니다. 다항함수 p(x)는 limx→a x = a와 이 성질을 거듭 써서 limx→a p(x) = p(a)임을 보일 수 있습니다.
  4. 연결성질을 쓰려면 두 극한값이 모두 실수로 존재해야 하고, 몫에서는 분모의 극한값이 0이 아니어야 합니다. 이 조건이 깨지면 성질로는 답을 낼 수 없을 뿐이고, 극한이 없다는 뜻은 아닙니다. 그때는 식을 고쳐 다시 구합니다. 극한값은 크기 비교도 지킵니다. a 근처에서 f(x) ≤ g(x)이면 α ≤ β이고, f(x) ≤ h(x) ≤ g(x)이며 α = β이면 limx→a h(x) = α입니다. 다만 f(x) < g(x)여도 α < β라고는 할 수 없고 α = β일 수 있습니다.
  5. 적용a = 2에서 다섯 가지 계산을 차례로 눌러 '값'과 '성질로 계산'이 같은지 보세요. 그다음 f / g를 고르고 a를 1과 −1로 옮겨 보세요. 두 경우 모두 lim g = 0인데, 실제 값은 어떻게 다르게 움직이나요?
  6. 판단a = −1에서는 lim f = 0, lim g = 0이라 성질로는 0/0을 얻지만, 실제로는 f/g = 1/(x − 1) (x ≠ ±1)이므로 극한값 −1/2이 있습니다. a = 1에서는 분자가 2로 가고 분모가 0으로 가서 발산합니다. 또 각각 발산하는 두 함수의 합이 수렴할 수도 있습니다. 1/x2과 −1/x2은 x → 0에서 발산하지만 합은 0입니다. 그래서 성질은 '두 극한값이 있을 때'에만 씁니다.

1.2.2

대입하면 0/0이 나오는 식의 극한값은 어떻게 구할까?

—
고친 식의 값
—
  1. 질문limx→2 (x2 − x − 2)/(x − 2)에 2를 넣으면 0/0이 됩니다. 분모의 극한값이 0이라 몫의 성질을 쓸 수 없습니다. 그래프를 보면 값이 한 곳으로 모이는데, 그 값을 계산으로 확실히 얻으려면 어떻게 해야 할까요?
  2. 복원극한의 성질은 두 극한값이 실수로 존재하고, 몫에서는 분모의 극한값이 0이 아닐 때만 씁니다. 또 극한은 x = a가 아닌 x에서의 값만 보므로, x ≠ a에서 같은 값을 갖는 식으로 바꾸어도 극한값은 그대로입니다.
  3. 설명대입했을 때 0/0, ∞/∞, ∞ − ∞, 0 × ∞가 되는 꼴은 그 자체로는 값이 정해지지 않습니다. 같은 0/0 꼴이라도 극한이 3일 수도, 발산할 수도 있습니다. 그래서 식을 고쳐 성질을 쓸 수 있는 꼴로 만듭니다. ① 다항식의 0/0 꼴은 인수분해하여 0이 되는 인수를 약분합니다. ② 근호가 있는 0/0 꼴은 분자나 분모를 유리화합니다. ③ x → ∞일 때 ∞/∞ 꼴은 분모의 최고차항으로 분자와 분모를 나눕니다. ④ ∞ − ∞ 꼴은 근호가 있으면 유리화하여 분수 꼴로 바꿉니다.
  4. 연결약분이 허용되는 까닭은 x → 2에서 x ≠ 2이기 때문입니다. (x − 2)(x + 1)/(x − 2)와 x + 1은 x = 2에서만 다르고, 극한은 그 점을 보지 않습니다. ∞/∞ 꼴에서 분자와 분모의 차수가 같으면 극한값은 최고차항 계수의 비, 분모의 차수가 더 크면 0, 분자의 차수가 더 크면 발산입니다.
  5. 적용식을 하나 고르고 '다음 단계'를 눌러 고치는 과정을 따라가세요. 식이 바뀌면 고친 식의 그래프가 처음 그래프와 겹치는지, 구멍을 채우는지 보세요. 슬라이더로 x를 보내며 두 식의 값이 같은지, 극한값으로 모이는지도 확인하세요.
  6. 판단0/0을 1로, ∞ − ∞를 0으로 두는 것은 틀립니다. 넷째 식은 ∞ − ∞ 꼴이지만 극한값이 1입니다. 또 √(x2)은 x가 아니라 |x|입니다. x → −∞에서 같은 식을 다루면 부호가 바뀌므로, 나누기 전에 x의 부호를 확인해야 합니다.

분모가 0으로 가는데 극한값이 있다면 분자는?

분자의 x → 1 극한

f(0.999) / f(1.001)
—
lim x→1
—

—

  1. 질문limx→1 (x2 + ax + b)/(x − 1) = 3이 되도록 상수 a, b를 정하려고 합니다. 분모가 0으로 가는데 몫이 3이라는 유한한 값으로 간다면, 분자에 대해 무엇을 알 수 있을까요?
  2. 복원lim f = α, lim g = β가 실수로 존재하면 lim f·g = αβ입니다. 다항함수는 limx→a p(x) = p(a)입니다.
  3. 설명limx→a f(x)/g(x) = α (α는 실수)이고 limx→a g(x) = 0이면 limx→a f(x) = 0입니다. f(x) = {f(x)/g(x)} × g(x)로 쓰면, 곱의 성질에서 lim f = α × 0 = 0이기 때문입니다. 이 카드의 식에서는 분자의 극한 1 + a + b가 0이어야 하므로 b = −1 − a입니다. 그러면 분자는 (x − 1)(x + 1 + a)로 인수분해되고, 약분하면 극한값은 2 + a입니다.
  4. 연결2 + a = 3에서 a = 1, b = −2입니다. 첫 조건(분자 → 0)은 '극한이 있을 수 있는 후보'를 한 직선 위로 좁히고, 둘째 조건(약분한 값 = 3)이 그중 하나를 고릅니다. 같은 생각을 거꾸로 쓰면, 분자가 0으로 가고 몫의 극한값이 0이 아닌 실수이면 분모도 0으로 가야 합니다.
  5. 적용먼저 a = 0으로 두고 b를 움직여 그래프가 x = 1 양쪽으로 갈라지지 않는 b를 찾으세요. 그때 극한값은 얼마인가요? 이번에는 분자의 극한이 0을 지키도록 a와 b를 함께 바꾸어 극한값이 3이 되는 경우를 찾으세요.
  6. 판단분자의 극한이 0이라는 조건만으로 답을 끝내면 안 됩니다. 그 조건은 극한이 존재하기 위한 필요조건일 뿐이고, 1 + a + b = 0을 만족하는 (a, b)는 무수히 많습니다. 반대로 분자의 극한이 0이 아니면 몫은 x = 1 양쪽에서 부호가 다른 무한대로 발산하여 어떤 극한값도 가질 수 없습니다.
