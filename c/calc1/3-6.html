속도와 거리

미분으로 위치에서 속도를 얻었습니다. 거꾸로 속도 기록만 남아 있을 때, 적분하면 물체가 어디에 있는지와 모두 얼마나 움직였는지 알 수 있습니다. 변위와 이동 거리가 언제 달라지는지 확인하고, 두 물체의 속도 그래프로 따라잡기 문제를 풀어 봅니다.

먼저 알면 좋은 것 수직선 위의 속도와 가속도정적분 \(F(b) - F(a)\)곡선과 \(x\)축 사이의 넓이

3.6.1

속도만 알면 움직인 거리를 알 수 있을까?

속도와 거리 · 변위와 이동 거리
속도 \(v(t)\)
—
변위 \(\int v\,dt\)
—
이동 거리 \(\int|v|\,dt\)
—
위치 \(x(t)\)
—

—

위 그래프 안을 끌면 시각 \(t\)가 바뀝니다. 아래 자취는 파랑이 양의 방향, 주황이 음의 방향으로 움직인 부분이고, 위로 갈수록 나중 시각입니다.

  1. 질문수직선 위를 움직이는 점 \(P\)의 속도가 \(v(t) = 3t^2 - 12t + 9\)입니다. 속도만 알 때, \(t = 4\)에서 \(P\)가 어디에 있는지, 그동안 \(P\)가 모두 얼마나 움직였는지 구할 수 있을까요?
  2. 복원위치 \(x(t)\)를 미분하면 속도 \(v(t) = x'(t)\)입니다. 곧 위치는 속도의 부정적분입니다. \(F' = f\)이면 \(\int_a^b f(t)\,dt = F(b) - F(a)\)이고, 그래프와 가로축 사이의 넓이는 \(\int|f(t)|\,dt\)입니다.
  3. 설명\(x' = v\)이므로 \(\int_a^b v(t)\,dt = x(b) - x(a)\)입니다. 이 값은 위치의 변화량, 곧 변위입니다. 그래서 시각 \(t\)에서의 위치는 \(x(t) = x(0) + \int_0^t v(s)\,ds\)입니다. 한편 실제로 움직인 길이인 이동 거리는 거꾸로 간 부분도 더해야 하므로 \(\int_a^b |v(t)|\,dt\)입니다. 예에서 \(v = 3(t - 1)(t - 3)\)이고 \(\int_0^4 v\,dt = [t^3 - 6t^2 + 9t]_0^4 = 4\)입니다. 이동 거리는 \(t = 1, 3\)에서 나누어 \(4 + 4 + 4 = 12\)입니다.
  4. 연결미분에서는 위치에서 속도로 갔고, 적분은 속도에서 위치로 돌아옵니다. 가속도를 적분하면 같은 방법으로 속도의 변화량을 얻습니다. 자동차의 주행 거리계는 바퀴가 돈 횟수로 이동 거리를 쌓아 가는데, 이것은 속력을 시간에 대해 적분하는 것과 같은 일입니다.
  5. 적용\(t\)를 0부터 4까지 밀면서 변위와 이동 거리가 언제부터 달라지는지 찾아 보세요. 처음 위치 \(x(0)\)을 바꾸면 위치, 변위, 이동 거리 가운데 무엇이 바뀌나요? \(v = t^2 - 4t + 5\)에서는 변위와 이동 거리가 끝까지 같습니다. 위 그래프의 어떤 모양 때문인가요?
  6. 판단"속도를 적분하면 이동 거리"는 속도의 부호가 바뀌지 않을 때만 맞습니다. 되돌아가는 구간이 있으면 \(\int v\,dt\)는 앞뒤로 간 거리가 서로 지워진 변위입니다. 또 \(\int_0^t v\,dt\)는 위치가 아니라 위치의 변화량이므로, 위치를 구하려면 처음 위치를 더해야 합니다. 이 카드는 직선 위의 운동만 다룹니다.

3.6.2

두 속도 그래프가 만나는 순간, 두 물체도 만날까?

\(A\)의 위치
—
\(B\)의 위치
—
간격 \(B - A\)
—
따라잡는 시각
—

—

\(A\)는 원점에서 정지 상태로 출발해 \(v_A = at\)로 빨라지고, \(B\)는 \(x = d\)에서 일정한 속도 \(v_B = k\)로 출발합니다. 위 그래프 안을 끌면 시각 \(t\)가 바뀝니다.

  1. 질문같은 출발선에서 \(A\)는 정지 상태에서 \(v_A = 2t\)로 가속하고, \(B\)는 일정한 속도 4로 출발합니다. 처음에는 \(B\)가 앞서 나갑니다. 두 속도 그래프는 \(t = 2\)에서 만나는데, 이때 \(A\)가 \(B\)를 따라잡을까요?
  2. 복원시각 0부터 \(t\)까지의 변위는 \(\int_0^t v(s)\,ds\)이고, 정적분은 \(\int(f - g) = \int f - \int g\)로 나눌 수 있습니다. 위끝이 변수인 정적분을 미분하면 피적분함수가 됩니다.
  3. 설명두 물체의 간격은 \(x_B(t) - x_A(t) = d + \int_0^t \{v_B(s) - v_A(s)\}\,ds\)입니다. 곧 두 속도 그래프 사이의 넓이가 간격의 변화입니다. \(B\)가 빠른 동안(노랑) 간격이 벌어지고, \(A\)가 빠른 동안(파랑) 줄어듭니다. 그래서 간격이 가장 큰 때는 두 속도가 같아지는 순간이고, 만나는 때는 처음 간격 + 노랑 넓이 − 파랑 넓이 = 0인 순간입니다. 예에서 간격은 \(4t - t^2\)이므로 \(t = 2\)에서 가장 큰 값 4가 되고, \(t = 4\)에서 0이 되어 \(A\)가 \(B\)를 따라잡습니다.
  4. 연결간격 \(D(t) = d + \int_0^t (v_B - v_A)\,ds\)를 미분하면 \(D'(t) = v_B(t) - v_A(t)\)입니다. \(D'\)의 부호가 +에서 −로 바뀌는 곳이 \(D\)의 극대이므로, 미분에서 배운 극대 판정과 같은 결론입니다. 앞차와의 거리를 재며 속도를 맞추는 자동차의 차간 거리 유지 기능도 이 간격의 변화를 다룹니다.
  5. 적용기본값에서 \(t\)를 움직여 노랑 넓이와 파랑 넓이가 같아지는 순간을 찾고, 그때 '간격 \(B - A\)'가 0인지 확인하세요. \(d\)를 늘리면 따라잡는 시각은 늦어지나요? 간격이 가장 큰 시각은 \(d\)에 따라 바뀌나요?
  6. 판단"속도 그래프가 만나는 점에서 두 물체가 만난다"는 흔한 오해입니다. 속도–시간 그래프의 교점은 속도가 같은 순간이고, 이때는 오히려 간격이 가장 큽니다. 위치가 같아지는 순간은 그래프 사이의 넓이로 판단해야 합니다. 이 카드는 같은 직선 위에서 같은 방향으로 움직이는 경우만 다룹니다.
