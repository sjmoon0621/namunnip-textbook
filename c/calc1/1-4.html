1.4.1

연속함수끼리 더하고 곱하고 나누어도 연속일까?

읽기 · 연속함수의 성질

x3 − 2x + 5가 모든 실수에서 연속이라는 것을 어떻게 알 수 있을까요? 점마다 세 조건을 확인하지 않고도 판정할 수 있는 방법이 있습니다.

1극한의 성질에서 바로 나온다

두 함수 f(x), g(x)가 x = a에서 연속이면 limx→a f(x) = f(a), limx→a g(x) = g(a)입니다. 두 극한값이 실수로 존재하므로 극한의 성질을 쓸 수 있습니다. 예를 들어 곱은 limx→a f(x)g(x) = f(a)g(a)이므로, f(x)g(x)도 x = a에서 연속입니다. 같은 방법으로 다음이 성립합니다.

f, g가 x = a에서 연속일 때x = a에서 연속인 함수근거
실수배cf(x) (c는 상수)lim cf = c lim f
합과 차f(x) + g(x), f(x) − g(x)lim (f ± g) = lim f ± lim g
곱f(x)g(x)lim fg = lim f × lim g
몫f(x)/g(x), 단 g(a) ≠ 0lim f/g = lim f ÷ lim g

2다항함수와 유리함수

상수함수 y = c와 y = x는 모든 실수에서 연속입니다. x2 = x × x는 곱이므로 연속이고, 같은 방법으로 xn도 연속입니다. 여기에 실수배와 합을 거듭하면 다항함수는 모든 실수에서 연속입니다. 다항함수의 몫인 유리함수 p(x)/q(x)는 q(x) ≠ 0인 모든 실수, 곧 정의역 전체에서 연속입니다. 그래서 (x2 + 1)/(x − 3)은 x ≠ 3인 모든 실수에서 연속인 연속함수입니다.

3쓰는 법

  • 식이 하나로 주어진 다항함수, 유리함수는 정의역의 모든 점에서 연속입니다. 따로 확인할 필요가 없습니다.
  • 식이 바뀌는 함수는 각 조각이 다항함수라면, 조각 안에서는 연속이고 식이 바뀌는 점에서만 세 조건을 확인하면 됩니다.
  • f(x)g(x)가 연속이 되도록 하는 문제에서는, 불연속인 점 a에서 다른 쪽 함수가 0이 되어 끊어진 곳을 메우는지 극한값을 직접 계산합니다.

판단성질의 역은 성립하지 않습니다. f + g나 fg가 연속이어도 f, g가 각각 연속이라는 보장은 없습니다. 예를 들어 f(x) = 1 (x ≥ 0), −1 (x < 0)은 x = 0에서 불연속이지만, f(x) × f(x) = 1은 모든 실수에서 연속입니다. 또 몫에서는 분모가 0이 되는 점을 반드시 따로 봐야 합니다.

그래프 위의 점을 끌어 구간에서 가장 높은 곳과 가장 낮은 곳을 직접 찾아보세요.

  1. 질문함수가 어떤 구간에서 가장 큰 값과 가장 작은 값을 꼭 가질까요? 끝점을 빼거나 한 점에서 끊어 놓아도 그럴까요? 최댓값이 '반드시 있다'고 말하려면 어떤 조건이 필요할까요?
  2. 복원구간에서의 최댓값은 구간 안의 어떤 점 c에서 f(c) ≥ f(x)가 모든 x에 대해 성립할 때의 f(c)입니다. 값에 한없이 가까워지기만 하고 그 값을 갖는 점이 없으면 최댓값이 아닙니다. 닫힌구간은 양 끝점을 포함하는 구간입니다.
  3. 설명최대·최소 정리: 함수 f(x)가 닫힌구간 [a, b]에서 연속이면, f(x)는 이 구간에서 반드시 최댓값과 최솟값을 갖습니다. 정리는 최댓값이 있다는 것만 알려 주고, 어디에 있는지는 알려 주지 않습니다. 최댓값은 구간 안쪽의 꼭대기에 있을 수도, 끝점에 있을 수도 있습니다.
  4. 연결[−1.5, 2]에서 f는 x = −1과 x = 2에서 최댓값 2를, x = 1에서 최솟값 −2를 갖습니다. 오른쪽 끝을 빼면 x = −1에서 여전히 최댓값 2를 갖습니다. 조건이 깨졌다고 결론이 꼭 깨지는 것은 아닙니다. 그러나 [−1.5, 2)를 [0, 2)처럼 바꾸면 값이 2에 가까워지기만 하고 2가 되는 점은 없습니다. 이번에는 최댓값이 없습니다.
  5. 적용처음 구간에서 점을 끌어 최댓값과 최솟값을 찾고 아래 값과 비교하세요. 다음으로 a = 0으로 옮기고 오른쪽 끝을 빼 보세요. 마지막으로 다시 닫힌구간으로 두고 'f(1)만 0으로 바꾸기'를 눌러 연속 조건을 깨 보세요. 최솟값은 어떻게 되나요? 이때 a = −2로 옮기면 무엇이 달라지나요?
  6. 판단정리는 '조건이 맞으면 반드시 있다'는 뜻이고, 그 역은 아닙니다. 조건이 깨지면 최댓값이 없을 수도, 우연히 있을 수도 있습니다. f(1)을 0으로 바꾸고 [−2, 2]를 보면, 연속이 아닌데도 x = −2에서 최솟값 −2를 갖습니다. 또 '열린구간이면 최댓값이 없다'도 틀립니다. 꼭대기가 구간 안쪽에 있으면 열린구간에서도 최댓값이 있습니다.

1.4.3

그래프를 보지 않고 방정식의 근이 있는 곳을 알 수 있을까?

사잇값 정리 · 이분법
지금 구간
—
구간의 폭
—
f(c) = k인 c
—

—

  1. 질문방정식 x3 + x − 1 = 0은 인수분해가 되지 않습니다. 그래도 f(0) = −1 < 0, f(1) = 1 > 0이라는 것만으로 0과 1 사이에 근이 있다고 말할 수 있을까요? 그 근을 원하는 만큼 정확하게 찾으려면 어떻게 해야 할까요?
  2. 복원다항함수는 모든 실수에서 연속입니다. 연속인 함수의 그래프는 구간 안에서 끊어지지 않습니다. 방정식 f(x) = 0의 실근은 그래프가 x축과 만나는 점의 x좌표입니다.
  3. 설명사잇값 정리: 함수 f(x)가 닫힌구간 [a, b]에서 연속이고 f(a) ≠ f(b)이면, f(a)와 f(b) 사이의 임의의 값 k에 대하여 f(c) = k인 c가 열린구간 (a, b)에 적어도 하나 존재합니다. 특히 f(a)와 f(b)의 부호가 다르면(f(a)f(b) < 0), k = 0으로 두어 방정식 f(x) = 0이 (a, b)에서 적어도 하나의 실근을 가집니다.
  4. 연결이 정리를 되풀이하면 근의 위치를 좁힐 수 있습니다. 구간의 가운데 m에서 f(m) − k의 부호를 보고, 부호가 바뀌는 절반을 남깁니다. 한 번에 폭이 절반이 되므로 10번이면 처음 폭의 1/1024 안에 근이 있습니다. 이 방법을 이분법이라 합니다.
  5. 적용첫째 함수에서 '구간을 반으로'를 여러 번 눌러 근을 소수 셋째 자리까지 찾으세요. 둘째 함수로 바꾸면 그 근이 어떤 수인지 알아보세요. k를 움직여 f(a)와 f(b) 사이의 높이마다 c가 있는지도 보세요. 셋째 함수에서는 같은 일을 하면 무엇이 달라지나요?
  6. 판단1/(x − 1)은 f(0) = −1, f(2) = 1로 부호가 다르지만 0과 2 사이에서 0이 되는 점이 없습니다. x = 1에서 정의되지 않아 [0, 2]에서 연속이 아니므로 사잇값 정리를 쓸 수 없습니다. 이분법은 근 대신 끊어진 점 1로 좁혀 들어갑니다. 또 정리는 근이 '적어도 하나' 있다고 할 뿐, 몇 개인지는 알려 주지 않습니다. 부호가 같다고 근이 없다는 뜻도 아닙니다.
