3.3.1

곡선 아래의 넓이를 직사각형으로 잴 수 있을까?

정적분 · 넓이로 정의하기
직사각형 넓이의 합
—
곡선 아래 넓이
—
차이
—

'곡선 아래 넓이'의 값을 계산하는 방법은 부정적분과 정적분의 관계에서 다룹니다. 여기서는 직사각형 합이 그 값에 다가가는지만 보세요.

  1. 질문직사각형, 삼각형의 넓이는 공식으로 구합니다. 그러면 y = x2과 x축, 직선 x = 2로 둘러싸인 도형처럼 한쪽이 곡선인 도형의 넓이는 어떻게 잴까요?
  2. 복원함수 f가 닫힌구간 [a, b]에서 연속이면 그래프가 끊어지지 않습니다. 직사각형의 넓이는 밑변 × 높이입니다. 수열의 극한에서는 n이 한없이 커질 때 값이 다가가는 수를 생각했습니다.
  3. 설명구간을 폭이 같은 직사각형 n개로 나누고, 각 직사각형의 높이를 그 칸 안의 함숫값으로 잡아 넓이를 더하면 곡선 아래 넓이의 근삿값을 얻습니다. n을 크게 할수록 남거나 모자라는 조각이 줄어, 높이를 어디서 잡든 합이 같은 값에 다가갑니다. 그 값이 곡선 아래의 넓이입니다. 닫힌구간 [a, b]에서 연속이고 f(x) ≥ 0인 함수에 대해, y = f(x)의 그래프와 x축 및 두 직선 x = a, x = b로 둘러싸인 도형의 넓이를 f(x)의 a에서 b까지의 정적분이라 하고 ∫ab f(x)dx로 씁니다. a를 아래끝, b를 위끝이라 합니다.
  4. 연결기호 ∫는 합(sum)의 첫 글자 S를 길게 늘인 모양이고, f(x)dx는 높이 f(x), 폭 dx인 아주 가는 직사각형을 떠올리게 합니다. 직사각형의 합을 극한으로 보내는 방법(구분구적법)은 미적분Ⅱ에서 정적분과 급수의 관계로 다시 다룹니다.
  5. 적용x2에서 '오른쪽 끝 높이'와 '왼쪽 끝 높이'를 번갈아 고르면 합이 참값보다 큰가요, 작은가요? 그 까닭을 그래프의 증가와 연결해 보세요. 차이가 0.01보다 작아지려면 n이 얼마쯤이어야 하나요? '가운데 높이'에서는 어떤가요?
  6. 판단직사각형 합은 어디까지나 근삿값입니다. n을 아무리 크게 해도 유한한 n에서는 대개 오차가 남고, 정적분은 그 합이 다가가는 극한값입니다. 또 이 정의는 f(x) ≥ 0인 경우의 것입니다. 함숫값이 음수인 곳이 있으면 '넓이'를 그대로 쓸 수 없어서 정의를 넓혀야 합니다.

3.3.2

그래프가 x축 아래로 내려가면 정적분은 어떻게 될까?

정적분 · 일반적인 연속함수로 확장
x축 위쪽 넓이
—
x축 아래쪽 넓이
—
∫ₐᵇ f(x)dx
—

—

x축 위의 점 a(검정)와 b(주황)를 끌어 옮길 수 있습니다. b를 a보다 왼쪽으로 보내 보세요.

  1. 질문정적분을 '곡선 아래 넓이'로 정했습니다. 그런데 y = x2 − 1처럼 그래프가 x축 아래로 내려가는 함수, 또 위끝이 아래끝보다 작은 경우에는 정적분을 어떻게 정해야 할까요?
  2. 복원f(x) ≥ 0이고 f가 [a, b]에서 연속이면 ∫ab f(x)dx는 그래프와 x축, x = a, x = b로 둘러싸인 넓이입니다. 넓이는 언제나 0 이상입니다.
  3. 설명직사각형 합으로 생각하면 함숫값이 음수인 칸은 높이가 음수이므로 넓이를 빼는 셈이 됩니다. 그래서 일반적인 연속함수에 대해 ∫ab f(x)dx = (x축 위쪽 넓이) − (x축 아래쪽 넓이) (a < b)로 정의를 넓힙니다. 또 끝이 같거나 거꾸로인 경우를 다음과 같이 약속합니다. ∫aa f(x)dx = 0, ∫ba f(x)dx = −∫ab f(x)dx (a < b). 이렇게 정하면 정적분은 넓이가 아니라 부호가 있는 값이 됩니다.
  4. 연결속도–시간 그래프에서 시간축 아래 넓이가 반대 방향의 변위를 뜻했던 것과 같은 생각입니다. 넓이 자체를 구하는 문제에서는 위쪽과 아래쪽을 모두 더해야 하고, 이것은 넓이 절에서 다시 다룹니다.
  5. 적용x2 − 1에서 a = −1, b = 1로 두면 정적분의 부호는 무엇인가요? x3 − 4x에서 a = −2, b = 2로 두면 위·아래 넓이와 정적분은 각각 얼마인가요? 그다음 a와 b를 바꾸어 놓으면 정적분은 어떻게 되나요?
  6. 판단"정적분 = 넓이"는 f(x) ≥ 0이고 a < b일 때만 맞습니다. 정적분이 0이어도 둘러싸인 도형의 넓이는 0이 아닐 수 있습니다. 위쪽 넓이와 아래쪽 넓이가 같아서 서로 지워졌을 뿐입니다.

표의 정적분은 모두 초록 곡선 y = k·f(x)의 값입니다. 회색 점선은 k = 1일 때의 f(x)입니다. 주황 점 c는 끌어서 옮길 수 있습니다.

  1. 질문[−1, 2]에서의 정적분을 [−1, 0.5]와 [0.5, 2] 두 조각으로 나누어 구한 뒤 더해도 될까요? 나누는 점 c가 구간 밖에 있으면 어떻게 될까요?
  2. 복원a < b일 때 ∫ab f(x)dx는 (x축 위쪽 넓이) − (아래쪽 넓이)이고, ∫ba f(x)dx = −∫ab f(x)dx, ∫aa f(x)dx = 0으로 약속했습니다.
  3. 설명연속함수 f, g와 실수 k에 대해 다음이 성립합니다. ① ∫ab kf(x)dx = k∫ab f(x)dx: 높이가 모두 k배가 되면 넓이도 k배이고, k < 0이면 위아래가 뒤집혀 부호가 바뀝니다. ② ∫ab {f(x) ± g(x)}dx = ∫ab f(x)dx ± ∫ab g(x)dx: 높이를 더하면 넓이도 더해집니다. ③ ∫ac f(x)dx + ∫cb f(x)dx = ∫ab f(x)dx: c가 a와 b 사이면 도형을 둘로 자른 것이고, 밖에 있어도 끝을 바꾸면 부호가 바뀐다는 약속 덕분에 그대로 성립합니다.
  4. 연결성질 ③은 그래프가 x축과 만나는 점에서 구간을 잘라 넓이를 구할 때, 또 구간마다 식이 다른 함수를 적분할 때 씁니다. 성질 ①, ②는 다항함수의 정적분을 항마다 나누어 계산하는 근거입니다.
  5. 적용c를 a와 b 사이에서 움직일 때 '두 값의 합'이 바뀌나요? c를 b보다 오른쪽으로 끌어 보세요. 노란 영역이 겹쳐 칠해지는데도 합이 ∫ab와 같은 까닭은 무엇인가요? k를 −1로 하면 그래프와 값이 어떻게 달라지나요?
  6. 판단곱에는 이런 성질이 없습니다. ∫ab f(x)g(x)dx는 대개 (∫ab f(x)dx)(∫ab g(x)dx)와 다릅니다. 예를 들어 f(x) = g(x) = x, [0, 1]에서 왼쪽은 1/3, 오른쪽은 1/4입니다.
