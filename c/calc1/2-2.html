미분가능성과 연속성

미분계수는 극한값이므로 언제나 있는 것은 아닙니다. 그래프가 뾰족하게 꺾이거나 끊어진 곳에서는 왼쪽에서 다가갈 때와 오른쪽에서 다가갈 때 평균변화율이 서로 다른 값으로 갑니다. 이 절에서는 미분가능하면 반드시 연속이라는 사실과, 연속이라고 해서 미분가능하지는 않다는 사실을 확인합니다. 그리고 두 식을 이어 붙인 함수가 매끄럽게 이어질 조건을 찾습니다.

2.2.1

왼쪽에서 본 기울기와 오른쪽에서 본 기울기가 다르면?

미분가능성 · 좌우 극한
왼쪽 (f(1 − h) − f(1))/(−h)
—
오른쪽 (f(1 + h) − f(1))/h
—
x = 1에서 연속인가
—

—

슬라이더를 오른쪽으로 밀면 h가 1, 0.1, 0.01, …로 줄어듭니다. 그림을 끌어도 L과 R이 함께 움직입니다.

  1. 질문y = |x − 1|의 그래프는 x = 1에서 V자로 꺾입니다. 이 점에서 접선의 기울기, 곧 미분계수를 하나로 정할 수 있을까요?
  2. 복원극한값 limx→a g(x)가 있으려면 좌극한과 우극한이 모두 있고 서로 같아야 합니다. 미분계수 f′(a)는 g(h) = (f(a + h) − f(a))/h의 h → 0일 때의 극한값입니다.
  3. 설명그래서 f′(a)가 있으려면 h → 0− (왼쪽 점 L에서 그은 할선)과 h → 0+ (오른쪽 점 R에서 그은 할선)의 극한이 모두 있고 같아야 합니다. |x − 1|에서는 왼쪽 값이 늘 −1, 오른쪽 값이 늘 1이라 극한이 서로 다릅니다. 따라서 x = 1에서 연속이지만 미분가능하지 않습니다. (x − 1)|x − 1|에서는 두 값이 모두 0에 다가가므로 미분가능하고 f′(1) = 0입니다. 그래프가 끊어진 세 번째 함수는 왼쪽 값이 한없이 커져 극한이 없습니다.
  4. 연결그래프로 보면 미분가능한 점은 매끄럽게 이어진 점이고, 미분가능하지 않은 점은 꺾인 점이나 끊어진 점입니다. 함수가 열린구간의 모든 점에서 미분가능하면 그 구간에서 미분가능한 함수라고 합니다. 다항함수는 모든 실수에서 미분가능합니다.
  5. 적용세 함수 각각에서 h를 0.0001까지 줄이며 왼쪽 값과 오른쪽 값이 어디로 가는지 보세요. 연속인데 미분가능하지 않은 함수, 연속이면서 미분가능한 함수, 연속도 아닌 함수는 각각 어느 것인가요?
  6. 판단'그래프가 이어져 있으면 미분가능하다'는 틀린 말입니다. |x − 1|처럼 이어져 있어도 꺾이면 미분가능하지 않습니다. 또 끊어진 함수에서 오른쪽 값만 보고 "f′(1) = 1"이라 하면 안 됩니다. 양쪽 극한이 모두 있고 같아야 합니다.

2.2.2

두 식을 이어 붙이면 언제 매끄럽게 이어질까?

미분가능성과 연속성 · 이어 붙인 함수

f(x) = x2 (x < 1),  ax + b (x ≥ 1)

lim x→1− f(x) / f(1)
—
왼쪽 미분계수
—
오른쪽 미분계수
—

—

왼쪽 미분계수는 limh→0− (f(1 + h) − f(1))/h입니다. f(1)은 오른쪽 식으로 정한 값 a + b입니다.

  1. 질문x < 1에서는 x2, x ≥ 1에서는 직선 ax + b인 함수가 있습니다. 끊기지도 꺾이지도 않게, 곧 x = 1에서 미분가능하게 하려면 a와 b를 어떻게 골라야 할까요?
  2. 복원f가 x = 1에서 연속이려면 limx→1 f(x) = f(1)이어야 합니다. 미분가능하려면 좌우의 (f(1 + h) − f(1))/h가 같은 극한값을 가져야 합니다.
  3. 설명f가 x = a에서 미분가능하면 x = a에서 연속입니다. h ≠ 0일 때 f(a + h) − f(a) = (f(a + h) − f(a))/h × h로 쓸 수 있습니다. h → 0이면 앞의 인수는 f′(a)로, 뒤의 인수는 0으로 가므로 f(a + h) − f(a) → f′(a) × 0 = 0, 곧 limh→0 f(a + h) = f(a)입니다. 이 정리의 대우는 "연속이 아니면 미분가능하지 않다"입니다. 그러나 역 "연속이면 미분가능하다"는 거짓입니다. |x|는 x = 0에서 연속이지만 미분가능하지 않습니다. 그래서 이 함수에서는 ① 연속 조건 1 = a + b와 ② 좌우 미분계수가 같다는 조건 2 = a를 함께 써야 합니다.
  4. 연결두 조건을 만족하는 직선 y = 2x − 1은 y = x2의 점 (1, 1)에서의 접선입니다. 이어 붙인 함수가 미분가능하다는 것은 오른쪽 식이 왼쪽 식과 같은 점, 같은 기울기로 이어진다는 뜻입니다.
  5. 적용먼저 a = 1로 둔 채 b만 움직여 연속이 되는 b를 찾으세요. 이때 좌우 미분계수는 같은가요? 이번에는 a + b = 1을 지키며 a를 바꾸어 미분가능하게 되는 a를 찾으세요. 연속이 아닐 때 왼쪽 미분계수가 어떻게 되는지도 보세요.
  6. 판단좌우 도함수의 값만 같게 맞추고 연속 조건을 빠뜨리는 실수가 흔합니다. a = 2, b = 0이면 왼쪽 식의 기울기 2x와 오른쪽 기울기 2가 x = 1에서 같아 보이지만, 그래프가 끊어져 있어 미분가능하지 않습니다. 이때 왼쪽 미분계수는 2가 아니라 발산합니다.
