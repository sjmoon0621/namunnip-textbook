미분가능성과 연속성

미분계수는 극한값이므로 언제나 있는 것은 아닙니다. 그래프가 뾰족하게 꺾이거나 끊어진 곳에서는 왼쪽에서 다가갈 때와 오른쪽에서 다가갈 때 평균변화율이 서로 다른 값으로 갑니다. 이 절에서는 미분가능하면 반드시 연속이라는 사실과, 연속이라고 해서 미분가능하지는 않다는 사실을 확인합니다. 그리고 두 식을 이어 붙인 함수가 매끄럽게 이어질 조건을 찾습니다.

2.2.1왼쪽 기울기와 오른쪽 기울기

미분계수 \(\displaystyle f'(a) = \lim_{h \to 0}\frac{f(a + h) - f(a)}{h}\)도 극한이므로, 좌극한과 우극한이 같아야 존재한다. \(f(x) = |x|\)에서 \(a = 0\)이면 \(\dfrac{|h|}{h}\)인데, \(h > 0\)이면 1, \(h < 0\)이면 \(-1\)이다. 두 값이 다르므로 극한이 없고, \(|x|\)는 \(x = 0\)에서 미분가능하지 않다.

그림 1의 슬라이더로 확대해 보자. 매끄러운 곡선은 확대할수록 한 직선처럼 보이지만, \(|x|\)는 몇 배를 확대해도 같은 V자가 그대로이다. 즉 미분가능하다는 것은 '충분히 확대하면 직선으로 보인다'는 뜻이고, 꺾인 점에서는 그 직선을 하나로 정할 수 없다.

2.2.2미분가능하면 연속이다

반대 방향은 언제나 성립한다. \(f\)가 \(x = a\)에서 미분가능하면 \(f(a + h) - f(a) = \dfrac{f(a + h) - f(a)}{h} \times h\)이고, \(h \to 0\)일 때 오른쪽은 \(f'(a) \times 0 = 0\)이다. 따라서 \(\displaystyle\lim_{h \to 0} f(a + h) = f(a)\)이므로 \(f\)는 \(x = a\)에서 연속이다.

정리 2.2.1 미분가능성과 연속성

함수 \(f(x)\)가 \(x = a\)에서 미분가능하면 \(x = a\)에서 연속이다. 그러나 그 역은 성립하지 않는다.

역의 반례가 바로 \(|x|\)이다. 원점에서 연속이지만 미분가능하지 않다. 그림 2처럼 연속이 아니면 미분가능할 수 없고, 연속이어도 꺾이거나 세로로 솟으면 미분가능하지 않다.1

2.2.3예제 하나를 끝까지

예제 2.2.2

함수 \(f(x) = \begin{cases} x^2 + a & (x < 1) \\ bx + 1 & (x \ge 1) \end{cases}\)이 \(x = 1\)에서 미분가능하도록 상수 \(a\), \(b\)를 정하여라.

미분가능하려면 먼저 연속이어야 한다. 좌극한 \(1 + a\)와 함숫값 \(b + 1\)이 같아야 하므로 \(a = b\)이다.

다음으로 왼쪽과 오른쪽의 기울기가 같아야 한다. 왼쪽 식 \(x^2 + a\)의 \(x = 1\)에서의 미분계수는 \(\displaystyle\lim_{h \to 0-}\frac{(1 + h)^2 - 1}{h} = 2\)이고, 오른쪽 직선의 기울기는 \(b\)이다. 따라서 \(b = 2\)이고, \(a = 2\)이다.

이때 \(f\)는 \(x < 1\)에서 포물선 \(x^2 + 2\), \(x \ge 1\)에서 직선 \(2x + 1\)이고, 직선은 점 \((1, 3)\)에서 포물선의 접선이 된다. 높이만 맞추면 연속이고, 기울기까지 맞추어야 매끄럽게 이어진다. 아래 탐구 카드에서 두 식을 이어 붙이며 높이와 기울기를 차례로 맞추어 보자.

  1. \(y = \sqrt[3]{x}\)는 원점에서 연속이지만, 접선이 세로선이 되어 기울기가 한없이 커지므로 미분가능하지 않다.
마무리

미분가능하려면 왼쪽과 오른쪽에서 잰 순간변화율이 같아야 하며, 미분가능한 함수는 반드시 연속이다. 그러나 연속이어도 꺾인 점에서는 기울기가 하나로 정해지지 않아 미분가능하지 않다. 그래서 처음 질문의 \(y = |x|\)는 원점에서 이어져 있지만 접선을 그을 수 없다.

—
오른쪽 \(\frac{f(1 + h) - f(1)}{h}\)

—

—

슬라이더를 오른쪽으로 밀면 \(h\)가 \(1, 0.1, 0.01, \cdots\)로 줄어든다. 그림을 끌어도 \(L\)과 \(R\)이 함께 움직인다.

  1. 질문\(y = |x - 1|\)의 그래프는 \(x = 1\)에서 \(V\)자로 꺾인다. 이 점에서 접선의 기울기, 곧 미분계수를 하나로 정할 수 있을까?
  2. 복원극한값 \(\lim_{x \to a} g(x)\)가 있으려면 좌극한과 우극한이 모두 있고 서로 같아야 한다. 그리고 미분계수 \(f'(a)\)는 \(g(h) = \frac{f(a + h) - f(a)}{h}\)의 \(h \to 0\)일 때의 극한값이다.
  3. 설명그래서 \(f'(a)\)가 있으려면 \(h \to 0^-\) (왼쪽 점 \(L\)에서 그은 할선)과 \(h \to 0^+\) (오른쪽 점 \(R\)에서 그은 할선)의 극한이 모두 있고 같아야 한다. \(|x - 1|\)에서는 왼쪽 값이 늘 \(-1\), 오른쪽 값이 늘 1이라 극한이 서로 다르다. 따라서 \(x = 1\)에서 연속이지만 미분가능하지 않다. 반면 \((x - 1)|x - 1|\)에서는 두 값이 모두 0에 다가가므로 미분가능하고 \(f'(1) = 0\)이다. 그래프가 끊어진 세 번째 함수는 왼쪽 값이 한없이 커져 극한이 없다.
  4. 연결그래프로 보면 미분가능한 점은 매끄럽게 이어진 점이고, 미분가능하지 않은 점은 꺾인 점이나 끊어진 점이다. 함수가 열린구간의 모든 점에서 미분가능하면 그 구간에서 미분가능한 함수라고 하며, 다항함수는 모든 실수에서 미분가능하다.
  5. 적용세 함수 각각에서 \(h\)를 0.0001까지 줄이며 왼쪽 값과 오른쪽 값이 어디로 가는지 보자. 그러면 연속인데 미분가능하지 않은 함수, 연속이면서 미분가능한 함수, 연속도 아닌 함수를 하나씩 가려낼 수 있다.
  6. 판단'그래프가 이어져 있으면 미분가능하다'는 틀린 말이다. \(|x - 1|\)처럼 이어져 있어도 꺾이면 미분가능하지 않다. 또 끊어진 함수에서 오른쪽 값만 보고 "\(f'(1) = 1\)"이라 하면 안 되고, 양쪽 극한이 모두 있고 같아야 한다.

\(\lim_{x \to 1^-} f(x) / f(1)\)
—
왼쪽 미분계수
—
오른쪽 미분계수
—

—

왼쪽 미분계수는 \(\lim_{h \to 0^-} \frac{f(1 + h) - f(1)}{h}\)이다. \(f(1)\)은 오른쪽 식으로 정한 값 \(a + b\)이다.

  1. 질문\(x < 1\)에서는 \(x^2\), \(x \ge 1\)에서는 직선 \(ax + b\)인 함수가 있다. 끊기지도 꺾이지도 않게, 곧 \(x = 1\)에서 미분가능하게 하려면 \(a\)와 \(b\)를 어떻게 골라야 할까?
  2. 복원\(f\)가 \(x = 1\)에서 연속이려면 \(\lim_{x \to 1} f(x) = f(1)\)이어야 한다. 그리고 미분가능하려면 좌우의 \(\frac{f(1 + h) - f(1)}{h}\)가 같은 극한값을 가져야 한다.
  3. 설명\(f\)가 \(x = a\)에서 미분가능하면 \(x = a\)에서 연속이다. \(h \ne 0\)일 때 \(f(a + h) - f(a) = \frac{f(a + h) - f(a)}{h} \times h\)로 쓸 수 있는데, \(h \to 0\)이면 앞의 인수는 \(f'(a)\)로, 뒤의 인수는 0으로 가므로 \(f(a + h) - f(a) \to f'(a) \times 0 = 0\), 곧 \(\lim_{h \to 0} f(a + h) = f(a)\)이다. 이 정리의 대우는 "연속이 아니면 미분가능하지 않다"이다. 그러나 역 "연속이면 미분가능하다"는 거짓이어서, \(|x|\)는 \(x = 0\)에서 연속이지만 미분가능하지 않다. 그래서 이 함수에서는 연속 조건 \(1 = a + b\)와 좌우 미분계수가 같다는 조건 \(2 = a\)를 함께 써야 한다.
  4. 연결두 조건을 만족하는 직선 \(y = 2x - 1\)은 \(y = x^2\)의 점 (1, 1)에서의 접선이다. 즉 이어 붙인 함수가 미분가능하다는 것은 오른쪽 식이 왼쪽 식과 같은 점, 같은 기울기로 이어진다는 뜻이다.
  5. 적용먼저 \(a = 1\)로 둔 채 \(b\)만 움직여 연속이 되는 \(b\)를 찾고, 이때 좌우 미분계수가 같은지 보자. 이번에는 \(a + b = 1\)을 지키며 \(a\)를 바꾸어 미분가능하게 되는 \(a\)를 찾고, 연속이 아닐 때 왼쪽 미분계수가 어떻게 되는지도 보자.
  6. 판단좌우 도함수의 값만 같게 맞추고 연속 조건을 빠뜨리는 실수가 흔하다. \(a = 2, b = 0\)이면 왼쪽 식의 기울기 \(2x\)와 오른쪽 기울기 2가 \(x = 1\)에서 같아 보이지만, 그래프가 끊어져 있어 미분가능하지 않다. 이때 왼쪽 미분계수는 2가 아니라 발산한다.
