방정식과 부등식

방정식과 부등식

본문

삼차방정식 \(x^3 - 3x - k = 0\)의 근은 \(k\)가 바뀔 때마다 새로 계산하기 어렵다. 그런데 \(k\)가 얼마일 때 실근이 세 개이고, 언제 하나뿐일까? 또 모든 양수 \(x\)에 대하여 \(x^3 + 2 \ge 3x\)가 성립한다는 것은 어떻게 보일까?

먼저 알아야 할 것그래프의 개형(그래프의 개형), 극대와 극소(증가·감소와 극대·극소), 최댓값과 최솟값.

2.9.1방정식의 실근과 그래프의 교점

방정식 \(f(x) = k\)의 실근은 \(y = f(x)\)의 그래프와 직선 \(y = k\)의 교점의 \(x\)좌표이다. 그래서 상수 \(k\)를 한쪽으로 옮겨 놓고 \(y = f(x)\)의 개형을 그리면, 가로선을 위아래로 움직이며 교점의 개수를 셀 수 있다.

\(f(x) = x^3 - 3x\)이면 \(f'(x) = 3(x + 1)(x - 1)\)이다. 그러면 \(x = -1\)에서 극댓값 \(f(-1) = 2\), \(x = 1\)에서 극솟값 \(f(1) = -2\)를 갖는다. 그림 1의 슬라이더로 \(k\)를 바꾸어 보자. \(-2 < k < 2\)이면 가로선이 봉우리와 골짜기 사이를 지나 세 번 만나고, \(k = \pm 2\)이면 극점에서 접해 두 번, \(|k| > 2\)이면 한 번 만난다.

방법 2.9.1 실근의 개수 세기

방정식을 \(f(x) = k\) 꼴로 정리하고 \(y = f(x)\)의 개형을 그린다. 가로선 \(y = k\)가 그래프와 만나는 점의 개수가 실근의 개수이며, 개수가 바뀌는 경계는 극댓값과 극솟값이다.

2.9.2부등식의 증명

'모든 \(x\)에 대하여 \(f(x) \ge g(x)\)'를 보이려면 \(h(x) = f(x) - g(x)\)로 두고 \(h(x) \ge 0\)을 보이면 된다. 다시 말해 \(h\)의 최솟값이 0 이상임을 보이는 문제로 바뀐다. 최솟값은 도함수로 증감표를 그려 구한다.1

2.9.3예제 하나를 끝까지

예제 2.9.2

\(x \ge 0\)일 때 부등식 \(x^3 + 2 \ge 3x\)가 성립함을 보여라. 또 방정식 \(2x^3 - 3x^2 - 12x - k = 0\)이 서로 다른 세 실근을 갖도록 하는 정수 \(k\)의 개수를 구하여라.

\(h(x) = x^3 - 3x + 2\)라 하면 \(h'(x) = 3x^2 - 3 = 3(x + 1)(x - 1)\)이다. \(x \ge 0\)에서 \(h'\)는 \(0 \le x < 1\)에서 음수, \(x > 1\)에서 양수이므로 \(h\)는 \(x = 1\)에서 최솟값 \(h(1) = 0\)을 갖는다. 따라서 \(x \ge 0\)이면 \(h(x) \ge 0\), 곧 \(x^3 + 2 \ge 3x\)이다. 등호는 \(x = 1\)일 때 성립한다.

두 번째 방정식은 \(2x^3 - 3x^2 - 12x = k\)로 쓴다. \(f(x) = 2x^3 - 3x^2 - 12x\)는 \(f'(x) = 6(x + 1)(x - 2)\)이므로 \(x = -1\)에서 극댓값 \(f(-1) = 7\), \(x = 2\)에서 극솟값 \(f(2) = -20\)을 갖는다.

서로 다른 세 실근이려면 가로선 \(y = k\)가 극댓값과 극솟값 사이를 지나야 하므로 \(-20 < k < 7\)이다. 이 범위의 정수는 \(-19\)부터 6까지 26개이다. 근을 하나도 구하지 않고 그래프의 봉우리와 골짜기 높이만으로 답했다. 아래 탐구 카드에서 가로선을 움직이며 근의 개수가 바뀌는 순간을 직접 확인해 보자.

  1. 범위가 닫힌구간이 아니어도, 증감표로 \(h\)가 한 점에서 가장 작아진다는 것을 보이면 그 값이 최솟값이다. 위 예제에서는 \(x = 1\)의 왼쪽에서 감소, 오른쪽에서 증가하므로 \(x \ge 0\) 전체에서 \(h(1)\)이 가장 작다.
마무리

방정식 \(f(x) = k\)의 실근의 개수는 \(y = f(x)\)의 개형과 가로선 \(y = k\)의 교점의 개수로 세며, 개수가 바뀌는 경계는 극댓값과 극솟값이다. 부등식은 두 식의 차의 최솟값이 0 이상임을 보여 증명한다. 그래서 처음 질문의 \(x^3 - 3x - k = 0\)은 \(-2 < k < 2\)일 때 실근이 셋, \(|k| > 2\)일 때 하나이다.

근을 구하지 않고 근의 개수를 셀 수 있을까?

방정식 · 그래프의 교점
서로 다른 실근의 개수
—
실근 (근삿값)
—
극값
—

그림 위를 위아래로 끌어도 수평선이 움직인다. 극값과 같은 높이에서 멈춰 보자.

  1. 질문방정식 \(x^3 - 3x - k = 0\)의 서로 다른 실근은 \(k\)에 따라 몇 개일까?
  2. 복원방정식 \(f(x) = g(x)\)의 실근은 두 그래프 \(y = f(x)\)와 \(y = g(x)\)의 교점의 \(x\)좌표이다. 그리고 \(x^3 - 3x\)는 \(x = -1\)에서 극댓값 2, \(x = 1\)에서 극솟값 \(-2\)를 가진다.
  3. 설명상수 \(k\)를 따로 떼어 \(f(x) = k\) 꼴로 바꾸면, 실근의 개수는 곡선 \(y = f(x)\)와 수평선 \(y = k\)의 교점의 개수이다. 수평선을 위아래로 움직이면 교점의 개수는 극값의 높이를 지날 때만 바뀐다. 그래서 \(x^3 - 3x = k\)는 \(-2 < k < 2\)이면 세 개, \(k = \pm 2\)이면 두 개(하나는 중근), \(|k| > 2\)이면 한 개의 실근을 가진다. 삼차방정식 \(f(x) = 0\)이 서로 다른 세 실근을 가질 조건을 "극댓값 × 극솟값 < 0"으로 쓰기도 한다.
  4. 연결이 방법은 공식이 없는 고차방정식에도 쓸 수 있다. 근의 정확한 값이 필요하면, 교점이 있는 구간을 좁혀 가는 사잇값 정리의 방법으로 근삿값을 구한다.
  5. 적용수평선을 끌어 교점이 1개, 2개, 3개가 되는 \(k\)의 범위를 각각 찾아보자. 사차함수 \(x^4 - 2x^2\)로 바꾸면 교점의 개수가 0, 2, 3, 4개로 바뀌는 경계가 어디인지도 확인해 보자.
  6. 판단교점의 개수를 셀 때는 극값과 같은 높이를 따로 봐야 한다. 그 높이에서는 수평선이 곡선에 접하므로 두 근이 하나로 겹친 중근이 되기 때문이다. 또 \(k\)를 떼어 내지 않고 \(y = x^3 - 3x - k\)를 그리면 \(k\)마다 곡선이 달라져 비교가 어렵다. 그래서 움직이는 부분을 직선 하나로 모아 두는 편이 낫다.

탐구 2

모든 \(x\)에서 성립한다는 것을 어떻게 보일까?

부등식 · 최솟값

—

최솟값 \(f(1) = a - 2\)
—
음수가 되는 \(x\)
—
\(x \ge 0\)에서 \(f(x) \ge 0\)
—

그래프는 \(x \ge 0\) 부분만 진하게 그렸다. 붉은 부분이 부등식을 깨뜨리는 곳이다.

  1. 질문\(x \ge 0\)인 모든 \(x\)에서 \(x^3 + a \ge 3x\)가 성립하려면 상수 \(a\)는 얼마 이상이어야 할까? \(x\)에 값을 몇 개 넣어 보는 것으로는 "모든 \(x\)"를 보일 수 없다.
  2. 복원닫힌 구간이나 반직선에서 함수의 최솟값은 극솟값과 끝값 가운데 가장 작은 값이다.
  3. 설명한쪽으로 모아 \(f(x) = x^3 - 3x + a \ge 0\)을 보이면 된다. 그런데 범위 전체에서 \(f(x) \ge 0\)인 것은 그 범위에서 \(f\)의 최솟값이 0 이상인 것과 같다. \(f'(x) = 3(x + 1)(x - 1)\)이므로 \(x \ge 0\)에서 \(f\)는 \(x = 1\)까지 감소하고 그 뒤로 증가한다. 그래서 최솟값은 \(f(1) = a - 2\)이고, 끝값 \(f(0) = a\)는 이보다 크다. 따라서 조건은 \(a - 2 \ge 0\), 곧 \(a \ge 2\)이다.
  4. 연결두 함수의 크기 비교 \(f(x) \ge g(x)\)도 차 \(h = f - g\)의 최솟값으로 바꾸어 같은 방법을 쓴다. \(a = 2\)일 때 \(x^3 + 2 \ge 3x\)이고, 등호는 \(x = 1\)에서만 성립한다.
  5. 적용\(a\)를 줄여 가며 그래프가 \(x\)축 아래로 처음 내려가는 순간을 찾고, 그 순간 최솟값 수치가 얼마인지 보자. \(a = 1.5\)일 때 음수가 되는 \(x\)의 범위도 읽어 보자.
  6. 판단범위를 빼먹으면 답이 달라진다. 실수 전체에서는 \(x^3 - 3x + a\)가 \(x \to -\infty\)에서 한없이 작아지므로 어떤 \(a\)로도 늘 0 이상이 될 수 없다. 또 극솟값만 보지 말고 끝값도 후보에 넣어야 한다.
