부정적분

본문

어떤 함수를 미분했더니 \(2x\)가 나왔다. 원래 함수는 \(x^2\)일 것 같다. 그런데 \(x^2 + 5\)나 \(x^2 - 3\)을 미분해도 \(2x\)이다. 그렇다면 원래 함수는 몇 개이고, 하나로 정하려면 무엇이 더 필요할까?

먼저 알아야 할 것도함수와 \(y = x^n\)의 도함수(y = xⁿ의 도함수), 평균값 정리(평균값 정리), 접선의 기울기.

3.1.1미분을 거꾸로

미분은 함수에서 기울기의 함수를 얻는 일이다. 그 반대로 기울기의 함수에서 원래 함수를 찾는 일을 생각하자. 함수 \(F(x)\)의 도함수가 \(f(x)\)일 때, 곧 \(F'(x) = f(x)\)일 때 \(F(x)\)를 \(f(x)\)의 부정적분이라 한다.

\(F(x) = x^2\)이 \(2x\)의 부정적분이면 \(x^2 + C\)(\(C\)는 상수)도 모두 부정적분이다. 상수는 미분하면 0이 되어 사라지기 때문이다. 그림 1에서 보듯 이 함수들의 그래프는 같은 모양의 포물선을 위아래로 옮긴 것이어서, 같은 \(x\)에서 접선의 기울기가 모두 같다.

3.1.2부정적분은 상수만큼만 다르다

거꾸로, 도함수가 같은 두 함수는 상수만큼만 다를까? \(F' = G'\)이면 \(H = F - G\)의 도함수는 0이다. 평균값 정리에 따라 어느 두 점 사이에서도 \(H(b) - H(a) = H'(c)(b - a) = 0\)이므로 \(H\)는 상수이다. 즉 \(f\)의 부정적분은 하나를 찾으면 나머지는 모두 그것에 상수를 더한 것이다.

정의 3.1.1 부정적분과 적분상수

\(F'(x) = f(x)\)일 때 \(f(x)\)의 부정적분은 \[\int f(x)\,dx = F(x) + C\ (C\text{는 상수})\] 이고, \(C\)를 적분상수라 한다. \(f(x)\)의 부정적분을 구하는 것을 \(f(x)\)를 적분한다고 한다.

적분상수를 하나로 정하려면 조건이 하나 더 있어야 한다. 그림 1의 슬라이더로 그래프가 지나는 점을 정하면, 포물선 가족 가운데 그 점을 지나는 것은 하나뿐이다.1

3.1.3예제 하나를 끝까지

예제 3.1.2

곡선 \(y = F(x)\) 위의 점 \((x, F(x))\)에서의 접선의 기울기가 \(2x\)이고, 이 곡선이 점 \((1, 3)\)을 지날 때 \(F(x)\)를 구하여라. 또 \(\displaystyle\frac{d}{dx}\int f(x)\,dx\)와 \(\displaystyle\int \left\{\frac{d}{dx}f(x)\right\}dx\)가 어떻게 다른지 \(f(x) = x^2 + 1\)로 확인하여라.

접선의 기울기가 \(F'(x) = 2x\)이므로 \(F(x) = x^2 + C\)이다. 점 \((1, 3)\)을 지나므로 \(1 + C = 3\), 곧 \(C = 2\)이다. 따라서 \(F(x) = x^2 + 2\)이다. 그림 1의 처음 모습이 이 곡선이다.

\(f(x) = x^2 + 1\)을 먼저 적분하면 \(\dfrac{x^3}{3} + x + C\)이고, 이것을 미분하면 다시 \(x^2 + 1\)이 된다. 반면 먼저 미분하면 \(2x\)이고, 이것을 적분하면 \(x^2 + C\)가 된다. 원래의 \(+1\)은 사라지고 \(C\)가 대신 붙는다.

즉 적분한 뒤 미분하면 제자리로 돌아오지만, 미분한 뒤 적분하면 상수만큼 차이가 남는다. 미분이 상수의 정보를 지우기 때문이다. 아래 탐구 카드에서 기울기만으로 그래프를 그려 보고, 한 점의 조건이 그래프를 정하는 모습을 확인해 보자.

  1. 기울기의 함수만 주어지면 그래프의 '모양'은 정해지지만 '높이'는 정해지지 않는다. 가령 물체의 속도만 알면 움직인 모양은 알 수 있어도, 처음 위치를 알아야 지금 위치가 정해진다.
마무리

부정적분은 미분하면 \(f(x)\)가 되는 함수이고, 도함수가 같은 함수들은 상수만큼만 다르므로 \(\int f(x)\,dx = F(x) + C\)로 쓴다. 적분상수 \(C\)는 지나는 점 같은 조건 하나로 정해진다. 그래서 처음 질문의 원래 함수는 \(x^2 + C\) 꼴로 무수히 많고, 한 점을 지난다는 조건이 있어야 하나로 정해진다.

초록 점을 끌면 곡선이 위아래로, 접점이 좌우로 움직인다. 회색 곡선은 \(C\)만 다른 다른 부정적분들이다.

  1. 질문미분해서 \(2x\)가 되는 함수를 하나 찾으면 \(x^2\)이다. 그런데 미분해서 \(2x\)가 되는 함수가 이것 하나뿐일까?
  2. 복원\((x^2)' = 2x\)이고, 상수함수의 도함수는 0이다. 미분계수 \(f'(a)\)는 \(x = a\)에서 그은 접선의 기울기이다. 또 평균값 정리에서, 어떤 구간에서 도함수가 늘 0인 함수는 그 구간에서 상수함수였다.
  3. 설명함수 \(F(x)\)의 도함수가 \(f(x)\)일 때, 곧 \(F'(x) = f(x)\)일 때 \(F(x)\)를 \(f(x)\)의 부정적분이라 한다. 그런데 부정적분은 하나가 아니다. \(G(x)\)도 \(f(x)\)의 부정적분이면 \((G - F)' = f - f = 0\)이므로 \(G(x) - F(x)\)는 상수이다. 그래서 부정적분 전체를 \(\int f(x)\,dx = F(x) + C\)로 쓴다. 이때 \(C\)를 적분상수, \(f(x)\)를 피적분함수라 하고, 부정적분을 구하는 것을 '\(f(x)\)를 \(x\)에 대하여 적분한다'고 한다. 부정적분과 미분은 서로 거꾸로 가는 계산이므로 \((\frac{d}{dx})\int f(x)\,dx = f(x)\)이고, \(\int\{(\frac{d}{dx})f(x)\}\,dx = f(x) + C\)이다.
  4. 연결그림에서 \(C\)를 바꾸면 곡선이 위아래로만 평행이동한다. 평행이동해도 같은 \(x\)에서 접선 기울기는 그대로이므로 도함수가 같다. 속도를 알고 위치를 구할 때도 같은 일이 생긴다. 속도만으로는 출발 위치를 알 수 없고, 출발 위치가 \(C\) 역할을 한다.
  5. 적용\(C\)를 바꾸어도 '초록 곡선의 접선 기울기'가 변하지 않는지 확인하고, \(x\)를 움직여 그 값이 언제나 \(f(x)\)와 같은지도 보자. \(f(x) = 3x^2 - 3\)에서는 접선이 모두 가로로 눕는 \(x\)를 찾아 그곳에서 \(f(x)\)가 얼마인지 확인해 보자.
  6. 판단"\(\int 2x\,dx = x^2\)"처럼 적분상수를 빼고 쓰면 부정적분 가운데 하나만 적은 것이다. 부정적분은 하나의 함수가 아니라 함수의 모임을 나타내므로 \(+ C\)를 꼭 붙인다. 또 미분한 뒤 적분하면 원래 함수로 돌아오지 않고 상수만큼의 차이가 남는데, 미분하면서 상수항의 정보가 사라지기 때문이다.

짧은 선분은 그 자리에서 곡선이 가져야 할 기울기 \(F'(x)\)이다. 주황 점을 끌어 옮겨 보자.

  1. 질문\(F'(x) = 2x\)를 만족하는 함수는 \(x^2 + C\) 꼴로 끝없이 많다. 그 가운데 점 (1, 3)을 지나는 것은 몇 개일까?
  2. 복원\(F'(x) = f(x)\)인 \(F(x)\)가 \(f(x)\)의 부정적분이고, 모든 부정적분은 \(\int f(x)\,dx = F(x) + C\)처럼 상수만큼씩 다르다.
  3. 설명각 점 \((x, y)\)에 기울기 \(f(x)\)인 짧은 선분을 그리면 기울기장이 되고, 부정적분의 그래프는 이 선분들을 따라 흐르는 곡선이다. 기울기가 \(x\)에만 달려 있으므로 같은 세로줄의 선분은 모두 평행하고, 곡선 하나를 위아래로 옮기면 다른 곡선이 된다. 그런데 한 점 \((x_0, y_0)\)을 지나야 한다는 조건을 주면 \(F(x_0) + C = y_0\)에서 \(C = y_0 - F(x_0)\)로 하나가 정해진다. 예를 들어 \(F'(x) = 2x, F(1) = 3\)이면 \(1 + C = 3\)에서 \(C = 2\), 곧 \(F(x) = x^2 + 2\)이다.
  4. 연결물체의 속도를 알면 위치 함수를 부정적분으로 구할 수 있고, 처음 위치 하나가 적분상수를 정한다. 또 기울기장은 나중에 미분방정식을 풀 때 그림으로 답의 모양을 미리 보는 도구로도 쓰인다.
  5. 적용점을 같은 세로줄에서 위아래로만 옮기면 곡선의 모양은 그대로이고 위치만 바뀐다. \(F'(x) = x^2 - 1\)에서는 점 (0, 0)을 지나는 곡선의 \(C\)를 구하고, 곡선 위의 어느 점에서 선분이 가로로 눕는지도 찾아보자.
  6. 판단조건을 쓸 때 \(F'(x_0)\)에 값을 넣는 실수가 흔하다. '점 (1, 3)을 지난다'는 \(F(1) = 3\)이라는 함숫값 조건이고, \(F'(1)\)은 그 점에서의 기울기이다. 기울기 조건으로는 \(C\)가 정해지지 않는데, 모든 부정적분이 같은 \(x\)에서 같은 기울기를 가지기 때문이다.
