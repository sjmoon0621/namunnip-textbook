3.1.1

도함수가 같은 함수는 몇 개일까?

부정적분 · 적분상수
초록 곡선 F(x) + C
—
초록 곡선의 접선 기울기
—
f(x)의 값
—

초록 점을 끌면 곡선이 위아래로, 접점이 좌우로 움직입니다. 회색 곡선은 C만 다른 다른 부정적분들입니다.

  1. 질문미분해서 2x가 되는 함수를 하나 찾으면 x2입니다. 그런데 미분해서 2x가 되는 함수가 이것 하나뿐일까요?
  2. 복원(x2)′ = 2x이고, 상수함수의 도함수는 0입니다. 미분계수 f′(a)는 x = a에서 그은 접선의 기울기입니다. 또 평균값 정리에서, 어떤 구간에서 도함수가 늘 0인 함수는 그 구간에서 상수함수입니다.
  3. 설명함수 F(x)의 도함수가 f(x)일 때, 곧 F′(x) = f(x)일 때 F(x)를 f(x)의 부정적분이라 합니다. 부정적분은 하나가 아닙니다. G(x)도 f(x)의 부정적분이면 (G − F)′ = f − f = 0이므로 G(x) − F(x)는 상수입니다. 그래서 부정적분 전체를 ∫f(x)dx = F(x) + C로 씁니다. C를 적분상수, f(x)를 피적분함수라 하고, 부정적분을 구하는 것을 'f(x)를 x에 대하여 적분한다'고 합니다. 부정적분과 미분은 서로 거꾸로 가는 계산이므로 (d/dx)∫f(x)dx = f(x)이고, ∫{(d/dx)f(x)}dx = f(x) + C입니다.
  4. 연결그림에서 C를 바꾸면 곡선이 위아래로만 평행이동합니다. 평행이동해도 같은 x에서 접선 기울기는 그대로이므로 도함수가 같습니다. 속도를 알고 위치를 구할 때도 같은 일이 생깁니다. 속도만으로는 출발 위치를 알 수 없고, 출발 위치가 C 역할을 합니다.
  5. 적용C를 바꾸어도 '초록 곡선의 접선 기울기'가 변하지 않는지 확인하세요. 그 값이 언제나 f(x)와 같은지도 x를 움직여 보세요. f(x) = 3x2 − 3에서 접선이 모두 가로로 눕는 x는 어디이고, 그곳에서 f(x)는 얼마인가요?
  6. 판단"∫2x dx = x2"처럼 적분상수를 빼고 쓰면 부정적분 가운데 하나만 적은 것입니다. 하나의 함수가 아니라 함수의 모임을 나타낸다는 뜻에서 + C를 꼭 붙입니다. 또 미분한 뒤 적분하면 원래 함수로 돌아오지 않고 상수만큼의 차이가 남습니다. 미분하면서 상수항의 정보가 사라지기 때문입니다.

3.1.2

한 점을 지나라는 조건이 있으면 적분상수가 정해질까?

부정적분 · 기울기장
조건
—
정해진 C
—
구한 함수 F(x)
—

짧은 선분은 그 자리에서 곡선이 가져야 할 기울기 F′(x)입니다. 주황 점을 끌어 옮겨 보세요.

  1. 질문F′(x) = 2x를 만족하는 함수는 x2 + C 꼴로 끝없이 많습니다. 그 가운데 점 (1, 3)을 지나는 것은 몇 개일까요?
  2. 복원F′(x) = f(x)인 F(x)가 f(x)의 부정적분이고, 모든 부정적분은 ∫f(x)dx = F(x) + C처럼 상수만큼씩 다릅니다.
  3. 설명각 점 (x, y)에 기울기 f(x)인 짧은 선분을 그리면 기울기장이 됩니다. 부정적분의 그래프는 이 선분들을 따라 흐르는 곡선입니다. 기울기가 x에만 달려 있으므로 같은 세로줄의 선분은 모두 평행하고, 곡선 하나를 위아래로 옮기면 다른 곡선이 됩니다. 한 점 (x0, y0)을 지나야 한다는 조건을 주면 F(x0) + C = y0에서 C = y0 − F(x0)로 하나가 정해집니다. 예를 들어 F′(x) = 2x, F(1) = 3이면 1 + C = 3에서 C = 2, 곧 F(x) = x2 + 2입니다.
  4. 연결물체의 속도를 알면 위치 함수를 부정적분으로 구할 수 있고, 처음 위치 하나가 적분상수를 정합니다. 기울기장은 나중에 미분방정식을 풀 때 그림으로 답의 모양을 미리 보는 도구로도 쓰입니다.
  5. 적용점을 같은 세로줄에서 위아래로만 옮기면 곡선의 모양이 바뀌나요, 위치만 바뀌나요? F′(x) = x2 − 1에서 점 (0, 0)을 지나는 곡선의 C는 얼마이고, 곡선 위의 어느 점에서 선분이 가로로 눕나요?
  6. 판단조건을 쓸 때 F′(x0)에 값을 넣는 실수가 흔합니다. '점 (1, 3)을 지난다'는 F(1) = 3이라는 함수값 조건이고, F′(1)은 그 점에서의 기울기입니다. 기울기 조건으로는 C가 정해지지 않습니다. 모든 부정적분이 같은 x에서 같은 기울기를 가지기 때문입니다.
