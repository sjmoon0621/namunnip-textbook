다항함수의 부정적분

부정적분을 미분의 거꾸로 보면, 미분 공식을 뒤집어 적분 공식을 얻을 수 있습니다. 거듭제곱 하나의 적분에서 시작해, 항을 나누어 적분하는 성질로 모든 다항함수의 부정적분을 구합니다.

  1. 질문미분하면 x2이 되는 함수를 찾고 싶습니다. 지수를 하나 올린 x3을 미분하면 3x2이라 3배가 남습니다. 이 3을 어떻게 없앨까요?
  2. 복원n이 자연수일 때 (xn)′ = nxn−1이고, 상수 k에 대해 {kf(x)}′ = kf′(x)입니다. 부정적분은 미분하면 피적분함수가 되는 함수입니다.
  3. 설명미분은 지수를 하나 내리면서 원래 지수를 앞에 곱합니다. 거꾸로 가려면 지수를 하나 올리고, 올린 지수로 나눕니다. 실제로 {xn+1/(n + 1)}′ = (n + 1)xn/(n + 1) = xn이므로 ∫xndx = xn+1/(n + 1) + C (n = 0, 1, 2, …)입니다. n = 0이면 ∫1 dx = x + C, 상수 k이면 ∫k dx = kx + C입니다.
  4. 연결이 공식과 다음에 볼 실수배·합·차의 성질을 합치면 모든 다항함수의 부정적분을 구할 수 있습니다. 미분 공식을 거꾸로 읽어 적분 공식을 얻는 방법은 미적분Ⅱ에서 삼각함수, 지수함수의 적분으로 이어집니다.
  5. 적용후보 ①을 고르고 n을 0부터 4까지 바꾸어 보세요. 'F′(x) ÷ f(x)'가 언제나 얼마인가요? 그 값과 n 사이의 관계를 찾은 다음 후보 ②로 바꾸어, 주황 점선이 파란 곡선과 겹치는지 확인하세요.
  6. 판단지수를 올리지 않고 내리거나(미분과 헷갈림), 지수는 올렸는데 나누지 않는 실수가 많습니다. 구한 결과를 미분해서 피적분함수로 돌아오는지 확인하면 바로 잡을 수 있습니다. 또 이 공식은 n = −1이면 0으로 나누게 되어 쓸 수 없습니다. 1/x의 적분은 미적분Ⅱ에서 따로 다룹니다.

  1. 질문x3 − 3x2 + 2를 적분하려면, 미분해서 이 식이 되는 함수를 통째로 찾아야 할까요? 아니면 항마다 따로 적분해서 더해도 될까요?
  2. 복원미분에서는 {kf(x)}′ = kf′(x), {f(x) ± g(x)}′ = f′(x) ± g′(x)입니다. 또 ∫xndx = xn+1/(n + 1) + C입니다.
  3. 설명F′ = f, G′ = g이면 미분의 성질에서 (kF)′ = kf, (F ± G)′ = f ± g입니다. 그래서 두 함수 f(x), g(x)와 상수 k에 대해 ∫kf(x)dx = k∫f(x)dx (k ≠ 0), ∫{f(x) ± g(x)}dx = ∫f(x)dx ± ∫g(x)dx입니다. 다항함수는 거듭제곱의 실수배를 더하고 뺀 것이므로, 항마다 적분해 더하고 적분상수는 마지막에 C 하나로 모읍니다. 예: ∫(x3 − 3x2 + 2)dx = ¼x4 − x3 + 2x + C.
  4. 연결곱으로 된 식은 먼저 전개해 합의 꼴로 바꾼 뒤 적분합니다. 이 성질은 정적분에서도 그대로 성립하여, 정적분을 항마다 나누어 계산하는 근거가 됩니다.
  5. 적용'다음 항'을 누를 때마다 주황 점선(F′)이 어떻게 파란 곡선(f)에 다가가나요? 끝까지 적분한 뒤 계수를 바꾸어 다른 식도 해 보세요. 상수항만 0이 아닌 식을 적분하면 F(x)는 어떤 그래프인가요?
  6. 판단합과 차는 항마다 나눌 수 있지만 곱은 나눌 수 없습니다. ∫x · x dx는 ∫x dx · ∫x dx = ¼x4이 아니라 ∫x2dx = ⅓x3 + C입니다. 또 실수배 성질에서 k = 0이면 왼쪽은 ∫0 dx = C, 오른쪽은 0이 되어 같지 않으므로 k ≠ 0이라는 조건을 붙입니다.
