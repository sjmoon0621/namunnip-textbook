다항함수의 부정적분

본문

\(x^3\)을 미분하면 \(3x^2\)이다. 그러면 \(x^2\)을 적분한 결과는 \(x^3\)일까? 미분하면 3이 앞에 나오니, 적분할 때는 그 3을 어떻게 처리해야 할까? 그리고 \(6x^2 - 4x + 5\)처럼 여러 항이 있으면 항마다 따로 적분해도 될까?

먼저 알아야 할 것부정적분과 적분상수(부정적분), \(y = x^n\)의 도함수(y = xⁿ의 도함수), 합·차·상수배의 미분법(다항함수의 도함수).

3.2.1\(x^n\)의 부정적분

\(x^2\)의 부정적분을 찾으려면 '미분하면 \(x^2\)이 되는 함수'를 찾아야 한다. 지수가 하나 줄어드는 것이 미분이므로, 원래 함수는 \(x^3\)의 꼴일 것이다. 그런데 \((x^3)' = 3x^2\)이라 3이 남는다. 그래서 미리 3으로 나눈 \(\dfrac{x^3}{3}\)을 미분하면 정확히 \(x^2\)이다.

같은 생각으로 \(\left(\dfrac{x^{n+1}}{n + 1}\right)' = \dfrac{(n + 1)x^n}{n + 1} = x^n\)이다. 그림 1에서 \(n\)을 바꾸어 보면, 미분으로 내려오는 수 \(n + 1\)을 적분에서 미리 나누어 둔다는 것이 보인다.

정리 3.2.1 \(x^n\)의 부정적분

\(n\)이 0 또는 자연수일 때 \[\int x^n\,dx = \frac{x^{n+1}}{n + 1} + C\] 특히 \(\int 1\,dx = x + C\), \(\int k\,dx = kx + C\)(\(k\)는 상수)이다.

3.2.2합, 차, 상수배는 항마다

미분에서 합, 차, 상수배는 항마다 따로 계산할 수 있었다. 적분은 미분의 반대이므로 같은 성질이 그대로 성립한다. \(F' = f\), \(G' = g\)이면 \((F + G)' = f + g\)이므로 \(f + g\)의 부정적분은 \(F + G\)에 상수를 더한 것이다.

정리 3.2.2 부정적분의 성질

\[\int kf(x)\,dx = k\int f(x)\,dx\ (k \ne 0),\quad \int \{f(x) \pm g(x)\}\,dx = \int f(x)\,dx \pm \int g(x)\,dx\]

그러나 곱은 그렇지 않다. \(\int x \cdot x\,dx = \dfrac{x^3}{3} + C\)인데, 따로 적분한 \(\dfrac{x^2}{2} \times \dfrac{x^2}{2}\)는 \(\dfrac{x^4}{4}\)로 다르다. 곱으로 된 식은 먼저 전개해서 항의 합으로 바꾼 뒤 적분한다.1

3.2.3예제 하나를 끝까지

예제 3.2.3

\(\displaystyle\int (6x^2 - 4x + 5)\,dx\)와 \(\displaystyle\int (x + 1)(3x - 1)\,dx\)를 구하여라. 또 \(f'(x) = 6x^2 - 4x + 5\)이고 \(f(0) = 1\)일 때 \(f(2)\)를 구하여라.

항마다 적분하면 \(\displaystyle\int (6x^2 - 4x + 5)\,dx = 2x^3 - 2x^2 + 5x + C\)이다. 미분하면 \(6x^2 - 4x + 5\)가 나오므로 맞는다.

두 번째 식은 먼저 전개한다. \((x + 1)(3x - 1) = 3x^2 + 2x - 1\)이므로 적분하면 \(x^3 + x^2 - x + C\)이다.

마지막 질문은 \(f(x) = 2x^3 - 2x^2 + 5x + C\)에서 \(f(0) = C = 1\)이므로 \(f(x) = 2x^3 - 2x^2 + 5x + 1\)이다. 따라서 \(f(2) = 16 - 8 + 10 + 1 = 19\)이다. 아래 탐구 카드에서 지수를 올리고 나누는 규칙을 직접 따라가 보자.

  1. \(n = -1\)일 때, 곧 \(\int \tfrac{1}{x}\,dx\)는 이 공식으로 구할 수 없다(분모가 0이 된다). 이 적분은 미적분Ⅱ에서 자연로그로 다룬다.
마무리

\(x^n\)을 미분하면 지수 \(n\)이 앞으로 내려오므로, 적분할 때는 지수를 하나 올리고 그 수로 나누어 \(\int x^n\,dx = \tfrac{x^{n+1}}{n + 1} + C\)이다. 다항식은 항마다 적분해 더하고, 곱은 전개한 뒤 적분한다. 그래서 처음 질문의 \(x^2\)의 부정적분은 \(x^3\)이 아니라 \(\tfrac{x^3}{3} + C\)이다.

\(f(x) = x^n\) 후보 \(F(x)\) \(F'(x)\)

  1. 질문미분하면 \(x^2\)이 되는 함수를 찾고 싶다. 지수를 하나 올린 \(x^3\)을 미분하면 \(3x^2\)이라 3배가 남는다. 이 3을 어떻게 없앨까?
  2. 복원\(n\)이 자연수일 때 \((x^n)' = nx^{n-1}\)이고, 상수 \(k\)에 대해 \(\{kf(x)\}' = kf'(x)\)이다. 그리고 부정적분은 미분하면 피적분함수가 되는 함수이다.
  3. 설명미분은 지수를 하나 내리면서 원래 지수를 앞에 곱한다. 그래서 거꾸로 가려면 지수를 하나 올리고, 올린 지수로 나누면 된다. 실제로 \(\{\frac{x^{n+1}}{n + 1}\}' = \frac{(n + 1)x^n}{n + 1} = x^n\)이므로 \(\int x^n\,dx = \frac{x^{n+1}}{n + 1} + C\) \((n = 0, 1, 2, \cdots)\)이다. \(n = 0\)이면 \(\int 1\,dx = x + C\)이고, 상수 \(k\)이면 \(\int k\,dx = kx + C\)이다.
  4. 연결이 공식과 다음에 볼 실수배, 합, 차의 성질을 합치면 모든 다항함수의 부정적분을 구할 수 있다. 미분 공식을 거꾸로 읽어 적분 공식을 얻는 방법은 미적분Ⅱ에서 삼각함수, 지수함수의 적분으로 이어진다.
  5. 적용첫째 후보를 고르고 \(n\)을 0부터 4까지 바꾸며 '\(F'(x) \div f(x)\)'가 언제나 얼마인지, 그 값과 \(n\) 사이에 어떤 관계가 있는지 찾아보자. 그다음 둘째 후보로 바꾸어 주황 점선이 파란 곡선과 겹치는지 확인해 보자.
  6. 판단지수를 올리지 않고 내리거나(미분과 헷갈림), 지수는 올렸는데 나누지 않는 실수가 많다. 구한 결과를 미분해서 피적분함수로 돌아오는지 확인하면 바로잡을 수 있다. 또 이 공식은 \(n = -1\)이면 0으로 나누게 되어 쓸 수 없고, \(\frac{1}{x}\)의 적분은 미적분Ⅱ에서 따로 다룬다.

—
적분한 항

\(F'(x) = f(x)\)?
—

\(f(x)\) 쌓은 \(F(x)\) \(F'(x)\)

  1. 질문\(x^3 - 3x^2 + 2\)를 적분하려면, 미분해서 이 식이 되는 함수를 통째로 찾아야 할까? 아니면 항마다 따로 적분해서 더해도 될까?
  2. 복원미분에서는 \(\{kf(x)\}' = kf'(x), \{f(x) \pm g(x)\}' = f'(x) \pm g'(x)\)이다. 또 \(\int x^n\,dx = \frac{x^{n+1}}{n + 1} + C\)이다.
  3. 설명\(F' = f, G' = g\)이면 미분의 성질에서 \((kF)' = kf, (F \pm G)' = f \pm g\)이다. 그래서 두 함수 \(f(x), g(x)\)와 상수 \(k\)에 대해 \(\int kf(x)\,dx = k\int f(x)\,dx\ (k \ne 0)\)이고, \(\int\{f(x) \pm g(x)\}\,dx = \int f(x)\,dx \pm \int g(x)\,dx\)이다. 다항함수는 거듭제곱의 실수배를 더하고 뺀 것이므로, 항마다 적분해 더하고 적분상수는 마지막에 \(C\) 하나로 모은다. 예를 들어 \(\int(x^3 - 3x^2 + 2)\,dx = \frac{1}{4}x^4 - x^3 + 2x + C\)이다.
  4. 연결곱으로 된 식은 먼저 전개해 합의 꼴로 바꾼 뒤 적분한다. 또 이 성질은 정적분에서도 그대로 성립하여, 정적분을 항마다 나누어 계산하는 근거가 된다.
  5. 적용'다음 항'을 누를 때마다 주황 점선\((F')\)이 파란 곡선\((f)\)에 어떻게 다가가는지 보자. 끝까지 적분한 뒤 계수를 바꾸어 다른 식도 해 보고, 상수항만 0이 아닌 식을 적분하면 \(F(x)\)가 직선이 되는 것도 확인해 보자.
  6. 판단합과 차는 항마다 나눌 수 있지만 곱은 나눌 수 없다. \(\int x \cdot x\,dx\)는 \(\int x\,dx \cdot \int x\,dx = \frac{1}{4}x^4\)이 아니라 \(\int x^2\,dx = \frac{1}{3}x^3 + C\)이다. 또 실수배 성질에서 \(k = 0\)이면 왼쪽은 \(\int 0\,dx = C\), 오른쪽은 0이 되어 같지 않으므로 \(k \ne 0\)이라는 조건을 붙인다.
