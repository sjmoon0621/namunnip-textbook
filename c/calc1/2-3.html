y = xⁿ의 도함수

미분계수 \(f'(a)\)는 점 하나에서의 기울기입니다. \(a\)를 바꿀 때마다 기울기도 바뀌므로, 기울기 자체를 \(x\)의 함수로 볼 수 있습니다. 이것이 도함수입니다. 이 절에서는 \((x + h)^n\)을 전개해 \(y = x^n\)의 도함수가 \(nx^{n-1}\)임을 보이고, 접선의 기울기를 하나씩 찍어 도함수의 그래프를 직접 만들어 봅니다.

y = xⁿ의 도함수

본문

\(y = x^2\)에서 \(x = 1\)의 접선 기울기는 2, \(x = 3\)에서는 6이었다. 점마다 극한을 새로 계산하는 대신, '\(x\)에서의 기울기'를 \(x\)의 식 하나로 쓸 수는 없을까? 그리고 \(x^3\), \(x^{10}\)의 기울기는 어떤 규칙을 따를까?

먼저 알아야 할 것미분계수(미분계수), 함수의 극한(함수의 극한), 곱셈 공식과 이항 전개.

2.3.1도함수

\(f(x) = x^2\)의 미분계수를 \(a\) 대신 문자 \(x\)로 계산해 보자. \(\dfrac{(x + h)^2 - x^2}{h} = \dfrac{2xh + h^2}{h} = 2x + h\)이므로, \(h \to 0\)이면 \(2x\)이다. 즉 어느 점에서든 접선의 기울기는 그 점의 \(x\)좌표의 2배이다. \(x = 1\)이면 2, \(x = 3\)이면 6으로 앞의 값과 맞는다.

다시 말해 각 \(x\)에 그 점의 미분계수를 대응시키면 새로운 함수가 생긴다.

정의 2.3.1 도함수

미분가능한 함수 \(f(x)\)의 정의역의 각 \(x\)에 미분계수 \(f'(x)\)를 대응시키는 함수 \[f'(x) = \lim_{h \to 0}\frac{f(x + h) - f(x)}{h}\] 를 \(f(x)\)의 도함수라 한다. \(y'\), \(\dfrac{dy}{dx}\)로도 쓰며, 도함수를 구하는 것을 미분한다고 한다.

2.3.2\(x^n\)의 도함수

\(x^3\)도 같은 방법으로 미분한다. \((x + h)^3 = x^3 + 3x^2h + 3xh^2 + h^3\)이므로 \(\dfrac{(x + h)^3 - x^3}{h} = 3x^2 + 3xh + h^2\)이고, \(h \to 0\)이면 \(3x^2\)이다. 여기서 \(h\)가 하나뿐인 항 \(3x^2h\)만 살아남고, \(h\)가 둘 이상 곱해진 항은 모두 사라진 것에 주목하자.

\(n\)제곱에서도 같다. \((x + h)^n\)을 전개하면 \(x^n + nx^{n-1}h + (h^2\text{ 이상이 곱해진 항})\)이다. \(x^n\)을 빼고 \(h\)로 나눈 뒤 \(h \to 0\)으로 보내면 \(nx^{n-1}\)만 남는다.1

정리 2.3.2 \(y = x^n\)의 도함수

\(n\)이 자연수일 때 \((x^n)' = nx^{n-1}\)이다. 또 상수함수 \(y = c\)의 도함수는 0이다.

그림 1에서 \(n\)과 \(x\)를 바꾸어 보자. 위 그래프의 접선 기울기가 아래 그래프의 점의 높이가 된다. \(n = 2\)이면 아래 그래프는 직선 \(y = 2x\), \(n = 3\)이면 포물선 \(y = 3x^2\)이다. \(x^3\)은 원점에서 기울기가 0이고 양쪽에서 모두 올라가므로, 도함수 \(3x^2\)은 원점에서 0이고 나머지에서 양수이다.

2.3.3예제 하나를 끝까지

예제 2.3.3

\(f(x) = x^4\)의 도함수를 구하고, \(x = -1\), \(0\), \(2\)에서의 접선의 기울기를 구하여라. 또 \(y = x^3\)의 그래프 위에서 접선의 기울기가 12인 점을 모두 구하여라.

공식에 따라 \(f'(x) = 4x^3\)이다. 그러면 \(f'(-1) = -4\), \(f'(0) = 0\), \(f'(2) = 32\)이다. \(x^4\)의 그래프는 원점에서 바닥이 평평하고, 왼쪽에서는 내려가며 오른쪽에서는 가파르게 올라간다는 것이 기울기의 부호와 크기에서 읽힌다.

\(y = x^3\)의 도함수는 \(3x^2\)이다. 기울기가 12인 점은 \(3x^2 = 12\), 곧 \(x = \pm 2\)인 점이다. 따라서 \((2, 8)\)과 \((-2, -8)\) 두 점이다.

정의로 확인하면 \(\dfrac{(2 + h)^3 - 8}{h} = 12 + 6h + h^2 \to 12\)이다. 공식 하나가 극한 계산을 대신해 주었다. 아래 탐구 카드에서 접선의 기울기를 모아 도함수의 그래프를 직접 그려 보자.

  1. \((x + h)^n\)의 전개에서 \(x^{n-1}h\)의 계수가 \(n\)인 것은, \(n\)개의 괄호 \((x + h)\) 가운데 하나에서만 \(h\)를 고르고 나머지에서 \(x\)를 고르는 방법이 \(n\)가지이기 때문이다.
마무리

도함수는 각 점의 미분계수를 \(x\)의 함수로 모은 것이다. \((x + h)^n\)을 전개해 \(h\)로 나누면 \(h\)가 하나 곱해진 항만 남으므로 \((x^n)' = nx^{n-1}\)이다. 그래서 처음 질문의 기울기는 \(x^2\)에서 \(2x\), \(x^3\)에서 \(3x^2\), \(x^{10}\)에서 \(10x^9\)이라는 한 규칙을 따른다.

위 그림을 좌우로 끌면 \(P\)가 움직이며 아래 그림에 점 \((a, f'(a))\)가 찍힌다. 파란 선분이 \(P\)에서의 접선이다.

  1. 질문곡선 위의 점을 옮기면 그 점에서의 접선 기울기도 바뀐다. 그래서 \(x\)좌표마다 그 기울기를 짝지으면 새 함수가 하나 생긴다. 그 함수의 그래프는 어떤 모양일까?
  2. 복원미분계수 \(f'(a) = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h}\)는 점 \((a, f(a))\)에서 그은 접선의 기울기이다. 그리고 함수는 \(x\)의 값 하나에 \(y\)의 값 하나를 짝짓는 대응이다.
  3. 설명미분가능한 함수 \(f\)에서 \(x\)의 값마다 미분계수 \(f'(x)\)를 짝지으면 새 함수가 된다. 이 함수 \(f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}\)를 \(f\)의 도함수라 하고, \(y', \frac{dy}{dx}, \frac{d}{dx} f(x)\)로도 쓴다. 도함수를 구하는 것을 '\(x\)에 대하여 미분한다'고 한다. 가령 \(f(x) = x^2\)이면 \(\frac{f(x + h) - f(x)}{h} = 2x + h\)이므로 \(f'(x) = 2x\)이다. 또 상수함수 \(f(x) = c\)는 \(f(x + h) - f(x) = 0\)이므로 \(f'(x) = 0\)이다.
  4. 연결도함수를 한 번 구해 두면 미분계수는 대입만으로 얻는다. \(f'(x) = 2x\)에서 \(f'(3) = 6\)인 식이다. 또 도함수의 부호는 원래 그래프가 오르는지 내리는지를 알려 준다. 아래 그림에서 점이 \(x\)축 위에 있는 구간에서는 위 그래프가 오른쪽 위로 향한다.
  5. 적용\(x^2\)에서 \(P\)를 끌어 점을 여러 개 찍고, 점들이 어떤 직선 위에 놓이는지 보자. \(x^3 - 3x\)에서는 어느 \(x\)에서 찍힌 점이 \(x\)축 위에 오는지, 그때 위 그래프의 접선이 어떤 모양인지 확인하고, 상수함수에서 점이 어디에 찍히는지도 보자.
  6. 판단\(f'(a)\)는 수 하나이고 \(f'(x)\)는 함수이다. 또 도함수의 그래프는 원래 그래프를 옮긴 것이 아니다. \(x^2\)의 그래프는 아래로 볼록하지만 도함수 \(2x\)의 그래프는 직선이다. 즉 아래 그림의 세로축은 높이가 아니라 기울기를 나타낸다.

\((x + h)^n\)을 전개하면 왜 \(nx^{n-1}\)만 남을까?

\(y = x^n\)의 도함수 · 단계별 유도

—

\(\frac{(x + h)^n - x^n}{h}\)
—
\(nx^{n-1}\)
—
차이
—

삼각형에서 지워진 수는 빠진 항의 계수이다. 주황 원이 끝까지 남는 계수 \(n\)이다.

  1. 질문\(x^2\)의 도함수는 \(2x\)였다. 그러면 \(x^3, x^4, \cdots\)의 도함수도 매번 극한을 새로 계산해야 할까? 지수 \(n\)만 보고 바로 쓰는 규칙이 있을까?
  2. 복원\((x + h)^n\)을 전개한 계수는 파스칼의 삼각형 \(n\)번째 줄의 수이고, 그 줄의 두 번째 수는 언제나 \(n\)이다. 그리고 도함수는 \(f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}\)이다.
  3. 설명\((x + h)^n = x^n + nx^{n-1}h\) + (\(h^2\) 이상이 곱해진 항들)이다. 여기서 \(x^n\)을 빼면 첫 항이 사라지고, \(h\)로 나누면 \(nx^{n-1}\) + (\(h\)가 곱해진 항들)이 남는다. \(h \to 0\)이면 뒤의 항이 모두 0으로 가므로 \(n\)이 양의 정수일 때 \((x^n)' = nx^{n-1}\)이다. 또 \(n = 1\)이면 \((x)' = 1\)이고, 상수함수는 \((c)' = 0\)이다.
  4. 연결그래서 이 규칙은 '지수를 앞으로 내리고 지수를 1 줄인다'로 기억할 수 있다. 앞으로 내려오는 수 \(n\)은 파스칼의 삼각형에서 \(h\)가 한 번만 곱해진 항의 계수이다. 이 규칙과 다음 절의 합과 실수배의 미분법을 합치면 모든 다항함수를 미분할 수 있다.
  5. 적용\(n = 3\)으로 두고 단계 버튼을 네 번 눌러 어떤 항이 사라지는지 보고, \(n\)을 바꾸어도 남는 계수가 늘 \(n\)인지 확인해 보자. 아래 슬라이더로 \(x = 1\)에서 \(h\)를 0.0001까지 줄이며 평균변화율이 \(nx^{n-1}\)에 얼마나 가까워지는지 보고, \(x = -1\)에서 \(n = 4\)와 \(n = 5\)의 부호도 비교해 보자.
  6. 판단\((x^3)'\)을 \(x^2\)나 \(3x^3\)으로 쓰는 실수가 많은데, 지수를 내리는 일과 1 줄이는 일을 함께 해야 한다. 또 이 규칙은 밑이 \(x\)인 꼴에만 바로 쓴다. \((2x)^3\)은 먼저 \(8x^3\)으로 정리하면 도함수가 \(24x^2\)이고, \(3(2x)^2 = 12x^2\)이 아니다.
