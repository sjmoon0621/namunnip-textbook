부정적분과 정적분의 관계

본문

정적분은 직사각형을 잘게 나누어 더한 극한으로 정했고, 부정적분은 미분을 거꾸로 한 것이었다. 전혀 다른 두 생각이다. 그런데 \(\displaystyle\int_0^1 x^2\,dx = \tfrac{1}{3}\)은 \(x^2\)의 부정적분 \(\tfrac{x^3}{3}\)에 1과 0을 넣은 차와 같다. 이것은 우연일까?

먼저 알아야 할 것부정적분(다항함수의 부정적분), 정적분의 뜻과 성질(정적분), 미분계수의 정의(미분계수).

3.4.1위끝이 움직이는 넓이

구간의 위끝을 변수로 둔 정적분 \(S(x) = \displaystyle\int_a^x f(t)\,dt\)를 생각하자. \(S(x)\)는 \(a\)에서 \(x\)까지 곡선 아래의 넓이이므로 \(x\)의 함수이다. 위끝을 \(x\)에서 \(x + h\)로 조금 옮기면, 넓이는 그 사이의 가는 띠만큼 는다.

그림 1에서 보듯 그 띠는 폭이 \(h\)이고 높이가 \(f(x)\) 근처이므로 넓이가 약 \(f(x)h\)이다. 따라서 \(\dfrac{S(x + h) - S(x)}{h}\)는 \(f(x)\)에 가깝고, \(h\)를 줄일수록 더 가까워진다. 즉 \(S'(x) = f(x)\)이다.1 넓이 함수를 미분하면 높이의 함수가 나오는 것이다.

정리 3.4.1 정적분과 미분의 관계

함수 \(f(x)\)가 닫힌구간 \([a, b]\)에서 연속일 때 \[\frac{d}{dx}\int_a^x f(t)\,dt = f(x)\ (a < x < b)\]

3.4.2부정적분으로 정적분 계산하기

정리에 따르면 \(S(x)\)는 \(f(x)\)의 부정적분 가운데 하나이다. 그러면 \(f\)의 다른 부정적분 \(F(x)\)와는 상수만큼만 다르므로 \(S(x) = F(x) + C\)이다. \(S(a) = 0\)이므로 \(C = -F(a)\)이고, \(x = b\)를 넣으면 \(S(b) = F(b) - F(a)\)이다.

정리 3.4.2 정적분의 계산

\(f(x)\)가 닫힌구간 \([a, b]\)에서 연속이고 \(F(x)\)가 \(f(x)\)의 한 부정적분이면 \[\int_a^b f(x)\,dx = \Big[F(x)\Big]_a^b = F(b) - F(a)\]

이 정리 덕분에 직사각형 합의 극한을 계산하지 않고도 정적분을 구할 수 있다. 부정적분 하나를 찾아 양 끝 값의 차를 구하면 된다. 처음 질문의 일치는 우연이 아니라 이 정리의 결과이다.

3.4.3예제 하나를 끝까지

예제 3.4.3

\(\displaystyle\int_1^3 (3x^2 - 2x)\,dx\)를 구하여라. 또 \(\displaystyle\int_1^x f(t)\,dt = x^3 - ax + 2\)를 만족하는 다항함수 \(f(x)\)와 상수 \(a\)를 구하여라.

\(3x^2 - 2x\)의 한 부정적분은 \(F(x) = x^3 - x^2\)이다. 따라서 \(\displaystyle\int_1^3 (3x^2 - 2x)\,dx = F(3) - F(1) = (27 - 9) - (1 - 1) = 18\)이다.

두 번째 식에 \(x = 1\)을 넣으면 왼쪽은 넓이가 0이므로 \(0 = 1 - a + 2\), 곧 \(a = 3\)이다. 또 양변을 \(x\)에 대해 미분하면 정리에 따라 왼쪽은 \(f(x)\)이므로 \(f(x) = 3x^2 - a = 3x^2 - 3\)이다.

확인하면 \(\displaystyle\int_1^x (3t^2 - 3)\,dt = (x^3 - 3x) - (1 - 3) = x^3 - 3x + 2\)로 주어진 식과 같다. 위끝이 변수인 정적분에서는 '\(x = a\)를 넣는 것'과 '미분하는 것'이 두 가지 정보를 준다. 아래 탐구 카드에서 위끝을 움직이며 넓이가 늘어나는 빠르기를 직접 확인해 보자.

  1. 정확히 말하면 띠의 넓이는 그 사이 \(f\)의 최솟값과 최댓값에 \(h\)를 곱한 값 사이에 있다. \(f\)가 연속이므로 \(h \to 0\)이면 둘 다 \(f(x)\)로 다가가 \(S'(x) = f(x)\)가 된다.
마무리

위끝이 변수인 정적분 \(S(x) = \int_a^x f(t)\,dt\)는 위끝을 조금 옮길 때 높이 \(f(x)\)인 띠만큼 늘어나므로 \(S'(x) = f(x)\)이고, 따라서 정적분은 부정적분 하나의 양 끝 값의 차 \(F(b) - F(a)\)로 계산된다. 그래서 처음 질문의 \(\tfrac{1}{3}\)은 넓이와 미분의 역관계가 만든 필연적인 일치이다.

노란 띠의 넓이가 \(S(x + h) - S(x)\)이다. 위 그래프의 주황 점을 끌어 \(x\)를 옮길 수 있다. 아래 그래프의 주황 직선은 기울기가 \(f(x)\)인 직선이고, 노란 점선은 \(x\)와 \(x + h\)를 잇는 할선이다.

  1. 질문아래끝 \(a\)는 두고 위끝 \(x\)를 움직이면 정적분 \(S(x) = \int_a^x f(t)\,dt\)는 \(x\)의 함수가 된다. 이 함수를 미분하면 무엇이 나올까?
  2. 복원미분계수는 평균변화율 \(\frac{S(x + h) - S(x)}{h}\)에서 \(h \to 0\)인 극한이다. 그리고 정적분은 구간을 나누어 더할 수 있고\((\int_a^{x+h} = \int_a^x + \int_x^{x+h}), \int_a^a = 0\)이다.
  3. 설명\(S(x + h) - S(x) = \int_x^{x+h} f(t)\,dt\)는 노란 띠의 넓이이다. \(h\)가 작으면 띠는 높이가 거의 \(f(x)\), 폭이 \(h\)인 직사각형이라 넓이는 \(f(x) \times h\)에 가깝다. 양변을 \(h\)로 나누고 \(h \to 0\)으로 보내면, \(f\)가 연속이므로 \((\frac{d}{dx})\int_a^x f(t)\,dt = f(x)\)이다. 곧 \(S(x)\)는 \(f(x)\)의 부정적분 가운데 하나이다. 넓이를 재는 일(정적분)과 미분이 서로 거꾸로 가는 계산이라는 이 사실을 미적분의 기본정리라고도 부른다.
  4. 연결\(S(x)\)가 부정적분이므로 다른 부정적분 \(F(x)\)와는 상수만큼 다르다. 여기에 \(S(a) = 0\)을 쓰면 \(\int_a^b f(x)\,dx = F(b) - F(a)\)가 나오고, 이것으로 정적분을 넓이를 재지 않고 계산한다. 그래서 넓이를 직사각형으로 쪼개던 일이 부정적분 한 번으로 바뀐다.
  5. 적용\(h\)를 0.01까지 줄이며 가운데 값이 \(f(x)\)에 다가가는지 확인해 보자. \(t^2 - 1\)에서 \(x\)를 \(-1\) 또는 1에 두면 \(S(x)\)의 그래프가 그 자리에서 평평해진다. 아래끝 \(a\)를 바꾸면 \(S(x)\)의 그래프가 위아래로만 움직이고 기울기는 그대로인지도 보자.
  6. 판단"정적분은 수이므로 미분하면 0"이라는 오해가 있다. \(\int_a^b f(t)\,dt\)처럼 두 끝이 모두 상수이면 그 말이 맞지만, 위끝이 변수 \(x\)이면 값이 \(x\)에 따라 바뀌는 함수이다. 또 \(f(x) < 0\)인 곳에서는 위끝을 오른쪽으로 옮길 때 정적분이 줄어들므로 \(S(x)\)가 감소한다.

넓이를 재지 않고 정적분을 구할 수 있을까?

부정적분과 정적분 · \(F(b) - F(a)\)

—

\(F(b) + C\)
—
\(F(a) + C\)
—
차 = 정적분
—
직사각형 2000개 합
—
  1. 질문\(\int_0^2 (3x^2 - 2x)\,dx\)를 구하려고 직사각형을 수천 개 더할 수는 없다. 부정적분을 알면 정적분을 바로 구할 수 있을까?
  2. 복원\(S(x) = \int_a^x f(t)\,dt\)는 \(f(x)\)의 부정적분이고 \(S(a) = 0\)이다. 그리고 같은 함수의 두 부정적분은 상수만큼 다르다.
  3. 설명\(F(x)\)를 \(f(x)\)의 한 부정적분이라 하면 \(S(x) = F(x) + k\) (\(k\)는 상수)이다. \(x = a\)를 넣으면 \(0 = F(a) + k\), 곧 \(k = -F(a)\)이므로 \(S(x) = F(x) - F(a)\)이다. 여기에 \(x = b\)를 넣으면 \(\int_a^b f(x)\,dx = [F(x)]_a^b = F(b) - F(a)\)이고, 기호 \([F(x)]_a^b\)는 \(F(b) - F(a)\)를 줄여 쓴 것이다. 예를 들어 \(\int_0^2 (3x^2 - 2x)\,dx = [x^3 - x^2]_0^2 = (8 - 4) - 0 = 4\)이다.
  4. 연결즉 넓이를 직접 재던 일이 부정적분의 두 함숫값의 차로 바뀌었다. 아래 그래프에서 이 차는 \(x = a\)와 \(x = b\)에서의 높이 차이다. 위치 함수의 높이 차가 변위인 것처럼, 부정적분의 높이 차가 정적분이다.
  5. 적용\(C\)를 바꾸어도 '차 = 정적분'이 바뀌지 않는지, 그 값이 '직사각형 2000개 합'과 같은지 확인해 보자. \(4 - x^2\)에서 \(a = -1.5, b = 2.5\)로 두면 정적분이 음수가 되는데, 위 그래프의 어느 부분 때문인지 찾아보고, \(a\)와 \(b\)를 바꾸면 부호가 뒤집히는 것도 보자.
  6. 판단정적분은 부정적분과 달리 하나의 수이다. \(F(b) + C\)와 \(F(a) + C\)를 빼면 \(C\)가 지워지므로, 계산할 때 적분상수는 0으로 두면 된다. 흔한 실수는 \(F\)가 아닌 \(f\)에 \(b, a\)를 넣는 것과, \(F(a)\)를 뺄 때 괄호를 빠뜨려 부호를 틀리는 것이다.
