부정적분과 정적분의 관계

부정적분은 미분을 거꾸로 하는 계산이고, 정적분은 넓이에서 출발한 개념입니다. 이 절에서는 두 개념이 사실은 하나로 이어진다는 것을 확인하고, 그 덕분에 다항함수의 정적분을 넓이를 재지 않고 계산합니다.

3.4.1

위끝을 조금 옮기면 정적분은 얼마나 빨리 변할까?

부정적분과 정적분 · 미적분의 기본정리

노란 띠의 넓이가 S(x + h) − S(x)입니다. 위 그래프의 주황 점을 끌어 x를 옮길 수 있습니다. 아래 그래프의 주황 직선은 기울기가 f(x)인 직선, 노란 점선은 x와 x + h를 잇는 할선입니다.

  1. 질문아래끝 a는 두고 위끝 x를 움직이면 정적분 S(x) = ∫ax f(t)dt는 x의 함수가 됩니다. 이 함수를 미분하면 무엇이 나올까요?
  2. 복원미분계수는 평균변화율 {S(x + h) − S(x)}/h에서 h → 0인 극한입니다. 정적분은 구간을 나누어 더할 수 있고(∫ax+h = ∫ax + ∫xx+h), ∫aa = 0입니다.
  3. 설명S(x + h) − S(x) = ∫xx+h f(t)dt는 노란 띠의 넓이입니다. h가 작으면 띠는 높이가 거의 f(x), 폭이 h인 직사각형이라 넓이 ≈ f(x) × h입니다. 양변을 h로 나누고 h → 0으로 보내면, f가 연속이므로 (d/dx)∫ax f(t)dt = f(x)입니다. 곧 S(x)는 f(x)의 부정적분 가운데 하나입니다. 넓이를 재는 일(정적분)과 미분이 서로 거꾸로 가는 계산이라는 이 사실을 미적분의 기본정리라고도 부릅니다.
  4. 연결S(x)가 부정적분이므로 다른 부정적분 F(x)와는 상수만큼 다릅니다. S(a) = 0을 쓰면 ∫ab f(x)dx = F(b) − F(a)가 나오고, 이것으로 정적분을 넓이를 재지 않고 계산합니다. 넓이를 직사각형으로 쪼개던 일이 부정적분 한 번으로 바뀝니다.
  5. 적용h를 0.01까지 줄이며 가운데 값이 f(x)에 다가가는지 확인하세요. t2 − 1에서 x를 −1 또는 1에 두면 S(x)의 그래프에서 무엇이 보이나요? 아래끝 a를 바꾸면 S(x)의 그래프는 어떻게 움직이고, 기울기는 바뀌나요?
  6. 판단"정적분은 수이므로 미분하면 0"이라는 오해가 있습니다. ∫ab f(t)dt처럼 두 끝이 모두 상수이면 그 말이 맞지만, 위끝이 변수 x이면 값이 x에 따라 바뀌는 함수입니다. 또 f(x) < 0인 곳에서는 위끝을 오른쪽으로 옮길 때 정적분이 줄어들므로 S(x)가 감소합니다.

3.4.2

넓이를 재지 않고 정적분을 구할 수 있을까?

—

F(b) + C
—
F(a) + C
—
차 = 정적분
—
직사각형 2000개 합
—
  1. 질문∫02 (3x2 − 2x)dx를 구하려고 직사각형을 수천 개 더할 수는 없습니다. 부정적분을 알면 정적분을 바로 구할 수 있을까요?
  2. 복원S(x) = ∫ax f(t)dt는 f(x)의 부정적분이고 S(a) = 0입니다. 같은 함수의 두 부정적분은 상수만큼 다릅니다.
  3. 설명F(x)를 f(x)의 한 부정적분이라 하면 S(x) = F(x) + k (k는 상수)입니다. x = a를 넣으면 0 = F(a) + k, 곧 k = −F(a)이므로 S(x) = F(x) − F(a)입니다. x = b를 넣으면 ∫ab f(x)dx = [F(x)]ab = F(b) − F(a)입니다. 기호 [F(x)]ab는 F(b) − F(a)를 줄여 쓴 것입니다. 예: ∫02 (3x2 − 2x)dx = [x3 − x2]02 = (8 − 4) − 0 = 4.
  4. 연결넓이를 직접 재던 일이 부정적분의 두 함숫값의 차로 바뀌었습니다. 아래 그래프에서 이 차는 x = a와 x = b에서의 높이 차입니다. 위치 함수의 높이 차가 변위인 것처럼, 부정적분의 높이 차가 정적분입니다.
  5. 적용C를 바꾸어도 '차 = 정적분'이 바뀌지 않는지 확인하세요. 그 값이 '직사각형 2000개 합'과 같은가요? 4 − x2에서 a = −1.5, b = 2.5로 두면 정적분이 음수가 됩니다. 위 그래프의 어느 부분 때문인가요? a와 b를 바꾸면 어떻게 되나요?
  6. 판단정적분은 부정적분과 달리 하나의 수입니다. F(b) + C와 F(a) + C를 빼면 C가 지워지므로 계산할 때 적분상수는 0으로 두면 됩니다. 흔한 실수는 F가 아닌 f에 b, a를 넣는 것과, F(a)를 뺄 때 괄호를 빠뜨려 부호를 틀리는 것입니다.
