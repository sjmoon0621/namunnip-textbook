다항함수의 도함수

y = xn의 도함수를 알면 다항함수는 거의 다 미분할 수 있습니다. 다항함수는 xn에 수를 곱하고 더한 것이기 때문입니다. 이 절에서는 실수배와 합, 차를 미분하면 각각의 도함수에 같은 계산을 하면 된다는 것을 확인합니다. 그리고 두 함수의 곱은 도함수끼리 곱해서는 안 되는 까닭을 직사각형의 넓이로 살펴봅니다.

2.4.1

두 함수를 더하면 기울기도 더해질까?

실수배·합·차의 미분법 · 계수 조절

—

f′(a) = 2a
—
g′(a) = 3a²
—
k·f′(a) + m·g′(a)
—
굵은 곡선의 평균변화율 (h = 0.001)
—

그림을 끌어도 P가 움직입니다. 주황 선분이 굵은 곡선의 접선입니다.

  1. 질문f(x) = x2와 g(x) = x3의 도함수는 압니다. 3x2이나 x3 + x2은 정의로 다시 계산해야 할까요, 아니면 아는 도함수를 이어 붙이면 될까요?
  2. 복원(xn)′ = nxn−1이고 상수의 도함수는 0입니다. 극한값이 있으면 lim (k·A) = k·lim A, lim (A ± B) = lim A ± lim B입니다.
  3. 설명(kf(x + h) − kf(x))/h = k × (f(x + h) − f(x))/h이므로 극한을 취하면 {kf(x)}′ = kf′(x)입니다(k는 실수). 같은 방법으로 평균변화율을 두 분수로 나누면 {f(x) + g(x)}′ = f′(x) + g′(x), {f(x) − g(x)}′ = f′(x) − g′(x)입니다. 단, f와 g가 미분가능해야 합니다. 그래서 다항함수는 항마다 미분해 더하면 됩니다. 예를 들어 (4x3 − 2x + 7)′ = 12x2 − 2입니다.
  4. 연결세 항 이상이어도 같습니다. {kf + mg}′ = kf′ + mg′처럼 계수를 곱하고 더하는 계산이 미분과 순서를 바꿔도 결과가 같습니다. 상수항은 그래프를 위아래로 옮길 뿐 기울기를 바꾸지 않으므로 미분하면 사라집니다.
  5. 적용'합'에서 a = 1일 때 f′(1), g′(1)을 더한 값과 굵은 곡선의 평균변화율을 비교하세요. '차'로 바꾸면 어떻게 되나요? k만 2배로 바꾸면 접선의 기울기 중 어느 부분이 2배가 되나요? a = 0으로 두면 계수와 상관없이 기울기가 0인 까닭은 무엇인가요?
  6. 판단상수항을 미분해 그대로 남기는 실수가 흔합니다. (x2 + 5)′ = 2x이지 2x + 5가 아닙니다. 또 실수배와 합은 이렇게 나눌 수 있지만, 곱은 {f(x)g(x)}′ ≠ f′(x)g′(x)입니다. 곱의 미분법은 따로 있습니다.

2.4.2

곱의 미분은 왜 f′g + fg′일까?

곱의 미분법 · 넓이 모형
늘어난 넓이 ÷ h = Δ(fg)/h
—
모서리 조각 ΔfΔg ÷ h
—
f′(x)g(x) + f(x)g′(x)
—
f′(x)g′(x) (흔한 착각)
—

연두 조각은 fΔg, 파란 조각은 gΔf, 주황 모서리는 ΔfΔg입니다. 그림은 직사각형이 칸을 채우도록 가로·세로 배율을 따로 맞춘 모식입니다.

  1. 질문{x · x2}′ = (x3)′ = 3x2입니다. 그런데 두 인수의 도함수를 곱하면 1 × 2x = 2x로 맞지 않습니다. 곱을 미분하는 올바른 규칙은 무엇일까요?
  2. 복원가로 a, 세로 b인 직사각형의 넓이는 ab입니다. 가로가 Δa, 세로가 Δb만큼 늘면 넓이는 (a + Δa)(b + Δb) = ab + aΔb + bΔa + ΔaΔb가 됩니다.
  3. 설명Δf = f(x + h) − f(x), Δg = g(x + h) − g(x)라 하면 f(x + h)g(x + h) − f(x)g(x) = gΔf + fΔg + ΔfΔg입니다. h로 나누면 g · Δf/h + f · Δg/h + Δf · Δg/h입니다. h → 0이면 Δf/h → f′(x), Δg/h → g′(x)이고, 마지막 항은 (Δf/h) × Δg → f′(x) × 0 = 0입니다. 그래서 {f(x)g(x)}′ = f′(x)g(x) + f(x)g′(x)입니다. 이 식은 f, g가 미분가능할 때 성립합니다.
  4. 연결세 함수의 곱은 {fgh}′ = f′gh + fg′h + fgh′입니다. 같은 함수를 곱하면 [{f(x)}2]′ = 2f(x)f′(x)입니다. 곱의 미분법을 쓰면 다항식을 전개하지 않고도 도함수를 구할 수 있습니다.
  5. 적용x · x2, x = 1에서 h를 줄여 보세요. 주황 모서리 조각 ÷ h는 어디로 가나요? 늘어난 넓이 ÷ h는 f′g + fg′과 f′g′ 중 어느 값에 다가가나요? 다른 함수와 다른 x에서도 확인하세요.
  6. 판단{f(x)g(x)}′ = f′(x)g′(x)는 틀린 식입니다. 그림에서 f′g′에 해당하는 것은 모서리 조각뿐이고, 이 조각은 h로 나누어도 0으로 사라집니다. 넓이를 실제로 늘리는 것은 양옆의 두 띠입니다. 넓이 그림은 f, g가 양수일 때의 모식이지만, 식의 유도는 부호와 상관없이 성립합니다.
