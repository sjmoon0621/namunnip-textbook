다항함수의 도함수

\(y = x^n\)의 도함수를 알면 다항함수는 거의 다 미분할 수 있습니다. 다항함수는 \(x^n\)에 수를 곱하고 더한 것이기 때문입니다. 이 절에서는 실수배와 합, 차를 미분하면 각각의 도함수에 같은 계산을 하면 된다는 것을 확인합니다. 그리고 두 함수의 곱은 도함수끼리 곱해서는 안 되는 까닭을 직사각형의 넓이로 살펴봅니다.

\(y = x^n\)의 도함수가 \(nx^{n-1}\)이라는 것을 알았다. 그렇다면 \(f(x) = 2x^3 - 5x^2 + 4x - 7\)처럼 여러 항이 더해진 식은 항마다 따로 미분해서 더해도 될까? 두 식을 곱한 \((x^2 + 1)(x^3 - x)\)는 각각 미분해서 곱하면 될까?

먼저 알아야 할 것도함수의 정의와 \(y = x^n\)의 도함수(y = xⁿ의 도함수), 극한의 성질(극한의 성질과 극한값).

2.4.1합과 상수배는 항마다

두 함수를 더하면 기울기도 더해질까? 도함수의 정의에 넣으면 \(\dfrac{\{f(x + h) + g(x + h)\} - \{f(x) + g(x)\}}{h} = \dfrac{f(x + h) - f(x)}{h} + \dfrac{g(x + h) - g(x)}{h}\)이다. 극한의 성질에 따라 \(h \to 0\)이면 \(f'(x) + g'(x)\)이다. 상수배도 같은 방법으로 \(\{cf(x)\}' = cf'(x)\)가 된다.

정리 2.4.1 합, 차, 상수배의 미분법

\(f\), \(g\)가 미분가능하고 \(c\)가 상수일 때 \(\{cf(x)\}' = cf'(x)\), \(\{f(x) \pm g(x)\}' = f'(x) \pm g'(x)\)이다.

따라서 다항함수는 항마다 미분해 더하면 된다. \(f(x) = 2x^3 - 5x^2 + 4x - 7\)이면 \(f'(x) = 6x^2 - 10x + 4\)이다. 상수항 \(-7\)은 그래프를 위아래로 옮길 뿐 기울기를 바꾸지 않으므로 미분하면 사라진다.

2.4.2곱은 따로 미분해 곱하면 안 된다

그런데 곱은 다르다. \(x \cdot x = x^2\)인데, 각각 미분한 \(1 \times 1 = 1\)은 \((x^2)' = 2x\)와 다르다. 곱의 도함수는 그림 1의 직사각형으로 생각하면 보인다. 가로 \(f\), 세로 \(g\)인 직사각형에서 \(x\)가 \(h\)만큼 늘면 가로는 \(\Delta f\), 세로는 \(\Delta g\)만큼 는다. 넓이가 는 양은 오른쪽 띠 \(g\Delta f\), 위쪽 띠 \(f\Delta g\), 모서리의 작은 사각형 \(\Delta f\Delta g\)이다.

이것을 \(h\)로 나누면 \(g\dfrac{\Delta f}{h} + f\dfrac{\Delta g}{h} + \dfrac{\Delta f}{h}\Delta g\)이다. \(h \to 0\)이면 \(\dfrac{\Delta f}{h} \to f'\), \(\dfrac{\Delta g}{h} \to g'\)이고, 마지막 항은 \(f' \times 0 = 0\)이 된다. 그림 1의 슬라이더로 \(h\)를 줄이면 모서리가 두 띠보다 훨씬 빨리 작아지는 것이 보인다.

정리 2.4.2 곱의 미분법

\(\{f(x)g(x)\}' = f'(x)g(x) + f(x)g'(x)\)

같은 함수를 \(n\)번 곱한 \(\{f(x)\}^n\)에 이 법칙을 되풀이하면 \(\left[\{f(x)\}^n\right]' = n\{f(x)\}^{n-1}f'(x)\)이다.1

2.4.3예제 하나를 끝까지

예제 2.4.3

\(f(x) = (x^2 + 1)(x^3 - x)\)를 곱의 미분법으로 미분하고, 전개한 뒤 미분한 결과와 비교하여라. 또 \(g(x) = (2x - 1)^3\)의 \(x = 1\)에서의 미분계수를 구하여라.

곱의 미분법으로 \(f'(x) = 2x(x^3 - x) + (x^2 + 1)(3x^2 - 1)\)이다. 전개하면 \(2x^4 - 2x^2 + 3x^4 + 2x^2 - 1 = 5x^4 - 1\)이다.

먼저 전개하면 \(f(x) = x^5 - x^3 + x^3 - x = x^5 - x\)이므로 \(f'(x) = 5x^4 - 1\)로 같다. 두 방법이 같은 답을 주었으니 계산이 맞는다.

\(g(x) = (2x - 1)^3\)은 \(\{f(x)\}^n\)의 꼴이므로 \(g'(x) = 3(2x - 1)^2 \times 2 = 6(2x - 1)^2\)이고, \(g'(1) = 6\)이다. 괄호 안의 \(2x\)를 미분한 2를 곱하는 것을 잊으면 3이라는 틀린 답이 나온다. 아래 탐구 카드에서 직사각형의 두 변을 늘이며 곱의 미분법을 직접 확인해 보자.

  1. \(n = 2\)이면 \((f^2)' = f'f + ff' = 2ff'\)이다. 이것을 되풀이해 \(n = 3, 4, \ldots\)로 넓히는 것은 수학적 귀납법으로 보일 수 있다.
마무리

도함수는 합, 차, 상수배에 대해 항마다 따로 구할 수 있으므로, 다항함수는 각 항에 \((x^n)' = nx^{n-1}\)을 쓰고 더하면 된다. 그러나 곱은 직사각형의 넓이가 두 띠로 늘어나듯 \(f'g + fg'\)이 된다. 그래서 처음 질문의 \(2x^3 - 5x^2 + 4x - 7\)은 항마다 미분하면 되지만, 곱은 각각 미분해 곱하면 안 된다.

두 함수를 더하면 기울기도 더해질까?

실수배·합·차의 미분법 · 계수 조절

—

\(f'(a) = 2a\)
—
\(g'(a) = 3a^2\)
—
\(k \cdot f'(a) + m \cdot g'(a)\)
—
굵은 곡선의 평균변화율 \((h = 0.001)\)
—

그림을 끌어도 \(P\)가 움직인다. 주황 선분이 굵은 곡선의 접선이다.

  1. 질문\(f(x) = x^2\)와 \(g(x) = x^3\)의 도함수는 안다. 그러면 \(3x^2\)이나 \(x^3 + x^2\)은 정의로 다시 계산해야 할까, 아니면 아는 도함수를 이어 붙이면 될까?
  2. 복원\((x^n)' = nx^{n-1}\)이고 상수의 도함수는 0이다. 그리고 극한값이 있으면 \(\lim (k \cdot A) = k \cdot \lim A, \lim (A \pm B) = \lim A \pm \lim B\)이다.
  3. 설명\(\frac{kf(x + h) - kf(x)}{h} = k \times \frac{f(x + h) - f(x)}{h}\)이므로 극한을 취하면 \(\{kf(x)\}' = kf'(x)\)이다(\(k\)는 실수). 같은 방법으로 평균변화율을 두 분수로 나누면 \(\{f(x) + g(x)\}' = f'(x) + g'(x)\), \(\{f(x) - g(x)\}' = f'(x) - g'(x)\)이고, 이때 \(f\)와 \(g\)가 미분가능해야 한다. 그래서 다항함수는 항마다 미분해 더하면 된다. 예를 들어 \((4x^3 - 2x + 7)' = 12x^2 - 2\)이다.
  4. 연결세 항 이상이어도 같다. 즉 \(\{kf + mg\}' = kf' + mg'\)처럼 계수를 곱하고 더하는 계산은 미분과 순서를 바꿔도 결과가 같다. 그리고 상수항은 그래프를 위아래로 옮길 뿐 기울기를 바꾸지 않으므로 미분하면 사라진다.
  5. 적용'합'에서 \(a = 1\)일 때 \(f'(1), g'(1)\)을 더한 값과 굵은 곡선의 평균변화율을 비교하고, '차'로 바꾸어서도 확인해 보자. 다음에는 \(k\)만 2배로 바꿔 접선의 기울기 가운데 어느 부분이 2배가 되는지 보고, \(a = 0\)으로 두면 계수와 상관없이 기울기가 0인 까닭도 생각해 보자.
  6. 판단상수항을 미분해 그대로 남기는 실수가 흔한데, \((x^2 + 5)' = 2x\)이지 \(2x + 5\)가 아니다. 또 실수배와 합은 이렇게 나눌 수 있지만 곱은 \(\{f(x)g(x)\}' \ne f'(x)g'(x)\)이다. 곱의 미분법은 따로 있다.

곱의 미분은 왜 \(f'g + fg'\)일까?

곱의 미분법 · 넓이 모형
늘어난 넓이 ÷ \(h = \frac{\Delta(fg)}{h}\)
—
모서리 조각 \(\Delta f\Delta g \div h\)
—
\(f'(x)g(x) + f(x)g'(x)\)
—
\(f'(x)g'(x)\) (흔한 착각)
—

연두 조각은 \(f\Delta g\), 파란 조각은 \(g\Delta f\), 주황 모서리는 \(\Delta f\Delta g\)이다. 그림은 직사각형이 칸을 채우도록 가로와 세로 배율을 따로 맞춘 모식이다.

  1. 질문\(\{x \cdot x^2\}' = (x^3)' = 3x^2\)이다. 그런데 두 인수의 도함수를 곱하면 \(1 \times 2x = 2x\)로 맞지 않는다. 곱을 미분하는 올바른 규칙은 무엇일까?
  2. 복원가로 \(a\), 세로 \(b\)인 직사각형의 넓이는 \(ab\)이다. 가로가 \(\Delta a\), 세로가 \(\Delta b\)만큼 늘면 넓이는 \((a + \Delta a)(b + \Delta b) = ab + a\Delta b + b\Delta a + \Delta a\Delta b\)가 된다.
  3. 설명\(\Delta f = f(x + h) - f(x), \Delta g = g(x + h) - g(x)\)라 하면 \(f(x + h)g(x + h) - f(x)g(x) = g\Delta f + f\Delta g + \Delta f\Delta g\)이다. 이것을 \(h\)로 나누면 \(g \cdot \frac{\Delta f}{h} + f \cdot \frac{\Delta g}{h} + \Delta f \cdot \frac{\Delta g}{h}\)이다. \(h \to 0\)이면 \(\frac{\Delta f}{h} \to f'(x), \frac{\Delta g}{h} \to g'(x)\)이고, 마지막 항은 \((\frac{\Delta f}{h}) \times \Delta g \to f'(x) \times 0 = 0\)이다. 그래서 \(\{f(x)g(x)\}' = f'(x)g(x) + f(x)g'(x)\)이고, 이 식은 \(f, g\)가 미분가능할 때 성립한다.
  4. 연결같은 방법으로 세 함수의 곱은 \(\{fgh\}' = f'gh + fg'h + fgh'\)이고, 같은 함수를 곱하면 \([\{f(x)\}^2]' = 2f(x)f'(x)\)이다. 곱의 미분법을 쓰면 다항식을 전개하지 않고도 도함수를 구할 수 있다.
  5. 적용\(x \cdot x^2\)에서 \(x = 1\)로 두고 \(h\)를 줄이며 주황 모서리 조각 ÷ \(h\)가 어디로 가는지 보자. 늘어난 넓이 ÷ \(h\)가 \(f'g + fg'\)과 \(f'g'\) 가운데 어느 값에 다가가는지 확인하고, 다른 함수와 다른 \(x\)에서도 확인해 보자.
  6. 판단\(\{f(x)g(x)\}' = f'(x)g'(x)\)는 틀린 식이다. 그림에서 \(f'g'\)에 해당하는 것은 모서리 조각뿐이고, 이 조각은 \(h\)로 나누어도 0으로 사라진다. 넓이를 실제로 늘리는 것은 양옆의 두 띠이다. 넓이 그림은 \(f, g\)가 양수일 때의 모식이지만, 식의 유도는 부호와 상관없이 성립한다.
