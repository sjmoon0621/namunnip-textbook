증가·감소와 극대·극소

그래프를 왼쪽에서 오른쪽으로 따라가면 오르막과 내리막이 번갈아 나옵니다. 그래프를 다 그리지 않고도 어디가 오르막인지 알 수 있을까요? 이 절에서는 접선의 기울기, 곧 도함수의 부호로 함수의 증가와 감소를 판정합니다. 오르막이 내리막으로 바뀌는 봉우리와 내리막이 오르막으로 바뀌는 골짜기를 극대와 극소라고 부르고, 이를 찾는 방법을 증감표로 정리합니다.

그림 위를 끌어도 점이 움직입니다.

  1. 질문f(x) = x3 − 3x는 어느 구간에서 오르막이고 어느 구간에서 내리막일까요? 점을 하나하나 찍지 않고 판정할 방법이 있을까요?
  2. 복원어떤 구간의 임의의 두 수 x1 < x2에 대하여 f(x1) < f(x2)이면 f는 그 구간에서 증가한다고 하고, f(x1) > f(x2)이면 감소한다고 합니다. f′(x)는 그 점에서 접선의 기울기입니다.
  3. 설명f가 어떤 열린 구간에서 미분가능하고 그 구간의 모든 x에서 f′(x) > 0이면 f는 그 구간에서 증가하고, f′(x) < 0이면 감소합니다. 근거는 평균값 정리입니다. x1 < x2이면 f(x2) − f(x1) = f′(c)(x2 − x1)인 c가 둘 사이에 있고, f′(c) > 0이면 이 값이 양수입니다. 그래서 x3 − 3x는 f′(x) = 3(x + 1)(x − 1)의 부호를 따져, x ≤ −1과 x ≥ 1에서 증가하고 −1 ≤ x ≤ 1에서 감소합니다.
  4. 연결증가와 감소를 판정하는 일은 결국 도함수에 대한 부등식 f′(x) > 0을 푸는 일입니다. 다항함수의 도함수는 다시 다항식이므로, 이차부등식의 풀이가 그대로 쓰입니다. 오르막과 내리막이 바뀌는 곳은 다음 카드의 극대와 극소입니다.
  5. 적용점을 왼쪽에서 오른쪽으로 끌면서 위 칸의 접선 기울기와 아래 칸의 f′ 그래프 높이가 늘 같은 부호인지 보세요. 아래 칸의 초록 띠는 위 칸에서 어떤 모양에 해당하나요? 세 번째 함수 x3에서는 x = 0일 때 f′ = 0입니다. 그 점에서 f는 증가를 멈추나요?
  6. 판단"f가 증가하면 f′ > 0"은 거꾸로는 맞지 않습니다. x3은 실수 전체에서 증가하지만 f′(0) = 0입니다. 그래서 다항함수가 어떤 구간에서 증가할 조건을 물으면 "그 구간에서 f′(x) ≥ 0"으로 풉니다. f′ = 0인 점이 따로 떨어져 있으면 증가는 깨지지 않습니다.

증감표는 f′(x) = 3x2 + 2px + q의 부호로 만들어집니다. 표의 화살표와 그래프의 오르내림을 견주어 보세요.

  1. 질문f′(c) = 0이면 접선이 수평입니다. 그러면 그 점은 언제나 봉우리나 골짜기일까요?
  2. 복원f′ > 0인 구간에서 f는 증가하고, f′ < 0인 구간에서 감소합니다.
  3. 설명x = a를 포함하는 어떤 열린 구간의 모든 x에서 f(x) ≤ f(a)이면 f는 x = a에서 극대라 하고, f(a)를 극댓값이라 합니다. 부등호를 바꾸면 극소와 극솟값입니다. 둘을 묶어 극값이라 합니다. 미분가능한 함수가 x = a에서 극값을 가지면 f′(a) = 0입니다. 판정은 f′의 부호 변화로 합니다. f′(a) = 0이고 a의 좌우에서 f′의 부호가 +에서 −로 바뀌면 극대, −에서 +로 바뀌면 극소입니다. 부호가 바뀌지 않으면 극값이 아닙니다. 이를 한눈에 정리한 것이 증감표입니다.
  4. 연결삼차함수에서 f′은 이차식이므로, 극값이 있는지는 f′ = 0의 판별식이 정합니다. D > 0이면 부호가 두 번 바뀌어 극대와 극소가 하나씩 생기고, D ≤ 0이면 부호가 바뀌지 않아 극값이 없습니다. 증감표는 다음 절에서 그래프의 개형을 그리는 뼈대가 됩니다.
  5. 적용p = 0, q = −3에서 증감표를 읽고 극댓값과 극솟값을 확인하세요. q를 늘리면 봉우리와 골짜기가 어떻게 되나요? 판별식이 0이 되는 순간(예: p = 0, q = 0)의 증감표에서 f′ = 0인 칸 좌우의 부호를 보세요. p = 3일 때는 q가 얼마 이상이면 극값이 사라지나요?
  6. 판단"f′(a) = 0이면 극값"은 틀립니다. x3은 f′(0) = 0이지만 0의 좌우에서 모두 증가합니다. 또 극댓값은 그 근처에서 가장 큰 값일 뿐, 함수 전체의 최댓값이 아닙니다. 극댓값이 극솟값보다 작을 수도 있고, 닫힌 구간의 최댓값은 끝점에서 나올 수도 있습니다.
