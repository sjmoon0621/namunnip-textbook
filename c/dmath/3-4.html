논리 회로

부울 식은 전기 회로로 그대로 옮겨집니다. AND, OR, NOT 같은 논리 게이트를 이으면 어떤 규칙이든 계산하는 회로가 되고, 이진수 덧셈의 규칙을 회로로 만들면 계산기가 됩니다. 이 절에서는 계단 조명과 금고 회로에서 신호가 흐르는 모습을 보고, 전가산기를 이어 받아올림이 전해지는 덧셈 회로를 완성합니다.

3.4.1식을 회로로 옮기다

부울 함수의 식은 그대로 회로가 된다. 곱은 그리고 게이트, 합은 또는 게이트, 부정은 부정 게이트로 바꾸고, 식의 계산 순서대로 게이트를 잇는다. 그래서 진리표로 원하는 규칙을 정하고, 곱의 합 꼴로 식을 쓰고, 간소화한 뒤 회로로 옮기면 어떤 규칙이든 기계로 만들 수 있다. 간소화한 식일수록 게이트가 적게 들어 회로가 작고 빠르다. 두 입력이 서로 다를 때만 1인 배타적 또는 \(A \oplus B = \bar AB + A\bar B\)도 이렇게 세 가지 게이트로 만든다.

정리 3.4.1 반가산기와 전가산기

한 자리 이진수 \(A\), \(B\)를 더하는 반가산기는 합 \(S = A \oplus B\)와 올림 \(C = AB\)를 낸다. 아래 자리에서 올라온 \(C_{\text{in}}\)까지 더하는 전가산기는 \[S = A \oplus B \oplus C_{\text{in}},\qquad C_{\text{out}} = AB + BC_{\text{in}} + C_{\text{in}}A\]를 낸다. 전가산기를 자릿수만큼 이어 붙이면 여러 자리 이진수의 덧셈 회로가 된다.

전가산기의 올림 \(C_{\text{out}}\)은 세 입력 가운데 둘 이상이 1일 때 1이므로, 앞에서 본 다수결 함수와 같다. 합 \(S\)는 세 입력 가운데 1이 홀수 개일 때 1이다. 반가산기 두 개와 또는 게이트 하나로 전가산기를 만들 수도 있다. 첫째 반가산기로 \(A\)와 \(B\)를 더하고, 둘째 반가산기로 그 합과 \(C_{\text{in}}\)을 더한 뒤, 두 올림 가운데 하나라도 1이면 올림을 낸다.1

3.4.2여러 자리 더하기

네 자리 이진수 두 개를 더하려면 전가산기 네 개를 한 줄로 잇는다. 맨 아래 자리의 올림 입력은 0으로 두고, 각 전가산기의 올림 출력을 바로 위 자리 전가산기의 올림 입력에 잇는다. 그러면 사람이 손으로 아래 자리부터 받아올리며 더하는 과정이 그대로 회로가 된다. 다만 위 자리는 아래 자리의 올림이 정해질 때까지 기다려야 해서, 자릿수가 많으면 올림이 차례로 전해지는 데 시간이 걸린다. 그래서 실제 컴퓨터는 올림을 미리 내다보는 더 복잡한 회로를 쓴다.

3.4.3예제 하나를 끝까지

예제 3.4.2

배타적 또는 \(A \oplus B\)를 그리고, 또는, 부정 게이트로 만들 때 필요한 게이트 수를 세어라. 전가산기에 \(A = 1\), \(B = 1\), \(C_{\text{in}} = 1\)을 넣었을 때의 출력을 구하고, 십진법으로 확인하여라.

\(A \oplus B = \bar AB + A\bar B\)이므로 부정 게이트 2개로 \(\bar A\), \(\bar B\)를 만들고, 그리고 게이트 2개로 \(\bar AB\), \(A\bar B\)를 만든 뒤, 또는 게이트 1개로 더한다. 모두 5개이다. 그래서 반가산기는 배타적 또는 회로와 그리고 게이트 하나로 만들어진다.

전가산기에 1, 1, 1을 넣으면 1이 세 개로 홀수이므로 \(S = 1\)이고, 둘 이상이 1이므로 \(C_{\text{out}} = 1\)이다. 출력은 이진수 \(11_{(2)} = 3\)이어서 \(1 + 1 + 1 = 3\)과 같다. 즉 진리표로 정한 규칙을 부울 식으로 쓰고 게이트로 옮기면 덧셈 같은 계산도 회로로 만들 수 있으며, 반가산기와 전가산기를 이어 붙인 회로가 컴퓨터 덧셈의 기본 부품이다.

마무리

부울 함수의 곱, 합, 부정은 각각 그리고, 또는, 부정 게이트가 되어, 진리표로 정한 규칙을 식으로 쓰고 간소화한 뒤 게이트로 옮기면 회로가 된다. 반가산기는 합 \(A \oplus B\)와 올림 \(AB\)를 내고, 전가산기는 아래 자리의 올림까지 더하며, 전가산기를 자릿수만큼 이으면 여러 자리 덧셈 회로가 된다. 처음 질문의 덧셈 기계는 세 가지 게이트만으로 만든 가산기들을 이어 붙여 만들 수 있다.

스위치와 게이트로 규칙을 회로로 만들 수 있을까?

논리 회로 · 조작

  1. 질문계단 아래와 위 어느 스위치로든 전등을 켜고 끌 수 있는 회로, 열쇠와 비밀번호가 함께 맞아야 열리는 금고는 어떻게 만들까? 앞 절의 부울 식이 실제 전기 회로가 될 수 있을까?
  2. 복원부울 함수는 곱(AND), 합(OR), 보수(NOT)로 나타낼 수 있다.
  3. 설명AND, OR, NOT 연산을 하는 전자 부품을 논리 게이트라 하고, 게이트를 선으로 이어 부울 함수를 계산하는 것을 논리 회로라 한다. 이 밖에 XOR(배타적 논리합, 둘이 다를 때 1)과 NAND(AND의 보수)가 자주 쓰인다. 부울 식의 구조가 그대로 회로의 연결이 되므로, 식을 간단히 하면 게이트가 줄어든다. 특히 NAND 하나로 NOT(\(\overline{AA}\)), AND, OR을 모두 만들 수 있어 NAND를 만능 게이트라고 한다.
  4. 연결컴퓨터의 처리 장치는 수십억 개의 트랜지스터로 만든 이런 게이트의 연결이다. 다음 카드에서는 게이트로 이진수 덧셈 회로를 만든다.
  5. 적용회로마다 스위치를 켜고 끄며 선의 색이 어떻게 흐르는지 보고, 참값표의 어느 줄에 해당하는지 확인해 보자. "NAND로 만든 OR"의 참값표가 OR과 같은지 비교해 보자.
  6. 판단실제 회로에서는 신호가 게이트를 지날 때마다 아주 짧은 지연이 생겨, 거쳐야 하는 게이트 수가 많으면 회로가 느려진다. 그래서 식의 글자 수뿐 아니라 "몇 단계를 거치는지"도 설계에서 중요하다.

가산기 회로 · 활용
A
B

  1. 질문이진수 덧셈의 규칙은 몇 줄뿐이었다. 그렇다면 스위치와 게이트만으로 두 수를 더하는 기계를 만들 수 있을까? 계산기의 덧셈은 안에서 어떻게 일어날까?
  2. 복원한 자리 덧셈은 \(0 + 0 = 00\), \(0 + 1 = 01\), \(1 + 1 = 10\)(받아올림 1). XOR은 둘이 다를 때 1, AND는 둘 다 1일 때 1이다.
  3. 설명한 자리 두 비트의 합의 자리는 \(S = A \oplus B\), 받아올림은 \(C = AB\)이다. 이것이 반가산기이다. 아랫자리에서 올라온 받아올림 \(C_{in}\)까지 더하는 전가산기는 \(S = A \oplus B \oplus C_{in}\), \(C_{out} = AB + C_{in}(A \oplus B)\)이다. 전가산기 네 개를 받아올림 선으로 이으면 4비트 덧셈 회로가 된다. 2의 보수와 함께 쓰면 같은 회로로 뺄셈도 한다.
  4. 연결받아올림이 오른쪽부터 차례로 전해져야 하므로 자리가 많을수록 느려진다. 실제 처리 장치는 받아올림을 미리 계산하는 회로(자리올림 예측)로 이 지연을 줄인다.
  5. 적용A, B의 자리를 눌러 여러 덧셈을 해 보자. 1111 + 0001처럼 받아올림이 끝까지 전해지는 경우를 "받아올림 전파 보기"로 확인해 보자. 마지막 받아올림 \(C_4\)는 무엇을 뜻하는가?
  6. 판단4비트 회로는 0~15만 나타내므로 합이 15를 넘으면 \(C_4 = 1\)로 넘침이 생긴다. 회로는 틀린 것이 아니라 정해진 자리만큼만 계산한 것이며, 넘침을 확인하는 일은 따로 해야 한다.
