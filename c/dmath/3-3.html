부울 함수와 간소화

본문

학급 회의에서 세 대표 A, B, C가 찬성(1)이나 반대(0)를 누르면, 둘 이상이 찬성할 때 안건이 통과(1)되는 장치를 만들려 한다. 찬성과 반대의 경우는 \(2^3 = 8\)가지이고, 통과되는 경우를 하나씩 적으면 \(\bar ABC + A\bar BC + AB\bar C + ABC\)라는 식이 된다. 이 식대로 회로를 만들면 부품이 많이 든다. 같은 일을 하는 더 짧은 식이 있을까? 그리고 그 식이 정말 같은 일을 하는지는 어떻게 확인할까?

먼저 알아야 할 것명제와 조건, 그리고와 또는, 이진수(이진수의 사칙연산).

3.3.1참과 거짓의 계산

0과 1만을 값으로 갖는 변수와, 그 변수들에 대한 연산 그리고(곱 \(AB\)), 또는(합 \(A + B\)), 부정(\(\bar A\))으로 만든 함수를 부울 함수라 한다. \(AB\)는 둘 다 1일 때만 1이고, \(A + B\)는 하나라도 1이면 1이며, \(\bar A\)는 \(A\)를 뒤집는다. 부울 함수는 모든 입력에 대한 출력을 적은 진리표로 완전히 정해진다. 진리표에서 출력이 1인 행마다, 그 행의 입력과 정확히 일치할 때만 1이 되는 곱을 만들어 모두 더하면 그 함수의 식이 된다. 이것을 곱의 합 꼴이라 한다.

정리 3.3.1 부울 대수의 법칙

교환법칙, 결합법칙, 분배법칙 \(A(B + C) = AB + AC\)와 함께 \(A + A = A\), \(A + \bar A = 1\), \(A\bar A = 0\), \(A + AB = A\)가 성립한다. 드모르간의 법칙은 \(\overline{A + B} = \bar A\,\bar B\), \(\overline{AB} = \bar A + \bar B\)이다. 두 부울 함수가 같은지는 진리표의 모든 행을 비교해 확인한다.

보통의 수와 달리 \(A + A = A\)이고, 또는 연산에 대해서도 분배법칙 \(A + BC = (A + B)(A + C)\)이 성립한다. 이 법칙들로 식을 바꾸어 같은 진리표를 갖는 더 짧은 식을 찾는 것을 간소화라 한다. 간소화의 기본 요령은 한 변수만 다르고 나머지가 같은 두 곱을 찾는 것이다. 예를 들어 \(ABC + AB\bar C = AB(C + \bar C) = AB\)처럼, 그 변수가 지워진다. 또 \(A + A = A\)를 써서 한 곱을 여러 번 짝짓는 데 쓸 수 있다.1

3.3.2그림으로 묶는 간소화

카르노 맵은 진리표의 칸을 이웃한 칸끼리 한 변수만 다르도록 늘어놓은 표이다. 출력이 1인 칸들을 2개, 4개처럼 2의 거듭제곱 개씩 직사각형으로 묶으면, 묶음 안에서 바뀌는 변수가 지워진 곱 하나가 된다. 묶음은 클수록, 개수는 적을수록 식이 짧아지고, 한 칸을 여러 묶음에 함께 넣어도 된다. 그래서 대수 법칙을 하나하나 쓰는 대신 그림에서 묶음을 찾아 간소화한다.

3.3.3예제 하나를 끝까지

예제 3.3.2

처음 질문의 식 \(\bar ABC + A\bar BC + AB\bar C + ABC\)를 부울 대수의 법칙으로 \(AB + BC + CA\)로 간소화하여라. 각 식을 회로로 만들 때 필요한 그리고 게이트와 또는 게이트의 입력 수를 비교하여라.

\(ABC = ABC + ABC + ABC\)이므로 식을 \((AB\bar C + ABC) + (\bar ABC + ABC) + (A\bar BC + ABC)\)로 다시 묶는다. 각 괄호는 한 변수만 다른 두 곱이어서 \(AB(\bar C + C) = AB\), \(BC(\bar A + A) = BC\), \(CA(\bar B + B) = CA\)가 된다. 그래서 \(f = AB + BC + CA\)이고, 그림 1의 진리표로 여덟 경우가 모두 같음을 확인할 수 있다.

원래 식은 세 입력 그리고 게이트 4개와 네 입력 또는 게이트 하나, 부정 게이트 3개가 필요하다. 간소화한 식은 두 입력 그리고 게이트 3개와 세 입력 또는 게이트 하나로 충분하다. 식으로 보면 "어느 두 사람이든 함께 찬성하면 통과"라는 뜻이 그대로 드러난다. 즉 부울 함수는 진리표로 정해지고 곱의 합 꼴로 쓸 수 있으며, 한 변수만 다른 곱을 짝지어 그 변수를 지우는 간소화로 같은 일을 하는 더 짧은 식을 얻는다.

  1. 1854년 영국의 불은 논리를 0과 1의 계산으로 다루는 대수를 만들었다. 80여 년 뒤인 1937년 미국의 섀넌은 대학원 논문에서 전기 스위치 회로가 불의 대수를 따른다는 것을 보여, 디지털 회로 설계의 바탕을 놓았다.

  2. 복원명제 \(p \wedge q\)(그리고)는 둘 다 참일 때만 참, \(p \vee q\)(또는)는 하나라도 참이면 참, \(\sim p\)는 참과 거짓을 바꾼다.
  3. 설명0과 1만 가지는 변수로 이루어진 함수를 부울 함수라 하고, 곱(AND) \(AB\), 합(OR) \(A + B\), 보수(NOT) \(A'\)로 나타낸다. 모든 입력에 대한 출력을 적은 표가 참값표이다. 참값표에서 출력이 1인 줄마다 "그 입력일 때만 1"인 곱(최소항, 예를 들어 \(ABC'\))을 만들어 모두 더하면 함수를 나타내는 식이 된다. 그래서 어떤 규칙이든 AND, OR, NOT만으로 쓸 수 있다.
  4. 연결이렇게 얻은 식은 길어지기 쉬워서 다음 카드에서 간단히 만들고, 4절에서 실제 논리 회로로 바꾼다. 부울 대수는 1854년 조지 불이 논리를 계산으로 다루려고 만들었다.
  5. 적용과제마다 출력 칸을 채우고 확인해 보자. 맞으면 참값표에서 얻은 식(최소항의 합)과 간단히 한 식이 나타난다. 다수결 함수의 최소항은 몇 개인가?
  6. 판단부울 대수의 \(1 + 1\)은 1이다(또는). 이진수 덧셈의 \(1 + 1 = 10_{(2)}\)과 기호가 같지만 다른 연산이다. 무엇을 계산하는지 늘 확인해 보자.

긴 부울 식을 그림으로 묶어 줄일 수 있을까?

부울 함수의 간소화 · 조작

칸을 누르면 그 입력의 출력이 0과 1로 바뀐다. 칸 아래의 색 점은 그 칸을 덮는 묶음이다.

  1. 질문참값표에서 최소항을 모두 더하면 식이 길어진다. 예를 들어 \(A'BC'D + A'BCD + ABC'D + ABCD\)는 사실 \(BD\) 하나와 같다. 이런 줄임을 눈으로 빨리 찾는 방법이 있을까?
  2. 복원부울 대수에서 \(X + X' = 1\)이므로 \(ABC + ABC' = AB(C + C') = AB\)이다. 한 변수만 다른 두 항은 그 변수를 지우고 하나로 합칠 수 있다.
  3. 설명카르노 맵은 참값표를 이웃한 칸끼리 한 변수만 다르도록(00, 01, 11, 10 순서) 배열한 표이다. 그래서 이웃한 1을 2개, 4개, 8개처럼 2의 거듭제곱 개의 직사각형으로 묶으면 그 안에서 바뀌는 변수가 지워진다. 표의 양 끝도 이웃한다(위아래, 좌우가 이어짐). 1을 모두 덮되 묶음은 되도록 크게, 개수는 되도록 적게 하면 간단한 식이 된다.
  4. 연결식이 간단하면 4절의 논리 회로에서 게이트 수가 줄어 회로가 싸고 빨라진다. 변수가 많아지면 컴퓨터가 같은 원리(콰인-매클러스키 방법 등)로 간소화한다.
  5. 적용예 1~3을 불러 묶음이 어떻게 생기는지 보자. 네 귀퉁이 칸만 1로 하면 어떤 식이 되는가? 직접 1을 놓으며, 처음 식(최소항의 합)과 간단한 식의 글자 수를 비교해 보자.
  6. 판단묶음은 반드시 1, 2, 4, 8개의 직사각형이어야 한다. 3개나 ㄱ자 모양은 묶을 수 없다. 또 간단한 식이 하나뿐이 아닌 경우도 있어, 같은 글자 수의 다른 답이 있을 수 있다.
