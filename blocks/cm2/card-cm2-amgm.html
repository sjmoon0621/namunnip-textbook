두 양수의 산술평균과 기하평균 가운데 어느 쪽이 클까?

절대부등식 · 산술평균 \(\ge\) 기하평균

—

산술평균 \(\frac{a + b}{2}\)
—
기하평균 \(\sqrt{ab}\)
—
차 \(\frac{(\sqrt{a} - \sqrt{b})^2}{2}\)
—

지름 위의 점을 끌거나 슬라이더로 \(a\)를 바꾸세요. 초록 수선이 기하평균, 주황 반지름이 산술평균입니다.

  1. 질문둘레가 16 cm인 직사각형 가운데 넓이가 가장 큰 것은 무엇일까요? 두 변을 \(a, b\)라 하면 \(a + b = 8\)일 때 \(ab\)가 가장 커지는 경우를 찾는 문제입니다.
  2. 복원지름에 대한 원주각은 직각입니다. 직각삼각형에서 빗변에 내린 수선의 길이 \(h\)는 빗변을 나눈 두 길이 \(a, b\)와 \(h^2 = ab\)의 관계가 있습니다.
  3. 설명\(a > 0, b > 0\)일 때 \(\frac{a + b}{2}\)를 산술평균, \(\sqrt{ab}\)를 기하평균이라 합니다. \(\frac{a + b}{2} - \sqrt{ab} = \frac{(\sqrt{a} - \sqrt{b})^2}{2} \ge 0\)이므로 \(\frac{a + b}{2} \ge \sqrt{ab}\)가 항상 성립하고, 등호는 \(a = b\)일 때만 성립합니다. 그림에서 반지름은 \(\frac{a + b}{2}\)이고 수선 \(CD\)는 \(\sqrt{ab}\)입니다. 수선은 반원 안의 현의 절반이므로 반지름보다 길 수 없고, \(C\)가 중심에 올 때만 반지름과 같아집니다.
  4. 연결합 \(a + b\)가 일정하면 곱 \(ab\)는 \(a = b\)일 때 최대이고, 곱이 일정하면 합은 \(a = b\)일 때 최소입니다. 예를 들어 \(x > 0\)이면 \(x + \frac{1}{x} \ge 2\sqrt{x \cdot \frac{1}{x}} = 2\)입니다.
  5. 적용\(a + b = 8\)로 두고 점을 움직여 기하평균이 가장 커지는 곳을 찾으세요. 그때 \(ab\)는 얼마인가요? 처음 질문의 답과 비교해 보세요. \(a\)가 0에 가까워지면 두 평균의 차는 어떻게 되나요?
  6. 판단이 부등식은 \(a, b\)가 양수일 때만 씁니다. \(x + \frac{1}{x} \ge 2\)는 \(x = -1\)에서 깨집니다. 또 최솟값을 구할 때는 등호가 실제로 성립하는 값이 있는지 확인해야 합니다. 등호 조건을 만족하는 값이 없으면 \(2\sqrt{ab}\)는 최솟값이 아니라 그보다 작은 하한일 뿐입니다.
