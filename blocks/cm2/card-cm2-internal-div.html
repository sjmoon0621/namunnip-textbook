A, B를 끌어 보세요. 선분 위의 작은 점은 AB를 m + n등분한 자리입니다.

  1. 질문두 도시 A, B를 잇는 곧은 도로에서 A부터 B까지의 2/3 되는 곳에 휴게소를 지으려고 합니다. 두 도시의 좌표만으로 휴게소의 좌표를 구할 수 있을까요?
  2. 복원수직선 위 두 점 사이의 거리는 좌표의 차입니다. 비례식 a : b = c : d에서는 ad = bc입니다. 평행선으로 잘린 삼각형의 변은 같은 비로 나뉩니다(닮음).
  3. 설명선분 AB 위의 점 P가 AP : PB = m : n (m > 0, n > 0)을 만족할 때, 점 P는 선분 AB를 m : n으로 내분한다고 하고 P를 내분점이라고 합니다. 수직선에서 A(x₁), B(x₂), P(x)이고 x₁ < x₂이면 (x − x₁) : (x₂ − x) = m : n이므로 x = (mx₂ + nx₁)/(m + n)입니다(x₁ > x₂여도 같은 식이 나옵니다). 좌표평면에서는 A, P, B에서 x축에 수선을 내리면 평행선 때문에 발끼리도 m : n으로 나뉩니다. 그래서 x좌표와 y좌표 각각에 같은 식을 쓰면 P((mx₂ + nx₁)/(m + n), (my₂ + ny₁)/(m + n))입니다. m = n이면 중점 ((x₁ + x₂)/2, (y₁ + y₂)/2)입니다.
  4. 연결삼각형의 무게중심은 중선을 꼭짓점에서부터 2 : 1로 내분하는 점입니다. 이 식을 쓰면 무게중심이 ((x₁ + x₂ + x₃)/3, (y₁ + y₂ + y₃)/3)임을 얻습니다. 중점은 대칭이동에서 대칭축을 찾는 데에도 쓰입니다.
  5. 적용먼저 '수직선 위에서'로 A, B를 놓고 m, n을 바꾸어 P가 몇 번째 작은 점에 오는지 보세요. 그다음 '좌표평면 위에서'로 바꾸어 축 위의 발들도 같은 비로 나뉘는지 확인하세요. m = n일 때의 P는 무엇인가요? m과 n을 서로 바꾸면 P는 어디로 가나요?
  6. 판단m : n은 A에서부터 잰 비입니다. 분자에서 m은 B의 좌표 x₂에, n은 A의 좌표 x₁에 곱합니다. 가까운 쪽이 아니라 먼 쪽 점에 큰 수가 곱해지는 것이 헷갈리기 쉽습니다. m이 클수록 P는 B에 가까워집니다. 또 내분점은 항상 선분 위, 두 점 사이에 있습니다.
