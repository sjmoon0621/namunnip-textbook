\(x^2 + y^2 + Ax + By + C = 0\)은 언제 원이 될까?

원의 방정식 · 완전제곱식

—

중심
—
\(\frac{A^2 + B^2 - 4C}{4}\)
—
그래프
—
  1. 질문\(x^2 + y^2 - 4x + 6y - 3 = 0\)은 원의 방정식을 전개한 모양입니다. 중심과 반지름이 보이지 않는 이 식에서 어떻게 그래프를 그릴까요? 또 이런 꼴의 식은 언제나 원일까요?
  2. 복원\(x^2 - 4x = (x - 2)^2 - 4\)처럼, 일차항 계수의 절반을 제곱해 더하고 빼면 완전제곱식을 만들 수 있습니다. 실수의 제곱은 0 이상입니다.
  3. 설명\(x^2 + y^2 + Ax + By + C = 0\)을 완전제곱식으로 고치면 \((x + \frac{A}{2})^2 + (y + \frac{B}{2})^2 = \frac{A^2 + B^2 - 4C}{4}\)입니다. 우변이 양수이면 중심이 \((-\frac{A}{2}, -\frac{B}{2})\)이고 반지름이 \(\frac{\sqrt{A^2 + B^2 - 4C}}{2}\)인 원입니다. 우변이 0이면 좌변이 0인 점 \((-\frac{A}{2}, -\frac{B}{2})\) 하나뿐이고, 음수이면 두 제곱의 합이 음수가 될 수 없으므로 만족하는 점이 없습니다. 그래서 이 식이 원을 나타낼 조건은 \(A^2 + B^2 - 4C > 0\)입니다.
  4. 연결일반형은 세 점을 지나는 원을 구할 때 편리합니다. 세 점의 좌표를 넣으면 \(A, B, C\)에 대한 연립일차방정식이 나오기 때문입니다. 또 원과 직선의 교점을 구할 때도 일반형에 직선의 식을 넣어 이차방정식을 얻습니다.
  5. 적용\(A, B\)는 두고 \(C\)만 늘려 보세요. 원은 어떻게 변하나요? \(A = -4, B = 6\)일 때 원이 점 하나로 줄어드는 \(C\)의 값을 찾고, 식으로도 확인해 보세요. \(A\)를 바꾸면 중심은 어느 방향으로 움직이나요?
  6. 판단\(x^2\)과 \(y^2\)의 계수가 같고 \(xy\)항이 없어야 원이 될 수 있습니다. \(x^2 + 2y^2 = 4\)는 원이 아닙니다. \(2x^2 + 2y^2 + \cdots = 0\)처럼 계수가 1이 아니면 먼저 양변을 그 계수로 나눕니다. 꼴이 맞아도 우변이 0 이하이면 원이 아닙니다.
