본문

"\(x\)가 4의 배수이면 \(x\)는 2의 배수이다"는 참이고, "\(x\)가 2의 배수이면 \(x\)는 4의 배수이다"는 거짓이다. 우리는 이것을 예를 몇 개 들어 짐작한다. 그런데 예를 아무리 많이 들어도 '모든 경우'를 다 확인한 것은 아니다. 참과 거짓을 확실하게 가르는 방법은 무엇일까?

2.4.1명제와 조건

"3은 홀수이다"는 참이고, "4는 홀수이다"는 거짓이다. 두 문장처럼 참인지 거짓인지를 분명하게 판별할 수 있는 문장이나 식을 명제라 한다. 그런데 "\(x\)는 홀수이다"는 \(x\)에 무엇을 넣느냐에 따라 참이 되기도 하고 거짓이 되기도 한다. 이렇게 변수의 값에 따라 참, 거짓이 정해지는 문장이나 식을 조건이라 한다.

조건을 다룰 때 쓰는 열쇠가 집합이다. 전체집합 \(U\)의 원소 가운데 조건 \(p\)를 참이 되게 하는 것을 모은 집합을 \(p\)의 진리집합이라 하고, 보통 대문자 \(P\)로 쓴다. 가령 \(U = \{1, 2, \ldots, 24\}\)에서 조건 '\(x\)는 4의 배수'의 진리집합은 \(\{4, 8, 12, 16, 20, 24\}\)이다.

2.4.2'\(p\)이면 \(q\)이다'의 참, 거짓

명제 '\(p\)이면 \(q\)이다'는 \(p \to q\)로 쓰고, \(p\)를 가정, \(q\)를 결론이라 한다. 이 명제가 주장하는 것은 '\(p\)를 만족하는 것은 언제나 \(q\)도 만족한다'이다. 이것을 진리집합으로 옮기면 '\(P\)의 원소는 모두 \(Q\)의 원소'이고, 이는 곧 \(P \subset Q\)이다.

정리 2.4.1 명제와 진리집합

두 조건 \(p\), \(q\)의 진리집합을 \(P\), \(Q\)라 하면, 명제 \(p \to q\)가 참이면 \(P \subset Q\)이고, \(P \subset Q\)이면 \(p \to q\)는 참이다.

그림 1의 슬라이더를 \(p\)는 4의 배수, \(q\)는 2의 배수에 두면 \(P\)의 칸이 모두 \(Q\) 안에 들어 있다. 반대로 \(p\)를 2의 배수, \(q\)를 4의 배수로 바꾸면 2, 6, 10 같은 칸이 \(Q\) 밖으로 나온다. 이렇게 \(P\)에는 있지만 \(Q\)에는 없는 원소가 반례이다. 반례가 하나라도 있으면 명제는 거짓이다.

2.4.3'모든'과 '어떤'

조건 앞에 '모든'이나 '어떤'을 붙이면 명제가 된다. '모든 \(x\)에 대하여 \(p\)'는 \(P = U\)일 때 참이고, '어떤 \(x\)에 대하여 \(p\)'는 \(P \ne \varnothing\)일 때 참이다. 따라서 '모든'이 붙은 명제는 반례 하나로 거짓이 되고, '어떤'이 붙은 명제는 예 하나로 참이 된다.

부정할 때는 두 말이 서로 바뀐다. "모든 학생이 안경을 썼다"의 부정은 "모든 학생이 안경을 쓰지 않았다"가 아니라 "안경을 쓰지 않은 학생이 있다"이다. 기호로는 '모든 \(x\)에 대하여 \(p\)'의 부정이 '어떤 \(x\)에 대하여 \({\sim}p\)'이다.1

2.4.4예제 하나를 끝까지

예제 2.4.2

실수 \(x\)에 대하여 명제 '\(1 \le x \le 3\)이면 \(x \le a\)이다'가 참이 되는 실수 \(a\)의 최솟값을 구하여라. 또 명제 '\(x^2 - 4x + 3 < 0\)이면 \(x > 0\)이다'의 참, 거짓을 판별하여라.

진리집합은 \(P = \{x \mid 1 \le x \le 3\}\), \(Q = \{x \mid x \le a\}\)이다. 명제가 참이려면 \(P \subset Q\)이어야 하므로, 수직선에서 \(P\)의 오른쪽 끝 3이 \(Q\) 안에 있어야 한다. 따라서 \(3 \le a\)이고, \(a\)의 최솟값은 3이다.

두 번째 명제의 가정을 풀면 \((x - 1)(x - 3) < 0\)에서 \(1 < x < 3\)이다. 그러면 \(P = \{x \mid 1 < x < 3\}\), \(Q = \{x \mid x > 0\}\)이고, \(P\)의 모든 원소가 양수이므로 \(P \subset Q\)이다. 따라서 참이다.

첫 번째 답을 점검해 보자. \(a = 3\)이면 \(Q = \{x \mid x \le 3\}\)이 \(P\)를 품는다. \(a = 2.9\)이면 \(x = 3\)이 \(P\)에는 있지만 \(Q\)에는 없으므로 반례가 되어 명제가 거짓이다. 경계값 하나가 참과 거짓을 가른다. 아래 탐구 카드에서 진리집합을 직접 움직이며 반례가 생기고 사라지는 순간을 찾아보자.

  1. 조건 \(p\)의 부정 \({\sim}p\)의 진리집합은 \(P^C\)이다. 그래서 '\(p\) 그리고 \(q\)'의 부정은 드모르간의 법칙에 따라 '\({\sim}p\) 또는 \({\sim}q\)'이다.
마무리

조건은 진리집합으로 바꾸어 다루며, 명제 \(p \to q\)는 \(P \subset Q\)일 때 참이고 \(P\) 가운데 \(Q\) 밖의 원소가 반례가 된다. 예를 많이 드는 것으로는 참을 확신할 수 없지만, 포함관계를 보이면 모든 경우를 한꺼번에 확인한 셈이다. 그래서 처음 질문에서 4의 배수의 집합은 2의 배수의 집합에 포함되어 앞 명제는 참이고, 2가 반례이므로 뒤 명제는 거짓이다.
