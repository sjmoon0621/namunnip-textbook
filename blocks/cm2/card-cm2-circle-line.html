원과 직선이 만나는지 그리지 않고 알 수 있을까?

원과 직선의 위치 관계 · 판별식과 거리

—

판별식 D/4
—
거리 d와 r
—
위치 관계
—
  1. 질문원 x2 + y2 = 9와 직선 y = x + 2는 몇 개의 점에서 만날까요? 그래프를 그리지 않고 판단할 수 있을까요?
  2. 복원두 그래프의 교점은 두 방정식을 연립한 해입니다. 이차방정식 ax2 + 2b′x + c = 0은 D/4 = b′2 − ac가 양수이면 서로 다른 두 실근, 0이면 중근, 음수이면 실근이 없습니다. 점 (x₁, y₁)과 직선 ax + by + c = 0 사이의 거리는 |ax₁ + by₁ + c|/√(a2 + b2)입니다.
  3. 설명방법 1 (판별식) y = mx + n을 원의 방정식에 넣으면 x에 대한 이차방정식 (1 + m2)x2 + 2mnx + n2 − r2 = 0이 됩니다. 실근의 개수가 교점의 개수이므로 D > 0이면 두 점에서 만나고, D = 0이면 한 점에서 만나며(접한다, 이 직선이 접선, 그 점이 접점), D < 0이면 만나지 않습니다. 방법 2 (거리) 중심에서 직선까지의 거리를 d라 하면 d < r이면 두 점, d = r이면 접하고, d > r이면 만나지 않습니다. 실제로 계산하면 D/4 = (1 + m2)(r2 − d2)이어서 두 방법의 판정은 언제나 같습니다.
  4. 연결거리 방법은 중심이 원점이 아닌 원에도 계산이 간단하고, 접선을 구할 때 그대로 쓰입니다. 판별식 방법은 교점의 좌표까지 구해 줍니다. 이차함수의 그래프와 직선의 위치 관계도 판별식으로 판단합니다.
  5. 적용n을 바꾸면서 D/4와 d − r의 부호가 언제 함께 바뀌는지 보세요. '접하는 예'에서 D/4와 d는 얼마인가요? r = 3, m = 0일 때 직선이 원에 접하는 n을 모두 찾아보세요.
  6. 판단D/4 < 0이면 '실수 범위에서' 교점이 없다는 뜻입니다. 중근은 두 교점이 하나로 겹친 것입니다. 또 판별식 방법에서는 직선의 식을 원의 식에 넣어 한 문자에 대한 이차방정식을 만든 뒤에 판별식을 써야 합니다. y축에 평행한 직선 x = k는 y에 대한 이차방정식이 됩니다.
