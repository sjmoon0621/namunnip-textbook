원래 도형 위의 점 \(Q\)를 도형을 따라 끌어 보세요.

  1. 질문포물선 \(y = x^2\)을 오른쪽으로 2, 위로 3만큼 옮기면 \(y = (x - 2)^2 + 3\)이 됩니다. 오른쪽으로 옮겼는데 왜 \(x + 2\)가 아니라 \(x - 2\)일까요?
  2. 복원점의 평행이동은 \((x, y) \to (x + a, y + b)\)입니다. 방정식 \(f(x, y) = 0\)의 그래프는 이 식을 만족하는 점 전체입니다.
  3. 설명옮긴 도형 위의 점을 \((X, Y)\)라 하면, 이 점은 원래 도형 위의 점 \((X - a, Y - b)\)를 옮겨 온 것입니다. 그래서 \((X, Y)\)가 새 도형 위에 있을 조건은 \(f(X - a, Y - b) = 0\)입니다. 문자를 다시 \(x, y\)로 쓰면, 방정식 \(f(x, y) = 0\)이 나타내는 도형을 \(x\)축의 방향으로 \(a\)만큼, \(y\)축의 방향으로 \(b\)만큼 평행이동한 도형의 방정식은 \(f(x - a, y - b) = 0\)입니다. 점을 옮길 때는 더하고, 식에서는 빼는 것은 '옮긴 점에서 거꾸로 돌아가 원래 식을 확인'하기 때문입니다.
  4. 연결원 \(x^2 + y^2 = r^2\)을 옮기면 중심이 \((a, b)\)인 원 \((x - a)^2 + (y - b)^2 = r^2\)이 됩니다. 이차함수 \(y = a(x - p)^2 + q\)의 꼭짓점이 \((p, q)\)인 까닭도 같습니다. 대칭이동도 같은 방법으로 식을 바꿉니다.
  5. 적용원을 고르고 \(a = 3, b = -1\)로 두세요. 새 식은 무엇이고 중심은 어디인가요? \(Q\)를 끌면서 \(Q'\)을 새 식에 넣은 값이 늘 성립하는지 보세요. 직선 \(y = \frac{x}{2}\)를 고르고 \(a = 2, b = 1\)로 옮기면 무엇이 보이나요?
  6. 판단\(x\) 대신 \(x + a\)를 넣는 실수가 가장 흔합니다. 그러면 반대 방향으로 옮겨집니다. 또 평행이동한 도형이 원래 도형과 같을 수도 있습니다. 직선을 그 직선의 방향으로 옮기면 직선은 그대로입니다. 식이 그대로라고 해서 옮기지 않은 것은 아닙니다.
