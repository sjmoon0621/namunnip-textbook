━ \(y = f(x)\)━ \(y = g(x)\)━ 합성함수┅ \(y = x\)

\(x\)축 위의 점 \(x_0\)을 끌어 보세요. 점선 화살표는 첫 함수의 그래프로 올라간 뒤, 직선 \(y = x\)에서 그 값을 다시 \(x\)좌표로 옮겨 두 번째 함수로 가는 길입니다.

  1. 질문\(f(x) = x - 1, g(x) = x^2 - 2\)일 때 \((g\circ f)(x)\)를 하나의 식으로 쓸 수 있을까요? 그래프만 보고 \((g\circ f)(2)\)를 찾을 수도 있을까요?
  2. 복원\((g\circ f)(x) = g(f(x))\)이고, 먼저 작용하는 것은 \(f\)입니다. 함수 \(y = f(x)\)의 그래프에서 \(x = a\)일 때의 높이가 \(f(a)\)입니다.
  3. 설명식으로 구할 때는 \(g(x)\)의 \(x\) 자리에 \(f(x)\)를 통째로 넣습니다. \(g(f(x)) = (x - 1)^2 - 2 = x^2 - 2x - 1\)입니다. 반대로 \((f\circ g)(x) = f(x^2 - 2) = x^2 - 3\)입니다. 일반적으로 \(f(x) = ax + b, g(x) = x^2 + c\)이면 \((g\circ f)(x) = a^2x^2 + 2abx + b^2 + c, (f\circ g)(x) = ax^2 + ac + b\)입니다. 그래프로 구할 때는 \(x_0\)에서 \(f\)의 그래프로 올라가 높이 \(f(x_0)\)를 얻고, 직선 \(y = x\)를 거쳐 그 높이를 \(x\)좌표로 옮긴 다음 \(g\)의 그래프로 가면 높이가 \(g(f(x_0))\)입니다.
  4. 연결값 하나만 필요하면 식 전체를 구하지 않고 안쪽부터 차례로 계산하는 편이 빠릅니다. 함수를 여러 번 거듭하는 계산\((f\circ f\circ f\cdots)\)이나 수열의 점화식도 같은 원리이고, 미적분에서는 합성함수의 미분으로 이어집니다.
  5. 적용처음 상태에서 \(x_0 = 2\)로 놓고 '먼저'와 '다음'의 값을 읽으세요. 식 \(x^2 - 2x - 1\)에 2를 넣은 값과 같나요? 순서를 \(f\circ g\)로 바꾸면 경로와 값이 어떻게 달라지나요? \(a = 1, b = 0\)으로 놓아 \(f\)를 항등함수로 만들면 두 합성함수가 어떻게 되나요?
  6. 판단합성함수의 식을 구할 때 \(g(x) = x^2 + c\)의 \(x\)에 \(f(x)\)를 넣으면서 괄호를 빠뜨리면 \(x - 1^2 - 2\)처럼 전혀 다른 식이 됩니다. 넣는 식은 반드시 괄호로 감쌉니다. 또 합성하려면 안쪽 함수의 값이 바깥 함수의 정의역에 들어가야 합니다. 바깥 함수가 \(\sqrt{x}\)처럼 정의역이 제한되면 이 조건을 따로 확인해야 합니다.
