무리함수의 그래프와 직선은 몇 번 만날까?

무리함수 · 교점의 개수

—

교점의 개수
—
\(u\)에 대한 판별식 \(9 - 4k\)
—
교점
—

\(k\)를 0.25씩 바꾸며 교점의 개수가 바뀌는 곳을 찾을 수 있다. 판별식이 양수인데도 교점이 하나뿐인 때가 있다.

  1. 질문직선 \(y = x + k\)를 위아래로 옮기면 곡선 \(y = \sqrt{x + 2}\)와 만나는 점의 개수는 어떻게 달라질까? 개수가 바뀌는 \(k\)를 그래프와 식으로 찾을 수 있을까?
  2. 복원\(y = \sqrt{x + 2}\)는 점 \((-2, 0)\)에서 시작해 오른쪽 위로 뻗고, 치역은 \(y \ge 0\)이다. 또 이차방정식 \(at^2 + bt + c = 0\)의 실근의 개수는 판별식 \(b^2 - 4ac\)의 부호로 정해진다.
  3. 설명교점의 \(x\)좌표는 방정식 \(x + k = \sqrt{x + 2}\)의 실근이다. \(u = \sqrt{x + 2}\)로 놓으면 \(x = u^2 - 2\)이므로 \(u^2 - u + (k - 2) = 0\)이 된다. 그런데 \(u\)는 근호의 값이므로 \(u \ge 0\)인 근만 교점이 된다. 판별식 \(1 - 4(k - 2) = 9 - 4k\)가 0이 되는 \(k = \frac{9}{4}\)에서 접하고, 두 근의 곱이 \(k - 2\)이므로 \(k < 2\)이면 근 하나가 음수라 교점은 하나뿐이다. 정리하면 \(k < 2\)에서 1개, \(2 \le k < \frac{9}{4}\)에서 2개, \(k = \frac{9}{4}\)에서 1개(접점), \(k > \frac{9}{4}\)에서 0개이다. \(k = 2\)는 직선이 시작점 \((-2, 0)\)을 지나는 경계이다.
  4. 연결양변을 제곱해 \((x + k)^2 = x + 2\)로 풀면, 직선이 \(y < 0\)에서 만나는 아래쪽 반쪽 곡선 \(y = -\sqrt{x + 2}\)과의 교점까지 섞여 나온다. 또 \(y = \sqrt{x + 2}\)는 \(y = x^2 - 2(x \ge 0)\)의 역함수이므로, 두 곡선은 직선 \(y = x\)에 대하여 대칭이다.
  5. 적용\(k = 0\)에서 교점이 하나인 것을 확인하고, 교점이 두 개가 되는 처음 \(k\)를 찾아보자. \(k = 2\)일 때 직선이 시작점 \((-2, 0)\)을 지나고, \(k = 2.25\)에서는 두 교점이 하나로 합쳐져 접한다. \(k = 1\)에서는 판별식이 양수인데도 근 하나가 음수라서 교점이 하나뿐이다.
  6. 판단무리방정식을 제곱해서 풀면 원래 식을 만족하지 않는 근이 생길 수 있다. 그래서 구한 근을 원래 식에 넣어 확인하거나, \(u \ge 0\) 같은 조건을 처음부터 붙여야 한다. 판별식만으로 교점의 개수를 정하면 시작점이 있는 무리함수에서는 틀리기 쉽다.
