무리함수

본문

정사각형 모양의 텃밭 넓이가 \(x\ \text{m}^2\)이면 한 변의 길이는 \(\sqrt{x}\) m이다. 넓이가 늘어날 때 변의 길이는 어떻게 늘어날까? 그리고 \(y = \sqrt{x}\)의 그래프는 왜 원점에서 시작해 한쪽으로만 뻗을까?

먼저 알아야 할 것제곱근과 근호, 역함수의 그래프(역함수), 그래프의 평행이동과 대칭이동(평행이동, 대칭이동).

3.5.1근호 안이 0 이상인 곳에서만

근호 안에 문자가 있는 식 가운데 유리식으로 나타낼 수 없는 것을 무리식이라 한다. \(y = f(x)\)에서 \(f(x)\)가 \(x\)에 대한 무리식이면 이 함수를 무리함수라 한다. 실수 범위에서는 음수의 제곱근을 생각하지 않으므로, 정의역을 따로 말하지 않으면 근호 안이 0 이상인 실수 전체를 정의역으로 본다.

\(y = \sqrt{x}\)의 정의역은 \(x \ge 0\)이고, 값도 0 이상이다. 그래서 그래프는 원점에서 시작해 제1사분면으로만 뻗는다. \(x\)가 0, 1, 4, 9일 때 \(y\)는 0, 1, 2, 3이므로, 넓이가 네 배가 되어야 변의 길이가 두 배가 된다. 그래프는 오른쪽으로 갈수록 점점 완만해진다.

3.5.2\(y = x^2\)의 절반을 돌린 것

\(y = \sqrt{x}\)는 \(y = x^2\ (x \ge 0)\)의 역함수이다. \(y = x^2\)을 \(x\)에 대해 풀면 \(x = \sqrt{y}\)이고, \(x\)와 \(y\)를 바꾸면 \(y = \sqrt{x}\)이기 때문이다. 따라서 \(y = \sqrt{x}\)의 그래프는 포물선의 오른쪽 절반을 직선 \(y = x\)에 대칭이동한 모양이다.

나머지 모양은 대칭이동과 평행이동으로 얻는다. \(y = -\sqrt{x}\)는 \(x\)축에 대칭, \(y = \sqrt{-x}\)는 \(y\)축에 대칭이다. 그리고 \(y = \sqrt{a(x - p)} + q\)는 \(y = \sqrt{ax}\)를 \(x\)축 방향으로 \(p\), \(y\)축 방향으로 \(q\)만큼 옮긴 것이다.

정리 3.5.1 \(y = \sqrt{a(x - p)} + q\)의 그래프

\(a > 0\)이면 정의역은 \(\{x \mid x \ge p\}\), \(a < 0\)이면 \(\{x \mid x \le p\}\)이고, 치역은 \(\{y \mid y \ge q\}\)이다. 그래프는 점 \((p, q)\)에서 시작한다.

그림 1에서 \(a\)의 부호를 바꾸면 그래프가 시작점에서 왼쪽으로 뻗고, \(p\)와 \(q\)를 바꾸면 시작점이 옮겨 간다. 근호 안이 0이 되는 \(x = p\)에서 출발한다는 것만 기억하면 그래프의 위치가 바로 정해진다.1

3.5.3예제 하나를 끝까지

예제 3.5.2

함수 \(y = \sqrt{2x - 4} + 1\)의 정의역과 치역을 구하고, 직선 \(y = x\)와의 교점을 구하여라.

근호 안을 묶으면 \(\sqrt{2(x - 2)} + 1\)이므로 \(a = 2\), \(p = 2\), \(q = 1\)이다. 따라서 정의역은 \(\{x \mid x \ge 2\}\), 치역은 \(\{y \mid y \ge 1\}\)이고, 그래프는 점 \((2, 1)\)에서 오른쪽 위로 뻗는다.

교점은 \(\sqrt{2x - 4} + 1 = x\)를 풀어 구한다. \(\sqrt{2x - 4} = x - 1\)의 양변을 제곱하면 \(2x - 4 = x^2 - 2x + 1\), 곧 \(x^2 - 4x + 5 = 0\)이다. 그런데 판별식이 \(\dfrac{D}{4} = 4 - 5 = -1 < 0\)이므로 실근이 없다. 따라서 그래프와 직선 \(y = x\)는 만나지 않는다.

그래프로 확인하면, 시작점 \((2, 1)\)은 직선 \(y = x\)보다 아래에 있고 \(x\)가 커질수록 그래프의 기울기는 1보다 작아지므로 끝까지 직선 아래에 머문다. 양변을 제곱하는 풀이에서는 원래 식의 해가 아닌 값이 끼어들 수 있으니, 해가 나오면 반드시 원래 식에 넣어 확인해야 한다.2 아래 탐구 카드에서 시작점과 방향을 바꾸며 그래프와 직선이 몇 번 만나는지 직접 확인해 보자.

  1. \(y = \sqrt{ax + b} + c\)꼴은 근호 안을 \(a\)로 묶어 \(\sqrt{a\left(x + \tfrac{b}{a}\right)} + c\)로 바꾸면 \(p = -\tfrac{b}{a}\)가 보인다.
  2. 가령 \(\sqrt{x} = x - 2\)를 제곱하면 \(x^2 - 5x + 4 = 0\)에서 \(x = 1, 4\)가 나오지만, \(x = 1\)은 우변이 \(-1\)이라 원래 식을 만족하지 않는다.
마무리

무리함수는 근호 안이 0 이상인 곳에서만 정의되므로, \(y = \sqrt{a(x - p)} + q\)의 그래프는 근호 안이 0이 되는 점 \((p, q)\)에서 시작해 한쪽으로만 뻗는다. 기본형 \(y = \sqrt{x}\)는 \(y = x^2\ (x \ge 0)\)의 역함수이다. 그래서 처음 질문의 텃밭은 넓이가 네 배가 되어야 변의 길이가 두 배가 되고, 그래프는 원점에서 시작해 점점 완만해진다.
