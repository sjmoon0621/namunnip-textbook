같은 범위인데 원소가 몇 개인지가 왜 달라질까?

원소의 개수 · 유한집합과 무한집합

—

\(n(A)\)
—
집합의 종류
—
\(b - a\)
—
  1. 질문\(-2 \le x \le 3\)을 만족하는 정수는 몇 개일까요? 정수가 아니라 실수라면요?
  2. 복원부등식 \(a \le x \le b\)는 수직선에서 \(a\)와 \(b\)를 포함하는 범위이고, \(a < x < b\)는 양 끝을 빼는 범위입니다. 끝을 포함하면 속이 찬 점, 빼면 빈 점으로 그립니다.
  3. 설명조건이 같은 모양이어도 \(x\)가 어떤 수인지에 따라 집합이 달라집니다. 정수만 고르면 범위 안의 눈금만 원소가 되어 유한집합이고, \(a, b\)가 정수이면 \(n(A) = b - a + 1\)입니다. 실수를 고르면 아무리 좁은 범위에도 수가 끝없이 있어 무한집합입니다. \(a > b\)이면 조건을 만족하는 수가 없어 공집합 \(\varnothing\)입니다.
  4. 연결부등식의 해를 집합으로 적는 일, 함수의 정의역을 정하는 일이 이 생각을 그대로 씁니다. 원소의 개수 \(n(A)\)는 경우의 수와 확률을 셀 때 다시 나옵니다.
  5. 적용\(a = -2, b = 3\)에서 정수의 개수를 세고 \(b - a\)와 비교하세요. 끝을 빼면 몇 개가 줄어드나요? \(a = 0.5\)처럼 끝이 정수가 아니면 공식이 그대로 맞나요? '실수'로 바꾸고 \(a = b\)로 맞추면 두 끝 모양에서 각각 무엇이 남나요?
  6. 판단"범위가 짧으면 유한집합"은 틀린 생각입니다. \(0 < x < 0.001\)인 실수도 무한히 많습니다. 유한과 무한을 가르는 것은 범위의 길이가 아니라 원소를 끝까지 셀 수 있는지입니다. 또 \(n(A) = b - a + 1\)은 양 끝이 정수이고 끝을 포함할 때만 맞습니다.

\(A = \{x \mid -2 < x \le 3, x\)는 정수\(\}\)일 때 \(n(A)\)는?
