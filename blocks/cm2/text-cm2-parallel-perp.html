두 직선의 평행과 수직

본문

직선 \(y = 2x + 1\)과 만나지 않는 직선은 어떤 식일까? 또 이 직선과 직각으로 만나는 직선의 기울기는 \(-2\)일까, \(\tfrac{1}{2}\)일까, 아니면 다른 수일까?

먼저 알아야 할 것중학교의 일차함수의 기울기와 \(y\)절편, 연립일차방정식의 해와 그래프의 교점, 두 점 사이의 거리(선분의 내분점).

1.2.1만나지 않는 두 직선

두 직선 \(y = 2x + 1\)과 \(y = 2x - 3\)의 교점을 구하려고 두 식을 같다고 놓으면 \(2x + 1 = 2x - 3\), 곧 \(0 = -4\)가 된다. 이 식을 만족하는 \(x\)는 없으므로 두 직선은 만나지 않는다. 기울기가 같아서 \(x\)가 지워졌기 때문이다.

일반적으로 \(y = m_1x + n_1\)과 \(y = m_2x + n_2\)를 연립하면 \((m_1 - m_2)x = n_2 - n_1\)이다. 그러면 \(m_1 \ne m_2\)이면 해가 하나이므로 한 점에서 만나고, \(m_1 = m_2\)이면서 \(n_1 \ne n_2\)이면 해가 없으므로 평행하며, 둘 다 같으면 모든 \(x\)가 해이므로 일치한다. 즉 처음 질문의 답은 기울기가 2이고 \(y\)절편이 1이 아닌 모든 직선이다.

정리 1.2.1 두 직선의 평행과 일치

두 직선 \(y = m_1x + n_1\), \(y = m_2x + n_2\)가 평행하면 \(m_1 = m_2,\ n_1 \ne n_2\)이고, 일치하면 \(m_1 = m_2,\ n_1 = n_2\)이다. 역도 성립한다.

1.2.2수직인 두 직선

수직 조건은 직선을 돌려서 찾는다. 원점을 지나고 기울기가 2인 직선 위에 점 \(Q(1, 2)\)를 잡자. 원점에서 오른쪽으로 1, 위로 2 가는 직각삼각형이 기울기를 만든다. 이 직각삼각형을 원점을 중심으로 \(90^\circ\) 돌리면, 가로 1이 세로 1로, 세로 2가 왼쪽으로 2 가는 가로로 바뀐다. 따라서 \(Q\)는 \(Q'(-2, 1)\)로 옮겨 간다.

돌린 직선의 기울기는 \(\dfrac{1}{-2} = -\dfrac{1}{2}\)이다. 다시 말해 역수를 취하고 부호를 바꾼 값이고, 두 기울기의 곱은 \(2 \times (-\tfrac{1}{2}) = -1\)이다. 그림 1의 슬라이더로 \(m\)을 바꾸어도 곱은 언제나 \(-1\)이다. 일반적으로 \(Q(p, q)\)가 \(Q'(-q, p)\)로 가므로 \(\dfrac{q}{p} \times \dfrac{p}{-q} = -1\)이기 때문이다.

정리 1.2.2 두 직선의 수직

두 직선 \(y = m_1x + n_1\), \(y = m_2x + n_2\)가 수직이면 \(m_1m_2 = -1\)이고, 역도 성립한다.

원점을 지나지 않는 직선도 평행이동하면 원점을 지나게 할 수 있고, 평행이동은 기울기를 바꾸지 않는다. 그래서 이 정리는 \(y\)절편과 상관없이 성립한다.1

1.2.3일반형으로 쓴 직선

직선은 \(ax + by + c = 0\)꼴로 쓸 때가 많다. \(b \ne 0\)이면 \(y = -\dfrac{a}{b}x - \dfrac{c}{b}\)이므로 기울기는 \(-\dfrac{a}{b}\)이다. 두 직선 \(ax + by + c = 0\), \(a'x + b'y + c' = 0\)이 수직이려면 \(\left(-\dfrac{a}{b}\right)\left(-\dfrac{a'}{b'}\right) = -1\)이어야 하고, 정리하면 \(aa' + bb' = 0\)이다. 이 꼴은 \(b = 0\)인 세로 직선에도 그대로 쓸 수 있다.

1.2.4예제 하나를 끝까지

예제 1.2.3

두 점 \(A(1, 2)\), \(B(5, 4)\)를 잇는 선분의 수직이등분선의 방정식을 구하여라.

수직이등분선은 선분의 중점을 지나고 선분에 수직인 직선이다. 중점은 \(\left(\dfrac{1 + 5}{2}, \dfrac{2 + 4}{2}\right) = (3, 3)\)이다. 직선 \(AB\)의 기울기는 \(\dfrac{4 - 2}{5 - 1} = \dfrac{1}{2}\)이므로, 수직인 직선의 기울기는 곱해서 \(-1\)이 되는 \(-2\)이다.

따라서 수직이등분선은 점 \((3, 3)\)을 지나고 기울기가 \(-2\)인 직선 \(y - 3 = -2(x - 3)\), 곧 \(y = -2x + 9\)이다.

확인해 보자. 이 직선 위의 점 \((4, 1)\)에서 \(A\)까지의 거리는 \(\sqrt{9 + 1} = \sqrt{10}\), \(B\)까지의 거리는 \(\sqrt{1 + 9} = \sqrt{10}\)으로 같다. 수직이등분선 위의 점은 두 끝점에서 같은 거리에 있어야 하므로 답이 맞는다. 아래 탐구 카드에서 기울기와 \(y\)절편을 바꾸며 교점이 생기고 사라지는 모습과, 직선을 돌릴 때 기울기의 곱을 직접 확인해 보자.

  1. \(m_1m_2 = -1\)은 두 기울기가 모두 있을 때만 쓸 수 있다. \(x\)축(기울기 0)과 \(y\)축(기울기가 없음)도 수직이지만 이 식으로는 확인할 수 없고, 일반형의 조건 \(aa' + bb' = 0\)을 쓰면 확인된다.
마무리

두 직선을 연립하면 기울기가 같을 때 \(x\)가 지워져 해가 없거나 무수히 많아지므로, 평행과 일치는 기울기와 \(y\)절편으로 가린다. 직선을 \(90^\circ\) 돌리면 가로와 세로가 바뀌고 부호 하나가 바뀌므로 수직인 두 직선의 기울기의 곱은 \(-1\)이다. 그래서 처음 질문의 직선 \(y = 2x + 1\)에 수직인 직선의 기울기는 \(-\tfrac{1}{2}\)이다.
