두 직선이 만나지 않으려면 무엇이 같아야 할까?

두 직선의 평행 · 일치 · 교점

위치 관계

교점
—
  1. 질문두 직선 y = 2x + 1과 y = 2x − 3은 아무리 길게 그어도 만나지 않습니다. 두 직선이 만나지 않으려면, 또 완전히 겹치려면 무엇이 같아야 할까요?
  2. 복원직선 y = mx + n에서 m은 x가 1 늘 때 y가 늘어나는 양(기울기)이고, n은 y축과 만나는 점의 y좌표(y절편)입니다. 두 직선의 교점은 두 방정식을 연립한 해입니다.
  3. 설명두 직선 y = m₁x + n₁, y = m₂x + n₂를 연립하면 (m₁ − m₂)x = n₂ − n₁입니다. m₁ ≠ m₂이면 해가 하나라서 한 점에서 만납니다. m₁ = m₂이면 좌변이 0이 되므로, n₁ ≠ n₂일 때는 해가 없어 평행하고, n₁ = n₂일 때는 모든 x가 해여서 일치합니다. 정리하면 평행 ⇔ m₁ = m₂, n₁ ≠ n₂입니다. 직선을 ax + by + c = 0, a′x + b′y + c′ = 0으로 쓰면 평행 조건은 a/a′ = b/b′ ≠ c/c′, 일치 조건은 a/a′ = b/b′ = c/c′입니다.
  4. 연결평행·일치·한 점에서 만남은 연립일차방정식의 해가 없음·무수히 많음·하나인 경우와 정확히 대응합니다. 그래프와 방정식이 같은 사실을 두 가지 말로 하고 있는 것입니다. 기울기의 곱이 −1이면 두 직선은 수직으로 만나는데, 그 까닭은 다음 카드에서 봅니다.
  5. 적용'평행한 예'를 누른 뒤 n₂만 바꾸어 보세요. 교점이 생기나요? n₂를 n₁과 같게 하면 무엇이 달라지나요? 이번에는 m₂를 m₁에 조금씩 가까이 가져가면서 교점이 어디로 달아나는지 보세요.
  6. 판단y축에 평행한 직선 x = k는 기울기가 없어서 y = mx + n 꼴로 쓸 수 없습니다. 그래도 두 직선 x = 1과 x = 3은 평행합니다. 일반형 조건을 쓰면 이런 경우도 다룰 수 있습니다. 다만 분모가 0이 되는 계수가 있으면 비의 꼴 대신 ab′ − a′b = 0처럼 곱의 꼴로 확인합니다.
