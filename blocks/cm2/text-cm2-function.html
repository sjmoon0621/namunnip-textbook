함수

본문

자판기에서 버튼 하나를 누르면 음료 하나가 나온다. 그런데 어떤 버튼을 누를 때마다 다른 음료가 나온다면 그 자판기는 믿을 수 없다. 수학의 함수는 이 '믿을 수 있는 자판기'와 같은데, 정확히 어떤 조건을 갖추어야 할까?

먼저 알아야 할 것집합과 원소(집합의 뜻과 표현), 순서쌍과 좌표, 중학교의 일차함수와 이차함수의 그래프.

3.1.1대응과 함수

두 집합 \(X\), \(Y\)에서 \(X\)의 원소에 \(Y\)의 원소를 짝지어 주는 것을 \(X\)에서 \(Y\)로의 대응이라 한다. 그림 1에서 화살표 하나가 짝 하나이다. 대응 가운데 \(X\)의 각 원소에 \(Y\)의 원소가 오직 하나씩 대응하는 것을 \(X\)에서 \(Y\)로의 함수라 하고 \(f: X \to Y\)로 쓴다.

조건은 두 가지이다. \(X\)의 원소는 하나도 빠짐없이 화살표를 가져야 하고, 각 원소에서 나가는 화살표는 하나뿐이어야 한다. 그림 1의 슬라이더로 대응을 바꾸어 보면, 화살표가 없는 원소가 있거나 한 원소에서 화살표가 둘 나가면 함수가 아니다. 그런데 \(Y\)의 원소 하나에 화살표가 여러 개 들어오는 것은 괜찮다. 다른 버튼에서 같은 음료가 나와도 자판기는 믿을 수 있기 때문이다.

정의 3.1.1 정의역, 공역, 치역

함수 \(f: X \to Y\)에서 \(X\)를 정의역, \(Y\)를 공역이라 한다. \(x\)에 대응하는 \(Y\)의 원소를 \(f(x)\)로 쓰고 함숫값이라 하며, 함숫값 전체의 집합 \(\{f(x) \mid x \in X\}\)를 치역이라 한다.

치역은 공역의 부분집합이다. 공역은 '나올 수 있는 후보'이고 치역은 '실제로 나온 것'이다. 자판기로 말하면 공역은 진열된 음료 목록, 치역은 버튼으로 실제 받을 수 있는 음료이다.1

3.1.2그래프로 보는 함수

함수 \(f\)의 그래프는 순서쌍 \((x, f(x))\) 전체의 집합이다. 정의역과 공역이 실수의 집합이면 이 순서쌍을 좌표평면에 점으로 찍을 수 있다. 그러면 함수의 조건 '\(x\) 하나에 \(y\) 하나'는 그래프에서 '세로선 하나에 점 하나'가 된다.

그림 2의 원 \(x^2 + y^2 = 1\)은 \(x = 0.5\)에서 \(y = \pm\dfrac{\sqrt{3}}{2}\) 두 값을 가지므로 \(x\)의 함수가 아니다. 하지만 위쪽 반원 \(y = \sqrt{1 - x^2}\)만 떼어 내면 함수가 된다.

3.1.3일대일함수와 일대일대응

함수 가운데 서로 다른 \(x\)에 서로 다른 함숫값이 대응하는 것을 일대일함수라 한다. 여기에 치역과 공역이 같다는 조건까지 갖추면 일대일대응이라 한다. 일대일대응에서는 \(Y\)의 원소마다 화살표가 정확히 하나씩 들어온다. 이 성질은 뒤의 역함수에서 쓰인다.

3.1.4예제 하나를 끝까지

예제 3.1.2

\(X = \{-1, 0, 1, 2\}\)에서 \(Y = \{0, 1, 2, 3, 4\}\)로의 함수 \(f(x) = x^2\)의 치역을 구하고, \(f\)가 일대일함수인지 판별하여라. 또 두 함수 \(f(x) = x^2\)과 \(g(x) = |x|\)가 정의역 \(\{-1, 0, 1\}\)에서 서로 같은지 판별하여라.

함숫값은 \(f(-1) = 1\), \(f(0) = 0\), \(f(1) = 1\), \(f(2) = 4\)이므로 치역은 \(\{0, 1, 4\}\)이다. 공역에 있는 2와 3은 치역에 들지 않는다. 또 \(-1 \ne 1\)인데 \(f(-1) = f(1)\)이므로 일대일함수가 아니다.

두 함수가 서로 같다는 것은 정의역과 공역이 같고, 정의역의 모든 원소에서 함숫값이 같다는 뜻이다. \(\{-1, 0, 1\}\)에서 \(x^2\)과 \(|x|\)는 각각 \(1, 0, 1\)로 모든 값이 같으므로 두 함수는 서로 같다. 식의 모양이 달라도 대응이 같으면 같은 함수이다.

정의역을 \(\{-1, 0, 1, 2\}\)로 넓히면 \(f(2) = 4\), \(g(2) = 2\)로 달라져서 더 이상 같은 함수가 아니다. 즉 함수는 식만이 아니라 정의역까지 함께 정해야 정해진다. 아래 탐구 카드에서 화살표와 그래프를 직접 조작하며 함수의 조건을 확인해 보자.

  1. 정의역과 공역을 따로 말하지 않고 \(y = f(x)\)로만 쓰면, 정의역은 \(f(x)\)가 정의되는 실수 전체, 공역은 실수 전체로 본다.
마무리

함수는 정의역의 원소마다 공역의 원소가 정확히 하나씩 대응하는 규칙이다. 그래프로는 세로선이 그래프와 한 점에서만 만나는 것이고, 공역의 한 원소에 여러 원소가 대응하는 것은 허용된다. 그래서 처음 질문의 자판기가 믿을 수 있으려면 버튼마다 음료가 정확히 하나씩 나와야 하고, 서로 다른 버튼이 같은 음료를 내는 것은 괜찮다.
