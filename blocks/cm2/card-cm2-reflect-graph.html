원래 도형 위의 점 Q를 도형을 따라 끌어 보세요.

  1. 질문원 (x − 3)2 + (y − 1)2 = 4를 x축에 대해 뒤집으면 중심이 (3, −1)인 원이 됩니다. 식을 어떻게 바꾸면 이 결과가 바로 나올까요? 직선 y = x에 대해 뒤집으면 어떨까요?
  2. 복원점의 대칭이동 규칙: x축 (x, −y), y축 (−x, y), 원점 (−x, −y), 직선 y = x (y, x). 평행이동에서는 옮긴 점에서 거꾸로 원래 점으로 돌아가 원래 식에 넣었습니다.
  3. 설명대칭이동한 도형 위의 점 (x, y)를 다시 같은 기준으로 대칭이동하면 원래 도형 위의 점이 됩니다. 대칭이동은 두 번 하면 제자리이기 때문입니다. 그래서 방정식 f(x, y) = 0이 나타내는 도형을 대칭이동한 도형의 방정식은 x축: f(x, −y) = 0, y축: f(−x, y) = 0, 원점: f(−x, −y) = 0, 직선 y = x: f(y, x) = 0입니다. 점의 규칙과 같은 꼴로 바꾸면 되므로 평행이동보다 헷갈릴 일이 적습니다.
  4. 연결y축 대칭으로 식이 바뀌지 않는 도형(y = x2 등)은 y축에 대해 대칭이고, 원점 대칭으로 바뀌지 않는 도형(y = x3 등)은 원점에 대해 대칭입니다. 이 생각은 함수의 그래프 모양을 판단할 때 다시 쓰입니다. 평행이동과 대칭이동을 차례로 하는 문제는 한 단계씩 식을 바꾸면 됩니다.
  5. 적용원을 고르고 네 기준을 차례로 눌러 새 식의 중심이 어디로 가는지 보세요. 포물선을 x축에 대해 대칭이동하면 그래프의 볼록한 방향은 어떻게 되나요? 직선을 y = x에 대해 대칭이동한 직선의 기울기는 원래 기울기와 어떤 관계인가요?
  6. 판단x축 대칭에서는 y만 −y로 바꿉니다. y = 2x − 3에서 −y = 2x − 3이 되고, 정리하면 y = −2x + 3입니다. 우변의 부호만 바꾸거나 좌변만 바꾸고 정리를 빠뜨리는 실수가 흔합니다. 직선 y = x 대칭은 x와 y를 맞바꾸는 것이지, 부호를 바꾸는 것이 아닙니다.
