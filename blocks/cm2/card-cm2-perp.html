수직인 두 직선의 기울기는 어떤 관계일까?

두 직선의 수직 · 기울기의 곱

—

ℓ₁ 기울기 m₁
—
ℓ₂ 기울기 m₂
—
m₁ × m₂
—

점 Q를 끌어 직선 ℓ₁의 방향을 바꾸세요. Q′은 Q를 원점을 중심으로 90° 돌린 점이고, ℓ₂는 원점과 Q′을 지납니다.

  1. 질문기울기가 2인 직선에 수직인 직선의 기울기는 얼마일까요? −2일까요, 1/2일까요, 아니면 다른 수일까요?
  2. 복원기울기는 (세로 변화량)/(가로 변화량)입니다. 직각삼각형을 90° 돌리면 가로 변과 세로 변이 서로 자리를 바꾼, 합동인 직각삼각형이 됩니다.
  3. 설명원점을 지나는 직선 ℓ₁ 위의 점 Q(p, q)를 원점을 중심으로 90° 돌리면 Q′(−q, p)가 됩니다. 그림의 두 직각삼각형은 합동이고, 가로와 세로가 바뀌면서 한쪽 부호가 바뀝니다. 그래서 m₁ = q/p, m₂ = p/(−q)이고 m₁m₂ = −1입니다. 거꾸로 기울기의 곱이 −1이면 두 직선은 수직입니다. 원점을 지나지 않는 직선도 평행이동하면 기울기가 그대로이므로 같은 조건이 성립합니다. 일반형 ax + by + c = 0과 a′x + b′y + c′ = 0에서는 수직 ⇔ aa′ + bb′ = 0입니다.
  4. 연결수직 조건은 선분의 수직이등분선을 구할 때, 점에서 직선에 내린 수선의 발을 구할 때 쓰입니다. 점과 직선 사이의 거리, 원의 접선(접점에서 반지름과 수직), 대칭이동에서 대칭축을 찾는 일이 모두 이 조건 위에 있습니다.
  5. 적용Q를 (2, 1), (1, 3), (−3, 2)로 옮기며 m₁ × m₂가 늘 −1인지 보세요. Q를 x축 위 (3, 0)으로 옮기면 무엇이 달라지나요? 아래 식에서 aa′ + bb′도 함께 확인하세요.
  6. 판단역수만 취해 1/2로 답하는 실수가 흔합니다. 수직인 직선의 기울기는 역수에 부호까지 바꾼 −1/m₁입니다. 또 m₁m₂ = −1은 두 기울기가 모두 있을 때만 쓸 수 있습니다. x축(기울기 0)과 y축(기울기 없음)도 수직이지만 곱을 만들 수 없습니다. 이럴 때는 aa′ + bb′ = 0으로 확인합니다.
