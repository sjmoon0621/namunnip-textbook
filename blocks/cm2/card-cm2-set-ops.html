두 집합으로 새 집합을 만드는 방법은 몇 가지일까?

집합의 연산 · 벤 다이어그램

—

\(n(A), n(B)\)
—
\(n(A \cap B)\)
—
\(n(A \cup B)\)
—

—

  1. 질문12 이하의 자연수 가운데 2의 배수이거나 3의 배수인 수는 몇 개일까요? 2의 배수 6개와 3의 배수 4개를 더해 10개라고 하면 맞을까요?
  2. 복원\(A \subset B\)는 \(A\)의 모든 원소가 \(B\)에 있다는 뜻입니다. 벤 다이어그램에서 사각형은 생각하는 대상 전체, 원은 각 집합입니다.
  3. 설명\(A\) 또는 \(B\)에 속하는 원소 전체가 합집합 \(A \cup B, A\)와 \(B\)에 모두 속하는 원소 전체가 교집합 \(A \cap B\)입니다. \(A \cap B = \varnothing\)이면 \(A\)와 \(B\)는 서로소입니다. 생각하는 대상 전체를 전체집합 \(U\)라 할 때, \(U\)의 원소 가운데 \(A\)에 속하지 않는 것 전체가 여집합 \(A^C\)이고, \(A\)에는 속하지만 \(B\)에는 속하지 않는 것 전체가 차집합 \(A - B\)입니다. \(A - B = A \cap B^C\)입니다. 합집합의 원소를 셀 때 \(A\)와 \(B\)를 그냥 더하면 \(A \cap B\)를 두 번 세므로 \(n(A \cup B) = n(A) + n(B) - n(A \cap B)\)입니다.
  4. 연결이 개수 공식은 확률의 덧셈정리 \(P(A \cup B) = P(A) + P(B) - P(A \cap B)\)와 같은 모양입니다. 여집합은 명제에서 조건의 부정 '\({\sim}p\)'의 진리집합이 됩니다.
  5. 적용첫 번째 집합 쌍에서 \(A \cup B\)를 고르고 \(n(A) + n(B)\)와 \(n(A \cup B)\)의 차이를 확인하세요. \(A - B\)와 \(A \cap B^C\)를 번갈아 눌러 보고, \((A \cup B)^C\)와 \(A^C \cap B^C\)도 비교해 보세요. 세 번째 쌍에서는 무엇이 달라지나요? 네 번째 쌍에서 \(A - B\)는 무엇인가요?
  6. 판단여집합은 전체집합이 정해져야 뜻이 생깁니다. 같은 \(A = \{2, 4\}\)라도 \(U = \{1, 2, 3, 4\}\)이면 \(A^C = \{1, 3\}\)이고, \(U = \{1, 2, \cdots, 12\}\)이면 원소가 10개입니다. 또 \(A - B\)와 \(B - A\)는 일반적으로 다릅니다.

전체집합 \(U\)에 대하여 \(n(U) = 30, n(A) = 12, n(B) = 15, n(A \cap B) = 5\)일 때 \(n(A^C \cap B^C)\)는?
