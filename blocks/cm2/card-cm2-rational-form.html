'다음 단계'를 눌러 식을 y = k/(x − p) + q 꼴로 고치면 점근선이 나타납니다. 계수를 바꾼 뒤 처음부터 다시 따라가 보세요.

  1. 질문y = (2x + 1)/(x − 1)의 그래프를 그리려고 합니다. 이 식만 보고는 점근선이 바로 보이지 않습니다. 이미 아는 꼴로 바꿀 수 있을까요?
  2. 복원y = k/(x − p) + q(k ≠ 0)의 그래프는 y = k/x를 평행이동한 것으로, 점근선은 x = p, y = q입니다. 다항식의 나눗셈 A = BQ + R에서 양변을 B로 나누면 A/B = Q + R/B입니다.
  3. 설명분자를 분모로 나누어 몫과 나머지로 씁니다. 예를 들어 2x + 1 = 2(x − 1) + 3이므로 (2x + 1)/(x − 1) = 2 + 3/(x − 1)입니다. 그래서 점근선은 x = 1, y = 2입니다. 일반적으로 c ≠ 0이면 세로 점근선은 분모가 0이 되는 x = −d/c, 가로 점근선은 x의 계수의 비 y = a/c입니다. 이때 k = (bc − ad)/c2이므로, bc − ad = 0이면 분자가 분모의 상수배라 y는 상수 a/c가 됩니다. 이 경우 그래프는 직선에서 x = −d/c인 한 점이 빠진 모양입니다.
  4. 연결이 방법은 다항식의 나눗셈 그대로입니다. c = 0이면 분모가 상수라 다항함수(일차함수)가 됩니다. 유리식의 덧셈·뺄셈과 약분도 같은 도구로 다룹니다.
  5. 적용처음 식에서 단계를 끝까지 넘겨 점근선 x = 1, y = 2를 확인하세요. a만 바꾸면 어느 점근선이 움직이나요? d만 바꾸면요? a = 2, c = 1, d = −1일 때 그래프가 직선으로 바뀌는 b를 찾고, 그때 빠지는 점의 좌표를 읽어 보세요.
  6. 판단가로 점근선을 "상수항의 비 b/d"로 잡는 실수가 흔합니다. b/d는 x = 0일 때의 값, 곧 y절편입니다. |x|가 아주 커지면 상수항은 무시되고 ax/cx = a/c에 가까워집니다. 또 약분해서 상수가 되더라도 원래 식의 분모를 0으로 만드는 x는 정의역에서 빠집니다.
