\(n^2\)이 짝수이면 \(n\)도 짝수임을 어떻게 증명할까?

대우를 이용한 증명 · 넓이 모형

—

\(n\)을 \(m\)으로 나눈 나머지
—
\(n^2\)을 \(m\)으로 나눈 나머지
—
구석 \(r^2\) 조각
—

—

  1. 질문"자연수 \(n\)에 대하여 \(n^2\)이 짝수이면 \(n\)은 짝수이다"를 증명하고 싶습니다. \(n^2 = 2k\)로 놓으면 \(n = \sqrt{2k}\)가 되어 더 나아갈 수 없습니다. 어떻게 해야 할까요?
  2. 복원명제와 그 대우는 참·거짓이 같습니다. 자연수 \(n\)을 \(m\)으로 나누면 \(n = mk + r (0 \le r < m)\)로 쓸 수 있습니다.
  3. 설명원래 명제 대신 대우 "\(n\)이 홀수이면 \(n^2\)은 홀수이다"를 증명합니다. \(n = 2k + 1\)이면 \(n^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1\)이므로 홀수입니다. 대우가 참이므로 원래 명제도 참입니다. 이것이 대우를 이용한 증명법입니다. 그림에서 한 변이 \(n = mk + r\)인 정사각형은 \((mk)^2\) 조각, \(mk \times r\) 띠 두 개, \(r \times r\) 구석으로 나뉩니다. 앞의 세 조각은 넓이가 모두 \(m\)의 배수이므로, \(n^2\)을 \(m\)으로 나눈 나머지는 구석 \(r^2\)이 정합니다.
  4. 연결이 결과는 바로 다음 카드의 귀류법에서 "\(p^2\)이 짝수이므로 \(p\)도 짝수"라는 단계로 쓰입니다. 결론이 '~가 아니다' 꼴이거나 가정에서 결론으로 가는 길이 막힐 때 대우를 떠올리면 좋습니다.
  5. 적용\(m = 2\)에서 \(n\)을 바꾸며 구석 조각을 보세요. \(n\)이 홀수이면 구석은 늘 몇 칸인가요? \(m = 3\)으로 바꾸어 \(r = 1, 2\)일 때 구석의 넓이를 3으로 나눈 나머지를 확인하세요. \(m = 4\)에서 \(n = 2, 6, 10\)은 무엇을 알려 주나요? 각 경우에 '증명 다음 단계'를 끝까지 눌러 보세요.
  6. 판단대우를 이용한 증명이 언제나 통하는 것은 아닙니다. 명제가 거짓이면 대우도 거짓이어서 증명이 막힙니다. \(m = 4\)에서 \(n = 2\)이면 \(n^2 = 4\)는 4의 배수이지만 2는 4의 배수가 아니므로, "\(n^2\)이 4의 배수이면 \(n\)은 4의 배수"는 거짓입니다. 증명 단계에서 막히면 반례를 찾아보세요.
