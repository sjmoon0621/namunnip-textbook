역함수

본문

섭씨온도 \(x\)를 화씨온도로 바꾸는 식은 \(y = 1.8x + 32\)이다. 화씨 77도는 섭씨 몇 도일까? 이렇게 결과에서 원래 값을 되찾는 함수를 만들 수 있을까? 그리고 \(y = x^2\)처럼 되찾을 수 없는 경우는 무엇이 다를까?

먼저 알아야 할 것일대일대응(함수), 합성함수와 항등함수(합성함수), 직선 \(y = x\)에 대한 대칭이동(대칭이동).

3.3.1화살표를 거꾸로

화씨 77도에서 섭씨를 구하려면 \(77 = 1.8x + 32\)를 풀면 된다. \(x = \dfrac{77 - 32}{1.8} = 25\)이다. 어떤 화씨온도 \(y\)에 대해서도 같은 계산이 되므로, \(x = \dfrac{y - 32}{1.8}\)이라는 새 함수가 생긴다. 이것은 원래 함수의 화살표를 모두 거꾸로 돌린 대응이다.

그런데 \(y = x^2\)에서는 화살표를 거꾸로 돌리면 문제가 생긴다. \(y = 4\)에서 거꾸로 가면 \(x = 2\)와 \(x = -2\) 두 곳으로 가므로, 하나의 값에 두 값이 대응하여 함수가 아니게 된다. 거꾸로 돌린 대응이 함수가 되려면 원래 함수가 서로 다른 \(x\)를 같은 \(y\)로 보내지 않아야 하고, 공역의 모든 원소가 어딘가에서 와야 한다. 즉 원래 함수가 일대일대응이어야 한다.

정의 3.3.1 역함수

함수 \(f: X \to Y\)가 일대일대응일 때, \(Y\)의 각 원소 \(y\)에 \(f(x) = y\)인 \(X\)의 원소 \(x\)를 대응시키는 함수를 \(f\)의 역함수라 하고 \(f^{-1}: Y \to X\)로 나타낸다. \[y = f(x) \iff x = f^{-1}(y)\]

정의에 따라 \(f^{-1}(f(x)) = x\)이고 \(f(f^{-1}(y)) = y\)이다. 다시 말해 \(f\)를 한 뒤 \(f^{-1}\)를 하면 제자리로 돌아오므로, \(f^{-1} \circ f\)는 항등함수이다.1

3.3.2역함수 구하기와 그래프

역함수를 식으로 구할 때는 \(y = f(x)\)를 \(x\)에 대해 푼 뒤, 습관대로 독립변수를 \(x\), 종속변수를 \(y\)로 쓰도록 \(x\)와 \(y\)를 맞바꾼다. 화씨 예에서는 \(x = \dfrac{y - 32}{1.8}\)을 \(y = \dfrac{x - 32}{1.8}\)로 바꾸어 쓴다.

\(x\)와 \(y\)를 맞바꾸면 그래프 위의 점 \((a, b)\)는 \((b, a)\)로 옮겨 간다. 대칭이동에서 본 것처럼 이것은 직선 \(y = x\)에 대한 대칭이다. 따라서 역함수의 그래프는 원래 그래프를 \(y = x\)에 대칭이동한 것이다. 그림 1의 슬라이더로 점을 옮기면 짝이 되는 점이 \(y = x\) 건너편에서 함께 움직인다.

3.3.3예제 하나를 끝까지

예제 3.3.2

함수 \(f(x) = 2x - 4\)의 역함수를 구하고, \(f^{-1}(6)\)과 \((f^{-1} \circ f)(3)\)을 구하여라. 또 \(y = f(x)\)와 \(y = f^{-1}(x)\)의 그래프의 교점을 구하여라.

\(y = 2x - 4\)를 \(x\)에 대해 풀면 \(x = \dfrac{y + 4}{2}\)이다. \(x\)와 \(y\)를 바꾸면 \(f^{-1}(x) = \dfrac{x + 4}{2}\)이다. 그러면 \(f^{-1}(6) = 5\)이고, 실제로 \(f(5) = 6\)이므로 맞는다.

\((f^{-1} \circ f)(3)\)은 \(f(3) = 2\)를 \(f^{-1}\)에 넣은 \(f^{-1}(2) = 3\)이다. 처음 값 3으로 돌아왔다.

두 그래프는 \(y = x\)에 대칭이므로, 교점을 찾을 때는 \(y = f(x)\)와 \(y = x\)의 교점을 먼저 본다. \(2x - 4 = x\)에서 \(x = 4\)이므로 교점은 \((4, 4)\)이다. 두 직선 \(y = 2x - 4\)와 \(y = \tfrac{x + 4}{2}\)를 직접 연립해도 \(4x - 8 = x + 4\)에서 \(x = 4\)로 같다.2 아래 탐구 카드에서 화살표를 거꾸로 돌리며 역함수가 생기는 조건을 직접 확인해 보자.

  1. \(f^{-1}\)의 \(-1\)은 거듭제곱이 아니다. \(f^{-1}(x)\)와 \(\tfrac{1}{f(x)}\)는 다르다.
  2. 증가하는 함수에서는 두 그래프의 교점이 항상 \(y = x\) 위에 있지만, 감소하는 함수에서는 \(y = x\) 밖에도 교점이 생길 수 있다. \(f(x) = -x + 1\)은 역함수가 자기 자신이라 두 그래프가 완전히 겹친다.
마무리

함수의 화살표를 거꾸로 돌린 대응이 다시 함수가 되려면 원래 함수가 일대일대응이어야 하고, 그때 생기는 함수가 역함수이다. 역함수는 \(x\)와 \(y\)를 맞바꾸어 구하므로 그래프는 \(y = x\)에 대칭이다. 그래서 처음 질문의 화씨 77도는 역함수 \(y = \tfrac{x - 32}{1.8}\)에 넣어 섭씨 25도이고, \(y = x^2\)은 한 값에 두 원래 값이 있어 정의역을 제한해야 되찾을 수 있다.
