  2. 복원두 수 묶음의 같은 위치끼리 곱해 모두 더하는 계산은 코사인 유사도를 구할 때 분자에서 했던 계산과 같다.
    3. 
      
  3. 설명3×3 행렬 \(K\)(필터)를 이미지 위에 올려, 겹치는 9개 성분끼리 곱해 더한 값을 가운데 픽셀의 새 값으로 한다. 이것을 모든 픽셀에서 반복하는 계산을 합성곱이라 한다. 9칸이 모두 \(\frac19\)이면 평균이라 흐려지고, 위쪽 행은 음수, 아래쪽 행은 양수(예를 들어 \(-1, -2, -1\)과 \(1, 2, 1\))이면 위아래 밝기 차이가 큰 곳, 곧 가로 윤곽에서 값이 커진다.
    4. 
      
  4. 연결이미지를 다루는 인공지능(합성곱 신경망)은 필터의 9개 수를 사람이 정하지 않고 자료로 학습한다. 그래서 처음 층은 윤곽을, 다음 층은 모양을, 더 깊은 층은 물체를 알아보는 필터가 학습된다.
    5. 
      
  5. 적용필터를 바꿔 결과를 비교하고, 원래 이미지를 눌러 한 픽셀의 계산을 따라가 보자. 그다음 필터 성분을 직접 바꿔 대각선 윤곽을 찾는 필터를 만들어 보자.
