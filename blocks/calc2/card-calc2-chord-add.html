\(\cos(\alpha - \beta)\)를 \(\alpha\), \(\beta\)의 삼각함수로 나타낼 수 있을까?

덧셈정리 · 단계별 증명
\(PQ^2\) (좌표로)
—
\(AB^2 = 2 - 2\cos(\alpha-\beta)\)

\(\cos(\alpha - \beta)\)

\(\cos \alpha \cos \beta + \sin \alpha \sin \beta\)

—

\(P(\cos \alpha, \sin \alpha)\), \(Q(\cos \beta, \sin \beta)\), \(A(1, 0)\), \(B(\cos(\alpha - \beta), \sin(\alpha - \beta))\)입니다. 초록 현 \(PQ\)와 주황 현 \(AB\)의 길이를 비교하세요.

  1. 질문\(\cos 15^\circ\)는 특수각이 아닙니다. \(15^\circ = 45^\circ - 30^\circ\)이니 \(\cos 45^\circ\)와 \(\cos 30^\circ\)만으로 구할 수 있을까요? \(\cos(\alpha - \beta) = \cos \alpha - \cos \beta\)일까요?
  2. 복원단위원 위에서 각 \(\theta\)를 나타내는 점은 \((\cos \theta, \sin \theta)\)입니다. 두 점 사이의 거리는 \(\sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}\)이고, \(\sin^2 \theta + \cos^2 \theta = 1\)입니다.
  3. 설명① 좌표로 계산하면 \(PQ^2 = (\cos \alpha - \cos \beta)^2 + (\sin \alpha - \sin \beta)^2 = 2 - 2(\cos \alpha \cos \beta + \sin \alpha \sin \beta)\)입니다. ② 삼각형 \(OPQ\)를 원점을 중심으로 \(-\beta\)만큼 돌리면 \(Q\)는 \(A(1, 0)\)로, \(P\)는 \(B(\cos(\alpha - \beta), \sin(\alpha - \beta))\)로 갑니다. 돌려도 길이는 그대로이므로 \(PQ^2 = AB^2 = 2 - 2\cos(\alpha - \beta)\)입니다. ③ 두 식을 비교하면 \(\cos(\alpha - \beta) = \cos \alpha \cos \beta + \sin \alpha \sin \beta\)입니다. \(\beta\) 자리에 \(-\beta\)를 넣으면 \(\cos(\alpha + \beta) = \cos \alpha \cos \beta - \sin \alpha \sin \beta\), \(\sin \theta = \cos(90^\circ - \theta)\)를 쓰면 \(\sin(\alpha \pm \beta) = \sin \alpha \cos \beta \pm \cos \alpha \sin \beta\), 두 식을 나누면 \(\tan(\alpha \pm \beta) = \frac{\tan \alpha \pm \tan \beta}{1 \mp \tan \alpha \tan \beta}\)입니다. 이것을 덧셈정리라고 합니다.
  4. 연결\(\beta = \alpha\)로 두면 배각 공식 \(\sin 2\alpha = 2 \sin \alpha \cos \alpha\), \(\cos 2\alpha = \cos^2 \alpha - \sin^2 \alpha = 2\cos^2 \alpha - 1 = 1 - 2\sin^2 \alpha\), \(\tan 2\alpha = \frac{2\tan \alpha}{1 - \tan^2 \alpha}\)가 나옵니다. 다음 절에서는 \(\sin(x + h)\)를 덧셈정리로 펼쳐 \(\sin x\)의 도함수를 구합니다.
  5. 적용\(\alpha\)와 \(\beta\)를 여러 값으로 바꾸고 '돌리기'를 눌러 보세요. 초록 삼각형이 어디에 겹치나요? \(PQ^2\)과 \(AB^2\)은 언제나 같나요? '\(\alpha = 45^\circ\), \(\beta = 30^\circ\)'를 눌러 \(\cos 15^\circ\)의 값과 아래 식의 \(\cos \alpha - \cos \beta\)를 비교하세요.
  6. 판단삼각함수는 일차식이 아니므로 \(\cos(\alpha + \beta) = \cos \alpha + \cos \beta\), \(\sin 2\alpha = 2 \sin \alpha\) 같은 분배는 성립하지 않습니다. \(\alpha = \beta = 60^\circ\)이면 \(\cos 120^\circ = -\frac{1}{2}\)이지만 \(\cos 60^\circ + \cos 60^\circ = 1\)입니다. 또 \(\tan\)의 덧셈정리는 \(\tan \alpha\), \(\tan \beta\), \(\tan(\alpha \pm \beta)\)가 모두 정의될 때만 씁니다.
