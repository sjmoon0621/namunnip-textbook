  1. 질문(3n+1 + 2n)/(3n + 2n)은 분자와 분모가 모두 한없이 커집니다. 3n과 2n 가운데 어느 쪽이 극한값을 정할까요?
  2. 복원−1 < r < 1이면 lim rn = 0입니다. 분자와 분모가 모두 발산하는 분수식은 분모의 '가장 빨리 커지는 부분'으로 나누어 수렴하는 꼴로 바꾸었습니다.
  3. 설명밑이 다른 거듭제곱이 섞이면, 밑의 절댓값이 가장 큰 거듭제곱으로 분자와 분모를 나눕니다. 3n으로 나누면 (3 + (2/3)n)/(1 + (2/3)n)이 되고, 0 < 2/3 < 1이므로 (2/3)n → 0입니다. 그래서 극한값은 3/1 = 3입니다. 일반적으로 a > b > 0이면 bn/an = (b/a)n → 0이므로, 큰 밑의 거듭제곱 앞에 붙은 계수끼리의 비가 극한값이 됩니다.
  4. 연결이 방법은 ∞/∞ 꼴 다항식에서 최고차항으로 나눈 것과 같은 생각입니다. 다항식에서는 차수가 높은 항이, 거듭제곱에서는 밑이 큰 항이 결국 나머지를 압도합니다. 또 x가 들어간 lim (x2n+1 + 1)/(x2n + 1) 같은 식은 |x| < 1, |x| = 1, |x| > 1로 나누어 같은 방법으로 구합니다.
  5. 적용a = 3, b = 2에서 n을 30까지 옮기며 (2/3)n이 0에 가까워지는 것을 확인하세요. a와 b를 바꾸어 a < b로 만들면 극한은 왜 1이 되나요? a = b일 때 극한이 (a + 1)/2인 이유를 식으로 설명해 보세요. a = 4, b = 5처럼 두 밑이 가까우면 수렴이 느린 이유도 (작은 밑/큰 밑)n 값에서 찾아보세요.
  6. 판단작은 밑의 거듭제곱으로 나누면 (3/2)n처럼 발산하는 항이 남아 몫의 성질을 쓸 수 없습니다. 또 3n+1은 3 · 3n이므로, 나눈 뒤 남는 계수 3을 빠뜨리지 않아야 합니다. 22n처럼 지수에 계수가 붙으면 4n으로 고쳐 밑을 비교합니다.
