직사각형은 고른 정적분의 구간을 n등분하고 오른쪽 끝의 높이를 쓴 것입니다. 첫째 값과 둘째 값이 n마다 똑같은지 보세요.

  1. 질문lim ∑k=1n (2/n)(1 + 2k/n)2를 정적분으로 바꾸는 방법은 하나뿐일까요?
  2. 복원구간 [a, b]를 n등분하면 Δx = (b − a)/n, xk = a + kΔx이고 lim ∑ f(xk)Δx = ∫ab f(x) dx입니다.
  3. 설명2/n을 Δx로 보면 구간 길이는 2입니다. xk = 1 + 2k/n으로 읽으면 x는 1에서 3까지 움직이고 높이는 x2이므로 ∫13 x2 dx입니다. xk = 2k/n으로 읽으면 높이는 (1 + x)2이고 구간은 [0, 2]입니다. 1/n을 Δx로 보면 남은 2는 높이에 들어가 ∫01 2(1 + 2x)2 dx가 됩니다. 세 해석은 직사각형의 넓이가 하나하나 같으므로 모두 같은 값 26/3을 줍니다. 핵심은 Δx, xk, f를 하나의 짝으로 맞추어 읽는 것입니다.
  4. 연결세 정적분이 같은 것은 치환적분으로도 확인됩니다. ∫13 x2 dx에서 x = 1 + t로 놓으면 ∫02 (1 + t)2 dt, x = 1 + 2s로 놓으면 ∫01 2(1 + 2s)2 ds입니다. 급수의 합을 정적분으로 바꾸는 일과 변수를 바꾸는 일은 같은 생각입니다.
  5. 적용네 해석을 차례로 골라 첫째 값과 둘째 값을 비교하세요. 어느 해석에서 두 값이 어긋나나요? n을 60까지 늘리면 Sn는 어떤 수에 다가가나요? 26/3 ≈ 8.667과 비교해 보세요.
  6. 판단2/n을 너비로 정했다면 구간 길이는 2이고 xk도 2/n 간격으로 움직여야 합니다. 넷째 해석처럼 구간만 [0, 2]로 정하고 높이에서 1을 빠뜨리면 다른 값 8/3이 됩니다. 너비와 구간 길이, xk의 간격이 서로 맞는지 꼭 확인하세요.
