화살표는 각 매개변수로 잰 속도 (dx/dt, dy/dt)를 0.15배로 줄여 그렸습니다. 파랑 A, 주황 B, 붉은색 C입니다. 점 P는 그림을 가로로 끌어도 움직입니다.

  1. 질문A: x = t, y = t2, B: x = 2t, y = 4t2, C: x = t3, y = t6은 모두 같은 곡선을 그립니다. 같은 점에서 세 방법으로 구한 dy/dx도 같을까요?
  2. 복원매개변수로 나타낸 함수에서 dx/dt ≠ 0이면 dy/dx = (dy/dt)/(dx/dt)입니다. y = x2의 도함수는 2x입니다.
  3. 설명세 식에서 t를 없애면 모두 y = x2이 됩니다. 이렇게 매개변수를 없애 x, y의 관계식을 얻는 것을 매개변수의 소거라고 합니다. 매개변수는 같은 길을 어떤 빠르기로 지나가는지를 정할 뿐이므로, dx/dt와 dy/dt는 매개변수마다 다르지만 두 값이 같은 비율로 커지고 작아집니다. 예를 들어 B에서는 dx/dt = 2, dy/dt = 8t이고 t = x/2이므로 dy/dx = 4t = 2x입니다. 그래서 접선의 기울기는 곡선이 정하는 값이고 매개변수를 고르는 방법과 상관없습니다.
  4. 연결매개변수를 쉽게 소거할 수 있으면 y를 x의 식으로 고쳐 미분해도 되고, 소거하기 어려우면 (dy/dt)/(dx/dt)를 씁니다. 두 방법의 결과는 같으므로 하나로 구하고 다른 하나로 검산할 수 있습니다.
  5. 적용P를 옮기며 세 줄의 dx/dt, dy/dt와 dy/dx를 비교하세요. 화살표의 길이는 다른데 방향은 어떤가요? P를 x = 0으로 옮기면 C의 줄은 어떻게 되나요? 그때도 접선은 있나요?
  6. 판단C에서 x = 0이면 dx/dt = dy/dt = 0이라 공식이 0/0이 됩니다. 그렇다고 접선이 없는 것은 아닙니다. 곡선은 같은 y = x2이고 원점의 접선은 x축입니다. 매개변수의 속도가 0이 된 것은 그 순간 점이 멈춘 것일 뿐, 곡선의 모양이 바뀐 것이 아닙니다. 또 매개변수를 소거할 때는 t의 범위에 따라 x의 범위가 제한될 수 있습니다. x = t2, y = t4이면 y = x2의 x ≥ 0인 부분만 그립니다.
