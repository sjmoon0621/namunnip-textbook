넓이는 삼각형 OAP = ½ sin x, 부채꼴 OAP = ½ x, 삼각형 OAT = ½ tan x입니다(반지름 1).

  1. 질문x = 0을 넣으면 sin x/x는 0/0이 되어 값이 없습니다. x가 0에 가까워질 때는 어떤 값으로 다가갈까요?
  2. 복원호도법에서 반지름 1, 중심각 x인 부채꼴의 넓이는 ½x입니다. 세 함수가 g(x) ≤ f(x) ≤ h(x)이고 g와 h의 극한이 같으면 f의 극한도 그 값입니다.
  3. 설명0 < x < π/2일 때 그림의 세 도형은 차례로 포함되므로 ½ sin x < ½ x < ½ tan x입니다. 각 변을 ½ sin x로 나누고 역수를 취하면 cos x < sin x/x < 1입니다. x → 0+일 때 cos x → 1이므로 limx→0 sin x/x = 1입니다. sin(−x)/(−x) = sin x/x이므로 왼쪽에서 다가가도 같습니다. 또 (1 − cos x)/x = (sin x/x) · sin x/(1 + cos x) → 1 · 0/2 = 0입니다. 같은 방법으로 lim tan x/x = 1입니다.
  4. 연결sin x/x → 1은 x가 작을 때 sin x ≈ x라는 뜻입니다. 진자의 진동 주기를 구할 때 쓰는 근사도 이것입니다. 이 두 극한으로 다음 카드에서 사인함수와 코사인함수의 도함수를 구합니다.
  5. 적용'x ÷ 2'를 여러 번 눌러 세 도형의 넓이가 어떻게 가까워지는지 보세요. sin x/x는 아래 경계 cos x와 위 경계 1 사이에 늘 있나요? (1 − cos x)/x는 x가 절반이 될 때 대략 몇 배가 되나요?
  6. 판단이 극한은 x를 라디안으로 잴 때만 1입니다. 각을 도(°)로 재면 부채꼴의 넓이가 달라져 limx→0 sin x°/x = π/180입니다. 또 0/0 꼴이라고 곧바로 1이라고 답할 수는 없습니다. 같은 0/0 꼴인 (1 − cos x)/x는 0으로 갑니다. 극한값은 넓이 비교와 조임으로 얻은 것입니다.
