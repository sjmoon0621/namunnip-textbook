아래 그림의 주황 점은 h가 가장 낮은 곳입니다. h가 x축 아래로 내려가는 곳이 있으면 부등식이 깨집니다.

  1. 질문모든 실수 x에 대하여 ex ≥ kx가 성립하도록 하는 k의 범위는 무엇일까요? k를 키우면 언젠가 직선이 곡선을 뚫고 올라갈 것입니다.
  2. 복원'모든 x에서 f(x) ≥ g(x)'는 'h(x) = f(x) − g(x) ≥ 0'과 같습니다. h에 최솟값이 있으면 최솟값 ≥ 0인지만 보면 됩니다.
  3. 설명h(x) = ex − kx로 두면 h′(x) = ex − k입니다. k > 0이면 x = ln k에서 h′의 부호가 −에서 +로 바뀌므로 최솟값은 h(ln k) = k(1 − ln k)입니다. 이 값이 0 이상이려면 ln k ≤ 1, 곧 k ≤ e입니다. k = 0이면 ex > 0이라 성립합니다. k < 0이면 x → −∞일 때 h(x) → −∞라 깨집니다. 따라서 답은 0 ≤ k ≤ e입니다.
  4. 연결k = e일 때 직선 y = ex는 곡선에 점 (1, e)에서 접합니다. 아래로 볼록한 곡선은 접선보다 위에 있다는 사실과 같은 이야기입니다. 같은 방법으로 ex ≥ x + 1(점 (0, 1)에서의 접선)과 ln x ≤ x − 1(점 (1, 0)에서의 접선)을 증명할 수 있습니다.
  5. 적용k를 키우며 셋째 칸이 '아니요'로 바뀌는 순간을 찾으세요. 그때 위 그림의 직선과 곡선은 어떤 관계인가요? k를 음수로 내리면 아래 그림의 어느 쪽에서 문제가 생기나요?
  6. 판단극솟값만 확인하고 끝내면 안 됩니다. k < 0이면 h′ > 0이라 극값이 아예 없고, 왼쪽 끝에서 h가 한없이 작아집니다. 최솟값이 없는 함수는 끝에서의 극한까지 보아야 합니다. 또 ex/x ≥ k처럼 x로 나누면 x < 0일 때 부등호 방향이 바뀌므로 조심합니다.
