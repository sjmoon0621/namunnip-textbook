\(\tan x\)의 접선의 기울기는 왜 1보다 작아지지 않을까?

삼각함수의 도함수 · 몫의 미분법
높이 \(f(x)\)
—
접선의 기울기
—
\(\sec^2x\)
—

—

점선은 점근선이다. 함수가 정의되지 않는 \(x\)에서는 점을 그리지 않는다.

  1. 질문\(y = \tan x\)는 한 주기 안에서 늘 증가한다. 가장 완만한 곳에서도 기울기가 1보다 작아지지 않는 것처럼 보이는데, 정말 그럴까? 기울기를 식으로 나타낼 수 있을까?
  2. 복원몫의 미분법 \((\frac{f}{g})' = \frac{f'g - fg'}{g^2}\), \((\sin x)' = \cos x\), \((\cos x)' = -\sin x\)를 쓴다. 그리고 새 함수로 시컨트 \(\sec x = \frac{1}{\cos x}\), 코시컨트 \(\csc x = \frac{1}{\sin x}\), 코탄젠트 \(\cot x = \frac{\cos x}{\sin x}\)를 정의한다.
  3. 설명\((\tan x)' = \frac{\cos x \cdot \cos x - \sin x \cdot (-\sin x)}{\cos^2 x} = \frac{1}{\cos^2 x}\)이므로 \((\tan x)' = \sec^2 x = 1 + \tan^2 x\)이다. 이 값은 언제나 1 이상이고, \(\tan x = 0\)인 곳에서 가장 작은 1이다. 같은 방법으로 \((\cot x)' = -\csc^2 x\), \((\sec x)' = \sec x \tan x\), \((\csc x)' = -\csc x \cot x\)이며, 예를 들어 \((\sec x)' = (\frac{1}{\cos x})' = \frac{\sin x}{\cos^2 x} = (\frac{1}{\cos x})(\frac{\sin x}{\cos x})\)이다.
  4. 연결\(\sec^2 x = 1 + \tan^2 x\)는 \(\sin^2 x + \cos^2 x = 1\)을 \(\cos^2 x\)로 나눈 식이다. 그리고 적분에서는 거꾸로 \(\int \sec^2 x\,dx = \tan x + C\)로 쓴다.
  5. 적용\(\tan x\)에서 \(P\)를 옮기며 접선의 기울기가 가장 작아지는 \(x\)와 그때의 기울기를 찾아보자. 그리고 \(\cot x\)의 기울기가 어떤 범위에 있는지 보고, \(\sec x\)에서 접선이 수평인 곳이 어디인지 그 이유를 공식 \(\sec x \tan x\)로 설명해 보자.
  6. 판단\(\sec x\)를 \(\cos x\)의 역함수 \(\cos^{-1} x\)와 혼동하면 안 되며, \(\sec x\)는 역수 \(\frac{1}{\cos x}\)이다. 또 \(\csc\)는 \(\sin\)의 역수, \(\sec\)는 \(\cos\)의 역수로 이름과 짝이 엇갈리니 주의해야 하고, 네 공식 모두 분모가 0이 아닌 곳, 곧 함수가 정의되는 곳에서만 성립한다.
