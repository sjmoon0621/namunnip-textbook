\((1 + h)^{\frac{1}{h}}\)는 \(h\)가 0에 가까워지면 어디로 갈까?

자연상수 \(e\) · 자연로그
\((1+h)^{\frac{1}{h}}\)
—
\(e - (1+h)^{\frac{1}{h}}\)
—
\(\frac{\ln(1+h)}{h}\)
—
\(\frac{e^h - 1}{h}\)
—

—

\(h = \frac{1}{n}\)로 놓으면 \((1 + h)^{\frac{1}{h}} = (1 + \frac{1}{n})^n\)입니다. 그림을 가로로 끌어도 \(h\)가 바뀝니다. \(e = 2.718281828\cdots\)

  1. 질문연이율 100%를 1년에 \(n\)번 나누어 복리로 주면 원금 1은 1년 뒤 \((1 + \frac{1}{n})^n\)이 됩니다. \(n\)을 한없이 키우면 원리합계도 한없이 커질까요?
  2. 복원\(\lim_{h\to 0}\)는 \(h = 0\)에서의 값이 아니라, \(h\)가 0에 한없이 가까워질 때 값이 다가가는 곳입니다. 로그에서는 \(\log_a M^k = k \log_a M\), \(\log_a a = 1\)입니다.
  3. 설명\(h \to 0\)일 때 \((1 + h)^{\frac{1}{h}}\)은 한 값 \(2.71828\cdots\)에 수렴합니다. 이 값을 \(e\)로 나타냅니다. \(e = \lim_{h\to 0} (1 + h)^{\frac{1}{h}} = \lim_{n\to \infty} (1 + \frac{1}{n})^n\)이고, \(e\)는 무리수입니다. 밑이 \(e\)인 로그 \(\log_e x\)를 자연로그라 하고 \(\ln x\)로 씁니다. 그러면 \(\frac{\ln(1 + h)}{h} = \ln (1 + h)^{\frac{1}{h}} \to \ln e = 1\)입니다. 또 \(e^h - 1 = t\)로 놓으면 \(h = \ln(1 + t)\)이고, \(h \to 0\)일 때 \(t \to 0\)이므로 \(\frac{e^h - 1}{h} = \frac{t}{\ln(1 + t)} \to 1\)입니다. 같은 방법으로 \(a > 0\), \(a \ne 1\)일 때 \(\frac{a^h - 1}{h} \to \ln a\), \(\frac{\log_a(1 + h)}{h} \to \frac{1}{\ln a}\)입니다.
  4. 연결\(\frac{e^h - 1}{h}\)는 곡선 \(y = e^x\) 위의 점 \((0, 1)\)에서 그은 할선의 기울기입니다. 그래서 이 극한이 1이라는 것은 \(y = e^x\)의 \(x = 0\)에서의 접선의 기울기가 1이라는 뜻입니다. 이 사실에서 \(e^x\)와 \(\ln x\)의 도함수가 나옵니다.
  5. 적용'\(h \div 10\)'을 여러 번 누르며 \(e\)와의 차이가 어떻게 줄어드는지 보세요. \(h\)가 10분의 1이 되면 차이는 대략 얼마가 되나요? 부호를 바꾸어 \(h < 0\)에서도 같은 값으로 가는지 확인하세요. 아래 두 칸의 값은 어디로 가나요?
  6. 판단"밑 \(1 + h\)가 1로 가니까 1을 몇 번 곱해도 1"이라는 추론은 틀립니다. 밑이 1로 가는 동안 지수 \(\frac{1}{h}\)는 한없이 커지므로, 이런 \(1^\infty\) 꼴은 값이 미리 정해지지 않습니다. 또 \(h = 0\)을 넣을 수는 없으므로 그래프에서 \(x = 0\)은 빈 점입니다. \(e\)는 함숫값이 아니라 극한값입니다.
