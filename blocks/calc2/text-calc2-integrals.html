여러 가지 함수의 적분

본문

미적분Ⅰ에서 \(\int x^n\,dx = \dfrac{x^{n+1}}{n+1} + C\)를 배웠다. 그런데 \(n = -1\)을 넣으면 분모가 0이 되어 공식이 무너진다. 그렇다고 \(y = \dfrac{1}{x}\)의 그래프 아래 넓이가 없는 것은 아니다. \(x = 1\)에서 \(x = 2\)까지 \(y = \dfrac{1}{x}\) 아래의 넓이는 얼마이고, 그 넓이는 어떤 함수로 나타날까?

먼저 알아야 할 것부정적분과 정적분(미적분Ⅰ), 지수함수·로그함수의 도함수(지수·로그함수의 극한과 미분), 삼각함수의 도함수(삼각함수의 극한과 미분).

3.1.1미분을 거꾸로 읽기

부정적분은 미분의 역이다. 그러므로 앞에서 구한 도함수 공식을 거꾸로 읽으면 적분 공식을 얻는다. \((\ln|x|)' = \dfrac{1}{x}\)이므로 \(\dfrac{1}{x}\)의 부정적분은 \(\ln|x|\)이다. \(x < 0\)에서도 \(\ln(-x)\)를 미분하면 \(\dfrac{-1}{-x} = \dfrac{1}{x}\)이 되므로 절댓값을 붙인다.

정리 3.1.1 여러 가지 함수의 부정적분 (\(C\)는 적분상수)

\[\int x^n\,dx = \frac{x^{n+1}}{n+1} + C\ (n \ne -1),\qquad \int \frac{1}{x}\,dx = \ln|x| + C\] \[\int e^x\,dx = e^x + C,\quad \int a^x\,dx = \frac{a^x}{\ln a} + C,\quad \int \sin x\,dx = -\cos x + C,\quad \int \cos x\,dx = \sin x + C\] \[\int \sec^2 x\,dx = \tan x + C\]

그림 1에서 \(n\)을 \(-1\)에 가깝게 움직여 보자. \(n = -0.99\)이면 \(\dfrac{2^{0.01} - 1}{0.01} \approx 0.6956\), \(n = -1.01\)이면 \(\approx 0.6908\)로, 둘 다 \(\ln 2 \approx 0.6931\)을 사이에 두고 다가간다. \(\dfrac{1}{x}\)의 적분이 거듭제곱이 아니라 로그로 나오는 것은 공식의 빈자리를 로그가 채우는 것이다.1

3.1.2원시함수 확인하기

부정적분이 맞는지는 미분해 보면 바로 확인할 수 있다. \(\int \sin x\,dx\)의 후보로 \(\cos x\)를 떠올리기 쉽지만, \((\cos x)' = -\sin x\)이므로 부호가 틀렸다. 올바른 답 \(-\cos x\)를 미분하면 \(\sin x\)가 된다. 적분 결과를 미분하여 처음 함수가 나오는지 확인하는 습관이 실수를 막는다.

3.1.3예제 하나를 끝까지

예제 3.1.2

다음 정적분의 값을 구하여라. (1) \(\int_1^{e} \dfrac{x + 1}{x}\,dx\) (2) \(\int_0^{\pi} \sin x\,dx\) (3) \(\int_0^{1} (e^x + 2^x)\,dx\)

(1) \(\dfrac{x + 1}{x} = 1 + \dfrac{1}{x}\)이므로 \(\left[x + \ln x\right]_1^e = (e + 1) - (1 + 0) = e\)이다. (2) \(\left[-\cos x\right]_0^{\pi} = -\cos\pi + \cos 0 = 1 + 1 = 2\)이다. 사인 곡선의 한 봉우리 아래 넓이가 정확히 2라는 뜻이다.

(3) \(\left[e^x + \dfrac{2^x}{\ln 2}\right]_0^1 = (e - 1) + \dfrac{2 - 1}{\ln 2} = e - 1 + \dfrac{1}{\ln 2} \approx 1.718 + 1.443 = 3.161\)이다. 밑이 \(e\)가 아닌 지수함수는 \(\ln a\)로 나누어야 한다는 점에 주의한다.

  1. 그래서 \(\ln x\)를 \(\ln x = \int_1^x \dfrac{1}{t}\,dt\)로 정의하기도 한다. 이렇게 정의하면 \(\ln(ab) = \ln a + \ln b\) 같은 로그의 성질도 넓이의 성질로 증명할 수 있다.
마무리

여러 가지 함수의 적분 공식은 도함수 공식을 거꾸로 읽어 얻으며, 결과를 미분하여 확인할 수 있다. \(x^n\)의 공식은 \(n = -1\)에서 쓸 수 없고, 그 자리를 \(\int \frac{1}{x}dx = \ln|x| + C\)가 채운다. 그래서 처음 질문의 \(y = \frac{1}{x}\) 아래 1에서 2까지의 넓이는 \(\ln 2 \approx 0.693\)이다.
