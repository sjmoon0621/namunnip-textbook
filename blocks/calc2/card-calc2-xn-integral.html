xn의 적분 공식은 n = −1에서 왜 멈출까?

거듭제곱함수의 적분 · 조작
넓이로 잰 ∫1b xn dx
—
(bn+1 − 1)/(n + 1)
—
ln b
—

그림을 끌면 위끝 b가 움직입니다. 첫 값은 칠한 넓이를 잘게 나누어 더한 값입니다(b < 1이면 부호가 음수).

  1. 질문∫xn dx = xn+1/(n + 1) + C는 n이 정수가 아닌 실수일 때도 맞을까요? 그리고 분모가 0이 되는 n = −1이면 1/x의 넓이는 어떻게 구할까요?
  2. 복원x > 0이고 n이 실수이면 (xn+1)′ = (n + 1)xn입니다. 또 (ln x)′ = 1/x입니다. 부정적분은 미분하면 피적분함수가 되는 함수입니다.
  3. 설명n ≠ −1이면 xn+1/(n + 1)을 미분해 xn이 되므로 ∫xn dx = xn+1/(n + 1) + C입니다. 예를 들어 ∫√x dx = (2/3)x3/2 + C, ∫1/x2 dx = −1/x + C입니다. n = −1이면 이 식은 0으로 나누게 되어 쓸 수 없습니다. 대신 (ln x)′ = 1/x이므로 ∫1/x dx = ln |x| + C입니다. x < 0에서도 (ln(−x))′ = 1/x이므로 절댓값을 씌웁니다.
  4. 연결n이 −1에 가까워지면 (bn+1 − 1)/(n + 1)은 앞 단원의 극한 (eh − 1)/h → 1과 같은 꼴이 되어 ln b로 다가갑니다. 그래서 1/x의 적분은 따로 떨어진 예외가 아니라 거듭제곱 적분이 이어지는 자리에 있습니다. 1/x의 넓이로 자연로그를 정의하는 교재도 있습니다.
  5. 적용n = −0.5, b = 4에서 넓이가 2인지 확인하세요. 이어서 n을 −1.1, −1.05로 옮기며 둘째 값과 ln b를 비교하세요. n = −1을 누르면 둘째 값은 어떻게 되고, 넓이는 무엇과 같아지나요? b를 1보다 작게 하면 부호는 어떻게 되나요?
  6. 판단∫1/x dx = x0/0 또는 −1/x2이라고 쓰는 실수가 흔합니다. 앞의 것은 정의되지 않고, 뒤의 것은 1/x를 미분한 결과입니다. 또 ∫−11 1/x2 dx에 공식을 그대로 넣어 −2를 얻으면 안 됩니다. 1/x2은 x = 0에서 정의되지 않아 그 구간에서는 이 방법으로 정적분을 구할 수 없습니다.
