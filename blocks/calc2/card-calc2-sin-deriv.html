\(\sin x\)의 접선의 기울기를 모으면 어떤 그래프가 될까?

사인·코사인함수의 도함수 · 조작
높이 \(f(x)\)
—
접선의 기울기
—
\(\cos x\)
—

\(P\)를 움직이면 그 \(x\)에서 잰 접선의 기울기가 아래 그림에 점으로 남습니다. 기울기는 아주 작은 \(h(0.00001)\)로 잰 값입니다.

  1. 질문\(y = \sin x\) 위의 점마다 접선의 기울기를 재어, 그 값을 같은 \(x\)에 점으로 찍으면 어떤 곡선이 나타날까요?
  2. 복원덧셈정리 \(\sin(x + h) = \sin x \cos h + \cos x \sin h\), 그리고 극한 \(\lim_{h\to 0} \frac{\sin h}{h} = 1\), \(\lim_{h\to 0} \frac{\cos h - 1}{h} = 0\)을 씁니다.
  3. 설명\(\frac{\sin(x + h) - \sin x}{h} = \sin x \cdot \frac{\cos h - 1}{h} + \cos x \cdot \frac{\sin h}{h}\)입니다. \(h \to 0\)이면 \(\sin x \cdot 0 + \cos x \cdot 1\)이므로 \((\sin x)' = \cos x\)입니다. 같은 방법으로 \(\cos(x + h) = \cos x \cos h - \sin x \sin h\)를 쓰면 \((\cos x)' = -\sin x\)입니다. 두 공식 모두 \(x\)를 라디안으로 잴 때 성립합니다.
  4. 연결\(\sin x\)를 두 번 미분하면 \(-\sin x\)로 돌아옵니다. 용수철에 매달린 물체처럼 가속도가 변위와 반대 방향으로 비례하는 운동이 사인 곡선을 그리는 까닭입니다. 다음 절에서는 몫의 미분법으로 \(\tan x\) 같은 다른 삼각함수도 미분합니다.
  5. 적용'훑기'를 눌러 기울기 점들이 그리는 곡선을 보고 어떤 함수인지 짐작한 뒤 '후보 그래프 겹치기'로 확인하세요. 위 그래프가 가장 높은 곳에서 아래 점은 어디에 있나요? \(y = \cos x\)로 바꾸면 기울기 점들은 어떤 곡선을 그리나요?
  6. 판단\((\cos x)' = \sin x\)로 부호를 빠뜨리는 실수가 흔합니다. \(0 < x < \pi\)에서 \(\cos x\)는 감소하므로 기울기가 음수여야 하고, 그래서 \(-\sin x\)입니다. 또 각을 도로 잰 함수 \(y = \sin x^\circ\)의 도함수는 \((\frac{\pi}{180}) \cos x^\circ\)입니다.
