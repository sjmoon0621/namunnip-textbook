수렴하는 두 수열을 더하고 곱하면 극한은 어떻게 될까?

수열의 극한에 대한 성질 · 합 · 차 · 곱 · 몫

\(a_n = 2 + \frac{1}{n} \to \alpha = 2\)

회색은 \(a_n\), 주황은 \(b_n\), 초록은 두 수열로 만든 \(c_n\)이다. 그림 밖으로 나간 항은 위아래 가장자리의 삼각형으로 표시한다.

  1. 질문\(a_n\)이 2에, \(b_n\)이 3에 수렴하면 \(a_n + b_n\)은 5에, \(a_nb_n\)은 6에 수렴할까? 극한값끼리 계산해도 되는 조건은 무엇일까?
  2. 복원함수의 극한에서 \(\lim f(x)\)와 \(\lim g(x)\)가 모두 존재하면 합, 차, 곱, 몫의 극한을 극한값끼리 계산할 수 있었다. 수열은 자연수에서 정의된 함수이므로 같은 성질을 기대할 수 있다.
  3. 설명두 수열 \(\{a_n\}\), \(\{b_n\}\)이 모두 수렴하고 \(\lim a_n = \alpha\), \(\lim b_n = \beta\)이면, 상수 \(k\)에 대해 \(\lim ka_n = k\alpha\), \(\lim (a_n \pm b_n) = \alpha \pm \beta\), \(\lim a_nb_n = \alpha \beta\)이고, \(b_n \ne 0\), \(\beta \ne 0\)일 때 \(\lim \frac{a_n}{b_n} = \frac{\alpha}{\beta}\)이다. 예를 들어 \(|a_n + b_n - (\alpha + \beta)| \le |a_n - \alpha| + |b_n - \beta|\)이므로, 두 오차가 모두 0으로 가면 합의 오차도 0으로 간다. 이 성질을 쓰면 복잡한 수열을 극한값을 아는 간단한 수열로 쪼개 계산할 수 있다.
  4. 연결\(\frac{1}{n} \to 0\)과 상수수열의 극한만 알면, 이 성질로 \(\frac{2n + 1}{n} = 2 + \frac{1}{n}\) 같은 수열의 극한을 바로 구할 수 있다. \(\infty/\infty\) 꼴의 분수식은 먼저 모양을 바꾼 뒤 이 성질을 쓴다.
  5. 적용\(b_n = 3 - \frac{2}{n}\)에서 다섯 가지 연산을 차례로 고르고, \(n\)을 30까지 옮기며 초록 점이 점선에 다가가는지 보자. 이번에는 \(b_n = \frac{(-1)^n}{n}\)으로 바꾸고 몫 \(\frac{a_n}{b_n}\)을 골라 \(\beta = 0\)이면 무엇이 일어나는지, 같은 \(b_n\)에서 곱 \(a_nb_n\)은 어디로 가는지 확인해 보자.
  6. 판단이 성질은 두 수열이 모두 수렴할 때만 쓴다. \(a_n = n\), \(b_n = -n\)이면 \(a_n + b_n = 0\)이라 0에 수렴하지만, \(\infty\)는 수가 아니므로 \(\lim a_n + \lim b_n = \infty + (-\infty)\)로 계산할 수는 없다. 반대로 \(a_n + b_n\)이 수렴해도 \(a_n\)과 \(b_n\)이 각각 수렴한다고 할 수 없지만, \(a_n\)과 \(a_n + b_n\)이 모두 수렴하면 \(b_n = (a_n + b_n) - a_n\)도 수렴한다.
