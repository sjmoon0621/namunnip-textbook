수열의 극한의 성질

본문

\(\dfrac{3n^2 + 5n}{n^2 + 1}\)이나 \(\dfrac{\sin n}{n}\)처럼 생긴 수열의 극한을 매번 정의로 따지기는 번거롭다. 함수의 극한에서처럼 더하고 곱하고 나누는 성질을 쓸 수 있다면 편할 것이다. 그런데 \(\sin n\)은 수렴하지 않는데, \(\dfrac{\sin n}{n}\)의 극한은 어떻게 구할 수 있을까?

먼저 알아야 할 것수열의 수렴과 발산(수열의 수렴과 발산), 함수의 극한에 대한 성질(미적분Ⅰ), 무리식의 유리화.

1.2.1극한의 기본 성질

두 수열 \(\{a_n\}\), \(\{b_n\}\)이 각각 \(\alpha\), \(\beta\)에 수렴하면, \(a_n\)과 \(b_n\)이 각각 \(\alpha\), \(\beta\)에 한없이 가까워지므로 그 합은 \(\alpha + \beta\)에 한없이 가까워진다. 곱과 몫도 마찬가지이다.

정리 1.2.1 수열의 극한에 대한 성질

\(\lim a_n = \alpha\), \(\lim b_n = \beta\)일 때 (\(c\)는 상수) \[\lim c\,a_n = c\alpha,\quad \lim (a_n \pm b_n) = \alpha \pm \beta,\quad \lim a_n b_n = \alpha\beta,\quad \lim \frac{a_n}{b_n} = \frac{\alpha}{\beta}\ (b_n \ne 0,\ \beta \ne 0)\]

이 성질은 두 수열이 모두 수렴할 때만 쓸 수 있다. \(\dfrac{3n^2 + 5n}{n^2 + 1}\)은 분자와 분모가 모두 발산하므로 바로 나눌 수 없다. 이럴 때는 분모의 최고차항 \(n^2\)으로 분자와 분모를 나누어 \(\dfrac{3 + \frac{5}{n}}{1 + \frac{1}{n^2}}\)로 바꾸면, 분자는 3, 분모는 1로 수렴하므로 극한은 3이다. 분모와 분자의 차수가 같으면 최고차항 계수의 비가, 분모의 차수가 더 높으면 0이 극한이 된다.

1.2.2대소 관계와 조임 정리

수렴하는 두 수열이 모든 \(n\)에서 \(a_n \le b_n\)이면 극한도 \(\alpha \le \beta\)이다. 이 성질에서 다음 정리가 나온다.

정리 1.2.2 조임 정리

모든 자연수 \(n\)에 대하여 \(a_n \le c_n \le b_n\)이고 \(\lim a_n = \lim b_n = \alpha\)이면 \(\lim c_n = \alpha\)이다.

\(\sin n\)은 \(-1\)과 1 사이를 불규칙하게 오가며 수렴하지 않는다. 그러나 \(-1 \le \sin n \le 1\)이므로 양변을 \(n\)으로 나누면 \(-\dfrac{1}{n} \le \dfrac{\sin n}{n} \le \dfrac{1}{n}\)이다. 그림 1에서 항의 수를 늘려 보자. 위아래 경계가 모두 0으로 조여 들면서 가운데 수열도 0으로 끌려간다.1

1.2.3예제 하나를 끝까지

예제 1.2.3

\(\lim_{n \to \infty} (\sqrt{n^2 + 4n} - n)\)을 구하여라.

\(\sqrt{n^2 + 4n}\)과 \(n\)이 모두 발산하므로 \(\infty - \infty\) 꼴이 되어 바로 뺄 수 없다. 분모를 1로 보고 분자를 유리화한다.

\[\sqrt{n^2 + 4n} - n = \frac{(n^2 + 4n) - n^2}{\sqrt{n^2 + 4n} + n} = \frac{4n}{\sqrt{n^2 + 4n} + n}\] 분자와 분모를 \(n\)으로 나누면 \(\dfrac{4}{\sqrt{1 + \frac{4}{n}} + 1}\)이 되고, \(n \to \infty\)일 때 분모가 \(1 + 1 = 2\)로 수렴하므로 극한은 \(\dfrac{4}{2} = 2\)이다. 실제로 \(n = 100\)이면 \(\sqrt{10\,400} - 100 \approx 1.98\)이다.

극한의 성질은 수렴하는 수열들로 쪼갠 뒤에야 쓸 수 있다는 점을 기억하자. 아래 탐구 카드에서 극한의 성질, \(\dfrac{\infty}{\infty}\) 꼴, 조임 정리를 직접 확인해 보자.

  1. '모든 \(n\)'이 아니라 '어느 번째 항부터 모든 \(n\)'에서 부등식이 성립해도 조임 정리는 그대로 성립한다. 극한은 처음 몇 항과 상관없기 때문이다.
마무리

수렴하는 수열의 합, 차, 곱, 몫의 극한은 각 극한의 합, 차, 곱, 몫이고, \(\dfrac{\infty}{\infty}\)나 \(\infty - \infty\) 꼴은 식을 변형하여 수렴하는 수열로 바꾼 뒤 성질을 쓴다. 위아래에서 같은 값으로 조여지는 수열은 그 값으로 수렴한다. 그래서 처음 질문의 \(\dfrac{\sin n}{n}\)은 \(\pm\dfrac{1}{n}\) 사이에 갇혀 0으로 수렴한다.
