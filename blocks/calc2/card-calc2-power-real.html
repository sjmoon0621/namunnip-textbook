접선의 기울기는 아주 작은 h(0.00001)로 잰 할선의 기울기입니다. 점 P는 그림을 가로로 끌어도 움직입니다.

  1. 질문(xn)′ = nxn−1은 n이 정수일 때 확인했습니다. 지수가 1/2이나 √2, π처럼 정수가 아니어도 같은 공식이 맞을까요?
  2. 복원x > 0이면 x = eln x이므로 xr = er ln x입니다. (eu)′ = eu, (ln x)′ = 1/x, 그리고 합성함수의 미분법을 씁니다.
  3. 설명y = er ln x에서 바깥 함수는 eu, 안쪽 함수는 u = r ln x입니다. 따라서 y′ = er ln x · r/x = xr · r/x, 곧 (xr)′ = rxr−1(r는 실수, x > 0)입니다. 같은 계산을 양변에 ln을 취해서 할 수도 있습니다. ln y = r ln x의 양변을 미분하면 y′/y = r/x입니다. 이렇게 로그를 취해 미분하는 방법을 로그미분법이라고 합니다.
  4. 연결x × 기울기 ÷ 높이 = r는 "x가 1% 늘면 y는 약 r% 는다"는 뜻입니다. 지수와 밑이 모두 변하는 y = xx도 ln y = x ln x로 바꾸어 미분하면 y′ = xx(ln x + 1)입니다.
  5. 적용√2와 π에서 P를 옮기며 접선의 기울기와 rxr−1을 비교하세요. 넷째 칸의 값은 P의 위치에 따라 바뀌나요? r를 움직여 r < 0, 0 < r < 1, r > 1일 때 그래프가 각각 어떻게 휘는지, 기울기의 부호가 어떤지 보세요.
  6. 판단xr(밑이 변수, 지수가 상수)과 ax(밑이 상수, 지수가 변수)를 섞지 않습니다. (xπ)′ = πxπ−1이지만 (πx)′ = πx ln π입니다. 또 지수가 무리수이면 xr은 x > 0에서만 정의하므로 공식도 그 범위에서 씁니다.
