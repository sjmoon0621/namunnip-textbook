A(a, b)는 y = f(x) 위에, B(b, a)는 역함수의 그래프 위에 있습니다. 두 기울기 삼각형은 가로와 세로가 서로 바뀐 모양입니다. 넷째 칸은 역함수를 수치로 풀어 가까운 두 점으로 잰 기울기입니다.

  1. 질문f(x) = x3 + x의 역함수 g는 식으로 쓰기 어렵습니다. 그래도 g′(2)를 구할 수 있을까요?
  2. 복원f가 일대일대응이면 역함수 g = f−1가 있고, 두 그래프는 직선 y = x에 대하여 대칭입니다. 또 모든 x에 대하여 f(g(x)) = x입니다.
  3. 설명직선 y = x에 대해 대칭이동하면 가로와 세로가 바뀌므로 기울기는 역수가 됩니다. 식으로는 f(g(x)) = x의 양변을 미분해 f′(g(x)) · g′(x) = 1을 얻습니다. 따라서 b = f(a)이고 f′(a) ≠ 0이면 g′(b) = 1/f′(a)입니다. dx/dy = 1/(dy/dx)로 써도 같습니다. 질문에서는 f(1) = 2, f′(1) = 4이므로 g′(2) = 1/4입니다.
  4. 연결y = ln x는 x = ey의 역함수입니다. dx/dy = ey = x이므로 (ln x)′ = 1/x를 다시 얻습니다. x = ey의 양변을 x로 미분해도 같은 결과가 나오므로, 역함수의 미분은 음함수의 미분과 같은 생각입니다.
  5. 적용첫 함수에서 a = 1에 맞추어 셋째 칸과 넷째 칸이 1/4로 같은지 보세요. ex에서는 a를 바꾸며 셋째 칸이 늘 1/b인지 확인하세요. x3에서 a를 0에 가깝게 보내면 B에서의 접선과 넷째 칸은 어떻게 되나요?
  6. 판단g′(b) = 1/f′(b)로 쓰는 실수가 흔합니다. 넣는 값은 b가 아니라 f(a) = b를 만족하는 a입니다. f′(a) = 0이면 역함수의 접선은 세로선이 되어 g는 b에서 미분가능하지 않습니다. x3의 역함수 ∛x가 x = 0에서 그렇습니다. 또 f−1(x)는 1/f(x)가 아닙니다.
