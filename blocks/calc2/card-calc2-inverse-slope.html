식을 모르는 역함수의 기울기를 구할 수 있을까?

역함수의 미분 · 조작
\(b = f(a)\)
—
\(f'(a)\)
—
\(\frac{1}{f'(a)}\)
—
\(f^{-1}\)의 \(\frac{\Delta y}{\Delta x}\) (\(b\) 근처)
—

—

\(A(a, b)\)는 \(y = f(x)\) 위에, \(B(b, a)\)는 역함수의 그래프 위에 있습니다. 두 기울기 삼각형은 가로와 세로가 서로 바뀐 모양입니다. 넷째 칸은 역함수를 수치로 풀어 가까운 두 점으로 잰 기울기입니다.

  1. 질문\(f(x) = x^3 + x\)의 역함수 \(g\)는 식으로 쓰기 어렵습니다. 그래도 \(g'(2)\)를 구할 수 있을까요?
  2. 복원\(f\)가 일대일대응이면 역함수 \(g = f^{-1}\)가 있고, 두 그래프는 직선 \(y = x\)에 대하여 대칭입니다. 또 모든 \(x\)에 대하여 \(f(g(x)) = x\)입니다.
  3. 설명직선 \(y = x\)에 대해 대칭이동하면 가로와 세로가 바뀌므로 기울기는 역수가 됩니다. 식으로는 \(f(g(x)) = x\)의 양변을 미분해 \(f'(g(x)) \cdot g'(x) = 1\)을 얻습니다. 따라서 \(b = f(a)\)이고 \(f'(a) \ne 0\)이면 \(g'(b) = \frac{1}{f'(a)}\)입니다. \(\frac{dx}{dy} = \frac{1}{\frac{dy}{dx}}\)로 써도 같습니다. 질문에서는 \(f(1) = 2\), \(f'(1) = 4\)이므로 \(g'(2) = \frac{1}{4}\)입니다.
  4. 연결\(y = \ln x\)는 \(x = e^y\)의 역함수입니다. \(\frac{dx}{dy} = e^y = x\)이므로 \((\ln x)' = \frac{1}{x}\)를 다시 얻습니다. \(x = e^y\)의 양변을 \(x\)로 미분해도 같은 결과가 나오므로, 역함수의 미분은 음함수의 미분과 같은 생각입니다.
  5. 적용첫 함수에서 \(a = 1\)에 맞추어 셋째 칸과 넷째 칸이 \(\frac{1}{4}\)로 같은지 보세요. \(e^x\)에서는 \(a\)를 바꾸며 셋째 칸이 늘 \(\frac{1}{b}\)인지 확인하세요. \(x^3\)에서 \(a\)를 0에 가깝게 보내면 \(B\)에서의 접선과 넷째 칸은 어떻게 되나요?
  6. 판단\(g'(b) = \frac{1}{f'(b)}\)로 쓰는 실수가 흔합니다. 넣는 값은 \(b\)가 아니라 \(f(a) = b\)를 만족하는 \(a\)입니다. \(f'(a) = 0\)이면 역함수의 접선은 세로선이 되어 \(g\)는 \(b\)에서 미분가능하지 않습니다. \(x^3\)의 역함수 \(\sqrt[3]{x}\)가 \(x = 0\)에서 그렇습니다. 또 \(f^{-1}(x)\)는 \(\frac{1}{f(x)}\)가 아닙니다.
