\(a \sin x + b \cos x\)는 어떤 모양의 그래프일까?

삼각함수의 합성 · 조작
\(r = \sqrt{a^2 + b^2}\)
—
\(\varphi\)
—
그래프의 최댓값
—
\(a + b\)
—

—

  1. 질문\(\sin x\)의 최댓값도 1, \(\cos x\)의 최댓값도 1입니다. 그러면 \(\sin x + \cos x\)의 최댓값은 2일까요? 두 그래프를 더한 모양은 어떤 곡선일까요?
  2. 복원덧셈정리 \(\sin(x + \varphi) = \sin x \cos \varphi + \cos x \sin \varphi\). \(y = r \sin(x + \varphi)\)는 \(y = \sin x\)를 세로로 \(r\)배 늘리고 \(x\)축 방향으로 \(-\varphi\)만큼 옮긴 그래프입니다.
  3. 설명\(r \sin(x + \varphi) = (r \cos \varphi) \sin x + (r \sin \varphi) \cos x\)이므로, \(a = r \cos \varphi\), \(b = r \sin \varphi\)가 되도록 \(r\), \(\varphi\)를 잡으면 \(a \sin x + b \cos x = r \sin(x + \varphi)\)입니다. 여기서 \(r = \sqrt{a^2 + b^2}\), \(\cos \varphi = \frac{a}{r}\), \(\sin \varphi = \frac{b}{r}\)입니다. 곧 점 \((a, b)\)를 좌표평면에 찍었을 때 원점까지의 거리가 \(r\), 동경이 이루는 각이 \(\varphi\)입니다. 그래서 합은 주기가 \(2\pi\)인 사인 곡선이고, 최댓값은 \(r\), 최솟값은 \(-r\)입니다. 이렇게 바꾸는 것을 삼각함수의 합성이라고 합니다.
  4. 연결주기가 같은 두 진동을 더하면 같은 주기의 진동 하나가 됩니다. 소리나 교류 전압처럼 같은 진동수의 파동이 겹칠 때 진폭이 \(\sqrt{a^2 + b^2}\)로 정해지는 것도 이 계산입니다.
  5. 적용\(\sin x + \cos x\)에서 그래프의 최댓값을 읽고 \(a + b\)와 비교하세요. \(3 \sin x + 4 \cos x\)의 최댓값은 얼마인가요? \(b\)를 음수로 바꾸면 오른쪽 위 그림의 점과 \(\varphi\)는 어디로 가나요? 최댓값이 나오는 \(x\)는 \(\varphi\)와 어떤 관계인가요?
  6. 판단최댓값을 \(a + b\)로 계산하는 실수가 흔합니다. \(\sin x\)가 최대인 \(x\)와 \(\cos x\)가 최대인 \(x\)가 다르므로 두 최댓값이 한꺼번에 나오지 않습니다. 또 합성은 두 함수의 주기가 같을 때만 됩니다. \(\sin x + \cos 2x\)는 사인 곡선 하나로 바꿀 수 없습니다.
