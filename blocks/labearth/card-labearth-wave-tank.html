물이 얕아지면 파도는 왜 느려지고 높아질까?

실험 · 조파 수조 · 천해파와 심해파의 속도
조파
가로축

수조 길이 3.4 m, 파고계 1과 2 사이 1.00 m. 도착 시간은 영상(초당 30프레임)에서 같은 마루가 두 파고계를 지난 프레임을 세어 구하므로 분해능이 0.033 s이고, 마루를 고르는 우연 오차가 더해집니다. 그림은 세로를 2.5배, 파고를 다시 3배 과장했습니다. 오른쪽 끝은 기울기 1/4의 경사 해빈입니다. 그래프의 점선은 √(gh), 파선은 gT/2π입니다.

  1. 탐구 문제지진 해일은 대양 한가운데에서 시속 700 km로 달리다가 해안 가까이 오면 느려지면서 높이가 몇 배로 커집니다. 파의 속도는 무엇이 정할까요? 수조 안의 작은 파로 해일의 성질을 확인할 수 있을까요?
  2. 복원파의 속도 c = λ / T입니다. 물 입자는 수면 아래 약 λ/2 깊이까지 원(또는 타원) 운동을 합니다. 수심이 λ/2보다 깊으면 바닥을 느끼지 못하는 심해파(c = gT / 2π, 수심과 무관), 수심이 λ/20보다 얕으면 바닥에 끌리는 천해파(c = √(gh), 주기와 무관)가 됩니다. 그 사이는 c² = (g / k)·tanh(kh)로 이어집니다(k = 2π / λ).
  3. 설계조작 변인은 수심 h와 조파 주기 T, 종속 변인은 두 파고계 사이(1.00 m)를 지나는 시간 Δt입니다. c = 1.00 m / Δt로 속도를 구합니다. 해일 모형은 수조 바닥 일부를 한 번에 들어 올려 파장이 수조보다 긴 혹 모양의 파를 만듭니다. 한 실험에서는 한 변인만 바꾸세요.
  4. 분석주기를 길게(T = 2–3 s) 두고 수심만 바꾸면 c와 √h가 원점을 지나는 직선에 놓이고, 기울기는 √g ≈ 3.13 √m/s입니다. 수심을 30 cm로 깊게 두고 주기를 0.4–0.8 s로 짧게 하면 c가 수심과 상관없이 gT/2π 파선에 붙습니다. 해일 모형의 혹은 언제나 √(gh)로 달립니다. 파장이 수심보다 훨씬 길기 때문입니다. 수심 4000 m 대양에서는 √(9.8 × 4000) ≈ 198 m/s(약 710 km/h)입니다.
  5. 측정T = 2.5 s로 두고 수심 4, 8, 12, 16, 20, 25 cm에서 재어 √h 그래프의 기울기를 구하세요. 다음으로 h = 30 cm에서 T를 0.5, 0.8, 1.2, 2.0, 3.0 s로 바꿔 주기 그래프에서 어느 곡선을 따르는지 보세요. 마지막으로 해일 모형을 켜고 경사 해빈에서 혹의 높이가 어떻게 되는지 관찰하세요.
  6. 오차·안전Δt가 짧을수록(수심이 깊고 속도가 빠를수록) 프레임 분해능 0.033 s가 차지하는 비율이 커지므로, 파고계 간격을 넓히거나 여러 마루의 평균을 냅니다. 수조 끝에서 되돌아온 반사파가 겹치면 마루를 잘못 고르므로 끝에 경사 해빈이나 흡수재를 둡니다. 파고가 수심에 비해 크면 마루가 더 빨리 달려(비선형 효과) 값이 √(gh)보다 커집니다. 수조 주변 바닥의 물기는 바로 닦고, 조파기 모터와 전원은 물에서 멀리 둡니다.
