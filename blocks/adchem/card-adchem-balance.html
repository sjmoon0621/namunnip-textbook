잃은 전자와 얻은 전자를 어떻게 맞출까?

산화수 · 반쪽 반응식 · 산성과 염기성 용액 · 불균등화

—

반쪽 반응식은 이미 원자 수와 전하를 맞춘 것입니다. 산성 용액에서는 H₂O와 H⁺로, 염기성 용액에서는 H₂O와 OH⁻로 O와 H를 맞췄습니다. 두 식에 같은 화학종이 양쪽에 있으면 빼서 정리했습니다.

  1. 질문MnO₄⁻ + Fe²⁺ + H⁺ → Mn²⁺ + Fe³⁺ + H₂O. 원자 수만 맞추려 하면 계수를 1로 두어도 Mn, Fe는 맞고 O와 H만 손보면 될 것 같습니다. 그런데 그렇게 맞춘 식은 양쪽의 전하가 다릅니다. 무엇을 기준으로 계수를 정해야 할까요?
  2. 복원산화는 전자를 잃는 것, 환원은 전자를 얻는 것이며 두 반응은 항상 함께 일어납니다. 화학 반응에서는 원자의 종류와 수, 그리고 전하의 총량이 보존됩니다.
  3. 설명공유 결합의 전자쌍을 전기 음성도가 큰 원자가 모두 가져간다고 보았을 때 각 원자가 갖는 전하가 산화수입니다. 홑원소 물질은 0, 화합물에서 O는 대개 −2, H는 대개 +1이며, 산화수의 합은 화학종의 전하와 같습니다. 그래서 MnO₄⁻의 Mn은 x + 4(−2) = −1에서 +7입니다. 산화수가 늘어난 원자는 산화되고 그 물질은 환원제, 산화수가 줄어든 원자는 환원되고 그 물질은 산화제입니다. 반응식을 맞출 때는 산화와 환원을 반쪽 반응식으로 나눠 각각 맞춘 뒤, 잃은 전자 수 = 얻은 전자 수가 되도록 정수를 곱해 더합니다.
  4. 연결산화수의 변화량은 원자 하나가 주고받은 전자 수와 같습니다. Mn이 +7에서 +2로 5만큼 줄면 Mn 원자 하나가 전자 5개를 받고, Fe는 +2에서 +3으로 1만큼 늘어 전자 1개를 내놓습니다. 그러므로 MnO₄⁻ 1개에 Fe²⁺ 5개가 필요합니다. 이 비율이 산화·환원 적정에서 물질의 양을 계산하는 근거입니다. 염기성 용액에서는 H⁺ 대신 OH⁻와 H₂O로 맞추며, 생성물도 산성에서와 다를 수 있습니다(Mn²⁺ 대신 MnO₂).
  5. 적용두 슬라이더를 움직여 아래 전자 줄이 똑같이 맞아떨어지게 하세요. 전자가 맞지 않을 때 완성된 식에는 무엇이 남고, 양쪽 전하는 어떻게 되나요? Cl₂ + OH⁻에서는 한 원소가 산화도 되고 환원도 됩니다. 산화수가 어떻게 갈라지나요? 같은 MnO₄⁻라도 산성과 염기성에서 받는 전자 수가 왜 다른가요?
  6. 판단산화수는 실제 전하가 아니라 전자의 이동을 세기 위한 약속입니다. MnO₄⁻ 속 Mn에 +7의 전하가 실제로 있는 것은 아니며, 공유 결합이 강한 화합물일수록 실제 전하와 거리가 멉니다. 또 산화수는 분수가 될 수도 있습니다(Fe₃O₄의 Fe는 평균 +8/3). 반응식이 맞았다고 그 반응이 실제로 일어나는 것도 아닙니다. 일어날지는 표준 환원 전위와 자유 에너지로 따져야 합니다.

확인조건이 달라지면

산성 용액에서 H₂O₂가 MnO₄⁻에 의해 O₂로 산화됩니다. 반쪽 반응식은 H₂O₂ → O₂ + 2H⁺ + 2e⁻, MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O입니다. 완성된 반응식에서 MnO₄⁻ 2개와 반응하는 H₂O₂의 수와 반응물 쪽 H⁺의 계수는?
