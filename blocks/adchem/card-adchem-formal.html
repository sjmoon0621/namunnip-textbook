세 결합의 길이가 같은 질산 이온을 루이스 구조식으로 어떻게 나타낼까?

형식 전하 · 공명 구조 · 안정한 구조 고르기

—

결합(선)을 누를 때마다 단일 → 이중 → 삼중 결합으로 바뀝니다. 비공유 전자쌍은 바깥 원자부터 옥텟을 채우고 남는 전자를 가운데 원자에 주도록 자동으로 배치합니다. 형식 전하 = (원자가 전자 수) − (비공유 전자 수) − (결합 수). 저장한 구조가 둘 이상이면 결합 옆에 구조들의 단순 평균 결합 차수를 적습니다(모든 구조의 비중을 같다고 가정). 실측 결합 길이: NO₃⁻의 N–O 세 개 모두 약 125 pm, O₃의 O–O 두 개 모두 128 pm.

  1. 질문질산 이온(NO₃⁻)의 루이스 구조식을 그리면 N=O 하나와 N–O 둘이 나옵니다. 이중 결합은 단일 결합보다 짧아야 하는데, 실제로 재 보면 세 N–O 결합은 모두 125 pm로 같습니다. 구조식이 틀린 것일까요?
  2. 복원루이스 구조식은 원자가 전자를 결합 전자쌍과 비공유 전자쌍으로 나누어, 각 원자가 옥텟(수소는 2개)을 이루도록 그린 것입니다. 결합 차수가 클수록 결합 길이는 짧고 결합 에너지는 큽니다(대표값: N–O 약 140 pm, N=O 약 120 pm).
  3. 설명공유 전자쌍을 두 원자가 반씩 나눠 가진다고 가정하고, 원자가 원래 가진 원자가 전자 수와 비교한 값을 형식 전하라 합니다. FC = V − N비공유 − (결합 수). 형식 전하의 합은 분자의 전하와 같습니다. 원자 배치는 그대로 두고 전자쌍의 위치만 다르게 그린 구조가 여럿 가능하면 이들을 공명 구조라 하며, 실제 분자는 어느 하나가 아니라 이들이 섞인 공명 혼성체입니다. NO₃⁻에서는 이중 결합의 자리만 다른 동등한 구조 세 개가 있으므로 실제 결합 차수는 모두 4/3입니다.
  4. 연결공명 구조들이 동등하지 않으면 더 안정한 구조가 실제 모습에 더 많이 기여합니다. 판단 기준은 ① 2주기 원자가 옥텟을 이루고, ② 형식 전하의 절댓값이 작으며, ③ 음의 형식 전하가 전기 음성도가 큰 원자에 있고, ④ 같은 부호의 전하가 이웃하지 않는 구조입니다. 전자가 여러 원자에 퍼지는(비편재화) 만큼 에너지가 낮아지는데, 이것이 카복실산 이온·벤젠이 안정한 까닭이며, 뒤에서 다룰 작용기의 산 세기와도 이어집니다.
  5. 적용NO₃⁻에서 이중 결합의 위치를 바꿔 가며 세 구조를 모두 저장하고 평균 결합 차수를 확인하세요. N₂O(N–N–O)에서는 형식 전하의 배치가 다른 구조를 몇 개 만들 수 있나요? 가장 안정한 구조는 무엇이고, 그 까닭은 무엇인가요? CO₂에서 O≡C–O 구조와 O=C=O 구조를 비교해 보세요.
  6. 판단공명 구조는 분자가 여러 구조 사이를 빠르게 오가는 것이 아닙니다. 실제 분자는 언제나 하나의 혼성체이며, 구조식 여러 개는 한 장으로 나타낼 수 없는 전자 분포를 표현하는 도구입니다. 형식 전하도 실제 원자의 부분 전하와 다릅니다(전기 음성도 차이를 무시함). SO₄²⁻에서 형식 전하를 줄이려고 S=O를 그리면 S 주위 전자가 12개가 되는데, 최근 계산은 3d 오비탈의 참여가 거의 없고 S–O 결합이 강한 극성을 띤 구조가 더 실제에 가깝다고 봅니다. ‘형식 전하 최소’ 규칙도 모형의 하나일 뿐입니다.
