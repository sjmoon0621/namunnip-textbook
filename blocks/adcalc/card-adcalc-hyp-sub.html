근호 속의 \(x^2 + 1\)을 없애는 치환은?

쌍곡선함수 치환 · 고르기 · 검산

어떤 치환이 근호를 없앨까요?

칠한 넓이 (수치)
—
치환으로 구한 값
—
구한 식
—
  1. 질문\(\int\frac{dx}{\sqrt{1 - x^2}}\)은 \(x = \sin t\)로 치환하면 \(1 - \sin^2 t = \cos^2 t\) 덕분에 근호가 사라졌다. \(\sqrt{x^2 + 1}\)이나 \(\sqrt{x^2 - 1}\)도 사라지게 하는 치환이 있을까?
  2. 복원\(\cosh^2 t - \sinh^2 t = 1\), \((\sinh t)' = \cosh t\), \((\cosh t)' = \sinh t\). 치환적분법에서는 \(x = g(t)\)이면 \(dx = g'(t)\,dt\)이다.
  3. 설명항등식을 두 가지로 읽으면 된다. \(1 + \sinh^2 t = \cosh^2 t\)이므로 \(x = \sinh t\)이면 \(\sqrt{x^2 + 1} = \cosh t\)이다. \(\cosh^2 t - 1 = \sinh^2 t\)이므로 \(x = \cosh t\ (t \ge 0)\)이면 \(\sqrt{x^2 - 1} = \sinh t\)이다. 예를 들어 \(dx = \cosh t\,dt\)이므로 \[\int\frac{dx}{\sqrt{x^2 + 1}} = \int\frac{\cosh t}{\cosh t}\,dt = t + C\]이고, \(t = \sinh^{-1} x = \ln\left(x + \sqrt{x^2 + 1}\right)\)이다. 넷째 적분은 \(\int\cosh^2 t\,dt = \int\frac{1 + \cosh 2t}{2}\,dt\)가 되어 \(\frac{1}{2}\left(x\sqrt{x^2 + 1} + \sinh^{-1} x\right) + C\)이다.
  4. 연결기본 적분 공식 \(\int\cosh x\,dx = \sinh x + C\), \(\int\sinh x\,dx = \cosh x + C\), \(\int\frac{dx}{\cosh^2 x} = \tanh x + C\)는 도함수 공식을 거꾸로 읽은 것이다. \(\sqrt{x^2 + 1}\)은 \(x = \tan t\)로도 없앨 수 있지만, 그러면 \(\int\sec t\,dt\) 같은 더 까다로운 적분이 남는다.
  5. 적용네 적분마다 근호를 없애는 치환을 고르자. 맞히면 구한 식이 나타난다. \(b\)를 움직이며 칠한 넓이(수치)와 식의 값이 같은지 확인해 보자. 셋째 적분에서 \(b\)를 1에 가깝게 하면 피적분함수는 어떻게 되는가?
  6. 판단\(x = \cosh t\)로 치환할 때는 \(x \ge 1\)이어야 하고, \(\sqrt{\sinh^2 t} = \sinh t\)가 되려면 \(t \ge 0\)으로 잡아야 한다. 치환의 범위를 확인하지 않으면 부호가 틀린 답이 나온다.
