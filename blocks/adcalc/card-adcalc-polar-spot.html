\(\theta = \tan^{-1}\frac{y}{x}\)로 각을 구한 이 풀이, 맞을까?

극좌표와 직교좌표 · 오류 찾기

처음 틀린 줄을 누르세요. 틀린 곳이 없으면 마지막 줄을 누르세요. 초록은 문제, 주황은 풀이의 답입니다.

  1. 점 \((-1, -\sqrt{3})\)을 극좌표로 나타낸다. \(r = \sqrt{1 + 3} = 2\)이다.맞습니다.
  2. \(\tan\theta = \frac{-\sqrt{3}}{-1} = \sqrt{3}\)이므로 \(\theta = \frac{\pi}{3}\)이다.여기가 틀렸습니다. \(\tan\theta = \sqrt{3}\)인 각은 \(\frac{\pi}{3}\)과 \(\frac{4\pi}{3}\) 두 가지입니다. 점이 제3사분면에 있으므로 \(\theta = \frac{4\pi}{3}\)입니다. \(\tan^{-1}\)은 언제나 \(-\frac{\pi}{2}\)와 \(\frac{\pi}{2}\) 사이의 값만 줍니다.
  3. 따라서 극좌표는 \(\left(2, \frac{\pi}{3}\right)\)이다.앞 줄을 이어받았습니다. 이 점은 \((1, \sqrt{3})\)으로, 원래 점의 반대쪽입니다.
  4. 이 풀이에는 틀린 곳이 없다.그림에서 두 점의 위치를 비교하세요.
  1. 점 \((0, -2)\)를 극좌표로 나타낸다. \(r = 2\)이다.맞습니다.
  2. \(\tan\theta = \frac{-2}{0}\)은 정의되지 않으므로 이 점은 극좌표로 나타낼 수 없다.여기가 틀렸습니다. \(\tan\theta = \frac{y}{x}\)는 \(x \ne 0\)일 때만 쓰는 식일 뿐입니다. 점은 \(y\)축의 음의 부분에 있으므로 \(\theta = \frac{3\pi}{2}\), 극좌표는 \(\left(2, \frac{3\pi}{2}\right)\)입니다.
  3. 그러므로 \(y\)축 위의 점은 직교좌표로만 나타낸다.앞 줄을 이어받은 결론입니다.
  4. 이 풀이에는 틀린 곳이 없다.\(\cos\theta = 0\), \(\sin\theta = -1\)인 각을 생각하세요.
  1. 극좌표 \(\left(-2, \frac{4\pi}{3}\right)\)인 점을 직교좌표로 바꾼다.문제를 옮겼습니다.
  2. \(x = -2\cos\frac{4\pi}{3} = -2 \cdot \left(-\frac{1}{2}\right) = 1\)이다.맞습니다.
  3. \(y = -2\sin\frac{4\pi}{3} = -2 \cdot \left(-\frac{\sqrt{3}}{2}\right) = \sqrt{3}\)이므로 점은 \((1, \sqrt{3})\)이다.맞습니다. 음의 \(r\)이어도 \(x = r\cos\theta\), \(y = r\sin\theta\)를 그대로 씁니다.
  4. 이 풀이에는 틀린 곳이 없다.맞습니다. \(\left(-2, \frac{4\pi}{3}\right)\)과 \(\left(2, \frac{\pi}{3}\right)\)은 같은 점입니다.
  1. 극방정식 \(r = 2\cos\theta\)를 직교좌표의 방정식으로 바꾼다.문제를 옮겼습니다.
  2. \(r = \sqrt{x^2 + y^2}\), \(\cos\theta = x\)이므로 \(\sqrt{x^2 + y^2} = 2x\)이다.여기가 틀렸습니다. \(\cos\theta = \frac{x}{r}\)입니다. 양변에 \(r\)을 곱해 \(r^2 = 2r\cos\theta\), 곧 \(x^2 + y^2 = 2x\)로 바꾸어야 합니다.
  3. 제곱하여 정리하면 \(y^2 = 3x^2\ (x \ge 0)\), 곧 두 반직선이다.앞 줄을 이어받았습니다. 바른 답 \((x - 1)^2 + y^2 = 1\)은 원입니다.
  4. 이 풀이에는 틀린 곳이 없다.그림의 곡선이 반직선처럼 보이나요?
  1. 질문직교좌표를 극좌표로 바꿀 때 \(r = \sqrt{x^2 + y^2}\), \(\theta = \tan^{-1}\frac{y}{x}\)로 계산하면 될까? 계산기도 이렇게 하라고 알려 주는 것 같다.
  2. 복원\(x = r\cos\theta\), \(y = r\sin\theta\), \(r^2 = x^2 + y^2\). \(\tan\theta\)는 주기가 \(\pi\)인 함수라, 같은 \(\tan\) 값을 갖는 각이 \(0 \le \theta < 2\pi\)에 두 개 있다.
  3. 설명\(\tan\theta = \frac{y}{x}\)는 각의 후보를 두 개로 좁혀 줄 뿐이다. 점이 몇 사분면에 있는지 보고 하나를 골라야 한다(풀이 1). \(x = 0\)이면 이 식을 쓸 수 없지만 각은 \(\frac{\pi}{2}\)나 \(\frac{3\pi}{2}\)로 정해진다(풀이 2). 극방정식을 직교좌표로 바꿀 때는 \(\cos\theta = \frac{x}{r}\)이므로 양변에 \(r\)을 곱해 \(r\cos\theta\) 꼴을 만드는 것이 요령이다(풀이 4).
  4. 연결프로그래밍 언어의 \(\operatorname{atan2}(y, x)\) 함수는 \(x\), \(y\)의 부호를 함께 보고 사분면까지 맞는 각을 돌려준다. \(\tan^{-1}\frac{y}{x}\)가 사분면을 잃어버리는 문제를 해결하려고 만든 함수이다.
  5. 적용네 풀이에서 처음 틀린 줄을 찾자. 풀이 1의 답은 원래 점과 어떤 관계인가? 풀이 3에서 음의 \(r\)이 나왔는데도 맞는 까닭은 무엇인가?
  6. 판단극방정식 양변에 \(r\)을 곱하면 극(\(r = 0\))이 새 해로 끼어들 수 있다. \(r = 2\cos\theta\)는 이미 \(\theta = \frac{\pi}{2}\)에서 극을 지나므로 괜찮지만, 다른 식에서는 극이 원래 곡선 위에 있는지 따로 확인해야 한다.
