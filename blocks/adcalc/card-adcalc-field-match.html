방향장만 보고 미분방정식을 알아맞힐 수 있을까?

방향장 읽기 · 도전
\(y' = x\)
\(y' = y\)
\(y' = x + y\)
\(y' = -\frac{y}{x}\)

  1. 질문네 방향장 A~D와 네 미분방정식이 있다. 식을 풀지 않고 방향장의 특징만으로 짝을 지을 수 있을까?
  2. 복원방향장의 선분은 점 \((x, y)\)에서의 기울기 \(f(x, y)\)를 나타낸다. 기울기가 양수이면 오른쪽 위로, 음수이면 오른쪽 아래로 기운다.
  3. 설명단서를 찾는 요령은 세 가지이다. ① \(f\)가 \(x\)만의 식이면 같은 세로줄의 선분이 모두 평행하고, \(y\)만의 식이면 같은 가로줄의 선분이 모두 평행한다. ② 기울기가 0인 곳(등경사선)을 찾는다. \(y' = x\)는 \(y\)축 위에서, \(y' = y\)는 \(x\)축 위에서, \(y' = x + y\)는 직선 \(y = -x\) 위에서 수평이다. ③ 부호를 본다. \(y' = -\frac{y}{x}\)는 제1, 3사분면에서 음수이고, 해는 쌍곡선 \(xy = c\)이다.
  4. 연결같은 줄의 선분이 평행하다는 것은 해 곡선끼리 평행이동한 모양이라는 뜻이다. \(y' = x\)의 해는 \(y = \frac{x^2}{2} + C\)로 위아래로 평행이동한 포물선들이고, \(y' = y\)의 해 \(y = Ce^x\)는 좌우로 평행이동한 곡선들이다.
  5. 적용네 방정식의 짝을 고르고 채점해 보자. 틀린 것은 어떤 단서로 다시 볼 수 있는가? 해 곡선을 겹쳐 짝이 맞는지 확인해 보자.
  6. 판단방향장 그림은 몇 개의 점에서만 기울기를 보여 주므로, 그림 사이의 좁은 곳에서 일어나는 일(기울기가 갑자기 커지는 곳 등)은 놓칠 수 있다. \(y' = -\frac{y}{x}\)는 \(x = 0\)에서 정의되지 않는데, 격자에 그 점이 없으면 그림에서는 보이지 않는다.

방향장에서 같은 가로줄(같은 \(y\))의 선분들이 모두 평행했다. 가능한 미분방정식은?
