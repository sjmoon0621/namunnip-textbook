미분방정식의 풀이

본문

미분방정식 \(y' = 2xy\), \(y(0) = 3\)을 풀던 학생이 \(\dfrac{dy}{y} = 2x\,dx\)로 변수를 나누고 양변을 적분해 \(\ln|y| = x^2\)을 얻었다. 그런 다음 \(y = e^{x^2}\)으로 쓰고 적분상수 \(C\)를 붙여 \(y = e^{x^2} + C\)로 놓은 뒤, \(y(0) = 3\)에서 \(C = 2\)를 얻었다. 그런데 \(y = e^{x^2} + 2\)를 원래 식에 넣어 보니 \(y' = 2xe^{x^2}\)이고 \(2xy = 2xe^{x^2} + 4x\)로 서로 달랐다. 어디서 잘못되었을까?

먼저 알아야 할 것치환적분법, 자연로그, 지수함수의 도함수, 방향장(미분방정식과 방향장).

4.3.1변수를 양쪽으로 나누다

\(y' = g(x)h(y)\)처럼 \(x\)만의 식과 \(y\)만의 식의 곱으로 쓸 수 있는 미분방정식을 변수분리형이라 한다. \(h(y) \ne 0\)이면 양변을 \(h(y)\)로 나누어 \(\dfrac{1}{h(y)}\dfrac{dy}{dx} = g(x)\)로 쓰고, 양변을 \(x\)로 적분한다. 왼쪽은 치환적분법에 따라 \(\int\dfrac{dy}{h(y)}\)가 된다. 그래서 \(y\)에 대한 적분과 \(x\)에 대한 적분을 따로 계산해 같다고 놓으면 해의 관계식을 얻는다. 이때 두 부정적분의 적분상수는 하나로 모아 한쪽에 붙인다.

정리 4.3.1 변수분리형 미분방정식의 풀이

\(\dfrac{dy}{dx} = g(x)h(y)\)이면 \[\int\frac{dy}{h(y)} = \int g(x)\,dx + C\]이다. 적분상수 \(C\)는 적분하는 단계에서 붙이고, 초기 조건으로 정한다. \(h(y_0) = 0\)인 \(y_0\)이 있으면 상수함수 \(y = y_0\)도 해이므로 따로 확인한다.

\(y' = 2xy\)에서는 \(\int\dfrac{dy}{y} = \int2x\,dx\)이므로 \(\ln|y| = x^2 + C\)이다. 지수로 바꾸면 \(|y| = e^{x^2 + C} = e^Ce^{x^2}\)이고, 부호까지 합쳐 \(y = Ae^{x^2}\)이다. 적분상수 \(C\)는 지수에 들어가 곱하는 상수 \(A\)로 바뀐다. 나누는 과정에서 \(y = 0\)을 제외했지만 \(y = 0\)도 \(y' = 2xy\)를 만족하므로, \(A = 0\)까지 허용하면 모든 해가 \(y = Ae^{x^2}\)에 들어간다.1

4.3.2끝없이 커지는 해

변수분리형의 해는 모든 \(x\)에서 정의되지 않을 수도 있다. \(y' = y^2\), \(y(0) = 1\)을 풀면 \(\int\dfrac{dy}{y^2} = \int dx\)에서 \(-\dfrac1y = x + C\)이고, 초기 조건으로 \(C = -1\)이므로 \(y = \dfrac{1}{1 - x}\)이다. 이 해는 \(x\)가 1에 다가가면 끝없이 커진다. \(y' = y\)의 해 \(e^x\)는 빨리 커져도 모든 \(x\)에서 유한한데, \(y' = y^2\)은 \(y\)가 클수록 훨씬 빠르게 커져 유한한 시간 안에 무한대가 된다. 그래서 풀이를 마친 뒤에는 해가 정의되는 구간도 함께 적어야 한다.

4.3.3예제 하나를 끝까지

예제 4.3.2

\(y' = 2xy\), \(y(0) = 3\)의 해를 구하고 \(y(1)\)을 구하여라. 구한 해를 원래 식에 넣어 확인하여라.

변수를 나누어 적분하면 \(\ln|y| = x^2 + C\)이고, 지수로 바꾸면 \(y = Ae^{x^2}\)이다. \(y(0) = A = 3\)이므로 해는 \(y = 3e^{x^2}\)이고, \(y(1) = 3e \approx 8.15\)이다.

확인하면 \(y' = 3e^{x^2}\cdot2x = 6xe^{x^2}\)이고 \(2xy = 2x\cdot3e^{x^2} = 6xe^{x^2}\)이므로 같다. 또 \(y(0) = 3\)이다. 처음 질문의 학생은 적분할 때 상수를 빠뜨리고 지수로 바꾼 뒤에 더해서, 곱하는 상수여야 할 것을 더하는 상수로 만들었다. \(y = e^{x^2} + C\)는 \(C = 0\)일 때만 해이다. 즉 변수분리형 미분방정식은 \(x\)와 \(y\)를 양쪽으로 나누어 각각 적분해 풀고, 적분상수는 적분하는 단계에서 붙여야 하며, 구한 해는 원래 식에 넣어 확인하고 정의되는 구간도 살핀다.

아래 탐구 카드에서 \(y' = 2xy\)를 변수분리로 풀어 방향장과 비교하고, 초기 조건을 넣은 풀이에서 틀린 곳을 찾아보자.

  1. 변수를 나누는 방법은 1691년 라이프니츠가 처음 썼고, 변수분리라는 이름은 1694년 요한 베르누이가 붙였다. \(dy/dx\)를 분수처럼 나누어 쓰는 라이프니츠의 기호가 이 풀이를 자연스럽게 만들어 주었다.
마무리

변수분리형 미분방정식 \(y' = g(x)h(y)\)은 \(\int dy/h(y) = \int g(x)\,dx + C\)로 풀며, 적분상수는 적분하는 단계에서 붙이고 초기 조건으로 정한다. \(h(y) = 0\)인 상수 해를 따로 확인하고, 해가 유한한 \(x\)에서 무한대가 될 수 있으므로 정의되는 구간도 적는다. 처음 질문의 해는 \(y = e^{x^2} + 2\)가 아니라 \(y = 3e^{x^2}\)이며, 상수를 지수로 바꾼 뒤에 더한 것이 잘못이었다.
