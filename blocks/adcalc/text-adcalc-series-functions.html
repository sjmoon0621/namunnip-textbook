멱급수의 성질과 함수의 표현

본문

등비급수 \(\dfrac{1}{1 + t^2} = 1 - t^2 + t^4 - \cdots\)를 0부터 \(x\)까지 항마다 적분하면 \(\tan^{-1}x = x - \dfrac{x^3}{3} + \dfrac{x^5}{5} - \cdots\)가 나온다. \(x = 1\)을 넣으면 \(\dfrac\pi4 = 1 - \dfrac13 + \dfrac15 - \cdots\)인데, 이 급수로는 1000항을 더해도 소수 셋째 자리밖에 맞지 않는다. 그런데 1706년 마친은 같은 급수를 조금 다르게 써서 손으로 원주율을 소수 100자리까지 구했다. 급수를 항마다 적분해도 괜찮을까? 그리고 어떻게 해야 급수가 빨리 수렴할까?

먼저 알아야 할 것등비급수, 여러 가지 함수의 적분, 멱급수와 수렴반경(멱급수와 수렴반경).

3.5.1멱급수는 다항식처럼 다룬다

멱급수는 수렴반경 안에서 항이 무한히 많은 다항식처럼 다룰 수 있다. 수렴반경이 \(R\)인 멱급수가 나타내는 함수는 \(|x| < R\)에서 미분할 수 있고, 그 도함수는 각 항을 미분한 급수와 같다. 적분도 각 항을 적분한 급수와 같으며, 미분하거나 적분해도 수렴반경은 바뀌지 않는다. 그래서 이미 아는 등비급수 \(\dfrac{1}{1 - t} = \sum t^n\)에서 출발해 \(t\)에 다른 식을 넣거나, 항마다 미분하거나 적분하면 새 함수의 멱급수를 얻는다.

정리 3.5.1 항별 미분과 항별 적분

\(f(x) = \sum_{n=0}^{\infty}a_nx^n\)의 수렴반경이 \(R > 0\)이면 \(|x| < R\)에서 \[f'(x) = \sum_{n=1}^{\infty}na_nx^{n-1},\qquad \int_0^x f(t)\,dt = \sum_{n=0}^{\infty}\frac{a_n}{n+1}x^{n+1}\]이고, 두 급수의 수렴반경도 \(R\)이다.

\(\ln(1 + x)\)는 \(\dfrac{1}{1 + t} = 1 - t + t^2 - \cdots\)를 0부터 \(x\)까지 적분해 \(x - \dfrac{x^2}{2} + \dfrac{x^3}{3} - \cdots\)이다. \(\tan^{-1}x\)는 \(\dfrac{1}{1 + t^2}\)을 적분해 얻는다. 두 급수는 \(|x| < 1\)에서 수렴하고, 경계 \(x = 1\)에서도 교대급수로 수렴해 \(\ln 2\)와 \(\pi/4\)를 준다. 다만 경계에서 수렴하는지는 정리가 보장하지 않으므로 따로 확인해야 한다.1

3.5.2작은 \(x\)를 넣어야 빠르다

\(\tan^{-1}1\)의 급수는 항이 \(1/(2n + 1)\)로 아주 느리게 줄어, 오차가 다음 항보다 작다는 교대급수의 성질로 보아도 소수 셋째 자리를 맞추는 데 500항이 넘게 필요하다. 반면 \(x\)가 작으면 항이 \(x^{2n+1}\)처럼 빠르게 줄어 몇 항만으로 정확해진다. 그래서 \(\pi/4\)를 작은 각들의 역탄젠트로 나누어 쓴다. 마친은 탄젠트의 덧셈정리로 \(\dfrac\pi4 = 4\tan^{-1}\dfrac15 - \tan^{-1}\dfrac{1}{239}\)를 찾아, \(x = 1/5\)과 \(x = 1/239\)를 넣은 급수로 원주율을 구했다.

3.5.3예제 하나를 끝까지

예제 3.5.2

\(\ln(1 + x)\)의 급수로 \(\ln 1.1\)을 넷째 항까지 구하여라. 또 \(\tan^{-1}\tfrac15\)을 넷째 항까지, \(\tan^{-1}\tfrac{1}{239}\)을 첫째 항까지 구해 마친의 식으로 \(\pi\)를 계산하여라.

\(\ln1.1 \approx 0.1 - 0.005 + 0.000333 - 0.000025 = 0.095308\)이다. 참값 \(0.0953102\cdots\)과 소수 다섯째 자리까지 같고, 오차는 다섯째 항 \(0.1^5/5 = 0.000002\)보다 작다.

\(\tan^{-1}\tfrac15 \approx 0.2 - \dfrac{0.008}{3} + \dfrac{0.00032}{5} - \dfrac{0.0000128}{7} = 0.2 - 0.0026667 + 0.000064 - 0.0000018 = 0.1973955\)이다. \(\tan^{-1}\tfrac{1}{239} \approx 1/239 \approx 0.0041841\)이다. 그러면 \(\dfrac\pi4 \approx 4\times0.1973955 - 0.0041841 = 0.7853979\)이고, \(\pi \approx 3.141592\)로 소수 다섯째 자리까지 맞는다. 즉 멱급수는 수렴반경 안에서 항마다 미분하고 적분할 수 있어 등비급수 하나로 여러 함수의 급수를 만들 수 있고, 수렴을 빠르게 하려면 작은 \(x\)를 넣도록 식을 바꾼다.

아래 탐구 카드에서 \(\dfrac{1}{1 - x}\) 하나로 \(\ln(1 + x)\)와 \(\tan^{-1}x\)의 급수를 만들어 보고, 여러 공식으로 원주율 계산 경주를 해 보자.

  1. \(\tan^{-1}x\)의 급수는 14세기 인도 케랄라의 마다바가 처음 찾았고, 유럽에서는 17세기에 그레고리와 라이프니츠가 다시 찾았다. 마친의 식과 비슷한 공식들은 컴퓨터가 원주율을 수조 자리까지 계산할 때도 검산에 쓰였다.
마무리

멱급수는 수렴반경 안에서 항마다 미분하고 적분할 수 있으며 수렴반경은 바뀌지 않으므로, 등비급수에 식을 대입하고 항별로 적분해 \(\ln(1 + x)\), \(\tan^{-1}x\) 같은 함수의 급수를 만든다. 경계에서의 수렴은 따로 확인하고, 수렴을 빠르게 하려면 작은 \(x\)를 넣도록 바꾸어 쓴다. 처음 질문의 \(\tan^{-1}1\)의 급수는 매우 느리지만, 마친의 식으로 \(x = 1/5\)과 \(1/239\)를 넣으면 몇 항만으로 원주율을 소수 다섯째 자리까지 맞힌다.
