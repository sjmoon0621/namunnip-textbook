이 수열은
—
  1. 질문일반항 식이 없어도 '첫째항은 1이고, 각 항에 2를 더하면 다음 항이 된다'고 하면 수열이 하나로 정해질까요?
  2. 복원등차수열은 이웃한 항의 차가 공차 d로 일정하고, 등비수열은 이웃한 항의 비가 공비 r로 일정합니다.
  3. 설명수열을 ① 첫째항 a1의 값과 ② 이웃한 항 사이의 관계식(예: an+1 = 2an + 1, n = 1, 2, 3, …)으로 정하는 것을 수열의 귀납적 정의라고 합니다. a1에서 관계식으로 a2를, a2에서 a3을 차례로 얻으므로 모든 항이 하나로 정해집니다. 등차수열은 an+1 = an + d, 등비수열은 an+1 = ran으로 나타냅니다. 또 2an+1 = an + an+2는 등차수열, an+12 = anan+2는 등비수열의 귀납적 표현입니다(등차중항·등비중항).
  4. 연결일반항은 n을 넣으면 바로 그 항을 주는 '직접 계산', 귀납적 정의는 앞 항에서 다음 항을 만드는 '한 단계씩 계산'입니다. 컴퓨터 프로그램의 반복문과 같은 생각이고, 다음 카드처럼 세는 문제를 나타내는 데 특히 편합니다.
  5. 적용'다음 항 만들기'를 여러 번 눌러 보세요. 세 가지 규칙에서 점들이 어떻게 놓이나요? 같은 관계식에서 첫째항만 바꾸면 어떻게 되나요? '곱하고 더하기'에서 첫째항을 4로 바꾸면 무엇이 보이나요?
  6. 판단관계식만 있고 첫째항이 없으면 수열이 정해지지 않습니다. 같은 an+1 = an + 2라도 첫째항이 1이면 홀수, 2이면 짝수의 수열입니다. 또 관계식의 n이 어디서부터 성립하는지(n = 1, 2, 3, …)도 함께 밝혀야 합니다.
