지수함수의 화살표를 거꾸로 하면 함수가 될까?

로그함수의 뜻 · 대응의 방향

—

\(x\)
—
\(y = \log_a x\)
—
검산 \(a^y\)
—

회색 화살표는 \(a^k\)와 \(k(k = -3, \cdots, 3)\)의 대응이고, 주황 화살표가 지금 고른 \(x\)입니다. 왼쪽 열은 수가 몇 배씩 커지는 간격으로 놓았습니다.

  1. 질문세균 수가 1시간마다 2배가 되면 처음의 5배가 되는 데 몇 시간이 걸릴까요? "시간 → 배율"을 거꾸로 "배율 → 시간"으로 읽는 대응도 함수일까요?
  2. 복원함수 \(f\)가 일대일대응이면 화살표를 거꾸로 한 역함수 \(f^{-1}\)가 있고, \(f\)의 정의역과 치역이 서로 바뀝니다. \(a^x = N \Leftrightarrow x = \log_a N\)입니다.
  3. 설명\(a > 0\), \(a \ne 1\)일 때 지수함수 \(y = a^x\)는 실수 전체에서 양의 실수 전체로 가는 일대일대응입니다. 서로 다른 \(x\)는 서로 다른 값으로 가고, 모든 양수가 한 번씩 값으로 나오기 때문입니다. 그래서 화살표를 거꾸로 해도 양수 \(x\)마다 \(y\)가 하나씩 정해지는데, 그 \(y\)가 바로 \(\log_a x\)입니다. 이 함수 \(y = \log_a x\)를 \(a\)를 밑으로 하는 로그함수라 합니다. 로그함수는 지수함수의 역함수이고, 정의역은 양의 실수 전체, 치역은 실수 전체입니다. 지수함수와 정의역·치역이 서로 바뀐 것입니다.
  4. 연결세균 문제의 답은 \(\log_2 5 \approx 2.32\)시간입니다. 지수함수가 "시간이 지나면 얼마가 되나"를 답한다면, 로그함수는 "얼마가 되려면 시간이 얼마나 걸리나"를 답합니다. 다음 절에서는 역함수 관계를 그래프의 대칭으로 확인합니다.
  5. 적용두 방향 보기를 번갈아 눌러 화살표가 어떻게 바뀌는지 보세요. 왼쪽 열에서 0이나 음수가 없는 까닭은 무엇인가요? \(x\)를 0.05까지 줄이면 \(y\)는 어떻게 되나요? 밑을 \(\frac{1}{2}\)로 바꾸면 왼쪽 열의 순서는 어떻게 되나요?
  6. 판단"로그함수의 치역은 양수"라고 하는 실수가 있습니다. 양수여야 하는 것은 진수, 곧 입력 \(x\)이고, 출력 \(\log_a x\)는 \(0 < x < 1\)에서 (밑이 1보다 크면) 음수가 됩니다. 지수함수와 로그함수의 정의역·치역을 바꿔 적지 않도록, 늘 "어느 쪽이 지수인가"를 먼저 따지세요.
