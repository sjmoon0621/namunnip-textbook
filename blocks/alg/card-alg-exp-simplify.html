식의 수를 모두 소인수 2와 3의 거듭제곱으로 바꾼 뒤, 각 밑의 지수를 따로 적어 갑니다.

  1. 질문43/2 × 8−1/3 ÷ √2는 밑도 지수도 제각각입니다. 계산기 없이 정리할 수 있을까요?
  2. 복원밑이 양수이고 지수가 실수일 때 axay = ax+y, ax ÷ ay = ax−y, (ax)y = axy, (ab)x = axbx입니다. 거듭제곱근은 n√a = a1/n입니다.
  3. 설명정리하는 순서는 늘 같습니다. 첫째, 근호를 유리수 지수로 바꿉니다. 둘째, 밑을 소인수의 거듭제곱으로 바꿉니다(4 = 22, 8 = 23, 27 = 33). 셋째, (ax)y = axy로 지수를 곱하고, (ab)x = axbx로 밑을 나눕니다. 넷째, 같은 밑끼리 곱셈은 지수를 더하고 나눗셈은 지수를 뺍니다. 그림의 수직선은 밑마다 지수를 적어 두는 장부입니다. 곱하면 오른쪽, 나누면 왼쪽으로 화살표가 이어지고, 마지막 위치가 답의 지수입니다.
  4. 연결이 방법은 단위 환산(1 km2 = (103 m)2 = 106 m2)이나 과학 표기 계산에서 그대로 쓰입니다. 밑을 하나로 맞추는 생각은 지수방정식을 풀 때도 첫 단계가 됩니다.
  5. 적용세 식을 하나씩 골라 "다음 단계"를 누르며 화살표가 어느 쪽으로 얼마나 움직이는지 보세요. 마지막 값이 처음 식을 직접 계산한 값과 같은지 아래 수치에서 확인하세요. 세 번째 식은 왜 장부가 두 줄 필요한가요?
  6. 판단43/2을 (43)/2 = 32나 4 × 3/2 = 6으로 계산하는 실수가 흔합니다. 43/2 = (22)3/2 = 23 = 8입니다. 또 밑이 다른 거듭제곱(23 × 32)은 지수를 더해 합칠 수 없습니다. 밑이 같아질 때까지 소인수로 나눈 뒤에만 지수를 더합니다.
