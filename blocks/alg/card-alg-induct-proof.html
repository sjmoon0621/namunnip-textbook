P(k)에서 P(k + 1)로 어떻게 건너갈까?

수학적 귀납법 · 등식의 증명

—

1 + 3 + … + (2k − 1)
—
더하는 홀수 2k + 1
—
(k + 1)2
—
  1. 질문모든 자연수 n에 대해 1 + 3 + 5 + … + (2n − 1) = n2임을 수학적 귀납법으로 증명해 봅시다. 가장 어려운 곳은 'P(k)이면 P(k + 1)'입니다. 무엇을 가정하고 무엇을 보여야 할까요?
  2. 복원수학적 귀납법은 ① P(1)이 참이고 ② P(k)가 참이라고 가정하면 P(k + 1)도 참임을 보이는 증명 방법입니다. 1부터 k번째 홀수까지의 합에 (k + 1)번째 홀수 2k + 1을 더하면 (k + 1)번째 홀수까지의 합입니다.
  3. 설명① n = 1일 때 왼쪽은 1, 오른쪽은 12 = 1이므로 성립합니다. ② n = k일 때 1 + 3 + … + (2k − 1) = k2이 성립한다고 가정합니다. 양변에 다음 홀수 2k + 1을 더하면 1 + 3 + … + (2k − 1) + (2k + 1) = k2 + 2k + 1 = (k + 1)2입니다. 이것은 P(k + 1)입니다. ①, ②에서 모든 자연수 n에 대해 등식이 성립합니다.
  4. 연결그림에서 한 변이 k인 정사각형(가정)에 2k + 1개의 칸을 ㄱ자로 붙이면 한 변이 k + 1인 정사각형이 됩니다. 식의 k2 + 2k + 1 = (k + 1)2이 바로 이 그림입니다. 같은 틀로 ∑k = n(n + 1)/2, ∑k2 = n(n + 1)(2n + 1)/6도 증명할 수 있습니다. 앞 절에서 구한 공식들이 모든 n에서 맞다는 보증이 여기서 나옵니다.
  5. 적용'다음 단계'를 눌러 증명의 네 단계를 따라가세요. k를 바꾸어도 ㄱ자 조각의 칸 수가 늘 2k + 1이고, 결과가 늘 정사각형인지 확인하세요.
  6. 판단②에서 P(k)는 증명할 대상이 아니라 가정입니다. '증명하려는 것을 가정했으니 순환 논리'라는 오해가 흔하지만, 가정한 것은 P(k)이고 보인 것은 P(k + 1)입니다. 또 P(k + 1)의 식에서 양변을 따로 계산해 맞추지 말고, P(k)의 식에서 출발해 P(k + 1)의 식에 이르러야 합니다.

확인조건이 달라지면

1 + 2 + 4 + … + 2n−1 = 2n − 1을 수학적 귀납법으로 증명합니다. n = k일 때 성립한다고 가정한 뒤 양변에 더할 것은?
