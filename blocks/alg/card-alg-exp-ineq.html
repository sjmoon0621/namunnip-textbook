지수부등식에서 부등호는 언제 뒤집힐까?

지수·로그 방정식과 부등식 · 그래프로 풀기

—

경계값
—
부등호 방향
—
해
—

주황색으로 칠한 x축 구간이 해입니다. 속이 빈 점은 해에 들지 않는 끝점입니다.

  1. 질문2x > 4의 해는 x > 2입니다. 그러면 (1/2)x > 4의 해도 x > 2일까요? log2 x < 3의 해는 x < 8이면 될까요?
  2. 복원a > 1이면 y = ax와 y = loga x는 증가하고, 0 < a < 1이면 감소합니다. ax > 0이고, 로그의 진수는 양수여야 합니다.
  3. 설명증가함수에서는 "값이 크다 ⇔ 입력이 크다", 감소함수에서는 "값이 크다 ⇔ 입력이 작다"입니다. 그래서 af(x) > ag(x)는 a > 1이면 f(x) > g(x), 0 < a < 1이면 f(x) < g(x)로 부등호가 바뀝니다. 방정식 ax = k(k > 0)의 해는 x = loga k 하나입니다. 로그부등식 loga f(x) > loga g(x)는 먼저 진수 조건 f(x) > 0, g(x) > 0을 세우고, 그다음 밑에 따라 진수의 대소를 비교한 뒤 두 조건을 함께 만족하는 범위를 답합니다.
  4. 연결4x − 3 · 2x + 2 = 0처럼 같은 밑이 거듭 나오면 2x = t(t > 0)로 두고 이차방정식으로 풉니다. 이때도 t가 양수라는 조건을 잊지 않아야 합니다. 이 식의 해는 t = 1, 2에서 x = 0, 1입니다.
  5. 적용부등호를 >로 두고 밑을 2에서 0.5로 바꾸면 칠한 구간은 어느 쪽으로 넘어가나요? k를 0 이하로 내리면 ax > k와 ax < k의 해는 각각 어떻게 되나요? 로그 모드에서 <를 고르면 해의 왼쪽 끝은 어디인가요?
  6. 판단로그부등식에서 진수 조건을 빠뜨리는 실수가 가장 흔합니다. log2 x < 3의 해는 x < 8이 아니라 0 < x < 8입니다. 또 밑에 문자가 있으면(예: ax > a2) a > 1인 경우와 0 < a < 1인 경우로 나누어 풀어야 합니다.
