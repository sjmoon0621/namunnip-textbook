큰 각과 마주 보는 변은 얼마나 길까?

사인법칙 · 외접원

—

\(a / \sin A\)
—
\(b / \sin B\)
—
\(c / \sin C\)
—
외접원의 지름 2R
—

꼭짓점을 끌어 삼각형을 바꿔 보세요. 길이는 눈금 한 칸을 1로 잰 값입니다.

  1. 질문삼각형에서 큰 각과 마주 보는 변이 더 깁니다. 그런데 각이 2배가 되면 변도 2배가 될까요? 변의 길이와 마주 보는 각 사이에 정확한 관계식이 있을까요?
  2. 복원삼각형 ABC에서 \(\angle A, \angle B, \angle C\)의 크기를 A, B, C로, 그 대변의 길이를 \(a, b, c\)로 씁니다. 한 원에서 같은 호에 대한 원주각은 크기가 같고, 지름에 대한 원주각은 \(90^\circ\)입니다.
  3. 설명삼각형 ABC의 외접원의 반지름을 R이라 하면 \(a/\sin A = b/\sin B = c/\sin C = 2R\)입니다. 이것을 사인법칙이라 합니다. 이유는 이렇습니다. B를 지나는 지름 \(BA'\)을 그으면 \(\angle BCA' = 90^\circ\)이고, A가 예각이면 \(\angle A' = A\)입니다. 직각삼각형 \(A'BC\)에서 \(\sin A = \frac{a}{2R}\)이므로 \(a = 2R \sin A\)입니다. A가 직각이면 \(a\)가 곧 지름이고 \(\sin 90^\circ = 1\)이며, A가 둔각이면 \(\angle A' = 180^\circ - A\)이고 \(\sin(180^\circ - A) = \sin A\)라서 같은 식이 나옵니다. 그래서 변의 길이는 각 자체가 아니라 그 각의 사인에 비례합니다: \(a : b : c = \sin A : \sin B : \sin C\).
  4. 연결한 변과 두 각을 알면(두 각을 알면 세 번째 각도 압니다) 나머지 변을 구할 수 있습니다. 직접 잴 수 없는 강 건너의 거리나 산의 높이를 측량할 때 쓰는 방법입니다. 두 변과 끼인각이 주어지면 다음 카드의 코사인법칙을 씁니다.
  5. 적용꼭짓점을 끌어 모양을 바꾸며 네 값이 언제나 같은지 보세요. "\(A = 90^\circ\)"를 누르면 \(a\)와 2R은 어떤 관계인가요? 증명 보기를 켜고 A를 원 위에서 움직이면 \(\angle A'\)이 \(\angle A\)와 늘 같은지 확인하세요. A가 둔각일 때 \(A'\)은 어느 쪽 호에 있나요?
  6. 판단"\(a : b : c = A : B : C\)"라고 생각하기 쉽지만 틀립니다. \(30^\circ, 60^\circ, 90^\circ\) 삼각형의 세 변의 비는 \(1 : \sqrt{3} : 2\)이지 1 : 2 : 3이 아닙니다. 또 두 변과 한 대각이 주어질 때 \(\sin B\) 값만으로 B를 구하면, B와 \(180^\circ - B\) 두 경우가 생길 수 있으니 삼각형이 되는지 따로 확인해야 합니다.
