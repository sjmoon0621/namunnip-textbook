로그

본문

\(2^x = 8\)이면 \(x = 3\)이다. 그런데 \(2^x = 5\)를 만족하는 \(x\)는 2와 3 사이 어딘가에 있지만, 정수도 깔끔한 분수도 아니다. 이 수를 어떻게 이름 붙이고, 어떻게 계산할까?

먼저 알아야 할 것실수 지수의 뜻(지수의 확장), 지수법칙(지수법칙), \(y = a^x\) 꼴의 그래프.

1.4.1지수를 묻는 기호

\(2^x\)는 \(x\)가 커지면 계속 커지고, 모든 양수 값을 한 번씩 지난다. 그림 1처럼 높이 5를 지나는 곳이 한 군데뿐이므로, \(2^x = 5\)인 실수 \(x\)는 하나로 정해진다. 이 수를 '2를 밑으로 하는 5의 로그'라 하고 \(\log_2 5\)로 쓴다. 즉 \(\log_2 5\)는 '2를 몇 제곱하면 5가 되는가'의 답이다.

정의 1.4.1 로그

\(a > 0\), \(a \ne 1\), \(N > 0\)일 때, \(a^x = N\)을 만족하는 실수 \(x\)를 \(a\)를 밑으로 하는 \(N\)의 로그라 하고 \(x = \log_a N\)으로 나타낸다. 이때 \(N\)을 진수라 한다. \[a^x = N \iff x = \log_a N\]

정의의 조건에는 까닭이 있다. 밑이 1이면 \(1^x\)은 언제나 1이라 5가 될 수 없고, 밑이 음수이면 실수 지수가 정해지지 않는다. 진수가 양수인 것은 \(a^x\)가 언제나 양수이기 때문이다. 정의에서 바로 \(\log_a 1 = 0\), \(\log_a a = 1\)이 나온다.

1.4.2로그의 성질

로그는 지수를 돌려 읽은 것이므로, 지수법칙이 그대로 로그의 성질이 된다. \(\log_a M = x\), \(\log_a N = y\)로 두면 \(M = a^x\), \(N = a^y\)이다. 그러면 \(MN = a^{x+y}\)이므로 \(\log_a MN = x + y\)이다. 다시 말해 진수의 곱셈이 로그의 덧셈으로 바뀐다. 그림 1에서 높이를 2배 할 때마다 \(x\)좌표가 1씩 늘어나는 것도 이 성질이다.

정리 1.4.2 로그의 성질

\(a > 0\), \(a \ne 1\), \(M > 0\), \(N > 0\)일 때 \[\log_a MN = \log_a M + \log_a N,\quad \log_a \frac{M}{N} = \log_a M - \log_a N,\quad \log_a M^k = k\log_a M\ (k\text{는 실수})\]

밑이 다른 로그는 밑을 바꾸어 비교한다. \(\log_a b = x\)이면 \(a^x = b\)이고, 양변에 밑이 \(c\)인 로그를 취하면 \(x\log_c a = \log_c b\)이다. 따라서 \(\log_a b = \dfrac{\log_c b}{\log_c a}\)이고, 이것을 밑변환 공식이라 한다.1

1.4.3예제 하나를 끝까지

예제 1.4.3

\(\log_2 3 = a\), \(\log_2 5 = b\)일 때 \(\log_2 60\)과 \(\log_3 10\)을 \(a\), \(b\)로 나타내어라.

\(60 = 2^2 \times 3 \times 5\)이므로 \(\log_2 60 = \log_2 2^2 + \log_2 3 + \log_2 5 = 2 + a + b\)이다. 곱셈이 덧셈으로 바뀌어 각 소인수의 로그만 알면 된다.

\(\log_3 10\)은 밑이 3이므로 밑을 2로 바꾼다. \(\log_3 10 = \dfrac{\log_2 10}{\log_2 3} = \dfrac{\log_2 2 + \log_2 5}{a} = \dfrac{1 + b}{a}\)이다.

확인해 보자. \(a \approx 1.585\), \(b \approx 2.322\)이므로 \(\log_2 60 \approx 5.907\)이고, 실제로 \(2^{5.907} \approx 60\)이다. 또 \(\dfrac{1 + b}{a} \approx 2.096\)이고 \(3^{2.096} \approx 10\)이다. 아래 탐구 카드에서 그래프의 높이와 가로 좌표를 오가며 로그를 직접 읽어 보자.

  1. 밑변환 공식에서 \(c = b\)로 두면 \(\log_a b = \dfrac{1}{\log_b a}\)이다. 가령 \(\log_2 8 = 3\)이고 \(\log_8 2 = \tfrac{1}{3}\)이다.
마무리

로그 \(\log_a N\)은 '\(a\)를 몇 제곱하면 \(N\)이 되는가'의 답으로, 지수 관계를 거꾸로 읽은 것이다. 그래서 지수법칙이 로그의 성질이 되어 진수의 곱은 로그의 합으로, 거듭제곱은 곱으로 바뀐다. 처음 질문의 수는 \(\log_2 5\)이고, 약 2.32이다.
