여러 가지 수열의 합

본문

\(1 + 2 + \cdots + n\)은 \(\dfrac{n(n + 1)}{2}\)이었다. 그렇다면 \(1^2 + 2^2 + \cdots + n^2\)과 \(1^3 + 2^3 + \cdots + n^3\)은 어떤 식일까? 그리고 \(\dfrac{1}{1 \times 2} + \dfrac{1}{2 \times 3} + \cdots\)처럼 분수가 이어진 합은 어떻게 구할까?

먼저 알아야 할 것\(\sum\)의 뜻과 성질(합의 기호 ∑), 등차수열의 합, 곱셈 공식 \((a + b)^3\), 분수식의 계산.

3.5.1세 가지 기본 공식

정리 3.5.1 자연수의 거듭제곱의 합

\[\sum_{k=1}^{n} k = \frac{n(n + 1)}{2},\qquad \sum_{k=1}^{n} k^2 = \frac{n(n + 1)(2n + 1)}{6},\qquad \sum_{k=1}^{n} k^3 = \left\{\frac{n(n + 1)}{2}\right\}^2\]

세제곱의 합이 자연수의 합의 제곱이라는 것은 그림 1로 볼 수 있다. 한 변이 \(1 + 2 + \cdots + k\)인 정사각형에서 한 변이 \(1 + 2 + \cdots + (k - 1)\)인 정사각형을 빼면 L자 띠가 남는데, 이 띠의 넓이가 정확히 \(k^3\)이다.1 그래서 띠를 \(k = 1\)부터 \(n\)까지 차례로 두르면 \(\sum k^3\)이 한 변 \(\sum k\)인 정사각형의 넓이와 같아진다.

3.5.2제곱의 합을 유도하기

제곱의 합은 곱셈 공식으로 유도한다. \((k + 1)^3 - k^3 = 3k^2 + 3k + 1\)을 \(k = 1\)부터 \(n\)까지 모두 더해 보자. 왼쪽은 \((2^3 - 1^3) + (3^3 - 2^3) + \cdots + \{(n + 1)^3 - n^3\}\)이므로 가운데 항이 서로 지워지고 \((n + 1)^3 - 1\)만 남는다.

오른쪽은 \(3\displaystyle\sum k^2 + 3\sum k + n\)이다. 따라서 \((n + 1)^3 - 1 = 3\displaystyle\sum k^2 + \frac{3n(n + 1)}{2} + n\)이고, \(\sum k^2\)에 대해 정리하면 \(\dfrac{n(n + 1)(2n + 1)}{6}\)이 나온다. 다시 말해 모르는 합을 이웃한 두 항의 차로 나타내면, 더하는 동안 대부분이 지워진다.

3.5.3차로 쪼개는 분수의 합

같은 생각을 분수에 쓸 수 있다. \(\dfrac{1}{k(k + 1)} = \dfrac{1}{k} - \dfrac{1}{k + 1}\)이므로 \(\displaystyle\sum_{k=1}^{n}\frac{1}{k(k + 1)} = \left(1 - \frac{1}{2}\right) + \left(\frac{1}{2} - \frac{1}{3}\right) + \cdots + \left(\frac{1}{n} - \frac{1}{n + 1}\right)\)이다. 가운데 항이 모두 지워져 \(1 - \dfrac{1}{n + 1} = \dfrac{n}{n + 1}\)이 남는다.

3.5.4예제 하나를 끝까지

예제 3.5.2

\(\displaystyle\sum_{k=1}^{10} k(k + 2)\)와 \(\displaystyle\sum_{k=1}^{20} \frac{1}{(2k - 1)(2k + 1)}\)의 값을 구하여라.

첫째 합은 전개해 \(\displaystyle\sum (k^2 + 2k) = \sum k^2 + 2\sum k\)로 나눈다. \(\displaystyle\sum_{k=1}^{10} k^2 = \frac{10 \times 11 \times 21}{6} = 385\), \(\displaystyle\sum_{k=1}^{10} k = 55\)이므로 답은 \(385 + 110 = 495\)이다.

둘째 합은 \(\dfrac{1}{(2k - 1)(2k + 1)} = \dfrac{1}{2}\left(\dfrac{1}{2k - 1} - \dfrac{1}{2k + 1}\right)\)로 쪼갠다. 오른쪽을 통분하면 \(\dfrac{1}{2} \times \dfrac{2}{(2k - 1)(2k + 1)}\)이므로 맞는다. 더하면 가운데가 지워져 \(\dfrac{1}{2}\left(1 - \dfrac{1}{41}\right) = \dfrac{20}{41}\)이다.

\(k = 1, 2\)만 직접 더해 확인하면 \(\tfrac{1}{3} + \tfrac{1}{15} = \tfrac{6}{15} = \tfrac{2}{5}\)이고, 공식에 \(n = 2\)를 넣은 \(\tfrac{1}{2}(1 - \tfrac{1}{5}) = \tfrac{2}{5}\)와 같다. 아래 탐구 카드에서 정사각형과 L자 띠를 직접 쌓으며 공식들을 확인해 보자.

  1. \(T_k = \tfrac{k(k + 1)}{2}\)라 하면 띠의 넓이는 \(T_k^2 - T_{k-1}^2 = (T_k - T_{k-1})(T_k + T_{k-1}) = k \times k^2 = k^3\)이다.
마무리

자연수, 제곱수, 세제곱수의 합은 공식으로 정리되며, 제곱의 합은 \((k + 1)^3 - k^3\)을 더해 가운데 항을 지우는 방법으로, 세제곱의 합은 L자 띠를 둘러 정사각형을 만드는 그림으로 얻는다. 분수의 합도 이웃한 항의 차로 쪼개면 처음과 끝만 남는다. 그래서 처음 질문의 합은 \(\tfrac{n(n + 1)(2n + 1)}{6}\), \(\left\{\tfrac{n(n + 1)}{2}\right\}^2\), \(\tfrac{n}{n + 1}\)이다.
