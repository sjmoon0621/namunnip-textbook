1² + 2² + … + n²은 어떻게 구할까?

여러 가지 수열의 합 · 자연수의 제곱의 합

—

하나씩 더한 ∑k2
—
n(n+1)(2n+1)/6
—
(n+1)3 − 1
—
  1. 질문1 + 2 + … + n은 거꾸로 더해 짝을 지으면 구할 수 있었습니다. 그런데 12 + 22 + … + n2은 짝의 합이 같지 않습니다. 어떻게 구할까요?
  2. 복원(a + b)3 = a3 + 3a2b + 3ab2 + b3입니다. 그리고 ∑k=1n k = n(n + 1)/2, ∑k=1n 1 = n입니다.
  3. 설명항등식 (k + 1)3 − k3 = 3k2 + 3k + 1에 k = 1, 2, …, n을 넣어 n개의 줄을 만들고 모두 더합니다. 왼쪽은 위 줄의 (k + 1)3과 아래 줄의 k3이 같아서 서로 지워지고 (n + 1)3 − 13만 남습니다. 오른쪽은 3∑k2 + 3∑k + n입니다. 따라서 3∑k2 = (n + 1)3 − 1 − 3n(n + 1)/2 − n이고, 정리하면 ∑k=1n k2 = n(n + 1)(2n + 1)/6입니다.
  4. 연결같은 방법으로 (k + 1)2 − k2 = 2k + 1을 쓰면 ∑k = n(n + 1)/2를, (k + 1)4 − k4을 쓰면 ∑k3을 얻습니다. 이웃한 줄끼리 지워지게 만드는 이 생각은 등비수열의 합에서 S − rS를 계산한 것과 같은 뿌리입니다.
  5. 적용'다음 단계'를 눌러 줄을 적고, 지워지는 세제곱을 확인하세요. n을 바꾸어도 남는 것이 늘 (n + 1)3과 13뿐인가요? 마지막 단계에서 하나씩 더한 값과 공식 값이 같은지 보세요.
  6. 판단∑k2을 (∑k)2으로 계산하는 실수가 흔합니다. n = 3이면 1 + 4 + 9 = 14이지만 (1 + 2 + 3)2 = 36입니다. 또 공식은 k = 1부터의 합입니다. 다른 번호에서 시작하면 1부터의 합 두 개의 차로 구합니다.
