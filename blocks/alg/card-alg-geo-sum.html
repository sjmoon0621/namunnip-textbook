곱해 가는 수열의 합은 어떻게 구할까?

등비수열 · \(S - rS\)

—

하나씩 더한 \(S_n\)
—
\(r^n\)
—
공식 값
—
  1. 질문\(1 + 2 + 4 + \cdots + 2^{63}\)처럼 곱해 가는 수열의 합은 등차수열처럼 거꾸로 더해 짝을 지어도 짝의 합이 같지 않습니다. 어떻게 구할까요?
  2. 복원등비수열의 일반항은 \(a_n = ar^{n-1}\)입니다. 각 항에 \(r\)을 곱하면 바로 다음 항이 됩니다.
  3. 설명\(S_n = a + ar + \cdots + ar^{n-1}\)의 양변에 \(r\)을 곱하면 \(rS_n = ar + ar^2 + \cdots + ar^n\)입니다. 두 줄은 \(ar\)부터 \(ar^{n-1}\)까지 같은 항을 공유하므로, 빼면 거의 다 지워지고 \(S_n - rS_n = a - ar^n\)만 남습니다. 따라서 \(r \ne 1\)이면 \(S_n = \frac{a(1 - r^n)}{1 - r} = \frac{a(r^n - 1)}{r - 1}\)입니다. \(r = 1\)이면 모든 항이 \(a\)이므로 \(S_n = na\)입니다.
  4. 연결합에서 일반항을 구할 때처럼, 여기서도 두 식을 빼서 같은 부분을 지우는 생각을 씁니다. 이 '어긋나게 빼기'는 여러 가지 수열의 합에서 소거되는 합으로 다시 나옵니다. \(r > 1\)이면 \(\frac{a(r^n - 1)}{r - 1}\), \(|r| < 1\)이면 \(\frac{a(1 - r^n)}{1 - r}\) 꼴을 쓰면 분모·분자가 양수라 계산이 편합니다.
  5. 적용'다음 단계'를 눌러 \(rS\) 줄이 한 칸 밀려 적히고 같은 항끼리 지워지는 것을 보세요. \(r = \frac{1}{2}\)이나 \(-2\)에서도 같은 일이 일어나나요? \(r = 1\)을 고르면 빼기가 왜 쓸모없어지나요?
  6. 판단공식의 지수를 \(r^{n-1}\)로 쓰는 실수가 흔합니다. 빼고 남는 마지막 항은 \(rS\) 줄의 끝인 \(ar^n\)입니다. 또 \(r = 1\)일 때 공식에 넣으면 \(\frac{0}{0}\)이 되므로 따로 \(S_n = na\)로 구해야 합니다. 이 공식은 연금이나 대출 상환 계산에도 쓰이지만, 여기서는 원리를 이해하는 데 집중합니다.

\(2 + 6 + 18 + \cdots\)처럼 첫째항이 2, 공비가 3인 등비수열의 첫째항부터 제6항까지의 합은?
