수열은 어떤 함수일까?

수열의 뜻 · 항과 일반항

—

번호 n
—
항 \(a_n\)
—
\(a_{n+1} - a_n\)
—

위 줄은 대응, 아래는 같은 대응을 점 \((n, a_n)\)으로 찍은 그래프입니다. 점 사이에는 항이 없습니다.

  1. 질문\(1, 3, 5, 7, \cdots\)처럼 수를 차례로 늘어놓으면 '첫째', '둘째' 같은 순서가 생깁니다. 순서가 있다는 것을 수학의 말로 하면 무엇일까요?
  2. 복원함수 \(f : X \to Y\)는 X의 원소 하나하나에 Y의 원소를 오직 하나씩 대응시킵니다. 정의역이 실수 전체인 일차함수의 그래프는 끊김 없는 직선입니다.
  3. 설명차례로 늘어놓은 수의 열을 수열, 각 수를 항이라고 합니다. 첫째항, 둘째항, \(\cdots, n\)번째 항을 \(a_1, a_2, \cdots, a_n\)으로 적습니다. 번호 1에는 \(a_1\), 번호 2에는 \(a_2\)가 하나씩 정해지므로, 수열은 자연수 \(n\)에 수 \(a_n\)을 하나씩 대응시킨 함수입니다. \(a_n\)을 \(n\)의 식으로 나타낸 것을 일반항이라 하고, 일반항이 \(a_n\)인 수열을 \(\{a_n\}\)으로 씁니다. 항이 끝없이 이어지면 무한수열, 끝이 있으면 유한수열입니다.
  4. 연결정의역을 자연수로 줄였기 때문에 그래프가 점으로 끊어집니다. 같은 식 \(2x - 1\)이라도 일차함수 \(y = 2x - 1\)의 그래프는 직선이고, 수열 \(a_n = 2n - 1\)의 그래프는 그 직선 위의 점들입니다. 다음 절의 등차수열은 일차함수, 등비수열은 지수함수를 자연수에서만 본 것입니다.
  5. 적용규칙을 바꾸며 \(n\)을 움직여 보세요. \((-1)^n\)은 어떤 값을 되풀이하나요? \(\frac{1}{n}\)은 \(n\)이 커질수록 어디에 가까워지나요? 소수의 수열처럼 간단한 식이 없어도 수열일까요? '점 사이를 선으로 이어 보기'를 켜고, 선 위의 점이 수열의 항인지 생각해 보세요.
  6. 판단수열의 그래프를 곡선으로 이어 그리고 그 위의 모든 점을 항으로 여기면 안 됩니다. 2.5번째 항 같은 것은 없습니다. 또 일반항이 식으로 주어져야만 수열인 것도 아닙니다. 각 번호에 값이 하나씩 정해지면 수열입니다. 같은 값이 여러 번 나와도(예: \(-1, 1, -1, 1, \cdots\)) 됩니다.

확인조건이 달라지면

일반항이 \(a_n = n^2 - 5n\)인 수열에서 값이 음수인 항은 모두 몇 개인가요?
