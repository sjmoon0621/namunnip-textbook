원을 도는 점의 높이를 옆으로 펼치면 어떤 모양일까?

사인·코사인·탄젠트함수의 그래프 · 주기
x (라디안)
—
\(\sin x\)
—
주기
—

—

x를 0에서 \(2\pi\), 다시 \(-2\pi\)까지 움직이면 굵은 선이 지나온 자취를 그립니다. 탄젠트에서는 원의 오른쪽 접선 위 점 T의 높이가 \(\tan x\)입니다.

  1. 질문관람차가 일정한 빠르기로 돌 때, 한 칸의 높이를 시간에 따라 그리면 어떤 모양일까요? 단위원 위를 도는 점 P의 높이를 각 \(x\)의 함수로 그려 보면 알 수 있습니다.
  2. 복원단위원에서 동경과 원의 교점은 \(P(\cos x, \sin x)\)입니다. 호도법을 쓰면 각 \(x\)는 실수이므로 가로축에 그대로 놓을 수 있습니다. \(x\)와 \(x + 2\pi\)는 같은 동경입니다.
  3. 설명\(y = \sin x\)의 그래프는 P의 높이를 옮긴 것입니다. 정의역은 실수 전체, 치역은 \(-1 \le y \le 1\)이고, 원점에 대하여 대칭입니다. 모든 실수 \(x\)에 대하여 \(f(x + p) = f(x)\)를 만족시키는 0이 아닌 상수 \(p\)가 있으면 \(f\)를 주기함수라 하고, 그런 \(p\) 중 가장 작은 양수를 주기라 합니다. \(\sin(x + 2\pi) = \sin x\)이므로 사인함수의 주기는 \(2\pi\)입니다. \(y = \cos x\)는 P의 가로 위치를 옮긴 것으로, 치역과 주기는 사인과 같고 \(y\)축에 대하여 대칭이며, \(y = \sin x\)를 \(x\)축 방향으로 \(-\frac{\pi}{2}\)만큼 평행이동한 모양입니다. \(y = \tan x\)는 직선 \(x = 1\)과 동경의 연장선이 만나는 점 T의 높이입니다. \(x = \frac{\pi}{2} + n\pi\)에서는 정의되지 않고 그래프가 이 직선들(점근선)에 한없이 가까워집니다. 치역은 실수 전체, 주기는 \(\pi\)이고 원점에 대하여 대칭입니다.
  4. 연결대칭은 앞에서 본 \(\sin(-x) = -\sin x\), \(\cos(-x) = \cos x\)가 그림으로 나타난 것입니다. 주기 \(\pi\)는 \(\tan(\pi + x) = \tan x\)에서 옵니다. 소리, 교류 전기, 밀물과 썰물처럼 되풀이되는 현상을 이 곡선으로 나타냅니다.
  5. 적용사인을 고르고 \(x\)를 0에서 \(2\pi\)까지 움직여 최댓값과 최솟값이 나오는 \(x\)를 찾으세요. 이어서 \(2\pi\)에서 \(-2\pi\)까지 움직이면 같은 모양이 몇 번 되풀이되나요? 코사인으로 바꿔 사인보다 몇만큼 앞서 같은 값을 갖는지 보세요. 탄젠트에서 \(x\)를 \(\frac{\pi}{2}\) 가까이 가져가면 T는 어디로 가나요? 전체 보기를 켜서 \(0 \le x < 2\pi\)에서 \(\sin x = \frac{1}{2}\)인 \(x\)를 두 개 찾아보세요.
  6. 판단모든 주기함수의 주기가 \(2\pi\)인 것은 아닙니다. 탄젠트의 주기는 \(\pi\)입니다. 또 \(2\pi\)도 사인함수를 되풀이시키지만 \(4\pi, 6\pi\)처럼 \(2\pi\)의 배수는 모두 그렇습니다. 주기는 그중 가장 작은 양수입니다. 탄젠트 그래프의 점근선은 그래프의 일부가 아니라 함숫값이 없는 자리입니다.

\(0 \le x < 2\pi\)에서 방정식 \(\cos x = -\frac{1}{2}\)의 해는?
