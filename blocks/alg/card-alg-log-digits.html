  1. 질문250을 끝까지 곱하지 않고 몇 자리 수인지 알 수 있을까요? 맨 앞자리 숫자까지 알 수 있을까요?
  2. 복원loga Mk = k loga M, loga MN = loga M + loga N입니다. 102 = 100은 세 자리, 103 = 1000은 네 자리입니다.
  3. 설명밑이 10인 로그를 상용로그라 하고, 밑을 생략해 log N으로 씁니다. 양수 N을 N = a × 10n(1 ≤ a < 10, n은 정수)으로 쓰면 log N = n + log a이고 0 ≤ log a < 1입니다. 그래서 log N의 정수 부분 n은 자리의 크기를, 소수 부분 log a는 숫자의 배열을 정합니다. n ≥ 0이면 N의 정수 부분은 n + 1자리이고, n < 0이면 N은 소수점 아래 −n째 자리에서 처음으로 0이 아닌 숫자가 나옵니다. 맨 앞 숫자는 10소수 부분의 정수 부분입니다. 예: log 250 = 50 log 2 ≈ 15.05이므로 250은 16자리이고, 100.05 ≈ 1.13이라 맨 앞 숫자는 1입니다.
  4. 연결계산기가 없던 시절에는 1.00부터 9.99까지의 상용로그 값을 적은 상용로그표로 소수 부분을 찾았습니다. 정수 부분은 자릿수만 보면 되므로 표 하나로 모든 양수의 로그를 구할 수 있었습니다. 이 생각이 다음 카드의 pH, 지진 규모, 데시벨로 이어집니다.
  5. 적용320을 눌러 자릿수와 맨 앞 숫자를 확인하세요. 지수를 1씩 늘리면 아래 눈금의 점은 얼마씩 움직이고, 한 바퀴 돌 때 정수 부분은 어떻게 바뀌나요? 7−10, 2−30에서는 처음으로 0이 아닌 숫자가 소수점 아래 몇째 자리에 나오나요?
  6. 판단log N ≈ −8.45일 때 정수 부분을 −8, 소수 부분을 −0.45로 읽는 실수가 흔합니다. 소수 부분은 언제나 0 이상 1 미만이 되도록 정하므로 −8.45 = −9 + 0.55입니다. 또 정수 부분이 15이면 16자리입니다. 15자리로 답하지 않도록 100 = 1이 한 자리라는 것을 떠올리세요.
