\(2^{\sqrt{2}}\)처럼 지수가 무리수인 수는 어떻게 정할까?

누를 때마다 그림을 10배로 확대합니다. 축 눈금은 감싸는 구간의 양 끝입니다.

  1. 질문\(\sqrt{2}\)는 분수로 나타낼 수 없으므로 \(2^{\sqrt{2}}\)는 거듭제곱근으로도 쓸 수 없습니다. 그래도 이 수는 하나로 정해질까요?
  2. 복원\(\sqrt{2} = 1.41421356\cdots\)은 무리수이고, 소수점 아래 자릿수를 늘리면 유리수로 얼마든지 가깝게 다가갈 수 있습니다. 밑이 1보다 큰 양수이면 유리수 지수가 커질수록 거듭제곱 값도 커집니다.
  3. 설명\(\sqrt{2}\)를 유리수로 위아래에서 감쌉니다. \(1.4 < \sqrt{2} < 1.5, 1.41 < \sqrt{2} < 1.42, 1.414 < \sqrt{2} < 1.415 \cdots\) 그러면 값도 \(2^{1.4} < 2^{\sqrt{2}} < 2^{1.5}, 2^{1.41} < 2^{\sqrt{2}} < 2^{1.42} \cdots\) 처럼 감싸집니다. 지수 구간의 폭이 0에 가까워지면 값 구간의 폭도 0에 가까워지므로, 모든 값 구간에 공통으로 들어 있는 수는 하나뿐입니다. 그 수를 \(2^{\sqrt{2}}\)로 정합니다(약 2.6651). 이렇게 하면 \(a > 0\)일 때 모든 실수 \(x\)에 대하여 \(a^x\)가 하나로 정해지고, 지수법칙도 그대로 성립합니다. 고등학교에서는 지수가 실수인 경우를 이처럼 직관적으로 이해하면 충분합니다.
  4. 연결계산기가 \(2^{\sqrt{2}}\)를 보여 주는 것도 이런 근삿값입니다. 지수가 모든 실수로 넓혀졌으므로 \(y = 2^x\)의 그래프는 끊긴 곳이 없는 곡선이 되고, 이것이 지수함수의 출발점입니다.
  5. 적용"소수 자릿수 하나 더"를 누르며 값 구간의 폭이 매번 약 몇 분의 1로 줄어드는지 보세요. 밑을 0.5로 바꾸면 지수 구간의 왼쪽 끝은 값 구간의 어느 쪽 끝과 짝이 되나요? 지수를 \(\pi\)로 바꾸면 \(2^\pi\)는 얼마에 가까워지나요?
  6. 판단밑이 1보다 작으면 지수가 커질수록 값이 작아지므로 부등호의 방향이 뒤집힙니다. 그래도 값 구간이 하나의 수로 좁혀지는 것은 같습니다. 밑이 1이면 구간 폭이 처음부터 0입니다. 이 방법은 밑이 양수일 때만 쓸 수 있습니다. 밑이 음수이면 유리수 지수부터 값이 정해지지 않기 때문입니다. 또 \(2^{\sqrt{2}} = 2.665\)처럼 근삿값을 등호로 쓰지 않습니다.
