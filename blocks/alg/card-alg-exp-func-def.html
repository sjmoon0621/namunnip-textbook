\(y = a^x\)가 함수가 되려면 밑은 어때야 할까?

지수함수의 뜻 · 밑의 조건

—

출력 \(a^x\)
—
찍힌 점 / 전체 입력
—
판정
—

점은 \(-4\)부터 4까지 0.25 간격의 입력에서 계산한 출력이고, 출력이 실수가 아니면 점을 찍지 않는다. 그림을 좌우로 끌어도 입력이 바뀐다.

  1. 질문세균이 1시간마다 2배로 늘면 \(x\)시간 뒤에는 \(2^x\)배가 된다. 그런데 \(x\)가 0.5나 \(-1\)이어도 이 식이 뜻을 가질까? 밑이 \(-2\)라면 어떨까?
  2. 복원함수는 정의역의 원소마다 공역의 원소를 하나씩 정하는 대응이다. 그리고 \(a > 0\)이면 \(a^x\)는 모든 실수 \(x\)에서 하나로 정해지고 언제나 양수이다.
  3. 설명\(a > 0\), \(a \ne 1\)일 때 실수 \(x\)마다 \(a^x\)를 대응시키는 함수 \(y = a^x\)를 \(a\)를 밑으로 하는 지수함수라 한다. 정의역은 실수 전체, 치역은 양의 실수 전체이다. 밑이 음수이면 \((-2)^{1/2}\)처럼 실수가 아닌 값이 생겨 실수 전체에서 함수가 되지 않는다. 또 밑이 1이면 \(1^x = 1\)인 상수함수가 되어 값이 늘거나 줄지 않고 거꾸로 지수를 찾을 수도 없으므로 제외한다.
  4. 연결방사성 원소의 붕괴, 원금이 복리로 불어나는 예금, 세균의 증식처럼 같은 시간마다 같은 비율로 변하는 양은 지수함수로 나타난다. 즉 \(x\)가 1 늘 때마다 출력이 \(a\)배가 된다는 것이 지수함수를 다른 함수와 가르는 성질이다.
  5. 적용밑 2에서 \(x\)를 1씩 늘리면 출력이 몇 배가 되는지 보고, \(x\)를 \(-4\)까지 줄여도 출력이 0이 되지 않는 것을 확인해 보자. 밑을 \(-2\)로 바꾸면 33개의 입력 가운데 몇 개에서만 점이 찍힌다.
  6. 판단\(y = x^2\)(거듭제곱 함수)와 \(y = 2^x\)(지수함수)는 변수가 밑에 있느냐 지수에 있느냐가 달라서 헷갈리지 않아야 한다. 또 지수함수의 출력은 아무리 작아져도 0이나 음수가 되지 않는다. 그래서 그래프는 \(x\)축에 가까워질 뿐 만나지 않는다.
