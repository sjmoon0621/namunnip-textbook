\(y = a^x\)가 함수가 되려면 밑은 어때야 할까?

지수함수의 뜻 · 밑의 조건

—

출력 \(a^x\)
—
찍힌 점 / 전체 입력
—
판정
—

점은 \(-4\)부터 4까지 0.25 간격의 입력에서 계산한 출력입니다. 출력이 실수가 아니면 점을 찍지 않습니다. 그림을 좌우로 끌어도 입력이 바뀝니다.

  1. 질문세균이 1시간마다 2배로 늘면 \(x\)시간 뒤에는 \(2^x\)배가 됩니다. \(x\)가 0.5나 \(-1\)이어도 이 식이 뜻을 가질까요? 밑이 \(-2\)라면 어떨까요?
  2. 복원함수는 정의역의 원소마다 공역의 원소를 하나씩 정하는 대응입니다. \(a > 0\)이면 \(a^x\)는 모든 실수 \(x\)에서 하나로 정해지고 언제나 양수입니다.
  3. 설명\(a > 0\), \(a \ne 1\)일 때 실수 \(x\)마다 \(a^x\)를 대응시키는 함수 \(y = a^x\)를 \(a\)를 밑으로 하는 지수함수라 합니다. 정의역은 실수 전체, 치역은 양의 실수 전체입니다. 밑이 음수이면 \((-2)^{1/2}\)처럼 실수가 아닌 값이 생겨 실수 전체에서 함수가 되지 않습니다. 밑이 1이면 \(1^x = 1\)인 상수함수가 되어, 값이 늘거나 줄어드는 지수함수의 성질이 없고 거꾸로 지수를 찾을 수도 없으므로 제외합니다.
  4. 연결방사성 원소의 붕괴, 원금이 복리로 불어나는 예금, 세균의 증식처럼 같은 시간마다 같은 비율로 변하는 양은 지수함수로 나타납니다. \(x\)가 1 늘 때마다 출력이 \(a\)배가 되는 것이 지수함수의 핵심 성질입니다.
  5. 적용밑 2에서 \(x\)를 1씩 늘리면 출력은 몇 배가 되나요? \(x\)를 \(-4\)까지 줄이면 출력은 0이 되나요? 밑을 \(-2\)로 바꾸면 33개의 입력 가운데 몇 개에서만 점이 찍히나요?
  6. 판단\(y = x^2\)(거듭제곱 함수)와 \(y = 2^x\)(지수함수)를 헷갈리지 마세요. 변수가 밑에 있느냐, 지수에 있느냐가 다릅니다. 또 지수함수의 출력은 아무리 작아져도 0이나 음수가 되지 않습니다. 그래프가 \(x\)축에 가까워질 뿐 만나지 않습니다.
