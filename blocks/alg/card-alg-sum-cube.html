세제곱을 모으면 왜 정사각형이 될까?

여러 가지 수열의 합 · 자연수의 세제곱의 합
k번째 띠의 넓이
—
\(1^3 + \cdots + n^3\)
—
\((1 + \cdots + n)^2\)
—

작은 칸 하나의 넓이가 1입니다. 띠는 한 변이 \(1 + \cdots + (k - 1)\)인 정사각형을 \(1 + \cdots + k\)인 정사각형으로 키울 때 덧붙는 부분입니다.

  1. 질문\(1^3 = 1\), \(1^3 + 2^3 = 9\), \(1^3 + 2^3 + 3^3 = 36\), \(1^3 + 2^3 + 3^3 + 4^3 = 100\). 합이 모두 제곱수입니다. 우연일까요?
  2. 복원\(1 + 2 + \cdots + n = \frac{n(n + 1)}{2}\)입니다. 한 변이 \(a\)인 정사각형을 한 변이 \(b\)인 정사각형으로 키우면 덧붙는 ㄱ자 모양의 넓이는 \(b^2 - a^2\)입니다.
  3. 설명\(T_k = 1 + 2 + \cdots + k = \frac{k(k + 1)}{2}\)라 하면 한 변이 \(T_{k-1}\)인 정사각형에서 \(T_k\)인 정사각형으로 키울 때 덧붙는 띠의 넓이는 \(T_k^2 - T_{k-1}^2 = (T_k - T_{k-1})(T_k + T_{k-1}) = k \cdot k^2\) = \(k^3\)입니다. (\(T_k - T_{k-1} = k\), \(T_k + T_{k-1} = k^2\)) 이 띠를 1번부터 \(n\)번까지 모으면 한 변이 \(T_n\)인 정사각형이 되므로 \(\sum_{k=1}^n k^3 = \left\{\frac{n(n + 1)}{2}\right\}^2\)입니다.
  4. 연결이 공식은 제곱의 합처럼 \((k + 1)^4 - k^4 = 4k^3 + 6k^2 + 4k + 1\)을 \(k = 1\)부터 \(n\)까지 더해서도 얻을 수 있습니다. 그림은 그 결과가 왜 \((\sum k)^2\)이라는 깔끔한 모양이 되는지 보여 줍니다. 세 공식 \(\sum k, \sum k^2, \sum k^3\)과 \(\sum\)의 성질을 함께 쓰면 일반항이 \(n\)의 다항식인 수열의 합을 구할 수 있습니다.
  5. 적용\(k\)를 움직이며 띠의 넓이가 \(k^3\)인지 칸을 세어 보세요. \(n\)을 늘리면 정사각형의 한 변은 얼마씩 커지나요? 두 수치 \(1^3 + \cdots + n^3\)과 \((1 + \cdots + n)^2\)이 늘 같은지 확인하세요.
  6. 판단\(\sum k^3 = (\sum k)^2\)은 세제곱에서만 성립하는 특별한 관계입니다. \(\sum k^2 = (\sum k)^2\)이나 \(\sum k^4 = (\sum k^2)^2\)처럼 일반화하면 틀립니다. 또 그림은 공식이 왜 맞는지 보여 주지만, 모든 \(n\)에 대한 증명은 위의 넓이 계산(또는 수학적 귀납법)이 맡습니다.
