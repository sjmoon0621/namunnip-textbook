세제곱을 모으면 왜 정사각형이 될까?

여러 가지 수열의 합 · 자연수의 세제곱의 합
k번째 띠의 넓이
—
13 + … + n3
—
(1 + … + n)2
—

작은 칸 하나의 넓이가 1입니다. 띠는 한 변이 1 + … + (k − 1)인 정사각형을 1 + … + k인 정사각형으로 키울 때 덧붙는 부분입니다.

  1. 질문13 = 1, 13 + 23 = 9, 13 + 23 + 33 = 36, 13 + 23 + 33 + 43 = 100. 합이 모두 제곱수입니다. 우연일까요?
  2. 복원1 + 2 + … + n = n(n + 1)/2입니다. 한 변이 a인 정사각형을 한 변이 b인 정사각형으로 키우면 덧붙는 ㄱ자 모양의 넓이는 b2 − a2입니다.
  3. 설명Tk = 1 + 2 + … + k = k(k + 1)/2라 하면 한 변이 Tk−1인 정사각형에서 Tk인 정사각형으로 키울 때 덧붙는 띠의 넓이는 Tk2 − Tk−12 = (Tk − Tk−1)(Tk + Tk−1) = k · k2 = k3입니다. (Tk − Tk−1 = k, Tk + Tk−1 = k2) 이 띠를 1번부터 n번까지 모으면 한 변이 Tn인 정사각형이 되므로 ∑k=1n k3 = {n(n + 1)/2}2입니다.
  4. 연결이 공식은 제곱의 합처럼 (k + 1)4 − k4 = 4k3 + 6k2 + 4k + 1을 k = 1부터 n까지 더해서도 얻을 수 있습니다. 그림은 그 결과가 왜 (∑k)2이라는 깔끔한 모양이 되는지 보여 줍니다. 세 공식 ∑k, ∑k2, ∑k3과 ∑의 성질을 함께 쓰면 일반항이 n의 다항식인 수열의 합을 구할 수 있습니다.
  5. 적용k를 움직이며 띠의 넓이가 k3인지 칸을 세어 보세요. n을 늘리면 정사각형의 한 변은 얼마씩 커지나요? 두 수치 13 + … + n3과 (1 + … + n)2이 늘 같은지 확인하세요.
  6. 판단∑k3 = (∑k)2은 세제곱에서만 성립하는 특별한 관계입니다. ∑k2 = (∑k)2이나 ∑k4 = (∑k2)2처럼 일반화하면 틀립니다. 또 그림은 공식이 왜 맞는지 보여 주지만, 모든 n에 대한 증명은 위의 넓이 계산(또는 수학적 귀납법)이 맡습니다.
