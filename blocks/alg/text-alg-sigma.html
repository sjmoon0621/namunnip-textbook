본문

\(1^2 + 2^2 + 3^2 + \cdots + 50^2\)이나 \(3 + 7 + 11 + \cdots + 199\)처럼 규칙이 있는 긴 덧셈을 매번 '…'로 쓰면 무엇을 더하는지, 몇 개를 더하는지가 흐려진다. 더하는 규칙과 범위를 한눈에 담는 표기는 어떻게 만들까?

먼저 알아야 할 것수열과 일반항(수열의 뜻), 등차수열과 등비수열의 합(등차수열, 등비수열), 분배법칙.

3.4.1합의 기호

수열 \(\{a_n\}\)의 첫째항부터 제\(n\)항까지의 합 \(a_1 + a_2 + \cdots + a_n\)을 기호 \(\sum\)을 써서 \(\displaystyle\sum_{k=1}^{n} a_k\)로 나타낸다. \(\sum\)은 합을 뜻하는 영어 sum의 첫 글자 S에 해당하는 그리스 문자로 '시그마'라 읽는다.

정의 3.4.1 합의 기호 \(\sum\)

\[\sum_{k=1}^{n} a_k = a_1 + a_2 + a_3 + \cdots + a_n\] \(k\)에 1부터 \(n\)까지의 자연수를 차례로 넣은 \(a_k\)를 모두 더한다는 뜻이다.

기호의 각 자리가 하는 일을 그림 1로 확인하자. 아래의 \(k = 1\)은 시작, 위의 \(n\)은 끝, 오른쪽의 식은 더할 항의 규칙이다. 처음 질문의 덧셈은 \(\displaystyle\sum_{k=1}^{50} k^2\)과 \(\displaystyle\sum_{k=1}^{50} (4k - 1)\)로 쓸 수 있다. 여기서 문자 \(k\)는 자리만 차지하므로 \(i\)나 \(j\)로 바꾸어도 뜻이 같다.

3.4.2\(\sum\)의 성질

\(\sum\)은 덧셈을 줄여 쓴 것이므로, 덧셈의 교환법칙과 분배법칙이 그대로 성질이 된다. 두 수열의 항을 짝지어 더한 합은 따로 더한 합의 합이고, 모든 항에 같은 수를 곱한 합은 합에 그 수를 곱한 것이다.

정리 3.4.2 \(\sum\)의 성질

\[\sum_{k=1}^{n}(a_k \pm b_k) = \sum_{k=1}^{n} a_k \pm \sum_{k=1}^{n} b_k,\quad \sum_{k=1}^{n} ca_k = c\sum_{k=1}^{n} a_k,\quad \sum_{k=1}^{n} c = cn\ (c\text{는 상수})\]

그런데 곱과 나눗셈은 이렇게 나눌 수 없다. \(\displaystyle\sum_{k=1}^{n} a_kb_k\)는 \(\displaystyle\sum a_k \times \sum b_k\)와 다르다. \(n = 2\)만 보아도 \(a_1b_1 + a_2b_2\)와 \((a_1 + a_2)(b_1 + b_2)\)는 다르다.1

3.4.3예제 하나를 끝까지

예제 3.4.3

\(\displaystyle\sum_{k=1}^{10} a_k = 20\), \(\displaystyle\sum_{k=1}^{10} b_k = 7\)일 때 \(\displaystyle\sum_{k=1}^{10} (3a_k - 2b_k + 1)\)의 값을 구하여라. 또 \(\displaystyle\sum_{k=1}^{50}(4k - 1)\)을 등차수열의 합으로 구하여라.

성질을 차례로 쓰면 \(\displaystyle 3\sum a_k - 2\sum b_k + \sum 1 = 3 \times 20 - 2 \times 7 + 10 = 56\)이다. 마지막 \(\sum_{k=1}^{10} 1\)은 1을 10번 더한 것이므로 10이다.

\(\displaystyle\sum_{k=1}^{50}(4k - 1)\)은 \(k = 1\)일 때 3, \(k = 50\)일 때 199인 등차수열 50개의 합이다. 따라서 \(\dfrac{50 \times (3 + 199)}{2} = 5050\)이다.

성질로 풀어도 \(4\displaystyle\sum_{k=1}^{50} k - 50 = 4 \times \dfrac{50 \times 51}{2} - 50 = 5100 - 50 = 5050\)으로 같다. 한 식을 두 방법으로 계산해 맞추어 보는 것은 \(\sum\) 계산에서 실수를 줄이는 좋은 습관이다. 아래 탐구 카드에서 \(\sum\)의 각 자리를 바꾸며 펼쳐진 덧셈을 직접 확인해 보자.

  1. 시작이 1이 아닌 합은 \(\displaystyle\sum_{k=m}^{n} a_k = \sum_{k=1}^{n} a_k - \sum_{k=1}^{m-1} a_k\)로 고쳐 계산한다.
마무리

\(\sum\) 기호는 일반항과 더하는 범위를 함께 적어 긴 덧셈을 하나의 식으로 줄인다. 덧셈을 줄여 쓴 것이므로 항별로 더하고 상수배를 밖으로 꺼내는 성질이 있지만, 곱과 나눗셈은 항별로 나누어지지 않는다. 그래서 처음 질문의 두 덧셈은 \(\sum_{k=1}^{50} k^2\)과 \(\sum_{k=1}^{50}(4k - 1)\)로 짧고 정확하게 쓸 수 있다.
