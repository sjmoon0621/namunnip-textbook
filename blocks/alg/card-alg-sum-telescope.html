  1. 질문1/(1 · 2) + 1/(2 · 3) + 1/(3 · 4) + …처럼 분모가 이웃한 수의 곱인 분수를 더하면, 통분할수록 분모가 커집니다. 더 쉬운 길이 있을까요?
  2. 복원1/k − 1/(k + 1) = {(k + 1) − k}/{k(k + 1)} = 1/{k(k + 1)}입니다. 분모를 유리화할 때 (√a + √b)(√a − √b) = a − b를 씁니다.
  3. 설명항을 1/{k(k + 1)} = 1/k − 1/(k + 1)처럼 두 수의 차로 쪼개면 앞 줄의 뒤쪽 수와 다음 줄의 앞쪽 수가 같아 지워집니다. 그래서 ∑k=1n 1/{k(k + 1)} = 1 − 1/(n + 1) = n/(n + 1)입니다. 분모의 두 수가 2만큼 차이 나면 1/{k(k + 2)} = (1/2)(1/k − 1/(k + 2))처럼 앞에 1/(차)를 곱하고, 두 줄 건너 지워지므로 처음 두 개와 끝 두 개가 남습니다. 1/(√(k + 1) + √k)는 유리화하면 √(k + 1) − √k이므로 합은 √(n + 1) − 1입니다.
  4. 연결합을 '지워지는 차'의 모양으로 바꾸는 생각은 제곱의 합 공식을 구할 때 (k + 1)3 − k3을 더한 것과 같습니다. 이런 합은 여러 줄을 더해도 처음과 끝만 남기 때문에 항의 개수와 상관없이 짧은 식이 됩니다.
  5. 적용세 가지 수열을 차례로 고르고 n을 늘려 보세요. 각 경우 몇 개의 수가 남나요? 첫 번째 수열의 아래 띠는 n이 커지면 어디에 가까워지나요?
  6. 판단1/{k(k + 2)}을 1/k − 1/(k + 2)로만 쪼개는 실수가 흔합니다. 이 차는 2/{k(k + 2)}이므로 1/2을 곱해야 합니다. 또 남는 항을 셀 때 앞에서 남는 것과 뒤에서 남는 것을 모두 적어야 합니다. 쪼갠 뒤 몇 개를 적어 보고 지워지는 짝을 직접 확인하는 습관이 안전합니다.
