2를 몇 제곱하면 5가 될까?

로그의 뜻 · 밑과 진수의 조건

—

교점의 개수
—
loga N
—
검산 alogaN
—

그림을 위아래로 끌면 수평선 y = N이 움직입니다.

  1. 질문2x = 8의 해는 3입니다. 그러면 2x = 5의 해는 있을까요? 있다면 어떻게 나타낼까요?
  2. 복원밑 a가 양수이면 ax는 모든 실수 x에서 정해지고 언제나 양수입니다. a > 1이면 x가 커질 때 ax도 커지고, 0 < a < 1이면 작아집니다.
  3. 설명a > 0, a ≠ 1이면 y = ax는 계속 증가하거나 계속 감소하면서 모든 양수 값을 한 번씩 지납니다. 그래서 N > 0이면 ax = N을 만족하는 실수 x가 오직 하나 있고, 이 수를 loga N으로 씁니다. a를 밑, N을 진수라 합니다. 곧 ax = N ⇔ x = loga N입니다. 조건은 세 가지입니다. 밑은 a > 0, a ≠ 1이고 진수는 N > 0입니다. 정의에서 바로 loga 1 = 0(a0 = 1), loga a = 1, alogaN = N이 나옵니다.
  4. 연결2x = 5의 해는 log2 5 ≈ 2.322입니다. 22 = 4와 23 = 8 사이이므로 2와 3 사이의 값이 나오는 것이 자연스럽습니다. 지진 규모, 소리의 세기(dB), 산성도(pH)는 모두 로그로 정한 양이고, 밑이 10인 상용로그로 다룹니다.
  5. 적용다섯 보기를 차례로 눌러 교점이 몇 개인지 확인하세요. 밑이 1일 때와 진수가 음수일 때 무엇이 문제인가요? 밑 0.5에서 진수를 1보다 크게 하면 로그 값의 부호는 어떻게 되나요?
  6. 판단log2(−4)를 −2라고 하는 실수가 있습니다. 2−2 = 1/4이지 −4가 아닙니다. 양수 밑의 거듭제곱은 음수가 될 수 없으므로 진수가 0 이하이면 로그는 정의되지 않습니다. 밑이 1이면 1x = 1이라 N ≠ 1이면 해가 없고, N = 1이면 해가 무수히 많아 값이 하나로 정해지지 않습니다.
