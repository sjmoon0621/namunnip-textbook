그래프가 \(x\)축 아래로 내려가면 정적분은 어떻게 될까?

정적분 · 일반적인 연속함수로 확장
\(x\)축 위쪽 넓이
—
\(x\)축 아래쪽 넓이
—
\(\int_a^b f(x)\,dx\)
—

—

\(x\)축 위의 점 \(a\)(검정)와 \(b\)(주황)를 끌어 옮길 수 있습니다. \(b\)를 \(a\)보다 왼쪽으로 보내 보세요.

  1. 질문정적분을 '곡선 아래 넓이'로 정했습니다. 그런데 \(y = x^2 - 1\)처럼 그래프가 \(x\)축 아래로 내려가는 함수, 또 위끝이 아래끝보다 작은 경우에는 정적분을 어떻게 정해야 할까요?
  2. 복원\(f(x) \ge 0\)이고 \(f\)가 \([a, b]\)에서 연속이면 \(\int_a^b f(x)\,dx\)는 그래프와 \(x\)축, \(x = a, x = b\)로 둘러싸인 넓이입니다. 넓이는 언제나 0 이상입니다.
  3. 설명직사각형 합으로 생각하면 함숫값이 음수인 칸은 높이가 음수이므로 넓이를 빼는 셈이 됩니다. 그래서 일반적인 연속함수에 대해 \(\int_a^b f(x)\,dx\) = (\(x\)축 위쪽 넓이) − (\(x\)축 아래쪽 넓이) \((a < b)\)로 정의를 넓힙니다. 또 끝이 같거나 거꾸로인 경우를 다음과 같이 약속합니다. \(\int_a^a f(x)\,dx = 0\), \(\int_b^a f(x)\,dx = -\int_a^b f(x)\,dx\) \((a < b)\). 이렇게 정하면 정적분은 넓이가 아니라 부호가 있는 값이 됩니다.
  4. 연결속도–시간 그래프에서 시간축 아래 넓이가 반대 방향의 변위를 뜻했던 것과 같은 생각입니다. 넓이 자체를 구하는 문제에서는 위쪽과 아래쪽을 모두 더해야 하고, 이것은 넓이 절에서 다시 다룹니다.
  5. 적용\(x^2 - 1\)에서 \(a = -1, b = 1\)로 두면 정적분의 부호는 무엇인가요? \(x^3 - 4x\)에서 \(a = -2, b = 2\)로 두면 위·아래 넓이와 정적분은 각각 얼마인가요? 그다음 \(a\)와 \(b\)를 바꾸어 놓으면 정적분은 어떻게 되나요?
  6. 판단"정적분 = 넓이"는 \(f(x) \ge 0\)이고 \(a < b\)일 때만 맞습니다. 정적분이 0이어도 둘러싸인 도형의 넓이는 0이 아닐 수 있습니다. 위쪽 넓이와 아래쪽 넓이가 같아서 서로 지워졌을 뿐입니다.
