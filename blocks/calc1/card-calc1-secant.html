할선의 기울기는 h가 0에 가까워지면 어디로 갈까?

그림을 끌면 점 Q가 움직입니다. 파란 직선이 할선이고, 주황색 두 선분이 Δx와 Δy입니다.

  1. 질문평균변화율은 두 점만 있으면 구할 수 있습니다. 그렇다면 곡선 위의 한 점에서 '지금 이 순간'의 변화율은 무엇으로 정해야 할까요? 두 점을 점점 붙여 보면 답이 보입니다.
  2. 복원두 점 (x1, y1), (x2, y2)를 지나는 직선의 기울기는 (y2 − y1)/(x2 − x1)입니다. 또 limh→0는 h가 0이 아니면서 0에 한없이 가까워질 때 식의 값이 다가가는 값입니다.
  3. 설명x의 값이 a에서 a + Δx로 변할 때 Δx를 x의 증분, Δy = f(a + Δx) − f(a)를 y의 증분이라고 합니다. Δy/Δx는 구간 [a, a + Δx]에서의 평균변화율이고, 그래프에서는 두 점 P, Q를 잇는 할선의 기울기입니다. Δx = h를 0에 가깝게 보낼 때 평균변화율이 다가가는 값 f′(a) = limh→0 (f(a + h) − f(a))/h를 x = a에서의 순간변화율 또는 미분계수라고 합니다. x = a + h로 두면 f′(a) = limx→a (f(x) − f(a))/(x − a)로도 씁니다. 이 극한값이 있을 때 f는 x = a에서 미분가능하다고 합니다. f(x) = x2이면 (f(a + h) − f(a))/h = (2ah + h2)/h = 2a + h이므로 f′(a) = 2a입니다.
  4. 연결Q가 P에 다가갈수록 할선은 한 직선에 가까워집니다. 그 직선이 P에서의 접선이므로, 미분계수 f′(a)는 점 (a, f(a))에서 그은 접선의 기울기입니다. 위치를 시간으로 미분하면 순간 속도가 되는 것도 같은 생각입니다.
  5. 적용x2, a = 1에서 'h ÷ 10'을 네 번 눌러 기록을 보세요. 평균변화율은 어느 수에 다가가나요? 부호를 바꾸어 h < 0 쪽에서도 같은 수에 다가가는지 확인하고, '접선 겹쳐 보기'로 그 수가 접선의 기울기인지 보세요. x3 − 2x, a = 1에서는 어느 수에 다가가나요?
  6. 판단(f(a + h) − f(a))/h에 h = 0을 바로 넣으면 0/0이 되어 아무것도 알 수 없습니다. 먼저 식을 정리해 h를 약분한 뒤 극한을 구해야 합니다. 또 h가 아무리 작아도 h ≠ 0인 동안의 값은 평균변화율일 뿐이고, 미분계수는 그 극한값입니다.
