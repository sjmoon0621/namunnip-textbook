기울기가 0인 점은 언제나 봉우리나 골짜기일까?

극대와 극소 · 증감표

—

\(f' = 0\)의 판별식 \(\frac{D}{4}\)
—
극댓값
—
극솟값
—

증감표는 \(f'(x) = 3x^2 + 2px + q\)의 부호로 만들어집니다. 표의 화살표와 그래프의 오르내림을 견주어 보세요.

  1. 질문\(f'(c) = 0\)이면 접선이 수평입니다. 그러면 그 점은 언제나 봉우리나 골짜기일까요?
  2. 복원\(f' > 0\)인 구간에서 \(f\)는 증가하고, \(f' < 0\)인 구간에서 감소합니다.
  3. 설명\(x = a\)를 포함하는 어떤 열린 구간의 모든 \(x\)에서 \(f(x) \le f(a)\)이면 \(f\)는 \(x = a\)에서 극대라 하고, \(f(a)\)를 극댓값이라 합니다. 부등호를 바꾸면 극소와 극솟값입니다. 둘을 묶어 극값이라 합니다. 미분가능한 함수가 \(x = a\)에서 극값을 가지면 \(f'(a) = 0\)입니다. 판정은 \(f'\)의 부호 변화로 합니다. \(f'(a) = 0\)이고 \(a\)의 좌우에서 \(f'\)의 부호가 +에서 −로 바뀌면 극대, −에서 +로 바뀌면 극소입니다. 부호가 바뀌지 않으면 극값이 아닙니다. 이를 한눈에 정리한 것이 증감표입니다.
  4. 연결삼차함수에서 \(f'\)은 이차식이므로, 극값이 있는지는 \(f' = 0\)의 판별식이 정합니다. \(D > 0\)이면 부호가 두 번 바뀌어 극대와 극소가 하나씩 생기고, \(D \le 0\)이면 부호가 바뀌지 않아 극값이 없습니다. 증감표는 다음 절에서 그래프의 개형을 그리는 뼈대가 됩니다.
  5. 적용\(p = 0, q = -3\)에서 증감표를 읽고 극댓값과 극솟값을 확인하세요. \(q\)를 늘리면 봉우리와 골짜기가 어떻게 되나요? 판별식이 0이 되는 순간(예: \(p = 0, q = 0\))의 증감표에서 \(f' = 0\)인 칸 좌우의 부호를 보세요. \(p = 3\)일 때는 \(q\)가 얼마 이상이면 극값이 사라지나요?
  6. 판단"\(f'(a) = 0\)이면 극값"은 틀립니다. \(x^3\)은 \(f'(0) = 0\)이지만 0의 좌우에서 모두 증가합니다. 또 극댓값은 그 근처에서 가장 큰 값일 뿐, 함수 전체의 최댓값이 아닙니다. 극댓값이 극솟값보다 작을 수도 있고, 닫힌 구간의 최댓값은 끝점에서 나올 수도 있습니다.
