  1. 질문f(x) = x (x < 2), x − 1 (x ≥ 2)는 x = 2에서 끊어집니다. 그렇다면 '구간 [0, 2]에서 연속'이라고 할 수 있을까요? [2, 4]에서는 어떨까요? 끝점에서는 한쪽에서만 다가갈 수 있는데, 연속을 어떻게 판정해야 할까요?
  2. 복원x = a에서 연속이라는 것은 f(a)가 정의되고 limx→a f(x) = f(a)라는 뜻입니다. 좌극한과 우극한은 각각 한쪽에서 다가갈 때의 극한입니다.
  3. 설명두 실수 a < b에 대하여 {x | a ≤ x ≤ b}를 닫힌구간 [a, b], {x | a < x < b}를 열린구간 (a, b)라 하고, [a, b), (a, b]를 반닫힌 구간(반열린 구간)이라 합니다. [a, ∞), (−∞, ∞)처럼 끝이 없는 구간도 씁니다. 함수가 어떤 구간에 속하는 모든 x에서 연속일 때 그 구간에서 연속이라고 합니다. 이때 닫힌 끝점에서는 구간 안쪽의 한쪽 극한만 봅니다. f가 [a, b]에서 연속이려면 (a, b)의 모든 점에서 연속이고, limx→a+ f(x) = f(a), limx→b− f(x) = f(b)여야 합니다. 정의역의 모든 점에서 연속인 함수를 연속함수라고 합니다.
  4. 연결첫째 함수는 f(2) = 1이고 우극한도 1이므로, 2를 왼쪽 끝으로 갖는 [2, 4]에서는 연속입니다. 그러나 좌극한이 2라서 2를 오른쪽 끝으로 갖는 [0, 2]에서는 연속이 아닙니다. [0, 2)처럼 2를 빼면 다시 연속입니다. √x는 x < 0에서 정의되지 않지만 [0, ∞)에서 연속이므로 연속함수입니다. 1/(x − 1)도 x = 1에서는 정의되지 않을 뿐, 정의역의 모든 점에서 연속인 연속함수입니다.
  5. 적용첫째 함수에서 구간을 [0, 2]로 두고 오른쪽 끝을 빼 보세요. 그다음 구간을 [2, 4]로 옮겨 판정을 비교하세요. 1/(x − 1)과 √x로 바꾸어 연속이 되는 가장 넓은 구간을 끝점 포함 여부까지 찾아보세요.
  6. 판단'그래프가 한 번이라도 끊어지면 연속함수가 아니다'는 판단은 조심해야 합니다. 1/(x − 1)의 그래프는 두 조각이지만, 끊어진 곳 x = 1은 정의역에 없으므로 연속함수입니다. 다만 1을 포함한 구간 [0, 2]에서는 연속이 아닙니다. 연속은 늘 '어느 점에서', '어느 구간에서'를 함께 말해야 뜻이 정해집니다.
