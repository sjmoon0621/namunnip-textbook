두 함수를 더하고 곱하면 극한값도 더하고 곱하면 될까?

극한의 성질 · 합 · 차 · 곱 · 몫

f(x) = x + 1,  g(x) = x2 − 1

lim f / lim g
—
값 (a − d / a + d)
—
성질로 계산
—

—

  1. 질문limx→2 (x + 1) = 3, limx→2 (x2 − 1) = 3입니다. 그렇다면 두 식의 합, 곱, 몫의 극한값도 3 + 3, 3 × 3, 3 ÷ 3으로 바로 얻을 수 있을까요? 언제나 그럴까요?
  2. 복원limx→a f(x) = α는 x가 a에 가까워질 때 f(x)가 실수 α에 한없이 가까워진다는 뜻입니다. f(x)가 α에, g(x)가 β에 가까우면 두 값을 더하거나 곱한 수도 α + β, αβ에 가깝습니다.
  3. 설명limx→a f(x) = α, limx→a g(x) = β (α, β는 실수)일 때 ① lim cf(x) = cα (c는 상수) ② lim {f(x) ± g(x)} = α ± β ③ lim f(x)g(x) = αβ ④ β ≠ 0이면 lim f(x)/g(x) = α/β입니다. 이 성질은 x → a+, x → a−, x → ∞, x → −∞일 때도 성립합니다. 다항함수 p(x)는 limx→a x = a와 이 성질을 거듭 써서 limx→a p(x) = p(a)임을 보일 수 있습니다.
  4. 연결성질을 쓰려면 두 극한값이 모두 실수로 존재해야 하고, 몫에서는 분모의 극한값이 0이 아니어야 합니다. 이 조건이 깨지면 성질로는 답을 낼 수 없을 뿐이고, 극한이 없다는 뜻은 아닙니다. 그때는 식을 고쳐 다시 구합니다. 극한값은 크기 비교도 지킵니다. a 근처에서 f(x) ≤ g(x)이면 α ≤ β이고, f(x) ≤ h(x) ≤ g(x)이며 α = β이면 limx→a h(x) = α입니다. 다만 f(x) < g(x)여도 α < β라고는 할 수 없고 α = β일 수 있습니다.
  5. 적용a = 2에서 다섯 가지 계산을 차례로 눌러 '값'과 '성질로 계산'이 같은지 보세요. 그다음 f / g를 고르고 a를 1과 −1로 옮겨 보세요. 두 경우 모두 lim g = 0인데, 실제 값은 어떻게 다르게 움직이나요?
  6. 판단a = −1에서는 lim f = 0, lim g = 0이라 성질로는 0/0을 얻지만, 실제로는 f/g = 1/(x − 1) (x ≠ ±1)이므로 극한값 −1/2이 있습니다. a = 1에서는 분자가 2로 가고 분모가 0으로 가서 발산합니다. 또 각각 발산하는 두 함수의 합이 수렴할 수도 있습니다. 1/x2과 −1/x2은 x → 0에서 발산하지만 합은 0입니다. 그래서 성질은 '두 극한값이 있을 때'에만 씁니다.
