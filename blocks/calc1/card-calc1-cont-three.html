그래프가 '이어져 있다'는 것을 극한으로 어떻게 말할까?

함수의 연속 · 세 조건

f(x) = x2 (x < 2),  c (x = 2),  k − x (x > 2)

  1. —① f(2)가 정의되어 있다
  2. —② limx→2 f(x)가 존재한다
  3. —③ limx→2 f(x) = f(2)이다

  1. 질문연필을 떼지 않고 그릴 수 있으면 '이어져 있다'고 말합니다. 그런데 이 말로는 구멍 하나, 튀어 나온 점 하나를 정확히 판정하기 어렵습니다. 한 점 x = a에서 그래프가 이어져 있다는 것을 극한으로 어떻게 정할 수 있을까요?
  2. 복원limx→a f(x)는 a 근처의 값들이 모이는 곳이고, f(a)는 x = a에서의 높이입니다. 극한이 존재하려면 좌극한과 우극한이 같아야 합니다.
  3. 설명함수 f(x)가 실수 a에 대하여 ① x = a에서 정의되어 있고 ② 극한값 limx→a f(x)가 존재하며 ③ limx→a f(x) = f(a)일 때, f(x)는 x = a에서 연속이라고 합니다. 세 조건 중 하나라도 성립하지 않으면 x = a에서 불연속이라고 합니다. 이 정의는 '근처의 값들이 모이는 곳에 실제로 점이 찍혀 있다'는 뜻입니다.
  4. 연결이 함수의 좌극한은 22 = 4, 우극한은 k − 2입니다. ②는 k = 6일 때만 성립하고, ③은 거기에 c = 4가 더해져야 성립합니다. 불연속의 모양도 조건으로 나뉩니다. ①이나 ③만 깨지면 구멍이나 떨어진 점이고, ②가 깨지면 그래프가 끊어져 뛰어오릅니다.
  5. 적용처음 상태에서 깨진 조건을 확인하세요. 함숫값을 정의하지 않으면 ①부터 깨집니다. k만 바꾸어 ②를 성립시킨 다음, c를 바꾸어 ③까지 성립시켜 보세요. 세 조건이 모두 성립할 때 그래프가 어떻게 보이나요?
  6. 판단세 조건은 차례로 확인합니다. ①이 깨지면 ③은 따질 수조차 없습니다. 또 '극한값이 존재하면 연속'은 틀립니다. 극한값이 4이고 f(2) = 3이면 불연속입니다. 반대로 식이 바뀌는 점이라고 해서 불연속인 것도 아닙니다. k = 6, c = 4이면 식이 바뀌어도 연속입니다.
