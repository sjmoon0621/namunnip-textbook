속도와 가속도 · 수직선 위의 운동
위치 \(x(t) = t^3 - 6t^2 + 9t\ (0 \le t \le 5)\)
위치 \(x\)
—
속도 \(v = x'\)
—
가속도 \(a = v'\)
—

수직선 위 화살표는 속도(초록: 양의 방향, 붉은색: 음의 방향)입니다. 아래 그래프의 접선 기울기와 견주어 보세요.

  1. 질문수직선 위를 움직이는 점 \(P\)의 위치가 \(x(t) = t^3 - 6t^2 + 9t\)입니다. \(P\)는 언제 오른쪽으로 가고, 언제 되돌아올까요?
  2. 복원시간 \(\Delta t\) 동안의 평균 속도는 \(\frac{\Delta x}{\Delta t}\), 곧 위치의 평균변화율입니다. \(\Delta t \to 0\)일 때의 극한이 순간변화율, 곧 미분계수입니다.
  3. 설명시각 \(t\)에서의 속도는 \(v = \frac{dx}{dt} = x'(t)\)이고, 가속도는 속도의 순간변화율 \(a = \frac{dv}{dt} = v'(t)\)입니다. 이 점에서는 \(v = 3t^2 - 12t + 9 = 3(t - 1)(t - 3), a = 6t - 12\)입니다. 속도의 부호가 운동 방향입니다. \(v > 0\)이면 양의 방향, \(v < 0\)이면 음의 방향으로 움직이고, 속도의 부호가 바뀌는 순간 운동 방향이 바뀝니다. 여기서는 \(t = 1, t = 3\)입니다. 속력은 속도의 크기 \(|v|\)입니다.
  4. 연결위치 그래프에서 속도는 접선의 기울기이고, 방향이 바뀌는 순간은 위치 그래프의 극대·극소입니다. 증가·감소의 판정이 그대로 운동의 판정이 됩니다. 거꾸로 속도에서 위치나 움직인 거리를 구하는 일은 적분 단원에서 다룹니다.
  5. 적용재생하거나 \(t\)를 움직여 \(P\)가 되돌아오는 두 순간에 속도 수치가 얼마인지 확인하세요. \(t = 2\)에서 가속도는 0인데 \(P\)는 멈추나요? \(1 < t < 2\)와 \(2 < t < 3\)에서 속력은 각각 커지나요, 작아지나요?
  6. 판단"가속도가 0이면 멈춘다"는 틀립니다. 멈춘 순간은 속도가 0인 순간이고, \(t = 2\)에서 \(P\)는 가속도 0, 속도 \(-3\)으로 움직이는 중입니다. 또 가속도가 음수라고 늘 느려지는 것은 아닙니다. 속도와 가속도의 부호가 같으면 속력이 커지고, 다르면 작아집니다. 이 카드는 직선 위의 운동만 다룹니다.
