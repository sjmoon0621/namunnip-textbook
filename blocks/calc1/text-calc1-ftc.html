부정적분과 정적분의 관계

본문

정적분은 직사각형을 잘게 나누어 더한 극한으로 정했고, 부정적분은 미분을 거꾸로 한 것이었다. 전혀 다른 두 생각이다. 그런데 \(\displaystyle\int_0^1 x^2\,dx = \tfrac{1}{3}\)은 \(x^2\)의 부정적분 \(\tfrac{x^3}{3}\)에 1과 0을 넣은 차와 같다. 이것은 우연일까?

먼저 알아야 할 것부정적분(다항함수의 부정적분), 정적분의 뜻과 성질(정적분), 미분계수의 정의(미분계수).

3.4.1위끝이 움직이는 넓이

구간의 위끝을 변수로 둔 정적분 \(S(x) = \displaystyle\int_a^x f(t)\,dt\)를 생각하자. \(S(x)\)는 \(a\)에서 \(x\)까지 곡선 아래의 넓이이므로 \(x\)의 함수이다. 위끝을 \(x\)에서 \(x + h\)로 조금 옮기면, 넓이는 그 사이의 가는 띠만큼 는다.

그림 1에서 보듯 그 띠는 폭이 \(h\)이고 높이가 \(f(x)\) 근처이므로 넓이가 약 \(f(x)h\)이다. 따라서 \(\dfrac{S(x + h) - S(x)}{h}\)는 \(f(x)\)에 가깝고, \(h\)를 줄일수록 더 가까워진다. 즉 \(S'(x) = f(x)\)이다.1 넓이 함수를 미분하면 높이의 함수가 나오는 것이다.

정리 3.4.1 정적분과 미분의 관계

함수 \(f(x)\)가 닫힌구간 \([a, b]\)에서 연속일 때 \[\frac{d}{dx}\int_a^x f(t)\,dt = f(x)\ (a < x < b)\]

3.4.2부정적분으로 정적분 계산하기

정리에 따르면 \(S(x)\)는 \(f(x)\)의 부정적분 가운데 하나이다. 그러면 \(f\)의 다른 부정적분 \(F(x)\)와는 상수만큼만 다르므로 \(S(x) = F(x) + C\)이다. \(S(a) = 0\)이므로 \(C = -F(a)\)이고, \(x = b\)를 넣으면 \(S(b) = F(b) - F(a)\)이다.

정리 3.4.2 정적분의 계산

\(f(x)\)가 닫힌구간 \([a, b]\)에서 연속이고 \(F(x)\)가 \(f(x)\)의 한 부정적분이면 \[\int_a^b f(x)\,dx = \Big[F(x)\Big]_a^b = F(b) - F(a)\]

이 정리 덕분에 직사각형 합의 극한을 계산하지 않고도 정적분을 구할 수 있다. 부정적분 하나를 찾아 양 끝 값의 차를 구하면 된다. 처음 질문의 일치는 우연이 아니라 이 정리의 결과이다.

3.4.3예제 하나를 끝까지

예제 3.4.3

\(\displaystyle\int_1^3 (3x^2 - 2x)\,dx\)를 구하여라. 또 \(\displaystyle\int_1^x f(t)\,dt = x^3 - ax + 2\)를 만족하는 다항함수 \(f(x)\)와 상수 \(a\)를 구하여라.

\(3x^2 - 2x\)의 한 부정적분은 \(F(x) = x^3 - x^2\)이다. 따라서 \(\displaystyle\int_1^3 (3x^2 - 2x)\,dx = F(3) - F(1) = (27 - 9) - (1 - 1) = 18\)이다.

두 번째 식에 \(x = 1\)을 넣으면 왼쪽은 넓이가 0이므로 \(0 = 1 - a + 2\), 곧 \(a = 3\)이다. 또 양변을 \(x\)에 대해 미분하면 정리에 따라 왼쪽은 \(f(x)\)이므로 \(f(x) = 3x^2 - a = 3x^2 - 3\)이다.

확인하면 \(\displaystyle\int_1^x (3t^2 - 3)\,dt = (x^3 - 3x) - (1 - 3) = x^3 - 3x + 2\)로 주어진 식과 같다. 위끝이 변수인 정적분에서는 '\(x = a\)를 넣는 것'과 '미분하는 것'이 두 가지 정보를 준다. 아래 탐구 카드에서 위끝을 움직이며 넓이가 늘어나는 빠르기를 직접 확인해 보자.

  1. 정확히 말하면 띠의 넓이는 그 사이 \(f\)의 최솟값과 최댓값에 \(h\)를 곱한 값 사이에 있다. \(f\)가 연속이므로 \(h \to 0\)이면 둘 다 \(f(x)\)로 다가가 \(S'(x) = f(x)\)가 된다.
마무리

위끝이 변수인 정적분 \(S(x) = \int_a^x f(t)\,dt\)는 위끝을 조금 옮길 때 높이 \(f(x)\)인 띠만큼 늘어나므로 \(S'(x) = f(x)\)이고, 따라서 정적분은 부정적분 하나의 양 끝 값의 차 \(F(b) - F(a)\)로 계산된다. 그래서 처음 질문의 \(\tfrac{1}{3}\)은 넓이와 미분의 역관계가 만든 필연적인 일치이다.
