극한의 성질과 극한값

본문

\(\displaystyle\lim_{x \to 2}(x^2 + 3x)\)는 2를 넣어 10이라고 답하면 된다. 그런데 \(\displaystyle\lim_{x \to 2}\frac{x^2 - 4}{x - 2}\)에 2를 넣으면 \(\tfrac{0}{0}\)이 된다. \(\tfrac{0}{0}\)은 값이 아니므로 다른 방법이 필요하다. 언제 그냥 넣어도 되고, 언제 식을 바꾸어야 할까?

먼저 알아야 할 것함수의 극한, 좌극한과 우극한(함수의 극한), 다항식의 인수분해(공통수학1), 분모의 유리화.

1.2.1극한의 성질

두 함수가 각각 수렴하면, 그 합과 곱의 극한은 극한값의 합과 곱이다. \(x\)가 \(a\)에 가까워질 때 \(f(x)\)가 \(L\)에, \(g(x)\)가 \(M\)에 가까워지면 \(f(x) + g(x)\)는 \(L + M\)에 가까워지는 것이 자연스럽다.

정리 1.2.1 함수의 극한의 성질

\(\displaystyle\lim_{x \to a} f(x) = L\), \(\displaystyle\lim_{x \to a} g(x) = M\)(\(L\), \(M\)은 실수)일 때 \[\lim (f \pm g) = L \pm M,\quad \lim cf = cL,\quad \lim fg = LM,\quad \lim \frac{f}{g} = \frac{L}{M}\ (M \ne 0)\]

이 성질에 따르면 다항함수는 \(x\)에 \(a\)를 넣은 값이 극한값이다. \(x^2 + 3x\)는 \(x\)와 상수를 곱하고 더해 만든 식이고, \(x\)의 극한이 \(a\)이기 때문이다. 분수식도 분모의 극한이 0이 아니면 넣으면 된다.

1.2.2\(\tfrac{0}{0}\) 꼴: 공통인수를 약분한다

분모의 극한이 0이면 나눗셈의 성질을 쓸 수 없다. 특히 분자도 0으로 가는 \(\tfrac{0}{0}\) 꼴은 분자와 분모가 '얼마나 빨리 0으로 가는가'를 비교해야 한다. 그림 1의 슬라이더로 \(x\)를 2에 가까이 옮기면, 분자와 분모가 함께 0으로 줄어드는데 비는 4 근처에 머문다.

까닭은 분자를 인수분해하면 보인다. \(x^2 - 4 = (x - 2)(x + 2)\)이므로 \(x \ne 2\)이면 \(\dfrac{x^2 - 4}{x - 2} = x + 2\)이다. 극한은 \(x = 2\)에서의 값을 따지지 않으므로, 약분한 식에 넣어 \(\displaystyle\lim_{x \to 2}(x + 2) = 4\)를 얻는다. 즉 분자와 분모의 0을 만드는 공통인수 \(x - 2\)를 지우는 것이 요령이다.

근호가 있으면 유리화로 공통인수를 드러낸다. \(\displaystyle\lim_{x \to 0}\frac{\sqrt{x + 9} - 3}{x}\)은 분자와 분모에 \(\sqrt{x + 9} + 3\)을 곱하면 \(\dfrac{x}{x(\sqrt{x + 9} + 3)} = \dfrac{1}{\sqrt{x + 9} + 3}\)이 되어 극한값 \(\dfrac{1}{6}\)을 얻는다.1

1.2.3예제 하나를 끝까지

예제 1.2.2

\(\displaystyle\lim_{x \to 1}\frac{x^3 - 1}{x^2 - 1}\)을 구하여라. 또 \(\displaystyle\lim_{x \to 2}\frac{x^2 + ax + b}{x - 2} = 5\)일 때 상수 \(a\), \(b\)를 구하여라.

첫 식에 1을 넣으면 \(\tfrac{0}{0}\)이다. 분자는 \((x - 1)(x^2 + x + 1)\), 분모는 \((x - 1)(x + 1)\)이므로 약분하면 \(\dfrac{x^2 + x + 1}{x + 1}\)이고, 극한값은 \(\dfrac{3}{2}\)이다.

두 번째 식은 분모가 0으로 가는데 극한값이 5로 존재한다. 만약 분자가 0이 아닌 값으로 가면 비가 한없이 커지므로, 분자도 0으로 가야 한다. 따라서 \(4 + 2a + b = 0\)이고, \(b = -2a - 4\)이다.

그러면 분자는 \(x^2 + ax - 2a - 4 = (x - 2)(x + 2 + a)\)로 인수분해되고, 극한값은 \(\displaystyle\lim_{x \to 2}(x + 2 + a) = 4 + a\)이다. 이것이 5이므로 \(a = 1\), \(b = -6\)이다. 확인하면 \(\dfrac{x^2 + x - 6}{x - 2} = \dfrac{(x - 2)(x + 3)}{x - 2}\)이고 극한값은 5이다. 아래 탐구 카드에서 분자와 분모가 0으로 가는 빠르기를 직접 비교해 보자.

  1. \(\tfrac{\infty}{\infty}\) 꼴, 가령 \(\displaystyle\lim_{x \to \infty}\frac{2x^2 + 1}{x^2 - 3}\)은 분자와 분모를 가장 높은 차수 \(x^2\)으로 나누어 \(\displaystyle\lim\frac{2 + 1/x^2}{1 - 3/x^2} = 2\)를 얻는다.
마무리

수렴하는 함수의 합, 차, 곱, 몫의 극한은 극한값의 합, 차, 곱, 몫이므로 다항함수와 분모가 0으로 가지 않는 분수식은 값을 넣어 극한값을 얻는다. 넣어서 \(\tfrac{0}{0}\)이 되면 인수분해나 유리화로 0을 만드는 공통인수를 지운 뒤 넣는다. 그래서 처음 질문의 \(\tfrac{x^2 - 4}{x - 2}\)는 \(x + 2\)로 약분해 극한값 4를 얻는다.
