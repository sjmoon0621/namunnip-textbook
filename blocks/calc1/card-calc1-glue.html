두 식을 이어 붙이면 언제 매끄럽게 이어질까?

미분가능성과 연속성 · 이어 붙인 함수

f(x) = x2 (x < 1),  ax + b (x ≥ 1)

lim x→1− f(x) / f(1)

오른쪽 미분계수
—

—

왼쪽 미분계수는 limh→0− (f(1 + h) − f(1))/h입니다. f(1)은 오른쪽 식으로 정한 값 a + b입니다.

  1. 질문x < 1에서는 x2, x ≥ 1에서는 직선 ax + b인 함수가 있습니다. 끊기지도 꺾이지도 않게, 곧 x = 1에서 미분가능하게 하려면 a와 b를 어떻게 골라야 할까요?
  2. 복원f가 x = 1에서 연속이려면 limx→1 f(x) = f(1)이어야 합니다. 미분가능하려면 좌우의 (f(1 + h) − f(1))/h가 같은 극한값을 가져야 합니다.
  3. 설명f가 x = a에서 미분가능하면 x = a에서 연속입니다. h ≠ 0일 때 f(a + h) − f(a) = (f(a + h) − f(a))/h × h로 쓸 수 있습니다. h → 0이면 앞의 인수는 f′(a)로, 뒤의 인수는 0으로 가므로 f(a + h) − f(a) → f′(a) × 0 = 0, 곧 limh→0 f(a + h) = f(a)입니다. 이 정리의 대우는 "연속이 아니면 미분가능하지 않다"입니다. 그러나 역 "연속이면 미분가능하다"는 거짓입니다. |x|는 x = 0에서 연속이지만 미분가능하지 않습니다. 그래서 이 함수에서는 ① 연속 조건 1 = a + b와 ② 좌우 미분계수가 같다는 조건 2 = a를 함께 써야 합니다.
  4. 연결두 조건을 만족하는 직선 y = 2x − 1은 y = x2의 점 (1, 1)에서의 접선입니다. 이어 붙인 함수가 미분가능하다는 것은 오른쪽 식이 왼쪽 식과 같은 점, 같은 기울기로 이어진다는 뜻입니다.
  5. 적용먼저 a = 1로 둔 채 b만 움직여 연속이 되는 b를 찾으세요. 이때 좌우 미분계수는 같은가요? 이번에는 a + b = 1을 지키며 a를 바꾸어 미분가능하게 되는 a를 찾으세요. 연속이 아닐 때 왼쪽 미분계수가 어떻게 되는지도 보세요.
  6. 판단좌우 도함수의 값만 같게 맞추고 연속 조건을 빠뜨리는 실수가 흔합니다. a = 2, b = 0이면 왼쪽 식의 기울기 2x와 오른쪽 기울기 2가 x = 1에서 같아 보이지만, 그래프가 끊어져 있어 미분가능하지 않습니다. 이때 왼쪽 미분계수는 2가 아니라 발산합니다.
