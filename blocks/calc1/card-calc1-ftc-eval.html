넓이를 재지 않고 정적분을 구할 수 있을까?

부정적분과 정적분 · \(F(b) - F(a)\)

—

\(F(b) + C\)
—
\(F(a) + C\)
—
차 = 정적분
—
직사각형 2000개 합
—
  1. 질문\(\int_0^2 (3x^2 - 2x)\,dx\)를 구하려고 직사각형을 수천 개 더할 수는 없다. 부정적분을 알면 정적분을 바로 구할 수 있을까?
  2. 복원\(S(x) = \int_a^x f(t)\,dt\)는 \(f(x)\)의 부정적분이고 \(S(a) = 0\)이다. 그리고 같은 함수의 두 부정적분은 상수만큼 다르다.
  3. 설명\(F(x)\)를 \(f(x)\)의 한 부정적분이라 하면 \(S(x) = F(x) + k\) (\(k\)는 상수)이다. \(x = a\)를 넣으면 \(0 = F(a) + k\), 곧 \(k = -F(a)\)이므로 \(S(x) = F(x) - F(a)\)이다. 여기에 \(x = b\)를 넣으면 \(\int_a^b f(x)\,dx = [F(x)]_a^b = F(b) - F(a)\)이고, 기호 \([F(x)]_a^b\)는 \(F(b) - F(a)\)를 줄여 쓴 것이다. 예를 들어 \(\int_0^2 (3x^2 - 2x)\,dx = [x^3 - x^2]_0^2 = (8 - 4) - 0 = 4\)이다.
  4. 연결즉 넓이를 직접 재던 일이 부정적분의 두 함숫값의 차로 바뀌었다. 아래 그래프에서 이 차는 \(x = a\)와 \(x = b\)에서의 높이 차이다. 위치 함수의 높이 차가 변위인 것처럼, 부정적분의 높이 차가 정적분이다.
  5. 적용\(C\)를 바꾸어도 '차 = 정적분'이 바뀌지 않는지, 그 값이 '직사각형 2000개 합'과 같은지 확인해 보자. \(4 - x^2\)에서 \(a = -1.5, b = 2.5\)로 두면 정적분이 음수가 되는데, 위 그래프의 어느 부분 때문인지 찾아보고, \(a\)와 \(b\)를 바꾸면 부호가 뒤집히는 것도 보자.
  6. 판단정적분은 부정적분과 달리 하나의 수이다. \(F(b) + C\)와 \(F(a) + C\)를 빼면 \(C\)가 지워지므로, 계산할 때 적분상수는 0으로 두면 된다. 흔한 실수는 \(F\)가 아닌 \(f\)에 \(b, a\)를 넣는 것과, \(F(a)\)를 뺄 때 괄호를 빠뜨려 부호를 틀리는 것이다.
