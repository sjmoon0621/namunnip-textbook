y = xⁿ의 도함수

본문

\(y = x^2\)에서 \(x = 1\)의 접선 기울기는 2, \(x = 3\)에서는 6이었다. 점마다 극한을 새로 계산하는 대신, '\(x\)에서의 기울기'를 \(x\)의 식 하나로 쓸 수는 없을까? 그리고 \(x^3\), \(x^{10}\)의 기울기는 어떤 규칙을 따를까?

먼저 알아야 할 것미분계수(미분계수), 함수의 극한(함수의 극한), 곱셈 공식과 이항 전개.

2.3.1도함수

\(f(x) = x^2\)의 미분계수를 \(a\) 대신 문자 \(x\)로 계산해 보자. \(\dfrac{(x + h)^2 - x^2}{h} = \dfrac{2xh + h^2}{h} = 2x + h\)이므로, \(h \to 0\)이면 \(2x\)이다. 즉 어느 점에서든 접선의 기울기는 그 점의 \(x\)좌표의 2배이다. \(x = 1\)이면 2, \(x = 3\)이면 6으로 앞의 값과 맞는다.

다시 말해 각 \(x\)에 그 점의 미분계수를 대응시키면 새로운 함수가 생긴다.

정의 2.3.1 도함수

미분가능한 함수 \(f(x)\)의 정의역의 각 \(x\)에 미분계수 \(f'(x)\)를 대응시키는 함수 \[f'(x) = \lim_{h \to 0}\frac{f(x + h) - f(x)}{h}\] 를 \(f(x)\)의 도함수라 한다. \(y'\), \(\dfrac{dy}{dx}\)로도 쓰며, 도함수를 구하는 것을 미분한다고 한다.

2.3.2\(x^n\)의 도함수

\(x^3\)도 같은 방법으로 미분한다. \((x + h)^3 = x^3 + 3x^2h + 3xh^2 + h^3\)이므로 \(\dfrac{(x + h)^3 - x^3}{h} = 3x^2 + 3xh + h^2\)이고, \(h \to 0\)이면 \(3x^2\)이다. 여기서 \(h\)가 하나뿐인 항 \(3x^2h\)만 살아남고, \(h\)가 둘 이상 곱해진 항은 모두 사라진 것에 주목하자.

\(n\)제곱에서도 같다. \((x + h)^n\)을 전개하면 \(x^n + nx^{n-1}h + (h^2\text{ 이상이 곱해진 항})\)이다. \(x^n\)을 빼고 \(h\)로 나눈 뒤 \(h \to 0\)으로 보내면 \(nx^{n-1}\)만 남는다.1

정리 2.3.2 \(y = x^n\)의 도함수

\(n\)이 자연수일 때 \((x^n)' = nx^{n-1}\)이다. 또 상수함수 \(y = c\)의 도함수는 0이다.

그림 1에서 \(n\)과 \(x\)를 바꾸어 보자. 위 그래프의 접선 기울기가 아래 그래프의 점의 높이가 된다. \(n = 2\)이면 아래 그래프는 직선 \(y = 2x\), \(n = 3\)이면 포물선 \(y = 3x^2\)이다. \(x^3\)은 원점에서 기울기가 0이고 양쪽에서 모두 올라가므로, 도함수 \(3x^2\)은 원점에서 0이고 나머지에서 양수이다.

2.3.3예제 하나를 끝까지

예제 2.3.3

\(f(x) = x^4\)의 도함수를 구하고, \(x = -1\), \(0\), \(2\)에서의 접선의 기울기를 구하여라. 또 \(y = x^3\)의 그래프 위에서 접선의 기울기가 12인 점을 모두 구하여라.

공식에 따라 \(f'(x) = 4x^3\)이다. 그러면 \(f'(-1) = -4\), \(f'(0) = 0\), \(f'(2) = 32\)이다. \(x^4\)의 그래프는 원점에서 바닥이 평평하고, 왼쪽에서는 내려가며 오른쪽에서는 가파르게 올라간다는 것이 기울기의 부호와 크기에서 읽힌다.

\(y = x^3\)의 도함수는 \(3x^2\)이다. 기울기가 12인 점은 \(3x^2 = 12\), 곧 \(x = \pm 2\)인 점이다. 따라서 \((2, 8)\)과 \((-2, -8)\) 두 점이다.

정의로 확인하면 \(\dfrac{(2 + h)^3 - 8}{h} = 12 + 6h + h^2 \to 12\)이다. 공식 하나가 극한 계산을 대신해 주었다. 아래 탐구 카드에서 접선의 기울기를 모아 도함수의 그래프를 직접 그려 보자.

  1. \((x + h)^n\)의 전개에서 \(x^{n-1}h\)의 계수가 \(n\)인 것은, \(n\)개의 괄호 \((x + h)\) 가운데 하나에서만 \(h\)를 고르고 나머지에서 \(x\)를 고르는 방법이 \(n\)가지이기 때문이다.
마무리

도함수는 각 점의 미분계수를 \(x\)의 함수로 모은 것이다. \((x + h)^n\)을 전개해 \(h\)로 나누면 \(h\)가 하나 곱해진 항만 남으므로 \((x^n)' = nx^{n-1}\)이다. 그래서 처음 질문의 기울기는 \(x^2\)에서 \(2x\), \(x^3\)에서 \(3x^2\), \(x^{10}\)에서 \(10x^9\)이라는 한 규칙을 따른다.
