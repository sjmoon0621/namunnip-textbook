여러 항의 합은 항마다 따로 적분해도 될까?

다항함수의 부정적분 · 실수배, 합, 차

—

—

지금까지 쌓은 \(F(x)\)
—
적분한 항
—
\(F'(x) = f(x)\)?
—

\(f(x)\) 쌓은 \(F(x)\) \(F'(x)\)

  1. 질문\(x^3 - 3x^2 + 2\)를 적분하려면, 미분해서 이 식이 되는 함수를 통째로 찾아야 할까요? 아니면 항마다 따로 적분해서 더해도 될까요?
  2. 복원미분에서는 \(\{kf(x)\}' = kf'(x), \{f(x) \pm g(x)\}' = f'(x) \pm g'(x)\)입니다. 또 \(\int x^n\,dx = \frac{x^{n+1}}{n + 1} + C\)입니다.
  3. 설명\(F' = f, G' = g\)이면 미분의 성질에서 \((kF)' = kf, (F \pm G)' = f \pm g\)입니다. 그래서 두 함수 \(f(x), g(x)\)와 상수 \(k\)에 대해 \(\int kf(x)\,dx = k\int f(x)\,dx\ (k \ne 0)\), \(\int\{f(x) \pm g(x)\}\,dx = \int f(x)\,dx \pm \int g(x)\,dx\)입니다. 다항함수는 거듭제곱의 실수배를 더하고 뺀 것이므로, 항마다 적분해 더하고 적분상수는 마지막에 \(C\) 하나로 모읍니다. 예: \(\int(x^3 - 3x^2 + 2)\,dx = \frac{1}{4}x^4 - x^3 + 2x + C\).
  4. 연결곱으로 된 식은 먼저 전개해 합의 꼴로 바꾼 뒤 적분합니다. 이 성질은 정적분에서도 그대로 성립하여, 정적분을 항마다 나누어 계산하는 근거가 됩니다.
  5. 적용'다음 항'을 누를 때마다 주황 점선\((F')\)이 어떻게 파란 곡선\((f)\)에 다가가나요? 끝까지 적분한 뒤 계수를 바꾸어 다른 식도 해 보세요. 상수항만 0이 아닌 식을 적분하면 \(F(x)\)는 어떤 그래프인가요?
  6. 판단합과 차는 항마다 나눌 수 있지만 곱은 나눌 수 없습니다. \(\int x \cdot x\,dx\)는 \(\int x\,dx \cdot \int x\,dx = \frac{1}{4}x^4\)이 아니라 \(\int x^2\,dx = \frac{1}{3}x^3 + C\)입니다. 또 실수배 성질에서 \(k = 0\)이면 왼쪽은 \(\int 0\,dx = C\), 오른쪽은 0이 되어 같지 않으므로 \(k \ne 0\)이라는 조건을 붙입니다.
