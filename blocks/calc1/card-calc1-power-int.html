f(x) = xⁿ 후보 F(x) F′(x)

  1. 질문미분하면 x2이 되는 함수를 찾고 싶습니다. 지수를 하나 올린 x3을 미분하면 3x2이라 3배가 남습니다. 이 3을 어떻게 없앨까요?
  2. 복원n이 자연수일 때 (xn)′ = nxn−1이고, 상수 k에 대해 {kf(x)}′ = kf′(x)입니다. 부정적분은 미분하면 피적분함수가 되는 함수입니다.
  3. 설명미분은 지수를 하나 내리면서 원래 지수를 앞에 곱합니다. 거꾸로 가려면 지수를 하나 올리고, 올린 지수로 나눕니다. 실제로 {xn+1/(n + 1)}′ = (n + 1)xn/(n + 1) = xn이므로 ∫xndx = xn+1/(n + 1) + C (n = 0, 1, 2, …)입니다. n = 0이면 ∫1 dx = x + C, 상수 k이면 ∫k dx = kx + C입니다.
  4. 연결이 공식과 다음에 볼 실수배·합·차의 성질을 합치면 모든 다항함수의 부정적분을 구할 수 있습니다. 미분 공식을 거꾸로 읽어 적분 공식을 얻는 방법은 미적분Ⅱ에서 삼각함수, 지수함수의 적분으로 이어집니다.
  5. 적용후보 ①을 고르고 n을 0부터 4까지 바꾸어 보세요. 'F′(x) ÷ f(x)'가 언제나 얼마인가요? 그 값과 n 사이의 관계를 찾은 다음 후보 ②로 바꾸어, 주황 점선이 파란 곡선과 겹치는지 확인하세요.
  6. 판단지수를 올리지 않고 내리거나(미분과 헷갈림), 지수는 올렸는데 나누지 않는 실수가 많습니다. 구한 결과를 미분해서 피적분함수로 돌아오는지 확인하면 바로 잡을 수 있습니다. 또 이 공식은 n = −1이면 0으로 나누게 되어 쓸 수 없습니다. 1/x의 적분은 미적분Ⅱ에서 따로 다룹니다.
