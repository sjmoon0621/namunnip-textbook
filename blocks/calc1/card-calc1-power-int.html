\(x^n\)을 적분하면 왜 \(n + 1\)로 나눌까?

다항함수의 부정적분 · 거듭제곱
후보 \(F(x)\)
—
\(F'(x)\)
—
\(F'(x) \div f(x)\)
—

\(f(x) = x^n\) 후보 \(F(x)\) \(F'(x)\)

  1. 질문미분하면 \(x^2\)이 되는 함수를 찾고 싶습니다. 지수를 하나 올린 \(x^3\)을 미분하면 \(3x^2\)이라 3배가 남습니다. 이 3을 어떻게 없앨까요?
  2. 복원\(n\)이 자연수일 때 \((x^n)' = nx^{n-1}\)이고, 상수 \(k\)에 대해 \(\{kf(x)\}' = kf'(x)\)입니다. 부정적분은 미분하면 피적분함수가 되는 함수입니다.
  3. 설명미분은 지수를 하나 내리면서 원래 지수를 앞에 곱합니다. 거꾸로 가려면 지수를 하나 올리고, 올린 지수로 나눕니다. 실제로 \(\{\frac{x^{n+1}}{n + 1}\}' = \frac{(n + 1)x^n}{n + 1} = x^n\)이므로 \(\int x^n\,dx = \frac{x^{n+1}}{n + 1} + C\) \((n = 0, 1, 2, \cdots)\)입니다. \(n = 0\)이면 \(\int 1\,dx = x + C\), 상수 \(k\)이면 \(\int k\,dx = kx + C\)입니다.
  4. 연결이 공식과 다음에 볼 실수배·합·차의 성질을 합치면 모든 다항함수의 부정적분을 구할 수 있습니다. 미분 공식을 거꾸로 읽어 적분 공식을 얻는 방법은 미적분Ⅱ에서 삼각함수, 지수함수의 적분으로 이어집니다.
  5. 적용후보 ①을 고르고 \(n\)을 0부터 4까지 바꾸어 보세요. '\(F'(x) \div f(x)\)'가 언제나 얼마인가요? 그 값과 \(n\) 사이의 관계를 찾은 다음 후보 ②로 바꾸어, 주황 점선이 파란 곡선과 겹치는지 확인하세요.
  6. 판단지수를 올리지 않고 내리거나(미분과 헷갈림), 지수는 올렸는데 나누지 않는 실수가 많습니다. 구한 결과를 미분해서 피적분함수로 돌아오는지 확인하면 바로 잡을 수 있습니다. 또 이 공식은 \(n = -1\)이면 0으로 나누게 되어 쓸 수 없습니다. \(\frac{1}{x}\)의 적분은 미적분Ⅱ에서 따로 다룹니다.
