분모가 0으로 가는데 극한값이 있다면 분자는?

극한값의 활용 · 미정계수 정하기

limx→1 (x2 + ax + b)/(x − 1) = 3이 되게 하기

분자의 x → 1 극한
—
f(0.999) / f(1.001)
—
lim x→1
—

—

  1. 질문limx→1 (x2 + ax + b)/(x − 1) = 3이 되도록 상수 a, b를 정하려고 합니다. 분모가 0으로 가는데 몫이 3이라는 유한한 값으로 간다면, 분자에 대해 무엇을 알 수 있을까요?
  2. 복원lim f = α, lim g = β가 실수로 존재하면 lim f·g = αβ입니다. 다항함수는 limx→a p(x) = p(a)입니다.
  3. 설명limx→a f(x)/g(x) = α (α는 실수)이고 limx→a g(x) = 0이면 limx→a f(x) = 0입니다. f(x) = {f(x)/g(x)} × g(x)로 쓰면, 곱의 성질에서 lim f = α × 0 = 0이기 때문입니다. 이 카드의 식에서는 분자의 극한 1 + a + b가 0이어야 하므로 b = −1 − a입니다. 그러면 분자는 (x − 1)(x + 1 + a)로 인수분해되고, 약분하면 극한값은 2 + a입니다.
  4. 연결2 + a = 3에서 a = 1, b = −2입니다. 첫 조건(분자 → 0)은 '극한이 있을 수 있는 후보'를 한 직선 위로 좁히고, 둘째 조건(약분한 값 = 3)이 그중 하나를 고릅니다. 같은 생각을 거꾸로 쓰면, 분자가 0으로 가고 몫의 극한값이 0이 아닌 실수이면 분모도 0으로 가야 합니다.
  5. 적용먼저 a = 0으로 두고 b를 움직여 그래프가 x = 1 양쪽으로 갈라지지 않는 b를 찾으세요. 그때 극한값은 얼마인가요? 이번에는 분자의 극한이 0을 지키도록 a와 b를 함께 바꾸어 극한값이 3이 되는 경우를 찾으세요.
  6. 판단분자의 극한이 0이라는 조건만으로 답을 끝내면 안 됩니다. 그 조건은 극한이 존재하기 위한 필요조건일 뿐이고, 1 + a + b = 0을 만족하는 (a, b)는 무수히 많습니다. 반대로 분자의 극한이 0이 아니면 몫은 x = 1 양쪽에서 부호가 다른 무한대로 발산하여 어떤 극한값도 가질 수 없습니다.
