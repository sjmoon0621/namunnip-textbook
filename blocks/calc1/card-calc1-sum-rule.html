두 함수를 더하면 기울기도 더해질까?

실수배·합·차의 미분법 · 계수 조절

—

f′(a) = 2a
—
g′(a) = 3a²
—
k·f′(a) + m·g′(a)
—
굵은 곡선의 평균변화율 (h = 0.001)
—

그림을 끌어도 P가 움직입니다. 주황 선분이 굵은 곡선의 접선입니다.

  1. 질문f(x) = x2와 g(x) = x3의 도함수는 압니다. 3x2이나 x3 + x2은 정의로 다시 계산해야 할까요, 아니면 아는 도함수를 이어 붙이면 될까요?
  2. 복원(xn)′ = nxn−1이고 상수의 도함수는 0입니다. 극한값이 있으면 lim (k·A) = k·lim A, lim (A ± B) = lim A ± lim B입니다.
  3. 설명(kf(x + h) − kf(x))/h = k × (f(x + h) − f(x))/h이므로 극한을 취하면 {kf(x)}′ = kf′(x)입니다(k는 실수). 같은 방법으로 평균변화율을 두 분수로 나누면 {f(x) + g(x)}′ = f′(x) + g′(x), {f(x) − g(x)}′ = f′(x) − g′(x)입니다. 단, f와 g가 미분가능해야 합니다. 그래서 다항함수는 항마다 미분해 더하면 됩니다. 예를 들어 (4x3 − 2x + 7)′ = 12x2 − 2입니다.
  4. 연결세 항 이상이어도 같습니다. {kf + mg}′ = kf′ + mg′처럼 계수를 곱하고 더하는 계산이 미분과 순서를 바꿔도 결과가 같습니다. 상수항은 그래프를 위아래로 옮길 뿐 기울기를 바꾸지 않으므로 미분하면 사라집니다.
  5. 적용'합'에서 a = 1일 때 f′(1), g′(1)을 더한 값과 굵은 곡선의 평균변화율을 비교하세요. '차'로 바꾸면 어떻게 되나요? k만 2배로 바꾸면 접선의 기울기 중 어느 부분이 2배가 되나요? a = 0으로 두면 계수와 상관없이 기울기가 0인 까닭은 무엇인가요?
  6. 판단상수항을 미분해 그대로 남기는 실수가 흔합니다. (x2 + 5)′ = 2x이지 2x + 5가 아닙니다. 또 실수배와 합은 이렇게 나눌 수 있지만, 곱은 {f(x)g(x)}′ ≠ f′(x)g′(x)입니다. 곱의 미분법은 따로 있습니다.
