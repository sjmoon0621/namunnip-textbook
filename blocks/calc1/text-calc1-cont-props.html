연속함수끼리 더하고 곱하고 나누어도 연속일까?

읽기 · 연속함수의 성질

\(x^3 - 2x + 5\)가 모든 실수에서 연속이라는 것을 어떻게 알 수 있을까요? 점마다 세 조건을 확인하지 않고도 판정할 수 있는 방법이 있습니다.

1극한의 성질에서 바로 나온다

두 함수 \(f(x), g(x)\)가 \(x = a\)에서 연속이면 \(\lim_{x \to a} f(x) = f(a), \lim_{x \to a} g(x) = g(a)\)입니다. 두 극한값이 실수로 존재하므로 극한의 성질을 쓸 수 있습니다. 예를 들어 곱은 \(\lim_{x \to a} f(x)g(x) = f(a)g(a)\)이므로, \(f(x)g(x)\)도 \(x = a\)에서 연속입니다. 같은 방법으로 다음이 성립합니다.

\(f, g\)가 \(x = a\)에서 연속일 때\(x = a\)에서 연속인 함수근거
실수배\(cf(x)\) (\(c\)는 상수)\(\lim cf = c \lim f\)
합과 차\(f(x) + g(x), f(x) - g(x)\)\(\lim (f \pm g) = \lim f \pm \lim g\)
곱\(f(x)g(x)\)\(\lim fg = \lim f \times \lim g\)
몫\(\frac{f(x)}{g(x)}\), 단 \(g(a) \ne 0\)\(\lim \frac{f}{g} = \lim f \div \lim g\)

2다항함수와 유리함수

상수함수 \(y = c\)와 \(y = x\)는 모든 실수에서 연속입니다. \(x^2 = x \times x\)는 곱이므로 연속이고, 같은 방법으로 \(x^n\)도 연속입니다. 여기에 실수배와 합을 거듭하면 다항함수는 모든 실수에서 연속입니다. 다항함수의 몫인 유리함수 \(\frac{p(x)}{q(x)}\)는 \(q(x) \ne 0\)인 모든 실수, 곧 정의역 전체에서 연속입니다. 그래서 \(\frac{x^2 + 1}{x - 3}\)은 \(x \ne 3\)인 모든 실수에서 연속인 연속함수입니다.

3쓰는 법

  • 식이 하나로 주어진 다항함수, 유리함수는 정의역의 모든 점에서 연속입니다. 따로 확인할 필요가 없습니다.
  • 식이 바뀌는 함수는 각 조각이 다항함수라면, 조각 안에서는 연속이고 식이 바뀌는 점에서만 세 조건을 확인하면 됩니다.
  • \(f(x)g(x)\)가 연속이 되도록 하는 문제에서는, 불연속인 점 \(a\)에서 다른 쪽 함수가 0이 되어 끊어진 곳을 메우는지 극한값을 직접 계산합니다.

판단성질의 역은 성립하지 않습니다. \(f + g\)나 \(fg\)가 연속이어도 \(f, g\)가 각각 연속이라는 보장은 없습니다. 예를 들어 \(f(x) = 1\ (x \ge 0), -1\ (x < 0)\)은 \(x = 0\)에서 불연속이지만, \(f(x) \times f(x) = 1\)은 모든 실수에서 연속입니다. 또 몫에서는 분모가 0이 되는 점을 반드시 따로 봐야 합니다.
