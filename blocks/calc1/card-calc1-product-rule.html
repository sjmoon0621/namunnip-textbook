곱의 미분은 왜 f′g + fg′일까?

곱의 미분법 · 넓이 모형
늘어난 넓이 ÷ h = Δ(fg)/h
—
모서리 조각 ΔfΔg ÷ h
—
f′(x)g(x) + f(x)g′(x)
—
f′(x)g′(x) (흔한 착각)
—

연두 조각은 fΔg, 파란 조각은 gΔf, 주황 모서리는 ΔfΔg입니다. 그림은 직사각형이 칸을 채우도록 가로·세로 배율을 따로 맞춘 모식입니다.

  1. 질문{x · x2}′ = (x3)′ = 3x2입니다. 그런데 두 인수의 도함수를 곱하면 1 × 2x = 2x로 맞지 않습니다. 곱을 미분하는 올바른 규칙은 무엇일까요?
  2. 복원가로 a, 세로 b인 직사각형의 넓이는 ab입니다. 가로가 Δa, 세로가 Δb만큼 늘면 넓이는 (a + Δa)(b + Δb) = ab + aΔb + bΔa + ΔaΔb가 됩니다.
  3. 설명Δf = f(x + h) − f(x), Δg = g(x + h) − g(x)라 하면 f(x + h)g(x + h) − f(x)g(x) = gΔf + fΔg + ΔfΔg입니다. h로 나누면 g · Δf/h + f · Δg/h + Δf · Δg/h입니다. h → 0이면 Δf/h → f′(x), Δg/h → g′(x)이고, 마지막 항은 (Δf/h) × Δg → f′(x) × 0 = 0입니다. 그래서 {f(x)g(x)}′ = f′(x)g(x) + f(x)g′(x)입니다. 이 식은 f, g가 미분가능할 때 성립합니다.
  4. 연결세 함수의 곱은 {fgh}′ = f′gh + fg′h + fgh′입니다. 같은 함수를 곱하면 [{f(x)}2]′ = 2f(x)f′(x)입니다. 곱의 미분법을 쓰면 다항식을 전개하지 않고도 도함수를 구할 수 있습니다.
  5. 적용x · x2, x = 1에서 h를 줄여 보세요. 주황 모서리 조각 ÷ h는 어디로 가나요? 늘어난 넓이 ÷ h는 f′g + fg′과 f′g′ 중 어느 값에 다가가나요? 다른 함수와 다른 x에서도 확인하세요.
  6. 판단{f(x)g(x)}′ = f′(x)g′(x)는 틀린 식입니다. 그림에서 f′g′에 해당하는 것은 모서리 조각뿐이고, 이 조각은 h로 나누어도 0으로 사라집니다. 넓이를 실제로 늘리는 것은 양옆의 두 띠입니다. 넓이 그림은 f, g가 양수일 때의 모식이지만, 식의 유도는 부호와 상관없이 성립합니다.
