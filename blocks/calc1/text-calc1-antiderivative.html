부정적분

본문

어떤 함수를 미분했더니 \(2x\)가 나왔다. 원래 함수는 \(x^2\)일 것 같다. 그런데 \(x^2 + 5\)나 \(x^2 - 3\)을 미분해도 \(2x\)이다. 그렇다면 원래 함수는 몇 개이고, 하나로 정하려면 무엇이 더 필요할까?

먼저 알아야 할 것도함수와 \(y = x^n\)의 도함수(y = xⁿ의 도함수), 평균값 정리(평균값 정리), 접선의 기울기.

3.1.1미분을 거꾸로

미분은 함수에서 기울기의 함수를 얻는 일이다. 그 반대로 기울기의 함수에서 원래 함수를 찾는 일을 생각하자. 함수 \(F(x)\)의 도함수가 \(f(x)\)일 때, 곧 \(F'(x) = f(x)\)일 때 \(F(x)\)를 \(f(x)\)의 부정적분이라 한다.

\(F(x) = x^2\)이 \(2x\)의 부정적분이면 \(x^2 + C\)(\(C\)는 상수)도 모두 부정적분이다. 상수는 미분하면 0이 되어 사라지기 때문이다. 그림 1에서 보듯 이 함수들의 그래프는 같은 모양의 포물선을 위아래로 옮긴 것이어서, 같은 \(x\)에서 접선의 기울기가 모두 같다.

3.1.2부정적분은 상수만큼만 다르다

거꾸로, 도함수가 같은 두 함수는 상수만큼만 다를까? \(F' = G'\)이면 \(H = F - G\)의 도함수는 0이다. 평균값 정리에 따라 어느 두 점 사이에서도 \(H(b) - H(a) = H'(c)(b - a) = 0\)이므로 \(H\)는 상수이다. 즉 \(f\)의 부정적분은 하나를 찾으면 나머지는 모두 그것에 상수를 더한 것이다.

정의 3.1.1 부정적분과 적분상수

\(F'(x) = f(x)\)일 때 \(f(x)\)의 부정적분은 \[\int f(x)\,dx = F(x) + C\ (C\text{는 상수})\] 이고, \(C\)를 적분상수라 한다. \(f(x)\)의 부정적분을 구하는 것을 \(f(x)\)를 적분한다고 한다.

적분상수를 하나로 정하려면 조건이 하나 더 있어야 한다. 그림 1의 슬라이더로 그래프가 지나는 점을 정하면, 포물선 가족 가운데 그 점을 지나는 것은 하나뿐이다.1

3.1.3예제 하나를 끝까지

예제 3.1.2

곡선 \(y = F(x)\) 위의 점 \((x, F(x))\)에서의 접선의 기울기가 \(2x\)이고, 이 곡선이 점 \((1, 3)\)을 지날 때 \(F(x)\)를 구하여라. 또 \(\displaystyle\frac{d}{dx}\int f(x)\,dx\)와 \(\displaystyle\int \left\{\frac{d}{dx}f(x)\right\}dx\)가 어떻게 다른지 \(f(x) = x^2 + 1\)로 확인하여라.

접선의 기울기가 \(F'(x) = 2x\)이므로 \(F(x) = x^2 + C\)이다. 점 \((1, 3)\)을 지나므로 \(1 + C = 3\), 곧 \(C = 2\)이다. 따라서 \(F(x) = x^2 + 2\)이다. 그림 1의 처음 모습이 이 곡선이다.

\(f(x) = x^2 + 1\)을 먼저 적분하면 \(\dfrac{x^3}{3} + x + C\)이고, 이것을 미분하면 다시 \(x^2 + 1\)이 된다. 반면 먼저 미분하면 \(2x\)이고, 이것을 적분하면 \(x^2 + C\)가 된다. 원래의 \(+1\)은 사라지고 \(C\)가 대신 붙는다.

즉 적분한 뒤 미분하면 제자리로 돌아오지만, 미분한 뒤 적분하면 상수만큼 차이가 남는다. 미분이 상수의 정보를 지우기 때문이다. 아래 탐구 카드에서 기울기만으로 그래프를 그려 보고, 한 점의 조건이 그래프를 정하는 모습을 확인해 보자.

  1. 기울기의 함수만 주어지면 그래프의 '모양'은 정해지지만 '높이'는 정해지지 않는다. 가령 물체의 속도만 알면 움직인 모양은 알 수 있어도, 처음 위치를 알아야 지금 위치가 정해진다.
마무리

부정적분은 미분하면 \(f(x)\)가 되는 함수이고, 도함수가 같은 함수들은 상수만큼만 다르므로 \(\int f(x)\,dx = F(x) + C\)로 쓴다. 적분상수 \(C\)는 지나는 점 같은 조건 하나로 정해진다. 그래서 처음 질문의 원래 함수는 \(x^2 + C\) 꼴로 무수히 많고, 한 점을 지난다는 조건이 있어야 하나로 정해진다.
