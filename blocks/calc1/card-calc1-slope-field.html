한 점을 지나라는 조건이 있으면 적분상수가 정해질까?

부정적분 · 기울기장
조건
—
정해진 \(C\)
—
구한 함수 \(F(x)\)
—

짧은 선분은 그 자리에서 곡선이 가져야 할 기울기 \(F'(x)\)입니다. 주황 점을 끌어 옮겨 보세요.

  1. 질문\(F'(x) = 2x\)를 만족하는 함수는 \(x^2 + C\) 꼴로 끝없이 많습니다. 그 가운데 점 (1, 3)을 지나는 것은 몇 개일까요?
  2. 복원\(F'(x) = f(x)\)인 \(F(x)\)가 \(f(x)\)의 부정적분이고, 모든 부정적분은 \(\int f(x)\,dx = F(x) + C\)처럼 상수만큼씩 다릅니다.
  3. 설명각 점 \((x, y)\)에 기울기 \(f(x)\)인 짧은 선분을 그리면 기울기장이 됩니다. 부정적분의 그래프는 이 선분들을 따라 흐르는 곡선입니다. 기울기가 \(x\)에만 달려 있으므로 같은 세로줄의 선분은 모두 평행하고, 곡선 하나를 위아래로 옮기면 다른 곡선이 됩니다. 한 점 \((x_0, y_0)\)을 지나야 한다는 조건을 주면 \(F(x_0) + C = y_0\)에서 \(C = y_0 - F(x_0)\)로 하나가 정해집니다. 예를 들어 \(F'(x) = 2x, F(1) = 3\)이면 \(1 + C = 3\)에서 \(C = 2\), 곧 \(F(x) = x^2 + 2\)입니다.
  4. 연결물체의 속도를 알면 위치 함수를 부정적분으로 구할 수 있고, 처음 위치 하나가 적분상수를 정합니다. 기울기장은 나중에 미분방정식을 풀 때 그림으로 답의 모양을 미리 보는 도구로도 쓰입니다.
  5. 적용점을 같은 세로줄에서 위아래로만 옮기면 곡선의 모양이 바뀌나요, 위치만 바뀌나요? \(F'(x) = x^2 - 1\)에서 점 (0, 0)을 지나는 곡선의 \(C\)는 얼마이고, 곡선 위의 어느 점에서 선분이 가로로 눕나요?
  6. 판단조건을 쓸 때 \(F'(x_0)\)에 값을 넣는 실수가 흔합니다. '점 (1, 3)을 지난다'는 \(F(1) = 3\)이라는 함수값 조건이고, \(F'(1)\)은 그 점에서의 기울기입니다. 기울기 조건으로는 \(C\)가 정해지지 않습니다. 모든 부정적분이 같은 \(x\)에서 같은 기울기를 가지기 때문입니다.

확인조건이 달라지면

\(f'(x) = 2x - 4\)이고 \(f(1) = 0\)일 때, \(f(2)\)의 값은?
