직선의 방정식

본문

평면에서는 직선을 \(y = mx + n\)처럼 기울기로 나타냈다. 그런데 공간의 직선에는 '기울기' 하나로 나타낼 수 있는 방향이 없다. 비행기가 한 점에서 출발하여 일정한 방향으로 곧게 날아간다면, 그 경로의 모든 점을 어떻게 나타낼까? 출발점과 방향만 알면 충분할까?

먼저 알아야 할 것위치벡터(위치벡터), 벡터의 실수배, 벡터의 내적과 수직 조건(벡터의 내적).

3.4.1방향벡터로 나타낸 직선

점 A를 지나고 벡터 \(\vec u\)에 평행한 직선 위의 점 P에 대하여, \(\overrightarrow{AP}\)는 \(\vec u\)와 평행하므로 어떤 실수 \(t\)에 대해 \(\overrightarrow{AP} = t\vec u\)이다. 위치벡터로 쓰면 \(\vec p - \vec a = t\vec u\)이다. 이 \(\vec u\)를 직선의 방향벡터라 한다.

정리 3.4.1 직선의 벡터방정식

점 \(A(x_1, y_1, z_1)\)을 지나고 방향벡터가 \(\vec u = (a, b, c)\)인 직선은 \[\vec p = \vec a + t\vec u\] 이다. 성분으로 쓰면 \(x = x_1 + at\), \(y = y_1 + bt\), \(z = z_1 + ct\)이고, \(t\)를 없애면 \[\frac{x - x_1}{a} = \frac{y - y_1}{b} = \frac{z - z_1}{c}\ (abc \ne 0)\]

그림 1에서 \(t\)를 움직여 보자. \(t = 0\)이면 P가 A에 있고, \(t > 0\)이면 \(\vec u\) 방향으로, \(t < 0\)이면 반대 방향으로 간다. 평면이든 공간이든 같은 식을 쓰며, 성분의 개수만 다르다. 두 점 A, B를 지나는 직선은 방향벡터로 \(\overrightarrow{AB}\)를 쓴다.1

3.4.2법선벡터로 나타낸 직선과 두 직선의 각

평면 위의 직선은 방향 대신 그에 수직인 벡터로도 정할 수 있다. 점 A를 지나고 벡터 \(\vec n = (a, b)\)에 수직인 직선 위의 점 P는 \(\vec n \cdot (\vec p - \vec a) = 0\)을 만족한다. 성분으로 쓰면 \(a(x - x_1) + b(y - y_1) = 0\)이다. 이 \(\vec n\)을 법선벡터라 한다. 곧 직선 \(ax + by + c = 0\)의 법선벡터는 \((a, b)\)이다.

두 직선이 이루는 각은 방향벡터 \(\vec u_1\), \(\vec u_2\)가 이루는 각으로 구한다. 예각을 택하므로 \(\cos\theta = \dfrac{|\vec u_1 \cdot \vec u_2|}{|\vec u_1||\vec u_2|}\)이다.

3.4.3예제 하나를 끝까지

예제 3.4.2

두 점 \(A(1, 0, 2)\), \(B(3, 1, 0)\)을 지나는 직선의 방정식을 구하고, 이 직선이 \(xy\)평면과 만나는 점을 구하여라.

방향벡터는 \(\overrightarrow{AB} = (2, 1, -2)\)이므로 직선은 \(x = 1 + 2t\), \(y = t\), \(z = 2 - 2t\)이다. \(t\)를 없애면 \(\dfrac{x - 1}{2} = y = \dfrac{z - 2}{-2}\)이다.

\(xy\)평면은 \(z = 0\)이므로 \(2 - 2t = 0\), 곧 \(t = 1\)이다. 그때 \(x = 3\), \(y = 1\)이므로 만나는 점은 \((3, 1, 0)\), 곧 B 자신이다. B가 처음부터 \(z\)좌표가 0인 점이었기 때문이다. 같은 방법으로 \(yz\)평면(\(x = 0\))과는 \(t = -\dfrac{1}{2}\)에서 \(\left(0, -\dfrac{1}{2}, 3\right)\)에서 만난다.

아래 탐구 카드에서 한 점과 방향으로 직선을 그리고, 공간의 직선과 법선벡터로 정한 직선을 직접 다루어 보자.

  1. 같은 직선이라도 지나는 점이나 방향벡터를 다르게 고르면 식의 모양이 달라진다. 방향벡터를 몇 배 하거나 다른 점을 골라도, 나타내는 점들의 집합은 같다.
마무리

점 A를 지나고 방향벡터가 \(\vec u\)인 직선은 \(\vec p = \vec a + t\vec u\)이며, 성분으로 쓰거나 \(t\)를 없애 \(\frac{x - x_1}{a} = \frac{y - y_1}{b} = \frac{z - z_1}{c}\)로 나타낸다. 평면 위에서는 법선벡터로도 직선을 정할 수 있다. 그래서 처음 질문의 비행기 경로는 출발점과 방향만으로 모든 점을 \(\vec a + t\vec u\)로 가리킬 수 있다.
