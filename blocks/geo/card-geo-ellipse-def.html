빨간 연필 P를 끌어 한 바퀴 돌리세요. 끈이 늘 팽팽하므로 P는 정해진 길로만 움직입니다. 그린 정도: 0%. c는 a보다 작아야 합니다.

  1. 질문판자에 핀 두 개를 꽂고 길이 8인 끈의 양 끝을 묶은 뒤, 연필로 끈을 팽팽하게 당기며 한 바퀴 돌립니다. 어떤 곡선이 그려질까요? 두 핀 사이를 넓히면 곡선은 어떻게 바뀔까요?
  2. 복원두 점 사이의 거리 공식을 씁니다. 근호가 들어 있는 등식은 근호 하나를 한쪽에 남기고 제곱하는 일을 두 번 하면 근호를 없앨 수 있습니다.
  3. 설명평면 위의 두 점 F, F'에서 거리의 합이 일정한 점들의 모임을 타원이라 하고, F, F'을 초점이라고 합니다. 초점이 F(c, 0), F'(−c, 0)이고 거리의 합이 2a(a > c > 0)이면 PF + PF' = 2a에서 √((x − c)2 + y2) = 2a − √((x + c)2 + y2)입니다. 제곱하여 정리하면 a√((x + c)2 + y2) = a2 + cx이고, 한 번 더 제곱하면 (a2 − c2)x2 + a2y2 = a2(a2 − c2)입니다. b2 = a2 − c2(b > 0)로 놓고 양변을 a2b2으로 나누면 x2/a2 + y2/b2 = 1(a > b > 0)입니다. 타원이 축과 만나는 네 점 (±a, 0), (0, ±b)을 꼭짓점, 두 초점을 잇는 선분의 중점을 중심이라 합니다. 길이 2a인 선분을 장축, 길이 2b인 선분을 단축이라고 합니다. 초점이 y축 위의 (0, ±c)이면 x2/b2 + y2/a2 = 1이고, 장축이 y축 위에 놓입니다.
  4. 연결단축의 끝 (0, b)에서 두 초점까지의 거리는 같으므로 각각 a입니다. 그래서 그림의 점선 직각삼각형에서 b2 + c2 = a2이 보입니다. c = 0이면 두 초점이 겹쳐 b = a가 되고, 식은 원 x2 + y2 = a2이 됩니다.
  5. 적용연필을 끌어 한 바퀴 돌리는 동안 PF + PF'이 바뀌는지 보세요. 곡선이 완성되면 '곡선 보기'로 식과 비교하세요. 끈 길이는 그대로 두고 c를 0에서 4.5까지 늘려 보세요. b와 곡선의 모양은 어떻게 바뀌나요? 초점을 y축 위로 옮기면 식의 분모는 어떻게 바뀌나요?
  6. 판단표준형에서 분모가 큰 쪽이 장축 방향입니다. x2/16 + y2/25 = 1은 y2의 분모가 크므로 초점이 y축 위에 있고, c2 = 25 − 16 = 9입니다. 타원에서는 c2 = a2 − b2입니다. 더하면 안 됩니다. 또 끈의 길이 2a가 두 핀 사이 거리 2c보다 길어야 곡선이 생깁니다. 같으면 선분 FF'만 남습니다.
