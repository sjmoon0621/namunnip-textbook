P를 끌어 PF와 PH가 같아지는 곳을 찾으면 초록 점이 남습니다. H는 P에서 준선에 내린 수선의 발입니다.

  1. 질문점 F(1, 0)과 직선 x = −1이 있습니다. F까지의 거리와 이 직선까지의 거리가 같은 점을 모두 모으면 어떤 모양이 될까요? 그 점들이 만족하는 식은 무엇일까요?
  2. 복원두 점 사이의 거리는 √((x2 − x1)2 + (y2 − y1)2)입니다. 점 (x, y)에서 직선 x = k까지의 거리는 수선의 길이 |x − k|입니다. 또 원처럼 조건을 만족하는 점의 모임(자취)은 방정식으로 나타낼 수 있습니다.
  3. 설명평면 위의 한 점 F와 F를 지나지 않는 한 직선 l에서 같은 거리에 있는 점들의 모임을 포물선이라고 합니다. F를 초점, l을 준선이라고 합니다. 초점을 지나고 준선에 수직인 직선을 포물선의 축, 축과 포물선이 만나는 점을 꼭짓점이라고 합니다. 초점이 F(p, 0), 준선이 x = −p(p ≠ 0)일 때 포물선 위의 점 P(x, y)는 PF = PH를 만족합니다. 곧 √((x − p)2 + y2) = |x + p|입니다. 양변이 0 이상이므로 제곱하면 x2 − 2px + p2 + y2 = x2 + 2px + p2이고, 정리하면 y2 = 4px입니다. 꼭짓점은 원점, 축은 x축입니다. 같은 방법으로 초점이 F(0, p), 준선이 y = −p이면 x2 = 4py입니다.
  4. 연결x2 = 4py는 y = x2/(4p)이므로 중학교와 공통수학에서 본 이차함수의 그래프도 포물선입니다. 예를 들어 y = x2은 4p = 1이므로 초점이 (0, 1/4), 준선이 y = −1/4입니다. 다만 y2 = 4px는 y가 x의 함수가 아니므로 이차함수의 그래프가 아닙니다.
  5. 적용'자유롭게 끌기'로 PF = PH인 점을 다섯 개 이상 찾아보세요. 초록 점들이 어떤 모양으로 늘어서나요? 그다음 '곡선 보기'를 눌러 비교하고, '곡선 위에서만'으로 P를 곡선을 따라 움직이며 PF와 PH가 늘 같은지 확인하세요. p를 키우면 포물선의 벌어진 정도는 어떻게 바뀌나요? p를 음수로 하면 어느 쪽으로 열리나요?
  6. 판단y2 = 8x의 초점을 (8, 0)으로 읽는 실수가 많습니다. 4p = 8이므로 p = 2이고 초점은 (2, 0)입니다. 또 꼭짓점은 초점과 준선의 한가운데에 있으므로 초점에서 꼭짓점까지 거리와 꼭짓점에서 준선까지 거리는 모두 |p|입니다. 초점이 준선 위에 있으면 조건을 만족하는 점은 초점을 지나고 준선에 수직인 직선이 되므로 포물선이 아닙니다.
