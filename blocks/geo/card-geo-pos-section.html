두 점의 위치벡터로 선분을 나누는 점을 어떻게 나타낼까?

위치벡터 · 내분점, 외분점

—

\(\overrightarrow{OA} = \vec{a}\)
—
\(\overrightarrow{OB} = \vec{b}\)
—
\(\overrightarrow{OP} = \vec{p}\)
—

점 A와 B를 끌고 \(m, n\)을 바꾸어 보세요. 괄호 안 수는 점의 좌표이자 위치벡터의 성분입니다.

  1. 질문두 점 A, B를 잇는 선분을 2 : 1로 나누는 점 P는 좌표 공식으로 구할 수 있습니다. 같은 일을 벡터로 하면 평면과 공간에서 한 번에 해결할 수 있을까요?
  2. 복원공통수학에서 \(A(x_1, y_1), B(x_2, y_2)\)를 \(m : n\)으로 내분하는 점의 좌표가 \((\frac{mx_2 + nx_1}{m + n}, \frac{my_2 + ny_1}{m + n})\)임을 배웠습니다. 또 \(\overrightarrow{OA} - \overrightarrow{OB} = \overrightarrow{BA}\)였습니다.
  3. 설명기준점 O를 정하면 점 A에 벡터 \(\overrightarrow{OA}\)가 하나씩 대응합니다. 이 \(\overrightarrow{OA}\)를 점 A의 위치벡터라고 하고 \(\vec{a}\)로 씁니다. 두 점의 위치벡터를 알면 \(\overrightarrow{AB} = \overrightarrow{OB} - \overrightarrow{OA} = \vec{b} - \vec{a}\)입니다. 점 P가 선분 AB를 \(m : n(m \gt 0, n \gt 0)\)으로 내분하면 \(\overrightarrow{AP} = \frac{m}{m + n} \overrightarrow{AB}\)이므로
    \(\vec{p} = \vec{a} + \frac{m}{m + n}(\vec{b} - \vec{a}) = \frac{m\vec{b} + n\vec{a}}{m + n}\)
    입니다. 외분\((m \ne n)\)이면 \(\vec{p} = \frac{m\vec{b} - n\vec{a}}{m - n}\)입니다. 중점은 \(\frac{\vec{a} + \vec{b}}{2}\), 삼각형 ABC의 무게중심은 \(\frac{\vec{a} + \vec{b} + \vec{c}}{3}\)입니다.
  4. 연결위치벡터를 성분으로 쓰면 이 식이 그대로 내분점의 좌표 공식이 됩니다. 식에 차원이 들어 있지 않으므로 좌표공간에서도 같은 식이 성립합니다. 또 \(\vec{p} = \vec{a} + t(\vec{b} - \vec{a})\)에서 \(t\)를 모든 실수로 넓히면 직선 AB 전체가 되는데, 이것이 직선의 방정식으로 이어집니다.
  5. 적용\(m = n\)으로 두고 P가 중점인지 확인하세요. 외분으로 바꾸어 \(m \gt n\)일 때와 \(m \lt n\)일 때 P가 각각 어느 쪽 바깥에 생기는지 보세요. \(m = n\)인 외분은 왜 그려지지 않을까요?
  6. 판단위치벡터는 기준점 O에 따라 달라집니다. 그러나 \(\overrightarrow{AB} = \vec{b} - \vec{a}\)는 O를 어디에 두어도 같습니다. 외분점 식에서 \(m\vec{b} - n\vec{a}\)의 순서를 바꾸어 \(m\vec{a} - n\vec{b}\)로 쓰는 실수가 많습니다. 비의 앞쪽 \(m\)은 언제나 B 쪽 벡터 \(\vec{b}\)에 곱합니다.
