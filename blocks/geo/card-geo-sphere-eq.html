Q의 좌표를 식의 좌변에 넣은 값과 r2을 비교해 보세요. 그림을 옆으로 끌면 돌려 볼 수 있습니다.

  1. 질문원은 "중심에서 거리가 r인 점들"이라는 말을 (x − a)2 + (y − b)2 = r2으로 바꾸어 썼습니다. 공간에서 같은 말을 하면 어떤 식이 될까요?
  2. 복원좌표공간의 두 점 A(x1, y1, z1), B(x2, y2, z2) 사이의 거리는 √((x2 − x1)2 + (y2 − y1)2 + (z2 − z1)2)입니다.
  3. 설명공간에서 한 점 C로부터 일정한 거리 r에 있는 점 전체의 도형을 구라 하고, C를 구의 중심, r을 반지름이라고 합니다. 점 P(x, y, z)가 중심 C(a, b, c), 반지름 r인 구 위에 있을 조건은 CP = r, 곧 CP2 = r2이므로
    (x − a)2 + (y − b)2 + (z − c)2 = r2입니다. 이것을 구의 방정식이라고 합니다. 중심이 원점이면 x2 + y2 + z2 = r2입니다. 거꾸로 이 식을 만족하는 점은 모두 구 위에 있으므로, 식과 도형이 정확히 대응합니다.
  4. 연결식을 전개하면 x2 + y2 + z2 + Ax + By + Cz + D = 0 꼴이 됩니다. 다음 카드에서는 이 꼴에서 거꾸로 중심과 반지름을 찾습니다. 또 점 Q에 대하여 CQ와 r을 비교하면 Q가 구의 안쪽(CQ < r), 구 위(CQ = r), 바깥쪽(CQ > r) 중 어디에 있는지 알 수 있습니다.
  5. 적용Q(3, 2, 2)를 고르고 중심을 (1, 0, 1)로 둔 채 반지름을 바꾸어, Q가 구 위에 놓이는 반지름을 찾으세요. 그때 CQ는 얼마인가요? 이번에는 반지름 3인 구가 원점을 지나도록 중심을 움직여 보세요. 중심의 좌표에 어떤 조건이 있나요?
  6. 판단(x + 1)2은 x − (−1)의 제곱이므로 중심의 x좌표는 −1입니다. 부호를 그대로 읽는 실수가 흔합니다. 또 우변은 반지름이 아니라 반지름의 제곱입니다. 우변이 8이면 반지름은 8이 아니라 2√2입니다.
