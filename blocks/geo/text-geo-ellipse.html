타원

본문

종이에 핀 두 개를 꽂고 그보다 긴 끈의 양 끝을 핀에 묶은 뒤, 연필로 끈을 팽팽하게 당기며 한 바퀴 돌리면 길쭉한 원 모양이 그려진다. 정원사들이 화단을 이렇게 그렸다고 해서 '정원사의 타원'이라고도 한다. 이 곡선은 어떤 식으로 나타날까? 핀 사이를 좁히면 어떻게 될까?

먼저 알아야 할 것두 점 사이의 거리, 원의 방정식(공통수학2), 포물선의 방정식(포물선), 피타고라스 정리.

1.2.1타원의 정의와 방정식

정의 1.2.1 타원

평면 위의 서로 다른 두 점 F, F′에서의 거리의 합이 일정한 점들의 집합을 타원이라 한다. 두 점 F, F′을 타원의 초점이라 한다.

두 초점을 \(F(c, 0)\), \(F'(-c, 0)\)으로, 거리의 합을 \(2a\) (\(a > c > 0\))로 놓자. 점 \(P(x, y)\)에 대하여 \(\sqrt{(x - c)^2 + y^2} + \sqrt{(x + c)^2 + y^2} = 2a\)이다. 근호 하나를 넘기고 제곱하기를 두 번 하면 \((a^2 - c^2)x^2 + a^2y^2 = a^2(a^2 - c^2)\)이 된다. \(b^2 = a^2 - c^2\)으로 놓으면 다음을 얻는다.

정리 1.2.2 타원의 방정식

\[\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\quad (a > b > 0),\qquad c^2 = a^2 - b^2\] 초점은 \((\pm c, 0)\), 장축의 길이는 \(2a\), 단축의 길이는 \(2b\)이다.

그림 1에서 점 P를 돌려 보면 두 거리는 달라져도 합은 늘 \(2a\)이다. \(a\)를 \(b = 3\)에 가깝게 줄이면 \(c\)가 0에 다가가 두 초점이 가운데로 모이고, 타원은 원에 가까워진다. 원은 두 초점이 겹친 타원인 셈이다.1

1.2.2방정식에서 초점 찾기

\(\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1\)에서 분모가 큰 쪽이 장축 방향이다. \(x^2\)의 분모가 크면 장축이 \(x\)축 위에, \(y^2\)의 분모가 크면 \(y\)축 위에 놓인다. 초점까지의 거리 \(c\)는 큰 분모에서 작은 분모를 뺀 값의 제곱근이다. 단축의 끝점에서 초점까지의 거리가 \(a\)이므로, \(a\), \(b\), \(c\)는 빗변이 \(a\)인 직각삼각형을 이룬다.

1.2.3예제 하나를 끝까지

예제 1.2.3

타원 \(9x^2 + 25y^2 = 225\)의 초점, 장축과 단축의 길이를 구하여라. 또 지구는 태양을 한 초점으로 하는 타원 궤도를 도는데, 근일점 거리가 1.471억 km, 원일점 거리가 1.521억 km이다. 궤도 장축의 절반 \(a\)와 초점 거리 \(c\)를 구하여라.

양변을 225로 나누면 \(\dfrac{x^2}{25} + \dfrac{y^2}{9} = 1\)이다. \(a = 5\), \(b = 3\)이고 \(c = \sqrt{25 - 9} = 4\)이므로 초점은 \((\pm 4, 0)\), 장축 10, 단축 6이다.

근일점과 원일점은 장축의 양 끝이므로 두 거리의 합이 장축 \(2a\)이다. \(2a = 1.471 + 1.521 = 2.992\)억 km에서 \(a = 1.496\)억 km이다. 원일점 거리는 \(a + c\)이므로 \(c = 1.521 - 1.496 = 0.025\)억 km, 곧 250만 km이다. \(\dfrac{c}{a} \approx 0.017\)로 매우 작아, 지구 궤도는 원에 아주 가까운 타원이다.

아래 탐구 카드에서 두 핀과 끈으로 타원을 그리고, 방정식만 보고 초점과 장축을 찾아보자.

  1. \(\dfrac{c}{a}\)를 이심률이라 하며, 0에 가까울수록 원에 가깝고 1에 가까울수록 길쭉하다. 핼리 혜성 궤도의 이심률은 약 0.97로 매우 길쭉하다.
마무리

타원은 두 초점에서의 거리의 합이 일정한 점들의 집합이며, 방정식은 \(\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1\), 초점은 \((\pm c, 0)\), \(c^2 = a^2 - b^2\)이다. 분모가 큰 쪽이 장축 방향이다. 그래서 처음 질문의 두 핀은 타원의 초점이고 끈의 길이가 장축의 길이 \(2a\)이며, 핀 사이를 좁히면 타원이 원에 가까워진다.
