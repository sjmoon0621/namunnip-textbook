이차곡선의 접선

본문

원 \(x^2 + y^2 = r^2\) 위의 점 \((x_1, y_1)\)에서의 접선은 \(x_1x + y_1y = r^2\)이었다. \(x^2\)을 \(x_1x\)로, \(y^2\)을 \(y_1y\)로 바꾼 꼴이다. 타원이나 쌍곡선에서도 같은 요령이 통할까? 그리고 기울기가 정해진 접선은 곡선의 어디에 닿을까?

먼저 알아야 할 것이차방정식의 판별식(공통수학1), 원의 접선의 방정식(공통수학2), 포물선·타원·쌍곡선의 표준형(포물선, 타원, 쌍곡선).

1.4.1기울기가 주어진 접선

직선 \(y = mx + n\)이 이차곡선에 접하려면, 두 식을 연립한 이차방정식이 중근을 가져야 한다. 곧 판별식이 0이어야 한다. 타원 \(\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1\)에 \(y = mx + n\)을 대입하여 정리한 이차방정식의 판별식을 0으로 놓으면 \(n^2 = a^2m^2 + b^2\)을 얻는다.

정리 1.4.1 기울기가 \(m\)인 접선

포물선 \(y^2 = 4px\)이면 \(y = mx + \dfrac{p}{m}\) (\(m \ne 0\))
타원 \(\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1\)이면 \(y = mx \pm \sqrt{a^2m^2 + b^2}\)
쌍곡선 \(\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1\)이면 \(y = mx \pm \sqrt{a^2m^2 - b^2}\) (\(a^2m^2 > b^2\))

쌍곡선에서는 근호 안이 양수여야 하므로 \(|m| > \dfrac{b}{a}\)일 때만 접선이 있다. 점근선보다 완만한 기울기의 직선은 쌍곡선에 접할 수 없다는 뜻이다.

1.4.2곡선 위의 점에서의 접선

타원 위의 점 \((x_1, y_1)\)에서의 접선은 음함수의 미분으로 구할 수 있다. \(\dfrac{2x}{a^2} + \dfrac{2y\,y'}{b^2} = 0\)이므로 기울기는 \(-\dfrac{b^2x_1}{a^2y_1}\)이고, 접선의 방정식을 정리하면 원과 같은 꼴이 된다.

정리 1.4.2 곡선 위의 점 \((x_1, y_1)\)에서의 접선

포물선 \(y^2 = 4px\)이면 \(y_1y = 2p(x + x_1)\)
타원이면 \(\dfrac{x_1x}{a^2} + \dfrac{y_1y}{b^2} = 1\)
쌍곡선이면 \(\dfrac{x_1x}{a^2} - \dfrac{y_1y}{b^2} = 1\)

요령은 \(x^2\)을 \(x_1x\)로, \(y^2\)을 \(y_1y\)로, \(x\)를 \(\dfrac{x + x_1}{2}\)로 바꾸는 것이다. 그림 1에서 접점을 돌려 보면 접선이 늘 타원에 한 점에서만 닿는다.1

1.4.3예제 하나를 끝까지

예제 1.4.3

타원 \(\dfrac{x^2}{16} + \dfrac{y^2}{9} = 1\)에 접하고 기울기가 1인 접선의 방정식과 접점을 구하여라.

공식에서 \(a^2 = 16\), \(b^2 = 9\), \(m = 1\)이므로 \(y = x \pm \sqrt{16 + 9} = x \pm 5\)이다.

\(y = x + 5\)의 접점을 \((x_1, y_1)\)이라 하면 그 점의 접선 \(\dfrac{x_1x}{16} + \dfrac{y_1y}{9} = 1\)이 \(y = x + 5\)와 같아야 한다. 기울기 \(-\dfrac{9x_1}{16y_1} = 1\)이고 \(y\)절편 \(\dfrac{9}{y_1} = 5\)이므로 \(y_1 = \dfrac{9}{5}\), \(x_1 = -\dfrac{16}{5}\)이다. 확인하면 \(\dfrac{(16/5)^2}{16} + \dfrac{(9/5)^2}{9} = \dfrac{16}{25} + \dfrac{9}{25} = 1\)로 타원 위의 점이다. 다른 접선 \(y = x - 5\)의 접점은 원점에 대칭인 \(\left(\dfrac{16}{5}, -\dfrac{9}{5}\right)\)이다.

아래 탐구 카드에서 기울기가 정해진 접선과 곡선 위의 점에서의 접선을 직접 구하고, 이차곡선이 쓰이는 곳을 살펴보자.

  1. 타원의 접선은 접점에서 두 초점으로 그은 선분이 이루는 각을 이등분하는 직선과 수직이다. 그래서 한 초점에서 나온 빛이나 소리는 타원에 반사되어 다른 초점에 모인다.
마무리

기울기가 주어진 접선은 연립한 이차방정식의 판별식이 0이 되는 조건으로 구하며, 곡선 위의 점 \((x_1, y_1)\)에서의 접선은 \(x^2 \to x_1x\), \(y^2 \to y_1y\)로 바꾸어 얻는다. 그래서 처음 질문처럼 원에서 쓰던 요령이 타원과 쌍곡선에서도 그대로 통하며, 접선은 \(\frac{x_1x}{a^2} \pm \frac{y_1y}{b^2} = 1\)이다.
