공간에서 수직인 벡터 하나는 무엇을 정할까?

평면의 방정식 · 법선벡터

—

\(\vec{n}\cdot\overrightarrow{AP}\)
—
점 P
—
좌표축과 만나는 점
—

점 \(A(1, 1, 1)\)은 고정입니다. 법선벡터 \(\vec{n} = (a, b, c)\)를 바꾸고, P를 평면 위에서 돌려 보세요. 그림을 끌면 돌아갑니다.

  1. 질문책상 위에 연필을 수직으로 세우면 책상면의 방향이 정해집니다. 공간에서 평면을 '한 점'과 '수직인 방향 하나'로 나타낼 수 있을까요?
  2. 복원점 A를 지나고 법선벡터가 \(\vec{n}\)인 좌표평면의 직선은 \(\vec{n}\cdot(\vec{p} - \vec{a}) = 0\)이었습니다. 공간에서 내적은 \(a_1b_1 + a_2b_2 + a_3b_3\)이고, 한 벡터에 수직인 벡터는 한 평면을 이룰 만큼 많습니다.
  3. 설명점 A를 지나고 영벡터가 아닌 벡터 \(\vec{n}\)에 수직인 평면을 \(\alpha\)라 합니다. 점 P가 \(\alpha\) 위에 있을 필요충분조건은 \(\overrightarrow{AP} \perp \vec{n}\) 또는 \(P = A\), 곧
    \(\vec{n}\cdot(\vec{p} - \vec{a}) = 0\)
    입니다. \(\vec{n}\)을 평면의 법선벡터라고 합니다. \(\vec{n} = (a, b, c), A(x_1, y_1, z_1)\)이면 \(a(x - x_1) + b(y - y_1) + c(z - z_1) = 0\), 정리하면 \(ax + by + cz + d = 0\)입니다. 거꾸로 일차방정식 \(ax + by + cz + d = 0((a, b, c) \ne (0, 0, 0))\)은 언제나 평면이고, 계수 \((a, b, c)\)가 그 법선벡터입니다.
  4. 연결좌표평면에서 직선이던 식이 좌표공간에서는 평면이 됩니다. 식이 같아도 사는 공간의 차원이 다르면 나타내는 도형이 달라집니다. 두 평면이 이루는 각은 두 법선벡터가 이루는 각으로 구하고, 직선과 평면이 평행한지는 방향벡터와 법선벡터의 내적이 0인지로 판단합니다.
  5. 적용P를 한 바퀴 돌리는 동안 \(\vec{n}\cdot\overrightarrow{AP}\)가 늘 0인지 확인하세요. \(a = 0\)으로 두면 평면은 어느 축과 평행해지나요? \(a = b = 0\)이면 평면은 어떻게 놓이고 식은 무엇인가요? \(\vec{n}\)을 \((2, 2, 4)\)처럼 2배로 바꿀 수 있다면 평면은 달라질까요?
  6. 판단평면 위의 점을 모두 담으려면 '한 점과 법선벡터' 두 가지가 필요합니다. 법선벡터만으로는 서로 평행한 평면들 가운데 어느 것인지 정해지지 않습니다. 또 \(ax + by + cz + d = 0\)에서 \((a, b, c)\)는 평면 위의 방향이 아니라 평면에 수직인 방향입니다.
