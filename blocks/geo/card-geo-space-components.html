세 성분을 바꾸고, 그림을 끌어 여러 방향에서 보세요. 초록 점선은 바닥(xy평면)의 대각선입니다.

  1. 질문방 한쪽 구석에서 맞은편 천장 구석까지 줄을 팽팽하게 걸면 줄의 방향과 길이는 무엇으로 정해질까요?
  2. 복원평면벡터는 성분 두 개로 정해지고 크기는 √(a12 + a22)입니다. 좌표공간의 점은 (x, y, z)로 나타내고, 두 점 사이의 거리는 √((Δx)2 + (Δy)2 + (Δz)2)입니다.
  3. 설명공간벡터 a를 시점이 원점이 되도록 옮겼을 때 종점이 (a1, a2, a3)이면 a = (a1, a2, a3)로 씁니다. 세 좌표축 방향의 단위벡터 e1, e2, e3을 쓰면 a = a1e1 + a2e2 + a3e3입니다. 크기는 피타고라스 정리를 두 번 써서 구합니다. 바닥의 대각선 길이가 √(a12 + a22)이고, 이것과 높이 |a3|가 직각을 이루므로 |a| = √(a12 + a22 + a32)입니다. 덧셈, 뺄셈, 실수배와 AB = (x2 − x1, y2 − y1, z2 − z1)도 평면과 똑같이 성분끼리 계산합니다.
  4. 연결이 성분 표현 덕분에 공간에서도 내적, 직선과 평면의 방정식을 좌표 계산으로 다룰 수 있습니다. 점의 좌표와 위치벡터의 성분이 같다는 사실은 평면과 공간 모두에서 쓰입니다.
  5. 적용(3, 2, 2)의 크기를 바닥 대각선과 높이로 나누어 계산해 보세요. 성분 하나를 0으로 만들면 화살표는 어디에 놓이나요? 크기가 정수가 되는 성분 조합을 하나 더 찾아보세요. 예를 들어 (1, 2, 2)는 어떨까요?
  6. 판단그림은 공간을 평면에 옮긴 것이라 화살표의 화면 길이는 실제 크기와 다릅니다. 같은 벡터도 돌리면 화면에서 길어지거나 짧아집니다. 크기는 반드시 성분으로 계산하세요.
