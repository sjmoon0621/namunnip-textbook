두 이동을 하나로 합치면 어떤 화살표가 될까?

벡터의 연산 · 덧셈, 뺄셈
\(|\vec{a}|\)
—
\(|\vec{b}|\)
—
|a + b|
—
\(|\vec{a}| + |\vec{b}|\)
—

화살표 끝의 큰 점을 끌어 보세요. 점은 격자점에 붙습니다. 한 칸의 길이는 1입니다.

  1. 질문동쪽으로 4칸, 북쪽으로 1칸 간 다음 다시 동쪽으로 1칸, 북쪽으로 3칸 갔습니다. 처음부터 한 번에 갔다면 어떤 화살표 하나로 나타낼 수 있을까요?
  2. 복원벡터는 크기와 방향만으로 정해지므로 평행이동해도 같은 벡터입니다. \(\overrightarrow{AB}\)는 A에서 B로 가는 이동이고, \(-\vec{a}\)는 \(\vec{a}\)와 크기가 같고 방향이 반대인 벡터입니다.
  3. 설명\(\vec{a}\)의 종점에 \(\vec{b}\)의 시점을 이어 붙였을 때 \(\vec{a}\)의 시점에서 \(\vec{b}\)의 종점으로 가는 벡터를 \(\vec{a} + \vec{b}\)라고 합니다. 식으로는 \(\overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}\)입니다(삼각형법). 두 벡터의 시점을 맞추면 두 벡터가 만드는 평행사변형의 대각선이 \(\vec{a} + \vec{b}\)입니다(평행사변형법). 이 그림에서 \(\vec{a} + \vec{b} = \vec{b} + \vec{a}\)(교환법칙)가 바로 보입니다. 뺄셈은 \(\vec{a} - \vec{b} = \vec{a} + (-\vec{b})\)로 정합니다. 시점을 맞춘 두 화살표에서 \(\vec{a} - \vec{b}\)는 \(\vec{b}\)의 종점에서 \(\vec{a}\)의 종점으로 가는 벡터입니다. 그래서 \(\overrightarrow{OA} - \overrightarrow{OB} = \overrightarrow{BA}\)입니다.
  4. 연결물리에서 두 힘의 합력, 이동한 변위의 합이 이 덧셈입니다. 뺄셈 \(\overrightarrow{OB} - \overrightarrow{OA} = \overrightarrow{AB}\)는 다음 절에서 위치벡터로 두 점 사이의 벡터를 구할 때 그대로 쓰입니다.
  5. 적용\(\vec{a}\)와 \(\vec{b}\)를 같은 방향으로 놓아 \(|\vec{a} + \vec{b}| = |\vec{a}| + |\vec{b}|\)가 되게 해 보세요. 이때 말고 두 값이 같아지는 경우가 있나요? 평행사변형 보기에서 \(\vec{a}\)와 \(\vec{b}\)를 수직으로 놓고, 뺄셈 보기로 바꾸어 \(|\vec{a} + \vec{b}|\)와 \(|\vec{a} - \vec{b}|\)를 비교해 보세요.
  6. 판단벡터의 덧셈은 크기의 덧셈이 아닙니다. 삼각형의 두 변의 길이의 합은 나머지 한 변보다 크므로 \(|\vec{a} + \vec{b}| \le |\vec{a}| + |\vec{b}|\)이고, 등호는 두 벡터의 방향이 같을 때(또는 하나가 \(\vec{0}\)일 때)만 성립합니다. 또 \(\vec{a} - \vec{b}\)의 방향을 거꾸로 그리는 실수가 많습니다. \(\vec{a} - \vec{b}\)는 '\(\vec{b}\)에 더하면 \(\vec{a}\)가 되는 벡터'이므로 \(\vec{b}\)의 종점에서 출발합니다.
