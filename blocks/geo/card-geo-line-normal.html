방향 대신 수직인 벡터로 직선을 정할 수 있을까?

직선의 방정식 · 법선벡터

—

\(\vec{n}\cdot(\vec{q} - \vec{a})\)
—
점 Q의 위치
—
Q에서 직선까지 거리
—

점 A, \(\vec{n}\)의 끝점, 그리고 시험점 Q를 끌어 보세요. Q가 직선 위에 오면 내적이 0이 됩니다.

  1. 질문직선 위의 점 A에서 직선 위의 다른 점 P로 가는 벡터는 모두 같은 방향(또는 반대 방향)입니다. 그렇다면 이 벡터들과 모두 수직인 벡터 하나로 직선을 정할 수 있지 않을까요?
  2. 복원영벡터가 아닌 두 벡터가 수직일 필요충분조건은 내적이 0인 것입니다. \(\overrightarrow{AP} = \vec{p} - \vec{a}\)이고, 내적은 성분으로 \(a_1b_1 + a_2b_2\)입니다.
  3. 설명점 A를 지나고 영벡터가 아닌 벡터 \(\vec{n}\)에 수직인 직선 위의 점 P는 \(\overrightarrow{AP} \perp \vec{n}\) 또는 \(P = A\)이므로
    \(\vec{n}\cdot(\vec{p} - \vec{a}) = 0\)
    을 만족합니다. 이런 \(\vec{n}\)을 직선의 법선벡터라고 합니다. \(\vec{n} = (a, b), A(x_1, y_1)\)로 쓰면 \(a(x - x_1) + b(y - y_1) = 0\), 곧 \(ax + by + c = 0\) 꼴입니다. 거꾸로 직선 \(ax + by + c = 0\)을 보면 계수 \((a, b)\)가 바로 법선벡터입니다. 방향벡터는 법선벡터에 수직이므로 \((b, -a)\)로 잡을 수 있습니다.
  4. 연결두 직선이 이루는 각은 두 방향벡터(또는 두 법선벡터)가 이루는 각으로 구합니다. 두 직선이 수직이면 법선벡터끼리 내적이 0입니다. 다음 절에서는 같은 식 \(\vec{n}\cdot(\vec{p} - \vec{a}) = 0\)이 좌표공간에서는 직선이 아니라 평면을 나타냅니다.
  5. 적용Q를 직선의 한쪽에서 반대쪽으로 끌어 보세요. 내적의 부호는 어떻게 바뀌나요? \(\vec{n}\)을 2배로 늘리면 직선은 바뀌나요, 식은 어떻게 바뀌나요? A를 직선을 따라 옮기면 식의 상수항은 그대로인가요?
  6. 판단\(ax + by + c = 0\)에서 \((a, b)\)를 방향벡터로 착각하는 실수가 많습니다. \((a, b)\)는 직선에 수직입니다. 또 이 그림의 내적 값 자체는 거리가 아닙니다. Q에서 직선까지의 거리는 \(\frac{|\vec{n}\cdot(\vec{q} - \vec{a})|}{|\vec{n}|}\)입니다.
