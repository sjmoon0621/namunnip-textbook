평면과 구의 방정식

본문

책상 위에 연필을 수직으로 세우면, 그 연필에 수직인 방향은 책상 면 위의 모든 방향이다. 평면 위의 직선은 법선벡터 하나와 한 점으로 정해졌다. 공간에서는 수직인 벡터 하나와 한 점이 직선이 아니라 평면을 정하지 않을까? 그렇다면 평면도 식 하나로 쓸 수 있을 것이다.

먼저 알아야 할 것벡터의 내적과 수직 조건(벡터의 내적), 직선의 벡터방정식(직선의 방정식), 구의 방정식(구의 방정식).

3.5.1평면의 방정식

점 \(A(x_1, y_1, z_1)\)을 지나고 영벡터가 아닌 벡터 \(\vec n = (a, b, c)\)에 수직인 평면을 생각하자. 평면 위의 점 P에 대하여 \(\overrightarrow{AP}\)는 평면 위에 있으므로 \(\vec n\)과 수직이다. 그러므로 \(\vec n \cdot (\vec p - \vec a) = 0\)이다. 이 \(\vec n\)을 평면의 법선벡터라 한다.

정리 3.5.1 평면의 방정식

점 \((x_1, y_1, z_1)\)을 지나고 법선벡터가 \((a, b, c)\)인 평면은 \[a(x - x_1) + b(y - y_1) + c(z - z_1) = 0\] 이다. 전개하면 \(ax + by + cz + d = 0\) 꼴이며, 이때 법선벡터는 \((a, b, c)\)이다.

평면 위의 직선에서 법선벡터 하나가 직선을 정했던 것과 꼭 닮았다. 공간에서는 한 벡터에 수직인 방향이 한 평면 전체이므로, 법선벡터와 한 점이 평면을 정한다. 그림 1에서 \(d\)를 바꾸어 보면 법선벡터는 그대로이고 평면만 나란히 옮겨 간다.1

3.5.2점과 평면 사이의 거리, 벡터로 쓴 구

점 \(P(x_0, y_0, z_0)\)에서 평면 \(ax + by + cz + d = 0\)까지의 거리는 평면 위의 한 점에서 P까지의 벡터를 법선 방향으로 정사영한 길이이다. 계산하면 \(\dfrac{|ax_0 + by_0 + cz_0 + d|}{\sqrt{a^2 + b^2 + c^2}}\)로, 좌표평면에서 점과 직선 사이의 거리 공식에 \(z\)항을 더한 꼴이다.

구도 벡터로 간단히 쓸 수 있다. 중심의 위치벡터가 \(\vec c\), 반지름이 \(r\)인 구 위의 점 P는 \(|\vec p - \vec c| = r\)을 만족한다. 양변을 제곱하여 \((\vec p - \vec c) \cdot (\vec p - \vec c) = r^2\)을 성분으로 풀면 앞에서 배운 구의 방정식이 된다.

3.5.3예제 하나를 끝까지

예제 3.5.2

세 점 \(A(1, 0, 0)\), \(B(0, 2, 0)\), \(C(0, 0, 3)\)을 지나는 평면의 방정식을 구하고, 원점에서 이 평면까지의 거리를 구하여라.

평면을 \(ax + by + cz = d\)로 놓고 세 점을 대입하면 \(a = d\), \(2b = d\), \(3c = d\)이다. \(d = 6\)으로 잡으면 \(a = 6\), \(b = 3\), \(c = 2\)이므로 평면은 \(6x + 3y + 2z = 6\)이다. 양변을 6으로 나누면 \(x + \dfrac{y}{2} + \dfrac{z}{3} = 1\)로, 세 축과 만나는 점이 바로 보인다.

원점에서의 거리는 \(\dfrac{|0 + 0 + 0 - 6|}{\sqrt{36 + 9 + 4}} = \dfrac{6}{7}\)이다. 법선벡터 \((6, 3, 2)\)의 크기가 \(\sqrt{49} = 7\)로 깔끔하게 나온다. 이 거리보다 반지름이 큰, 원점을 중심으로 하는 구는 이 평면과 원에서 만난다.

마무리

점 A를 지나고 법선벡터 \(\vec n = (a, b, c)\)에 수직인 평면은 \(\vec n \cdot (\vec p - \vec a) = 0\), 곧 \(ax + by + cz + d = 0\)이며, 점과 평면 사이의 거리는 법선 방향의 정사영 길이로 구한다. 구는 \(|\vec p - \vec c| = r\)로 쓸 수 있다. 그래서 처음 질문의 수직인 벡터 하나와 한 점은 공간에서 하나의 평면을 정한다.
