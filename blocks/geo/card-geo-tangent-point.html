빨간 점 P와 회색 점 Q는 곡선을 따라 끌 수 있습니다. 노란 실선이 공식으로 그린 접선입니다.

  1. 질문타원 \(\frac{x^2}{9} + \frac{y^2}{4} = 1\) 위의 점 \(P(x_1, y_1)\)에서 그은 접선의 방정식을 매번 판별식을 풀지 않고 바로 쓸 수 있을까요?
  2. 복원원 \(x^2 + y^2 = r^2\) 위의 점 \((x_1, y_1)\)에서의 접선은 \(x_1x + y_1y = r^2\)이었습니다. 또 기울기가 \(m\)인 접선은 대입한 이차방정식의 판별식이 0이 되는 조건으로 찾습니다.
  3. 설명\(P(x_1, y_1)\)를 지나고 기울기가 \(m\)인 직선을 타원에 대입해 \(D = 0\)을 풀면 \(m = -\frac{b^2x_1}{a^2y_1}\)이 나옵니다\((y_1 \ne 0)\). 이를 정리하고 \(\frac{x_1^2}{a^2} + \frac{y_1^2}{b^2} = 1\)을 쓰면 접선은 \(\frac{x_1x}{a^2} + \frac{y_1y}{b^2} = 1\)입니다. 같은 방법으로 쌍곡선 \(\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1\)은 \(\frac{x_1x}{a^2} - \frac{y_1y}{b^2} = 1\), 포물선 \(y^2 = 4px\)는 \(y_1y = 2p(x + x_1)\)입니다. 규칙은 원과 같습니다. 곡선의 식에서 \(x^2\)을 \(x_1x\)로, \(y^2\)을 \(y_1y\)로, 일차항 \(x\)를 \(\frac{x + x_1}{2}\)로 바꿉니다. \(y_1 = 0\)인 꼭짓점에서도 공식이 세로 접선 \(x = x_1\)을 바르게 줍니다.
  4. 연결접선은 곡선 위의 다른 점 Q를 P에 한없이 가깝게 할 때 할선 PQ가 다가가는 직선입니다. 이 생각은 미분계수로 이어집니다. 미적분Ⅱ에서 배우는 음함수의 미분법으로 \(\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\)의 양변을 \(x\)에 대해 미분하면 \(\frac{2x}{a^2} + \frac{2yy'}{b^2} = 0\)입니다. 그러면 \(y' = -\frac{b^2x}{a^2y}\)가 되어 판별식으로 얻은 기울기와 같습니다.
  5. 적용'Q를 P 쪽으로 반만큼'을 여러 번 누르며 할선 PQ의 기울기가 접선의 기울기에 다가가는지 보세요. P를 타원의 꼭짓점 \((3, 0)\)으로 끌면 접선은 어떻게 되나요? 쌍곡선과 포물선으로 바꾸어 같은 일을 해 보고, 화면에 나온 식이 규칙대로 바뀌었는지 확인하세요.
  6. 판단이 공식은 점 P가 곡선 위에 있을 때만 접선입니다. 곡선 밖의 점 \((x_1, y_1)\)을 넣으면 식은 직선이 되지만 접선이 아닙니다. 곡선 밖의 점에서 그은 접선은 접점을 \((x_1, y_1)\)로 놓고 접선이 그 점을 지난다는 조건과 접점이 곡선 위에 있다는 조건을 연립하거나, 기울기를 \(m\)으로 놓고 판별식을 써서 구합니다. 또 이 공식은 표준형에서 유도한 것이므로 평행이동한 곡선에 그대로 쓰면 틀립니다.
