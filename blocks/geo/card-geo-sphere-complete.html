전개된 식에서 구의 중심과 반지름을 되찾을 수 있을까?

구의 방정식의 일반형 · 완전제곱식

—

중심
—
r2 = (A2 + B2 + C2)/4 − D
—
나타내는 도형
—

식은 x2 + y2 + z2 + Ax + By + Cz + D = 0입니다. 그림을 옆으로 끌면 돌려 볼 수 있습니다.

  1. 질문x2 + y2 + z2 − 2x + 4y − 6z + 5 = 0은 구일까요? 구라면 중심과 반지름은 무엇일까요? 상수항이 커지면 무슨 일이 생길까요?
  2. 복원x2 + px = (x + p/2)2 − p2/4처럼 이차식은 완전제곱식과 상수로 바꿀 수 있습니다. 원의 방정식 x2 + y2 + Ax + By + C = 0에서도 같은 방법으로 중심과 반지름을 찾았습니다.
  3. 설명x2 + y2 + z2 + Ax + By + Cz + D = 0을 문자별로 묶어 완전제곱식을 만들면
    (x + A/2)2 + (y + B/2)2 + (z + C/2)2 = (A2 + B2 + C2 − 4D)/4입니다. 우변이 양수이면 이 식은 중심 (−A/2, −B/2, −C/2), 반지름 √(A2 + B2 + C2 − 4D)/2인 구입니다. 따라서 이 꼴의 식이 구를 나타낼 조건은 A2 + B2 + C2 − 4D > 0입니다.
  4. 연결x2, y2, z2의 계수가 모두 같고 xy, yz, zx 항이 없어야 이 방법을 씁니다. 계수가 모두 2이면 먼저 양변을 2로 나눕니다. 네 점을 지나는 구를 구할 때는 이 일반형에 네 점을 넣어 A, B, C, D에 대한 연립방정식을 풉니다.
  5. 적용첫 번째 식을 고르고 "다음 단계"를 눌러 완전제곱식을 만드는 과정을 따라가세요. 그다음 D를 키우며 구의 크기가 어떻게 변하는지 보세요. r2이 0이 되는 D는 얼마이고, 그때 그림에는 무엇이 남나요? D가 그보다 크면 어떻게 되나요?
  6. 판단모든 이차식이 구를 나타내지는 않습니다. 우변이 0이면 중심 한 점만 식을 만족하고, 우변이 음수이면 제곱의 합이 음수가 될 수 없으므로 식을 만족하는 점이 없습니다. 반지름을 구할 때 A2 + B2 + C2을 4로 나누는 것을 잊으면 조건이 크게 틀어집니다.
