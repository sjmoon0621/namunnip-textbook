솔레노이드 속 자기장 μ₀nI는 언제 믿을 수 있을까?

비오–사바르 법칙 · 암페어 법칙 · 원형 고리와 솔레노이드
중심의 B (비오–사바르)
—
암페어 법칙 μ₀NI/ℓ
—
중심 B ÷ μ₀nI
—

μ₀ = 4π×10⁻⁷ T·m/A. 화살표는 각 고리를 36조각으로 나눠 조각마다 비오–사바르 법칙을 더해 그렸고, 축 위 곡선은 원형 고리 하나의 정확한 식을 고리마다 더했습니다. 공기 속(철심 없음)입니다.

  1. 질문교과서는 긴 솔레노이드 속 자기장을 B = μ₀nI라고 씁니다. 그런데 실제 코일은 길이가 유한하고, 감은 사이에 틈도 있습니다. 이 식은 어떻게 얻었고, 어떤 코일에서 맞을까요?
  2. 복원직선 전류 둘레의 자기장은 동심원 모양이고, 방향은 오른손 법칙으로 정합니다. 여러 전류가 만드는 자기장은 벡터로 더합니다(중첩).
  3. 설명비오–사바르 법칙은 전류 조각 I dl이 거리 r인 곳에 만드는 자기장 dB = (μ₀/4π)·I dl × r̂/r²입니다. 원형 고리의 중심에서는 모든 조각이 같은 방향의 dB = μ₀I dl/4πR²를 주므로, 둘레 2πR를 따라 더하면 B = μ₀I/2R입니다. 축 위 거리 z에서는 축에 수직한 성분이 상쇄되고 B = μ₀IR²/2(R² + z²)3/2만 남습니다. 코일은 이런 고리를 늘어놓은 것이므로 그래프의 초록 곡선은 이 식을 더한 결과입니다.
  4. 연결대칭성이 있으면 암페어 법칙 ∮B·dl = μ₀I안이 더 빠릅니다. 무한히 긴 직선 도선을 둘러싼 원에서는 B·2πr = μ₀I로 B = μ₀I/2πr입니다. 무한히 긴 솔레노이드에서 길이 ℓ인 직사각형 고리의 한 변을 안에, 맞은편 변을 바깥에 두면, 바깥 B ≈ 0이고 옆변은 B와 수직이라 Bℓ = μ₀(nℓ)I, 곧 B = μ₀nI입니다. 이 결과는 ‘바깥 자기장 0, 안은 균일’이라는 대칭 가정에 기댑니다.
  5. 적용세 예시를 차례로 누르세요. 원형 고리 하나에서 중심 B가 μ₀I/2R과 같은지 확인하세요. 짧고 굵은 코일에서 중심 B는 μ₀nI의 몇 %인가요? 길이를 늘리거나 반지름을 줄여 이 비율이 95 %를 넘는 조건(ℓ/R)을 찾아보세요. 긴 솔레노이드의 양 끝(z = ±ℓ/2)에서 B는 중심값의 얼마인가요?
  6. 판단암페어 법칙은 언제나 성립하지만, B를 적분 밖으로 꺼낼 수 있을 만큼 대칭이 있을 때만 B를 직접 구하는 도구가 됩니다. 짧은 코일이나 고리 하나에는 μ₀nI를 쓸 수 없고, 긴 솔레노이드도 끝에서는 중심의 절반쯤으로 줄어듭니다. 또 이 식은 정상 전류(시간에 따라 변하지 않는 전류)에서 성립하며, 전류가 변하면 맥스웰이 보탠 변위 전류 항이 필요합니다.
