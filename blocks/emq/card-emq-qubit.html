측정하기 전의 양자 상태는 0일까, 1일까?

중첩과 측정 · 큐비트
예측 확률
—
측정 결과 (횟수)
—
마지막 측정 직후 상태
—

편광된 광자처럼 상태를 평면의 화살표로 나타냈습니다: |ψ⟩ = cos(θ/2)|0⟩ + sin(θ/2)|1⟩. 측정 결과가 나올 확률은 해당 기준 방향과 이루는 각의 cos²입니다.

  1. 질문동전은 던지기 전에도 앞이나 뒤 중 하나로 정해져 있고, 우리가 모를 뿐입니다. 양자 상태도 측정 전에 이미 0 또는 1로 정해져 있는데 우리가 모르는 것일까요?
  2. 복원전자 하나는 두 슬릿의 경로가 겹친 확률 파동처럼 행동했고, 어느 슬릿을 지났는지 측정하면 간섭이 사라졌습니다(앞 절). 편광판을 지난 광자가 다음 편광판을 지날 확률은 cos²θ입니다.
  3. 설명양자 상태는 두 상태 |0⟩과 |1⟩이 겹친 중첩 상태일 수 있습니다. 측정하면 결과는 0 또는 1 하나로만 나오며, 각각의 확률은 중첩의 계수를 제곱한 값입니다. 측정 직후 상태는 나온 결과의 상태로 바뀌므로, 곧바로 같은 측정을 다시 하면 같은 결과가 나옵니다. 측정 전 상태가 0이나 1로 이미 정해진 것이 아니라는 점은 다른 기준(대각선)으로 측정했을 때 간섭처럼 드러납니다.
  4. 연결0과 1의 중첩 상태를 가진 정보 단위가 큐비트입니다. 큐비트 n개는 2ⁿ개 상태의 중첩을 다룰 수 있어, 특정 문제(소인수분해, 분자 시뮬레이션 등)에서 기존 컴퓨터보다 훨씬 빠른 양자 컴퓨터를 만들 수 있습니다. 측정이 상태를 바꾼다는 성질은 도청을 반드시 흔적으로 남기는 양자 암호 통신에 쓰입니다(읽기).
  5. 적용θ = 60°로 준비해 100번 측정하고 비율을 예측 확률과 비교하세요. 한 번 측정한 뒤 같은 기준으로 다시 측정하면 어떻게 되나요? θ = 90°인 상태를 0/1 기준과 대각선 기준으로 각각 측정해 보세요. 어느 쪽 결과가 확실한가요?
  6. 판단“중첩은 0과 1을 동시에 가진다”는 설명은 오해를 부르기 쉽습니다. 측정 결과는 언제나 하나이고, 중첩은 여러 가능성이 확률 진폭으로 겹쳐 간섭할 수 있는 상태라는 뜻입니다. 또 양자 컴퓨터가 모든 계산을 빠르게 하는 것은 아니며, 간섭을 잘 이용하는 알고리즘이 있는 문제에서만 이점이 있습니다.

확인조건이 달라지면

θ = 90°로 준비한 큐비트를 0/1 기준으로 측정했더니 1이 나왔습니다. 곧바로 같은 기준으로 다시 측정하면?
