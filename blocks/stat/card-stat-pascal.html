이항계수를 삼각형으로 쌓으면 어떤 규칙이 보일까?

파스칼의 삼각형 · 이항계수의 성질

—

삼각형의 수를 눌러 고르세요. n행의 왼쪽에서 r번째(0부터 셈) 수가 nCr입니다.

  1. 질문(a + b)0, (a + b)1, (a + b)2, …의 계수를 한 줄씩 쌓으면, 전개하지 않고도 다음 줄을 쓸 수 있을까요?
  2. 복원(a + b)n의 전개식에서 an−rbr의 계수는 이항계수 nCr입니다. 또 nCr = nCn−r입니다.
  3. 설명이항계수를 n = 0부터 차례로 쌓은 것을 파스칼의 삼각형이라고 합니다. 각 행의 양 끝은 1이고, 나머지 수는 바로 위 왼쪽과 오른쪽 두 수의 합입니다. 이것이 nCr = n−1Cr−1 + n−1Cr입니다. (a + b)n = (a + b)n−1(a + b)에서 an−rbr는 앞 줄의 an−rbr−1에 b를 곱하거나 an−1−rbr에 a를 곱해서만 생기기 때문입니다. 각 행이 좌우 대칭인 것은 nCr = nCn−r를 뜻합니다.
  4. 연결이항정리에 a = b = 1을 넣으면 nC0 + nC1 + ⋯ + nCn = 2n이고, a = 1, b = −1을 넣으면 번갈아 더하고 뺀 값이 0입니다(n ≥ 1). 두 식을 더하고 2로 나누면 짝수 번째 수들의 합이 2n−1입니다. 대각선을 따라 더한 합은 그 끝에서 한 칸 아래 오른쪽(또는 왼쪽)의 수가 됩니다. 예를 들어 2C2 + 3C2 + 4C2 = 5C3입니다. 위의 두 수 규칙을 맨 아래 칸부터 거듭 쓰면 이 식이 나옵니다.
  5. 적용'위의 두 수'에서 여러 수를 눌러 덧셈 규칙을 확인하세요. '행의 합'으로 바꾸어 N을 늘리면서 합이 어떻게 변하는지, 번갈아 더한 값은 얼마인지 보세요. '대각선 합'에서는 아래쪽 수를 눌러 위로 이어지는 대각선의 합이 어느 수와 같은지 찾으세요. '홀수만 칠하기'를 켜고 N을 12까지 늘리면 어떤 무늬가 보이나요?
  6. 판단행 번호와 자리 번호는 0부터 셉니다. 맨 위 1은 0행이고, 각 행의 첫 1은 nC0입니다. 1부터 세면 계수가 한 칸씩 어긋납니다. 또 홀수 무늬는 N이 작을 때 보이는 모양에서 짐작한 것입니다. 그림에서 짐작한 규칙은 덧셈 규칙이나 이항정리로 따져 보아야 성질이라고 말할 수 있습니다.
