P(X ≤ k)

정규분포 근사
—

막대는 B(n, p)의 확률, 곡선은 평균과 표준편차가 같은 정규분포 N(np, npq)입니다. 진한 막대는 X ≤ k인 부분이고, k는 np + √npq를 넘지 않는 가장 큰 정수입니다. P(X ≤ k)는 이항분포로 계산한 정확한 값, 근사값은 P(Z ≤ (k − np)/√npq)입니다.

  1. 질문동전을 100번 던져 앞면이 60번 이하로 나올 확률을 이항분포로 구하려면 100Ck(1/2)100을 61개나 더해야 합니다. 더 간단한 방법은 없을까요?
  2. 복원B(n, p)의 평균은 np, 표준편차는 √npq입니다(q = 1 − p). 정규분포 N(m, σ2)의 확률은 Z = (X − m)/σ로 표준화해 표준정규분포표에서 읽습니다.
  3. 설명n이 커지면 이항분포의 막대그래프는 평균 np를 중심으로 좌우가 거의 대칭인 종 모양이 됩니다. 그래서 X가 B(n, p)를 따르고 n이 충분히 크면, X는 근사적으로 정규분포 N(np, npq)를 따른다고 봅니다. 확률은 Z = (X − np)/√npq로 표준화해 구합니다. 앞의 동전은 m = 50, σ = 5이므로 P(X ≤ 60) ≈ P(Z ≤ 2) = 0.9772입니다.
  4. 연결이 근사 덕분에 표본비율처럼 '성공 횟수를 센 값'도 정규분포로 다룰 수 있습니다. 모비율을 추정하고 여론조사의 오차 범위를 계산하는 바탕이 이것입니다.
  5. 적용p = 0.2로 두고 n을 5에서 100까지 천천히 키워 보세요. n이 작을 때 막대는 어느 쪽으로 치우쳐 있나요? P(X ≤ k)와 '정규분포 근사'의 차이는 n이 커질수록 어떻게 되나요? p를 0.5로 바꾸면 더 작은 n에서도 곡선이 잘 맞나요?
  6. 판단근사는 n이 충분히 클 때만 씁니다. 흔히 np ≥ 5, nq ≥ 5를 기준으로 삼으며, p가 0이나 1에 가까울수록 더 큰 n이 필요합니다. 또 이항분포는 정수에만 확률이 있지만 정규분포는 연속이므로, n이 작으면 근사값이 정확한 값과 꽤 다릅니다.
