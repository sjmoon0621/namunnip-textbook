X는 주사위 한 개의 눈으로 E(X) = 3.5, V(X) = 35/12, σ(X) ≈ 1.708입니다. E(Y)와 σ(Y)는 Y의 여섯 값으로 직접 계산한 값입니다.

  1. 질문시험 점수를 모두 2배로 하고 5점을 빼서 환산하면 평균은 쉽게 짐작됩니다. 점수가 흩어진 정도, 곧 표준편차도 2배에서 5를 뺀 값이 될까요?
  2. 복원E(X) = ∑xipi, V(X) = ∑(xi − m)2pi, σ(X) = √V(X)입니다. 확률의 합 ∑pi는 1입니다.
  3. 설명Y = aX + b는 X의 값마다 axi + b를 같은 확률 pi로 갖습니다. 그래서 E(Y) = ∑(axi + b)pi = a∑xipi + b∑pi = aE(X) + b입니다. 편차는 (axi + b) − (am + b) = a(xi − m)로 b가 사라지므로 V(aX + b) = a2V(X), σ(aX + b) = |a|σ(X)입니다. 모든 값을 똑같이 옮기는 b는 퍼짐을 바꾸지 못하고, 간격을 늘리는 a만 퍼짐을 바꿉니다.
  4. 연결섭씨온도를 화씨온도로 바꾸는 F = 1.8C + 32, 원을 달러로 바꾸는 환산도 모두 aX + b 꼴입니다. 뒤에서 정규분포를 표준화할 때 쓰는 Z = (X − m)/σ도 a = 1/σ, b = −m/σ인 경우로, 평균 0, 표준편차 1이 되는 까닭이 이 성질입니다.
  5. 적용a를 1에 두고 b만 움직여 보세요. 분포는 어떻게 움직이고, σ(Y)는 변하나요? a를 −2로 하면 분포가 어떻게 놓이고, σ(Y)는 음수가 되나요? a = 0이면 무엇이 보이나요?
  6. 판단"σ(2X − 5) = 2σ(X) − 5"나 "V(2X) = 2V(X)"는 흔한 실수입니다. 더하는 수는 퍼짐과 무관하고, 분산은 제곱 단위라서 a2배가 됩니다. 표준편차는 0 이상이므로 a가 음수여도 |a|배입니다.
