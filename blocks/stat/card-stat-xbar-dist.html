사과 한 개의 무게(g)가 정규분포 N(300, 202)을 따른다고 가정한 모식입니다. 점선은 모집단의 분포, 막대는 지금까지 뽑은 x̄들의 히스토그램(넓이 합 1), 초록 곡선은 N(300, 202/n)입니다. 주황 삼각형은 마지막 x̄입니다.

  1. 질문사과 4개의 평균 무게와 64개의 평균 무게 중 어느 쪽이 과수원 전체의 평균 무게에 더 가까울까요? '더 가깝다'를 수로 나타낼 수 있을까요?
  2. 복원확률변수의 평균, 분산, 표준편차를 구할 수 있고, E(aX + b) = aE(X) + b, V(aX + b) = a2V(X)입니다. 정규분포의 확률은 표준화해서 구합니다.
  3. 설명모집단의 평균, 분산, 표준편차를 각각 모평균 m, 모분산 σ2, 모표준편차 σ라고 합니다. 모집단에서 임의추출한 크기가 n인 표본 X1, X2, …, Xn에 대하여 X̄ = (X1 + X2 + ⋯ + Xn)/n을 표본평균, S2 = {(X1 − X̄)2 + ⋯ + (Xn − X̄)2}/(n − 1)을 표본분산, S를 표본표준편차라고 합니다. X̄는 표본마다 값이 다른 확률변수이며 E(X̄) = m, V(X̄) = σ2/n, σ(X̄) = σ/√n입니다. 특히 모집단이 정규분포 N(m, σ2)을 따르면 X̄는 정규분포 N(m, σ2/n)을 따릅니다.
  4. 연결표본의 크기를 4배로 늘리면 σ(X̄)는 절반이 됩니다. 임의추출한 표본이면 x̄가 n이 클수록 m 가까이 모이므로, 다음 절에서는 x̄ 하나로 m이 있을 만한 범위를 추정합니다.
  5. 적용n = 4에서 '표본 100개'를 여러 번 눌러 x̄들의 표준편차를 σ/√n과 비교해 보세요. n을 16, 64로 바꾸면 표준편차는 몇 배가 되나요? x̄들의 평균은 n에 따라 달라지나요? n = 1이면 막대는 어느 곡선과 겹치나요?
  6. 판단표본분산은 n이 아니라 n − 1로 나눕니다. n으로 나누면 평균적으로 모분산보다 작게 나오기 때문입니다. 또 σ(X̄) = σ/√n은 복원추출이거나 모집단이 표본보다 충분히 클 때의 식입니다. 모집단이 정규분포가 아니어도 n이 크면 X̄의 분포는 정규분포에 가까워지지만, 여기서는 모집단이 정규분포인 경우만 다룹니다.
