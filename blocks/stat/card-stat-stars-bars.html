종류마다 몇 개씩 고를지는 몇 가지로 정할 수 있을까?

중복조합 · 공과 칸막이

\({}_{n}\mathrm{C}_{r}\)

세로 막대(칸막이)를 끌어서 다른 칸으로 옮겨 보세요. 칸막이는 서로 지나칠 수 없습니다.

  1. 질문사과, 배, 감 세 종류에서 과일 5개를 사려고 합니다. 같은 과일을 여러 개 사도 되고, 한 종류를 사지 않아도 됩니다. 담는 순서는 상관없다면 살 수 있는 방법은 몇 가지일까요?
  2. 복원서로 다른 \(n\)개에서 순서 없이 \(r\)개를 고르는 조합의 수는 \({}_{n}\mathrm{C}_{r}\)입니다. 같은 것이 있는 순열에서는 공 \(r\)개와 막대 \(k\)개를 한 줄로 늘어놓는 방법이 \(\frac{(r + k)!}{r!k!}\)가지입니다.
  3. 설명서로 다른 \(n\)종류에서 중복을 허락하여 순서 없이 \(r\)개를 택하는 조합을 중복조합이라 하고, 그 수를 \({}_{n}\mathrm{H}_{r}\)로 나타냅니다. 고른 결과는 '종류마다 몇 개'만으로 정해집니다. 그래서 고른 \(r\)개를 공으로 그리고, 종류 사이에 칸막이 \(n - 1\)개를 세우면 고르는 방법 하나가 공과 칸막이의 배열 하나와 짝지어집니다. 첫 칸막이 앞의 공 수가 첫째 종류의 개수, 두 칸막이 사이의 공 수가 다음 종류의 개수입니다. 이 배열의 수는 \(r + n - 1\)개의 자리에서 공이 놓일 \(r\)자리를 고르는 수와 같으므로 \({}_{n}\mathrm{H}_{r} = {}_{n+r-1}\mathrm{C}_{r}\)입니다. 사과·배·감 5개이면 \({}_{3}\mathrm{H}_{5} = {}_{7}\mathrm{C}_{5} = 21\)가지입니다.
  4. 연결중복을 허락하므로 \({}_{n}\mathrm{H}_{r}\)에서는 \(r\)가 \(n\)보다 커도 됩니다. 여기에 순서까지 따지면 중복순열 \({}_{n}\Pi_{r} = n^r\)가 됩니다. 똑같은 사탕 \(r\)개를 \(n\)명에게 나누어 주는 방법, 같은 색 공 \(r\)개를 서로 다른 상자 \(n\)개에 넣는 방법도 모두 \({}_{n}\mathrm{H}_{r}\)가지입니다. 또 집합 \(\{1, 2, \cdots, r\}\)에서 \(\{1, 2, \cdots, n\}\)으로 가는 함수 가운데 \(f(1) \le f(2) \le \cdots \le f(r)\)인 것의 개수도 \({}_{n}\mathrm{H}_{r}\)입니다. 함숫값 \(r\)개를 중복을 허락해 고르면 크기 순서는 저절로 정해지기 때문입니다.
  5. 적용\(n = 3\), \(r = 5\)로 두고 칸막이를 끌어 '사과 0, 배 5, 감 0'을 만들어 보세요. 칸막이가 맨 앞에 붙어 있을 때 무엇을 뜻하나요? '다음 경우'를 계속 눌러 마지막 경우가 몇 번째인지 보고 \({}_{3}\mathrm{H}_{5}\)와 비교하세요. \(r\)를 \(n\)보다 작게 했을 때와 크게 했을 때 \({}_{n}\mathrm{C}_{r}, {}_{n}\mathrm{H}_{r}, {}_{n}\Pi_{r}\)는 각각 어떻게 되나요?
  6. 판단\({}_{n}\mathrm{H}_{r}\)를 \({}_{n+r-1}\mathrm{C}_{n}\)으로 쓰는 실수가 흔합니다. 전체 자리 \(n + r - 1\)개 가운데 고르는 것은 공 \(r\)자리 또는 칸막이 \(n - 1\)자리입니다. 그래서 \({}_{n+r-1}\mathrm{C}_{r} = {}_{n+r-1}\mathrm{C}_{n-1}\)입니다. 또 '종류마다 적어도 하나씩' 같은 조건이 붙으면 그만큼 먼저 하나씩 담아 두고, 남은 개수로 중복조합을 셉니다.
