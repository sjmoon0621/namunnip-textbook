\((a + b)^n\)의 계수는 왜 조합의 수일까?

위 칸 하나가 인수 \((a + b)\) 하나입니다. 칸을 누르면 그 인수에서 고르는 문자가 바뀝니다.

  1. 질문\((a + b)^4\)를 전개하면 \(a^2b^2\)의 계수는 얼마일까요? 곱셈을 끝까지 하지 않고 알 수 있을까요?
  2. 복원\((a + b)(c + d) = ac + ad + bc + bd\)처럼, 다항식의 곱을 전개하면 인수마다 항을 하나씩 골라 곱한 것이 모두 나옵니다. 서로 다른 \(n\)개에서 순서 없이 \(r\)개를 고르는 방법은 \({}_{n}\mathrm{C}_{r}\)가지입니다.
  3. 설명\((a + b)^n = (a + b)(a + b)\cdots(a + b)\)에서 인수 \(n\)개마다 \(a\)나 \(b\)를 하나씩 골라 곱하면 항이 하나 생깁니다. 선택은 모두 \(2^n\)가지입니다. \(b\)를 \(r\)번, \(a\)를 \(n - r\)번 고르면 항은 \(a^{n-r}b^r\)이고, \(b\)를 고를 인수 \(r\)개를 정하는 방법이 \({}_{n}\mathrm{C}_{r}\)가지이므로 이 항은 \({}_{n}\mathrm{C}_{r}\)번 나옵니다. 따라서 \((a + b)^n = {}_{n}\mathrm{C}_{0}a^n + {}_{n}\mathrm{C}_{1}a^{n-1}b + \cdots + {}_{n}\mathrm{C}_{r}a^{n-r}b^r + \cdots + {}_{n}\mathrm{C}_{n}b^n\)입니다. 이것을 이항정리라 하고, 계수 \({}_{n}\mathrm{C}_{r}\)를 이항계수, \({}_{n}\mathrm{C}_{r}a^{n-r}b^r\)를 일반항이라고 합니다. \(\sum\) 기호로는 \((a + b)^n = \sum_{r=0}^n\) \({}_{n}\mathrm{C}_{r}a^{n-r}b^r\)로 씁니다.
  4. 연결고른 문자를 늘어놓은 abba 같은 문자열은 \(a\)가 \(n - r\)개, \(b\)가 \(r\)개인 같은 것이 있는 순열입니다. 그래서 계수는 \(\frac{n!}{(n - r)!r!} = {}_{n}\mathrm{C}_{r}\)로도 구해집니다. 바둑판 길의 최단 경로 수와 같은 수인 것도 이 때문입니다. 막대 높이를 \(n\)마다 한 줄씩 쌓으면 파스칼의 삼각형이 됩니다.
  5. 적용\(n = 4\)에서 칸을 눌러 \(b\)를 두 번 고르는 선택을 서로 다르게 여러 개 만들어 보세요. 모두 몇 가지이고, 가운데 막대의 높이와 같나요? '다음 선택'을 \(2^n\)번 누르면 모든 선택을 한 번씩 지나갑니다. 그동안 막대마다 몇 번씩 강조되나요? \(n\)을 바꾸며 막대 높이의 합이 얼마인지도 확인하세요.
  6. 판단\((a + b)^n\)을 \(a^n + b^n\)으로 쓰는 실수가 흔합니다. 그것은 인수마다 모두 \(a\)를 고르거나 모두 \(b\)를 고르는 두 경우만 센 것입니다. 또 일반항의 \(r\)는 \(b\)의 지수이므로 '\(r\)번째 항'이 아니라 '\(r + 1\)번째 항'입니다. \(a, b\) 자리에 \(2x\), \(-1\) 같은 식이 들어가면 계수에 \(2^{n-r}\)와 \((-1)^r\)도 곱해집니다.
