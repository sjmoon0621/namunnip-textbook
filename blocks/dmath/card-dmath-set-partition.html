다섯 명을 세 모둠으로 나누는 방법은 몇 가지일까?

집합의 분할 · 만들기

사람을 누르면 모둠 번호가 바뀐다. 모둠의 이름(번호)은 구별하지 않고, 빈 모둠은 허용하지 않는다.

—

  1. 질문다섯 명(A~E)을 이름 없는 세 모둠으로 나눈다. 모둠마다 적어도 한 명은 있어야 한다. {A, B}, {C, D}, {E}와 {C, D}, {A, B}, {E}는 같은 나눔이다. 모두 몇 가지일까?
  2. 복원집합을 공집합이 아니고 서로 겹치지 않는 부분집합들로 나누어 합하면 전체가 되게 하는 것을 집합의 분할이라고 한다.
  3. 설명\(n\)개의 원소를 \(k\)개로 분할하는 방법의 수를 \(S(n, k)\)라 한다. 마지막 원소 E를 생각하면 ① E 혼자 한 모둠이면 나머지를 \(k - 1\)개로 나누고(\(S(n - 1, k - 1)\)), ② E가 다른 모둠에 끼면 나머지를 \(k\)개로 나눈 뒤 E가 들어갈 모둠을 고른다(\(k\,S(n - 1, k)\)). 그래서 \(S(n, k) = S(n - 1, k - 1) + k\,S(n - 1, k)\)이다. 모든 \(k\)에 대해 더한 것을 벨 수라고 한다.
  4. 연결모둠에 이름(1모둠, 2모둠)이 붙으면 분할마다 \(k!\)가지로 이름을 붙일 수 있으므로 \(k!\,S(n, k)\)이다. 이것은 \(n\)개를 \(k\)개로 보내는 전사함수의 개수와 같다.
  5. 적용\(n = 5\), \(k = 3\)에서 서로 다른 분할을 찾아 기록해 보자. 모둠 크기가 (3, 1, 1)인 것과 (2, 2, 1)인 것은 각각 몇 개인가? 합이 표의 \(S(5, 3)\)과 같은가?
  6. 판단번호를 바꿔 붙인 같은 분할을 두 번 세기 쉽다. 이 카드는 "가장 작은 사람이 속한 모둠부터 1, 2, 3"으로 번호를 다시 붙여 같은 분할을 알아본다. 사람이 서로 같다면(구별하지 않으면) 이것은 다음 카드의 자연수 분할이 된다.
