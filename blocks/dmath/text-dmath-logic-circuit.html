본문

계산기 안에는 전기가 흐르면 1, 흐르지 않으면 0인 신호를 주고받는 작은 부품들이 있다. 두 신호가 모두 1일 때만 1을 내보내는 그리고 게이트, 하나라도 1이면 1을 내보내는 또는 게이트, 신호를 뒤집는 부정 게이트가 대표적이다. 이 세 가지 부품만 이어 붙여 이진수 두 자리의 덧셈, 예를 들어 \(1 + 1 = 10_{(2)}\)을 하는 회로를 만들 수 있을까? 여러 자리의 덧셈은 어떻게 할까?

먼저 알아야 할 것부울 함수와 간소화(부울 함수와 간소화), 이진수의 덧셈(이진수의 사칙연산).

3.4.1식을 회로로 옮기다

부울 함수의 식은 그대로 회로가 된다. 곱은 그리고 게이트, 합은 또는 게이트, 부정은 부정 게이트로 바꾸고, 식의 계산 순서대로 게이트를 잇는다. 그래서 진리표로 원하는 규칙을 정하고, 곱의 합 꼴로 식을 쓰고, 간소화한 뒤 회로로 옮기면 어떤 규칙이든 기계로 만들 수 있다. 간소화한 식일수록 게이트가 적게 들어 회로가 작고 빠르다. 두 입력이 서로 다를 때만 1인 배타적 또는 \(A \oplus B = \bar AB + A\bar B\)도 이렇게 세 가지 게이트로 만든다.

정리 3.4.1 반가산기와 전가산기

한 자리 이진수 \(A\), \(B\)를 더하는 반가산기는 합 \(S = A \oplus B\)와 올림 \(C = AB\)를 낸다. 아래 자리에서 올라온 \(C_{\text{in}}\)까지 더하는 전가산기는 \[S = A \oplus B \oplus C_{\text{in}},\qquad C_{\text{out}} = AB + BC_{\text{in}} + C_{\text{in}}A\]를 낸다. 전가산기를 자릿수만큼 이어 붙이면 여러 자리 이진수의 덧셈 회로가 된다.

전가산기의 올림 \(C_{\text{out}}\)은 세 입력 가운데 둘 이상이 1일 때 1이므로, 앞에서 본 다수결 함수와 같다. 합 \(S\)는 세 입력 가운데 1이 홀수 개일 때 1이다. 반가산기 두 개와 또는 게이트 하나로 전가산기를 만들 수도 있다. 첫째 반가산기로 \(A\)와 \(B\)를 더하고, 둘째 반가산기로 그 합과 \(C_{\text{in}}\)을 더한 뒤, 두 올림 가운데 하나라도 1이면 올림을 낸다.1

3.4.2여러 자리 더하기

네 자리 이진수 두 개를 더하려면 전가산기 네 개를 한 줄로 잇는다. 맨 아래 자리의 올림 입력은 0으로 두고, 각 전가산기의 올림 출력을 바로 위 자리 전가산기의 올림 입력에 잇는다. 그러면 사람이 손으로 아래 자리부터 받아올리며 더하는 과정이 그대로 회로가 된다. 다만 위 자리는 아래 자리의 올림이 정해질 때까지 기다려야 해서, 자릿수가 많으면 올림이 차례로 전해지는 데 시간이 걸린다. 그래서 실제 컴퓨터는 올림을 미리 내다보는 더 복잡한 회로를 쓴다.

3.4.3예제 하나를 끝까지

예제 3.4.2

배타적 또는 \(A \oplus B\)를 그리고, 또는, 부정 게이트로 만들 때 필요한 게이트 수를 세어라. 전가산기에 \(A = 1\), \(B = 1\), \(C_{\text{in}} = 1\)을 넣었을 때의 출력을 구하고, 십진법으로 확인하여라.

\(A \oplus B = \bar AB + A\bar B\)이므로 부정 게이트 2개로 \(\bar A\), \(\bar B\)를 만들고, 그리고 게이트 2개로 \(\bar AB\), \(A\bar B\)를 만든 뒤, 또는 게이트 1개로 더한다. 모두 5개이다. 그래서 반가산기는 배타적 또는 회로와 그리고 게이트 하나로 만들어진다.

전가산기에 1, 1, 1을 넣으면 1이 세 개로 홀수이므로 \(S = 1\)이고, 둘 이상이 1이므로 \(C_{\text{out}} = 1\)이다. 출력은 이진수 \(11_{(2)} = 3\)이어서 \(1 + 1 + 1 = 3\)과 같다. 즉 진리표로 정한 규칙을 부울 식으로 쓰고 게이트로 옮기면 덧셈 같은 계산도 회로로 만들 수 있으며, 반가산기와 전가산기를 이어 붙인 회로가 컴퓨터 덧셈의 기본 부품이다.

마무리

부울 함수의 곱, 합, 부정은 각각 그리고, 또는, 부정 게이트가 되어, 진리표로 정한 규칙을 식으로 쓰고 간소화한 뒤 게이트로 옮기면 회로가 된다. 반가산기는 합 \(A \oplus B\)와 올림 \(AB\)를 내고, 전가산기는 아래 자리의 올림까지 더하며, 전가산기를 자릿수만큼 이으면 여러 자리 덧셈 회로가 된다. 처음 질문의 덧셈 기계는 세 가지 게이트만으로 만든 가산기들을 이어 붙여 만들 수 있다.
