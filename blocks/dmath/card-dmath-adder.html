  1. 질문이진수 덧셈의 규칙은 몇 줄뿐이었다. 그렇다면 스위치와 게이트만으로 두 수를 더하는 기계를 만들 수 있을까? 계산기의 덧셈은 안에서 어떻게 일어날까?
  2. 복원한 자리 덧셈은 \(0 + 0 = 00\), \(0 + 1 = 01\), \(1 + 1 = 10\)(받아올림 1). XOR은 둘이 다를 때 1, AND는 둘 다 1일 때 1이다.
  3. 설명한 자리 두 비트의 합의 자리는 \(S = A \oplus B\), 받아올림은 \(C = AB\)이다. 이것이 반가산기이다. 아랫자리에서 올라온 받아올림 \(C_{in}\)까지 더하는 전가산기는 \(S = A \oplus B \oplus C_{in}\), \(C_{out} = AB + C_{in}(A \oplus B)\)이다. 전가산기 네 개를 받아올림 선으로 이으면 4비트 덧셈 회로가 된다. 2의 보수와 함께 쓰면 같은 회로로 뺄셈도 한다.
  4. 연결받아올림이 오른쪽부터 차례로 전해져야 하므로 자리가 많을수록 느려진다. 실제 처리 장치는 받아올림을 미리 계산하는 회로(자리올림 예측)로 이 지연을 줄인다.
  5. 적용A, B의 자리를 눌러 여러 덧셈을 해 보자. 1111 + 0001처럼 받아올림이 끝까지 전해지는 경우를 "받아올림 전파 보기"로 확인해 보자. 마지막 받아올림 \(C_4\)는 무엇을 뜻하는가?
  6. 판단4비트 회로는 0~15만 나타내므로 합이 15를 넘으면 \(C_4 = 1\)로 넘침이 생긴다. 회로는 틀린 것이 아니라 정해진 자리만큼만 계산한 것이며, 넘침을 확인하는 일은 따로 해야 한다.
