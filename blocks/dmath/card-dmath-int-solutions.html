조건이 붙은 방정식의 정수해는 몇 개일까?

중복조합과 정수해 · 예측→확인

먼저 예측해 보자. 해의 개수는?

  1. 질문방정식 \(x + y + z = 8\)의 음이 아닌 정수해는 중복조합으로 셀 수 있었다. 그런데 "모두 1 이상", "\(x \ge 3\)", "모두 4 이하" 같은 조건이 붙으면 어떻게 셀까?
  2. 복원\(x_1 + \cdots + x_n = r\)의 음이 아닌 정수해의 개수는 \({}_n\mathrm{H}_r = {}_{n+r-1}\mathrm{C}_r\)이다.
  3. 설명아래로 막힌 조건은 미리 나눠 주고 센다. \(x \ge 3\)이면 \(x = x' + 3\)으로 두어 \(x' + y + z = 5\), 곧 \({}_3\mathrm{H}_5 = 21\)개이다. "모두 1 이상"은 하나씩 먼저 주고 \({}_3\mathrm{H}_5\)이다. 위로 막힌 조건 "4 이하"는 이렇게 바꿀 수 없어서, 전체에서 "어느 하나가 5 이상"인 해를 빼야 하며 이때 겹치는 것을 조심해야 한다(다음 절의 포함배제의 원리).
  4. 연결세 변수의 해는 정삼각형 모양 격자의 점으로 그릴 수 있다. 꼭짓점이 \((8, 0, 0)\), \((0, 8, 0)\), \((0, 0, 8)\)이고, 아래로 막힌 조건은 작은 삼각형을, 위로 막힌 조건은 모서리를 잘라 낸 육각형을 남긴다.
  5. 적용네 문제의 답을 먼저 예측한 뒤 그림으로 확인해 보자. 문제 4에서 잘려 나간 세 모서리 삼각형은 각각 몇 개의 점을 가지는가? 서로 겹치는가?
  6. 판단"양의 정수해"와 "음이 아닌 정수해"는 다르다. 문제를 읽을 때 0을 허용하는지 먼저 확인해야 한다.
