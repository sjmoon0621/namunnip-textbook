이진수의 사칙연산

본문

오래된 게임에서 캐릭터의 체력을 8자리 이진수로 저장했다. 이 게임은 음수도 다루어야 해서 맨 앞자리가 1이면 음수로 읽는다. 체력 100에 물약 50을 더했더니, 화면에 150이 아니라 \(-106\)이 떴다. 덧셈 자체는 틀리지 않았는데 왜 이런 결과가 나왔을까? 컴퓨터는 0과 1만으로 음수를 어떻게 나타내고, 빼기를 어떻게 더하기로 바꾸어 계산할까?

먼저 알아야 할 것진법(진법), 덧셈의 받아올림.

3.2.1받아올림만 있는 덧셈

이진수의 덧셈은 십진수와 같은 방법으로 아래 자리부터 더하되, 2가 되면 받아올린다. 한 자리에서 일어나는 일은 \(0 + 0 = 0\), \(0 + 1 = 1\), \(1 + 1 = 10_{(2)}\)의 세 가지뿐이어서, 받아올림까지 합쳐도 \(1 + 1 + 1 = 11_{(2)}\)이 가장 크다. 곱셈은 더 단순해서, 곱하는 수의 각 자리가 1이면 피승수를 그 자리만큼 왼쪽으로 옮겨 적고 0이면 적지 않은 뒤 모두 더한다. 왼쪽으로 한 칸 옮기는 것은 2를 곱하는 것과 같다. 그래서 이진수의 곱셈은 옮기기와 더하기만으로 이루어진다.

정리 3.2.1 2의 보수

\(n\)자리 이진수에서 음수 \(-x\)는 \(2^n - x\)로 나타내며, 이를 \(x\)의 2의 보수라 한다. \(x\)의 각 자리를 뒤집고 1을 더하면 2의 보수가 된다. 이렇게 하면 \(n\)자리로 \(-2^{n-1}\)부터 \(2^{n-1} - 1\)까지 나타내고, 뺄셈 \(a - b\)는 \(a\)에 \(b\)의 2의 보수를 더한 뒤 넘친 자리를 버려서 구한다.

8자리에서 \(-x\)를 \(256 - x\)로 나타내면, \(x + (-x) = 256 = 1\,0000\,0000_{(2)}\)이 되는데 아홉째 자리는 버리므로 0이 된다. 그래서 음수를 더하는 것이 자연스럽게 빼는 것이 되고, 컴퓨터는 덧셈 회로 하나로 덧셈과 뺄셈을 모두 한다. 각 자리를 뒤집으면 \(255 - x\)가 되므로 1을 더하면 \(256 - x\)이다. 맨 앞자리가 1인 수는 128 이상이어서 음수를 나타내므로, 맨 앞자리가 부호를 알려 준다.1

3.2.2넘침

부호 있는 8자리 이진수가 나타낼 수 있는 가장 큰 수는 \(0111\,1111_{(2)} = 127\)이다. 두 양수를 더해 127을 넘으면 결과의 맨 앞자리가 1이 되어 음수로 읽히는데, 이것을 넘침이라 한다. 두 양수를 더했는데 음수가 나오거나 두 음수를 더했는데 양수가 나오면 넘친 것이다. 그래서 컴퓨터는 이런 경우를 따로 알려 주는 표시를 두고, 프로그램을 만들 때는 다룰 값의 범위에 맞게 자릿수를 정해야 한다.

3.2.3예제 하나를 끝까지

예제 3.2.2

이진수 \(1011_{(2)} + 0110_{(2)}\)과 \(1011_{(2)}\times101_{(2)}\)을 계산하고 십진법으로 확인하여라. 또 처음 질문의 \(100 + 50\)이 \(-106\)으로 읽히는 까닭을 2의 보수로 설명하여라.

\(1011 + 0110\)은 아래 자리부터 \(1 + 0 = 1\), \(1 + 1 = 10\)이므로 0을 쓰고 1을 올리며, \(0 + 1 + 1 = 10\)이므로 0을 쓰고 1을 올리고, \(1 + 0 + 1 = 10\)이어서 결과는 \(10001_{(2)}\)이다. 십진법으로 \(11 + 6 = 17\)과 같다. \(1011\times101\)은 1011과 두 칸 옮긴 101100을 더해 \(110111_{(2)} = 55\)이고, \(11\times5 = 55\)와 같다.

\(100 + 50 = 150 = 1001\,0110_{(2)}\)이다. 맨 앞자리가 1이므로 부호 있는 수로는 음수 \(150 - 256 = -106\)으로 읽힌다. 부호 있는 8자리가 나타낼 수 있는 가장 큰 수 127을 넘었기 때문이다. 즉 이진수의 사칙연산은 받아올림과 자리 옮기기로 단순하게 이루어지고, 음수는 2의 보수로 나타내 뺄셈을 덧셈으로 바꾸지만, 정해진 자릿수의 범위를 넘으면 넘침이 생긴다.

아래 탐구 카드에서 이진수의 덧셈과 곱셈을 해 보고, 8자리 이진수로 음수를 나타내 넘침이 생기는 경우를 찾아보자.

마무리

이진수의 덧셈은 2에서 받아올리고, 곱셈은 곱하는 수의 1인 자리만큼 옮겨 더하는 것만으로 이루어진다. 음수 \(-x\)는 \(n\)자리에서 2의 보수 \(2^n - x\)로 나타내며, 각 자리를 뒤집고 1을 더해 얻고, 뺄셈은 2의 보수를 더한 뒤 넘친 자리를 버려 계산한다. 처음 질문의 게임은 부호 있는 8자리의 최댓값 127을 넘는 150을 만들어, 맨 앞자리가 1이 되면서 \(-106\)으로 읽혔다.
