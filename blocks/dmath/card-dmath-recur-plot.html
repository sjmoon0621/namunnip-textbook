점화식만 보고 수열이 어디로 갈지 알 수 있을까?

점화 관계와 일반항 · 조작

  1. 질문\(a_{n+1} = 0.5a_n + 2\)이면 수열은 커질까요, 작아질까요, 어느 값에 머물까? 항을 하나하나 계산하지 않고 알 수 있을까?
  2. 복원한 단계마다 같은 수 \(p\)를 곱하는 수열 \(b_{n+1} = pb_n\)(대수의 등비수열)의 일반항은 \(b_n = b_1p^{n-1}\)이고, \(|p| < 1\)이면 \(b_n\)은 0에 한없이 가까워진다.
  3. 설명\(\alpha = p\alpha + q\)인 수 \(\alpha = \dfrac{q}{1 - p}\) (\(p \ne 1\))를 찾아 빼면 \(a_{n+1} - \alpha = p(a_n - \alpha)\)가 되어 등비수열이 나온다. 그래서 일반항은 \(a_n = \alpha + (a_1 - \alpha)p^{n-1}\)이고, \(|p| < 1\)이면 \(\alpha\)에 한없이 가까워지고, \(|p| > 1\)이면 \(\alpha\)에서 멀어지며, \(p < 0\)이면 \(\alpha\)의 양쪽을 번갈아 오간다. 거미줄 그림에서 \(\alpha\)는 두 직선 \(y = px + q\)와 \(y = x\)의 교점이다. 이웃한 세 항의 관계 \(a_{n+2} = ra_{n+1} + sa_n\)은 특성방정식 \(t^2 = rt + s\)의 근으로 푼다.
  4. 연결약을 일정한 간격으로 먹을 때 몸속 약의 양(매번 일정 비율이 빠져나가고 일정량이 들어옴), 다음 카드의 대출 잔액이 모두 이 꼴의 점화식이다.
  5. 적용\(p\)를 0.5, −0.5, 1.2, −1.2로 바꾸며 거미줄이 교점으로 모이는지, 계단 모양인지, 소용돌이인지 보자. \(a_1 = \alpha\)로 맞추면 어떻게 되는가?
  6. 판단\(p = 1\)이면 \(\alpha\)가 없고 수열은 공차 \(q\)인 등차수열이다. 공식 \(\frac{q}{1 - p}\)에 그대로 넣으면 0으로 나누게 된다. 공식이 성립하는 조건을 먼저 확인해 보자.

확인조건이 달라지면

\(a_1 = 1\), \(a_{n+1} = \frac{1}{3}a_n + 4\)인 수열의 극한값은?
