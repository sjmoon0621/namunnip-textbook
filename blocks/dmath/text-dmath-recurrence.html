점화 관계와 일반항

본문

1000만 원을 월 이자율 0.5%로 빌렸다. 매달 말에 이자가 붙고, 같은 금액 \(x\)원씩 갚는다. 그러면 \(n\)개월 뒤 남은 빚 \(a_n\)은 \(a_{n+1} = 1.005a_n - x\)라는 점화 관계를 따른다. 24개월 뒤 빚이 정확히 0이 되려면 \(x\)는 얼마여야 할까? 한 달씩 24번 계산해 맞추어 보는 대신, \(a_n\)을 \(n\)의 식으로 바로 쓸 수 있다면 한 번에 풀 수 있을 것이다. 이런 점화 관계의 일반항은 어떻게 구할까?

먼저 알아야 할 것점화 관계(수열의 귀납적 정의), 등비수열의 일반항과 합.

2.2.1고정점을 기준으로 보기

\(a_{n+1} = pa_n + q\) 꼴의 점화 관계는 수열이 변하지 않는 값, 곧 \(\alpha = p\alpha + q\)인 고정점을 먼저 찾으면 풀린다. 두 식을 빼면 \(a_{n+1} - \alpha = p(a_n - \alpha)\)이므로, 고정점에서 벗어난 정도 \(a_n - \alpha\)는 공비 \(p\)인 등비수열이다. 그래서 \(a_n = \alpha + (a_0 - \alpha)p^n\)이다. \(|p| < 1\)이면 수열은 고정점으로 다가가고, \(|p| > 1\)이면 고정점에서 점점 멀어진다. 그래서 점화식만 보고도 수열이 어디로 갈지 알 수 있다.

정리 2.2.1 일차 점화 관계의 일반항

\(a_{n+1} = pa_n + q\)이고 \(p \ne 1\)이면 고정점 \(\alpha = \dfrac{q}{1 - p}\)에 대해 \[a_n = \alpha + (a_0 - \alpha)p^n\]이다. \(a_{n+2} = pa_{n+1} + qa_n\) 꼴이면 특성방정식 \(t^2 = pt + q\)의 서로 다른 두 근 \(t_1\), \(t_2\)로 \(a_n = Ct_1^n + Dt_2^n\)이다.

대출의 점화 관계는 \(p = 1.005\), \(q = -x\)이므로 고정점은 \(\alpha = \dfrac{-x}{1 - 1.005} = 200x\)이다. 고정점은 빚이 늘지도 줄지도 않는 금액, 곧 매달 갚는 \(x\)원이 이자와 꼭 같은 빚이다. 빚이 고정점보다 작으면 \(a_n - \alpha\)가 음수이고 1.005배씩 커지므로 빚은 점점 빨리 줄어든다. 두 항 점화 관계도 같은 생각으로, 등비수열 \(t^n\)이 점화식을 만족하도록 \(t\)를 정한 뒤 두 해를 섞어 처음 항에 맞춘다.1

2.2.2점화식만 보고 내다보기

\(a_{n+1} = 0.5a_n + 3\)은 고정점이 6이고 \(p = 0.5\)이므로, 어디서 출발하든 6으로 다가가며 6과의 차이가 매번 절반이 된다. \(a_{n+1} = 2a_n - 3\)은 고정점이 3이지만 \(p = 2\)이므로, 3에서 조금만 벗어나도 차이가 두 배씩 커져 멀어진다. \(a_{n+1} = -a_n + 4\)는 \(p = -1\)이어서 고정점 2를 사이에 두고 두 값을 번갈아 오간다. 그래서 \(p\)의 크기와 부호를 보면 수열이 모이는지, 퍼지는지, 진동하는지 알 수 있다.

2.2.3예제 하나를 끝까지

예제 2.2.2

처음 질문의 대출에서 \(a_{24} = 0\)이 되는 \(x\)를 구하여라. \(1.005^{24} \approx 1.12716\)이다. 24개월 동안 낸 이자는 모두 얼마인가?

일반항은 \(a_n = 200x + (10^7 - 200x)\times1.005^n\)이다. \(a_{24} = 0\)이면 \(200x = (200x - 10^7)\times1.12716\)이므로 \(200x\times0.12716 = 10^7\times1.12716\), 곧 \(x = \dfrac{10^7\times0.005\times1.12716}{0.12716} \approx 443206\)원이다.

24개월 동안 갚은 돈은 \(443206\times24 \approx 1063.7\)만 원이므로 이자는 약 63.7만 원이다. 원금 1000만 원의 0.5%씩 24개월이면 120만 원이지만, 원금이 매달 줄어들어 실제 이자는 그 절반 남짓이다. 즉 \(a_{n+1} = pa_n + q\) 꼴의 점화 관계는 고정점을 기준으로 등비수열로 바꾸어 일반항을 구하고, 그 일반항으로 몇 번째 항의 조건을 한 번에 풀거나 수열이 어디로 갈지 내다볼 수 있다.

아래 탐구 카드에서 점화식만 보고 수열이 어디로 갈지 예측해 그래프로 확인하고, 대출을 갚는 매달 금액을 계산해 보자.

  1. 이 방식처럼 매달 같은 금액을 갚는 것을 원리금 균등 상환이라 한다. 매달 원금을 같은 금액씩 갚는 원금 균등 상환은 처음에 더 많이 내지만, 원금이 빨리 줄어 전체 이자는 조금 적다.
마무리

\(a_{n+1} = pa_n + q\) 꼴의 점화 관계는 고정점 \(\alpha = q/(1 - p)\)에서 벗어난 정도가 공비 \(p\)인 등비수열이어서 \(a_n = \alpha + (a_0 - \alpha)p^n\)이고, \(|p|\)가 1보다 작으면 모이고 크면 멀어진다. 두 항 점화 관계는 특성방정식의 근으로 일반항을 구한다. 처음 질문의 대출은 일반항으로 \(a_{24} = 0\)을 풀어 매달 약 443206원씩 갚아야 하고, 이자는 모두 약 63.7만 원이다.
