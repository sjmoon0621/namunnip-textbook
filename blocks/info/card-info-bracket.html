후위 표기식은 수와 연산자를 빈칸으로 띄어 씁니다(정수와 + − * /). 괄호 검사는 ( ) [ ] { }만 보고 나머지 글자는 건너뜁니다.

      

    

    
    
      
  1. 질문코드 편집기는 괄호 짝이 틀리면 곧바로 표시합니다. 여는 괄호와 닫는 괄호의 개수만 세면 될까요? ([)]는 개수가 맞는데도 틀린 식입니다. 또 계산기는 (3 + 4) * 2에서 무엇을 먼저 계산할지 어떻게 정할까요?
    2. 
      
  2. 복원스택은 맨 위에서만 넣고 꺼내는 후입선출 구조입니다. 보통 쓰는 수식(중위 표기)은 연산자가 두 수 사이에 있고, 곱셈이 덧셈보다 먼저라는 우선순위와 괄호로 계산 순서를 정합니다.
    3. 
      
  3. 설명괄호는 가장 나중에 열린 것이 가장 먼저 닫혀야 합니다. 이 성질이 바로 후입선출이므로, 여는 괄호는 스택에 넣고 닫는 괄호를 만나면 맨 위를 꺼내 종류가 맞는지 봅니다. 중간에 짝이 틀리거나 스택이 비어 있으면 실패, 끝까지 읽은 뒤 스택이 비어야 성공입니다. 후위 표기식은 연산자를 두 수 뒤에 씁니다. (3 + 4) * 2는 3 4 + 2 *가 됩니다. 수는 스택에 넣고, 연산자를 만나면 두 수를 꺼내 계산한 결과를 다시 넣습니다. 괄호도 우선순위도 필요 없고, 왼쪽에서 오른쪽으로 한 번만 읽으면 됩니다.
    4. 
      
  4. 연결두 알고리즘 모두 입력을 한 번씩만 읽으므로 걸리는 시간이 입력 길이에 비례합니다. 계산기와 컴파일러는 중위식을 먼저 후위식으로 바꾼 뒤 이 방법으로 계산하는데, 이 변환에도 연산자를 잠시 쌓아 두는 스택이 쓰입니다. HTML 태그의 짝, 함수 호출과 반환처럼 ‘안에 같은 구조가 들어 있는’ 것을 다룰 때 스택이 쓰입니다.
    5. 
      
  5. 적용([)]는 몇 번째 글자에서 실패하나요? ((a+b)*c는 언제 실패가 드러나나요? 후위식 8 2 / 3 -에서 연산자를 만날 때 먼저 꺼낸 수가 왼쪽인지 오른쪽인지 확인하세요. 2 3 4 * +를 중위식으로 바꾸어 쓰고, 직접 만든 후위식으로 시험해 보세요.
    6. 
      
  6. 판단괄호가 한 종류뿐이면 개수를 세는 변수 하나로도 검사할 수 있습니다(중간에 음수가 되지 않고 끝에 0이면 성공). 여러 종류가 섞이면 어떤 괄호가 열려 있는지 순서까지 기억해야 하므로 스택이 필요합니다. 또 이 함수는 print(')')처럼 문자열 안에 든 괄호까지 세어 틀렸다고 판정합니다. 실제 편집기는 문자열과 주석을 먼저 구분합니다. 후위식 코드도 마지막에 스택에 값이 정확히 하나 남았는지 확인해야 잘못된 식을 걸러 낼 수 있습니다.
