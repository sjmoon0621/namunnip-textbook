고분자 한 분자의 분자량 (대략)

실제 고분자는 사슬마다 길이가 달라 분자량이 평균값으로 나타납니다. 그림에는 처음 몇 개의 반복 단위만 그렸습니다.

  1. 질문에틸렌(C₂H₄)은 끓는점이 −104 °C인 기체입니다. 그런데 이 분자 수천 개를 이으면 질기고 유연한 비닐봉지가 됩니다. 분자가 어떻게 이어지고, 이어지면 왜 성질이 이렇게 달라질까요?
  2. 복원이중 결합에는 다른 원자가 붙는 첨가 반응이 일어나고, 카복실산과 알코올은 물을 내놓으며 에스터로 이어집니다(앞 절). 녹말과 단백질도 작은 단위가 이어진 고분자입니다(통합과학).
  3. 설명작은 분자(단위체)가 수백~수만 개 이어져 만들어진 거대 분자를 고분자라 합니다. 이중 결합이 열리며 단위체가 그대로 이어지는 것을 첨가 중합이라 하고(폴리에틸렌, PVC, 폴리스타이렌), 작용기 두 개를 가진 단위체들이 물 같은 작은 분자를 내놓으며 이어지는 것을 축합 중합이라 합니다(나일론은 아마이드 결합, PET는 에스터 결합). 사슬이 길어지면 분자 사이의 인력이 매우 커져 기체나 액체였던 물질이 튼튼한 고체가 됩니다.
  4. 연결단위체의 곁가지가 성질을 바꿉니다. Cl이 붙은 PVC는 불에 잘 타지 않고 단단해 수도관으로, 벤젠 고리가 붙은 폴리스타이렌은 투명하고 딱딱하거나 부풀려 스티로폼이 됩니다. 나일론의 아마이드 결합은 사슬 사이에 수소 결합을 만들어 질긴 섬유가 됩니다. 1935년 캐러더스가 만든 나일론은 ‘석탄과 물과 공기로 만든, 거미줄보다 가늘고 강철보다 강한 섬유’로 광고되었습니다.
  5. 적용다섯 고분자를 비교해 첨가 중합과 축합 중합으로 나누어 보세요. 나일론 6,6에서 반복 단위 1000개가 생기는 동안 물 분자가 몇 개 빠져나오나요? n을 10에서 10000으로 늘리면 분자량은 어떻게 되나요?
  6. 판단합성 고분자의 튼튼함은 장점이자 문제입니다. 자연에서 잘 분해되지 않아 수백 년 동안 남고, 잘게 부서진 미세 플라스틱이 바다와 생물 몸속에 쌓입니다. 축합 중합체(PET 등)는 가수 분해로 단위체로 되돌리는 화학적 재활용이 연구되고 있습니다(다음 읽기).
