유전체를 잘게 잘라 읽은 뒤, 컴퓨터는 어떻게 다시 이어 붙일까?

생물정보학 · 산탄총 염기 서열 분석과 조립 · 랜더–워터먼 모형

유전체 길이는 대장균 K-12 MG1655의 4,641,652 bp, rRNA 오페론은 이 균주의 실제 수인 7벌입니다. 읽기 시작 위치를 무작위로 뽑아 실제로 이어 붙인 모의 결과이며, 두 읽기가 읽기 길이의 20 % 이상(θ = 0.2) 겹쳐야 잇는다고 두었습니다. 시퀀싱 오류는 없다고 가정했고, 반복 서열은 7벌을 모두 끊는 것으로 단순화했습니다(모식).

  1. 질문오늘날의 시퀀서는 DNA를 처음부터 끝까지 한 번에 읽지 못합니다. 유전체를 무작위로 잘게 부숴 수백만 조각을 읽은 뒤, 겹치는 부분을 찾아 컴퓨터로 이어 붙입니다. 그렇다면 얼마나 많이 읽어야 빈틈없이 이어질까요? 아무리 많이 읽어도 이어지지 않는 곳도 있을까요?
  2. 복원DNA 염기 서열은 A, T, G, C 네 글자로 된 긴 문자열입니다. 서로 다른 두 조각의 끝부분 서열이 같으면, 두 조각이 유전체에서 이웃해 있었다고 추정할 수 있습니다. 이어 붙여 만든 끊김 없는 서열을 콘티그라 합니다.
  3. 설명길이 G인 유전체에서 길이 L인 읽기 N개를 무작위로 얻으면, 평균 커버리지는 c = NL / G입니다. 한 염기가 한 번도 읽히지 않을 확률은 푸아송 분포로 e−c입니다. 콘티그가 끊기는 곳은 ‘다음 읽기가 충분히 겹치지 않는 곳’이므로, 콘티그 수는 대략 N e−c(1−θ)입니다(θ는 잇는 데 필요한 최소 겹침 비율). 이것이 1988년의 랜더–워터먼 모형입니다. 커버리지가 늘수록 빈틈은 지수적으로 줄어듭니다.
  4. 연결모형이 놓친 장애물은 반복 서열입니다. 같은 서열이 여러 곳에 있으면, 반복보다 짧은 읽기로는 반복의 양쪽 이웃이 어느 것끼리 짝인지 알 수 없습니다. 그래서 짧은 읽기만 쓴 유전체는 반복마다 끊깁니다. 수십 kb를 한 번에 읽는 긴 읽기 기술이 나오면서, 2022년에는 사람 유전체의 남은 빈틈을 메운 ‘끝에서 끝까지(T2T)’ 서열이 발표되었습니다. 이렇게 생물 자료를 수학, 통계, 컴퓨터로 해석하는 분야가 생물정보학입니다.
  5. 적용짧은 읽기로 커버리지를 1×, 3×, 8×, 20×로 올리며 콘티그 수를 이론값과 비교하세요. 반복 서열을 켜면 커버리지를 40×로 올려도 콘티그가 몇 개 아래로 내려가지 않나요? 긴 읽기로 바꾸면 같은 커버리지에서 읽기 수 N과 콘티그 수가 어떻게 달라지나요?
  6. 판단커버리지를 높이면 빈틈은 줄지만 반복 문제는 풀리지 않습니다. 반복을 풀려면 반복보다 긴 읽기가 필요합니다. 또 실제 읽기에는 오류가 있습니다. 짧은 읽기는 정확도가 높고 값이 싸며, 긴 읽기는 오류율이 상대적으로 높았지만 최근에는 크게 낮아졌습니다. 그래서 실제 연구에서는 두 방법을 섞기도 합니다. 랜더–워터먼 모형은 읽기 위치가 완전히 무작위라고 가정하지만, GC 함량 등에 따라 잘 읽히지 않는 구간이 있어 실제 빈틈은 이론보다 많기 쉽습니다.
