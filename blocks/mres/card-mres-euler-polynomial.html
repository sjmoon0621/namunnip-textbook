n = 0, 1, 2, …, 39에서 모두 소수가 나온다면 "n² + n + 41은 언제나 소수"라고 써도 될까?

결론의 한계 · 오류 찾기

  1. 질문어떤 모둠의 탐구 결론은 이렇다. "\(n^2 + n + 41\)에 0부터 차례로 수를 넣었더니 모두 소수였다. 따라서 이 식의 값은 언제나 소수이다." 이 결론의 문제는 무엇일까?
  2. 복원소수와 합성수, 인수분해를 떠올리자.
  3. 설명오일러가 다룬 것으로 알려진 이 식은 \(n = 0\)부터 39까지 40번 연속으로 소수를 낸다. 그러나 \(n = 40\)이면 \(40^2 + 40 + 41 = 40 \cdot 41 + 41 = 41^2\), \(n = 41\)이면 \(41(41 + 1 + 1) = 41 \cdot 43\)으로 합성수이다. 많은 예에서 성립해도 반례 하나면 일반적인 주장은 거짓이다. 탐구를 반성할 때는 결론이 확인한 범위를 넘어서지 않았는지 점검하고, 한계를 정직하게 적어야 한다.
  4. 연결콜라츠 추측, 원 나누기 문제와 같은 교훈이다. 확인은 증명이 아니고, 반례 하나가 결론을 무너뜨린다.
  5. 적용확인 범위를 늘려 처음으로 소수가 아닌 n을 찾자. 위 모둠의 결론을 사실에 맞게 고쳐 써 보자.
  6. 판단반대로, 반례가 없다고 증명된 것도 아니다. 한계에는 "어디까지 확인했는지"와 "무엇이 아직 밝혀지지 않았는지"를 함께 쓴다.

확인조건이 달라지면

\(n = 40\)일 때 \(n^2 + n + 41\)이 합성수인 까닭을 가장 잘 설명한 것은?
