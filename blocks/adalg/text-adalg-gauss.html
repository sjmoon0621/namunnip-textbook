가우스 소거법

본문

가스레인지의 프로페인이 타는 반응은 \(a\,\mathrm{C_3H_8} + b\,\mathrm{O_2} \to c\,\mathrm{CO_2} + d\,\mathrm{H_2O}\)이다. 반응 전후에 탄소, 수소, 산소 원자의 수가 같아야 하므로 원소마다 방정식이 하나씩 생긴다. 미지수는 넷인데 방정식은 셋이다. 손으로 이리저리 맞추어 보면 계수를 찾을 수 있지만, 원소와 물질이 많은 반응에서는 그렇게 하기 어렵다. 어떤 연립일차방정식이든 같은 순서로 차례차례 풀어 가는 방법이 있을까?

먼저 알아야 할 것연립일차방정식, 행렬의 뜻과 성분, 일차독립과 일차종속(일차독립과 일차종속).

2.1.1세 가지 행 연산

연립일차방정식의 계수와 상수항을 행렬로 늘어놓은 것을 첨가행렬이라 한다. 방정식을 풀 때 하는 일은 두 방정식의 순서를 바꾸기, 한 방정식에 0이 아닌 수를 곱하기, 한 방정식의 실수배를 다른 방정식에 더하기의 세 가지이다. 이 세 가지 기본 행 연산은 해를 바꾸지 않는다. 그래서 첨가행렬에 행 연산을 되풀이해 아래쪽 행부터 미지수를 하나씩 없애 계단 모양으로 만들고, 맨 아래 행에서부터 거꾸로 대입하면 해를 얻는다. 이것이 가우스 소거법이다.

정리 2.1.1 가우스 소거법과 해의 개수

기본 행 연산으로 첨가행렬을 행사다리꼴로 바꾸면, \(0 = (\text{0이 아닌 수})\) 꼴의 행이 생길 때 해가 없고, 그렇지 않으면 해가 있다. 해가 있을 때 각 행의 맨 앞 0이 아닌 성분이 있는 열의 미지수를 기본 변수, 나머지를 자유 변수라 하며, 자유 변수가 있으면 해가 무수히 많다.

미지수가 방정식보다 많은 동차 연립방정식은 자유 변수가 반드시 생기므로 0이 아닌 해가 무수히 많다. 반응식에서 이것은 계수를 모두 두 배, 세 배 해도 여전히 맞는 반응식이 된다는 뜻이다. 그래서 자유 변수 하나에 적당한 값을 주고 나머지를 정한 뒤, 계수가 가장 작은 자연수가 되도록 맞춘다. 가우스 소거법은 정해진 순서를 따르기만 하면 되므로 컴퓨터로 수천 개의 미지수가 있는 방정식도 풀 수 있다.1

2.1.2계단을 만들어 풀기

연립방정식 \(x + y + z = 6\), \(2x + y - z = 1\), \(x - y + 2z = 5\)에 가우스 소거법을 써 보자. 둘째 행에서 첫째 행의 2배를, 셋째 행에서 첫째 행을 빼면 \(x\)가 사라져 \(-y - 3z = -11\), \(-2y + z = -1\)이 된다. 다시 셋째 행에서 둘째 행의 2배를 빼면 \(7z = 21\)이 되어 \(z = 3\)이다. 거꾸로 대입하면 \(-y - 9 = -11\)에서 \(y = 2\), 첫째 식에서 \(x = 1\)이다. 그래서 해는 \((1, 2, 3)\) 하나뿐이다.

2.1.3예제 하나를 끝까지

예제 2.1.2

그림 1의 연립방정식을 가우스 소거법으로 풀어 프로페인 연소 반응식의 가장 작은 자연수 계수를 구하여라.

탄소의 식에서 \(c = 3a\), 수소의 식에서 \(d = 4a\)이다. 행 연산으로 쓰면 첫째 행을 3으로, 둘째 행을 2로 나누어 \(a\)의 계수를 맞추고 빼는 과정이다. 산소의 식에 넣으면 \(2b = 2c + d = 6a + 4a = 10a\)이므로 \(b = 5a\)이다. 미지수 넷에 방정식이 셋이어서 \(a\)가 자유 변수로 남는다.

계수가 가장 작은 자연수가 되도록 \(a = 1\)로 놓으면 \(b = 5\), \(c = 3\), \(d = 4\)이다. 그래서 반응식은 \(\mathrm{C_3H_8} + 5\,\mathrm{O_2} \to 3\,\mathrm{CO_2} + 4\,\mathrm{H_2O}\)이다. 확인하면 산소 원자는 왼쪽 10개, 오른쪽 \(6 + 4 = 10\)개로 같다. 즉 가우스 소거법은 세 가지 행 연산으로 미지수를 하나씩 없애 계단 모양을 만들고 거꾸로 대입하는 정해진 순서여서, 해가 하나인지, 없는지, 무수히 많은지까지 함께 알려 준다.

마무리

가우스 소거법은 행의 순서 바꾸기, 0이 아닌 수 곱하기, 한 행의 실수배를 다른 행에 더하기의 세 가지 행 연산으로 첨가행렬을 계단 모양으로 만들고, 맨 아래부터 거꾸로 대입해 해를 구한다. \(0 = \)(0이 아닌 수)인 행이 생기면 해가 없고, 자유 변수가 남으면 해가 무수히 많다. 처음 질문의 반응식은 자유 변수 \(a = 1\)로 놓아 \(\mathrm{C_3H_8} + 5\,\mathrm{O_2} \to 3\,\mathrm{CO_2} + 4\,\mathrm{H_2O}\)로 계수가 정해진다.
