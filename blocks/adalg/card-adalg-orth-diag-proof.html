대칭행렬의 고유벡터는 왜 서로 수직일까?

대칭행렬의 성질 · 증명 조립

  1. \(A^T = A\)이고 \(A\vec{v}_1 = \lambda_1\vec{v}_1\), \(A\vec{v}_2 = \lambda_2\vec{v}_2\), \(\lambda_1 \ne \lambda_2\)라 하자.
  2. \(\lambda_1(\vec{v}_1\cdot\vec{v}_2) = (\lambda_1\vec{v}_1)\cdot\vec{v}_2 = (A\vec{v}_1)\cdot\vec{v}_2\)이다.먼저 무엇을 가정하는지 밝혀야 합니다.
  3. \((A\vec{v}_1)\cdot\vec{v}_2 = (A\vec{v}_1)^T\vec{v}_2 = \vec{v}_1^TA^T\vec{v}_2 = \vec{v}_1^TA\vec{v}_2\) (\(A^T = A\)를 씀)이다.이 식은 \(\lambda_1(\vec{v}_1\cdot\vec{v}_2)\)를 행렬로 바꾼 뒤에 이어집니다.
  4. \(\vec{v}_1^TA\vec{v}_2 = \vec{v}_1\cdot(A\vec{v}_2) = \lambda_2(\vec{v}_1\cdot\vec{v}_2)\)이다.\(A\)를 \(\vec{v}_2\) 쪽으로 옮기는 단계(대칭을 쓰는 곳)가 먼저입니다.
  5. 따라서 \((\lambda_1 - \lambda_2)(\vec{v}_1\cdot\vec{v}_2) = 0\)이고 \(\lambda_1 \ne \lambda_2\)이므로 \(\vec{v}_1\cdot\vec{v}_2 = 0\), 곧 두 고유벡터는 수직이다.같은 양을 두 가지로 나타낸 식이 아직 완성되지 않았습니다.
  6. \(\lambda_1 \ne \lambda_2\)이면 \(\vec{v}_1 \ne \vec{v}_2\)이므로 두 벡터는 수직이다.다른 벡터라고 수직인 것은 아닙니다. 대칭이 아닌 행렬(c ≠ 1)에서 그림을 보세요.
  1. 질문앞 카드에서 대칭행렬의 두 고유벡터는 \(b\)를 아무리 바꿔도 늘 수직이었다. 우연일까, 아니면 증명할 수 있을까?
  2. 복원\(\vec{u}\cdot\vec{v} = \vec{u}^T\vec{v}\), \((AB)^T = B^TA^T\)이다.
  3. 설명요령은 \((A\vec{v}_1)\cdot\vec{v}_2\)를 두 가지로 계산하는 것이다. 한 번은 \(A\vec{v}_1 = \lambda_1\vec{v}_1\)으로, 한 번은 \(A\)를 반대편으로 옮겨 \(A\vec{v}_2 = \lambda_2\vec{v}_2\)로 계산한다. \(A\)를 옮길 때 \(A^T\)가 생기는데, 대칭이라 \(A^T = A\)이다. 두 결과가 같으려면 \(\lambda_1 \ne \lambda_2\)일 때 내적이 0이어야 한다.
  4. 연결이 성질에 "대칭행렬의 고윳값은 실수"라는 사실까지 쓰면, 모든 실대칭행렬은 직교대각화된다는 스펙트럼 정리가 나온다. 다음 절에서 이차곡선의 축을 찾는 근거이다.
  5. 적용증명을 순서대로 쌓자. 그다음 \(c\)를 움직여 대칭(\(c = 1\))일 때만 두 고유벡터가 수직인지 확인해 보자.
  6. 판단증명에서 \(A^T = A\)를 쓴 곳은 한 군데뿐이다. 그곳이 없으면 증명이 무너지고, 그림에서도 \(c \ne 1\)이면 각이 90°가 아니다. 가정이 증명의 어디에 쓰였는지 찾는 습관이 중요하다.
