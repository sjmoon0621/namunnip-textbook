두 그래프가 만나는 점
—

초록 실선은 좌변, 주황 점선은 우변의 그래프입니다. 두 그래프가 완전히 겹치면 모든 x에서 두 값이 같습니다.

  1. 질문x2 − 1 = (x + 1)(x − 1)은 x에 5를 넣어도 −3을 넣어도 맞습니다. 2x − 4 = 0은 x = 2일 때만 맞습니다. 둘 다 등식인데 무엇이 다를까요?
  2. 복원방정식은 특정한 x의 값에서만 참이 되는 등식이고, 그 값을 해라고 합니다. 다항식을 전개하면 차수별 계수로 정리할 수 있습니다.
  3. 설명문자에 어떤 값을 넣어도 항상 성립하는 등식을 그 문자에 대한 항등식이라 합니다. ax2 + bx + c = 0이 x에 대한 항등식이면 a = b = c = 0이고, 그 역도 성립합니다. 또 ax2 + bx + c = a'x2 + b'x + c'이 항등식이면 a = a', b = b', c = c'입니다. 까닭은 0이 아닌 이차 이하의 다항식은 0이 되는 x가 많아야 2개뿐이기 때문입니다. 그래서 이차 이하인 두 식의 그래프가 세 점 이상에서 만나면 완전히 겹칩니다. 이 성질로 항등식 속의 모르는 계수를 정하는 방법을 미정계수법이라 합니다. 양변을 전개해 같은 차수의 계수를 맞추는 계수비교법과, 계산이 쉬운 x의 값을 넣는 수치대입법이 있습니다.
  4. 연결다항식의 나눗셈 결과 A = BQ + R도 x에 대한 항등식입니다. 그래서 B가 0이 되는 x를 넣으면 몫을 몰라도 나머지를 구할 수 있습니다. 이것이 나머지정리입니다.
  5. 적용수치대입법: x = 1을 넣으면 우변에서 a와 b가 붙은 항이 0이 되어 c만 남습니다. 대입할 x를 1에 두고 c를 좌변 값에 맞추세요. 그다음 a, b를 움직여 두 그래프를 겹쳐 보세요. 완전히 겹치기 직전에 만나는 점은 몇 개인가요? 위 줄의 계수 비교로도 같은 답이 나오는지 확인하세요.
  6. 판단어떤 x 몇 개에서 양변이 같다고 항등식인 것은 아닙니다. 이차식끼리는 서로 다른 세 값에서 같아야 항등식이고, 두 값에서만 같으면 그래프가 두 점에서 만나는 것에 그칩니다. 수치대입법으로 모르는 수 세 개를 정하려면 서로 다른 x 세 개를 넣어야 합니다.
