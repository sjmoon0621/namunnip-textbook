연립일차부등식

본문

한 개에 800원인 과자와 한 개에 1,200원인 음료를 합쳐 10개 사려고 한다. 총액은 9,600원 이상 10,400원 이하로 맞추고 싶다. 음료는 몇 개를 살 수 있을까? 조건이 두 개이면 두 조건을 어떻게 함께 다룰까?

먼저 알아야 할 것중학교의 일차부등식 풀이와 부등식의 성질(양변에 음수를 곱하면 부등호의 방향이 바뀐다), 수직선 위의 범위 표시.

2.9.1조건마다 부등식 하나

음료를 \(x\)개 사면 과자는 \(10 - x\)개이므로 총액은 \(800(10 - x) + 1200x = 8000 + 400x\)원이다. 총액이 9,600원 이상이어야 하므로 \(8000 + 400x \ge 9600\)이고, 10,400원 이하여야 하므로 \(8000 + 400x \le 10400\)이다. 즉 조건 두 개가 부등식 두 개가 되었다.

첫째 부등식을 풀면 \(400x \ge 1600\), 곧 \(x \ge 4\)이다. 둘째 부등식을 풀면 \(400x \le 2400\), 곧 \(x \le 6\)이다. 두 조건을 모두 만족해야 하므로 \(x\)는 4 이상이면서 동시에 6 이하여야 한다. 따라서 \(4 \le x \le 6\)이고, 음료는 4개, 5개, 6개를 살 수 있다.

2.9.2공통부분이 해이다

정의 2.9.1 연립부등식

두 개 이상의 부등식을 한 쌍으로 묶어 나타낸 것을 연립부등식이라 하고, 각 부등식이 모두 일차부등식이면 연립일차부등식이라 한다. 각 부등식을 동시에 만족하는 \(x\)의 값 또는 범위를 연립부등식의 해라 한다.

정의에서 '동시에'가 뜻하는 것은 각 부등식의 해의 공통부분이다. 그림 1에서 위쪽 띠는 \(x \ge a\), 아래쪽 띠는 \(x \le b\)의 해이다. 두 띠가 겹치는 구간이 연립부등식의 해이다. 슬라이더로 \(a\)를 \(b\)보다 크게 만들면 두 띠가 겹치지 않는데, 이때 연립부등식은 해가 없다.

수직선에 그릴 때 등호가 들어간 끝점은 속을 채운 점으로, 등호가 없는 끝점은 속이 빈 점으로 나타낸다.1 끝점 하나의 차이로 해가 '한 점'이 되기도 하고 '없음'이 되기도 하므로, 그림을 그릴 때 이 구분을 놓치면 답이 달라진다.

2.9.3\(A < B < C\)꼴의 부등식

처음 질문의 조건은 한 줄로 \(9600 \le 8000 + 400x \le 10400\)이라고 쓸 수도 있다. 이런 \(A \le B \le C\)꼴은 '\(A \le B\) 그리고 \(B \le C\)'라는 연립부등식이다. 따라서 \(\begin{cases} A \le B \\ B \le C \end{cases}\)로 나누어 푼다.

그런데 이 꼴을 \(A \le C\)와 \(B \le C\)로 나누면 틀린다. 가운데 식 \(B\)가 양쪽 조건에 모두 들어가야 하기 때문이다. 처음 질문처럼 \(x\)가 가운데에만 있으면 세 변에 같은 수를 더하거나 같은 양수로 나누어 한 번에 풀어도 된다. \(1600 \le 400x \le 2400\)에서 \(4 \le x \le 6\)이 바로 나온다.

2.9.4예제 하나를 끝까지

예제 2.9.2

연립부등식 \(\begin{cases} 3x - 2 > x + 4 \\ 2(x - 1) \le x + 5 \end{cases}\)를 풀어라. 또 \(x - 1 < 2x + 3 \le 3x - 1\)을 풀어라.

첫째 부등식에서 \(2x > 6\)이므로 \(x > 3\)이다. 둘째 부등식은 \(2x - 2 \le x + 5\)이므로 \(x \le 7\)이다. 두 해를 수직선에 겹치면 3은 빈 점, 7은 채운 점이므로 해는 \(3 < x \le 7\)이다.

두 번째 문제는 \(x\)가 세 변 모두에 있으므로 한 번에 풀 수 없고, \(\begin{cases} x - 1 < 2x + 3 \\ 2x + 3 \le 3x - 1 \end{cases}\)로 나눈다. 첫째는 \(-4 < x\), 둘째는 \(4 \le x\)이다. 그러면 공통부분은 \(x \ge 4\)이다.

답이 맞는지 경계 근처의 값으로 확인해 보자. \(x = 4\)이면 \(3 < 11 \le 11\)이므로 성립하고, \(x = 3\)이면 \(2 < 9 \le 8\)에서 둘째 부등식이 깨진다. 아래 탐구 카드에서 두 부등식의 해를 수직선 위에서 직접 움직이며 공통부분이 바뀌는 모습을 확인해 보자.

  1. 부등식의 양변에 음수를 곱하거나 음수로 나누면 부등호의 방향이 바뀐다. 가령 \(-2x < 6\)을 풀면 \(x > -3\)이다. 연립부등식의 각 부등식을 풀 때도 이 규칙을 그대로 쓴다.
마무리

조건이 여러 개이면 조건마다 부등식을 세우고 각각 푼 뒤, 수직선 위에서 해들의 공통부분을 찾는다. 공통부분은 구간이 될 수도 있고, 한 점이나 공집합이 될 수도 있다. 처음 질문에서 두 조건의 공통부분은 \(4 \le x \le 6\)이므로 음료는 4개, 5개, 6개를 살 수 있다.
