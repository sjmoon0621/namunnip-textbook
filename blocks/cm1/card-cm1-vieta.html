두 근의 합과 곱은 계수 어디에 숨어 있을까?

근과 계수의 관계

—

\(\alpha + \beta\)
—
\(-b/a\)
—
\(\alpha\beta\)
—
\(c/a\)
—

실근 모드에서는 \(x\)축 위의 두 점 \(\alpha\), \(\beta\)를 끌어 옮기세요(0.5 간격).

  1. 질문\(2x^2 - 6x + 1 = 0\)의 근은 무리수라 계산이 번거롭습니다. 근을 구하지 않고 두 근의 합과 곱을 알 수 있을까요?
  2. 복원인수정리에 따르면 \(\alpha\), \(\beta\)가 이차방정식 \(ax^2 + bx + c = 0\)의 두 근이면 \(ax^2 + bx + c = a(x - \alpha)(x - \beta)\)는 항등식입니다. 항등식은 같은 차수의 계수끼리 같습니다.
  3. 설명오른쪽을 전개하면 \(ax^2 - a(\alpha + \beta)x + a\alpha\beta\)입니다. 계수를 비교하면 \(b = -a(\alpha + \beta)\), \(c = a\alpha\beta\)이므로 \(\alpha + \beta = -b/a\), \(\alpha\beta = c/a\)입니다. 이것을 근과 계수의 관계라 합니다. 근의 공식으로 나온 두 근을 더하고 곱해도 같은 결과가 나오므로, 두 근이 허근이어도 성립합니다.
  4. 연결합과 곱을 알면 \(\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta\), \((\alpha - \beta)^2 = (\alpha + \beta)^2 - 4\alpha\beta\), \(1/\alpha + 1/\beta = (\alpha + \beta)/\alpha\beta\)처럼 \(\alpha\), \(\beta\)를 바꾸어도 그대로인 식의 값을 근 없이 구합니다. \((\alpha - \beta)^2 = D/a^2\)이어서 판별식과도 이어집니다.
  5. 적용\(\alpha\), \(\beta\)를 끌어 옮기며 \(\alpha + \beta\)와 \(-b/a\), \(\alpha\beta\)와 \(c/a\)가 항상 같은지 보세요. \(a\)를 바꾸면 \(b\), \(c\)는 바뀌는데 두 비는 왜 그대로인가요? 두 근의 곱이 음수가 되게 놓으면 두 근은 어디에 있나요? 허근 모드에서 \(q\)를 움직이면 합과 곱 중 어느 것이 바뀌나요?
  6. 판단부호를 자주 틀립니다. 두 근의 합은 \(b/a\)가 아니라 \(-b/a\)입니다. 또 관계식은 \(ax^2 + bx + c = 0\) 꼴로 정리한 뒤에 씁니다. \(2x^2 = 6x - 1\)처럼 항이 양쪽에 있으면 먼저 한쪽으로 옮기세요.
