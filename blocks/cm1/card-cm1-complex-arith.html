복소수로 나눗셈은 어떻게 할까?

복소수의 사칙연산 · 켤레복소수

—

\(z\)
—
\(w\)
—
결과
—

\(z\) \(w\) 결과 · 점선은 켤레복소수 \(\overline{z}\)

  1. 질문\((1 + 2i) + (1 - i)\)나 \((1 + 2i)(1 - i)\)는 \(i\)를 문자처럼 두고 계산하면 된다. 그런데 \((1 + 2i) \div (1 - i)\)는 어떻게 \(a + bi\) 꼴로 만들까?
  2. 복원실수의 덧셈과 곱셈에는 교환법칙, 결합법칙, 분배법칙이 성립한다. 또 분모에 \(1 + \sqrt{2}\)가 있으면 \(1 - \sqrt{2}\)를 분모와 분자에 곱해 분모를 유리수로 만들었다.
  3. 설명복소수도 \(i\)를 문자처럼 계산하고 \(i^2\)만 \(-1\)로 바꾼다. 그래서 \((a + bi) \pm (c + di) = (a \pm c) + (b \pm d)i\), \((a + bi)(c + di) = (ac - bd) + (ad + bc)i\)이다. 이제 \(z = a + bi\)에서 허수부분의 부호만 바꾼 \(a - bi\)를 켤레복소수라 하고 \(\overline{z}\)로 쓰자. 그러면 \(z + \overline{z} = 2a\), \(z \overline{z} = a^2 + b^2\)으로 둘 다 실수이다. 따라서 나눗셈은 분모의 켤레복소수를 분모와 분자에 곱해 분모를 실수로 만들면 되고, \((a + bi)/(c + di)\) = {\((ac + bd) + (bc - ad)i\)}/\((c^2 + d^2)\)이다(단, \(c + di \ne 0\)).
  4. 연결켤레복소수로 나누는 방법은 분모의 유리화와 같은 생각이다. 또 복소수끼리 더하고 빼고 곱하고 0이 아닌 수로 나눈 결과는 다시 복소수이므로, 실수에서 쓰던 계산 법칙을 그대로 쓸 수 있다. 켤레복소수는 뒤에서 계수가 실수인 이차방정식의 두 허근으로 다시 나온다.
  5. 적용"\(z \div w\)"를 고르고 \(z = 1 + 2i\), \(w = 1 - i\)로 두어 결과를 읽어 보자. 그다음 "\(z \times \overline{z}\)"를 고르고 \(a\), \(b\)를 움직이면 결과 점이 늘 실수축 위에 머물고, \(a = b = 0\)일 때만 0이 된다. \(w\)를 0으로 만들면 나눗셈이 정의되지 않는 것도 확인해 보자.
  6. 판단나눗셈에서 실수부분끼리, 허수부분끼리 따로 나누면 안 된다. \((1 + 2i)/(1 - i)\)는 \(1/1 + (2/-1)i = 1 - 2i\)가 아니다. 실제로 곱해 보면 \((1 - 2i)(1 - i) = -1 - 3i\)여서 \(1 + 2i\)가 나오지 않는다. 그래서 계산이 끝나면 결과에 \(w\)를 곱해 \(z\)로 돌아오는지 검산하는 습관이 좋다.
