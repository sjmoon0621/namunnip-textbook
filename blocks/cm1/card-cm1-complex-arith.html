복소수로 나눗셈은 어떻게 할까?

복소수의 사칙연산 · 켤레복소수

—

\(z\)
—
\(w\)
—
결과
—

\(z\) \(w\) 결과 · 점선은 켤레복소수 \(\overline{z}\)

  1. 질문\((1 + 2i) + (1 - i)\)나 \((1 + 2i)(1 - i)\)는 \(i\)를 문자처럼 두고 계산하면 됩니다. 그런데 \((1 + 2i) \div (1 - i)\)는 어떻게 \(a + bi\) 꼴로 만들까요?
  2. 복원실수의 덧셈과 곱셈에는 교환법칙, 결합법칙, 분배법칙이 성립합니다. 분모에 \(1 + \sqrt{2}\)가 있으면 \(1 - \sqrt{2}\)를 분모와 분자에 곱해 분모를 유리수로 만들었습니다.
  3. 설명복소수도 \(i\)를 문자처럼 계산하고 \(i^2\)은 \(-1\)로 바꿉니다. \((a + bi) \pm (c + di) = (a \pm c) + (b \pm d)i\), \((a + bi)(c + di) = (ac - bd) + (ad + bc)i\)입니다. \(z = a + bi\)에서 허수부분의 부호만 바꾼 \(a - bi\)를 켤레복소수라 하고 \(\overline{z}\)로 씁니다. \(z + \overline{z} = 2a\), \(z \overline{z} = a^2 + b^2\)으로 둘 다 실수입니다. 그래서 나눗셈은 분모의 켤레복소수를 분모와 분자에 곱해 분모를 실수로 만듭니다. \((a + bi)/(c + di)\) = {\((ac + bd) + (bc - ad)i\)}/\((c^2 + d^2)\)입니다(단, \(c + di \ne 0\)).
  4. 연결켤레복소수로 나누는 방법은 분모의 유리화와 같은 생각입니다. 복소수끼리 더하고 빼고 곱하고 (0이 아닌 수로) 나눈 결과는 다시 복소수이므로, 실수에서 쓰던 계산 법칙을 그대로 쓸 수 있습니다. 켤레복소수는 계수가 실수인 이차방정식의 두 허근으로 다시 나옵니다.
  5. 적용"\(z \div w\)"를 고르고 \(z = 1 + 2i\), \(w = 1 - i\)로 두어 결과를 읽으세요. 그다음 "\(z \times \overline{z}\)"를 고르고 \(a\), \(b\)를 움직여 결과 점이 늘 실수축 위에 있는지 보세요. 결과가 0이 되는 것은 언제인가요? \(w\)를 0으로 만들면 나눗셈은 어떻게 되나요?
  6. 판단나눗셈에서 실수부분끼리, 허수부분끼리 따로 나누면 안 됩니다. \((1 + 2i)/(1 - i)\)는 \(1/1 + (2/-1)i = 1 - 2i\)가 아닙니다. 곱해 보면 \((1 - 2i)(1 - i) = -1 - 3i\)로 \(1 + 2i\)가 나오지 않습니다. 계산이 끝나면 결과에 \(w\)를 곱해 \(z\)로 돌아오는지 검산하세요.
