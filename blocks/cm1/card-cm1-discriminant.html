근의 공식의 √ 안이 음수이면 근이 없는 걸까?

판별식 · 실근과 허근

—

판별식 D = b2 − 4ac
—
근의 종류
—
근
—

그래프는 y = ax2 + bx + c입니다. 실근은 그래프가 x축과 만나는 점으로 보이지만, 허근은 그래프에 나타나지 않습니다.

  1. 질문x2 − 2x + 5 = 0을 근의 공식에 넣으면 x = (2 ± √−16)/2가 됩니다. √ 안이 음수이면 이 방정식은 근이 없다고 해야 할까요?
  2. 복원ax2 + bx + c = 0(a ≠ 0)을 완전제곱식으로 고치면 (x + b/2a)2 = (b2 − 4ac)/4a2이고, 여기서 근의 공식 x = (−b ± √(b2 − 4ac))/2a가 나옵니다. 음수 −k의 제곱근은 ±√k i입니다.
  3. 설명복소수 범위에서는 √−16 = 4i이므로 x = 1 ± 2i입니다. 실수인 근을 실근, 허수인 근을 허근이라 합니다. 근이 어떤 수인지는 √ 안의 값 D = b2 − 4ac가 정하므로 이것을 판별식이라 합니다. 계수가 실수일 때 D > 0이면 서로 다른 두 실근, D = 0이면 중근(서로 같은 두 실근), D < 0이면 서로 다른 두 허근을 가집니다. b = 2b′처럼 일차항의 계수가 짝수이면 D/4 = b′2 − ac로 계산해도 부호가 같습니다.
  4. 연결어떤 경우든 근의 공식으로 근이 나오므로, 계수가 실수인 이차방정식은 복소수 범위에서 항상 근을 가집니다(중근은 두 번 셉니다). D < 0일 때 두 허근 p + qi, p − qi는 서로 켤레복소수입니다. D의 부호는 그래프가 x축과 만나는 점의 개수와도 이어집니다.
  5. 적용세 번째 예(x2 − 2x + 5)에서 c를 줄이며 D가 0이 되는 c를 찾으세요. 그때 그래프는 x축과 어떻게 만나나요? c를 더 줄이면 근은 어떻게 바뀌나요? a를 음수로 바꾸어도 같은 판별이 통하는지, a = 0이면 무엇이 달라지는지 보세요.
  6. 판단"D < 0이면 근이 없다"는 실수 범위에서만 맞는 말입니다. 복소수 범위에서는 두 허근이 있습니다. 또 판별식으로 근을 가르는 방법은 계수가 실수인 이차방정식에만 씁니다. a = 0이면 이차방정식이 아니므로 판별식을 쓰지 않습니다. 실근을 가질 조건은 D ≥ 0입니다. 중근도 실근입니다.
