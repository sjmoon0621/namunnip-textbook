이차방정식과 이차함수

본문

이차방정식 \(x^2 - 4x + 3 = 0\)의 근은 1과 3이다. 이차함수 \(y = x^2 - 4x + 3\)의 그래프를 그리면 이 두 수는 어디에 나타날까? 그리고 근이 허수일 때 그래프는 무엇을 보여 줄까?

먼저 알아야 할 것중학교의 이차함수 \(y = a(x - p)^2 + q\)의 그래프와 꼭짓점, 판별식(이차방정식의 판별식).

2.4.1\(y = 0\)인 곳을 찾는 일

함수 \(y = x^2 - 4x + 3\)에서 \(x = 1\)을 넣으면 \(y = 0\)이다. \(x = 3\)을 넣어도 \(y = 0\)이다. 그래프 위에서 \(y\)좌표가 0인 점은 \(x\)축 위의 점이므로, 그래프는 점 \((1, 0)\)과 \((3, 0)\)에서 \(x\)축과 만난다.

거꾸로 그래프가 \(x\)축과 만나는 점을 찾는 일은 \(y = 0\), 곧 \(x^2 - 4x + 3 = 0\)을 푸는 일이다. 다시 말해 이차방정식 \(ax^2 + bx + c = 0\)의 실근은 이차함수 \(y = ax^2 + bx + c\)의 그래프가 \(x\)축과 만나는 점의 \(x\)좌표이다. 방정식은 수의 언어로, 그래프는 그림의 언어로 같은 질문을 한다.

2.4.2그래프를 위아래로 옮기면

그림 1의 슬라이더는 상수항 \(k\)를 바꾼다. \(y = x^2 - 4x + k = (x - 2)^2 + k - 4\)이므로 그래프의 모양은 그대로이고 꼭짓점 \((2, k - 4)\)만 위아래로 움직인다. 꼭짓점이 \(x\)축 아래에 있으면 그래프는 \(x\)축을 두 번 가로지르고, 꼭짓점이 \(x\)축 위에 놓이면 한 번 닿기만 하며, 꼭짓점이 \(x\)축보다 위로 올라가면 만나지 않는다.

이 세 경우를 판별식으로 확인할 수 있다. \(\dfrac{D}{4} = 4 - k\)이므로 \(k < 4\)이면 \(D > 0\), \(k = 4\)이면 \(D = 0\), \(k > 4\)이면 \(D < 0\)이다. 꼭짓점의 \(y\)좌표 \(k - 4\)가 \(-\dfrac{D}{4}\)와 같다는 것도 보인다.1

정리 2.4.1 이차함수의 그래프와 x축의 위치 관계

이차함수 \(y = ax^2 + bx + c\)의 그래프와 \(x\)축은 판별식 \(D = b^2 - 4ac\)에 따라 \(D > 0\)이면 서로 다른 두 점에서 만나고, \(D = 0\)이면 한 점에서 만나며(접하며), \(D < 0\)이면 만나지 않는다.

정리의 '접한다'는 그래프가 \(x\)축에 닿기만 하고 가로지르지 않는다는 뜻이다. 그림 1에서 \(k = 4\)일 때 꼭짓점 \((2, 0)\)이 바로 그 점이고, 방정식 \((x - 2)^2 = 0\)의 중근 2가 그 점의 \(x\)좌표이다. 근이 허수일 때 그래프가 보여 주는 것은 '만나는 점이 없다'는 사실이다. 허근은 \(x\)축 위의 어떤 점으로도 그려지지 않는다.

그래도 허근이 그래프와 아무 상관이 없는 것은 아니다. \(k = 5\)이면 방정식 \((x - 2)^2 + 1 = 0\)의 근은 \(x - 2 = \pm i\)에서 \(2 \pm i\)이다. 이번에는 그래프를 꼭짓점 \((2, 1)\)을 지나는 가로선 \(y = 1\)에 대해 위아래로 뒤집어 보자. 뒤집은 포물선은 \(y = 1 - (x - 2)^2\)이고, 이것은 \(x = 2 \pm 1\)에서 \(x\)축과 만난다. 허근 \(2 \pm i\)의 실수부분 2는 두 교점의 한가운데이고, 허수부분 1은 가운데에서 교점까지의 거리이다. 일반적으로 꼭짓점이 \((p, q)\)이고 \(q > 0\)인 \(y = (x - p)^2 + q\)의 허근은 \(p \pm \sqrt{q}\,i\)이고, 뒤집은 포물선 \(y = q - (x - p)^2\)은 \(x = p \pm \sqrt{q}\)에서 \(x\)축과 만나므로 같은 일이 늘 일어난다. 그림 1에서 \(k\)를 4보다 크게 하면 이 뒤집은 포물선이 점선으로 함께 나타난다.

2.4.3\(a\)의 부호가 바뀌어도

\(a < 0\)이면 그래프가 위로 볼록해서 꼭짓점이 가장 높은 점이 된다. 그래도 정리는 그대로이다. 이때는 꼭짓점이 \(x\)축보다 위에 있어야 두 점에서 만나는데, 이 경우에도 \(D > 0\)이다. 판별식은 그래프의 방향과 상관없이 교점의 개수를 알려 준다.

2.4.4예제 하나를 끝까지

예제 2.4.2

이차함수 \(y = -x^2 + 2x + k\)의 그래프가 \(x\)축과 서로 다른 두 점에서 만나고, 두 교점 사이의 거리가 4일 때 상수 \(k\)의 값을 구하여라.

먼저 두 점에서 만날 조건을 본다. 방정식 \(-x^2 + 2x + k = 0\)의 양변에 \(-1\)을 곱하면 \(x^2 - 2x - k = 0\)이고, \(\dfrac{D}{4} = 1 + k > 0\)이므로 \(k > -1\)이어야 한다.

두 교점의 \(x\)좌표를 \(\alpha\), \(\beta\)라 하면 이 방정식의 두 근이다. 근과 계수의 관계에서 \(\alpha + \beta = 2\), \(\alpha\beta = -k\)이다. 두 점 사이의 거리는 \(|\alpha - \beta|\)이고, \((\alpha - \beta)^2 = (\alpha + \beta)^2 - 4\alpha\beta = 4 + 4k\)이다.

거리가 4이므로 \(4 + 4k = 16\), 따라서 \(k = 3\)이다. 이 값은 조건 \(k > -1\)을 만족한다. 확인해 보면 \(y = -x^2 + 2x + 3 = -(x + 1)(x - 3)\)이므로 교점은 \(x = -1\)과 \(x = 3\)이고, 거리는 정말 4이다. 그래프로는 꼭짓점 \((1, 4)\)에서 아래로 열린 포물선이 \(x\)축을 \(-1\)과 3에서 가로지르는 모습이다. 아래 탐구 카드에서 그래프를 움직이며 교점과 근이 함께 움직이는지 직접 확인해 보자.

  1. 일반적으로 \(y = ax^2 + bx + c = a\left(x + \tfrac{b}{2a}\right)^2 - \tfrac{D}{4a}\)이므로 꼭짓점의 \(y\)좌표는 \(-\tfrac{D}{4a}\)이다. \(a = 1\)이면 \(-\tfrac{D}{4}\)이다.
마무리

이차방정식 \(ax^2 + bx + c = 0\)을 푸는 일은 그래프 \(y = ax^2 + bx + c\)에서 \(y = 0\)인 점을 찾는 일과 같다. 그래서 실근은 \(x\)축과의 교점의 \(x\)좌표로 나타나고, 교점의 개수는 판별식의 부호가 정한다. 처음 질문의 근 1과 3은 그래프가 \(x\)축을 가로지르는 두 점이고, 근이 허수이면 그래프는 \(x\)축과 만나지 않는다.
