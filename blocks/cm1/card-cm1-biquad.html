왼쪽 그림의 회색 띠는 \(t < 0\)인 곳입니다. \(t = x^2\)이 음수이면 \(x\)는 허수입니다.

  1. 질문\(x^4 - 5x^2 + 4 = 0\)에는 \(x^4\)과 \(x^2\)만 있고 홀수 차수 항이 없습니다. 이 모양을 이용하면 더 쉽게 풀 수 있을까요?
  2. 복원이차방정식 \(t^2 + pt + q = 0\)은 인수분해나 근의 공식으로 풉니다. 또 \(x^2 = k\)의 근은 \(k > 0\)이면 \(\pm\sqrt{k}\), \(k = 0\)이면 0, \(k < 0\)이면 \(\pm\sqrt{-k}i\)입니다.
  3. 설명\(x^2 = t\)로 놓으면 \(x^4 + px^2 + q = 0\)은 \(t^2 + pt + q = 0\)이 됩니다. 이 식을 풀어 \(t\)를 구한 뒤 \(x^2 = t\)를 다시 풉니다. \(x^4 - 5x^2 + 4 = 0\)이면 \((t - 1)(t - 4) = 0\)이므로 \(x^2 = 1\) 또는 \(x^2 = 4\), 곧 \(x = \pm1\), \(\pm2\)입니다. \(t\)에 대한 식이 인수분해되지 않을 때는 \(A^2 - B^2\) 꼴로 바꿉니다. \(x^4 + x^2 + 1 = (x^2 + 1)^2 - x^2 = (x^2 + x + 1)(x^2 - x + 1)\)처럼 완전제곱식에서 제곱식을 빼면 합차 공식으로 인수분해됩니다.
  4. 연결양수 \(t\) 하나는 실근 두 개\((\pm\sqrt{t})\)를, 음수 \(t\) 하나는 허근 두 개를 줍니다. 그래서 오른쪽 그래프가 \(x\)축과 만나는 횟수는 왼쪽 그래프의 근 가운데 양수인 것의 두 배입니다. 오른쪽 그래프는 \(y\)축에 대칭인데, \(x\)와 \(-x\)를 넣은 값이 같기 때문입니다.
  5. 적용\(p\)와 \(q\)를 움직이며 실근이 4개, 3개, 2개, 1개, 0개가 되는 경우를 하나씩 찾아보세요. 실근이 3개일 때 \(t\)의 값에는 어떤 공통점이 있나요? 네 번째 식에서 \(t\)는 어떤 수인가요?
  6. 판단\(t\)의 값을 구하고 끝내면 안 됩니다. \(t = 4\)는 \(x\)의 값이 아니라 \(x^2\)의 값입니다. 또 \(t\)가 음수라고 버리면 허근을 잃습니다. 문제가 실근만 묻는지, 복소수 범위의 근을 모두 묻는지 확인하세요.
