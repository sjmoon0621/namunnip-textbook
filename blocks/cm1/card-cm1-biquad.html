왼쪽 그림의 회색 띠는 \(t < 0\)인 곳이다. \(t = x^2\)이 음수이면 \(x\)는 허수이다.

  1. 질문\(x^4 - 5x^2 + 4 = 0\)에는 \(x^4\)과 \(x^2\)만 있고 홀수 차수의 항이 없다. 이 모양을 이용하면 사차방정식을 더 쉽게 풀 수 있지 않을까?
  2. 복원이차방정식 \(t^2 + pt + q = 0\)은 인수분해나 근의 공식으로 푼다. 또 \(x^2 = k\)의 근은 \(k > 0\)이면 \(\pm\sqrt{k}\), \(k = 0\)이면 0, \(k < 0\)이면 \(\pm\sqrt{-k}i\)이다.
  3. 설명그래서 \(x^2 = t\)로 놓으면 \(x^4 + px^2 + q = 0\)은 \(t^2 + pt + q = 0\)이 된다. 이 식에서 \(t\)를 구한 뒤 \(x^2 = t\)를 다시 풀면 된다. 예를 들어 \(x^4 - 5x^2 + 4 = 0\)은 \((t - 1)(t - 4) = 0\)이므로 \(x^2 = 1\) 또는 \(x^2 = 4\), 곧 \(x = \pm1\), \(\pm2\)이다. 그런데 \(t\)에 대한 식이 인수분해되지 않으면 \(A^2 - B^2\) 꼴로 바꾸어 본다. \(x^4 + x^2 + 1 = (x^2 + 1)^2 - x^2 = (x^2 + x + 1)(x^2 - x + 1)\)처럼 완전제곱식에서 제곱식을 빼면 합차 공식으로 인수분해된다.
  4. 연결양수 \(t\) 하나는 실근 두 개 \(\pm\sqrt{t}\)를, 음수 \(t\) 하나는 허근 두 개를 준다. 따라서 오른쪽 그래프가 \(x\)축과 만나는 횟수는 왼쪽 그래프의 근 가운데 양수인 것의 두 배이다. 또 오른쪽 그래프가 \(y\)축에 대칭인 것은 \(x\)와 \(-x\)를 넣은 값이 같기 때문이다.
  5. 적용\(p\)와 \(q\)를 움직이며 실근이 4개, 3개, 2개, 1개, 0개가 되는 경우를 하나씩 찾아보자. 실근이 3개일 때는 \(t\)의 값 하나가 꼭 0이라는 공통점이 보인다. 네 번째 식에서는 \(t\)가 어떤 수인지도 확인해 보자.
  6. 판단\(t\)의 값을 구하고 끝내면 안 된다. \(t = 4\)는 \(x\)의 값이 아니라 \(x^2\)의 값이기 때문이다. 또 \(t\)가 음수라고 버리면 허근을 잃는다. 그래서 문제가 실근만 묻는지, 복소수 범위의 근을 모두 묻는지 먼저 확인해야 한다.
