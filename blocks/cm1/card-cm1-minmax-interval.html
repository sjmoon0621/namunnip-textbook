  1. 질문f(x) = x2 − 4x + 1은 x = 2에서 가장 작은 값 −3을 가집니다. 그런데 x가 3 이상 5 이하로 정해져 있다면 최솟값도 −3일까요? 최댓값은 있을까요?
  2. 복원f(x) = a(x − p)2 + q에서 a > 0이면 꼭짓점에서 최솟값 q를 가지고 최댓값은 없습니다. 그래프는 축 x = p에서 멀어질수록 높아집니다.
  3. 설명α ≤ x ≤ β에서 그래프는 끊기지 않는 한 조각이므로 최댓값과 최솟값이 모두 있습니다. 후보는 꼭짓점(범위 안에 있을 때만)과 양 끝 f(α), f(β)뿐입니다. a > 0일 때 꼭짓점이 범위 안이면 최솟값은 q, 최댓값은 양 끝 가운데 축에서 더 먼 쪽의 값입니다. 꼭짓점이 범위 밖이면 범위 안에서 그래프가 한쪽으로만 올라가거나 내려가므로, 최댓값과 최솟값이 모두 양 끝에서 생깁니다. a < 0이면 최대와 최소의 역할이 바뀝니다.
  4. 연결꼭짓점은 완전제곱식으로 고쳐 찾습니다. 범위가 정해진 최대·최소는 길이, 넓이, 이익처럼 x에 현실적인 제한이 있는 문제를 풀 때 쓰입니다. 미적분에서 닫힌 구간의 최대·최소를 찾는 방법도 같은 생각입니다.
  5. 적용범위를 0 ≤ x ≤ 3으로 두고 최솟값이 꼭짓점에서 생기는지 보세요. 왼쪽 끝을 3으로 옮기면 최솟값은 어디서 생기나요? 범위가 축 x = 2를 사이에 두고 한쪽으로 더 길게 뻗을 때 최댓값이 어느 끝에서 생기는지 확인하세요. 위로 볼록한 두 번째 함수에서도 같은 규칙이 통하나요?
  6. 판단꼭짓점의 값을 무조건 답으로 쓰는 실수가 흔합니다. 꼭짓점이 범위 밖에 있으면 그 값은 f(x)가 범위 안에서 가지지 않는 값입니다. 또 범위에 끝점이 포함되지 않으면(예: 3 < x < 5) 최댓값이나 최솟값이 없을 수 있습니다. 꼭짓점이 범위 안인지, 끝점이 포함되는지를 먼저 확인하세요.
