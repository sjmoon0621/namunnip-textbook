복소수

본문

실수는 제곱하면 언제나 0 이상이므로 방정식 \(x^2 = -1\)에는 실수 해가 없다. 그렇다면 제곱해서 \(-1\)이 되는 새 수를 하나 약속하고 계산 규칙을 그대로 쓰면, 모순 없이 계산할 수 있을까?

먼저 알아야 할 것중학교의 제곱근과 실수, 근호 계산 \(\sqrt{a}\sqrt{b} = \sqrt{ab}\ (a, b \ge 0)\), 다항식의 연산(다항식의 연산).

2.1.1수는 방정식을 풀려고 넓어져 왔다

자연수만 알면 \(x + 3 = 1\)을 풀 수 없다. 그래서 음수를 들여와 정수를 만들었다. 정수만으로는 \(2x = 1\)을 풀 수 없어서 분수를 들여와 유리수를 만들었고, \(x^2 = 2\)를 풀려고 \(\sqrt{2}\) 같은 무리수를 더해 실수를 만들었다. 새 수를 들일 때마다 지켜 온 원칙이 있다. 원래 수의 계산 규칙은 그대로 둔다는 것이다.

이제 \(x^2 = -1\) 차례이다. 실수 가운데에는 답이 없으므로, 제곱해서 \(-1\)이 되는 수를 새로 하나 약속하고 이름을 \(i\)라 하자. 그러면 \(i^2 = -1\)이고, \(i\)는 '상상의 수'라는 뜻에서 허수단위라 부른다.

약속만 하고 넘어가면 \(i\)가 어떤 수인지 손에 잡히지 않으니, 수직선에서 곱셈이 하는 일을 다시 떠올려 보자. 3을 곱하면 0에서 멀어지는 거리가 세 배가 되고, \(-1\)을 곱하면 거리는 그대로인 채 0을 사이에 두고 반대쪽으로 넘어간다. 반대쪽으로 넘어가는 것을 0을 중심으로 반 바퀴 도는 것으로 보면, \(-1\)을 두 번 곱해 제자리로 오는 것도 반 바퀴씩 두 번 돌아 한 바퀴를 채운 것이다. 그렇다면 두 번 곱해서 \(-1\)이 되는 수는 두 번 하면 반 바퀴가 되는 움직임, 곧 4분의 1 바퀴 돌리기여야 한다. 수직선 위에는 4분의 1 바퀴 돈 자리가 없으므로 \(i\)는 수직선 밖, 0에서 수직선과 직각으로 뻗은 방향에 놓인다고 생각할 수 있다. 그림 1에서 \(i\)를 한 번 곱할 때마다 점이 원을 따라 4분의 1 바퀴씩 도는 것이 바로 이 그림이다.

2.1.2복소수의 뜻

\(i\)를 들였으면 \(2i\)도, \(3 + 2i\)도 생각할 수 있어야 한다. 덧셈과 곱셈을 그대로 쓰기로 했기 때문이다. 그래서 실수 \(a\), \(b\)로 \(a + bi\)꼴의 수를 모두 모은다.

정의 2.1.1 복소수

실수 \(a\), \(b\)에 대하여 \(a + bi\)꼴의 수를 복소수라 하고, \(a\)를 실수부분, \(b\)를 허수부분이라 한다. \(b = 0\)이면 실수이고, \(b \ne 0\)이면 허수이다. 두 복소수는 실수부분과 허수부분이 각각 같을 때 서로 같다.

정의에 따라 실수 \(5\)도 \(5 + 0i\)이므로 복소수이다. 즉 복소수는 실수를 버린 새 집합이 아니라 실수를 품은 더 큰 집합이다. 두 복소수가 같다는 조건이 '두 부분이 각각 같다'인 까닭은, 실수 \(a, b, c, d\)에 대해 \(a + bi = c + di\)이면 \(a - c = (d - b)i\)인데 왼쪽은 실수이므로 \(d = b\)여야 하기 때문이다.

2.1.3계산 규칙은 그대로

복소수의 덧셈과 뺄셈은 \(i\)를 문자처럼 보고 동류항끼리 모으면 된다. 가령 \((3 + 2i) + (1 - 5i) = 4 - 3i\)이다. 곱셈도 분배법칙으로 전개한 뒤, 나오는 \(i^2\)을 \(-1\)로 바꾸기만 하면 된다.

\((3 + 2i)(1 - 5i)\)를 전개하면 \(3 - 15i + 2i - 10i^2\)이다. 여기서 \(i^2 = -1\)이므로 \(-10i^2 = 10\)이고, 따라서 곱은 \(13 - 13i\)이다. 그림 1의 슬라이더로 \(n\)을 늘려 보면 \(i\)의 거듭제곱도 같은 규칙으로 계산된다. \(i^3 = i^2 \cdot i = -i\), \(i^4 = (i^2)^2 = 1\)이므로 네 번마다 값이 되풀이된다.

나눗셈에는 한 가지 장치가 더 필요하다. 복소수 \(a + bi\)에 대하여 \(a - bi\)를 켤레복소수라 하고 \(\overline{a + bi}\)로 쓴다. 둘을 곱하면 \((a + bi)(a - bi) = a^2 - b^2i^2 = a^2 + b^2\)으로 실수가 된다. 그래서 분모에 켤레복소수를 곱하면 분모의 \(i\)를 없앨 수 있다. 무리수를 분모로 가진 식에서 분모를 유리화하던 것과 같은 생각이다.

2.1.4음수의 제곱근

\(i\)가 있으면 음수의 제곱근을 쓸 수 있다. \(a > 0\)일 때 \((\sqrt{a}\,i)^2 = a \cdot i^2 = -a\)이므로 \(\sqrt{a}\,i\)는 \(-a\)의 제곱근이다. 이것을 \(\sqrt{-a} = \sqrt{a}\,i\)로 약속한다. 가령 \(\sqrt{-4} = 2i\)이고, \(-4\)의 제곱근은 \(\pm 2i\)이다.

그런데 근호의 곱셈 규칙 \(\sqrt{a}\sqrt{b} = \sqrt{ab}\)는 여기서 조심해야 한다. \(\sqrt{-4}\sqrt{-9}\)를 이 규칙대로 쓰면 \(\sqrt{36} = 6\)이 되지만, 약속대로 바꾸면 \(2i \cdot 3i = 6i^2 = -6\)이다. 둘 다 음수일 때는 규칙이 성립하지 않는 것이다.1 그래서 음수의 제곱근은 먼저 \(i\)를 써서 바꾼 다음에 계산한다.

2.1.5예제 하나를 끝까지

예제 2.1.2

\(\dfrac{3 + 2i}{1 - i}\)를 \(a + bi\)꼴로 나타내고, 결과가 맞는지 확인하여라.

분모 \(1 - i\)의 켤레복소수는 \(1 + i\)이다. 분자와 분모에 같은 수를 곱해도 값은 변하지 않으므로 둘 다 \(1 + i\)를 곱한다. 분모는 \((1 - i)(1 + i) = 1 - i^2 = 2\)가 된다.

분자는 \((3 + 2i)(1 + i) = 3 + 3i + 2i + 2i^2 = 3 + 5i - 2 = 1 + 5i\)이다. 따라서 \(\dfrac{3 + 2i}{1 - i} = \dfrac{1 + 5i}{2} = \dfrac{1}{2} + \dfrac{5}{2}i\)이다.

확인은 곱셈으로 한다. 몫에 나누는 수를 곱하면 \(\left(\tfrac{1}{2} + \tfrac{5}{2}i\right)(1 - i) = \tfrac{1}{2} - \tfrac{1}{2}i + \tfrac{5}{2}i - \tfrac{5}{2}i^2 = 3 + 2i\)이므로 분자가 그대로 나온다. 다시 말해 \(i^2 = -1\) 하나만 더한 규칙으로 덧셈, 뺄셈, 곱셈, 나눗셈이 모두 막힘없이 된다. 아래 탐구 카드에서 \(i\)의 거듭제곱과 복소수의 곱을 직접 계산해 보자.

  1. \(a < 0\), \(b < 0\)일 때만 \(\sqrt{a}\sqrt{b} = -\sqrt{ab}\)이고, 나머지 경우에는 \(\sqrt{a}\sqrt{b} = \sqrt{ab}\)이다. 나눗셈에서는 \(a > 0\), \(b < 0\)일 때 \(\tfrac{\sqrt{a}}{\sqrt{b}} = -\sqrt{\tfrac{a}{b}}\)이다.
마무리

제곱해서 \(-1\)이 되는 수 \(i\)를 약속하고 실수의 계산 규칙을 그대로 쓰면, \(a + bi\)꼴의 복소수 안에서 사칙연산이 모순 없이 이루어진다. 곱셈에서는 \(i^2\)을 \(-1\)로 바꾸고, 나눗셈에서는 켤레복소수를 곱해 분모를 실수로 만든다. 그래서 \(x^2 = -1\)은 복소수 범위에서 \(x = \pm i\)라는 해를 갖는다.
