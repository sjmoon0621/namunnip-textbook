나누어 보지 않고 나머지를 알 수 있을까?

나머지정리 · 인수정리

—

나눗셈의 나머지 R
—
P(a)
—
x − a는 인수인가
—

나머지 R은 긴 나눗셈(조립제법)으로 따로 계산한 값이고, P(a)는 그래프의 높이입니다. 두 값을 비교해 보세요.

  1. 질문x3 − 2x2 − 5x + 6을 x − 3으로 나눈 나머지를, 긴 나눗셈을 하지 않고 구할 수 있을까요?
  2. 복원다항식 P(x)를 B로 나눈 결과 P = BQ + R은 x에 대한 항등식입니다. 일차식으로 나누면 나머지 R은 상수입니다.
  3. 설명P(x) = (x − a)Q(x) + R은 항등식이므로 x = a를 넣어도 성립합니다. 그러면 (a − a)Q(a) = 0이 되어 R = P(a)입니다. 이것이 나머지정리입니다. 일차식 px + q로 나누면 나머지는 P(−q/p)입니다. 특히 P(a) = 0이면 나머지가 0이므로 P(x)는 x − a로 나누어떨어지고, x − a는 P(x)의 인수입니다. 거꾸로 x − a가 인수이면 P(a) = 0입니다. 이것이 인수정리입니다. 그래프에서 P(a)는 x = a에서의 높이이므로, 나머지가 0인 곳은 그래프가 x축과 만나는 곳입니다.
  4. 연결인수정리는 삼차식, 사차식을 인수분해할 때 첫 인수를 찾는 도구가 됩니다. 또 방정식 P(x) = 0의 해가 그래프와 x축의 교점이라는 생각은 이차방정식과 이차함수, 삼차방정식으로 이어집니다.
  5. 적용a를 움직이며 나머지 R과 P(a)가 언제나 같은지 확인하세요. 첫 번째 식에서 나머지가 0이 되는 a를 모두 찾으면 몇 개인가요? 두 번째 식에서는 a = −1.5에서 무엇이 보이나요? 세 번째 식에서는 a를 0.5 간격으로 바꾸어서는 나머지가 0이 되는 곳을 찾을 수 없습니다. 그래프는 무엇을 알려 주나요?
  6. 판단"x + 2로 나눈 나머지는 P(2)"라고 하는 실수가 흔합니다. x + 2 = x − (−2)이므로 P(−2)를 계산해야 합니다. 또 나머지정리는 일차식으로 나눌 때 나머지를 바로 알려 줍니다. 이차식으로 나누면 나머지가 일차식 mx + n이라 값 두 개가 필요합니다.
