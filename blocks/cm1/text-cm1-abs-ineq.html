절댓값을 포함한 부등식

본문

기준 무게 500 g에서 3 g 넘게 벗어나면 불량으로 치는 과자 봉지가 있다. 무게를 \(x\) g이라 하면 합격 조건은 \(|x - 500| \le 3\)이다. 이 부등식을 풀면 어떤 범위가 나오고, 절댓값 기호는 어떻게 벗겨야 할까?

먼저 알아야 할 것중학교의 절댓값(수직선에서 원점까지의 거리), 연립일차부등식(연립일차부등식).

2.10.1절댓값은 거리이다

중학교에서 \(|x|\)는 수직선 위에서 \(x\)를 나타내는 점과 원점 사이의 거리라고 배웠다. 그러면 \(|x - a|\)는 무엇일까? \(x - a\)는 \(x\)를 \(a\)만큼 왼쪽으로 옮긴 수이므로, \(|x - a|\)는 \(x\)와 \(a\) 사이의 거리이다. 가령 \(|7 - 4| = 3\)은 7과 4가 3만큼 떨어져 있다는 뜻이다.

이렇게 읽으면 처음 질문의 \(|x - 500| \le 3\)은 '\(x\)와 500 사이의 거리가 3 이하'라는 말이다. 500에서 왼쪽으로 3, 오른쪽으로 3까지가 그 범위이므로 \(497 \le x \le 503\)이다. 그림 1에서 \(a\)와 \(r\)을 바꾸어 보면, 범위는 언제나 \(a\)를 가운데에 둔 길이 \(2r\)인 구간이다.

정리 2.10.1 절댓값을 포함한 일차부등식

\(r > 0\)일 때 \(|x - a| < r \iff a - r < x < a + r\)이고, \(|x - a| > r \iff x < a - r\) 또는 \(x > a + r\)이다.

두 번째 경우는 거리가 \(r\)보다 큰 점들이므로 구간의 바깥, 두 쪽으로 갈라진 범위이다. '또는'이 붙는 까닭이 여기에 있다. 연립부등식의 해가 공통부분이었다면, 이 경우의 해는 합친 범위이다.

2.10.2범위를 나누어 기호를 벗기기

거리로 읽기 어려운 식도 있다. \(|x - 1| + |x + 2| < 5\)처럼 절댓값이 두 개이거나, \(|2x - 3| < x\)처럼 오른쪽에 \(x\)가 있으면 그렇다. 이때는 절댓값의 정의로 돌아간다. \(|A|\)는 \(A \ge 0\)이면 \(A\), \(A < 0\)이면 \(-A\)이다. 따라서 절댓값 안이 0이 되는 \(x\)를 경계로 범위를 나누면, 각 범위에서 기호를 확실하게 벗길 수 있다.

그림 2는 \(|x - 1| + |x + 2|\)의 경계 \(x = -2\)와 \(x = 1\)로 나눈 세 범위이다. 각 범위에서 기호를 벗겨 부등식을 풀고, 그 해가 그 범위 안에 있는 것만 남긴다. 마지막으로 세 범위의 해를 모두 합친다.

2.10.3예제 하나를 끝까지

예제 2.10.2

부등식 \(|x - 1| + |x + 2| < 5\)를 풀어라.

먼저 \(x < -2\)이면 두 식이 모두 음수이므로 \(-(x - 1) - (x + 2) < 5\), 곧 \(-2x - 1 < 5\)이다. 따라서 \(x > -3\)이고, 범위 \(x < -2\)와 겹치는 부분은 \(-3 < x < -2\)이다.

다음으로 \(-2 \le x < 1\)이면 \(-(x - 1) + (x + 2) = 3 < 5\)로 언제나 성립한다. 그래서 이 범위 전체 \(-2 \le x < 1\)이 해이다. 마지막으로 \(x \ge 1\)이면 \((x - 1) + (x + 2) = 2x + 1 < 5\)에서 \(x < 2\)이므로 \(1 \le x < 2\)이다.

세 결과를 합치면 \(-3 < x < 2\)이다. 거리로 읽어 확인할 수도 있다. \(|x - 1| + |x + 2|\)는 \(x\)에서 1까지의 거리와 \(-2\)까지의 거리의 합이다. 두 점 사이에 있으면 합이 늘 3이고, 바깥으로 1만큼 나가면 합이 2만큼 늘어 5가 된다. 그래서 경계가 \(-3\)과 2인 것이다.1 아래 탐구 카드에서 기준점과 거리를 바꾸며 해가 되는 구간을 직접 확인해 보자.

  1. \(|x - a| < r\)에서 \(r \le 0\)이면 거리는 음수가 될 수 없으므로 해가 없다. 반대로 \(|x - a| > r\)에서 \(r < 0\)이면 모든 실수가 해이다.
마무리

\(|x - a|\)는 수직선 위에서 \(x\)와 \(a\) 사이의 거리이므로, \(|x - a| \le r\)은 \(a\)를 가운데에 둔 구간이 되고 \(|x - a| > r\)은 그 바깥이 된다. 거리로 읽기 어려운 식은 절댓값 안이 0이 되는 점에서 범위를 나누어 기호를 벗긴다. 그래서 처음 질문의 합격 범위는 \(497 \le x \le 503\)이다.
