뽑아서 줄 세우는 방법은 왜 n(n − 1)(n − 2)…일까?

순열 · 계승

—

nPr
—
n!/(n−r)!
—
n!
—
  1. 질문8명 가운데 3명을 뽑아 1등, 2등, 3등 상을 주는 방법은 몇 가지일까요?
  2. 복원앞 단계에서 무엇을 골랐든 다음 단계의 선택 수가 같으면, 곱의 법칙에 따라 단계마다 선택 수를 곱합니다.
  3. 설명서로 다른 n개에서 r개를 택해 한 줄로 나열하는 것을 n개에서 r개를 택하는 순열이라 하고, 그 수를 nPr로 나타냅니다. 첫째 자리에는 n가지, 둘째 자리에는 이미 쓴 하나를 뺀 n − 1가지, …, r째 자리에는 n − r + 1가지가 올 수 있습니다. 따라서 nPr = n(n − 1)(n − 2)…(n − r + 1) (단, 0 < r ≤ n)입니다. n개를 모두 나열하는 수 n(n − 1)…2 · 1을 n의 계승이라 하고 n!로 씁니다. 계승을 쓰면 nPr = n!/(n − r)!입니다. 이 식이 r = n과 r = 0일 때도 성립하도록 0! = 1, nP0 = 1로 정합니다.
  4. 연결순열은 '뽑아서 순서대로 놓기'입니다. 순서를 따지지 않고 뽑기만 하는 조합의 수는 순열 목록에서 같은 모임끼리 묶어 나누어 구합니다.
  5. 적용n = 8, r = 3에서 '한 자리 채우기'를 눌러 자리마다 남은 후보 수가 어떻게 줄어드는지 보세요. r를 n까지 올리면 마지막 자리의 후보는 몇 개인가요? 같은 n에서 r = n − 1일 때와 r = n일 때 값이 같은 까닭을 생각해 보세요.
  6. 판단nPr를 n × r나 nr로 착각하기 쉽습니다. nr은 한 번 쓴 것을 다시 써도 되는 경우(예: 자리마다 숫자를 새로 고르는 비밀번호)의 수입니다. 순열에서는 한 번 쓴 것을 다시 쓰지 않으므로 자리마다 후보가 하나씩 줄어듭니다. 또 0! = 1은 증명한 결과가 아니라, 식이 계속 성립하도록 정한 약속입니다.
