행렬을 더하고 실수배하면 성분은 어떻게 바뀔까?

행렬의 연산 · 덧셈, 뺄셈, 실수배

—

(1, 1) 성분 계산
—
넓이의 비 (결과 : A)
—
도형의 방향
—

A의 각 열 (a1j, a2j)을 좌표평면의 점으로 보았습니다. 회색 점을 끌어 A를 바꾸세요. 점선 삼각형은 kA, 초록 삼각형이 결과입니다.

  1. 질문행렬 A의 각 열을 좌표평면의 점으로 보면 2 × 3 행렬 하나가 삼각형 하나입니다. A를 2배 하거나 다른 행렬 B를 더하면 삼각형은 어떻게 움직일까요?
  2. 복원두 행렬은 크기가 같고 같은 자리의 성분이 모두 같을 때 서로 같습니다. 좌표평면에서 점 (x, y)를 x축 방향으로 p, y축 방향으로 q만큼 옮기면 (x + p, y + q)가 됩니다.
  3. 설명크기가 같은 두 행렬 A, B에서 같은 자리의 성분끼리 더한 행렬을 A + B, 뺀 행렬을 A − B라 합니다. 실수 k에 대해 A의 모든 성분에 k를 곱한 행렬을 kA라 하고, 이것을 행렬의 실수배라 합니다. 예를 들어 (kA + B)의 (i, j) 성분은 kaij + bij입니다. 그림에서 B의 열이 모두 (p, q)이면 B를 더하는 것은 모든 꼭짓점을 같은 방향으로 옮기는 평행이동이고, k를 곱하는 것은 원점을 중심으로 k배 늘이는 것입니다. 모든 성분이 0인 행렬을 영행렬 O라 하며, A − A = O입니다.
  4. 연결성분끼리 계산하므로 수의 덧셈과 같은 방식으로 A + B = B + A, (A + B) + C = A + (B + C)가 성립합니다. 다항식에서 동류항끼리 모아 더한 것처럼, 행렬에서는 같은 자리끼리 모아 더합니다. 두 달 동안의 판매표를 합치거나 가격을 모두 1.1배 올린 표를 만드는 일이 바로 행렬의 덧셈과 실수배입니다.
  5. 적용k = 1, p = q = 0에서 시작해 p만 바꾸면 삼각형이 어느 쪽으로 움직이나요? 그다음 k를 2로 바꾸고 넓이의 비가 얼마인지 보세요. k = −1이면 도형은 어떻게 되나요? kA − B를 골라 B를 빼는 것이 반대 방향으로 옮기는 것과 같은지도 확인하세요.
  6. 판단행렬의 덧셈과 뺄셈은 크기가 같은 행렬끼리만 정의됩니다. 2 × 3 행렬과 3 × 2 행렬은 성분의 개수가 같아도 더할 수 없습니다. 또 2A는 A의 성분 하나가 아니라 모든 성분을 2배 합니다. 이 그림에서는 평행이동이 보이도록 B의 열을 모두 같게 두었을 뿐이고, 일반적인 B는 열마다 다른 수를 가질 수 있습니다. 그때는 꼭짓점마다 옮겨지는 정도가 달라 삼각형의 모양도 바뀝니다.
