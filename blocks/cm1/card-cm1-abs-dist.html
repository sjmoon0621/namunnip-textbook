\(|x - a| < r\)은 수직선에서 어떤 범위일까?

절댓값 부등식 · 거리로 읽기

—

경계 \(a - r\)
—
경계 \(a + r\)
—
해
—
  1. 질문\(|x - 1| < 3\)을 만족하는 \(x\)는 어떤 수일까요? 절댓값 기호를 어떻게 없애야 할까요?
  2. 복원\(|A|\)는 \(A \ge 0\)이면 \(A\), \(A < 0\)이면 \(-A\)입니다. 수직선에서 \(|x - a|\)는 \(x\)와 \(a\) 사이의 거리입니다. 예를 들어 \(|5 - 1| = |-3 - 1| = 4\)입니다.
  3. 설명\(r > 0\)일 때 \(|x - a| < r\)은 '\(a\)에서 거리가 \(r\)보다 가까운 점'이므로 \(a - r < x < a + r\)입니다. \(|x - a| > r\)은 '거리가 \(r\)보다 먼 점'이므로 \(x < a - r\) 또는 \(x > a + r\)입니다. 정리하면 \(|A| < r \Leftrightarrow -r < A < r\), \(|A| > r \Leftrightarrow A < -r\) 또는 \(A > r\)입니다. 그래서 \(|x - 1| < 3\)의 해는 \(-2 < x < 4\)입니다.
  4. 연결그래프로 보면 \(y = |x - a|\)는 \(x = a\)에서 꺾이는 V자이고, 부등식의 해는 V자가 수평선 \(y = r\)보다 아래(또는 위)에 있는 \(x\)의 범위입니다. V자의 두 갈래 \(y = x - a\)와 \(y = -(x - a)\)는 범위를 나누어 푸는 방법의 두 경우와 같습니다.
  5. 적용\(a\)를 움직이면 해의 구간은 어떻게 움직이나요? \(r\)을 0으로, 그리고 음수로 내리면서 <, ≤, >, ≥ 네 경우의 해가 어떻게 되는지 확인하세요. \(r = 0\)일 때 '해가 한 점', '해가 없음', '한 점만 빼고 모두'가 각각 어느 부등호에서 나오나요?
  6. 판단\(|x - a| > r\)을 '\(a - r > x > a + r\)'처럼 한 줄로 쓰면 틀립니다. 그런 \(x\)는 없습니다. 해는 두 부분으로 떨어져 있으므로 '또는'으로 씁니다. 또 우변이 음수이면 절댓값은 음수가 될 수 없으므로, <이면 해가 없고 >이면 모든 실수가 해입니다.
