\((a + b + c)^2\)의 아홉 조각은 어떻게 모일까?

인수분해 · 넓이 모형
\((a+b+c)^2\)
—
\(a^2+b^2+c^2\)
—
\(2(ab+bc+ca)\)
—

—

그림 속 세로 가르는 선을 좌우로 끌면 이웃한 두 길이가 바뀝니다(합은 그대로). 슬라이더로는 한 길이씩 바꿀 수 있습니다. 넓이는 상대값입니다.

  1. 질문\((a + b)^2\)은 정사각형을 네 조각으로 나눈 그림이었습니다. 항이 셋이면 몇 조각이 생기고, 어떤 조각끼리 모일까요? 거꾸로 \(x^2 + y^2 + 1 + 2xy + 2y + 2x\)는 한 식의 제곱으로 볼 수 있을까요?
  2. 복원인수분해는 하나의 다항식을 두 개 이상의 다항식의 곱으로 나타내는 것으로, 전개(곱셈 공식)를 거꾸로 하는 과정입니다. 중학교에서 \(a^2 + 2ab + b^2 = (a + b)^2\), 공통인수로 묶기를 배웠습니다.
  3. 설명한 변을 \(a\), \(b\), \(c\)로 자르면 조각이 9개 생깁니다. 대각선 위의 정사각형 셋은 \(a^2\), \(b^2\), \(c^2\)이고, 나머지 여섯 조각은 같은 직사각형이 둘씩 짝을 이룹니다\((ab, bc, ca)\). 그래서 \(a^2 + b^2 + c^2 + 2ab + 2bc + 2ca = (a + b + c)^2\)입니다. 인수분해할 때는 제곱인 항 셋과 '두 배의 곱' 항 셋을 찾습니다. 두 배의 곱 항의 부호가 \(a\), \(b\), \(c\)의 부호를 정합니다. 예를 들어 \(x^2 + y^2 + 1 - 2xy - 2y + 2x\)에서 \(2xy\)와 \(2y\)가 음수이므로 \(y\) 쪽을 \(-y\)로 잡아 \((x - y + 1)^2\)입니다.
  4. 연결인수분해의 첫 단계는 언제나 공통인수로 묶는 것입니다. 식이 길면 같은 덩어리를 한 문자로 바꾸는 치환을 씁니다. 예를 들어 \((x^2 + x)^2 + 2(x^2 + x) + 1\)은 \(x^2 + x = X\)로 두면 \((X + 1)^2 = (x^2 + x + 1)^2\)입니다. 세제곱 공식도 같은 방식으로 부피 모형을 만들 수 있습니다.
  5. 적용세로 선을 끌어 \(b\)를 가장 작게 만들어 보세요. 남는 그림은 어떤 공식의 그림과 닮았나요? \(ab\) 조각 두 개는 놓인 방향이 달라도 넓이가 늘 같은지, 세 수의 합이 언제나 \((a + b + c)^2\)과 같은지 확인하세요.
  6. 판단\((a + b + c)^2 = a^2 + b^2 + c^2\)으로 쓰는 실수는 직사각형 여섯 조각을 버린 것입니다. 넓이 모형은 \(a\), \(b\), \(c\)가 양수일 때만 그릴 수 있지만, 등식 자체는 전개로 확인되므로 음수나 문자식을 넣어도 성립합니다.
