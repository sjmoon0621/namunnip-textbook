디자인 프로그램은 점 네 개로 어떻게 매끄러운 곡선을 그릴까?

베지에 곡선과 내분점 · 만들기

  1. 질문글꼴의 둥근 획, 로고의 곡선, 애니메이션의 이동 경로는 컴퓨터 화면에서 점 몇 개를 끌어 모양을 정한다. 점 네 개만으로 어떻게 곡선 전체가 정해질까?
  2. 복원두 점 \(A\), \(B\)를 \(t : (1 - t)\)로 내분하는 점은 \((1 - t)A + tB\)이다.
  3. 설명조절점 \(P_0, P_1, P_2, P_3\)에서 이웃한 두 점을 \(t : (1-t)\)로 내분하면 점 3개, 다시 내분하면 2개, 한 번 더 하면 점 1개가 남는다. \(t\)를 0에서 1까지 움직일 때 이 마지막 점이 그리는 자취가 3차 베지에 곡선이고, 식으로는 \(B(t) = (1-t)^3P_0 + 3(1-t)^2tP_1 + 3(1-t)t^2P_2 + t^3P_3\)이다. 곡선은 \(P_0\)에서 출발해 \(P_3\)에서 끝나고, \(P_1\), \(P_2\)는 곡선이 휘는 방향을 정한다.
  4. 연결글꼴 파일, 벡터 그림(SVG), 애니메이션의 속도 곡선(ease-in-out)이 모두 베지에 곡선이다. 확대해도 깨지지 않는 까닭은 점이 아니라 식을 저장하기 때문이다.
  5. 적용점을 끌어 하트의 반쪽이나 영문자 S 모양을 만들어 보자. \(P_1\)과 \(P_2\)를 겹치면 곡선은 어떻게 되는가?
  6. 판단곡선은 대개 \(P_1\), \(P_2\)를 지나지 않는다. 조절점은 곡선을 끌어당기는 손잡이이지, 곡선 위의 점이 아니다.
