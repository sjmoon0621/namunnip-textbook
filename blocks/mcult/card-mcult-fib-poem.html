줄마다 글자 수가 1, 1, 2, 3, 5, 8인 시를 지어 볼까?

수열과 문학 · 만들기

  1. 질문시조는 3·4·3·4처럼 글자 수의 규칙을 지킨다. 행마다 글자 수가 피보나치 수열을 따르는 시(피보나치 시)를 지으면, 시의 모양은 어떻게 될까?
  2. 복원피보나치 수열은 \(F_1 = F_2 = 1\), \(F_{n+2} = F_{n+1} + F_n\)이다.
  3. 설명피보나치 시는 행의 글자 수가 1, 1, 2, 3, 5, 8, …로 늘어난다. 각 행이 앞의 두 행을 합친 길이라서, 시는 점점 빠르게 넓어지는 삼각형 모양이 된다. 수학의 규칙이 형식을 정하고, 그 형식 안에서 표현을 고르는 것이 창작의 재미이다. 음악의 박자, 시조의 음수율도 같은 생각이다.
  4. 연결정해진 규칙(제약) 안에서 만드는 창작은 문학 실험 모임 울리포(OuLiPo)가 즐겨 쓴 방법이다.
  5. 적용예시 시를 바꿔 여러분의 피보나치 시를 6행 이상 지어 보자. 7행은 몇 글자여야 하는가?
  6. 판단글자 수를 맞추려고 뜻이 어색한 말을 넣으면 시가 망가진다. 규칙과 의미가 둘 다 살아야 좋은 작품이다.
