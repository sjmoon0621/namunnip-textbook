현의 길이를 어떻게 나누면 두 소리가 잘 어울릴까?

음악과 비 · 조작

소리는 단추를 누를 때만 난다. 기본음은 220 Hz(라)로 정했다.

  1. 질문피타고라스 학파는 줄 하나를 매단 악기로 실험했다고 전해진다. 줄을 어디쯤 눌러야 원래 소리와 잘 어울리는 소리가 날까?
  2. 복원비 \(a : b\)를 가장 작은 자연수의 비로 나타내기, 반비례 \(y = \frac{k}{x}\)를 떠올리자.
  3. 설명줄의 장력이 같으면 진동수는 울리는 길이에 반비례한다. 길이를 \(\frac12\)로 하면 진동수가 2배인 옥타브, \(\frac23\)이면 1.5배인 완전5도, \(\frac34\)이면 \(\frac43\)배인 완전4도이다. 진동수의 비가 간단한 자연수의 비일수록 두 파형이 자주 맞아떨어져 어울리는 소리(협화음)로 들린다. \(\frac{\sqrt2}{2}\)처럼 무리수 비는 파형이 끝내 맞아떨어지지 않는다.
  4. 연결기타의 프렛, 피아노 현의 길이, 관악기의 관 길이도 같은 원리이다. 다음 카드에서는 이 비로 음계를 만들 때 생기는 문제를 본다.
  5. 적용간단한 비와 √2/2를 차례로 눌러 파형과 소리를 비교해 보자. 간단한 비에서 두 파형이 다시 맞아떨어지기까지 각각 몇 번 진동하는가?
  6. 판단어떤 소리가 "어울린다"는 느낌은 문화와 경험에도 영향을 받는다. 간단한 비가 협화음이라는 설명은 서양 음악 전통에서 널리 쓰이는 하나의 모형이다.
